## 1. 游戏类型定位（第 1 类相关部分）

- **游戏类型**：大地图商队 RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件
- **地图形式**：格子地图，不采用爬塔路线，不采用自由移动
- **移动方式**：像下棋——向上、下、左、右移动一格
- 不是 3D 开放世界（早期废弃方案，已全部丢弃）

---

## 2. 时间系统

游戏所有系统统一到 **"天数"** 上计算。

| 项目 | 规则 |
|---|---|
| 移动 1 步（1 格） | 消耗 1 天 |
| 休养 1 天 | 重伤恢复进度 +1 |
| 等待 1 天 | 天气推进 +1 |
| 订单期限 | 按天计算 |
| 天气持续 | 按天计算 |
| 补给消耗 | 按天消耗 1 份 |

> 核心体验：每一步都是一天，每一天都在消耗，每一次等待都在赌订单，每一次坏天气都可能是灾难，也可能是机会。

## 3. 地图规格

| 项目 | 规则 |
|---|---|
| 地图尺寸 | 8×6 或 10×6 的格子 |
| 出发位置 | 左下角 |
| Boss 位置 | 远端（右上角方向） |
| 移动方式 | 向上、下、左、右移动一格 |
| 每移动一格 | 消耗 1 天 + 1 份补给 |
| 第一版地图 | 固定地图，不需要随机生成 |

> 地图详细设计（具体每张地图的格子布局）已搁置，留到正式开发时再做。本文件只记录地图规格参数。

## 4. 地图节点（格子）类型

地图上每一格可能是以下类型之一：

| 序号 | 节点类型 | 功能 |
|:---:|----------|------|
| 1 | 空地 | 只消耗资源，无事件 |
| 2 | 战斗 | 进入普通战斗 |
| 3 | 事件 | 触发随机事件（正面/负面/选择分支） |
| 4 | 营地 | 可以休息、修车、鼓舞士气 |
| 5 | 补给点 | 可以治疗、招募、替换队员 |
| 6 | 危险区 | 可能战斗，也可能获得奖励（高风险高回报） |
| 7 | Boss | 区域最终战，击败后激活驿站 |

## 5. 移动消耗

每移动一格的消耗：

| 消耗项 | 规则 |
|---|---|
| 当前天数 | +1 |
| 补给 | -1 份 |
| 重伤角色休息倒计时 | -1（休息节点数 -1） |

### 5.1 补给耗尽惩罚

**补给 = 0 时，每移动 1 天：**
- 士气 -1
- 全队每人失去 2 点生命

**士气 ≤ 2 时缺补给移动：**
- 士气 -1
- 全队每人失去 3 点生命
- 有概率获得疲惫状态

## 6. 路线分类

两个休息点（驿站/城镇/中继点）之间的平均距离约为 **30 天**。

路线按总天数分类如下：

| 路线类型 | 总距离 | 定位 |
|:-------:|:------:|------|
| 短途 | 30 天以上，60 天以下 | 新手路线 / 短途跑商 |
| 中途 | 60 天以上，120 天以下 | 有规划压力的主力路线 |
| 长途 | 120 天以上，180 天以下 | 真正远征 |
| 超长 | 180 天以上 | 后期大订单 / 边境商路 |

### 6.1 推荐补给携带量

| 路线类型 | 理论最低补给 | 推荐携带 |
|:-------:|:----------:|:--------:|
| 短途（30–60 天） | 30–60 | 40–80 |
| 中途（60–120 天） | 60–120 | 80–150 |
| 长途（120–180 天） | 120–180 | 150–220 |
| 超长（180 天以上） | 180+ | 220+ |

### 6.2 中继点

中继点可以是：驿站、小镇、村庄、半废弃货站、边境前哨、旧路标节点、灰烬边缘点。

### 6.3 每段路线参考参数

| 项目 | 参考值 |
|---|---|
| 城市到第一个驿站 | 约 18–24 天 |
| 两个休息点之间 | 约 30 天 |
| 安全绕路 | 在原天数上增加约 20%–25% |
| 高风险捷径 | 在原天数上减少约 15%–25% |

## 7. 经济参考（关联第 2.1 类全局经济系统）

本章只引用与路线消耗直接相关的经济数据，完整经济系统参见《第 2.1 类_全局经济与物价锚点系统》。

### 7.1 基础物资价格（城市基准价）

| 物资 | 城市基准价 |
|:---:|:---------:|
| 补给 | 10 金币 / 份 |
| 零件 | 50 金币 / 个 |
| 药包 | 50 金币 / 个 |

### 7.2 路线消耗模型

路线消耗按以下方式估算：

```
每天折算成本：
  补给        10 金币
  零件折算     5 金币
  药包折算    10 金币
  事件/修理预留 5 金币
  ─────────────────
  合计        30 金币 / 天
```

**出行预计消耗 ≈ 天数 × 30 金币**

例：
- 50 天短途 → 约 1500 金币
- 100 天中途 → 约 3000 金币
- 150 天长途 → 约 4500 金币

> 此公式用于倒推订单奖励和判断路线压力，不是精确结算公式。实际消耗会受修补师技能、天气、战斗、事件等因素浮动。

### 7.3 订单期限

订单期限按路线路程天数的 **1.3 倍** 计算：

```
订单期限 = 路程天数 × 1.3
```

例：
- 100 天路程 → 订单期限 130 天
- 200 天路程 → 订单期限 260 天

### 7.4 订单奖励参考

单个主订单奖励按预计消耗倒推，参考第 2.1 类经济系统：

```
单个订单奖励 ≈ 预计消耗 × 1.5（中心值，浮动范围 1.4–1.7）
```

| 路线天数 | 预计消耗 | 订单奖励（约） |
|:-------:|:-------:|:-------------:|
| 30 天 | 900 | 1260–1530 |
| 60 天 | 1800 | 2520–3060 |
| 100 天 | 3000 | 4200–5100 |
| 150 天 | 4500 | 6300–7650 |
| 220 天 | 6600 | 9240–11220 |

> 长线真实总收益（含顺路订单、自营贸易、战斗收益等）可达 20000–30000 金币。

## 8. 玩家路线决策

出发前玩家需要判断以下事项：

1. 到下个驿站大概多少天
2. 要带多少补给
3. 要带多少零件
4. 是否少带货、多带生存物资
5. 天气是否适合出发
6. 订单期限是否允许等待
7. 遇到坏天气是否硬闯、绕路或等待
