## 1. 移动与每日结算（体力系统）

### 1.1 移动

- **移动**：每格消耗 **20 点野外体力**（🔴 **恒定**）。体力池 **上限 100 · 每天回复 50**（🔴 **与人数无关** —— 车队固定池；**没花完可留到明天**）；日回全速约 2.5 格/天、**攒满冲刺 5 格**、均速约 2 格/天。
  - 🔴 **每格消耗只有「变高」、没有「变低」**：恶劣天气（+5 / +10）· 坏路况 · 超载 · **车况损坏**（抛锚 / 车轮磨损 / 爆裂 / 陷车）→ 同样天数走得更近。见第 1A 类 §2 / §5.1、第 5A 类。
  - 🔴 **2026-10-05：原「车轮可降每格消耗」已删除**（用户裁定：**否则后期会被无限拉长**）。车轮从此**只是车况项**，不是提速档。
- 移动本身**不推进天数、不扣补给 / 耐久**；只扣体力 + 标记该格已探索 + 触发地图 / 事件 / 战斗判定（判定规则见 `19`）。
- 天数 = 自然日：**体力用尽算 1 天**（**池里没花完的余量不清零，留到明天**）。

### 1.2 何时触发日终结算

⚠️ **关键**：每日结算在**「当天体力耗尽（池见底）」或「主动休整」时统一触发一次**，**不是每走一格触发一次**。

### 1.3 `daily_settle()` 结算顺序（严格按此序，禁止调换）

| # | 步骤 | 说明 |
|:--:|:--|:--|
| 1 | `day += 1` | 先推天数 |
| 2 | 推进灰度（**三层**） | **L1 固定不动**（地图常数场 · 设计上限 750）· **L2 每 3 天重掷**（`L1 × ±20%`，封顶 ±40）· **L3 随天气段**（灰烬风 +100 / 风暴 +200）—— 规则见 `19`（第 8A 类 §2）· 锚 A23 |
| 3 | 推进天气 | 含灰烬风暴概率，规则见 `19`（第 5A 类） |
| 4 | 补给消耗 | `food -= N`、`water -= N`（🔴 **N = 出战人数**，Rule L：不出战的人不消耗；旧 `-= 14` 按全队人数算，已废） |
| 5 | 耐久磨损（地形基础） | 每车 `durability -= 1.5`（见 §4） |
| 6 | 灰度额外磨损 | 若 `current_gray(pos) >= 50` → 每车再 `-1`（宜绕路） |
| 7 | 断粮 / 断水惩罚 | 见 §3（`food<=0` → 士气 −1 + **全员最大生命减少"该角色上限的 10%"** 且**当前血同步减少同样点数**；`water<=0` → 士气 −1 + **20%**（同上）；两者皆 0 叠加） |
| 8 | 感染风险 | 若 `current_gray >= 70` → 标记感染（城市可治愈） |
| 9 | 死亡 / 抛锚判定 | 任一角色 `hp<=0` → `alive=False`（可治疗复活）；单辆 `durability<=0` → 抛锚（**须修到 20 以上**才能动，见 §8） |
| 10 | 强制撤退判定 | 🔴 **三种"失败"**（见 §8）：**① 士气归零**（系统）· **② 全队严重重伤（全部失去战斗力）+ 零件耗尽**（系统 · 🔴 2026-10-10 改，门槛**上调**）· **③ 手动撤退**（玩家主动认输，**代价明显更小**）。触发则**退到「玩家指定的已探明大城 / 小城」**（🔴 2026-10-12 三硬规则，原"出发时的安全点"已废）、付代价后继续玩——**本版没有"失败"结局，不结束这一局** |

> **顺序固定的原因**：避免「先扣耐久再判边界」之类 bug。每一步都写日志（见 `11`）。

## 2. 补给消耗（每人每天）

| 资源 | 每人每天 | 14 人 / 天 | 占格 | 重量 |
|:--|:--:|:--:|:--:|:--:|
| 食物 | 1 份 | 14 份 | 1 格 = 5 份（升级 10 份） | 1 格 ≈ 1 kg |
| 水 | 1 份 | 14 份 | 1 格 = 1 水箱 = 3 份（喝完占格不释放，空箱 0.1 kg） | 1 格 = 2 kg |
| 零件 | 维修用 | 见 §4 | 1 格 = 1 个 | 1 格 = 3 kg |
| 药包 | 治疗用 | 见角色 | 1 格 = 1 个 | 1 格 = 1 kg |

- ⚠️ **无推荐携带量**：玩家按路线 / 资金 / 据点自行采购（第 3A 类 §1.4），想怎么买就怎么买。
- 余烬核心 / 火种 / 金钱 **不占格**。

## 3. 断粮 / 断水惩罚（立即生效，不等待）

| 状态 | 每天惩罚 |
|:--|:--|
| **食物 = 0** | 士气 -1 + 全员最大生命 **-10%** + 重伤恢复恶化 |
| **水 = 0** | 士气 -1 + 全员最大生命 **-20%** + 重伤恢复恶化 |
| 两者皆 0 | 双重惩罚叠加，商队迅速崩溃 |

> 最大生命降低是百分比、可累积（连续断粮天数越多，上限越低）；进城补满食物/水后恢复。
> 路上天然水源多为脏水，需净化（见 §7）。

---

## 4. 商队耐久（3 辆货车各自独立）

> **只有货车计耐久**；载人车（**小型 / 大型**）不拉货、不计耐久、不被攻击、不吃护盾（见 `16 §5`）。

- **上限**：3 车 × 60 = **180**；每车独立计，单辆 0 → 抛锚（**须修到 20 以上才能动**）。
- **地形损耗**：每车每天 **-1.5**（底层小数累加，显示取整；60 天累计 -90/车，已超单辆 60 上限 → 中途必须维修）。
- **战斗损耗**（**按每车扣**，三辆货车同扣）：普通 **每车 -5（全队 -15）** / 精英 **每车 -10（全队 -30）** / Boss **每车 -50 以上**。
- **修车**：1 零件修 **10 耐久/个**（升级后 20 耐久/个，见第 3A 类 §3.5）；高灰区（灰 ≥ 50）额外磨损，宜绕路。
- **一段路（30 天）总损耗 ≈ 225**（地形 135 + 战斗 90）→ **超过上限 180，中途必须修车**；**单辆纯自持力 ≈ 24 天**（地形 1.5 + 战斗摊销 1.0 = 2.5/天），**但随身零件可路上自助修车**（1 零件 = 10 耐久）→ **据点间距 ≈30 天左右**（20~30、不固定），**24~30 天之间的缺口靠零件补**。
- 无修补师时约 **0.73 零件/天**（60 天 ≈44 个，⚠️ 实测）。

## 5. 士气

- 0~10；断粮 / 断水每天 -1；酒馆 150 / 宴席 400 / 豪华 800（无单城次数限）。
- **士气归零 → 强制撤退**（不是游戏结束，见 §8.2）。
- 消耗类（药包 / 修车）也吃战斗共享体力（**25 点**，第 4A 类 §2.4）。

---

## 6. 车厢占格与载重

- 3 货车 × **300 格 = 900 格**；载重 = 格 × 2 = **1800 kg**（临界 2 kg/格）。
- 食物 5/格、水 3/格（水箱）、零件 1/格（3 kg）、药包 1/格（1 kg）。
- **不整理仓库**：格子当作资源计数，玩家不需手动整理（第 3A 类 §3）。

---

## 7. 脏水与净化（后期机制）

- 路上天然水源多为**脏水**；未净化饮用挂负面状态（中毒 / 腹泻 / 疾病），不推荐。
- 后期解锁**净化设备**（水箱改造 / 车载净水模块）后可安全饮用，减轻超长途（≥200 天）补给压力。
- 净化设备属可升级项（第 3A 类 §3.5），升级途径 ⚠️ 待定。

## 8. 打不过怎么办：强制撤退（**没有"失败"结局**）

> 用户 2026-09-12：**"不要有失败了——失败了之后回到最近的安全点。"** 这与 0A 第3A类 §5 完全一致（0A 原话："失败本质是商队被迫撤退止损，**不是游戏结束**"）。此前本文件把它写成 `outcome="lose"` 结算是错的，已改。

### 8.1 抛锚

- 单辆货车耐久 0 → **抛锚**，无法移动，须就地修车（零件）或进城**修到 20 以上**脱困。
- 🔴 **修复门槛 20**（= 单辆上限 60 的 1/3）：用户 2026-10-06 裁定 ——「**不要必须修到 10 以上才能动，要修到 20 以上才能继续行动**」。
  **为什么涨到 20**：抛锚的代价必须**真的疼** —— 修 10 点就能走，等于代价只有「半天 + 一点零件」；修 20 点才走，**意味着要在原地停一整段**（且停着照按天吃补给和工资）。符合铁律：**让玩家感到"太远修不起"，不是"系统不许"** —— 随时能修，只是得多花一两天。

### 8.2 三种"失败"（🔴 2026-10-06 用户裁定）

| # | 类型 | 触发 | 是谁决定的 |
|:--:|:----|:--|:--|
| 1 | **士气崩溃** | 士气归 0 | 系统 |
| 2 | 🔴 **全队严重重伤 + 零件耗尽** | **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）** | 系统 |
| 3 | 🔴 **手动撤退** | **玩家主动点撤退** | **玩家自己** |

> 🔴 **第 3 种（手动撤退）也算失败** —— 相当于**玩家主动认输**。但**代价明显小于前两种**（见 §8.4）。
> 🔴 **第 2 种的门槛是刻意调高的**（2026-10-10 / 10-12 用户裁定）—— 原条件"全队倒下 + 耐久归零"**打输就触发**，但**打输不等于没救**。现改为**两头都堵死**：**人**（🔴 **全队严重重伤**＝全部失去战斗力，⚠️ **不是普通重伤** —— 前三次重伤能靠等待恢复）+ **车**（🔴 **零件耗尽**，再也修不好）。
> 🔴 **为什么不是"药包耗尽"**（2026-10-12 用户纠正）：**药包只加血 —— 对严重重伤的人无效**（他不是伤，是动不了）。所以带不带药包都一样。
> **设计意图**：🔴 **玩家还有希望的时候，永远不会触发强制撤退。**

### 8.3 撤退目的地（🔴 2026-10-12 三硬规则）

🔴 **所有撤退（三种失败都算）退到「玩家指定的、已探明的大城 / 小城」。**

| 项目 | 规则 |
|:--|:--|
| **撤退目的地** | 🔴 **只能是大城 / 小城** —— 城镇 / 驿站 / 村庄**都不接收撤退** |
| **必须已探明** | 没到过 / 没侦察过的地方，**玩家不知道那儿有没有城** → 不能退 |
| **由玩家指定** | 🔴 **不是"最近的那个"、不是"出发时的安全点"**（旧口径，已废） |
| **中途经过的安全点** | 🔴 **不作数** —— 路过一座城不等于改主意；想在那儿当据点，就得**先把订单路线改成从那儿出发** |
| **城市也不是绝对安全区** | 安全点只是**能休整 / 治疗 / 补给 / 接单**，**灰兽潮照样来**（`第2A类 §1`） |

> 🔴 **为什么不是"出发时的安全点"**（旧口径已废）：那会让玩家**故意往坏地形里冲** —— 反正出事就退回起点，风险被系统买单。
> 🔴 **为什么不是"沿途最近的安全点"**：玩家会**走到一半就往后撤**，**白赚一半路程** —— 地图等于没有风险。
> 🔴 **"你选 + 你付代价"**：代价按**实际要退回多远**算（`第3A类 §5.2.2`）。

### 8.4 撤退后果（**然后接着玩**）

**A. 士气崩溃 / 全队严重重伤 + 零件耗尽（被动失败）**

| 惩罚项 | 内容 |
|:--|:--|
| **位置** | **退到玩家指定的已探明大城 / 小城**（§8.3） |
| 货物 | 🔴 **按距离档随机抽**（近30% / 中45% / 远60%；强制撤退固定 50%）|
| 食物 / 水 / 零件 | **全部损失**（药包本来就已经耗尽） |
| 全员 | 强制进入休养状态 |
| 士气 | **不额外扣**（触发时已为 0）· 到达后**恢复到 1** |
| 商队耐久 | 降到 **30**（**总耐久**；3 辆车均摊各 **10** 点） |
| 当前订单 | 大概率失败或严重降级 |
| 金钱 | **不扣**（0A 明确"避免彻底死档"） |

**B. 🔴 手动撤退（玩家主动认输 · 代价明显更小）**

| 惩罚项 | 内容 |
|:--|:--|
| **性质** | **主动认输** —— 不是被打崩 |
| **位置** | **退到玩家指定的已探明大城 / 小城**（§8.3） |
| 货物 | 🔴 **损失可自选比例**（如 10% / 25%，玩家自己挑） |
| 食物 / 水 / 零件 | 少量 |
| 士气 | **主动撤退 −2** · 到达后恢复到 1 |
| 商队耐久 | 视损失比例 |
| 全员 | **无强制休养** |
| 当前订单 | **可当场放弃** |
| 金钱 | **不扣** |

> 🔴 **为什么手动撤退代价更小**：它是**玩家的主动选择** —— 一看"这趟亏了"果断掉头止损，这是**合理的经营决策**，不该跟"被打崩"同等处罚。**惩罚的是被动失败**；主动认输只需付"退掉的货"这份**真实成本**（铁律 8：**惩罚只能要价，不能剥夺**）。
- 数据实现上 `outcome` **只有 `""`（进行中）/ `"win"`（通关）两种**，没有 `"lose"`（见 `07` §4）。
- 撤退判定放在 `daily_settle()` 第 10 步（见 §1.3）；但**全队严重重伤 + 零件耗尽发生在战斗里时，由战斗结算当场触发**（见 `17`）。

## 9. 实现接口（供 `07_一局流程` 串接）

- `daily_settle(state, cfg, rng, log)`：当天体力耗尽 / 主动休整时调用，**按 §1.3 的顺序**结算。
- `move_step(state, cfg, rng, log, pos)`：走 1 格，消耗 20 点体力，做地图 / 事件 / 战斗判定（**不结算日终**）。
- 具体函数签名与数据类见 `05_数据结构` / `06_模块结构`（`caravan/supply.py`）。
