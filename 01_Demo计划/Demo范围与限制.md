# 🔴 Demo 的范围与限制（从 A 类抽出来的集中说明）

> 🔴 **2026-10-12 整理** —— 原先散落在 `0A_权威系统文档/` 各文件里的 Demo 内容，**全部抽到这里**。
> **理由**：🔴 **A 类是"游戏怎么运作"的权威，不该被"Demo 暂时不做"污染** —— 否则以后看设定的人会被"Demo 不做""Demo 才400×400"误导。

---

## 🔴 核心原则

| | |
|:--|:--|
| 🔴 **`0A_权威系统文档/` = 游戏本身的规则** | 与"做不做 Demo"**无关** |
| 🔴 **`01_Demo计划/` = 这一版做多少** | 临时范围，**Demo 做完就会变** |

**所以**：A 类里**不再出现**"Demo 不做""Demo 暂缓"这类话 —— 它们全部属于本页。

---

## 🔴 一、Demo 只测什么

| 机制 | Demo | 正式版 | 备注 |
|:--|:--:|:--:|:--|
| 🔴 **体力机制**（走路 / 赶路节奏） | ✅ **做、测** | ✅ | `第1A类 §2` —— **速度恒定，没有提速轴** |
| 🔴 **选路机制**（棋盘 / 岔路选择） | 🔴 **不做** | ✅ | 🔴 **Demo 的走法差异由体力节奏承担** |
| 捷径与绕路触发规则 | 🔴 **不做** | ✅ | 同上 |

> 🔴 **为什么这样分**：**选路是"体验"，体力是"骨架"** —— Demo 先验证骨架（能不能跑通、数值对不对），体验层留给正式版。

---

## 🔴 二、Demo 的地图规模（**这些数字不属于游戏设定**）

| | 值 |
|:--|:--|
| **Demo 地图尺寸** | **400×400 格** |
| **Demo 地点数** | **76 个** |
| **坐标权威** | 🔴 `01_Demo计划/地图坐标.txt` |
| ⚠️ **正式版规模** | 🔴 **完全未定** —— 不受上面两个数字约束 |

> 🔴 **重要**：**正式版的地图多大是未定的**，需要等行进节奏定死后单独设计。**不要把 400×400 / 76 地点当成游戏的正式设定。**

---

## 🔴 三、Demo 的其他范围限制

| 限制 | 内容 |
|:--|:--|
| **只测体力** | 🔴 选路、岔路、翻越 vs 绕行**全部不做** |
| **余烬核心 = 激活钥匙**（不是能源）| 只激活**节点反应炉**（`第7A类 §四`：钥匙 + 烬油，缺一不可）|
| **节点反应炉只在大城** | 9 个大城有，小城没有 |
| **无传送 / 驿站无回城** | 🔴 不存在"传送回城" |
| **不做专版测试图** | 🔴 **同一张正式版地图**，Demo 只做一小块（"麻雀虽小五脏俱全"）|

## 🔴 四、Demo 的通关条件

| | |
|:--|:--|
| 🔴 **通关 = 攒够钱主动打灰烬城** | **不是"撑到 X 天"** |
| **Demo 无剧情** | 主线在正式版 |
| **无"失败"结局** | 🔴 **三种撤退**（士气崩溃 / 全队严重重伤+零件耗尽 / 手动撤退）—— 退到**玩家指定的已探明大城/小城**，**本局继续** |

## 🔴 五、Demo 必须测 / 不测的系统

**必测 16 项**：大地图移动 · 资源 · 五类地点 · 交易 · 订单 · 卡牌战斗 · 3 敌种 · 随机事件 · 节点激活 · 天气 · 侦察 · 撤退 · 装备(4-10套) · 遗迹(1-2处) · 记忆 · 招募(1-2人)

**不测 7 项**：灰兽潮 · 主线支线剧情 · 存档 · 玩家城市建设 · 情报购买 · 工会商会声望 · 地图随机生成
