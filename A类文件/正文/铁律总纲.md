## 二、机制设计铁律（怎么设计）

|  #  |              铁律             | 说明                                                                                     |
| :-: | :-------------------------: | :------------------------------------------------------------------------------------- |
|  12 |    🔴 **惩罚只能「要价」，不能「剥夺」**   | 掉钱 / 货 / 士气 / 强制撤退 / 多花天数；**迟到 ≠ 失败**                                                  |
|  13 |          **别用硬限制**          | 让玩家感到"太远养不起"，不是"系统不许"；大地图无硬边界                                                          |
|  14 | 🔴 **每一个机制必须能回答「它服务于哪条体验」** | 答不出 → 是摩擦，砍掉；只能服务于优化 → 降级（让"不优化"也能玩）。⚠️ **"玩家会很烦"= 机制失败的信号**                           |
|  15 | 🔴 **给「为什么」必须写机制性理由，不许自己编** | 判据：**这个理由防住了哪个坏结果**？只是"听起来合理" = 不合格。**理由必须是用户给的，或能防住具体坏结果的**                           |
|  16 |     🔴 **不许自己造规则冒充用户裁定**    | 用户没定的（如"单日行动 ≤10 小时"）**只能当提案**，并**明确问用户**；禁止写进正文当铁律                                    |
|  17 |      **每件装备必须有「做不到的事」**     | 不是"做得差的事"；**让敌人制造选择，不要让数值制造选择**                                                        |
|  18 |    **机制解释前先确认它在服务哪条既定机制**   | 连续否掉 3 次方案就该停下来问，别硬撑                                                                   |
|  19 |           **规模三层**          | `§0.7.4` 没钱时 · `§0.7.7` 有钱后 · `§0.7.8` 一次性事件                                           |
|  20 |      **据点不能没有；村庄不算据点**      | **危险来自"恢复跟不上"**                                                                        |
|  21 |    **不设「减员 / 被挖走 / 逃跑」**    | **商队人数只增不减**；不出战的人**还在车队上**（不领工资、不消耗补给、不会消失、不会老）                                       |
|  22 |   🔴 **失败 = 撤退，没有"游戏结束"**   | 三种：士气崩溃 / 全队倒下 / **手动撤退（代价明显更小）**；**统一退到出发时的安全点**，且**必须玩家指定**、**只能退大城 / 小城**、**必须已探明** |
|  23 |    🔴 **惩罚里不许有"剥夺玩家投入"**    | 装备被回收、构筑被清空、核心成员被限制 —— 这类设计一律不做                                                        |
| 🔴 **24** | 🔴 **不做性格数值 / 善恶值 / 魅力值**   | **养成系统是这类游戏的默认引力** —— 一旦做了性格值，玩家就会开始刷那个值，**成长就变成了刷数值**。🔴 **也不做「完成度」结算**（一旦完成度可算，最优解就变成"全收集"）。🔴 依据 → `第0B类 §八` |

## 三、时间 / 速度 / 体力（2026-10-13 用户定，**别再改错**）

|         项目        |              口径              | 🔴 注意                                                        |
| :---------------: | :--------------------------: | :----------------------------------------------------------- |
|    **每天可行动时间**    |   **07:00 → 19:00 = 12 小时**  | 入夜睡觉**不耗时间**；**单日没有任何额外硬顶**                                  |
|     **走 1 格**     |     **2 小时 + 野外体力 15 点**     | 两个闸门                                                         |
|       **速度**      |    **正常 3 格/天 · 极限 4 格/天**   | 冲刺 = 攒满池 **6 格**                                             |
|     **野外体力池**     | **上限 100 · 日回 50 · 每格 15 点** | 🔴 **上限是 100，不要动它**                                          |
|  **野外体力为什么不随人数变** |        🔴 **所有人都要一起走**       | **这是唯一理由，不许编别的**（如"车就那么多"——用户明确否掉）                           |
| 🔴 **"10 小时"是什么** |       **超长订单全程的游玩时长尺度**      | **不是单日行动上限**（`1A §7.1`：≈600 格 ≈ 10 小时 → 超长档封顶 600 格 / 200 天） |
|      **速度恒定**     |         **没有任何提速手段**         | 只有「变慢」（天气 / 路况 / 超载 / 车况），**没有「变快」**                         |
|     **全库折算基准**    |           **3 格/天**          | 按天计的（订单期限 / 补给 / 工资）**不随速度变**                                |

## 四、地图与信息

|  #  |            铁律           | 说明                                                               |
| :-: | :---------------------: | :--------------------------------------------------------------- |
|  24 |   🔴 **大城 / 小城必须分开写**   | **只有大城（九城）有节点反应炉**；**小城没有节点**（`7A §二`）—— 不是"缩水版大城"               |
|  25 |     **迷雾只针对「随机事件」**     | **除随机事件之外没有迷雾**：地形 / 灰度读数 / 地点位置 / **遗迹位置** —— 玩家直接可见（`1A §9.0`） |
|  26 |       **遗迹位置永远不变**      | 随机的是**信息与内容时机**，不是位置                                             |
|  27 | **所有玩家能到达的地块踩上去都可触发事件** | 例外 = 城市格 / 据点格（"踩上去 = 进界面"）                                      |
|  28 |    **侦察只抬信息等级、不给坐标**    | 看到具体格子的唯一途径 = 走到十字邻格（等级到顶也一样）                                    |
|  29 |      **格子类型只写一张总表**     | 安全等级 / 能否撤退 / 有无反应炉**并入同一张表**，**不许再另设一张重复的表**                    |

## 五、失败与撤退（摘要）

- **撤退三硬规则**：🔴 只能退**大城 / 小城** · 🔴 必须**已探明** · 🔴 **玩家指定**（不是最近的，否则白赚一半路程）
- **代价 = 按距离档随机抽货损**（手动 / 士气崩溃按距离分档，强制固定）
- **撤退路上不补扣补给**（否则会饿死在路上 = 死档）
- **重伤四级**：重伤 → 加重 → 再加重 → 🔴 **严重重伤 = 全部失去战斗力**
- 🔴 **强制撤退条件 = 全队严重重伤 + 零件耗尽**（两头堵死；**药包只加血、对严重重伤无效，所以不进条件**）

## 六、术语与文风

- 🔴 **正式术语在前、白话在括号里** —— 例：**「全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）」**、抛锚（这辆车动不了）、重度灰度区（水粮都不太正常）
- **只用机械 / 工程语汇**：禁用医学·生物语汇（摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体）。「身体改造」→**加装 / 装具**；「排异」→**不兼容**
- 🔴 **装具 9 项定名**：运动 = 助力臂架 / 背负支架 · 循环 = 循环辅助背心 / 滤尘面罩 · 代谢 = 净水壶 / 解毒滤面罩 · 感知 = 反应辅助头环 / 防尘罩衣 · 独立 = 负重背心
- **命名只改内容、不造新词**；反感江湖风 / 奇怪名目
- **不做恐怖 / 惊悚 / 生物改造感**
- 🔴 **不要用像地名的词描述"某个最高点"**（如"后期深处"）—— 要么写死它是描述、要么换说法
- **正文要干净**：不留重复表、不留"东说一句西说一句"的散段；同一件事只在一处说
