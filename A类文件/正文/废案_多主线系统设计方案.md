# 【废案】多主线系统设计方案

> **状态：已废止（2026-09-24 正式废止）**
> 本文档仅作历史记录与追溯，**不代表现行权威设定**。**不得据以开发。**
> 🔴 **现行口径见 `A类文件\正文/第7A类_世界观与设定_权威口径.md` §第零部分「无强制主线 · 长支线 · 多结局」** —— 🔴 **原「单主线」表述也已于 2026-10-23 作废**（"只有一条主线"把世界写成了围着一个目标转）。

---

## 废止原因（2026-09-24）

1. **架子已空转** —— 多主线是为旧「救世线（母兽 / 烬渊山）」搭的架构；**母兽设定已废**（见 `废案_灰烬母兽设定.md`）→ "救世线"地基消失，9 线框架失去支点。
2. **一人开发的规模上限** —— 9 条线（当时只定 3 条），每条都要有自己的**目标 / 故事 / 结局 / 玩法侧重 / 冲突表**；**写量与测试面积 = 线数 × 单线长度**，不可承受。
3. **与基调冲突** —— 现行基调用的是"**世界不逼你当英雄**""**弱引导**""**目标由玩家自己定义**"。多主线表面是自由，实际是**把自由变成一道开局选择题**（当商人 / 探索者 / 救世主）——**是在给玩家派角色**，反而更窄。

## 替代口径（现行）

| 层 | 现行 |
|:--|:--|
| **世界** | 🔴 **世界自己按自己的逻辑发展** —— 🔴 **玩家不推进它照样发展** |
| **主线** | 🔴 **无强制主线** —— 🔴 **「九城重连」只是玩家可以选的一种活法，不是唯一正确的目标** |
| **支线** | **若干长支线**，贯穿多幕 —— **自由度的主要来源** |
| **结局** | **多结局保留**：灰烬止息 / 灰烬吞噬 / 时间结局 / 灰烬共生 —— 🔴 **但不算「通关」** |

> 🔴 **多主线 ≠ 多结局。** 结局是**同一条主线的不同收场**，不是"不同的线"；**砍线不砍结局**。
> 🔴 **自由度来自「支线」与「世界开口」，不来自「主线分叉」。**
> 🔴 **完整口径 → `第7A类 §第零部分`** · 🔴 **整体结构 → `第0B类`**。

## 原方案正文（历史快照 · 不得据以开发）

以下为废止时的原文，仅作追溯。

### 一、核心结构

#### 1.1 世界基础活动（不是主线）

| 活动 | 说明 |
|:-----|:-----|
| **点亮九城** | 像开放世界"开图"——玩家自由做的基础目标（激活节点、打通商路） |
| 定位 | 不是主线本身；但某些主线可能**要求**先激活某些城（前置条件） |

#### 1.2 多条主线（总框架9条）

- **总框架：9条主线**
- 现在先定 **3 条**（其余6条之后再做）
- 每条主线独立：有自己的目标、故事、结局
- **不做"多线完成度"机制**（难设定）——玩家一个存档选择推进主线，想体验其他主线就开新存档

#### 1.3 存档设计

- 一个存档 = 一条主线的主视角体验
- 玩家可开多个存档体验不同主线（多周目式）
- 不强制一个存档玩完所有主线

### 二、已定3条主线

#### 主线①：商道线（商人之道）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 打通全部商路，建立九城最强商行（商业帝国） |
| 配套玩法 | **商会系统**（创建商会/雇佣商队/发布订单）+ **城市经营**（买城/收税/建设）+ **动态经济**（供需影响价格） |
| 对应玩家 | 纯商人——最契合商队身份 |
| 结局方向 | 富可敌国 / 商行崩塌 / 商业帝国（具体结局后定） |

#### 主线②：秘闻线（灰潮之秘）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 查清灰潮真相、母兽来历、旧文明秘密 |
| 配套玩法 | **遗迹探索**（旧文明废墟）+ **情报系统**（线索收集）+ 各地文献 |
| 对应玩家 | 求知的探索者 |
| 结局方向 | 真相公开 / 真相深埋 / 真相被利用（具体结局后定） |

#### 主线③：救世线（终结灰潮）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 激活九城、直面烬渊山的母兽，终结灰潮 |
| 配套玩法 | **卡牌战斗**（高难Boss战）+ **旧文明武器**（终极爆发）+ 激活节点 |
| 对应玩家 | 想当英雄的人 |
| 结局方向 | 吸收现有4结局：灰烬止息 / 灰烬吞噬 / 灰烬共生 / （时间结局） |

> 现有主线故事（激活九城→真相→烬渊山→母兽）归入**救世线**。

### 三、玩法多样化（配合多主线）

主线多了，玩法也要多样，每条主线有各自的玩法重点：

| 主线 | 核心玩法 | 次要玩法 |
|:-----|:---------|:---------|
| 商道线 | 贸易/经营/商会 | 跑商/护送 |
| 秘闻线 | 探索/遗迹/情报 | 战斗/解谜 |
| 救世线 | 战斗/激活节点 | 跑商（补给准备） |

> 玩家选不同主线 → 玩法侧重不同 → 一个游戏多种体验。

### 四、主线冲突（部分互斥）

- **不是所有主线都冲突**——有些可并行
- **部分主线互斥**：核心资源/NPC互斥时二选一
  - 例：A线要杀某NPC，B线要保护该NPC → 做了A，B锁死
- 冲突关系：**具体哪几条冲突，之后定**

### 五、待定

| 待定项 | 说明 |
|:-------|:------|
| 剩下6条主线 | 之后设计（含教团立场线等） |
| 每条主线的具体剧情 | 分段故事（后写） |
| 结局细节 | 每条主线的结局变体 |
| 冲突关系表 | 哪几条互斥 |
| 与支线的挂钩 | 哪些支线支撑哪些主线 |
