## 1. 战斗定位与目标

- **战斗类型**：回合制战术卡牌，**全队共享一个体力池**（🔴 **出战人数不是固定三人** —— 按当期出战人数变化，见 §2.2）
- 🔴 **战斗体验口径（2026-10-25~28 用户与 ChatGPT 讨论）**：**以思考和决策为核心** —— 玩家的战斗能力来自**卡牌及其组合 · 记忆提供的知识与效果 · 武器装备 · 能力间的协同**；**重视研究构筑、分析规则、组合能力的过程**，🔴 **不考验实时反应、不依赖大量随机性**。具体机制**服从本作设计目标**，**不照搬**传统卡牌游戏的抽牌 / 打牌 / 行动点等规则。
- **UI 形式**：队列式 UI，不是棋盘
- **核心目标**：不只是杀敌，还要保护商队、保护货物、避免重伤
- **与杀戮尖塔区别**：
  - 🔴 **多人小队共享一个体力池**（出战人数可多可少，**不是固定三人**），不是单角色构筑
  - 三层防御结构
  - 战斗结果会影响大地图旅程
  - 伤害分内伤 / 外伤，**内伤不可被防御阻挡**

### 1.1 核心设计红线（最高优先级 · 不可违反）

> ⚠️ **本红线高于一切数值与组合设计。任何新卡牌、新组合、新机制在加入前必须通过本红线审查。**

- **游戏类型约束**：本作是 **RPG（角色养成类）**，不是 Roguelike。玩家一旦获得的卡组 / 构筑会**永久保留**，不会随单局重置。
- **禁止单回合无限出牌**：严禁出现「某组卡组合可在单回合内打出几十 / 上百张牌」的连锁（如 出牌→产牌→再出牌 的指数级滚雪球）。**本作没有"出牌张数上限"** —— 闸门设在另外两处：**① 每回合起手只能选 3 张牌**（2 动作 + 1 记忆，§2.3）；**② 出牌消耗「体力」**，而体力池每回合按出战人数固定（§2.2）。**打出过程中新生成的牌不计入本回合可继续打出**，进入手牌留待下回合。
- **禁止伤害严重溢出**：严禁出现「一击秒全图 / 单回合清场」的溢出组合。单体伤害应有合理上限；**Boss 单独设计**（血量 / 承伤 / 回合结构全独立，见 §8.1），清杂兵靠数值平衡而非无限连。
- **原因**：Roguelike 里无限 combo 是「付出不小成本、且每局重置」的可接受爽点；但本作构筑永久保留，一旦玩家拿到此类 combo，后期将直接平推、整个游戏变得极度无聊。故宁可少给爽点，也绝不放出破坏长期可玩性的连锁。
- **现有守门机制**：§2.3 起手选牌上限 + 手牌每回合清空、§2.2 体力池预算、§2.3.3 零耗卡硬约束（禁攻击 / 禁产牌 / 再选牌必耗体力）正是本红线的落地手段；后续新增内容不得绕过。
- **🔴 出牌口径（2026-09-20 明确）**：**一回合抽 3 张牌 = 2 张动作牌 + 1 张记忆牌，仅此而已** —— 这是**起手抽牌量**，**不是出牌上限**。**回合内出多少牌、抽多少牌都没有任何限制**（把抽牌堆抽完、全打出、再洗一遍再抽再打，重复多少遍都合法），**唯一的约束是体力**。

## 2. 体力系统（原「行动力系统」· **2026-09-20 改口径**）

> 🔴 **术语**：文件里统一写 **「体力」**（不写 AP、不写"费"）。牌的消耗一律写**具体点数**（"消耗 50 点体力"），**不再写"1 费 / 2 费"**。
>
> 🔴 **模型 = 存量（不是流量）**：体力有**上限**、每回合**回复**、**用不完可以攒**。

### 2.1 基础规则

- **全队共享一个体力池**（谁花都行，一个人可以一次把整池用光）
- 每回合在攻击、防御、治疗、修车之间取舍
- **牌的消耗 = 体力**（原"费"），按效果强度分五档：

| 档      |      消耗 | 用途                                                                                         |
| :----- | ------: | :----------------------------------------------------------------------------------------- |
| **微**  |   **0** | 纯铺垫 / 辅助，**只能**做轻度负面（标记类）、轻度正面（少量护盾 / 小增益）。**禁止伤害、禁止抽牌 / 再选牌 / 加手牌、禁止强负面**（见 §2.3.3 零耗硬约束） |
| **轻**  |  **25** | 格挡 · 快速射击 · 收招                                                                             |
| **标准** |  **50** | 常规主力，大部分基础技能（挥砍 / 射击 / 刺击）                                                                 |
| **重**  | **100** | 强力 / 爆发 / 关键技能（重击 · 精确射击 · 盾反 · 重盾防御）                                                      |
| **极限** | **150** | 后期大招级（塔盾铁壁 · 终极爆发 · 强 combo 收尾）—— **前期 3 人队一次吃掉全池**，后期人数多了才流畅                              |

### 2.2 商队人数与体力池

**出战规则（已定）：战斗出战无上限——商队里所有护卫（战斗成员）都能出战。** 平衡靠护卫日薪（后勤人员的 2 倍以上）自然限制，不限制出战人数。

**体力刻度（2026-09-20 定）**：

| 项             | 值                                                                                        |
| :------------ | :--------------------------------------------------------------------------------------- |
| **每人基准体力**    | **50**                                                                                   |
| **个体差异**      | 🔴 **有** —— 与血量同理：**50 只是基准**，不同角色**高于或低于 50**（按招募到的人定）。所以**全队池 = 各人相加**，**不是"50 × 人数"** |
| **每回合回复**     | **50 × 出战人数**（个体差异照加，即"每个人回满自己那一份"）                                                      |
| **体力上限（存量池）** | **100 × 出战人数**（= 2 倍回复，即**最多攒住一回合的量**）                                                   |
| **起手**        | **= 上限（满）**                                                                              |

| 出战人数 | 每回合回复 |      上限 |    相当于几张标准招（50）    |
| :--: | ----: | ------: | :----------------: |
|  3 人 |   150 | **300** | 3 张 / 回合 · 最多攒 6 张 |
|  4 人 |   200 |     400 |      4 张 / 回合      |
|  5 人 |   250 |     500 |      5 张 / 回合      |

> **为什么刻度从"3 点"放大到"50 点"（2026-09-20）**：旧刻度太粗 —— 池只有 3 点，**任何调整的最小步长就是 1 点 = 池的 33%**，导致"重甲每张牌 +1 体力"这类代价**要么砍掉三分之一（没人穿）、要么没感觉**。放大到 50 之后，**最小步长 1 点 = 2%**，中间地带才存在，加成 / 减益 / 装备差异**全都能落在数值上**。
>
> **为什么个体差异（2026-09-20）**：体力基准 50 与血量基准 100 是**同一类"人的底子"** —— 有人体力好、有人差。于&#x662F;**"招募谁"多了一个维度**（血量 / 体力 / 体征 / 卡池），也让"体质差的角色连招都放不利索"变得可表达。
>
> **"攒"的价值 = 集火，不是变强**：每回合回复总量固定，攒**不出一滴多余的体力**，只是把"两回合的量压进一回合" —— 用来**快速点掉一个敌人**（少挨一回合打）。所&#x4EE5;**「每回合打满」（稳）与「憋一波」（爆发）两种打法天然并存**，不需要额外规则去平衡。

**体力池怎么被削减（这就是各种"代价"的落点）**：

- **重甲**：该角色体力上限 / 回复按比例下降（具体值待装备表定）
- **双持 / 高消耗招式**：靠**牌本身的消耗**自然拉开（一半 25、一半 50~100）
- **行军疲劳**（野外接战）：该场**体力上限 ×70%** —— 🛑 **废案（2026-10-13 用户定：暂不实施）**，规则文本保留备查

### 2.3 每回合选牌（**起手 3 张 · 出牌无上限**）

> 旧版「每回合随机抽 7~11 张」已废除；旧版"Qa/Qm 配额 + AP 闸门"表述**同步作废**。现行口径见下。

- **持有牌（牌池）无上限**：角色能用的所有动作卡 + 记忆卡，数量不设限
- **每回合起手抽 3 张**：**每人** 回合开始抽 **3 张**（**2 张动作牌 + 1 张记忆牌**），从自己牌池里自由选，**选完即定**
- 🔴 **没有出牌上限** —— 抽出来的牌**全部打出**（顺序玩家定）；**回合内出牌数、抽牌数都不受任何限制**（抽完再洗再抽再打，重复多少遍都合法），**唯一的约束是体力池**
- **手牌每回合清空**：回合结束弃掉未用手牌，下回合重新抽（防止「再抽牌」变囤牌引擎）
- **体力当闸门**：每张牌按档收体力（§2.1）；**体力耗尽则本回合不能再出牌**
- **记忆卡不限次**：只按体力收费，无单独冷却

#### 2.3.1 卡牌双层（UI 上下两排 · 🔴 2026-10-28 定位细化）

|  层  | 名称      | 来源                       | 🔴 核心定位             |
| :-: | :------ | :----------------------- | -------------- |
|  下层 | **动作卡** | 角色自带基础攻击 + 装备（武器 / 护甲）提供 | 🔴 **执行具体行为，产生直接效果** —— 回答「角色做了什么、结果是什么」 |
|  上层 | **记忆卡** | 知识领域（记忆系统 §5.1）提供        | 🔴 **提供知识，引入或改变战斗机制** —— 回答「角色懂什么、这份知识改变了哪些规则」 |

- 🔴 **动作牌子类**：
  - **武器招式** —— **基础招式**（有武器就能用：砍击 / 刺击 / 横扫 / 基础格挡）· **特殊招式**（特定战术功能：缴械 / 打断 / 攻防转换；不一定复杂、可跨武器通用）· **复杂招式**（需专门学习：特殊剑术 / 复杂连招 / 武器套路；特殊与复杂不互斥）。
  - **准备与强化行为** —— **基础准备**（不需专门学习，有物品和条件即可：给刀涂毒 / 用现成药剂）· **特殊准备**（需知识或前置：战前鼓舞 / 特殊强化 / 复杂战斗准备）。
  - 🔴 **不是所有行为都要做成卡** —— 如涂毒可由物品 + 时间 + 通用规则决定能否执行，不必有专门的「涂毒」卡。
- 🔴 **记忆卡不是动作卡的数值升级** —— 不应主要靠「直接加某张动作牌的伤害」体现价值；它的作用是**引入新机制、改变现有机制、让动作之间产生新联动**（防御转伤害 / 条件自动触发 / 中毒提前一次结算 / 资源转换 / 连招积累 / 改变限制成本收益），让**相同基础动作配不同记忆 = 完全不同的战斗逻辑**。机制五类分类 → §2.3.4。
- 🔴 **同一份知识服务多场景** —— 记忆代表的知识在战斗 / 探索 / 贸易各有落点（领域给三类卡）→ `第6A类 §5.1`；获取 / 知识库 / 记忆槽 → `第6A类 §18`。

#### 2.3.2 组合机制（1+1>2 的来源）

记忆卡做**赋能 / 铺垫**、动作卡做**出手**，可跨角色串：

> 例：射手**标记(0)** → 化学**制毒(记忆，攻击附带中毒状态)** → 护路人**穿甲重击(100 体力)** = 中毒内伤 + 标记增伤 + 穿甲，远超单卡。

#### 2.3.3 零体力卡硬约束（核心：杜绝无限循环）

- 零体力卡**只能是铺垫 / 辅助**：给敌方上轻度负面（标记）、给我方上轻度正面（少量护盾）
- ❌ **禁止攻击牌**（任何直接伤害）
- ❌ **禁止抽牌 / 再抽牌 / 加手牌**（任何增加手牌的牌）
- ❌ 禁止强负面（灼烧 / 强迟滞）
- **原因**：若 0 体力能「再抽 2 张」，玩家带「1 点伤害牌 + 0 耗再抽牌」→ 无限抽无限打。故**任何「再抽牌」牌一律 > 0 体力**，靠体力当闸门，不可能零成本循环。
- ⚠️ **零体力卡仍然占 1 张起手名额**（每回合只有 2 动作 + 1 记忆）→ **不会出现"无限叠盾 / 无限铺标记"**

#### 2.3.4 记忆卡机制五类（🔴 2026-10-28 新增 · 分类用于描述机制，不要求每张记忆只属一类）

| # | 类型 | 改变什么 | 例（示例非定稿） |
|:-:|:--|:--|:--|
| 1 | **效果转换型** | 把已有数值 / 资源 / 状态转换成另一种效果 | 防御值转伤害 · 剩余能量转蓄力 · 中毒层数转一次性伤害 |
| 2 | **条件触发型** | 指定事件发生时自动触发额外效果 | 格挡后获蓄力 · 敌人失衡后追加攻击 · 用指定招式后回体力 |
| 3 | **结算方式改变型** | 改变结算的时间 / 次数 / 顺序 / 算法 | 中毒提前全额触发 · 逐回合伤害一次结算 · 积累集中兑现 |
| 4 | **累积与连锁型** | 建立跨行动 / 跨回合的积累机制 | 持续准备积势能 · 连续不同招式积专注 · 积累交给终结招兑现 |
| 5 | **规则修改型** | 改变行为的限制 / 收益 / 适用条件 | 耗防御代替体力 · 特定状态解锁平时不可用招式 |

> **设计含义**：记忆卡的价值 = 让玩家**安排行动顺序、围绕机制构筑战术**，而不是+10% 伤害。

#### 2.3.5 卡牌的战斗职责（🔴 与「卡牌类别」是两个不同维度 · 2026-10-28 新增）

- **类别**（动作卡 / 记忆卡）回答「这张牌**是什么**」；**职责**回答「这张牌在一场战斗里**解决什么问题**」。
- 🔴 **每张牌必须有且只有一个主要职责**，必要时可带次要职责 —— 方便设计与程序管理。

| 战斗职责 | 主要作用 | 例 |
|:--|:--|:--|
| 直接输出 | 直接造成伤害 | 砍击、刺击、重击 |
| 防御与应对 | 降伤 / 挡攻击 / 创造反击 | 格挡、卸力、反击 |
| 控制与破坏 | 影响敌人行动或防御 | 打断、缴械、制造失衡 |
| 准备与积累 | 产生后续收益所需的状态 / 资源 | 涂毒、蓄力、积势能 |
| 资源管理 | 获取 / 储存 / 转换 / 节省战斗资源 | 能量储存、防御转化 |
| 机制与连锁 | 建立特殊规则让多个行为互相影响 | 毒素 × 失衡联动 |
| 终结与兑现 | 把前期积累转化为高额收益 | 消耗蓄力的重击 |

#### 2.3.6 准备、积累与兑现（🟡 探索方向 · 2026-10-28 · **非定稿**）

- **方向**：鼓励投入回合 / 体力 / 资源做准备，在合适时机把积累兑现成高额收益；一种**可探索**的奖励曲线是**递增式成长** —— 示例（🔴 纯示意，**不是数值公式**）：基础攻击 10 点，准备 1 回合兑现 20 → 2 回合 40 → 3 回合 80 → …
- **设计意图**：① 直接打 = 低但稳；② 投入准备 = 更高最终收益；③ 记忆卡可改变准备效率 / 积累方式 / 兑现算法；④ 不同准备行为 × 终结招 = 不同爆发构筑。
- 🔴 **两条硬边界**：① **递增兑现不得突破 §1.1 红线**（禁止伤害严重溢出 / 单回合清场 —— Boss 承伤独立设计也照此审查）；② **准备越久必然越优 = 设计失败** —— 必须配套**成本与风险**（体力消耗 · 挨打 · 准备被打断 · 维持状态的要求），具体规则 → 待裁定㉚。
- 🔴 **不要求所有攻击牌遵循同一增长规则** —— 这是一种构筑奖励机制，不是通用公式。

#### 2.3.7 卡牌定义字段（🔴 设计与程序要求 · 2026-10-28 新增）

> 🔴 每张卡牌必须有**明确定义**，方便分类、平衡与程序实现。至少记录以下字段；**不适用的可留空，但涉及的规则必须明确**：

| 字段 | 说明 | 字段 | 说明 |
|:--|:--|:--|:--|
| 卡牌名称 | 唯一名称 | 行动成本 | 回合 / 体力 / 物品等 |
| 卡牌类别 | 动作卡 / 记忆卡 | 具体效果 | 伤害 / 状态 / 资源 / 规则变化 |
| 具体子类 | 武器招式 / 准备强化 / 机制五类之一 | 触发条件 | 何时触发、由什么事件触发 |
| 主要战斗职责 | §2.3.5 七类之一（可带次要） | 联动条件 | 与哪些动作 / 状态 / 机制关联 |
| 执行方式 | 主动使用 / 持续生效 / 条件自动触发 | 持续与结束条件 | 效果多久、何时结束 |
| 前置条件 | 所需武器 / 资源 / 状态 / 知识 | 获取来源 | 初始 / 学习 / 探索 / 记忆解锁 / 装备 |

> 🔴 **记忆卡额外必须写明**：引入或修改的机制 —— 状态如何产生、如何积累、何时触发、如何结算、什么情况下结束。

### 2.4 消耗品消耗体力

在战斗中使用消耗品（药包、零件等）需要消耗体力，**与出牌共用同一个池**：

- 使用药包：消耗 **25 点体力**
- 使用零件修车 / 补甲：消耗 **25 点体力**
- 其他消耗品同理

> 战斗中的**每个行动都要花体力**，包括使用消耗品。这是为了让玩家在"打伤害"、"防御"、"治疗"、"修车"之间做取舍。

### 2.5 知识强化（通用战斗技巧 × 知识 · 2026-10-28 用户与 ChatGPT 讨论新增）

> 📌 **知识的获取 / 商队知识库 / 个人记忆槽 / 配置更换 → `第6A类 §18`**（本节只管「知识在战斗里怎么用」）。

- 🔴 **基本原则**：采用「**有限的通用战斗技巧 + 知识提供的针对性强化**」—— 🔴 **不为每一种敌人或每一条知识单独制作完整技能**。**通用技巧负责执行战斗行动**；**知识负责揭示特定对象的弱点、改变技巧的适用条件，或强化技巧的实际效果**。
- 🔴 **没掌握相关知识时，通用技巧照常可用**（只是不触发针对特定敌人的特殊效果）；掌握并满足条件时，获得额外效果。（示例，非定稿：「识破破绽」无相关知识 = 普通效果；掌握某野兽知识后，在其特定动作后使用 = 额外伤害 / 眩晕 / 失衡。）
- **知识强化的三种形式**（🔴 优先复用已有规则，以 ①② 为基础，③ 谨慎增加）：

| # | 形式 | 效果 |
|:-:|:--|:--|
| 1 | **数值强化** | 提高特定情况下的伤害、眩晕等数值 |
| 2 | **条件强化** | 揭示特殊触发时机或适用条件 |
| 3 | **机制强化** | 特定条件下额外产生打断、失衡、破防等效果 |

- 🔴 **特殊知识 → 独立技能 = 例外通道**：仅用于有特殊意义的敌人、稀有技术、旧文明遗产，🔴 **不作为普通知识的默认处理方式**；按独特性 / 玩法价值 / 开发成本 / 平衡难度逐个判断。
- 🔴 **构筑配合走复用**：知识 × 记忆 × 通用技巧 × 装备 × 特殊品的组合尽量复用已有规则（如知识利用破绽 + 装备强化破绽攻击 + 特殊品使失衡附加效果），不为组合单独做效果；组合价值不只是伤害数值，也在行动选择 / 触发条件 / 状态变化 / 战术适用范围。
- 🔴 **衔接红线**：本机制**不含任何可刷取的熟练度 / 等级**（`第6A类 §5.1`）；研究不靠重复相同操作（`第6A类 §18` 二）。并非所有知识都强化战斗——生物 / 材料 / 工艺知识分别服务其适用的玩法系统。

## 3. 伤害类型：内伤与外伤

伤害分为两大类：

| 类型     | 说明                     | 举例            |
| :----- | ---------------------- | :------------ |
| **外伤** | 可以被防御阻挡                | 普通攻击、穿甲攻击、灼烧  |
| **内伤** | **不可被防御阻挡**，无视护盾/护甲/屏障 | 流血伤害、已施加的持续伤害 |

> 防御系统只对外伤生效。内伤一旦施加，伤害无法通过防御减免。

## 4. 防御系统

三层防御结构，均只对外伤生效：

| 类型     | 特性             |         持续        | 来源           | 说明                                        |
| :----- | :------------- | :---------------: | :----------- | ----------------------------------------- |
| **护盾** | 临时防御           |     **回合结束清空**    | **盾牌卡**      | 挡外伤。若完全挡住攻击，可阻止流血施加。🔴 **可给任意队友叠**（不限于自己） |
| **护甲** | **本场战斗内的持久防御** | 直到被打掉（**战毕自动复位**） | **防具**（5 部位） | 只挡普通攻击。不挡穿甲攻击、流血、灼烧                       |
| **屏障** | 高级防御           |       直到被打掉       | 旧文明手段 / 特殊物品 | 挡外伤、大多数负面施加。不挡已有流血伤害                      |

> **护盾与护甲两条渠道互不混淆**：**护盾只由盾牌提供**（举盾挡住的那一下），**护甲只由防具提供**（穿在身上扛的）。

### 4.1 防护档（敌我通用）

> **"档"= 目标当前的**整体防护水平\** —— 不是"甲在不在"的开关，而是一个**状态分级**。
>
> 🔴 **护盾和护甲都吃这个倍率**：打它的盾、打它的甲、还是打进它的血，**都按它当前所处的档那一列算**（用户 2026-09-18 原话："无论是护甲还是护盾，都造成这个倍率的伤害"）。

| 档      | 判定                           | 例         |
| :----- | :--------------------------- | :-------- |
| **无甲** | 甲值 = **0**（没穿防具，**或甲已被打碎**）  | 野兽、破甲后的目标 |
| **软甲** | 甲值 > 0 · 材质 **布 / 皮 / 薄壳**   | 强盗        |
| **硬甲** | 甲值 > 0 · 材质 **铁 / 钢 / 灰烬甲壳** | 灰烬兽、重装强盗  |

- **档是动态的**：甲的数值被打碎 → **当场转「无甲」档** → 之后挨打按无甲那一列算。
- **无甲 ≠ 打不动**：无甲单位照样能叠护盾 / 护甲，只是**它自己叠不出多少**（敌人侧写在敌人数值表里；我方是因为没有能撑住的防具）。
- **混穿按最高的那件算**：全布 / 皮 = 软甲；**只要含一件铁或钢 = 硬甲**。

### 4.2 攻击类型与倍率表（**核心机制 · 2026-09-20 定 · 倍率 2026-10-10 修订**）

> 你手里拿什么武器，决定你**打什么甲划算**。这是"武器除了数字之外的第二重身份"。

**攻击类型三型（敌我通用）**：

| 类型     | 武器例                         |
| :----- | :-------------------------- |
| **打击** | 锤 / 棍 / 钝斧 / **弩** / **火枪** |
| **斩击** | 剑 / 刀 / 斧                   |
| **刺击** | 长矛 / 匕首 / **弓**             |

**倍率表**：

| 类型     |   对无甲 |      对软甲 |      对硬甲 |
| :----- | ----: | -------: | -------: |
| **打击** | ×0.9 |     ×1.0 | **×1.3** |
| **斩击** |  ×1.1 | **×1.2** |     ×0.9 |
| **刺击** |  ×1.1 |     ×0.9 |     ×0.9 |

**三型的性格**：

| 类型     | 性格                    | 什么时候带        |
| :----- | :-------------------- | :----------- |
| **打击** | 克硬甲，但破甲后垫底（**前半场武器**） | 明知前面是硬壳（灰烬兽） |
| **斩击** | 偏科 —— 克软甲最强，也最怕硬甲     | 打人形敌人（强盗）    |
| **刺击** | **两头都不吃**（对软甲 / 硬甲都 ×0.9） | 情报不足时选它 = **赌博**，不是安全选择 |

**判定规则**：

- 倍率作用于**整次伤害**（不做溢出分段）—— 🔴 **必须一直算到生命**，不能只打在甲上。否则"甲厚的人总撑得久"，**相性会被厚度吃掉**。
- **只在目标当前"有档"时生效**；甲碎 → 转无甲档。
- **统一作用于 护盾 / 护甲 / 屏障 三层**。
- **穿甲攻击不吃这张表**（它本来就无视护甲）。
- **内伤不吃**（直接进生命）。

**设计约束（防失衡，必须守）**：

|  #  | 约束                     | 理由                                     |
| :-: | :--------------------- | :------------------------------------- |
|  1  | 倍率区间 **×0.9 ~ ×1.3**   | 幅度再大就变成"带错武器打不动" = 事实上的硬限制             |
|  2  | 🔴 **打击对无甲必须 < 1.0**   | **保险丝** —— 让打击只是"前半场武器"，防止"无脑选打击"变成唯一解 |
|  3  | 三型**整场加权总量齐平**（差 4% 内）· ⚠️ **2026-10-10 改值后此条待复核**（简单均值：打击 **1.067** / 斩击 **1.067** / 刺击 **0.967**，相差约 10%）—— 若"刺击 = 两头都不吃的赌博"是**有意的代价**，本条应改成"加权齐平"或明确允许刺击总量偏低；**归数值调平期定** | 差异体现在**节奏**（回合数 → 药包消耗），**不在总量**       |
|  4  | 敌人的武器类型**必须混着来**       | 全是一种，玩家的选择就死了                          |

> 🔴 **2026-10-10 用户裁定**：**打击对无甲 ×0.95 → ×0.9**（"前半场武器"手感更明显）；**刺击 ×1.0 / ×1.0 → ×0.9 / ×0.9**（削弱成"两头都不吃" —— 情报不足时选它是**赌博**而非安全选择）。权威同步见 `第6A类 §14.2`。
>
> 🔴 **取消"通用减伤率"**（2026-09-20）：曾经设想过防具给一条无相性的"减伤率"（皮 5% / 铁 10% / 钢 15%）—— **该条作废**。因为它是**纯优乘数**（谁高谁永远更抗打），会把软硬甲的相性差异直接抹平，等于把上面这张表废掉。**防具的差异全部由本节这张倍率表承担。**
>
> （`第6A类 §11.3` 车辆配件「**装甲板：提升减伤率**」**是车的**，不受本条影响。）

### 4.3 伤害结算顺序（仅外伤）

```
面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率 → 护盾 → 屏障 → 护甲 → 生命
```

> **攻击类型倍率与角色加成都在"整次伤害"这一层**，**扣血之前全部算完**。
>
> 护盾优先结算，因为护盾过一回合就消失。屏障在护盾之后。

**穿甲攻击**的结算顺序：护盾 → 屏障 → 生命（**无视护甲**）

> 内伤不经过上述结算，直接作用于生命。

### 4.4 护盾（只由盾牌提供）

| 盾      | 占手    | 消耗体力       | 护盾值               |
| :----- | :---- | :--------- | :---------------- |
| **小盾** | 1     | **0 ~ 25** | 5~6 / 12          |
| **中盾** | 1     | **50**     | 26                |
| **重盾** | 1     | **100**    | 55 / 全队 20 × 出战人数 |
| **塔盾** | **2** | **150**    | 100               |

- 🔴 **护盾可以给任意队友叠**（不限于自己）—— 这直接决定了"远程必须有人护"：**远程是双手武器，拿不了盾，连自救能力都没有**。
- ⚠️ **0 体力消耗的盾卡仍然占 1 个动作位**（每人每回合只有 2 动作 + 1 记忆）→ 否则 0 耗 + 不占位 = **无限叠盾 = 无敌**。

### 4.5 护甲（只由防具提供）

|  #  | 条目               | 定法                                                                                                 |
| :-: | :--------------- | :------------------------------------------------------------------------------------------------- |
|  1  | **甲值**           | **开战赋值**（头 / 躯干 / 手 / 腿 / 足 **5 部位相加**，躯干权重最大）· **战内只减不增** · 甲值归零 = **防具报废** → 同时失去甲值 + 转「无甲」档     |
|  2  | **战毕复位**         | **战斗结束自动回满**，不花钱、不占天数、不用修（与"不做装备耐久"一致）                                                             |
|  3  | **可补充**          | 🔴 **甲在战内并非绝对不可恢复** —— **修补师可用「紧急加固」补甲**（1 点体力 + 1 零件 → 队友 +12 甲）                                  |
|  4  | **完全吸挡**         | 本次伤害**被甲完全吸收（无溢出到生命）** → **不施加流血 / 迟滞**                                                            |
|  5  | **厚度目标**         | **总甲 ≈ 血池 ÷ 3**（≈ 总耐久的 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具数值必须跟着血池一起升级**，否则后期被甩开 |
|  6  | **软硬甲值差 ≤ ~20%** | 例：软 36 ∶ 硬 45（≈80%）—— **别让厚度把相性吃掉**                                                                |


> **甲 vs 护盾**：**甲**开战满 / 回合末不清空 / 只给自己 / 战毕复位；**护盾**开战 0 / 回合末清空 / **可给队友** / 每回合能重叠。

## 5. 状态系统

### 5.0 对等原则（**2026-09-29 定 · 本节总纲**）

> 🔴 **状态按「机制」定义，不按「阵营」分家。**

- **敌我共用同一套状态、同一套数值、同一个结算函数。** 玩家能上的负面，敌人也能上；玩家能有的增益，敌人也有其对应物。**不为敌人另写一套战斗** —— `04 §9.6 ④` 原话：「敌人动作表**与玩家的"手牌"对称，走同一个结算函数**。**不是写两套战斗，是一套。**」
- **为什么要这条原则**（三条，缺一不可）：
  1. **读得懂才谈得上应对** —— 玩家能反推"它也会流血、它也会被迟滞"，规则才**可被利用**；
  2. **一套代码** —— `core.js` 只写一遍，加新敌人 = 加一行数据（`04 §9.6 ⑤`）；
  3. **后期敌人"会打配合"不是新规则** —— 只是**同一套规则用得更熟**（AI 档 C · 协同，`04 §9.6 ③`）。
- **对等的是「规则」，不对等的是「内容」**：同一个状态打在玩家身上与打在敌人身上，走**同一个函数、同一套数值**；差异只来自**双方各自手里有什么牌**：

| 一方     | 牌从哪来                                            |
| :----- | :---------------------------------------------- |
| **玩家** | 老本行 · 武器 · 记忆 · 商队牌（`04 §9.1.1`）+ 装备 / 装具 / 消耗品 |
| **敌人** | **物种动作表**（每只 2~4 个动作）+ 物种属性                     |

- **唯一例外 = 物种属性**（且它**不是"阵营专属"**）：物种自带的生态行为，如"灰烬兽不逃跑 / 野兽天生易逃 / 强盗抢到货就撤"。→ **归敌人表（`17 §6`），不进本节状态表。**
- ⚠️ **"近乎"对等的边界**：**规则对等，处境不对等** —— 敌人不心疼药包、不养车、不记每日消耗；玩家受持久与补给约束。**这是两条不同的轴，不冲突。**

**状态双向性一览**（§5.1~§5.5 各表亦逐行标注 · 增益对照见 §5.7）：

| 状态                |    敌我    | 备注                                              |
| :---------------- | :------: | :---------------------------------------------- |
| 标记 · 流血 · 灼烧 · 迟滞 | ✅ **双向** | 玩家可上给敌人，敌人同样可上给玩家                               |
| 反击                | ✅ **双向** | 我方侧 = 盾反；敌方侧 = 反打类动作                            |
| 蓄力                | ✅ **双向** | 原文已写"敌我双方都可拥有"                                  |
| 狂化                | ✅ **双向** | 🔴 原写"**敌人**强化状态" → **已去阵营标签**（改为通用的**伤害递增**状态） |
| 灰蚀                | ✅ **双向** | 绑定**灰烬生态**（谁都会染），**不是敌人专属**                     |
| 护盾 · 护甲 · 屏障      | ✅ **双向** | §4 三层防御，敌我走同一套规则                                |

> ⚠️ **本节只写规则，不写数值 / 不写具体动作名** —— 敌人侧的具体动作与数值归 `17 §6` 敌人表。

### 5.1 攻击类型状态

> **攻击类型有两个层次**：① **常规三型 —— 打击 / 斩击 / 刺击**（决定"打什么甲划算"，完整倍率表与控制规则见 **§4.2**）；② **特殊攻击类型 —— 穿甲**（无视护甲，见下表）。三型的归属由**武器**决定（剑 = 斩击 · 锤 = 打击 · 弓 = 刺击）。

## 6. 旧文明武器系统（终极爆发·已定）

**定位：** 大后期终极爆发手段——一击秒精英、重创Boss的超高伤害招式。

### 6.1 世界观

- **记忆 = 旧文明大型武器的操作说明书**（不是武功秘籍——玩家是"看懂说明书"才能操作武器）
- **武器 = 旧文明仪器**（遗迹里找到的大型武器）
- **火种 = 电池**（高密度能量结晶，给武器供电）
- 三者缺一不可：没有说明书不会用，没有武器没得用，没有火种用不了

### 6.2 获取（双重门槛）

| 门槛        | 来源                         |
| :-------- | :------------------------- |
| 说明书（奥义记忆） | 大后期：遗迹深处 / 灰烬城数据库 / Boss掉落 |
| 武器（旧文明仪器） | 遗迹探索获得                     |

### 6.3 发射模式

| 模式            | 消耗           | 威力                 |
| :------------ | :----------- | :----------------- |
| **弱发射**（免费）   | 不消耗火种        | ≈普通攻击，甚至略弱——应急用    |
| **强发射**（终极爆发） | 消耗**火种**（电池） | 超高伤害——一击秒精英、重创Boss |

### 6.4 使用规则

- 战斗中操作武器攻击，**消耗体力**
- 弱发射免费但弱——平时用普通技能，武器是"保险"
- 强发射烧火种——火种同时用于记忆强化，玩家自己权衡（强化记忆 or 攒着放大招）
- 火种稀有 → 大招不能乱放，是战略资源

> 烬油是**城市节点反应炉**的燃料（详见第 7A 类），不属于玩家随身携带的战斗消耗品；战斗侧的能源只剩火种电池。

### 6.5 战场规则型旧文明物品（新增）

> 旧文明特殊物品不止「武器·终极爆发」（§6.1~6.4），新增一类改变整场战斗规则的物品。

- **定位**：消耗火种、持续 N 回合改变整场**战斗规则**、敌我双方都吃
- **例**：毒雾场——带中毒状态的单位每回合受毒伤，第 N 回合全场爆炸（玩家方中毒也生效）
- **使用门槛**：仅精英 / Boss 战等难度大的战斗使用；普通战斗不需要（不耗火种）
- 与「武器·终极爆发」共用火种资源，玩家权衡（放大招 or 改战场）

## 9. 撤退系统

撤退分为两大类：**战斗撤退**（战斗中）和 **地图撤退**（大地图上）。

### 9.1 战斗撤退

在战斗中可以选择撤退。某些特定 Boss 不可撤退。

#### 判定规则

| 项目    | 规则                                    |
| :---- | :------------------------------------ |
| 出现时机  | **每回合都**可以选择撤退（含战斗开始），**第 3 回合起**开始判定 |
| 基础成功率 | **50%**                               |
| 判定结果  | 成功→撤离战斗；失败→继续战斗，后续可再次尝试               |

#### 成功率修正

| 影响因素   |    修正    | 说明                               |
| :----- | :------: | -------------------------------- |
| Boss 战 | 默认不能普通逃跑 | 剧情允许逃跑的 Boss 战成功率 25%–35%        |
| 严重超重   |   无法逃跑   | 超重状态下不能撤退                        |
| 敌方平均迟滞 |  提高逃跑成功率 | 逃跑加成 = 向下取整（所有敌人的迟滞失败率之和 ÷ 敌人数量） |


#### 撤退结果

| 项目   | 规则                     |
| :--- | :--------------------- |
| 士气变化 | **-1**                 |
| 货物   | **不损失货物**              |
| 战斗奖励 | **无法获得**（敌人没打完，奖励无法获取） |

### 9.2 敌方逃跑

敌人分为三类：**野兽**、**强盗**、**灰烬兽**。逃跑机制各不相同。

> 🔴 **强盗为什么"抢到货就跑"（2026-09-24 补 · 因果）**：强盗是**寄生者**，靠**过路商队**吃饭（"商路还在，才养得起强盗"，见 `第7A类` §二）。他**要的是货，不是命** —— 所以**抢到货物意愿直接 +100、立刻撤**，符合"打劫糊口"的立场，也解释了为什么强盗身上装备差、护卫少：**他不是军队，是饿肚子的人。**

#### 基本规则

- 每个敌人**独立累计**逃跑意愿
- **第 1 回合起**即可开始累计逃跑意愿
- **第 3 回合后**开始判定
- 逃跑意愿达到 **100** → 显示"敌人将要逃跑"提示
- 提示后**第 3 回合**开始判定（玩家有准备时间）
- 判定成功→敌人逃跑；判定失败→继续战斗，后续可再次判定
- **灰烬兽不会逃跑**

#### 逃跑意愿增加

| 条件         |    增加    | 说明         |
| :--------- | :------: | ---------- |
| 敌方数量少于一半   |    +30   | 单次触发       |
| 自身血量低于 50% |    +20   | 单次触发       |
| 自身血量低于 30% |    +30   | 单次触发       |
| 队友被击杀      |    +10   | 每死一个队友触发一次 |
| 精英被击杀      |    +30   | 精英死亡时触发    |
| Boss 被击杀   |    +50   | Boss 死亡时触发 |
| 野兽初始倾向     |    +20   | 野兽天生容易逃跑   |
| 野兽每回合自然累计  |   +5/回合  | 仅野兽        |
| 强盗抢到货物     | **+100** | 直接满，立刻准备逃跑 |

> 逃跑意愿**只增不减**。没有减少逃跑意愿的手段。

#### 判定成功率

| 项目    |               数值               |
| :---- | :----------------------------: |
| 基础成功率 |             **50%**            |
| 迟滞修正  | 每层迟滞增加行动失败概率（对所有行动生效，逃跑也受迟滞影响） |

#### 逃跑结果

| 结果   | 说明             |
| :--- | -------------- |
| 判定成功 | 敌人逃跑，离开战斗      |
| 判定失败 | 敌人继续战斗，后续可再次判定 |

| :--- | :------------------------------------------------------- |
| 触发条件 | **士气归 0** 时自动触发                                          |
| 士气变化 | 士气已为 0，不额外扣除。到达安全点后**恢复到 1**                             |
| 货物损失 | 🔴 **按距离档随机抽**（近 30% / 中 45% / 远 60% —— 见 `第3A类 §5.2.2`） |
| 撤离目标 | 🔴 **玩家指定的已探明大城 / 小城**                                   |

#### ③ 全队严重重伤 + 零件耗尽（强制撤退）

| 项目   | 规则                                   |
| :--- | :----------------------------------- |
| 触发条件 | 🔴 **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）** |
| 士气变化 | 到达安全点后**恢复到 1**                      |
| 货物损失 | 🔴 **固定 75%**（不按距离 —— 已没得选，代价要明确；🔴 2026-10-14 用户定，原 50%）    |
| 撤离目标 | 🔴 **玩家指定的已探明大城 / 小城**               |

> 🔴 **撤离目标三条硬规则**（2026-10-12 用户裁定）：  
> ① **只能是大城 / 小城**（城镇/驿站/村庄都不收，§6）· ② 🔴 **必须已探明**（没到过 / 没侦察过的地方，玩家不知道那儿有没有城）· ③ 🔴 **由玩家指定**，**不是"最近的那个"**。  
> **为什么第③条重要**：如果按"最近的安全点"，玩家会**走到一半就撤**（反正最近那座城就在后面）→ **白赚一半路程**。**必须"你选 + 你付代价"** —— 代价按**实际要退回多远**算（`第3A类 §5.2.2`）。  
> 📌 **完整规则见 `第3A类 §5.2`**（含货损抽签方式 + 保险箱）。

### 9.4 撤退总表

| 撤退类型       |  分类  | 触发方式                 |             货物损失             |    士气   | 能否获得战斗奖励 |
| :--------- | :--: | :------------------- | :--------------------------: | :-----: | :------: |
| **战斗撤退**   | 战斗撤退 | 战斗中点逃跑（第 3 回合起判定）    |              0%              |    -1   |   ❌ 不能   |
| **主动撤退**   | 地图撤退 | 玩家主动                 | 🔴 **按距离档随机抽** 10 / 20 / 35% |    -2   |     —    |
| **士气崩溃撤退** | 地图撤退 | 士气归 0                | 🔴 **按距离档随机抽** 30 / 45 / 60% | 到达后恢复 1 |     —    |
| **强制撤退**   | 地图撤退 | 🔴 **全队严重重伤 + 零件耗尽** |         🔴 **固定 75%**        | 到达后恢复 1 |     —    |

> 主动撤退惩罚最低，给玩家止损机会。崩溃类撤退代价更高，但不会死档。  
> 🔴 **所有撤退的撤离目标相同**：**玩家指定的已探明大城 / 小城**（不是"最近的那个"）—— 见 §9.3 三条硬规则。  
> 🔴 **货损一律"随机抽签"、不是精确扣 %**：**排除储水格**（水不参与）· **保险箱参与抽但抽中不丢** · 抽到大件就少抽几件 —— **每次损失不同**。详见 `第3A类 §5.2.3`。
