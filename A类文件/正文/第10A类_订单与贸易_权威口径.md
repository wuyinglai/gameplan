## 一、交易与讲价系统

本系统借鉴"商人视角游戏"的核心乐趣——**做生意本身就是目的，不是手段**。讲价机制从已有系统自然长出，不凭空加设定。

### 1.1 交易场景

商队在各类地点（城市 / 城镇 / 小城 / 驿站 / 村庄）可与固定商人 NPC 发生三类交易：

| 场景 | 行为 | 讲价方向 |
|:----|:----|:----|
| 买 | 购入货物 / 装备 / 补给 | 压低成交价 |
| 卖 | 出售货物 / 旧装备 | 抬高成交价 |
| 接订单 | 与订单发布者谈酬金 | 抬高委托酬金（"这趟风险大，加钱我才接"） |

标价为**城市基准价**（🔴 价格的家 = **`第2A类 §7`**，不在本文件），讲价围绕基准价上下浮动。

### 1.2 讲价触发

- **大单 / 订单**：默认进入谈判界面。
- **小单**：按默认价直接成交；玩家**主动按键**才进入讲价。
- 自然过渡：前期资金紧张，玩家会为省几块主动讲价攒钱买装备；后期宽裕后往往直接按默认价买，不再耗时间讲小单。

### 1.3 讲价执行者

- 队伍中有 **"账房 / 商人"特质的特殊人员**（定义见第6A类）→ 讲价加成：成交空间更大、对方更易接受。
- **无特质（队长自己谈）** → 也能讲，但成功率降低、对方底线更硬（压不到那么低 / 卖不到那么高）。
- 不强制要求特定职业在场，但有无对应人员会造成明显差异。

### 1.4 核心机制：5 轮拉锯 + 读态度

每个固定商人 NPC 隐藏三条线，玩家不可直接读取数值：

| 隐藏线 | 含义 |
|:----|:----|
| 成本底价 | 他的成本线，低于此他不卖 / 不买 |
| 满意价 | 他心理舒服的成交价 |
| 急迫度 | 他多想做成这单（库存积压 / 急需某货 / 月底交差等） |

玩家出价 → NPC 给出**态度反馈（不显示数字）** → 可拉锯最多 **5 轮**，越谈越能摸透对方价位区间：

- 他皱眉 → 你压太低 / 抬太高
- 他眼神亮了 → 这价他赚到了
- 他叹气说"今年灰重货紧" → 暗示稀缺、底线硬

第 5 轮或玩家主动喊停时定结果：成交 / 妥协价成交 / 暂不成交。

### 1.5 影响成败的变量

讲价结果由以下因素共同决定（均从已有设定长出，不新增独立系统）：

1. **讲价者特质**：有"账房 / 商人"特质 → 加成。
2. **宏观声望**：商会城市分会声望（见第7A类）。声望高 → 该城分会提供更好价格与订单条件。
3. **个体信任**：具体 NPC 的信任值（见 1.6）。
4. **城市态度（仅统治层政策，见 1.7）**：影响关税与官方门槛，不裁定普通 NPC。
5. **灰度**：高灰烬区物资稀缺 → 卖家抬价、玩家反而能高价出货。
6. **急需度**：你带去的货正是对方紧缺的 → 他更松口。

### 1.6 声望与个体信任（三层）

- **世界声望（全局）**：跨城可见的**公开名声**，放在所有城市都算数。遭遇其他商队时**对方能看到它**（见第7A类「路上遇到的人」）；动手打人被发现会掉，**剿灭有悬赏的劫道者会涨**。
- **宏观声望（城市分会级）**：沿用第7A类设定。玩家是余烬商会流动分会，在某城分会声望高 → 该城提供更好价格与专属订单。
- **个体信任（NPC 级）**：每个固定商人 NPC **有名字、有信任值**。
  - 公平成交、不欺诈 → 信任升；
  - 狠宰 / 骗 → 信任降。
  - 信任高了 → 给暗折扣、留好货、甚至**透露灰烬区情报**（接"世界活着"与灰度系统）。
- **通缉标记**：被某城悬赏的公开状态，遭遇时可见。它有两面——**对方被通缉 = 打他合法、无恶名、还能领赏**；**自己被通缉 = 谁都不怕先动手打你，且赏金猎人会上门**（见第7A类 §五 / §六）。
- 这几层叠加，是把"稀疏的生机"变成温度的方式——路上难得遇个熟人，处好关系就是孤旅里的温暖点。

#### 🔴 1.6.1 🔴 信任的表现层（**信任涨了之后对方说什么、什么态度**）

> 🔴 **2026-10-23 补** —— 🔴 `0A §四之五 §2` 指出：「`10A §1.6` 已有信任值，🔴 **但信任涨了之后对方说什么、什么态度，文件里一个字都没写**」。

| 信任档 | 对方的态度 | 🔴 **具体表现（至少一种）** |
|:--|:--|:--|
| 🔴 **陌生**（初始） | 公事公办 | 🔴 只谈生意 · 不主动提别的 |
| 🔴 **面熟** | 认得你 | 🔴 一句问候 · 报出你的商队名 |
| 🔴 **熟客** | 惦记你 | 🔴 主动留好货 · 告诉你哪里不太对劲 |
| 🔴 **自己人** | 站在你这边 | 🔴 透露灰烬区情报 · 危险时出价更低 · 替你说话 |

| 🔴 三条不能破 | 说明 |
|:--|:--|
| 1 | 🔴 **不需要所有人都有庞大记忆** —— 🔴 **只要在"合适的时候"让玩家感觉到"我过去的经历没有完全消失"** | 🔴 `0A §四之五 §2` 原话 |
| 2 | 🔴 **表现层不许变成数值面板** —— 🔴 **要靠对话与态度，不靠弹窗写"信任 +5"** | 🔴 **性格数值 / 养成系统是这类游戏的默认引力**（`0A设计思路 §八`） |
| 3 | 🔴 **态度变化必须与那段经历相符** —— 🔴 **帮过他 → 再遇时他记着；被他骗过 → 他也不记着** | 🔴 🔴 **"世界记得玩家"的核心** |

> 🔴 **具体台词与选项写法 → 属 `5A` 事件内容**，🔴 **本节只定"档位 → 态度 → 表现方向"**。
> 🔴 **完整口径（两种记忆 / 日常与深刻事件共存 / 世界记忆只做三层）→ `0A §四之五`**。

### 1.7 城市态度的修正口径（重要）

**城市态度仅指统治阶层的官方政策**：
- 城市的"态度"**仅指其统治阶层 / 城主 / 主流势力对商队的官方政策态度**，作用范围限于**政策与权贵层面**：关税高低、能否自由进城、城主是否故意刁难、城里大势力是否针对你。
- **普通 NPC 拥有完全独立的立场**，不随城市态度被裁定。
- 因此：敌对城（枯林 / 海盐 / 灰烬）的铁匠可能乐意帮你修车；友善城（粮野 / 黑石）也有想坑你钱的奸商。
- 🔴 **本口径同样适用于城市交互的全部场景**（`第2A类`）—— 🔴 **第9A类城市系统不建**（用户裁定：城市交互已由 `第2A类` 覆盖，宏观城市系统与孤旅调性冲突），城市差异主要通过统治层政策（关税 / 准入）体现，**而非全员立场**。

### 1.8 谈崩处理与竞争者窗口（防刷）

- **谈崩 ≠ 绝交**：可以妥协到一个双方都接受的价格成交；也可以改日再来，他**不涨价**继续谈。
- **竞争者时间窗口（防无限拉锯）**：
  - **稀缺物资 + 订单**：有窗口，约 **1~2 周（游戏内时间）**，玩家磨蹭会被世界上**别的商队买走 / 接走**，该单消失。
  - **普通物资**：**不设窗口**，满世界都是不值得抢，玩家可随意讲价。
- 此机制既防止无限拉锯，又让"世界在运转"——别的商队也在活动、抢机会。

## 二、订单系统

> 🔴 **本节是订单的家** —— 分档 / 报酬公式 / 类型 / 时效 / 违约 / 接单规则，**全部写在这里**，别处只引用。
> ⚠️ **数值口径**：移动基准 = **3 格/天**（`第1A类 §2.2`）；🔴 **本节的 `H_档` / `k_档` / `k_期` 只是推导用的参考值**，最终数值走 **`23` 数值推导规则** / **`24` 执行器**，**不在本文件手改**。

### 2.1 订单从哪来 · 怎么流转（**玩家视角的完整流程**）

```
① 在城里看到订单       ← 市场 / 商会分会 / 悬赏板 / 城主·领主 / 个人 NPC / 酒馆
        ↓
② 决定接不接（讲价可抬酬金，见 §一）
        ↓
③ 接单 → 货物/人/目标 装车（占车厢格，见 `第3A类 §3`）
        ↓
④ 出发上路（🔴 订单只给起点+终点，怎么走玩家自己定）
        ↓
⑤ 路上：可顺路接别的单 / 探索 / 卖货（🔴 期限是"里程预算"，不是死线）
        ↓
⑥ 到终点交付 → 按 §2.7 判结果（早到 / 准时 / 延期 / 严重超期）
        ↓
⑦ 领报酬（+ 或 − 声望）
```

- 🔴 **同时持单无上限** —— **为什么**：A→B 路上有 C 点，去 C 的单和去 B 的单顺路，就该一起接、顺路做，路上还能卖货。**多接顺路单正是赚钱方法**，不该禁。
- 🔴 **好消息：订好货 ≠ 一定要按时到**（见 2.7）。

### 2.2 四档划分（**按路程，不按客户要求**）

> 🔴 **移动基准 3 格/天** → **天数 × 3 = 格数**（`第1A类 §2.2`）

| 档位 | 天数 | 对应格数 | 典型阶段 |
|:--|:--:|:--:|:--:|
| **短途** | **≤ 60 天** | ≤ 180 格 | 初期 |
| **中途** | 60 ~ 120 天 | 180 ~ 360 格 | 初期 → 中期过渡 |
| **长途** | 120 ~ 200 天 | 360 ~ 600 格 | 中期 |
| **超长途** | **≥ 200 天** | ≥ 600 格 | 后期 |

- 🔴 **超长途有上限**（600 格 / 200 天）—— 不是无限单。
- **期限** = **路程天数 × `k_期`**（短 2.0 / 中 2.1 / 长 2.2 / 超长 2.3 · ⚠️ 参考值，归 `23`）。
- 🔴 **期限 = 里程预算，不是限时死线**（2026-09-24 用户定）：**订单只规划路线** —— 怎么走、绕不绕、停不停，玩家自己决定。

### 2.3 报酬怎么算（**主式**）

```text
订单报酬 = H_档 × 路程天数 × k_档

k_档（倍率，逐档递增 · 超长途单独拔高）：
  短途 2.4  ｜  中途 2.7  ｜  长途 3.0  ｜  超长途 3.6
```

| 档位 | `k_档` | 净利润率（走最短 · 全额拿 · 上限口径） |
|:--|:--:|:--:|
| 短途 | 2.4 | 约 140% |
| 中途 | 2.7 | 约 170% |
| 长途 | 3.0 | 约 200% |
| 超长途 | 3.6 | 约 260% |

- **`H_档` = 该档应有规模的日均硬账**（⚠️ 参考值 300 / 934 / 1,493 / 1,493，**归 `23`**）。
- **倍率是中心值，不是固定值** —— 实际发放时在该倍率上下浮动（⚠️ ±5%，待实测）。
- 🔴 **"净利润率"是上限口径**（走最短路径、不在路上多待）；**期限给足后玩家通常会"在路上多待"** → 实际净利向下走。
- 🔴 **报酬可以谈**（接单时抬酬金，见 `§一` 讲价）—— 谈成了就是你的。

### 2.4 订单类型（**4 大类**）

| 类型 | 内容 | 时效 | 🔴 需要接取？ | 失败条件 |
|:--|:--|:--:|:--:|:--|
| **送货** | 把货物运到指定收货地 | **有期限** | ✅ **需要** | 严重超时 → 失败 |
| **护送** | 护送某人 / 某物到指定城市 | **有期限** | ✅ **需要** | 严重超时 → 失败 |
| **收购** | 高价收购指定物品（城市 / 个人发布） | **无期限** | ❌ **不用接** | 无 —— 交货就给钱 |
| **悬赏** | 击杀指定敌人 / Boss | **无期限** | ❌ **不用接** | 无 |

- **来源**：市场 / 商会 / 悬赏板 / 领主·城主 / 个人 NPC / 酒馆。
- 🔴 **收购、悬赏不用专门接** —— 带着货到了直接交、杀了目标拿凭证直接领，**世界更活**。
- 🔴 **收购 / 悬赏有随机时限**：**被别的商队 / 赏金猎人完成了就消失** —— 世界在运转，别人也在抢。

### 2.5 难度分级

| 难度 | 说明 |
|:--|:--|
| **很简单 / 简单 / 正常 / 困难 / 很困难** | 越难 → **刷新率越低 · 奖励越高 · 被 NPC 抢走得越慢** |

### 2.6 接单规则与刷新

| 项 | 规则 |
|:--|:--|
| **同时持单** | 🔴 **无上限**（理由见 2.1） |
| **期限** | 路程天数 × `k_期`（见 2.2）· 🔴 **里程预算不是死线** |
| **讲价抬酬** | 接单时可谈判提高酬金（`§一`） |
| **刷新** | **每天随机刷新**，各类型概率 ⚠️ 待定 |
| **竞争者窗口** | 好订单约**1~2 周（游戏内）**会被别的商队接走（`§一 1.8`） |

### 2.7 交付结果与违约（**四种结局**）

| 交付情况 | 结果 |
|:--|:--|
| **早到** | 🔴 **额外声望奖励**（可能还有小额奖金 ⚠️ 待定） |
| **正常时间到** | 无额外奖励、无惩罚，**按约定付酬** |
| **延期**（超期但可补救） | **声望损失 + 佣金减少**（还是给钱，只是少给） |
| **严重超期** | **大量声望损失 + 不支付报酬** → **订单失败** |

- 🔴 **货物被毁不算订单失败**，只损失货物本身（不扣报酬 —— 那是 `第3A类 §5.2` 的货损，另一件事）。
- 🔴 **延期不是失败** —— 铁律："**迟到 ≠ 失败**"。延期照样拿钱（少拿），只有严重超期才黄。
- **收购 / 悬赏** 无接取，不存在失败，只可能**被别人完成而消失**。
- 🔴 **货损 ≥70% → 订单直接失败**（见 `第5A类 §7.3`）。

### 2.8 🔴 一条贯穿全局的红线

> 🔴 **订单只定起点和终点，怎么走玩家自己定。**
>
> 期限给得足（≥ 最短路程 × 2），所以**绕路、停驻、探索都不亏**（`第0A类 §三`）。**订单不是"限时打卡任务"，是"一段路的委托"。**

## 三、跨城物价与跑商

> 核心结论（🔴 细则原挂在 `90_历史与废案/25_Demo计划_已废案_20261024/14`，**已按废案管理**）：
> - **每城一套价**（🔴 **物价三档口径见 `第2A类 §1.3`** —— 一档：大城 · 小城 → 二档：城镇 · 驿站 → 三档：村庄最贵；有特产的城把该货调低）；**每日三角分布波动**（一般货±20%、战略资源±10%）。
> - **跨区利差**是核心玩法：产地低价买入 → 他城高价卖出（如盐 60→100、钢锭 130→220、灰烬兽牙 800 来自高灰区）。
> - 货物可卖到任意地点，玩家自挑收货地。
