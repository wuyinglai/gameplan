# A 类文件 · 设定权威源

> 🔴 **整个项目的规则唯一权威源** —— 机制 · 数值 · 世界观 · 设计思路。
> 🔴 **谁改**：只有 WorkBuddy（AI）能改；**改前必须先解锁只读，改完必须上锁**。
> 🔴 **冲突时**：🔴 **用户最新口头指令 > `正文/` > `附件/`**。

---

## 📌 这个文件夹装什么

```
A类文件\
├─ 正文\    ← 🔴 **规则本体** —— 「现在是什么口径」· 写代码和做设计的依据
└─ 附件\    ← 🔴 **历史档** —— 「当初为什么这么定」「什么时候改的」· 只供追溯
```

| | 🔴 **正文/** | 🔴 **附件/** |
|:--|:--|:--|
| 装什么 | 🔴 **当前生效的口径** | 🔴 **搬走的历史内容** |
| 回答 | 「现在是什么规则」 | 「这条规则怎么来的 · 什么时候改的」 |
| 生命周期 | 🔴 **一直在改**（每次裁定都更新） | 🔴 **只追加，不动** |
| 冲突时 | ✅ **以它为准** | ❌ 不作依据 |

> 🔴 **规矩**：**正文只留当前口径**；历史论证、修订记录、废案原因**一律下沉到附件**。
> 🔴 **同一件事不许写两遍** —— 正文的每一段只在一处出现，其他地方只放一行指针。
