# A5.2 士气下降与扣减上限

> **来源**：`3A` 第 474–504 行 · 复制迁移 2026-10-28（🔴 迁移只搬不修，原文一字未动）
> **系统**：A5 · **迁移期权威源仍为旧 A 类**

### 4.3 士气下降

⚠️ **以下数值为参考值**。

| 事件            |                  变化                  |
| :------------ | :----------------------------------: |
| 一名角色轻伤或重伤      |                  -1                  |
| 两名角色在同一场战斗中受伤 |              -2（受扣减上限限制）             |
| 三名角色全部重伤但商队未毁 |                  -3（**封顶**）           |
| 🔴 **其中含严重重伤**     | 🔴 **该人按 2 人份算** —— 所以 1 人严重重伤 = **-2**；仍受 -3 封顶 |
| 商队耐久降到 25% 以下 |             -1（每趟远行只首次触发）            |
| 商队耐久归零但未崩溃    |                  -1                  |
| 订单货物损失超过 50%  |              -1（每单只触发一次）             |
| 🔴 **订单货物损失 ≥ 70%** | 🔴 **订单直接失败**（2026-10-15 用户定：**不再额外扣士气** —— 已经黄了，不用再补一刀）→ 判据见 `第5A类 §7.3` |
| 食物归零后继续行进     |                每天士气 -1（与 §1.6 统一）               |
| 灰烬风暴开始        |                  -1                  |
| 主动撤退          |                  -2                  |
| 崩溃撤退          | **不额外扣**（触发时士气已为 0）· 到达安全点后**恢复到 1** |
| 订单失败          |                  -2                  |


> 🔴 **轻伤与重伤一样扣，不分开算**（2026-10-14 用户裁定）—— 只要人受伤了就是 -1 起；🔴 **只有严重重伤额外加重**（按 2 人份算）。
> 没有死亡系统，没有死亡扣士气。
>

### 4.4 扣减上限

- 同一场战斗最多扣 **-3** 士气（🔴 **含严重重伤加权之后仍是 -3 封顶**）
- 同一天最多扣 **-3** 士气（🔴 **崩溃撤退不在此列** —— 它**不扣士气**，见 §4.3 校注）
- 🔴 **为什么要封顶**：一次战斗打成什么样都是 -3，**不让单场战斗把士气打穿** —— 真正拖垮士气的是"连续很多天的消耗"，不是某一场硬仗
