## 一、交易与讲价系统

本系统借鉴"商人视角游戏"的核心乐趣——**做生意本身就是目的，不是手段**。讲价机制从已有系统自然长出，不凭空加设定。

### 1.1 交易场景

商队在各类地点（城市 / 城镇 / 小城 / 驿站 / 村庄）可与固定商人 NPC 发生三类交易：

| 场景 | 行为 | 讲价方向 |
|:----|:----|:----|
| 买 | 购入货物 / 装备 / 补给 | 压低成交价 |
| 卖 | 出售货物 / 旧装备 | 抬高成交价 |
| 接订单 | 与订单发布者谈酬金 | 抬高委托酬金（"这趟风险大，加钱我才接"） |

标价为**城市基准价**（🔴 价格的家 = **`第2A类 §7`**，不在本文件），讲价围绕基准价上下浮动。

### 1.2 讲价触发

- **大单 / 订单**：默认进入谈判界面。
- **小单**：按默认价直接成交；玩家**主动按键**才进入讲价。
- 自然过渡：前期资金紧张，玩家会为省几块主动讲价攒钱买装备；后期宽裕后往往直接按默认价买，不再耗时间讲小单。

### 1.3 讲价执行者

- 队伍中有 **"账房 / 商人"特质的特殊人员**（定义见第6A类）→ 讲价加成：成交空间更大、对方更易接受。
- **无特质（队长自己谈）** → 也能讲，但成功率降低、对方底线更硬（压不到那么低 / 卖不到那么高）。
- 不强制要求特定职业在场，但有无对应人员会造成明显差异。

### 1.4 核心机制：5 轮拉锯 + 读态度

每个固定商人 NPC 隐藏三条线，玩家不可直接读取数值：

| 隐藏线 | 含义 |
|:----|:----|
| 成本底价 | 他的成本线，低于此他不卖 / 不买 |
| 满意价 | 他心理舒服的成交价 |
| 急迫度 | 他多想做成这单（库存积压 / 急需某货 / 月底交差等） |

玩家出价 → NPC 给出**态度反馈（不显示数字）** → 可拉锯最多 **5 轮**，越谈越能摸透对方价位区间：

- 他皱眉 → 你压太低 / 抬太高
- 他眼神亮了 → 这价他赚到了
- 他叹气说"今年灰重货紧" → 暗示稀缺、底线硬

第 5 轮或玩家主动喊停时定结果：成交 / 妥协价成交 / 暂不成交。

### 1.5 影响成败的变量

讲价结果由以下因素共同决定（均从已有设定长出，不新增独立系统）：

1. **讲价者特质**：有"账房 / 商人"特质 → 加成。
2. **宏观声望**：商会城市分会声望（见第7A类）。声望高 → 该城分会提供更好价格与订单条件。
3. **个体信任**：具体 NPC 的信任值（见 1.6）。
4. **城市态度（仅统治层政策，见 1.7）**：影响关税与官方门槛，不裁定普通 NPC。
5. **灰度**：高灰烬区物资稀缺 → 卖家抬价、玩家反而能高价出货。
6. **急需度**：你带去的货正是对方紧缺的 → 他更松口。

### 1.6 声望与个体信任（三层）

- **世界声望（全局）**：跨城可见的**公开名声**，放在所有城市都算数。遭遇其他商队时**对方能看到它**（见第7A类「路上遇到的人」）；动手打人被发现会掉，**剿灭有悬赏的劫道者会涨**。
- **宏观声望（城市分会级）**：沿用第7A类设定。玩家是余烬商会流动分会，在某城分会声望高 → 该城提供更好价格与专属订单。
- **个体信任（NPC 级）**：每个固定商人 NPC **有名字、有信任值**。
  - 公平成交、不欺诈 → 信任升；
  - 狠宰 / 骗 → 信任降。
  - 信任高了 → 给暗折扣、留好货、甚至**透露灰烬区情报**（接"世界活着"与灰度系统）。
- **通缉标记**：被某城悬赏的公开状态，遭遇时可见。它有两面——**对方被通缉 = 打他合法、无恶名、还能领赏**；**自己被通缉 = 谁都不怕先动手打你，且赏金猎人会上门**（见第7A类 §五 / §六）。
- 这几层叠加，是把"稀疏的生机"变成温度的方式——路上难得遇个熟人，处好关系就是孤旅里的温暖点。

### 1.7 城市态度的修正口径（重要）

**城市态度仅指统治阶层的官方政策**：
- 城市的"态度"**仅指其统治阶层 / 城主 / 主流势力对商队的官方政策态度**，作用范围限于**政策与权贵层面**：关税高低、能否自由进城、城主是否故意刁难、城里大势力是否针对你。
- **普通 NPC 拥有完全独立的立场**，不随城市态度被裁定。
- 因此：敌对城（枯林 / 海盐 / 灰烬）的铁匠可能乐意帮你修车；友善城（粮野 / 黑石）也有想坑你钱的奸商。
- 🔴 **本口径同样适用于城市交互的全部场景**（`第2A类`）—— 🔴 **第9A类城市系统不建**（用户裁定：城市交互已由 `第2A类` 覆盖，宏观城市系统与孤旅调性冲突），城市差异主要通过统治层政策（关税 / 准入）体现，**而非全员立场**。

### 1.8 谈崩处理与竞争者窗口（防刷）

- **谈崩 ≠ 绝交**：可以妥协到一个双方都接受的价格成交；也可以改日再来，他**不涨价**继续谈。
- **竞争者时间窗口（防无限拉锯）**：
  - **稀缺物资 + 订单**：有窗口，约 **1~2 周（游戏内时间）**，玩家磨蹭会被世界上**别的商队买走 / 接走**，该单消失。
  - **普通物资**：**不设窗口**，满世界都是不值得抢，玩家可随意讲价。
- 此机制既防止无限拉锯，又让"世界在运转"——别的商队也在活动、抢机会。
