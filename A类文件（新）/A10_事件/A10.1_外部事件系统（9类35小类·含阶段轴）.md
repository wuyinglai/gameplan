## 3. 外部事件系统（5.2）

### 3.1 四层抽取结构

**第一层**：按自然区域判断是否发生强事件
**第二层**：若发生强事件，从**大类池**抽取（战斗 / 交涉 / 通行 / 落脚 / 采集 / 搜刮 / 交易 / 求助 / 情报）
**第三层**：在该大类内按**小类**权重抽取（如「战斗」下抽强盗 / 野兽 / 灰烬兽）
**第四层**：在该小类内抽**具体条目**（如「强盗」下抽索过路费 / 抢货 / 扣人）

> 🔴 **四层的意义 = 权重表可分层维护**：区域气候决定"哪类事多"（第二层），当地生态决定"具体遇上谁"（第三层），剧本决定"这一次什么戏"（第四层）。**加事件只动第四层，不用改权重表。**

### 3.3 外部事件类型总纲（**9 类 · 35 小类** · 2026-09-29 重排）

> 🔴 **为什么重排**：旧 `E1~E13` 是按「事件**讲什么**」排的（E1 遇敌 / E2 道路 / E3 资源…），有两个硬伤 ——
> ① **维度不纯**：`E2 道路` 与 `E10 路线判断` 都是"路的事"；`E9 情报` 与 `E13 地标视野` 都是"信息的事"，边界靠感觉；
> ② **装不下新系统**：装具盘 · 商队信物 · 记忆 · 货舱模块 · 灰度三层 —— **一个接口都没有**。
>
> 🔴 **新维度 = 「它要求玩家做什么」** —— 9 类 = **9 种玩家动作**，**互不重叠、也不漏**，任何事件都能塞进**唯一**一类。

| 大类 | 干什么 | 玩家动作 | 小类（**= 权重表的格子**） |
|:--|:--|:--|:--|
| **战斗** | 已经动手的 | 打 · 避 · 撤 | **强盗** · **野兽** · **灰烬兽** |
| **交涉** | 还能谈的 | 谈 · 让 · 威胁 · 识破 | **谈判**（要钱/货/过路费）· **识破**（伪装商队 · 劫道者）· **威慑**（亮实力）· **驱赶**（火/声/气味/诱饵）· **示好**（投喂/让路） |
| **通行** | 让路本身要代价 | 修 · 绕 · 停 · 硬闯 | **路被挡** · **路难走** · **车损风险** · **岔路近路** |
| **落脚** | 给节奏留白 | 落脚 · 修整 · 补给 | **天然庇护** · **前人营地** · **野店** |
| **采集** | 自然给的 · 花时间 | 快采 · 停采 · 放弃 | **水** · **食物** · **药草** · **材料** |
| **搜刮** | 人造遗留 · 花风险 | 翻 · 拆 · 拿走 | **遗落货箱** · **废弃车辆** · **废墟建筑** · **遗迹** · **战场尸骸** |
| **交易** | **对等**交换 | 买 · 卖 · 换 | **行商** · **其他商队** · **猎人/采集者** · **走私黑市** |
| **求助** | **不对等**交换 | 帮 · 拒 · 索价 | **有人求你** · **你求人** · **共同困境** |
| **情报** | 揭示地图与敌情 | 记 · 追 · 忽略 | **敌情** · **地形** · **世界** · **商情** |

🔴 **两条判据（防止类与类打架）**：

| 分界 | 归哪边 |
|:--|:--|
| 打了人 vs 还能谈 | **战斗 / 交涉** —— **谈不拢才打** |
| 摘药草 vs 翻遗迹 | **采集 / 搜刮** —— **自然的 / 人造的** |
| 换货 vs 有人求你 | **交易 / 求助** —— **对等 / 不对等** |
| 有人喊渴 vs 你喊饿 | **求助 / 补给（内部）** —— **外因 / 内因** |
| 路把车弄坏 vs 车自己坏 | **通行（外部）/ 车（内部）** —— **触发源在哪边** |

🔴 **"档位"不占分类位** —— **普通 / 精英 / Boss 是"类内强度"，不是小类**。战斗小类只有 3 个（敌种），写法恒为「**敌种 (档位)**」（如「强盗(精英)」「灰烬兽(Boss)」），与 `17 §6` 敌人表**同形**。

🔴 **交涉不是万能钥匙** —— 能不能用由「**对面是谁**」决定（与 `0A 第8A类 §6` 的"敌对灰兽没有回避选项"**接上、不是另起一套**）：

| 手段 | 强盗 | 野兽 | 灰烬兽 |
|:--|:--:|:--:|:--|
| **谈判** | ✅ | — | ⚠️ 看型（部分可"谈"= 不主动攻击） |
| **识破** | ✅ | — | — |
| **威慑** | ✅ | ✅（群居型怕大队伍） | ⚠️ 看型 |
| **驱赶** | — | ✅ | ✅ 部分型（**特殊记忆**可开更省事的驱赶法 → 记忆系统的解锁钩） |
| **示好** | — | — | ✅ **只对友善 / 中立灰兽** |
| **打 / 避 / 撤** | ✅ | ✅ | ✅（**敌对灰兽只能打**） |

🔴 **外部 9 类归 5 大区**（外面看是 5 类，里面是 9 类）：**冲突**（战斗 · 交涉）｜ **途中**（通行 · 落脚）｜ **收获**（采集 · 搜刮）｜ **人事**（交易 · 求助）｜ **信息**（情报）。

🔴 **编号 = `大类-序号`**（如 `交涉-2` / `通行-1`）—— **加事件直接往后排，永不留空洞**（旧 `E5` / `E8` 删了留坑的毛病不再有）。

**三条贯穿轴**（**每条事件都必须填**）：

| 轴 | 取值 |
|:--|:--|
| **触发方式** | 区域池抽 / 天气绑定 / 地点绑定 / 玩家主动 |
| **强度** | 普通 / **强**（占池） |
| **解锁钩** | **装具 / 记忆 / 信物 / 装备**（`0A 第6A类 §10.2`「装具盘 ≥ 人份阈值 → 事件多开一个选项」在旧事件表里**一个钩子都没有**，等于那句话是空的 —— 此处补齐） |

**🔴 第四条轴 · 阶段**（2026-10-23 新增 · 原则见 `第0A类_设计思路 §五`）：

| 阶段 | 玩家到的时候 | 事件状态 |
|:--|:--|:--|
| 🔴 **一 · 起因期** | 较早到 | **起因与发展过程** |
| 🔴 **二 · 转折期** | 较晚到 | **已升级 / 转折 / 僵持** |
| 🔴 **三 · 余波期** | 🔴 **很久以后** | 🔴 **事件已结束** —— 但🔴 **能从当地现状 · 人物经历 · 遗留物品 · 历史记录了解过去** |

| 判据 | 说明 |
|:--|:--|
| 🔴 **阶段由世界时间推进，不由玩家等待触发** | 否则就成了"蹲着刷进度" |
| 🔴 **事件不能因为玩家没来就消失** —— 但**可以已经结束** | 🔴 `7A §第零部分` 三条不能破之第 1 条 |
| 🔴 **"已结束"必须还能查到** —— 🔴 **遗留物 / 记录 / 人物转述** | 🔴 **否则玩家晚到 = 白来** —— 🔴 那就没有分阶段的意义 |
| 🔴 **余波期不重复给奖励** | 🔴 **它给的是"了解过去"，不是又一次战斗** |

> 🔴 **落点**：🔴 **阶段字段写进每条事件的统一 7 栏**（下条）—— 变成 **8 栏**。
> 🔴 **探索要能查「已结束事件的遗留」→ `第1A类 §9`**。

**每条事件的统一 8 栏**：`编号名 · 触发 · 出现条件 · **阶段** · 选项（2~4 个，各写代价与结果）· 解锁 · 冷却 · 压力标签`

> 🔴 **2026-10-15 用户定：重排暂缓，当前不铺新表** —— **现行有效编号 = `E1~E13`**（见 `§3.5` 起的原文，可直接用）。`9 大类 · 35 小类` 那套**只留作未来方向**，**不是现行口径，不得据它新增事件**。

### 3.5 E1 遇敌事件

商队遭遇敌对力量。可进入战斗，也可先出现伏击前兆、拦路威胁、追踪痕迹等战前状态。

> **本事件只管"敌对力量"（强盗 / 野兽 / 灰烬兽）**。与**其他正常人**（商队 / 信使 / 赏金猎人）的相遇走 **E4 商队/旅人事件**；其中"**伪装成商队的劫道者**"的配比、识破、先手与动手后果，见 **第7A类 §五「路上遇到的人」/ §六「动手与后果」**。

**敌对阵营：**
- **强盗** — 普通敌人基准（路匪、抢货强盗、火瓶匪、拦路队）
- **野兽** — 低强度、多数量（野狗、狼群、湿地兽、山地兽）
- **灰烬兽** — 高危险敌人（灰爪兽、灰蚀兽、灰烬虫群）

### 3.6 E2 道路事件

道路、通行、车损和路线选择事件，给玩家商队做选择题：修还是绕、花零件还是花时间。

**子类型：**
| 编号 | 类型 | 说明 |
|:---:|------|------|
| R1 | 通行受阻 | 原路线被挡住，需修、绕、等或强行清障 |
| R2 | 难行代价 | 路能走但通过需额外代价 |
| R3 | 车损/货损风险 | 车辆或货物损失检定 —— 🆕 **含"劣质箱自坏"分支**（见下） |
| R4 | 路线机会/绕路选择 | 出现近路、旧路、隐藏路径 |

> 🆕 **R3 的一个常驻分支：劣质箱损坏（2026-09-29）**
> **脆弱档的货舱箱会自己坏**（`0A 第6A类 §11.4.3`）—— **这是"便宜"的价格**。
> - **判定**：**每走一格判一次**（与本文档 **§0 的事件判定同频**）· 概率**很小**（⚠️ 值由 `24_数值计算器.html` 定）。
> - **后果**：箱体破裂 → **按箱内货量比例掉货**，**不整箱归零**。
> - **补救（必须给 —— 守"惩罚只能要价、不能剥夺"铁律）**：**停车加固**（**1 天 + 零件** → 该箱本趟不再判）· **转货**（0 成本，挪进别的箱 / 车厢 → **空箱不判**）· **硬扛**（0 成本，继续按原概率判）。
> - 🔴 **口径**：它**不占强事件池权重**，是 R3 内部的**独立小概率判定** → **不改 §3.2 的区域强事件概率**，也**不改变"世界不空"**。

### 3.7 E3 资源事件

发现资源机会，但不是白送资源。快速采集只拿一点，想拿更多需额外停留一天。

**子类型：**
| 编号 | 类型 | 例子 |
|:---:|------|------|
| G1 | 水源/补给类 | 水源、干粮、鱼、旧粮袋 |
| G2 | 狩猎/采集类 | 猎物、药草、干柴、兽骨 |
| G3 | 零件/材料类 | 备用零件、木材、金属残料 |
| G4 | 废弃货物/可交易物 | 遗落货箱、旧商队货 |
| G5 | 特殊/高风险资源 | 灰烬材料、污染残骸、旧时代样本 |

**给量限制：**
- 快速采集：通常 +1 补给/材料，零件低概率 +1
- 停留采集：+2 补给/材料，零件 +1
- 特殊资源：通常只给线索，实物有风险
