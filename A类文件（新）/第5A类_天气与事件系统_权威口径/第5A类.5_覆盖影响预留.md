## 4. 覆盖影响预留（**重排暂缓**）

自然区域基础强事件池只是底层，**地点覆盖**会再改一层权重（**乘在第二层大类上**，不新建事件）：

| 覆盖影响 | 抬哪些大类 / 小类 |
|:--------|---------------|
| **城镇 / 驿站周边** | **交易**（行商 / 商队）· **落脚**（野店）· **交涉**（盘查）· **情报**（商情 / 地形） |
| **城市外围** | **交易** · **交涉**（盘查）· **情报** |
| **稳定商路** | **交易** · **交涉**（通行规则）· **情报**（商情）· **通行**（岔路近路） |
| **断裂 / 危险商路** | **战斗** · **通行**（路被挡 / 车损风险）· **情报**（敌情）· **交涉**（拦路） |
| **废墟 / 遗址周边** | **搜刮**（废墟建筑 / 遗迹）· **情报**（地形 / 世界） |
| **巢穴周边** | **战斗**（野兽 / 灰烬兽）· **情报**（敌情） |
| **灰烬污染覆盖** | **战斗**（灰烬兽）· **搜刮**（战场尸骸 · 灰烬材料）· **交易**（走私黑市）· **情报**（世界） |

> 🔴 **只"抬权重"，不"加事件"** —— 覆盖影响改的是**抽签时的偏好**，否则同一件事要写好几份。
