## 3. 车厢容量（占格系统 v4.2）

> **核心转变**：格子不是「要手动摆放的仓库格」，而是一种**资源计数**。车队有「总容量 N 格」，物品按「占几格」计入，玩家只关心「还剩多少格能装」。**不做整理玩法**（无格子拼图、无挪货），装/卸按数量自动归类。
>   


### 3.1 初始车队与容量

| 项目   |                                   数值                                   |
| :--- | :--------------------------------------------------------------------: |
| 初始车队 |                **3 辆小型货车**（300 格/辆 · 14 人随车）               |
| 每车货容 | **`q` 格**（仅货车载货）—— 车型三档：**小型 300（前）/ 中型 600（中）/ 大型 900（后）**（锚 **A15**） |
| 总货容  |      **900 格**（3 辆小型货车 × 300）。通式 = **`q(阶段) × 计耐久货车数` + 容量箱**      |
| 载重上限 |               **格数 × 2 = 1800 kg**（轻货填格子、重货压重量，临界 2 kg/格）              |
| 耐久   |             **只计货车**（3 辆 × 60 → 总 180）；**载人车不计耐久、不被攻击**             |

> **扩容三条路**（① 换车 `q` · ② 加挂货车 · ③ 容量箱）见 **§3.3**；**货舱模块**（容量箱 / 功能箱 / 品质三档）见 **`0A 第6A类 §11.4`**。

### 3.2 物品占格与重量

| 物品         |   占格  | 容量/说明                       |                      重量                     |
| :--------- | :---: | :-------------------------- | :-----------------------------------------: |
| **食物**     |  1 格  | **5 份**（后期可升 10 份/格，见 §3.5） |           **2.5 kg/格**（= 0.5 kg/份）          |
| **清水（水箱）** |  1 格  | **3 份**；喝完水箱占格不释放、可再灌       | 满箱 **1.5 kg/格**（= 0.5 kg/份）；**空箱 0.1 kg/格** |
| **零件**     |  1 格  | 1 个                         |                 **1.5 kg/个**                |
| **药包**     |  1 格  | 1 个                         |                 **0.3 kg/个**                |
| **贸易货物**   | 按货物类定 | 见《14_跑商系统数值》                |                    按货物类定                    |

> **重量口径（2026-09-14 统一）**：物品重量一律以 **kg** 计、**保留一位小数、允许小于 1**；**界面照原样显示小数（`0.5` / `1.5`），一律不取整**。重量是**软限制**（真正的硬限制是车厢格）。
>   
> **细粒度基准值以 `第 6A 类 §11.2` 为准**：补给 **0.5 kg/份** · 零件 **1.5 kg/个** · 药包 **0.3 kg/个** · 普通货物 **0.1~3.0 kg/件**；本表的"kg/格"是**整格口径**（1 格 = 5 份食物 / 3 份水）。**2026-09-14 已按细粒度值把上表整格重量换算对齐并锁值。**

**双约束规则**：

- 物品同时占「体积格」与「重量」。
- 任一满（格满 或 重满）都装不下。
- 轻货（食物 2.5 / 药包 0.3 / 水满 1.5）优先撞格子上限；重货（零件 1.5）优先撞重量上限。

**水/食物特殊规则（用户早期认可，保留）**：

- 食物吃完 → 该格释放（可再装货）。
- 水喝完 → 水箱仍在，占格不释放（可重复灌）；瓶装/容器水可交易（卖/喝两用）。
- 空水箱重量极低（0.1 kg），长途越走越轻。

### 3.3 车厢容量成长

**"货舱变大"有三条路**（完整口径见 `0A 第6A类 §11.1 / §11.4`）—— **互相不顶替，量级差一个数量级**：

| 路             | 动什么        | 幅度                                                                             | 说明                           |
| :------------ | :--------- | :----------------------------------------------------------------------------- | :--------------------------- |
| **① 换车（`q`）** | 车的**规格**   | 300 → 600 → 900（**×3**）                                                        | **大跳 · 贵 · 一次到位**（锚 A15）     |
| **② 加挂货车**    | 车队的**规模**  | 🔴 **每辆 +`q` 格 / +60 耐久**（**跟着当期能买到的规格**：前 **+300** / 中 **+600** / 后 **+900**） | 多养一辆（多 1 车夫 + 2 后勤）          |
| **③ 容量箱**     | 现有车的**微调** | 每车**数十格**                                                                      | **补零头** —— 空间差一点就够，**不必换新车** |

> 🔴 **总量由 `24_数值计算器.html` 生成**（`q(阶段) × 计耐久货车数` + 容量箱），**本表不手写总量**。

### 3.4 车厢限制原则

| 限制           | 含义                                        |
| :----------- | ----------------------------------------- |
| **空间（格）**    | 硬限制，格子塞不进去就不能带                            |
| **重量（载重）**   | 硬限制（= 格 × 2），超重同样装不下                      |
| **补给挤压货物**   | 食物/水/零件/药包占格占重，会挤压贸易货空间——但格子是计数不是拼图，不手动整理 |
| **订单货物**     | 也占格，和补给竞争空间                               |
| **战利品/灰烬材料** | 也占格，远行后期进一步挤压空间                           |

### 3.5 可升级项（占格与补给效率）

| 升级项  |       初始（常规补给）       |       后期（可升）       | 说明                         |
| :--- | :------------------: | :----------------: | :------------------------- |
| 食物密度 |  5 份/格（普通粮 ≈10 金/份）  |   **10 份/格（优质粮）**  | 单格装更多食物，省格                 |
| 零件效率 | 10 耐久/个（普通件 ≈50 金/个） | **20 耐久/个（高耐久零件）** | 单零件修更多耐久，省零件（见 §2.4）       |
| 水净化  |        仅干净水可饮        |   **可饮脏水**（净化设备）   | 见 §1.7；大幅减轻超长途（≥200 天）补给压力 |

#### 升级机制（购买更高品质的同类补给）

**升级的本质 = 在特定城市购买「更高品质的同类补给」，而非独立升级槽。**

- 部分城市有特产 / 更高工艺：例如 **粮野城**（粮产城）出售 **优质食物**——同样 1 格装 10 份，但单价更高（示例：**30 金/份**，对比普通 10 金/份）。
- 同理，高耐久零件（20 耐久/个）在部分城市工坊可按更高价购入（示例：**150 金/个**，对比普通 50 金/个）。
- 含义：「升级」用 **金钱 + 城市选择** 换「更省格子 / 更耐修」，玩家在特产城按需采购即可，无需单独升级界面。

> ⚠️ 上述城市与单价仅为 **机制示例**（正式版由物价/地点系统逐城定稿，AI 不编具体城价）。
>   
> **Demo 阶段的基准值** → 见 `90_历史与废案/25_Demo计划_已废案_20261024/Demo范围与限制.md`。
>

| 项目             | 60 天总量 |      占格     |           重量           |
| :------------- | :----: | :---------: | :--------------------: |
| 食物（840 份）      |  840 份 |    168 格    |       **420 kg**       |
| 水（水箱，840 份）    |  840 份 |  280 格（常驻）  | 满 **420 kg** / 空 28 kg |

| 药包（常备 ~15 个）   |  15 个  |     15 格    |       **4.5 kg**       |
