## 4. 士气系统

| :----- | :----: |
| 士气范围   |  0-10  |
| 初始士气 | 🔴 **6**（2026-10-24 项目主裁定；原参考值「6/10」取 6，**已写死**） |

### 4.2 士气状态

|  士气  |   状态  | 说明         |
| :--: | :---: | ---------- |
| 8-10 |   高昂  | 商队状态很好     |
|  5-7 |   正常  | 商队稳定       |
|   4  | 低士气预警 | 提示需要休整     |
|  2-3 |   危险  | 继续远行风险明显   |
|   1  |  崩溃边缘 | 强烈提示尽快找安全点 |
|   0  |   崩溃  | 强制撤退       |

### 4.3 士气下降

⚠️ **以下数值为参考值**。

| 事件            |                  变化                  |
| :------------ | :----------------------------------: |
| 一名角色轻伤或重伤      |                  -1                  |
| 两名角色在同一场战斗中受伤 |              -2（受扣减上限限制）             |
| 三名角色全部重伤但商队未毁 |                  -3（**封顶**）           |
| 🔴 **其中含严重重伤**     | 🔴 **该人按 2 人份算** —— 所以 1 人严重重伤 = **-2**；仍受 -3 封顶 |
| 商队耐久降到 25% 以下 |             -1（每趟远行只首次触发）            |
| 商队耐久归零但未崩溃    |                  -1                  |
| 订单货物损失超过 50%  |              -1（每单只触发一次）             |
| 🔴 **订单货物损失 ≥ 70%** | 🔴 **订单直接失败**（2026-10-15 用户定：**不再额外扣士气** —— 已经黄了，不用再补一刀）→ 判据见 `第5A类 §7.3` |
| 食物归零后继续行进     |                每天士气 -1（与 §1.6 统一）               |
| 灰烬风暴开始        |                  -1                  |
| 主动撤退          |                  -2                  |
| 崩溃撤退          | **不额外扣**（触发时士气已为 0）· 到达安全点后**恢复到 1** |
| 订单失败          |                  -2                  |


> 🔴 **轻伤与重伤一样扣，不分开算**（2026-10-14 用户裁定）—— 只要人受伤了就是 -1 起；🔴 **只有严重重伤额外加重**（按 2 人份算）。
> 没有死亡系统，没有死亡扣士气。
>

### 4.4 扣减上限

- 同一场战斗最多扣 **-3** 士气（🔴 **含严重重伤加权之后仍是 -3 封顶**）
- 同一天最多扣 **-3** 士气（🔴 **崩溃撤退不在此列** —— 它**不扣士气**，见 §4.3 校注）
- 🔴 **为什么要封顶**：一次战斗打成什么样都是 -3，**不让单场战斗把士气打穿** —— 真正拖垮士气的是"连续很多天的消耗"，不是某一场硬仗

### 4.5 士气消费（⚠️ **价格与士气数值均为参考值**）

⚠️ **以下价格与效果均为参考值** —— 具体项目未定，实装时按实际设定调整。

| 项目       | 价格（参考） | 效果（参考） |    生效条件    |
| :------- | :----: | :----: | :--------: |
| **酒馆小聚** |  150 金 |  士气 +1 |  士气 6 以下有效 |
| **商队宴席** |  400 金 |  士气 +1 | 士气 10 以下有效 |
| **豪华休整** |  800 金 |  士气 +2 |    不限士气    |

规则：

- 只要有钱可以多次消费，不限制每座城市次数
- 士气有上限（最高 10），达到上限后无法再提升
- 🔴 **花钱恢复绕开 §4.6 的「上限 + 20 天冷却」** —— 那两根闸只管**自然**恢复；花钱是玩家的主动选择，代价是钱

### 4.6 自然士气恢复

🔴 **2026-10-06 用户裁定**：抵达**城市 / 城镇 / 驿站**时恢复 **+1 士气**（**所有地点一律 +1**，不按大小分档），但**有恢复上限 + 20 天冷却**。

| 地点              |   恢复   | **上限（士气低于此值才恢复）** |  冷却  |
| :-------------- | :----: | :---------------: | :--: |
| **城市**（大城 / 小城） | **+1** |     **6 点以下**     | 20 天 |
| **城镇**          | **+1** |     **4 点以下**     | 20 天 |
| **驿站**          | **+1** |     **4 点以下**     | 20 天 |
| **村庄**          |    0   |         —         |   —  |
| 野外              |    0   |         —         |   —  |

> 📜 **本段历史论证已移入附件** → 见 `../A类文件\附件/第3A类_附录_历史与修订.md`（2.4 为什么没有「大型城镇」这一档（2026-10-06））
>
> - **上限**：城市 ≤ 6 恢复、城镇 / 驿站 ≤ 4 恢复 —— 防止"到处停一停就把士气拉满"，**士气是稀缺资源**。
> - **冷却 20 天**：同一个地点**每 20 天最多触发一次自然恢复** —— 防止"在城门口反复进出刷士气"。绕路重访同一城站，20 天内**不再恢复**。
>     
>   **村庄不恢复士气，野外不会自然恢复士气**；**打赢精英战斗不加士气**。
>     
>   ⚠️ 以上数值**仅作参考值**，具体项目未写死（见 §4.5 消费表同条声明）。

### 4.7 花费金币额外恢复

在城市、城镇、驿站时，可以通过花钱额外恢复士气（**绕开 §4.6 的上限与冷却**，代价是钱）：

| 地点          |       可额外恢复      |
| :---------- | :--------------: |
| 城市（大城 / 小城） |      可额外 +1      |
| 城镇          |      可额外 +1      |
| 驿站          |      可额外 +1      |
| 村庄          | 可额外 +1（需花钱或触发事件） |
| 野外          |        不可用       |

> 每个地点每次停留最多额外恢复 1 次。具体消费价格见 §4.5 士气消费表。
>   
> ⚠️ 数值**仅作参考值**。
