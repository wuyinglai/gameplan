### 1.3 消耗规则（按「份」整数计量）

**食物和水以「份」为最小单位（整数，不拆份）：**

- 1 份食物 = 1 人 1 天口粮
- 1 份水 = 1 人 1 天饮水
- 购买补给按格（1 格 = 整数份），不拆散份

| 项目           | 规则                                                                                                              |
| :----------- | :-------------------------------------------------------------------------------------------------------------- |
| 移动 1 步（1 格）  | 消耗 **15 点野外体力**（**体力池上限 100 · 日回 50**；🔴 **不随人数变化——所有人都要一起走**；**正常 3 格/天 · 极限 4 格/天**、攒满冲刺 **6 格**；详见第 1A 类 §2） |
| 每人每天         | 消耗 **1 份食物 + 1 份水**                                                                                             |
| 🔴 **重伤恢复**    | 🔴 **重伤不是只有"休养"才恢复 —— 只要有食物和水，重伤每天自动恢复进度 +1**（走不走路都一样）。**食物或水归零 → 不但不恢复，反而恶化 1 档**（见 §1.6） |
| 🔴 **等待**        | 🔴 **野外也能等**（不只是城市 / 城镇 / 驿站）—— 原地不动过一天，**照常消耗食物和水**。等待**风险更高**：外部事件照常触发，且不会因为"你在等人"就减少 |
| 🔴 **野外扎营**    | 🔴 **和等待不是一回事**：① **不额外消耗食物和水**（和平时一样）② **消耗当天全部体力 + 全部可支配时间**（按日回 50 点体力 = 当天体力全掉，12 小时全用掉）③ **不受外部事件影响** —— 扎营期间只会有内部事件 ④ **扎营越久，内部事件触发率越高**（久扎必出事，但出的不是外部那类） |
| 订单期限         | 按天计算                                                                                                            |

### 1.4 出发采购（无推荐方案）

商队出发前自行采购补给，**不预设推荐 / 保守 / 冒险等方案**——玩家按路线长短、资金、据点分布自行决定买多少，**想怎么买就怎么买**。

- 清水以**水箱**为单位采购（1 格 = 1 水箱 = 3 份），喝完水箱占格不释放、可沿途再灌（见 §3.2），**没有"水桶"设定**。
- 食物 / 零件 / 药包按 §1.3 消耗、§3.2 占格与重量自行搭配。
- 采购成本以第 2A 类经济系统为准；初始资金见 §1.1。



### 1.5 商队人数与补给消耗

商队初始 **14 人**（核心成员，含 3 护卫 + 车夫 + 后勤 + 其余，详见第 **6A** 类），后期可招募扩展，**不设硬上限**。

商队人数影响战斗行动点数（行动点数归属第 **4A** 类战斗系统）；🔴 **每天食物/水消耗只按「出战人数」算**（见下表）。

|   **出战人数**  | 每天食物 | 每天清水 | 说明                                                                     |
| :---------: | :--: | :--: | ---------------------------------------------------------------------- |
| 3 人（初始出战基准） |  3 份 |  3 份 | 🔴 **每人每天 = 1 份食物 + 1 份清水**（2026-10-13 用户亲口定：14 人 = 14 份食物 + 14 份清水/天） |
|   每 +1 名出战  | +1 份 | +1 份 | 整数份，不拆份；🔴 **两列永远分开写，禁止合并成「28 份」这类总数**                                 |


> 🔴 **表述铁律**：两种资源**永远分开写**（「N 份食物 + N 份清水」），**禁止合并成「28 份」这类总数**。
> 🔴 **受影响的数值链待重调**：`§3.6` 示例账 · `04 §0.3` 日均硬账 300 / 934 / 1,493 · `第1A类 §10.2` 消耗模型 →统一由 `23` / `24` 处理（**盖章法：不在本文件逐行改数**）。
> 占格换算见 §3.2 / §3.6。
>
> 🔴 **不出战的人不消耗商队补给**（2026-10-06 用户裁定 · 2026-10-09 补解释）：**口粮他们自己买、工钱他们不领** —— 因为**还没被雇佣**（雇佣 = 建立关系 = 领工资 + 吃商队的粮）。商队走到哪人跟到哪（`§4.9.3`），不出战的人**仍在车队上**，只是这一趟没动用他们。完整理由见 `§4.9.2` / `第6A类 §8.4`。

### 1.6 食物/水耗尽惩罚（立即生效，不等待）

🔴 **2026-10-05 用户裁定：血量上限与当前生命值「同步下降」** —— 100/100 断食一天 → **90/90**（上限 −10 **且** 当前 −10，**两件事同时发生**）。与 `第1A类 §5.2` 一致。

> **怎么算**：`−10%` = **减去「该角色最大生命值的 10%」这么多点生命值**。上限 100 → 上限变 **90**、当前血也变 **90**；上限 240 → 上限变 **216**、当前血也变 **216**（各人按自己的上限算，不是固定扣 10 点）。

**食物 = 0 后，每天恶化一次：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **10%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | **恶化一次**（见下方说明） |

> 🔴 **断粮士气 −1 与其他士气惩罚叠加**（2026-10-24 项目主裁定）—— 多项惩罚同日发生时**各自照扣、不互相顶替**。

**清水 = 0 后，每天恶化一次：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **20%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | **恶化一次**（见下方说明） |

**🔴 重伤恶化 = 什么**（2026-10-14 用户要求写明）：

- 重伤角色本来**每天恢复进度 +1**；**一旦食物或水归零，这一天不但不恢复，反而倒退 1 档** —— 从"离治好更近"变成"离治好更远"。
- **恶化是往回退，不是叠加扣血** —— 血量那部分已经在上面两张表里扣了，这里动的是**重伤恢复进度**。
- 🔴 **恶化可以靠后续补粮补水退回来**（见下方「恢复机制」）—— **不是永久的**。

> 🔴 **为什么当前血也要扣**：被削掉的那部分上限**当场就没了** —— 100/100 断食一天变 90/90，而不是 100/90。**若只降上限、当前血不动**，会出现 60/100 这种"上限低于当前"的荒谬状态。
>
> 食物和水都归零 → 双重惩罚叠加（90/90 → 70/70），商队迅速崩溃。

### 1.6.1 🔴 补给耗尽的**恢复机制**（不是永久的）

🔴 **2026-10-14 用户裁定**：断粮断水削掉的上限**能补回来** —— 只要重新有食物和水，**每天自动往回修**，**但当前血量不会因此恢复**。

| 恢复来源 | 每天恢复「该角色上限的」 | 当前生命值 |
|:--|--:|:--:|
| **重新有食物** | **10%** | 🔴 **不恢复** |
| **重新有水** | **20%** | 🔴 **不恢复** |

- **上限会回来，血不会自己回来**：断食两天把上限从 100 削到 80，补粮两天后上限回到 100 —— 但**当前血仍然是 80**（或更低），要靠**药包 / 治疗 / 自然休息**把血填回来。
- **只挨一两天完全补得回来**；长期断粮削掉的幅度很大，靠自然回补会慢很多（每天 10% / 20%）。
- 🔴 **上限恢复到多少封顶**：**不超过该角色原本的上限**（不会因为多吃几天把上限撑得比初始还高）。

> 路上天然水源多为**脏水**，需净化后饮用（详见 §1.7）。

### 1.7 脏水与净化（后期机制）

路上常遇见**脏水**水源（事件系统详见第 5A 类），分两种情况：

| **情况** | **结果** |
| :--- | :--- |
| **未净化直接喝** | 🔴 **挂负面状态**：**污染度累积**（叠加型，可多层）→ 体力恢复变慢、士气自然恢复受阻；喝够一定量会**直接生病**（持续掉当前血，不治疗不会好） |
| **净化后饮用** | 后期解锁**净化设备**（水箱改造或车载净水模块）后，脏水可安全饮用，等于沿途白捡水源 |

> 🔴 **脏水不是"一次就死"，是"越喝越糟"**（2026-10-14 用户定方向）：脏水的代价走**累积**路线 —— 喝着喝着，队伍的整体状态被拖下去。
> **具体数值**（污染度几层、每层扣多少、几层生病）⚠️ **待定**，走 `23` / `24` 调平。
> **意义**：净化设备大幅减轻**超长途（≥200 天）**的补给压力——不必全程自带几百格水，沿途净化脏水即可。
>
> 净化设备属 §3.5「可升级项」之一，升级途径 ⚠️ 待定。
