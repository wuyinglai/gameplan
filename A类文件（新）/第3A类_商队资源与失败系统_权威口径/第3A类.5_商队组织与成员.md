## 4.9 商队组织与成员

### 4.9.1 成员分类（后勤 / 护卫 / 特殊人员）

| 类型                   |    是否出战   | 说明                                                                      |
| :------------------- | :-------: | :---------------------------------------------------------------------- |
| **后勤人员**             |     ❌     | 基础人员，**无特殊效果**，价格便宜且彼此差不多；**每次出发必须带够数量**（每车≥1车夫，后勤按人数配），不够有严重负面惩罚（具体后定） |
| **护卫**（战斗人员）         | ✅ 只有护卫能出战 | 如初始3人（护路人/荒野射手/修补师），能出战                                                 |
| **特殊人员**（厨师/账房/修车匠等） |     ❌     | **无统称，直接叫具体职业**；每个职业提供一种固定被动效果（如厨师每隔几天+1士气）                             |


> 🔴 **称呼统一（2026-10-06 用户裁定）**：**从始至终只有「后勤人员」这一个称呼** —— **没有「杂役」这个名称**。全库凡写"杂役"处一律改为"后勤人员"。
>   
> 硬性分工：只有护卫能出战，后勤 / 特殊人员不能参战。职责不交叉。
>   
> 人员上限：**升级车厢/车辆 → 增加可携带人员上限**。

### 4.9.2 核心成员与雇佣

> 📜 **本段历史论证已移入附件** → 见 `../A类文件\附件/第3A类_附录_历史与修订.md`（2.2 核心成员为什么不领日薪（2026-10-06 · 防止死档））

| 项目       | 规则                                                          |
| :------- | :---------------------------------------------------------- |
| **核心成员** | 🔴 **初始全部 14 人都是核心成员**（3 护卫 + 若干车夫 + 其余后勤 / 特殊人员）· **不领日薪** |
| **雇佣成员** | 之后招募的成员，**领日薪**                                             |
| 新核心角色    | **后期通过剧情/特殊事件，也可能加入新的核心角色**——同样不领日薪                         |
| 护卫日薪     | 后勤人员的 **2 倍以上**（平衡手段：出战无上限）；特殊人员居中                          |

> 🔴 **为什么核心成员不领日薪 —— 是「防死档」的结构件，不是人情设定**（用户 2026-10-06 给出理由）：
>
> **一天的硬账是三笔同时付**：**工资** + **补给（吃喝）** + **货 / 零件 / 药包**。
>
> - 如果**开局 14 人全要领工资**，玩家从第一天起就背上一笔**永不缩水的固定开销**；而**工资是按天付、不做任何折减** —— 于是「买货要钱 / 修车要钱 / 雇人要钱」全部叠加在**同一条已经见底的现金流**上。
> - 结果就是：**玩家迟早破产，且没有任何办法回血** —— 卖货？货已经压在车上了。裁员？🔴 **人只增不减、不可能裁**（§4.9.3）。于是**存档直接崩掉（死档）**。
> - **核心成员不领工资 = 商队有一个"零工资底座"** —— 哪怕玩家打光了钱、走投无路，**还有 14 个人跟着你**，队伍**永远不会因为"发不出工资"而整个垮掉**。工资只压在**后来主动招的人**身上，那是**玩家自己选的扩张**，亏了也是自己该承担的。
>
> **一句话**：**不领日薪 = 给玩家一条"破产了还能爬起来"的后路**，而不是一个温情设定。
>
> ⚠️ **这条同时决定了装备 / 装具可以放心砸**（见 §4.9.3）—— 因为核心成员**不会走**、**也不会因为欠薪而消失**。
>   
> 🔴 **反面代价（必须承认）**：不领日薪意味着**工资这个人数抑制器在初期是失效的** —— 早期招人几乎不涨成本，所以"招募"没有天然的价格刹车。这由**补给 + 车辆载人 + 编制铁律**（§1.5）来兜；`04 §0.7.5` 另算"后期工资随人数翻倍"的抑制作用。

### 4.9.3 成员离队

🔴 **2026-10-06 用户裁定：没有「被挖走」这回事。**

| 项目      | 规则                                 |
| :------ | :--------------------------------- |
| **被挖走** | 🔴 **不存在这个设定** —— 没有任何势力会来挖你的成员    |
| **逃跑**  | 🔴 **不存在这个设定** —— 士气低了不跑，只干活变差     |
| **减员**  | 🔴 **不存在"减员"这个概念** —— **商队人数只增不减** |

**玩家能做的只有一件事：在城市里决定谁出战**

| 操作       | 说明                                                           |
| :------- | :----------------------------------------------------------- |
| **选择出战** | 在城市里**自由切换**哪些护卫随队出战斗 —— **出战无上限**（不是"固定三人"，也不是"必须满员"）       |
| **不出战**  | 不出战的人**还在车队上**（他没有离队）：**不领工资**、**不消耗补给**、**不会消失**、**不会老**（理由见 §4.9.2）|
| **轮换**   | 🔴 **在任何城市都能换人** —— 因为人从来没离开过队伍（**商队走到哪人跟到哪**） |
| **装备**   | **谁出战，装备就跟谁走** —— 不出战的人装备在车队库里，不穿就等于在库房，这是玩家的自然选择 |
| **构筑**  | 🔴 **随时能换回来** —— **不需要重招、不重建构筑** |

> **为什么没有"被挖走"**：玩家在一个角色身上砸了装备、装具、记忆，**还把他排进阵容的核心** —— 结果某天他被高价挖走了，**玩家会非常烦**。这个设计是在惩罚玩家投入，不是制造决策。
>   
> **锈味替代**：人员选择的压力应该来自**"带谁出、谁留守"**（留守的人不领工资 = 白养），而不是"我会不会突然少个人"。
> 🔴 **两条轴分开算（2026-10-12 校，消歧）**：**工资看"雇佣关系"**（初始 14 核心成员 + 未招募者不领；招募进来的领，与出不出战无关，§4.9.2）· **补给看"出战关系"**（出战的人吃商队的粮，不出战的人口粮自己买，§1.5）。⚠️ 残余待裁：**招募来但不出战的成员**——按现行口径**领工资但不吃商队的粮**。
>   
> ⚠️ 原 §8.4「装备离队回收」「加装仅核心」两条设计前提（防装具随人流失）**已无必要** —— 详见 `第6A类` 同步记录。

### 4.9.4 牲畜（🔴 只作背景，不做系统 · 2026-10-09 裁定）

🔴 **本节不是系统，是世界观背景。**

**保留的意义**（一句话）：**后末日的世界里，商队是用牲畜拉车的。** 粮野城产马匹与驮畜、黑石城缺驮畜（见 `第7A类` 区域表）—— **这是画面，不是系统。**

| 项目 | 口径 |
|:----|:--|
| **要不要做系统** | 🔴 **不做** —— 没有饲料、没有水源、没有耐力、没有买卖、没有疾病死亡 |
| **进不进硬账** | 🔴 **不进** —— 跟人一样，**商队口粮不按牲畜算** |
| **算不算车数 / 编制** | 🔴 **不算** —— 车辆与编成口径见 `§4.9.5` 与 `§1.5` |
| **种类差异** | 🔴 **不做** —— 无载重 / 耐旱 / 稳定性差异 |
| **购买** | 🔴 **不作为可交易项** —— 城市里有牲畜，是背景 |
| **拉车 / 速度** | 🔴 **不做提速轴** —— 速度只有「加能量」一条轴（动力抬 `S`，见 `23 §2.2`），**牲畜不参与** |

> **为什么不做好**：① 它唯一的功能是"让车走得快"，而这件事 `23 §2.2` 已用「**动力抬 `S`**」解决，**不需要第二套实现**；② 一旦牲畜能加 `S`，就等于**多出一条提速轴** —— 直接违反 **2026-10-05 用户裁定「速度恒定（每格消耗恒定）、无任何提速手段」**；③ 真做起来要接**饲料 / 水源 / 耐力 / 车速 / 地形 / 疾病 / 价格** 七八个接口，**麻烦且收益不抵**。
>⚠️ **术语**：本节统一叫「**牲畜**」（类目，涵盖马 / 驴 / 驼等）；**「驮畜」是其中一类**，不是全部。
> 🔴 **搭配**：`23 §2.2` 动力轴原写「**驼兽 / 旧文明引擎**」—— **"驼兽"已改称「动力装置」**，避免与本节的牲畜纠缠。

### 4.9.5 车辆

🔴 **2026-10-06 用户裁定：车辆分两族 —— 货车（大/中/小）· 载人车（小型/大型）。**

**货车族** —— 按车厢格数分三档：

| 货车       | 载货（格） | 随车人员 | 用途   |
| :------- | :---: | :--: | ---- |
| **小型货车** |  300  |   有  | 前期主力 |
| **中型货车** |  600  |   有  | 中期主力 |
| **大型货车** |  900  |   有  | 后期主力 |

**载人车族** —— 🔴 **也分小型 / 大型两档**（**不拉货**）：

| 载人车       |  载客 | 用途 |
| :-------- | :-: | -- |
| **小型载人车** |  少  | 前期 |
| **大型载人车** |  多  | 后期 |

> ⚠️ **具体格数 / 载客数仅作参考值**，见 `第6A类 §11`（车型与 `q` 的对应）。
>   
> 🔴 **每车 ≥1 车夫**，随车人员 = 该车型自带的固定编制（战斗人员 + 后勤 / 特殊），换车才会变（见 `第6A类 §11.5`）。
>   
> **初始车队：3 辆小型货车（300 格/辆 = 900 格）**。车辆在城市工坊购买 / 升级。
>

### 4.9.6 联合商队

🔴 **2026-10-06 用户裁定：取消。** 理由（用户原话）：**"这个设定不太好弄"** —— 联盟要处理指挥权、战利品分配、AI 同盟、互相伤害判定一整套规则，**复杂且写不好**，收益不抵成本。

> 🔴 **不做** —— 玩家永远只操控**自己这一支商队**，不与其他商队结盟同行。
