## 5. 失败条件

🔴 **2026-10-06 用户裁定：这里没有"游戏结束"这回事 —— 所有失败都只是「撤退」。** 🔴 **退到哪儿（2026-10-12 用户裁定）**：**玩家指定的、已探明的大城 / 小城** —— **不是"最近的"**（会被白赚路程），完整规则见 §5.2。

### 5.1 三种"失败"

|  #  | 类型          | 触发                   | 是谁决定的    |
| :-: | :---------- | :------------------- | :------- |
|  1  | **士气崩溃**    | 士气归 0                | 系统       |
|  2  | **全队失去战力**    | 🔴 **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）**，**玩家真的没救了才触发** | 系统|
|  3  | 🔴 **手动撤退** | **玩家主动点撤退**          | **玩家自己** |

> 🔴 **第3 种（手动撤退）也算失败** —— 相当于**玩家主动认输**。但**代价明显小于前两种**（见 §5.3）。

#### 🔴 第 2 种的触发门槛：越难触发越好（2026-10-10 用户裁定）

> **用户原话**：「**强制撤退并不等于失败**……反而相当于**上调了强制撤退的下限**……玩家还有希望的时候不会强制撤退，**要完全没希望了才会**。」

**这是刻意把门槛调高的一批 —— 强制撤退触发得越难，玩家体验越好。**

**原条件（"全队倒下 + 商队耐久归零"）的问题**：它把**"打输了"**当成触发点 —— 但**打输不等于没救**：

| 漏洞 | 问题 |
|:--|:--|
| **车坏了 ≠ 修不好** | 耐久归零 → **抛锚 → 用零件能修好**（§2.4）—— 所以"车坏了"只是"停下来"，不是"没救了" |
| **重伤 ≠ 动不了** | 前三次重伤**都能靠等待恢复**（`第6A类 §7.2`）—— 所以"重伤"只是"这仗打得惨" |

**新条件 = 两条同时成立，"两头都堵死"**：

| | 条件 | 堵住什么 |
|:--|:--|:--|
| **① 人** | 🔴 **全队严重重伤** | 🔴 **全部失去战斗力** | 一个都不能上场（**注意：不是"重伤"** —— 前三次重伤能靠等待恢复） |
| **② 车** | 🔴 **零件耗尽** | 🔴 **再也修不好车** | 抛锚了也修不好 —— **真的走不了** |

> 🔴 **为什么是"零件"不是"药包"**（2026-10-12 用户纠正）：**药包只加血 —— 对「严重重伤」的人无效**（他不是伤，是动不了）。所以带不带药包都一样，**药包不该进触发条件**。
> 🔴 **零件才是真死结**：它是**唯一能解除抛锚的资源**（§2.4）—— 没了它，车一旦抛锚就**永远动不了**。

> ⚠️ **这不是"游戏结束"** —— 触发后仍然退回到安全点（§5.2），代价见 §5.3。**玩家可以接着玩**，只是这一趟完了。
> 🔴 **设计意图**：**玩家还有希望的时候，永远不会触发强制撤退。**

### 5.2 撤退去哪 🔴（2026-10-12 用户裁定 · 三处修正）

#### 5.2.1 撤退目的地（三条硬规则）

| 规则 | 内容 |
|:--|:--|
| 🔴 **只能是大城 / 小城** | 城镇 / 驿站 / 村庄**都不接收撤退**（`第1A类 §6`） |
| 🔴 **必须已探明** | 玩家**实际到过**或**侦察到过**的地点 —— **未知的不能退** |
| 🔴 **由玩家指定** | 玩家在撤退界面选"退到哪座城" —— **不是系统自动选最近的** |

#### 5.2.2 撤退代价怎么算（🔴 按距离分档）

> **用户裁定（2026-10-12）**：「**这两条都会影响到货物的损失**……比如说我可能是 100 格撤退，那我可能手动撤退就是乘以四分之一，然后士气崩溃撤退乘以二分之一。」

🔴 **核心原则：退得越远，损失越大。**

**为什么必须按距离**：如果只按"手动 / 被动"固定比例，那**卡在某个距离反复撤退刷最低损耗**就成了最优解。

| 距离档 | 判定 | 手动撤退 | 士气崩溃撤退 |
|:--|:--|--:|--:|
| 🔴 **近** | ≤ 1/3 全程 | **10%** | **30%** |
| 🔴 **中** | 1/3 ~ 2/3 | **20%** | **45%** |
| 🔴 **远** | > 2/3 | **35%** | **60%** |
| 🔴 **强制**（全队严重重伤 + 零件耗尽） | —— | —— | 🔴 **固定 75%** |

- **为什么按距离**：货在车上**越久越危险**（路上还会遇到别的事）—— 所以**退得远 = 货损更大**，这合理。
- 🔴 **强制撤退固定 75%（2026-10-14 用户定，原 50% 提高）** —— **为什么这么高**：强制撤退的前提是**全队严重重伤 + 零件耗尽** —— 🔴 **车已经没了，人也基本走不动**：能跟出来的人本来就不多，还得一边带人一边带货，**实际能带走的东西极少**。所以 75% 不是"惩罚太重"，而是**贴合实际** —— 玩家的车和货本来就已经留在那儿了。**代价要明确，不该让玩家在"没救"时还去算距离。**

#### 5.2.3 货损怎么扣（🔴 随机抽签，不是精确扣 %）

> **用户裁定**：「**随机选个几个格子抽**……让它凑到多少格……**可能我一次损失少一点，有一次损失多一点**。」

| 步骤 | 规则 |
|:--|:--|
| **① 排除储水格** | 🔴 **水不会被抽走** —— 它有专门的格子（水箱），**不参与货损** |
| **② 保险箱参与抽签** | 🔴 保险箱里的货**参与抽**，但**抽中不丢** |
| **③ 随机抽货凑格数** | 从剩下的货里**随机拿**，一直拿到**达标格数**就停（**不是精确扣 25%**） |
| **④ 每次不一样** | 🔴 **抽到大件就少抽几件，抽到碎的就多抽几件** |

> **为什么随机而不是精确扣**：① 玩家可以**优化**（碎货放外面、贵重放保险箱）；② 有**悬念**；③ **统一按格数算**，不用算货物价值。

#### 🔴 保险箱（新部件 · 2026-10-12 用户裁定）

| 项目 | 规则 |
|:--|:--|
| **作用** | 🔴 **里面的货物在货损中一定不会丢** —— **参与抽签，但抽中不丢** |
| **为什么要有它** | 扩容箱 / 防潮箱 / 药品箱**各有功能，不是保险** —— 需要专门一类**保护贵重物品** |
| **数量** | 🔴 **固定 1~2 个**（占格）—— **不能多**，否则"撤退不掉东西"变成常态 |
| 归属 | `第6A类 §11.4`（货舱模块） |

#### 🔴 撤退路上不再补扣补给（2026-10-12 用户裁定）

**原问题**：如果撤退路上照常按天扣补给，会出现**死档** ——
> 补给已耗尽 → 遇到意外 → 撤退 → **路上还要扣补给** → 全队饿死 → 到城直接死档。

**解决**：🔴 **撤退的代价是货损，不补扣补给。**

**为什么这样自洽**：**货损的钱 ≫ 撤退那几天的补给** → **玩家永远不会选"饿着走回去"** → 所以不需要再叠一层补给惩罚。

> **玩家的账**：撤退 = **一次性货损（重）** + **路上照常消耗**。两条都是真实代价，但**不会出现"饿死"**。

### 5.3 撤退代价（三者不同）

| 代价项| 士气崩溃 / 全队严重重伤+零件耗尽 |         🔴 **手动撤退**（玩家认输）         |
| :---------- | :-----------------------------: | :-------------------------------: |
| **性质**      |               被迫止损              |         **主动认输** —— 损失小一点         |
| 货物          | 🔴 **按距离档随机抽**（§5.2.2 / §5.2.3）     | 🔴 **按距离档随机抽**（玩家指定退去哪，决定档位） |
| 食物 / 水 / 零件 |              损失一部分              |                 少量                |
| 士气          | **不额外扣**（触发时已为 0）· 到达后**恢复到 1** |   🔴 **主动撤退 −2**（§4.3）· 到达后恢复到 1  |
| 商队耐久        |            降到 **30**            |               视损失比例               |
| 所有角色        |               强制休养              |                 无                 |
| 钱           |                不扣               |                 不扣                |
| 位置          |   🔴 **玩家指定的已探明大城/小城**    |              同左             |
| 当前订单        |            大概率失败或严重降级           |        **可当场放弃**（不罚士气之外的东西）       |

> 🔴 **为什么手动撤退的代价更小**：它是**玩家的主动选择** —— 玩家一看"这趟亏了"，**果断掉头止损**，这是**合理的经营决策**，不该跟"被打崩"同等处罚。系统惩罚的是**被动失败**（士气崩 / 全队倒），玩家主动认输只需要付"退掉的货"这份**真实成本**。
>   
> ⚠️ 这也符合铁律 8：**惩罚只能要价，不能剥夺** —— 手动撤退的代价是**货损 + 士气**，不是"你这一趟白干"。

### 5.4 全队严重重伤 + 零件耗尽（**门槛最高的一种**）

「**全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）**」是**三种失败里门槛最高的一种** —— 🔴 **它是"真的没救了"才触发**，不是"打输了"就触发。它意味着**一个能打的人都没有，而且车再也修不好**。它的**专属代价**（在 §5.3 基础上追加）：

| 惩罚项         | 内容                                      |
| :---------- | --------------------------------------- |
| **货物**      | 🔴 **按固定 75% 抽**（不按距离 —— 强制撤退时车和人基本都折在原地了，已没得选，代价要**明确**） |
| 食物 / 水 / 零件 | **全部损失**（零件本来就已经耗尽）                |
| 所有角色        | **强制进入休养状态**（全部严重重伤 → 只能到城市治） |
| 当前订单        | **大概率失败或严重降级**                          |

> 其余项（位置 / 士气 / 耐久 / 钱）同 §5.3：**退回到玩家指定的已探明大城 / 小城（§5.2.1）** · **士气不额外扣、到达后恢复到 1** · **耐久降到 30** · **钱不扣**（避免彻底死档）。
>   
> 这会非常痛，**但还能继续** —— 玩家不会被踢出游戏。
> 🔴 **触发条件见 §5.1 的专门说明** —— 关键是**「玩家还有希望时不触发」这条设计意图**：前三次重伤**都能靠等待恢复**，所以只有**第四次（严重重伤）+ 零件也耗尽**才算真的没救。
