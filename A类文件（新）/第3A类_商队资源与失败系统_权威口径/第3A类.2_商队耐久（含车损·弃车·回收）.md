# 第3A类.2 商队耐久（含车损·弃车·回收）

## 2. 商队耐久

### 2.1 基础数值

| 项目     |                                      数值                                      |
| :----- | :--------------------------------------------------------------------------: |
| 商队耐久上限 | 🔴 **各车的相对耐久上限加在一起 = 车队总上限**（**不是"车数 × 固定值"**）—— 每辆车各有自己的上限，成长时逐车提升，总上限自动跟着涨 |
| 单辆归零状态 | 该辆抛锚，无法继续移动，**必须修到 20 以上才能动** · 🔴 **也可以「弃车」把车留在原地**（见 §2.2A）—— **弃了车队伍就能走** |
| 底层损耗   |                         每车每天 -1.5（地形基础，显示取整，底层按小数累加）                         |

> 🔴 **耐久是「每车独立算」的**（2026-10-14 用户澄清）—— **不要再写"3 车 × 60 = 180"这种算法**：3 辆只是开局车数，换成 5 辆或 2 辆时上限自动跟着变。
> 🔴 **耐久分部位** —— 车有部位，坏哪个决定后果（`§2.2A`）；**具体分哪几个部位、部位占比 ⚠️ 待定**（后续一起定）。
> 商队是商队的命根子。任何一辆中途抛锚都会拖慢整队。  
> 🔴 **但不会把商队卡死**：抛锚可以修，也可以**弃车**（车留在原地，之后能拖回来 —— 见 `§2.2A`）。**只要还有一辆能动，车队就能走。**

### 2.2 耐久状态分级（按单辆百分比）

|   耐久百分比  |  状态  | 说明                       |
| :------: | :--: | ------------------------ |
| 81%-100% |  完好  | 正常                       |
|  61%-80% | 轻度损坏 | 略有影响                     |
|  41%-60% |  损坏  | 效果明显                     |
|  21%-40% | 严重损坏 | 风险较高                     |
|  1%-20%  |  濒毁  | 随时可能抛锚                   |
|    0%    |  抛锚  | 不能继续移动，**必须修到 20 以上才能动** |

> 🔴 **2026-10-06 用户裁定：抛锚修复门槛 10 → 20**（用户原话：「不要必须修到 10 以上才能动，**要修到 20 以上**才能继续行动」）。
>
> **为什么涨到 20**：抛锚的代价必须**真的疼** —— 修 10 点就能走，等于抛锚的代价只有「半天 + 一点零件」；修 20 点才走，**意味着商队得在原地停一整段**（而停着也照按天吃补给和工资）。这跟铁律一致：**让玩家感到"太远修不起"，不是"系统不许"** —— 玩家随时可以修，只是得**多花一天、两天**。

### 2.2A 车损、弃车与回收（🔴 2026-10-10 用户裁定）

> **用户原话**：「你这辆车可能还能捡回来，但是你可能要带着很多零件去给它修到能开……而且你也要在规定时间内去给它修好。不然的话它也会报废。」  
> **决策过程**：先议"弃车"→ 发现**弃车即永久失去太狠** → 加一步「**可回收**」→ 定「**限时内不修 → 报废**」→ **模块化车（部位化）**。

#### 一、车有四个部位，坏哪个决定什么后果

🔴 **2026-10-14 用户重做** —— 原「车轮 / 车轴 / 车架 / 减震 / 牵引 / 制动」**五部位表作废**，改为 **四部位**。理由：**部位要对应一条真实的损耗渠道**，玩家一眼能预判"什么时候会坏"。

🔴 **每辆车标配四个部位**，部位本身是「那条损耗的缓冲垫」—— 坏了不夺走你的车（还在走），只是**那条损耗失去压制**。

| 部位 | 损耗来源 | 主要坏法 | 🔴 掉到「损坏」后的后果 |
| :--- | :--- | :--- | :--- |
| **车轮** | 行驶 | 磨 / 爆 / 陷 | 🔴 **车辆无法继续前进** |
| **车身** | 战斗 | 打架时受冲击 | 🔴 **车辆无法继续前进** |
| **车架** | 地形 | 烂路 / 碎石 / 托底 | ⚠️ **走烂路时，车轮与车身的磨损翻一倍** |
| **车篷** | 天气 | 大风 / 暴雨 / 灰烬风 | ⚠️ **下雨或恶劣天气时，货物受损** |

**四条渠道互不重叠** —— 跑长途磨车轮 · 打架磨车身 · 走烂路磨车架 · 雨天磨车篷。玩家能按这趟的行程，提前决定要养哪个部位。

#### 一之二、部位的四档状态（🔴 前三档纯显示，只有「损坏」有效果）

| 档 | 名称 | 效果 |
| :-: | :--- | :--- |
| 1 | **完好** | — |
| 2 | **磨损** | 🔴 **无任何效果**，只告诉玩家状态 |
| 3 | **破损** | 🔴 **无任何效果**，只告诉玩家状态 |
| 4 | **损坏** | 🔴 **上表的后果生效**，必须修 |

🔴 **「磨损」「破损」不算惩罚** —— 它们只是标签（2026-10-14 用户裁定）。**只有掉到「损坏」才有实际后果**。

#### 一之三、耐久 UI 分三层

平时**只看一个数字**，想看细了再逐层点开：

```
第 1 层   车队总耐久  [ 85% ]
             ↓ 点开
第 2 层   车1 [92%]    车2 [78%]    车3 [85%]
             ↓ 点某辆
第 3 层   车轮 88%  ｜  车身 70%  ｜  车架 95%  ｜  车篷 82%
```

🔴 **一个界面不铺开所有部位** —— 数字太多会控制不住（2026-10-14 用户裁定）。

#### 二、弃车 → 回城修 → 拖回来（玩家视角的完整流程）

```
① 车在乙城附近抛锚
   ↓
② 【弃车】车留在原地，脱离车队（不占编制、不占货舱）
   ↓
③ 你带着车队先撤回甲城（有维修能力的地方）休整
   ↓
④ 修好之后，【回收】—— 再走一趟把弃车拖回来
```

**为什么这条流程是合理的**（三条理由）：

| 理由                    | 说明                                                                                |
| :-------------------- | :-------------------------------------------------------------------------------- |
| **① 弃车不等于失去**         | 车**留在原地**，不是永久报废 —— 玩家有第二次机会                                                      |
| **② "限时" = 你多久没回去**   | 🔴 **不写死天数** —— **你的商路如果反复走同一条，你就能救回来**；越走越远不回头的，自然报废。**这样"路线规划"多了一层意义**          |
| **③ "刚出发就坏"是玩家自己的问题** | 车刚出门就抛锚 = **你零件没带够** → 这一趟本来就走不通 → 最后大概率强制撤退回甲城 → **休整一下照样能把车拖回来**。**不是倒霉，是准备不足** |

#### 三、弃车的代价

| 代价              | 内容                                                               |
| :-------------- | :--------------------------------------------------------------- |
| 🔴 **货舱永久减少**   | 弃一辆 = **货舱 −300 格**（小型）/ **−600**（中型）/ **−900**（大型）—— **永久，不可逆** |
| 🔴 **耐久上限永久减少** | 每辆车 **−60**                                                      |
| 🔴 **车上的货要卸**   | 装到别的车上；**装不下的部分只能处理掉**（= 货损）                                     |
| **车夫**          | 🔴 **不减人** —— 他跟着走，去**载人车**或**当后勤**（车夫是**岗位**，不是人）               |

#### 四、回收的代价

| 代价          | 说明                           |
| :---------- | :--------------------------- |
| 🔴 **零件**   | 回收 = **带零件去修** —— 零件用掉了就真没了  |
| 🔴 **时间**   | 要**专门走一趟**去拖回来 —— 这趟的补给和工资照付 |
| 🔴 **车是空的** | 回收的车**没有货** —— 回来后要重新装       |

> **回收是"一次投资"**：你弃车时零件还在，回来时能救回来。**所以"弃"不是终局，是"先保住这趟"。**

### 2.3 耐久损耗

**地形基础损耗（每车独立）：**

- 每车每天 -1.5 耐久（60 天累计 -90/车，已超单辆 60 上限 → 中途必须维修）

**战斗损耗（每车计 · 三辆货车同时扣）：**

| 战斗类型   |   每车损耗  | 全队合计（3 货车） |
| :----- | :-----: | :--------: |
| 普通战斗   |  **-5** |   **-15**  |
| 精英战斗   | **-10** |   **-30**  |
| Boss 战 |  -50 以上 |   -150 以上  |

> **口径（2026-09-14 定）**：战斗损耗按**每辆车**扣，**不是"全队总共扣"**。三辆货车同时受损——"每车 5" = **全队 15**，"每车 10" = **全队 30**。
>
> ⚠️ **Boss 那条也是每车口径**，即一场 Boss ≈ **全队 150 以上**（占上限 180 的 83%）。Boss 是终局战、打完即通关，影响可控；**但若中途中出现 Boss 级撞击（如修车逃生战 §2.5），此值须另定** → 留待战斗层。

**意外缓冲**：远行额外预留约 **+20 耐久/全队**（天气、山路、事故等）。

**一段路（30 天）的耐久账（2026-09-14 核定）：**

| 项                     | 算式               |      全队耐久 |
| :-------------------- | :--------------- | --------: |
| 地形基础                  | 1.5 × 30 天 × 3 车 |   **135** |
| 战斗（5 场 = 4 普通 + 1 精英） | 4×15 + 1×30      |    **90** |
| **合计**                |                  | **≈ 225** |

> **关键结论**：30 天一段路总损耗 **≈225，已超过总上限 180** → **中途必须修车**（刚需，不是可选）。
>
> **单辆车纯自持力 ≈ 24 天**（完全不修车）：每车每天摊销 = 地形 **1.5** + 战斗 **1.0**（90 ÷ 3 车 ÷ 30 天）= **2.5/天** → 60 ÷ 2.5 = **24 天**。
>
> **但玩家随身带零件、能在路上自助修车**（**1 零件 = 10 耐久**，见 §2.4）→ **24~30 天之间的缺口由随身零件补掉**，所以**据点间距 ≈30 天左右**（20~30 天、不固定），**不是被 24 天锁死**。
>
> 🔴 **真正的硬约束是「恢复」，不是「耐久」**：药包只能应急，**让队伍回满的是中继点**（治伤 / 修车 / 补给）—— 所以每段路必须有中继点。


> **60 天典型远行总损耗 ≈ 435 耐久**：地形 270（3车×1.5×60）+ 战斗 165（10 场 = 9 普通 + 1 精英）+ 意外 20。
>   
> 平均摊到每天 ≈ **7.3 耐久/天**；折合零件 ≈ **0.73 个/天**（1 零件 = 10 耐久，50 金/个 → ≈36 金/天）。

### 2.4 修理规则

| 方式            |   消耗  |               效果               |
| :------------ | :---: | :----------------------------: |
| 城市修理          | 10 金币 |           恢复 20 商队耐久           |
| 驿站修理          | 25 金币 |           恢复 20 商队耐久           |
| 城镇修理          | 30 金币 |           恢复 20 商队耐久           |
| 使用零件·普通       |  1 零件 |           恢复 10 商队耐久           |
| 使用零件·有修补师     |  1 零件 |           恢复 15 商队耐久           |
| 使用零件·**后期升级** |  1 零件 | **恢复 20 商队耐久**（零件效率升级后，见 §3.5） |

> 经济物价口径以第 **2A** 类 §7 为准（原「第 2.1 类」为旧编号归档件，内容已并入第 2A 类）。
>   
> 据点修车比零件更便宜，玩家通常优先靠城镇/驿站修，零件作应急/野外备用。

### 2.5 修车逃生战（简化版）

触发条件：商队耐久过低 / 特殊事件 / Boss 撞击 / 恶劣天气 / 路线事故。

规则：

- 角色可消耗共享体力和零件修车
- 修到指定耐久后可以撤离
- 消耗 **25 点共享体力** + 1 零件，恢复 12 点商队耐久
- 修补师可恢复 18 点
