## 11. 不做内容

| 不做项 | 原因 |
|--------|------|
| 玩家城市建设 / 城市重建 | **不做**（Demo 不测；正式版亦无此系统 —— 城市状态由 `第8A类` 灰兽潮等事件推动，不由玩家建造） |
| 跑商贸易品细表 | 贸易体系复杂，后续单独做 |
| 货物容量/资源容量 | 和商队车辆货舱系统一起做 |
| 订单数量限制 | 先无限接，靠路线和时间自然限制 |
| 具体特殊事件价格 | 每个事件写入事件系统时再定 |
| 库存刷新规则 | 当前只定库存范围 |
| 技能升级表 | 接 `第6A类 §6`（记忆成长：广度 / 深度 / 推演） |
| 招募传闻/固定招募事件 | 后续角色招募系统 |
