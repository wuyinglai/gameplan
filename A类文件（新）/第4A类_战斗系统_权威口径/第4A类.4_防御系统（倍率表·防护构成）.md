## 4. 防御系统

三层防御结构，均只对外伤生效：

| 类型     | 特性             |         持续        | 来源           | 说明                                        |
| :----- | :------------- | :---------------: | :----------- | ----------------------------------------- |
| **护盾** | 临时防御           |     **回合结束清空**    | **盾牌卡**      | 挡外伤。若完全挡住攻击，可阻止流血施加。🔴 **可给任意队友叠**（不限于自己） |
| **护甲** | **本场战斗内的持久防御** | 直到被打掉（**战毕自动复位**） | **防具**（5 部位） | 只挡普通攻击。不挡穿甲攻击、流血、灼烧                       |
| **屏障** | 高级防御           |       直到被打掉       | 旧文明手段 / 特殊物品 | 挡外伤、大多数负面施加。不挡已有流血伤害                      |

> **护盾与护甲两条渠道互不混淆**：**护盾只由盾牌提供**（举盾挡住的那一下），**护甲只由防具提供**（穿在身上扛的）。

### 4.1 防护构成（敌我通用 · 🔴 2026-10-28 装备讨论重做：加权构成制，旧「防护档」废止）

> 🔴 **护盾和护甲都吃倍率**：打它的盾、打它的甲、还是打进它的血，**都按整体防护倍率算**（用户 2026-09-18 原话："无论是护甲还是护盾，都造成这个倍率的伤害"——口径不变）。

**三种防护类型**（定义不变）：**无甲**（没穿防具）· **软甲**（布 / 皮 / 薄壳）· **硬甲**（铁 / 钢 / 灰烬甲壳）。

| # | 规则 |
|:-:|:--|
| 1 | 🔴 **五部位独立穿戴、各自归入一种防护类型**；每部位带**预设防护权重**（五部位合计 **100%**；🔴 **权重 ≠ 甲值** —— 甲值决定防护池**有多少**（§4.5），权重决定构成**是什么**，两者独立计算不得混同） |
| 2 | 🔴 **整体防护构成 = 各部位类型按权重加权汇总**（例：硬甲 60% / 软甲 30% / 无甲 10% —— 🔴 示例非正式权重，部位权重待裁定㉛） |
| 3 | 🔴 **整体防护倍率 = 硬甲占比 × 攻击对硬甲倍率 + 软甲占比 × 对软甲倍率 + 无甲占比 × 对无甲倍率**（§4.2 表的值即各类型的基础倍率）——三种攻击类型**分别计算**，角色同时持有三个整体倍率 |
| 4 | 🔴 **旧「混穿按最高件」废止** —— 一件硬甲不再把全身判成硬甲；🔴 **不做部位命中**：不随机选部位、不分部位判定 / 结算、五部位无独立战斗耐久 —— 部位只参与构成计算（保持简单，不做身体部位伤害模拟） |
| 5 | **无甲 ≠ 打不动**：无甲单位照样能叠护盾 / 靠构成提供软甲占比（原「自己叠不出多少」的表述随构成制移敌人数值表） |
| 6 | ⚠️ **甲值池归零后的构成处理待定**（旧「甲碎→转无甲档」是否保留 / 如何表达）→ 待裁定㉛ |
| 7 | 🔴 **装备带来的体力修正（负重倍率 / 行动阻碍倍率）→ `第6A类 §14.3`** —— 只作用于受影响的具体动作，不在本表 |

### 4.2 攻击类型与倍率表（**核心机制 · 2026-09-20 定 · 倍率 2026-10-10 修订**）

> 你手里拿什么武器，决定你**打什么甲划算**。这是"武器除了数字之外的第二重身份"。

**攻击类型三型（敌我通用）**：

| 类型     | 武器例                         |
| :----- | :-------------------------- |
| **打击** | 锤 / 棍 / 钝斧 / **弩** / **火枪** |
| **斩击** | 剑 / 刀 / 斧                   |
| **刺击** | 长矛 / 匕首 / **弓**             |

**倍率表**：

| 类型     |   对无甲 |      对软甲 |      对硬甲 |
| :----- | ----: | -------: | -------: |
| **打击** | ×0.9 |     ×1.0 | **×1.3** |
| **斩击** |  ×1.1 | **×1.2** |     ×0.9 |
| **刺击** |  ×1.1 |     ×0.9 |     ×0.9 |

**三型的性格**：

| 类型     | 性格                    | 什么时候带        |
| :----- | :-------------------- | :----------- |
| **打击** | 克硬甲，但破甲后垫底（**前半场武器**） | 明知前面是硬壳（灰烬兽） |
| **斩击** | 偏科 —— 克软甲最强，也最怕硬甲     | 打人形敌人（强盗）    |
| **刺击** | **两头都不吃**（对软甲 / 硬甲都 ×0.9） | 情报不足时选它 = **赌博**，不是安全选择 |

**判定规则**：

- 倍率作用于**整次伤害**（不做溢出分段）—— 🔴 **必须一直算到生命**，不能只打在甲上。否则"甲厚的人总撑得久"，**相性会被厚度吃掉**。⚠️ 讨论稿提出「仅作用于护甲层」的改法 —— 🔴 现行保持整次攻击，改动须单独确认（待裁定㉛③）。
- 🔴 **对目标当前的整体防护构成生效**（2026-10-28 改；旧「有档/甲碎转无甲档」随构成制废止）—— 构成怎么算见 §4.1；甲值池归零后的构成处理待裁定㉛⑧。
- **统一作用于 护盾 / 护甲 / 屏障 三层**。
- **穿甲攻击不吃这张表**（它本来就无视护甲）。
- **内伤不吃**（直接进生命）。

> 🔴 **2026-10-28 装备讨论衔接**：本表数值 = 对**单一纯构成**目标的基础倍率；混合防护构成按 **§4.1 加权公式**使用这些值。⚠️ 两项待裁定㉛：① 表值是否随构成制调整 ② 🔴 **倍率作用层** —— **现行为「作用于整次攻击」**（上方判定规则第 1 条），讨论稿明确要求：改成「仅护甲层」会改变伤害结算方式，**必须项目主单独确认后才能动**。

**设计约束（防失衡，必须守）**：

|  #  | 约束                     | 理由                                     |
| :-: | :--------------------- | :------------------------------------- |
|  1  | 倍率区间 **×0.9 ~ ×1.3**   | 幅度再大就变成"带错武器打不动" = 事实上的硬限制             |
|  2  | 🔴 **打击对无甲必须 < 1.0**   | **保险丝** —— 让打击只是"前半场武器"，防止"无脑选打击"变成唯一解 |
|  3  | 三型**整场加权总量齐平**（差 4% 内）· ⚠️ **2026-10-10 改值后此条待复核**（简单均值：打击 **1.067** / 斩击 **1.067** / 刺击 **0.967**，相差约 10%）—— 若"刺击 = 两头都不吃的赌博"是**有意的代价**，本条应改成"加权齐平"或明确允许刺击总量偏低；**归数值调平期定** | 差异体现在**节奏**（回合数 → 药包消耗），**不在总量**       |
|  4  | 敌人的武器类型**必须混着来**       | 全是一种，玩家的选择就死了                          |

> 🔴 **2026-10-10 用户裁定**：**打击对无甲 ×0.95 → ×0.9**（"前半场武器"手感更明显）；**刺击 ×1.0 / ×1.0 → ×0.9 / ×0.9**（削弱成"两头都不吃" —— 情报不足时选它是**赌博**而非安全选择）。权威同步见 `第6A类 §14.2`。
>
> 🔴 **取消"通用减伤率"**（2026-09-20）：曾经设想过防具给一条无相性的"减伤率"（皮 5% / 铁 10% / 钢 15%）—— **该条作废**。因为它是**纯优乘数**（谁高谁永远更抗打），会把软硬甲的相性差异直接抹平，等于把上面这张表废掉。**防具的差异全部由本节这张倍率表承担。**
>
> （`第6A类 §11.3` 车辆配件「**装甲板：提升减伤率**」**是车的**，不受本条影响。）

### 4.3 伤害结算顺序（仅外伤）

```
面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率 → 护盾 → 屏障 → 护甲 → 生命
```

> **攻击类型倍率与角色加成都在"整次伤害"这一层**，**扣血之前全部算完**。
> 🔴 **「角色加成」的构成（2026-10-28 新增）**：= **力量 × 武器技巧按武器类别比例加权**（各类别倾向表 🟡 待裁定㉝ → `第6A类 §14.1.1`）—— 🔴 不做全武器统一公式；🔴 力量来自装具模块、武器技巧来自学习（不可装具增加）。
>
> 护盾优先结算，因为护盾过一回合就消失。屏障在护盾之后。

**穿甲攻击**的结算顺序：护盾 → 屏障 → 生命（**无视护甲**）

> 内伤不经过上述结算，直接作用于生命。

### 4.4 护盾（只由盾牌提供）

| 盾      | 占手    | 消耗体力       | 护盾值               |
| :----- | :---- | :--------- | :---------------- |
| **小盾** | 1     | **0 ~ 25** | 5~6 / 12          |
| **中盾** | 1     | **50**     | 26                |
| **重盾** | 1     | **100**    | 55 / 全队 20 × 出战人数 |
| **塔盾** | **2** | **150**    | 100               |

- 🔴 **护盾可以给任意队友叠**（不限于自己）—— 这直接决定了"远程必须有人护"：**远程是双手武器，拿不了盾，连自救能力都没有**。
- ⚠️ **0 体力消耗的盾卡仍然占 1 个动作位**（每人每回合只有 2 动作 + 1 记忆）→ 否则 0 耗 + 不占位 = **无限叠盾 = 无敌**。

### 4.5 护甲（只由防具提供）

|  #  | 条目               | 定法                                                                                                 |
| :-: | :--------------- | :------------------------------------------------------------------------------------------------- |
|  1  | **甲值**           | **开战赋值**（头 / 躯干 / 手 / 腿 / 足 **5 部位相加**，躯干权重最大）· **战内只减不增** · 🔴 **甲值归零 = 本场防护耗尽（2026-10-28 改）—— 🔴 甲值是角色整体的战斗防护资源，不是装备耐久度：归零不代表装备损坏报废（旧「防具报废 + 转无甲档」废止），装备本身完好；归零后的构成处理 → 待裁定㉛** |
|  2  | **战毕复位**         | **战斗结束自动回满**，不花钱、不占天数、不用修（与"不做装备耐久"一致）                                                             |
|  3  | **可补充**          | 🔴 **甲在战内并非绝对不可恢复** —— **修补师可用「紧急加固」补甲**（1 点体力 + 1 零件 → 队友 +12 甲）                                  |
|  4  | **完全吸挡**         | 本次伤害**被甲完全吸收（无溢出到生命）** → **不施加流血 / 迟滞**                                                            |
|  5  | **厚度目标**         | **总甲 ≈ 血池 ÷ 3**（≈ 总耐久的 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具数值必须跟着血池一起升级**，否则后期被甩开 |
|  6  | **软硬甲值差 ≤ ~20%** | 例：软 36 ∶ 硬 45（≈80%）—— **别让厚度把相性吃掉**                                                                |


> **甲 vs 护盾**：**甲**开战满 / 回合末不清空 / 只给自己 / 战毕复位；**护盾**开战 0 / 回合末清空 / **可给队友** / 每回合能重叠。
> 🔴 **甲 vs 承伤能力（2026-10-28 新增）**：**护甲负责直接防护**（吸收 / 阻挡单次攻击）；**承伤能力**（旧称生命 / 血量，`第6A类 §15.2`）是角色能承受的**累计伤害上限** —— 🔴 提高承伤**不代表**每次受伤自动减伤；两者是不同属性，不得混为一谈。结算链末端的「生命」即承伤能力（术语清扫 → 待裁定㉜⑧）。
