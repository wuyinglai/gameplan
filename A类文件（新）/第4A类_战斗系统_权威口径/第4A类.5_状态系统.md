## 5. 状态系统

### 5.0 对等原则（**2026-09-29 定 · 本节总纲**）

> 🔴 **状态按「机制」定义，不按「阵营」分家。**

- **敌我共用同一套状态、同一套数值、同一个结算函数。** 玩家能上的负面，敌人也能上；玩家能有的增益，敌人也有其对应物。**不为敌人另写一套战斗** —— `04 §9.6 ④` 原话：「敌人动作表**与玩家的"手牌"对称，走同一个结算函数**。**不是写两套战斗，是一套。**」
- **为什么要这条原则**（三条，缺一不可）：
  1. **读得懂才谈得上应对** —— 玩家能反推"它也会流血、它也会被迟滞"，规则才**可被利用**；
  2. **一套代码** —— `core.js` 只写一遍，加新敌人 = 加一行数据（`04 §9.6 ⑤`）；
  3. **后期敌人"会打配合"不是新规则** —— 只是**同一套规则用得更熟**（AI 档 C · 协同，`04 §9.6 ③`）。
- **对等的是「规则」，不对等的是「内容」**：同一个状态打在玩家身上与打在敌人身上，走**同一个函数、同一套数值**；差异只来自**双方各自手里有什么牌**：

| 一方     | 牌从哪来                                            |
| :----- | :---------------------------------------------- |
| **玩家** | 老本行 · 武器 · 记忆 · 商队牌（`04 §9.1.1`）+ 装备 / 装具 / 消耗品 |
| **敌人** | **物种动作表**（每只 2~4 个动作）+ 物种属性                     |

- **唯一例外 = 物种属性**（且它**不是"阵营专属"**）：物种自带的生态行为，如"灰烬兽不逃跑 / 野兽天生易逃 / 强盗抢到货就撤"。→ **归敌人表（`17 §6`），不进本节状态表。**
- ⚠️ **"近乎"对等的边界**：**规则对等，处境不对等** —— 敌人不心疼药包、不养车、不记每日消耗；玩家受持久与补给约束。**这是两条不同的轴，不冲突。**

**状态双向性一览**（§5.1~§5.5 各表亦逐行标注 · 增益对照见 §5.7）：

| 状态                |    敌我    | 备注                                              |
| :---------------- | :------: | :---------------------------------------------- |
| 标记 · 流血 · 灼烧 · 迟滞 | ✅ **双向** | 玩家可上给敌人，敌人同样可上给玩家                               |
| 反击                | ✅ **双向** | 我方侧 = 盾反；敌方侧 = 反打类动作                            |
| 蓄力                | ✅ **双向** | 原文已写"敌我双方都可拥有"                                  |
| 狂化                | ✅ **双向** | 🔴 原写"**敌人**强化状态" → **已去阵营标签**（改为通用的**伤害递增**状态） |
| 灰蚀                | ✅ **双向** | 绑定**灰烬生态**（谁都会染），**不是敌人专属**                     |
| 护盾 · 护甲 · 屏障      | ✅ **双向** | §4 三层防御，敌我走同一套规则                                |

> ⚠️ **本节只写规则，不写数值 / 不写具体动作名** —— 敌人侧的具体动作与数值归 `17 §6` 敌人表。

### 5.1 攻击类型状态

> **攻击类型有两个层次**：① **常规三型 —— 打击 / 斩击 / 刺击**（决定"打什么甲划算"，完整倍率表与控制规则见 **§4.2**）；② **特殊攻击类型 —— 穿甲**（无视护甲，见下表）。🔴 **三型的归属由具体执行的招式决定**（2026-10-28 改，原「由武器决定」废止）—— 同一把剑：剑柄砸击 = 打击 · 剑尖刺击 = 刺击 · 剑刃挥砍 = 斩击。

| 状态     | 类型    |  敌我  | 说明                                                       |   上限   |
| :----- | :---- | :--: | -------------------------------------------------------- | :----: |
| **穿甲** | 攻击类型  | ✅ 双向 | 无视护甲的伤害类型（不是状态），**且不吃 §4.2 的倍率表**                        |    —   |
| **标记** | 增益/铺垫 | ✅ 双向 | 攻击命中后消耗 1 层，本次伤害 +25%。每击最多消耗 1 层，可连续触发                   | **不限** |
| **反击** | 反打    | ✅ 双向 | 受到攻击后对攻击者造成该次伤害 50% 的反击伤害。每触发一次消耗 1 层。层数只叠加持续回合数，不叠加反伤比例 |  不限层数  |

> **"敌我"列 = §5.0 对等原则的逐行落实**：**✅ 双向** = 该状态**不区分为谁所有**，同一套数值与触发条件；敌人获得它时不再另算。

### 5.5 特殊威胁

| 威胁     |  敌我  | 说明                             | 处理方式       |
| :----- | :--: | ------------------------------ | ---------- |
| **灰蚀** | ✅ 双向 | 最多 3 层。每层每回合 4 灰烬伤害，满 3 层爆发后清零 | 只能通过灰烬治疗处理 |

### 5.7 增益对照（**我方 ↔ 敌方** · 设计约束）

> 🔴 **约束**：**我方有哪一种增益，敌方就应当有对应的那一种** —— 只改"叫什么、由哪个动作给"，**不改机制**。
>
> 这是"敌人是**对手**"而不是"数值更高的靶子"的来源；也是"后期对方能打出配合"的地基（`§5.0`）。
>
> ⚠️ **本表只列机制名**，**具体动作名与数值归 `17 §6` 敌人表** —— 别在这里编动作。

| 机制             | 我方载体           | 敌方载体                       |  已就位？  |
| :------------- | :------------- | :------------------------- | :----: |
| **临时防御（可给队友）** | 护盾（盾牌卡 · §4.4） | ⏳ 防御类动作（`17 §6`）           | **待补** |
| **反打**         | 反击（盾反 · §7.1）  | ⏳ 反打类动作                    | **待补** |
| **强招预警**       | 蓄力             | 蓄力（§5.3 原文已有）              |    ✅   |
| **伤害递增**       | 过载 · 标记爆发      | 狂化（§5.3 已去阵营标签）            |    ✅   |
| **持续伤害**       | 流血 · 灼烧        | 同两个状态（反向施加）                |    ✅   |
| **行动干扰**       | 迟滞             | 迟滞                         |    ✅   |
| **全队集火**       | 玩家手动指定目标       | AI 档 C · 协同（`04 §9.6 ③`）   |    ✅   |
| **救队友**        | 护盾可给任意队友       | 保护残血同伴（AI 档 C）             |    ✅   |
| **改战场规则**      | 旧文明战场物品        | **同一个物品 · 敌我双方都吃**（`§6.5`） |    ✅   |

> **两处"待补"= `17 §6` 敌人表的硬性待办** —— 敌人表里若找不到"给队友上护盾 / 反打"的动作，就是**漏了**。
>
> ⚠️ **不必强行凑对称**：表中的机制是**维度**，不是**数量** —— 一个敌人会 2~4 个动作（`04 §9.6 ④`），**不需要把 9 种机制全带齐**；约束是"**凡我方有、敌方也要有路可走**"，不是"每只怪都得有"。
