### 一、一场战斗的全流程（14 步）

```
① 遭遇：踩到触发格（触发规则归事件系统 A10）→ 进入战斗
② 先手判定：机动高者先手；伏击=最高初始优先级（不改数值）   [4A §2.6]
③ 开战初始化：
   体力池 = Σ各人体力 → 回复=该和 · 上限=2×回复 · 起手=上限（满）  [4A §2.2]
   护甲=开战赋值（五部位相加）· 护盾=0 · 手牌=空                  [4A §4.5/§4.4]
④ 我方回合：每人抽 3 张（2 动作 + 1 记忆，从自己牌池自由选）    [4A §2.3]
⑤ 出牌：无上限，体力当闸门（体力尽则停）；每张按档收费           [4A §2.1/§2.3]
⑥ （第 3 回合起每回合可尝试撤退，50% 基础成功率）               [4A §9.1]
⑦ 敌方回合：敌方按物种动作表行动；敌方第 3 回合起判定逃跑        [4A §9.2]
⑧ 回合末：灼烧/灰蚀结算 → 双方护盾清空 → 手牌清空 →
   体力池回复（封顶上限）→ 回合 +1                              [4A §2.3/§4.4/进入下一回合]
⑨ 循环 ④~⑧，直到：敌方全部退出（胜）/ 我方全部退出（败）/ 撤退成功
⑩ 战后结算：重伤四级定级 · 商队耐久损耗（普通−5/车）· 士气变化 ⚠️㉕ · 拾取 ⚠️   [4A §8/§10]
```

### 二、体力条怎么算（战斗体力池 · 全队共享）

| 项 | 规则 | 出处 |
|:--|:--|:--|
| 池的归属 | 🔴 **全队共享一个池**（谁花都行） | 4A §2.1 |
| 每回合回复 | **Σ 各人体力**（每人基准 50，有个体差异照加）——3 人 = 150 | 4A §2.2 |
| 池上限 | **2 × 回复**（3 人 = 300）—— 最多攒一回合的量 | 4A §2.2 |
| 起手 | = 上限（满进入战斗） | 4A §2.2 |
| 回复时机 | 每次回合切换时 +回复，**封顶上限**（攒的价值=集火，不是变多） | 4A §2.2 |
| 牌的消耗五档 | 微 **0** / 轻 **25** / 标准 **50** / 重 **100** / 极限 **150** | 4A §2.1 |
| 消耗品 | 药包 25 点 · 零件修车/补甲 25 点（与出牌共用同一池） | 4A §2.4 |
| 🔴 与野外体力池的区分 | 战斗池独立结算；野外旅行消耗走 `第1A类 §2.1` 的野外体力池（15 点/格），两池互不相通 | 1A §2.1 |
| 装具属性钩子 | 体力储备→个人对容量的贡献 · 体力恢复→对每回合回复的贡献（多人汇总规则 ⚠️ 待裁定㉜①） | 6A §15.2 |

### 三、选卡具体怎么选（每回合的选牌流程）

1. **每人每回合起手抽 3 张 = 2 张动作牌 + 1 张记忆牌**，从**自己的牌池**里自由选，选完即定。
2. **出牌无上限**：抽出来的牌全部可打（顺序玩家定）；打完可再抽再打，重复多少遍都合法。
3. **唯一闸门 = 体力池**：体力不够则本回合不能再出牌。
4. **手牌回合末清空**，下回合重新抽（防囤牌引擎）。
5. **记忆卡不限次**：只按体力收费，无冷却。
6. **零体力卡硬约束**：只能铺垫/辅助（挂标记、小护盾）；❌ 禁伤害 ❌ 禁抽牌 ❌ 禁强负面；且占 1 个起手名额。
7. **组合示例**：射手标记(0) → 修补师防护加固(50) → 护路人重击(100 穿甲) —— 跨角色按任意顺序串。

出处：4A §2.3 全节（含 §2.3.3 零耗硬约束）。

### 五、伤害怎么算（完整算式）

```
外伤：面板 × 招式倍数 ×（1 + 力量技巧加权%）× 攻击类型倍率（按防护构成加权）
        → 护盾 → 屏障 → 护甲 → 承伤
穿甲：跳过护甲（护盾 → 屏障 → 承伤）
内伤：无视一切防御，直接扣承伤
```

| 步 | 规则 | 出处 |
|:-:|:--|:--|
| 1 | **面板**：武器提供（⚠️ 数值待裁定㉖）· 招式只写倍数（挥砍×1.0 / 重击×1.5） | 6A §14.2 |
| 2 | **力量/技巧加权**：按武器类别比例（🟡 初步：剑70/30 · 弩10/90 · 枪0/100 ⚠️ 未定稿㉝）；技巧**不可装具增加** | 6A §14.1.1 |
| 3 | **攻击类型由招式决定**：同一把剑，柄砸=打击 / 剑尖=刺击 / 剑刃=斩击 | 4A §3.2 |
| 4 | **防护构成加权**：五部位类型×权重 → 整体构成 → 整体倍率 = Σ(占比×类型倍率)；基础表：打击 ×0.9/1.0/**1.3** · 斩击 ×1.1/**1.2**/0.9 · 刺击 ×1.1/0.9/0.9 | 4A §3.2/§3.3 |
| 5 | **结算顺序**：护盾 → 屏障 → 护甲 → 承伤；完全吸挡（无溢出）不施加流血/迟滞；**倍率作用于整次伤害**（算到承伤，不分段） | 4A §3.4/§3.2 |
| 6 | **内伤不吃任何防御与倍率**；穿甲不吃倍率表 | 4A §3.1/§3.2 |
| 7 | 🔴 **承伤 ≠ 护甲**：护甲吸收单次；承伤能力 = 累计上限（装具提高承伤≠自动减伤） | 4A §4.5 注 |

| 参与者 | 提供什么 | 战斗入口 | 出处 |

| **知识** | 针对性强化（数值/条件/机制三形式；通用技巧照常可用） | 伤害算式前后 hook | 4A §2.5 |

### 九、逐步数值示例（一场演示战斗 · 全部用已定数值 ⚠️ 假设项单独标注）

**阵容**：护路人（承伤120·体力50）+ 荒野射手（70·50）+ 修补师（85·50）→ 池 = 回复 150 / 上限 300 / 起手 300。
**敌人**：灰狼 ×1（承伤 60 · **无甲构成 100%**）· 难度普通。
**假设项**（⚠️ 示例用，非定稿）：双方机动 15 vs 10 → 我方先手；迎击/精确射击的攻击类型未标注（㉖）→ 示例按无甲 ×1.1（斩击）计；敌不逃跑。

| 时点 | 动作 | 算式 | 结果 |
|:--|:--|:--|:--|
| 开战 | 初始化 | 池 300/300 · 护盾 0 · 护甲 0（无人穿甲示例） | 先手=我方 |
| R1 我方 | 护路人出**迎击**（50） | 12 × 1.1（斩击对无甲）= 13.2 → 取整 13 → 直进承伤 | 灰狼 60→**47** · 池 300→250 · 护路人 +5 盾 |
| R1 我方 | 射手出**精确射击**（50） | 12 × 1.1 = 13.2 → 13 | 灰狼 47→**34** · 池 250→200 |
| R1 敌方 | 灰狼咬护路人（示例 10 伤） | 打击对无甲 ×0.9 → 9 → 护盾 0 → 直进承伤 | 护路人 120→**111** |
| R1 回合末 | 结算 | 池 200+150=**300**（封顶）· 护盾清空（护路人5盾没了）· 手牌清空 | 回合 → 2 |
| R2 我方 | 护路人出**重击**（100·穿甲） | 28 穿甲（无视倍率与甲） | 灰狼 34→**6** · 池 300→200 |
| R2 我方 | 射手出**精确射击**（50） | 13 | 灰狼 6→**0 → 退出本场** | 
| 结算 | 敌全灭 → **胜利** | 回合数 2 · 我方无退出 · 耐久 −15（−5/车×3）· 士气变化 ⚠️㉕ · 拾取 ⚠️ | 战斗结束 |

> 🔴 本示例演示**算法**，不代表平衡数值；武器动作卡（㉖）、属性数值（㉜⑥）、加成比例（㉝①）定稿后示例随之更新。
