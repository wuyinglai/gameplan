## 7. 角色技能概览

以下为三名初始角色的技能概览，详细数值以第 6A 类（第 6.1 类）为准。

### 7.1 护路人（承伤 120 / 主承伤 / 护车）

| 技能   |  体力 | 类型    | 简述                                    |
| :--- | :-: | :---- | ------------------------------------- |
| 迎击   |  50 | 攻击+防御 | 造成伤害，获得护盾                             |
| 掩护   |  50 | 防御    | 获得护盾；本回合队友第一次受直接伤害时承担 50%             |
| 稳住阵线 |  50 | 团队防御  | 全队每人获得护盾，货车获得护盾                       |
| 盾反   |  50 | 反打    | 获得护盾 + **反击状态**（受到攻击后反打 50% 伤害，可叠加层数） |
| 重击   | 100 | 穿甲爆发  | 穿甲伤害；目标有护甲时额外伤害                       |
| 车队防护 |  50 | 护车    | 货车获得护盾；本回合货车下次直接伤害额外降低                |

### 7.2 荒野射手（承伤 70 / 脆皮高输出 / 标记 / 流血）

| 技能   |   体力  | 类型    | 简述                           |
| :--- | :---: | :---- | ---------------------------- |
| 标记   | **0** | 铺垫    | 给一个敌人添加 1 层标记                |
| 精确射击 |   50  | 稳定输出  | 造成伤害（消耗标记触发增伤）               |
| 放血箭  |   50  | 流血    | 造成伤害，施加流血（**内伤**）            |
| 断筋箭  |   50  | 迟滞    | 8 点伤害，施加 1 层迟滞               |
| 补射   |   50  | 补刀返体力 | 10 点伤害，可消耗标记增伤 + 额外消耗标记每层 +6 |
| 猎灰重箭 |  100  | 标记爆发  | 高伤害，可消耗多层标记每层额外增伤            |

### 7.3 修补师（承伤 85 / 修车 · 辅助（非全能）/ 治疗）

| 技能       |   体力   | 类型    | 简述                                                                          |
| :------- | :----: | :---- | --------------------------------------------------------------------------- |
| 简易治疗     | **25** | 治疗+止血 | **用药包**（见 §2.4 / §4.5）：恢复生命 ×1.5；有流血时移除流血层数。⚠️ **与"直接用药包"同价（25 点）**，换取 ×1.5 |
| 防护加固     |   50   | 团队护盾  | 全队获得护盾，货车获得护盾                                                               |
| 车体修理     | **25** | 修车    | 消耗 1 零件，恢复商队耐久                                                              |
| **紧急加固** | **25** | 补甲    | 🔴 消耗 1 零件，恢复一名队友 **12 点护甲**（不可超过其甲值上限）                                     |
| 拆解穿甲     |   50   | 穿甲    | 移除目标护甲，造成穿甲伤害                                                               |
| 灰烬治疗     |   50   | 净化    | 清除一名角色身上的灰蚀；成功清除后抽 1 张牌                                                     |
| 过载       |   100  | 强化    | 使场上任意一张牌的效果**翻倍（+100%）**。不限于攻击牌，防御牌、治疗牌均可。使用后该角色受到 **5 点内伤**                |
