## 4. 地图节点（格子）类型

🔴 **2026-10-05 重构**：原表把**格子**和**事件**混在一起（导致"补给点"这种**事件内容**被当成格子类型）。现拆成两层：

**第一层：格子本身 = 地形 / 据点**

|  序号 | 格子类型                       | 定位与功能                                                       |  安全点  | 接收撤退 |   节点反应炉   |
| :-: | -------------------------- | ----------------------------------------------------------- | :---: | :--: | :-------: |
|  1  | **空地 / 野外**                | 🔴 **踩上去照样可能触发事件**（玩家能到达的地块都能触发；例外 = 城市 / 据点格，见本节末「触发规则」）   |   —   |   —  |     —     |
|  2  | **地形**（山 / 水 / 桥 / 林 / 废墟） | 多数不可通行；可通行的（桥 / 林）影响每格消耗（见 §5）                              |   —   |   —  |     —     |
|  3  | 🔴 **大城**                  | 九城 —— 功能最完整、物价最低；可处理重伤 / 严重重伤（`第7A类`）                       | ★★★★★ |   ✅  |   **有**   |
|  4  | 🔴 **小城**                  | 自发聚集定居点；设施除旧文明特殊设施外齐全；物价比大城稍贵、比城镇低；治安更危险                    |  ★★★★ |   ✅  |   **无**   |
|  5  | **城镇**                     | 路上的补给容错点；补给 / 生活物资 / 普通治疗                                   |  ★★★  |   ❌  |     无     |
|  6  | **驿站**                     | 商队专门休息点；零件 / 修车 / 路线服务（**中继点之一**）                           |  ★★★  |   ❌  | 无（只有中继节点） |
|  7  | **村庄**                     | 最小聚落；功能最少、少量交易 / 情报、物价最高                                    |   ★★  |   ❌  |     无     |
|  8  | **营地**                     | 临时落脚点 —— 🔴 **只能休息**（**不能修车**；要修车得**自己耗零件修**，见 `第3A类 §2.4`） |   —   |   —  |     —     |

> 🔴 **本表就是「地图格子总表」** —— 安全等级、能否撤退、有没有节点反应炉，**一律在这里查，不再另设一张重复的表**（原 §6 的「安全点表」已并入本表，2026-10-13）。  
> 🔴 **大城 / 小城必须分开看（2026-10-13 用户定 · 对齐 `第7A类 §二`）**：**只有大城有节点反应炉**（九城各 1 座，靠烬油运转）；**小城没有节点** —— 它是自发聚集起来的定居点，**不是"缩水版大城"**，只是缺旧文明的特殊设施。  
> 🔴 **安全等级 ★ 与"接收撤退"是两件事**：★ 说的是"能休整到什么程度"，**撤退只有大城 / 小城收**（规则见 §6）。

> 各类据点的功能差异、物价、能否招募 / 治疗 / 修车，详见 `0A 第2A类 地点系统`。  
> 🔴 **「营地能修车 / 鼓舞士气」已作废** —— **修车是消耗零件的动作，不依赖格子类型**。

**第二层：踩上去可能触发的「事件」（不是格子类型）**

| 事件       | 说明                                       |
| -------- | ---------------------------------------- |
| **战斗**   | 进入普通战斗（敌种 + 档位：普通 / 精英 / Boss）           |
| **随机事件** | 正面 / 负面 / 选择分支 —— **补给、资源、情报、采集…全都属于此类** |
| **危险区**  | 高风险高回报：可能战斗，也可能获得奖励                      |
| **Boss** | 区域最终战                                    |

> 🔴 **原独立的「补给点」格已取消** —— **补给是事件内容，不是格子类型**（原表把两者混排，容易让人以为地图上专门摆着"补给点格"）。

> 🔴 **触发规则（2026-10-13 用户定）**：**所有玩家能到达的地块，踩上去都可以触发事件**（第二层那张表就是为此服务的）—— **没有"踩上去什么都不发生"的空白格**。  
> 例外只有**特殊地块**：**城市格踩上去就是城市**（直接进城市界面，不掷事件）、**据点格**（城镇 / 驿站 / 村庄 = 直接进据点界面）—— 用户原话只点了城市格，据点格按同一性质处理（都是"踩上去 = 进界面"）。
