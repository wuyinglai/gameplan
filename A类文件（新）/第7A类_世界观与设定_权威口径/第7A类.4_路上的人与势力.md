# 第7A类.4 路上的人与势力

> **来源**：`A类文件\正文\第7A类_世界观与设定_权威口径.md` 第 296–405 行 · 复制迁移 2026-10-28（🔴 迁移只搬不修，原文一字未动）
> **系统**：第7A类 · **迁移期权威源仍为旧 A 类**

## 一、余烬商会（可加入）

余烬商会是九城中唯一一个曾在各城设有分部的商业组织。🔴 **灰潮之后不是"失去联系"，是"联系越来越少"**（2026-10-15 用户裁定）：**商路一条条变少 · 愿意走这条路的人越来越少 · 路也越来越危险** —— 三件事叠在一起，分会之间的往来就断了。🔴 **但每个分会都没有解散**，仍在各自城市周边继续运转，只是各自为政。

玩家不需要"加入"商会——商队本身就是余烬商会的一部分，是流动的分会。玩家在某城分会的声望高了，该城分会才会提供更好的价格和订单。

**分会分布：** 灰原城（活跃）、枯林城（活跃）、鱼水城（活跃）、粮野城（活跃）、海盐城（活跃）、火油城（小型）、药泽城（小型）、黑石城（活跃、规模最大）、灰烬城（无）。

## 二、强盗（敌对·常见）

各路强盗、流寇、劫匪的统称，不是统一的组织。分为路匪（三五成群）、匪帮（有组织有据点、多达数十人）、流寇（无固定据点）三种。

**强盗的动机：** 他们不是生性凶恶。灰潮之后土地不适宜耕种，动物狂暴，没有粮食，快要饿死了，才被迫出来打劫过路的商队来勉强糊口。没有真正的反派，只是立场不同。一些小型匪帮会选择避让强大的商队，少数匪帮可以谈判交"过路费"换平安通过。

> 🔴 **强盗为什么存在（2026-09-24 补 · 因果链）：商路还在，才养得起强盗。**（用户原话："为什么会有强盗？就是因为商路还在，所以才会有强盗。"）
> - **强盗是"寄生者"，不是"定居者"** —— 他要靠**过路的商队**吃饭。**路彻底断了 = 没有货可抢 = 强盗先饿死**。
> - 所以现在的世界只能是**"衰落但没断"**：路太旺 → 商队多、护卫强、强盗打不过；路太断 → 强盗没得抢、活不下去。**恰是"稀疏但还通着"的中间态，才生得出"有强盗、打得过、也谈得拢"的局面。**
> - 🔴 **这条因果反过来锁死了世界状态**：如果商路"断绝"，强盗在逻辑上就不成立；本作**保留强盗这一常见敌人**，也就**必须**保留"路还在走"这一前提。**两者是同一件事的两面。**

## 三、灰渊信徒（敌对·极罕见）【已废止】

> 该阵营基于早期"灰烬母兽"设定（母兽崇拜），随母兽设定废止而一并作废（详见 废案_灰烬母兽设定.md）。灰烬生态重做后，不再存在"崇拜母兽"的教派。如有类似敌对势力需求，应另行设计为针对灰烬生态 / 旧文明实验的极端组织。

## 四、灰兽

灰兽是灰烬生态中的动物统称，其分类与分布由「生态角色」与「灰度分层」共同决定（玩法细节见第 8A 类）：

- **按生态角色分四类**：掠食型（主动猎食，危险）/ 食腐清道型（吃灰烬沉积物，一般不咬人）/ 群居迁徙型（像象群，围城属此类）/ 共生型（罕见，可理解互动）。
- **按灰度分层分布**：低灰区（灰度 < 300）几乎无灰兽；中灰区（300–700）以被灰烬感染变异的普通野兽为主（食腐 / 群居多见）；高灰区（> 700）以灰烬生态自古演化的原生动物为主（掠食 / 共生多见）。
- **灰蚀**：高灰区接触或战斗中施加的共有环境危险状态，是灰烬"腐蚀性后遗症"的体现，并非某一类的专属标签（接入第 4A 类状态系统）。

灰兽是生态住户，除掠食型本能猎食外不恶意；玩家进灰区才是闯入者。

## 五、路上遇到的人

路上遇到的**不是刷出来的怪，而是跟你一样在讨生活的人**——他可能真在做生意，也可能装成商队在那里等你；也可能你会先动手。

| 类型 | 真实身份 | 战斗强度 | 你主动动手的代价 |
|:--|:--|:--|:--|
| **正常商队 / 城镇车队** | 真在做买卖的人 | 低（护卫少、装备差） | **极高**：世界声望 + 该城商会分会声望双跌 |
| **信使 / 传令队** | 城与城之间的官方联络 | 低 | **极高**：截信使可能让**几座城市同时跟你交恶** |
| **伪装商队（劫道）** | 强盗装成商队 | 中，且**会先手** | **不打才是亏**：打掉 = **剿匪**，世界声望**上涨** + **可领赏金** |
| **赏金猎人** | 冲你的悬赏来的人 | 高（强于你的护卫） | 低，但你不打他就得跑、或者死 |

### 遭遇配比（防止"哪哪都有危险"）

- **频率**：正常商队 / 城镇车队 = **绝大多数**；信使 = **少**；**伪装商队（劫道）= 罕见**；赏金猎人 = **不参与随机**（只在你被通缉后由状态触发，是你自己惹出来的）。
- **默认安全**：碰上的绝大多数是真商队——"停下来谈生意"是正常选择，不必每队都设防。
- **危险必有前兆**：伪装型动手前会留线索——车辙不对、路边假货包、突然安静（见第 5A 类 B4「伏击前兆」）；**侦察等级高 = 提前看出来**。
- **目的**：稀有才有价值。伪装型一多、又没征兆，玩家只会"见人就防"，这套设计就废了。
- ⚠️ 具体频率 / 配比数值留空（见第 5A 类事件池）。

## 六、动手与后果

### 6.1 相遇时看得到什么

遭遇界面直接显示对方的**世界声望**与**通缉标记**。

⚠️ 但这是"**对方愿意让你看到的**"：伪装成商队的劫道者，挂着一套正常商队的名声；被通缉的也未必不是正经商人。想看穿，靠玩家侧能力（野外侦察 / 情报 / 相关记忆），破绽例如"车辙太重，护卫身上却一件货都没有"。

**反向一样成立**：对方也看得到**你的**世界声望与通缉标记，并据此决定动不动手。

### 6.2 谁先动手

结果三分支：**玩家先手 / NPC 先手（伏击：你首轮受创、可能被围）/ 同时**。

| 偏向你先手 | 偏向对方先手 |
|:--|:--|
| 护卫多、侦察等级高 | 对方是伪装型，本来就在等你 |
| 提前设防、天气利于观察 | 对方已经决定吃你这票 |
| 对方规模明显更小 | **你体力低 / 你正被通缉** |

> 被通缉的人，别人动手的心理门槛就低——通缉不只是"赏金猎人来杀你"，也是"**谁都敢先打你**"。

### 6.3 假意交易 → 伏击

伪装型车队**会先跟你谈生意**，在**谈价 / 验货 / 付钱的某一步突然翻脸**：交易界面**原地转战斗**（不是随机弹窗、不新开场景），**对方先手**。只有伪装型会干，真商队不会。

玩家侧：侦察够高 → **提前识破**、不进这笔交易；明知有诈仍进 → **带护卫戒备**可压低伏击效果。

### 6.4 玩家主动动手

- **入口**：遭遇界面 / 交易途中；**按钮显示「动手」**（内部字段 `hostile_attack`；给玩家看的一律**不用"劫掠 / 攻击 / 抢夺"这类字眼**）。
- **战斗形式 = 双方护卫对打**：平民、车夫、账房不参战（要么跑、要么跪；**打不还手的人 = 额外恶名**）。
- 即使你先动手，也可能**被反先手**（对方先手值更高时）。

### 6.5 谁知道是你干的

| 情形 | 是否被知道 | 后果 |
|:--|:--|:--|
| 全灭、无目击者 | 当场不知道 | 不立刻结算；立**悬案**，⚠️ 若干天后按概率被追认 |
| 有活口逃掉 / 附近有人看见（其他商队、驿站、村庄方向） | 知道 | **立刻结算** |
| 在城市内动手 | **必定知道** | 立刻结算，且**加重** |

> **环境耳目** = 附近有人烟的地点、路过的其他车队、看见你的人。**清场只等于"延迟暴露"，不等于没人知道**。

### 6.6 代价与收益：声望 + 通缉（双向）

- **被发现之后**：**世界声望（全局）↓** + **涉事城商会分会声望（局部）↓↓** + **该 NPC 个体信任 → 敌对**；累犯 → **通缉 → 赏金猎人上门**。
- **打掉有悬赏的人 = 剿匪，是正经收益**：**世界声望 ↑** + **可领赏金**（凭尸首 / 信物到挂悬赏的城市或商会分会领）。
  **前提是他身上有悬赏**——遭遇界面那个**通缉标记**，就是"打他有钱"的提示。没有悬赏的**散匪**（路边拦路要过路费那种）打了只算自卫：**不涨世界声望、不给赏金**，只是不背恶名。
- 所以信息是两面的、要赌：
  - **挂着干净名声的**，可能是**伪装的劫道者**（打了他：涨声望 + 领赏），也可能是**真商队**（打了他：双跌）；
  - **挂着通缉标记的**，打了**合法、无恶名**、还能领赏——但他也可能是个**被冤枉的正经商人**；**悬赏即授权，不必替他平反**。
- 一句话：**看错就打错**——侦察等级的意义就在这儿。
