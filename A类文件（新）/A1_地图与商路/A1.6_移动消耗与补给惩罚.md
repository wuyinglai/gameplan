## 5. 移动消耗

**移动规则**：移动按**野外体力池**结算（**池怎么攒、每格多少点，见 §2.1**）。每移动一格的消耗：

| 消耗项       | 规则                                                                      |
| --------- | ----------------------------------------------------------------------- |
| 野外体力      | **−15 点**（🔴 **恒定**；🔴 正常 3 格/天 · 极限 4 格/天 —— **只有「变高」，没有「变低」**，见 §5.1） |
| 当前天数      | +1（每过完一个自然日）                                                            |
| 补给        | 每名**出战者** −1 份食物、−1 份清水（整数份，不拆份；🔴 **不出战的人不消耗**，见 `第3A类 §1.5`）          |
| 重伤角色休息倒计时 | −1（休息节点数 −1）                                                            |

### 5.1 每格消耗只会变高（**没有「变低」**）

| 情况           | 每格消耗         | 说明                                |
| :----------- | :----------- | :-------------------------------- |
| **恶劣天气**     | **+5 / +10** | 暴雨 / 暴雪 / 灰烬风 / 灰烬风暴（见 `第5A类`）    |
| **坏路况 / 超载** | 上升           | 地形与载重修正                           |
| **车况损坏**     | 上升           | 抛锚 · 车轮磨损 / 爆裂 / 陷车（见 `第5A类` 车况表） |

### 5.2 补给耗尽惩罚

补给 = 0 后，每天：

- 士气 −1
- 全体角色**最大生命值降低 + 当前生命值同步扣掉同样的量**（食物归零 −10%，水归零 −20%；二者皆零则叠加）
- 重伤恢复天数 +1（不恢复反而恶化）

> 🔴 **2026-10-05 用户裁定：上限与当前血同步下降**。100/100 断食一天 → **90/90**（上限 −10 **且** 当前 −10，**两件事同时发生**）；断水一天 → **80/80**；二者皆零 → **70/70**。  
> **这不是"扣血"而是"身体上限被削掉了一块"**—— 当前血跟着降，是因为被削掉的那部分**当场就没了**，之后靠治疗也补不回那 10 点上限（治疗只填当前血，不涨上限）。
