## 11. 不做内容

以下内容属于第 **1A** 类的细分工作，不在当前设计阶段细化：

| 不做项           | 原因           |
| ------------- | ------------ |
| 具体每张地图的格子布局   | 属于关卡设计阶段     |
| 随机地图生成规则      | 第一版做固定地图     |
| 每条路线的具体怪物分布   | 路线细化阶段再做     |
| 每个中继点的具体剧情    | 暂不细化         |
| 安全点详细功能/物价/治疗 | 属于第 2A 类地点系统 |
| 情报系统详细规则      | 属于第 2A 类     |
| 天气系统详细规则      | 属于第 5A 类     |
| 战斗系统详细规则      | 属于第 4A 类     |
| 订单系统详细规则      | 属于第 2A 类     |
