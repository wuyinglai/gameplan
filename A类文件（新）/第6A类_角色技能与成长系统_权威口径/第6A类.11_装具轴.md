## 15. 装具轴（第三成长轴）

### 15.0 🔴 装具系统的结构：**装具平台 + 功能模块**（🔴 2026-10-28 模块化重做 · 总纲）

> 🔴 **2026-10-28 用户与 ChatGPT 讨论重做**：旧「骨架 + 装具盘（9 格 + 联锁落差）」体系废止，重整为**「装具平台 + 功能模块 + 角色属性」**的模块化构筑系统。装具 = **外置、可拆卸的模块化机械设备** —— 🔴 不是人体内部改造，不通过生物改造改变身体（基调红线不变，见 §15.1）。

| 层 | 是什么 | 决定什么 |
|:--|:--|:--|
| 🔴 **装具平台**（原「骨架」，硬件层） | 安装功能模块的**基础机械框架** | ① **接口类型**——能装哪些类型的模块 ② **接口数量**——能装多少、各类型配额 ③ 🔴 **供能能力**——能支持多少模块**同时运行** |
| 🔴 **功能模块**（原「装具」，配件层） | 实际提供属性与特殊效果的设备 | 模块类型（接口需求）· 供能需求 · 提供的**角色属性数值**（可一项或多项）· 模块自身特殊效果 |

**链条**：`装具平台 → 接口 + 供能 → 功能模块 → 角色属性 / 特殊效果 → 战斗与生存能力`

| # | 🔴 必须记住的点 | 说明 |
|:-:|:--|:--|
| **1** | 🔴 **平台差 = 带不动好模块** | 平台材质**粗劣 → 常规 → 精良 → 旧时代**（升级轴保留），越高级接口越多、供能越强 —— 好模块不是买得起就装得上 |
| **2** | 🔴 **平台专长 = 接口分布** | 运动 / 循环 / 代谢 / 感知 / 均衡型的差异**只体现在接口往哪偏**（本行接口多、好组合）；🔴 **不做「同模块装在专长平台上效果加倍率」** —— 专长平台的优势是**更容易安装、组合某类模块**，不是自动增益 |
| **3** | 🔴 **双闸门 = 接口 + 供能** | **接口限制**：类型对 + 数量够；**供能限制**：已装模块的**总供能需求 ≤ 平台供能能力**。两闸共同决定能装什么、跑得动什么 |
| **4** | 🔴 **供能概念本轮正式引入** | 旧表述「『超限』= 负载不足，不是能量 / 供能，本作不引入能量概念」**废止** —— 现行为**平台供能能力 vs 模块供能需求**的约束方向；🔴 供能数值 / 来源 / 是否有持续消耗或充能机制 **待讨论，不擅自添加**（待裁定㉜④） |

> 📌 与记忆轴（§5）、装备轴（§14）并列的第三成长轴，**三轴都是主轴**。本节原名「身体改造轴」（2026-09-24 改「装具轴」—— 去生物感）。模块名沿用铁律定名的 **9 项装具**（§15.3，名称不改）。
> 📌 旧「骨架分两轴」的**种类轴**演化为平台专长（接口分布）、**材质轴**保留为平台升级轴；旧「负载」概念由**供能**接替。

### 15.1 定位与边界（**2026-09-20 改口径 · 2026-09-24 改称谓**）

- 成长三轴：**记忆轴（§5）· 装备轴（§14）· 装具轴（本节）**。
- 🔴 **加装 = 穿「可拆卸的装具」，不是"换器官"**（2026-09-18 用户定，**基调红线**）：
  - 装具是**外挂助力装置** —— 像外骨骼那样**接 / 穿**上去，**不是"把肌肉挖出来换掉"**。
  - 因此它**可以完整拆下来、转给另一个人用**（"脱下来给别人穿"）→ **换阵容时装具投资不白费**。
  - 🔴 **禁止恐怖 / 惊悚 / 生物改造感**：一律用 **机械·工程语汇**（装具 / 外骨骼 / 支架 / 背心 / 面罩 / 水壶），**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体）。
- **拆装规则**：拆下 / 装上要收代价（**装具台工费 / 少量材料损耗**，具体待定）—— 否则加装会变成"免费洗点"，就不存在取舍了。
- **拆装会改变联锁**：从老角色身上拆走一件、装到新人身上，**新人的配比就变了**，可能出现"落差 ≥3"的**破口**（见 §15.2）→ 这正是**配装乐趣**：你得给新人配一套平衡的。
- 🔴 **2026-10-06：取消「加装仅核心成员」这条限制** —— 原理由是"防止装具投资随人流失"，但**人不会走**（§8.4），前提已消失。**现在任何战斗人员都可以加装**（含后来招募的雇佣成员）。
- 其余两轴规则不变。

### 15.2 🔴 角色六属性与功能模块（2026-10-28 重做 · 旧「装具盘 9 格 + 联锁」废止）

#### 一、角色属性清单（🔴 六项，确定保留）

| 属性 | 作用 |
|:--|:--|
| 🔴 **承伤能力**（旧称生命值 / 血量，全库统一改称） | 决定角色能承受的**累计伤害上限**。🔴 **世界观**：装具通过外部支撑 / 冲击分散 / 关节辅助 / 身体姿态稳定，使角色受损伤后仍能维持行动战斗 —— 🔴 不是人体组织数量、不是"凭空加血"、不是人体内部改造 |
| **力量** | 影响角色的**力量输出**（机械关节 / 驱动结构辅助发力）；对具体武器招式的影响 → 待裁定㉜②（🔴 不做对所有攻击的统一伤害倍率） |
| **承载** | 角色个人携带重量上限（外部支撑框架分担负荷）；🔴 只管个人 → 与商队货物载重（`第3A类`）分开；超重影响战斗动作体力的规则（§14.3.3/14.3.4）不变 |
| **体力储备** | 对**队伍共享体力池容量**的贡献（§4.2 全队共享池不变；多人如何汇总 → 待裁定㉜①） |
| **体力恢复** | 对**共享池每回合回复量**的贡献（循环辅助 / 呼吸辅助 / 负荷调节；汇总规则 → 待裁定㉜①） |
| **机动** | 🔴 **只管两件事**：① 战斗先手 ② 按机动差值累积获得额外行动的频率。🔴 **不影响闪避 / 移动速度 / 命中 / 反应速度**（细则 → `第4A类 §2.6`） |

> 🔴 **承伤能力 ≠ 普通护甲**：护甲负责**直接防护**（吸收 / 阻挡单次攻击，有自己的防护值 → `第4A类 §4.3`）；承伤能力是**累计伤害上限**。提高承伤**不代表**每次受伤自动减伤。
> 🔴 **不新增属性**：闪避 / 命中 / 反应速度 / 移动速度 / 抗感染 / 抗灰蚀 / 抗毒 / 补给效率 / 排毒 🔴 **不做通用属性** —— 由具体模块的特殊效果承担（见下表）。
> ⚠️ 各属性初始值 / 成长值 / 模块提供数值 / 供能需求 / 接口数量 → 全部待裁定㉜⑥，本节不写数。

#### 二、功能模块（铁律 9 项装具名不变 → 按新体系重整）

| 模块（铁律定名） | 接口方向 | 🔴 提供（按新属性体系重整） |
|:--|:-:|:--|
| **助力臂架** | 运动 | **力量 +** |
| **背负支架** | 运动 | **承载 +** |
| **循环辅助背心** | 循环 | **体力储备 +**（旧「体力上限」） |
| **滤尘面罩** | 循环 | **体力恢复 +**（旧「每回合体力回复」） |
| **负重背心** | 独立 | **承伤能力 +**（旧「最大生命」） |
| **反应辅助头环** | 感知 | **机动 +**（🔴 旧「闪避时机」取消 —— 机动不管闪避） |

> 🔴 **一个模块可同时提供多项属性 + 特殊效果**（例：承伤 +3 且 力量 +1 —— 示例非数值）；🔴 **不是所有模块功能都转化为属性**。
> 🔴 **旧「装具盘 9 格（100→200→300）+ 联锁（落差 ≥3 → 破口）」随结构废止** —— 加点 / 配负荷的替代方案（接口 + 供能如何形成取舍）→ 待裁定㉜⑦。旧「心肺职能（滤尘面罩=肺 / 循环背心=心脏）」由**体力恢复 / 体力储备**两属性接替。

### 15.4 不兼容机制（原「排异」）

> ⚠️ 🔴 **2026-10-28 标注：本节与 §15.5「六种结果」的机制**建立在旧「装具盘加点」结构上，模块化重做后**保留概念、细节随新结构重整**（哪些保留 / 怎么改 → 待裁定㉜⑦）；🔴 重整前**不扩展**新的随机安装 / 失败惩罚机制。

- **不兼容率按装具大小定**：微型 **0%** / 小型 **10–20%** / 大型 **40–60%**（⚠️ 初值，实测再锁）。
- **不兼容 ≠ 失败**：不兼容是**这具身体装不上这件**；失败是**技术没做成**（见 15.5）。
- **不兼容后果（轻量、可重试、不永久伤残）**：**装具无效 + 资源白费 + 短暂负面**（休养数天 / 临时 -属性）。绝不影响已完成改造、绝不永久伤残（接「不做永久惩罚」）。

### 15.5 加装结果：六种可能

一次加装落定后，结果分六种，让玩家自己权衡风险：

| 结果 | 说明 |
|:--|:--|
| **成功** | 装具生效，获得效果 |
| **技术失败** | 没做成，资源白费，轻微负面（短时虚弱） |
| **不兼容** | 这具身体接受不了这件装具（见 15.4），轻量可重试 |
| **接口冲突** | 与已装件互斥 / 缺前置 → 无效或需先移除前置（形成 build 多样性，不堆同一项） |
| **感染风险** | 在灰区 / 无高级器械时加装，有灰度感染概率（接第 8A 类感染机制） |
| **副作用** | 成功但附带轻微负面（如背负支架 → 灵活性 -），是 trade-off 非 bug |

### 15.6 前置 / 互斥

- 部分装具需前置（如先装负重背心，才能上反应辅助头环）。
- 部分装具互斥（占用同一接口）。
- 形成 build 多样性，不堆同一项无脑变强。

### 15.7 资源与显示

- 消耗复用 **灰烬材料 + 火种 + 金币**（与装备强化同源，不另造资源）。
- **装具台**界面显示「本次不兼容率 / 失败率 / 预计恢复 / 兼容性」，玩家自己决定赌不赌基础台。
- **可拆卸转移** → 换阵容时把装具从老角色拆下、装到新人身上（收拆装费）。

### 15.8 不做内容（装具相关）

| 内容 | 说明 |
|:--|:--|
| 永久伤残 / 不可逆惩罚 | 不兼容 / 失败轻量可重试，绝不留永久伤 |
| 加装必成功 | 风险（不兼容 / 失败 / 感染）是机制一部分，不是 bug |
| 堆同一项无脑变强 | 接口 / 前置约束，鼓励 build 多样性 |
| 🔴 **恐怖 / 生物改造感** | **一律机械·工程语汇**；**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体）；装具**可拆卸、可转给他人** |
