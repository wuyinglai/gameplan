## 14. 角色成长·装备驱动

角色不通过经验值或金币直接升级属性。角色的成长通过**装备驱动**实现。

### 14.1 核心理念（**2026-09-20 重写**）

> 🔴 **旧口径作废**：原 §14.1 写"角色基础数值（生命值、**攻击力**等）**固定不变**"——**作废**。角色的**攻击力不是常数**，它来自**武器面板 + 身体加成**，是会成长的东西。

**伤害从哪来（总链）**：

```
伤害 = 武器面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率
        ↓
依次扣：护盾 → 屏障 → 护甲 → 生命
```

| 谁 | 给什么 | 形式 |
|:--|:--|:--|
| **武器** | **面板**（基础伤害） | **固定数字**（离散、有上限） |
| **招式** | 倍数（挥砍 ×1.0 / 重击 ×1.5） | 乘法 |
| **身体（装具模块 · 属性）** | **战斗加成** | **百分比**（🔴 2026-10-28 起：角色六属性见 `§15.2`；力量对武器的具体影响 → 待裁定㉜②） |
| **攻击类型 × 防护档** | 克制倍率 | 乘法（第 4A 类 §4.2） |

> **为什么不用"角色基础攻击力 + 两个加成"**（2026-09-20 用户指出）：基础是常数的话，全部成长都得由两个乘数扛 → 后期两个乘数只能一路往上堆 → **相乘 = 平方增长 → 数值爆炸**。**拆成"面板（离散、有上限）+ 加成（百分比）"各承担一半**，两边都不用涨到夸张。
> **加成幅度的上限**：⚠️ **合计 ≈60% 为 AI 提案，非用户铁律**（用户 2026-09-24 明确：这条是 AI 提的，他只默认，可以改）。数值随装具模块体系一起定（待裁定㉜⑥；旧出处 `04 §10.1` 已废案）。
> **空手兜底**：**拳打 = 3 面板（打击）** —— 防止"卸下武器卡死"。

### 14.1.1 🔴 武器属性加成与武器技巧（2026-10-28 用户与 ChatGPT 讨论重做 · 原「角色给武器的补正」升级）

> 🔴 **攻击表现由三方共同决定**：**武器自身性能 × 角色属性 × 武器技巧**。🔴 **不同武器类别有不同的力量 / 技巧依赖度**，🔴 **不做全武器统一的属性加成公式**。两个成长方向：**力量** = 身体直接发力能力（🔴 由装具模块提供，`§15.2`）；**武器技巧** = 对特定武器及其使用方式的掌握程度（🔴 通过学习 / 教学 / 研究获得，**不可由装具模块直接增加**）。技巧还承担**特殊招式的学习门槛**（→ `第4A类 §2.3.1` 复杂 / 特殊招式）。

**机制底线（不变）**：🔴 **空手**走兜底伤害（拳打 = 3 面板，`§14.1`）；🔴 **拿武器按武器面板算**（面板是主体）；🔴 **角色反过来影响武器** —— 同一把武器，不同角色打出来不是一个数。

#### 一、加成倾向表（🟡 初步建议 · 🔴 数值未定稿，待裁定㉝）

| 武器类别 | 力量占比 | 技巧占比 | 设计倾向 |
|:--|--:|--:|:--|
| 剑类 | 70% | 30% | 主要靠身体发力，技巧辅助 |
| 钝器类 | 80% | 20% | 强调力量与冲击 |
| 长柄武器 | 60% | 40% | 两者并重 |
| 投掷武器 | 70% | 30% | 主要靠投掷力量 |
| 弓类 | 50% | 50% | 力量管拉弓与发挥，技巧管射击表现 |
| 弩类 | 10% | 90% | 主要靠机械结构与使用技巧（力量只可能影响上弦等操作） |
| 枪械 | 0% | 100% | 攻击能量来自弹药，🔴 力量不直接加威力 |

#### 二、七类武器技巧（🔴 按操作方式与技术体系划分，不按每把具体武器设技巧）

**剑术 · 钝器 · 长柄 · 弓术 · 弩术 · 投掷 · 枪械** —— 同类别下不同型号 / 材质 / 规格**原则上共用**该类技巧。🔴 **技巧不可由装具模块增加**（与力量相区分）。具体招式可对类别基础比例做**招式级修正**（劈砍偏力量 · 精细刺击偏技巧 · 特殊剑术双高——修正方式待裁定㉝）。

#### 三、学习与成长（🔴 不刷熟练度——与 `§5.1` 禁刷裁定一致）

- 🔴 技巧**不通过**反复使用武器 / 累计攻击次数成长。渠道：**向专业人物或队友学习 · 阅读研究特殊技术资料 · 观察 / 实验 / 探索 · 旧文明战斗技术资料 · 特殊记忆物品**（可直接赋予技巧，作为免训练例外）。
- 🔴 **学习时间成本**：训练需投入时间且训练期间不能做其他工作；🔴 **商队必须停止正常赶路**（行程成本也是成本）；可能需场地 / 指导者 / 设备。训练时长未定（待裁定㉝）。

#### 四、技巧总容量共享上限（🔴 防全能）

- 角色所有武器技巧**共享一个总容量**（示例：容量 50 = 剑术 40 + 弓术 10，即满）——🔴 学新技巧须**调整或放弃**已掌握的技巧腾容量。**限制无限累积、防后期全能**（与 `§5.2` 构筑平衡、`§18` 记忆槽的取舍思路同源；🔴 技巧容量是独立于记忆槽的另一条容量）。容量数值与遗忘 / 替换规则 → 待裁定㉝。

#### 五、传授上限与商队笔记（🔴 教学不能完整复制专家）

- **传授**：只能传部分水平（示例：100 点剑术 → 按 50% 传授比例 → 他人最高 50 点）。
- 🔴 **商队笔记**：只记录**可传授的部分**（100 点角色只能记约 50 点水平的知识），供其他角色学习——**商队共享部分知识，但保留专家角色的个人技术优势**（与 `§18` 商队知识库「记录 ≠ 掌握」同一思路；衔接细节 → 待裁定㉝）。

> 🔴 原则七条：力量与技巧共同影响攻击但各类武器依赖度不同 · 力量来自装具模块、技巧来自学习 · 技巧兼作特殊招式门槛 · 不刷熟练度 · 技巧共享总容量 · 教学 / 笔记只传部分不复制专家 · 学习产生角色时间 + 商队旅行的双重成本。

### 14.2 武器系统

🔴 **武器使用的两项独立要求（2026-10-25~28 用户与 ChatGPT 讨论 · 新增）**：
- ① **专业要求** —— 角色须掌握该武器所需的专业知识/技能（🔴 **看实际知识，不看职业名称**）；
- ② **能力值要求** —— 力量等能力不足时，无法正常使用超出自身能力的重型武器。
- 🔴 **两项相互独立**：满足其一 ≠ 自动满足另一。哪些武器需要专业要求、要求如何划分 → 待职业/专业知识分类定后逐类确认（待裁定㉘）。

**一件武器给三样东西**（🔴 第三样 2026-10-28 改）：

| 给什么 | 性质 | 例 |
|:--|:--|:--|
| **动作牌** | 定性 · 不随强化变（武器的"身份"） | 剑 → 挥砍 + 轻格挡；重盾 → 重盾防御；小盾 → 盾反；长矛 → 刺击 |
| **面板** | 定量 · **强化就是强化它** | 钢剑 13 |
| 🔴 **武器自身的特殊机制与特点** | 定性 · 每把武器的独有特性（招式池差异、特殊效果等） | 🔴 待装备设计（🔴 原「攻击类型」项废止 —— 🔴 **攻击类型改由具体招式决定**，见下） |

🔴 **攻击类型由招式决定（2026-10-28 · 原「武器↔攻击类型一一绑定」废止）**：打击（撞击锤击）/ 斩击（锋刃切割）/ 刺击（尖端刺入）由**本次执行的招式**决定，不吃倍率表哪一列跟着招式走 —— 同一把剑：**剑柄砸击 = 打击 · 剑尖刺击 = 刺击 · 剑刃挥砍 = 斩击**。

**面板怎么来**：

> **面板 = 材质基准（绝对）× 种类系数（相对）**

- **材质**：**铁 < 钢 < 旧时代**（高级是低级的上位替代）
- **种类**：决定它在这个基准上坐哪一档
- **招式只写倍数**（挥砍 ×1.0 · 重击 ×1.5 · 横扫 ×0.8 打两个）→ **换一次武器，整组招式一起变强**

**十四种类**：

| 握持 | 种类 | 🔴 惯用主类型 | 特点 |
|:--|:--|:--|:--|
| **单手**<br>（可配盾 · 可双持） | 匕首 | 刺击 | 面板低 · 体力消耗低 · 易挂流血 |
| | 单手剑 | 斩击 | **基准 1.0** · 均衡 |
| | 单手斧 | 斩击 | 面板稍高 · 附带少量流血 |
| | 单手锤 | 打击 | 面板中低 · 破甲 |
| **双手**<br>（占两手 · 格挡弱） | 长矛 | 刺击 | 面板高 · 不挑敌人 |
| | 双手剑 | 斩击 | 面板很高 |
| | 战锤 | 打击 | **面板最高 · 破甲最强** |
| **远程**<br>（双手 · **零格挡**） | 弓 | 刺击 | 无装填 · 便宜 |
| | 弩 | 刺击 | 装填 1 回合 · 面板高于弓 |
| | 火枪 | 打击 | 装填 1 回合 · 面板最高 · **耗火药** |
| **盾** | 小盾 | — | 0~25 体力 · 护盾 5~6 / 12 |
| | 中盾 | — | 50 体力 · 护盾 26 |
| | 重盾 | — | 100 体力 · 护盾 55 / 可全队 |
| | 塔盾 | — | 占两手 · 150 体力 · 护盾 100 |

**握持五型**：

| 配置 | 占手 | 格挡 | 输出 | 性格 |
|:--|:--|:--|--:|:--|
| 单手 + 盾 | 1+1 | **强** | 1.0 | 稳健、护队友 |
| **双持** | 1+1 | 弱 | 1.0 + α | 灵活（两套卡池）· 体力跨度大 |
| **双手武器** | 2 | 弱 | **≈2.5** | 高伤、笨重 |
| **塔盾** | 2 | 极强 | ~0 | 极限防御 |
| **远程** | 2 | 🔴 **无** | **≈1.5** | **纯输出、零防御** |

- **近战都能格挡**（弱于带盾：例 25 体力 → 5~6 护盾）；🔴 **只有远程完全不能格挡、不能近战** → 拉弓占满两手 → **连自救能力都没有**，只能靠队友叠盾（**护盾可给队友**，见第 4A 类 §4.4）。
- **双持**：左右手各一把单手（或两面盾）→ 解锁**连击牌**；**同类双持**给通用连击，**成套武器**（物品标「套」）给专属牌。
- **远程不做弹药计数系统**（成本并入硬账）；**投掷武器（飞刀 / 投斧 / 燃烧瓶）归消耗品**，不占武器栏。

**攻击类型 × 防护档**（完整表与判定规则见 **第 4A 类 §4.2**；🔴 2026-10-28 起：表中倍率 = 对**单一纯构成**的基础值，混合防护构成按 `第4A类 §4.1` **加权公式**使用；攻击类型由招式决定，见本节上文）：

| 类型 | 对无甲 | 对软甲 | 对硬甲 |
|:--|--:|--:|--:|
| **打击** | ×0.9 | ×1.0 | **×1.3** |
| **斩击** | ×1.1 | **×1.2** | ×0.9 |
| **刺击** | ×1.1 | ×0.9 | ×0.9 |

> 🔴 **2026-10-10 用户裁定**：**打击对无甲 ×0.95 → ×0.9**（"前半场武器"手感更明显）；**刺击 ×1.0 / ×1.0 → ×0.9 / ×0.9**（削弱成"两头都不吃" —— 情报不足时选它是**赌博**而非安全选择）。详见 `第4A类 §4.2`。

**其余规则不变**：**不设攻速**、**强化 = 灰烬材料 + 火种 + 金币**、**强化只提数值不改核心特点**、**武器对特定记忆有加成**（如重锤对【重击】+15%——保留，这是"武器 × 记忆"构筑的核心）。

### 14.3 护甲系统（🔴 2026-10-28 装备讨论重做：加权构成 + 行动阻碍 + 个人负重）

**防具（5 部位：头 / 躯干 / 手 / 腿 / 足）给的东西**（🔴 2026-10-28 改）：

| 给什么 | 内容 |
|:--|:--|
| **① 甲值** | **开战一次性赋值**（各部位相加成**整体甲值池**，躯干贡献可更高 · 具体数值待裁定㉛）· **本场战斗内持久、只减不增** · **战毕自动复位** · 🔴 **归零 = 本场防护耗尽，不代表装备损坏报废（旧「防具报废 + 转无甲档」废止）—— 甲值是战斗防护资源，不是装备耐久** |
| **② 防护类型** | 每部位按其防具归入 **软甲**（布 / 皮）或 **硬甲**（铁 / 钢）或 **无甲**（不穿）→ 🔴 五部位按**防护权重**加权出**整体防护构成**，挨打时按构成算加权倍率（公式与「不做部位命中」→ `第4A类 §4.1`；🔴 旧「一件硬甲 = 全身硬甲」废止） |
| **③ 重量与行动阻碍** | 🔴 **两个独立属性**（见下 14.3.3 / 14.3.4）—— 重量决定是否超重；行动阻碍决定妨碍哪些动作；🔴 旧「重甲影响野外体力」笼统表述废止（🔴 个人负重**不影响**商队行进与野外移动体力） |

**批次规则**：

- **材料是升级轴**：**皮甲 < 铁甲 < 钢甲**（高级是低级的上位替代，花钱买更好天经地义）
- **软 / 硬是取向轴**：**软甲不怕打击、怕斩击；硬甲不怕斩击、怕打击** —— **两者永不互相淘汰**（"哪件甲更好"没有通解，答案取决于对面拿什么招式）
- **甲值差距压到 ≤ ~20%**（软 36 ∶ 硬 45）：**别让厚度把相性吃掉**
- 🔴 **不做"通用减伤率"**（2026-09-20 作废）：它是纯优乘数（谁高谁永远更抗打），会把软硬甲的相性抹平。**防具差异全部由攻击类型倍率表 + 防护构成承担。**
- 🔴 **甲值归零 = 本场防护耗尽**（装备本身不损坏）；**修补师可用「紧急加固」补甲**（25 点共享体力 + 1 零件 → 队友 +12 甲）
- **强化方式**同武器：**灰烬材料 + 火种 + 金币**

> **厚度目标**：**总甲 ≈ 血池 ÷ 3**（≈ 总耐久 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具得跟着血池一起升级**，否则后期被甩开。

#### 14.3.1 防具六属性（🔴 2026-10-28 新增 · 防具不能只有甲值）

| 属性 | 作用 |
|:--|:--|
| **甲值** | 为角色整体甲值池提供防护能力 |
| **防护类型** | 决定该部位属于无甲 / 软甲 / 硬甲（参与构成加权 → `第4A类 §4.1`） |
| **重量** | 计入角色**个人总负重**（→ 14.3.4） |
| **行动阻碍** | 对特定身体动作产生额外体力成本（→ 14.3.3） |
| **特殊防护特性** | 针对特定攻击或负面效果提供防护（→ 14.3.2） |
| **装备限制** | 规定装备需满足的体格等条件 |

#### 14.3.2 特殊防护四要素（🔴 新增 · 防随意扩展 / 防完全免疫）

每条特殊防护必须写明四样：**① 防护对象**（防什么攻击 / 负面）· **② 生效条件**（何时触发）· **③ 效果程度**（减伤 / 减轻 / 改变结算）· **④ 作用边界**（🔴 不能防什么）。🔴 不应扩展成全面减伤，也不应轻易形成对某类攻击的完全免疫。具体护甲种类与特殊效果以后续装备设计为准（待裁定㉛⑦）。

#### 14.3.3 行动阻碍（🔴 新增 · 与重量分开计算）

- **重量**决定是否超重（→ 14.3.4）；**行动阻碍**决定装备本身妨碍哪些动作 —— 🔴 两者不能混为一谈（两件同重的重甲，灵活度可以不同：结构 / 关节设计 / 柔韧程度）。
- 🔴 **只作用于相关身体动作**，不得无差别影响所有卡牌：腿 → 跳跃 / 闪避 / 快速移动；躯干 → 大幅身体运动；手 → 精细操作（具体影响哪些动作，结合动作牌的实际执行方式确定）；🔴 **不依赖身体活动的战术准备 / 机制操作，不因穿重甲自动加价**。
- 🔴 **多件合并 = 加法**：同一动作受两件装备阻碍（3% + 2%）→ **装备行动阻碍倍率 = 1 + 3% + 2% = 1.05**（🔴 不逐件连续相乘）；数值由各装备自定，不写死统一倍率。
- 🔴 **最终体力消耗 = 基础体力消耗 × 总负重倍率 × 装备行动阻碍倍率**（正常负重时负重倍率 = 1；阻碍只计影响当前动作的相关装备、加法累计再乘）。🔴 重甲不再因部位多而重复吃固定「重甲倍率」—— 重量走总负重、结构走行动阻碍，不重复惩罚。

#### 14.3.4 角色个人负重系统（🔴 新增 · 与商队货物彻底分开）

- 🔴 **个人负重 = 角色实际穿戴 + 随身携带**（护甲 / 武器盾牌 / 工具 / 个人物品）；**商队货车里的货物不计入**（货物重量走 `第3A类` 车厢载重，两套系统互不干扰）。
- 🔴 **个人负重不影响商队每日行进距离，也不增加野外移动体力消耗** —— 只影响战斗内的体力成本（经由 14.3.3 的倍率）。
- **负重比例 = 当前个人总负重 ÷ 角色承载上限 × 100%**（每人独立承载能力）。三状态：

| 状态 | 判断 | 效果 |
|:--|:--|:--|
| **正常负重** | ≤ 承载上限 100% | 🔴 无任何惩罚：不影响移动与战斗、不增战斗体力成本 |
| **超重** | > 100%（未达严重阈值） | 🔴 **负重倍率 = 实际负重比例（小数）**：105% → ×1.05 · 120% → ×1.20；按实际比例一次算清，🔴 不按装备件数重复相乘；只加**受影响战斗动作**的体力成本 |
| **严重超重** | 达严重超重阈值 | 🔴 **硬性限制**：无法正常行动 / 移动 / 参与常规战斗；须卸装或转移物品降回允许范围（与 `第4A类 §9.1`「严重超重不可撤退」同源） |

> ⚠️ **承载上限与严重超重阈值未定** → 待裁定㉛⑤。

### 14.4 装备分类与价格

装备分为两类，**不存在品质等级（普通/精良/特殊）的区分**，只有装备本身的差异：

| 类型 | 说明 | 参考价格 | 获取方式 |
|:----|:-----|:--------:|:--------|
| **普通装备** | 当代工艺制造的武器和护甲，各有不同特点 | **约 2,000 金** | 城市购买 |
| **旧时代装备** | 旧文明遗留的高科技装备，效果更强 | **约 6,000 金** | 遗迹探索，**出现概率低**。更稀有的可达 **7,000~8,000 金** |

> 旧时代装备是普通装备的**稀有上位替代**（材料与旧文明技术都更强）；普通装备内部按材料分级也存在上位替代（铁<钢）。三者都可用灰烬材料 + 火种 + 金币强化。
