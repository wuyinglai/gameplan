## 18. 🔴 知识与商队知识库系统（2026-10-28 用户与 ChatGPT 讨论新增）

> ## 📌 定位（先看这段）

> | **本节负责** | 知识的**获取途径** · **研究原则** · **商队知识库（永久记录）** · **个人记忆槽（同时运用上限）** · **记忆配置与旅途准备** |

### 一、知识的获取

- 世界中的知识部分由**人物、组织、地区传承**，部分存于**书籍、旧文明手稿、实验记录、遗迹**，还有部分需玩家**重新发现**。
- 🔴 **玩家主要通过主动探索获得特殊知识**，不依赖系统直接发布任务或强制触发事件。
- **六条获取途径**（可相互结合，例：手稿 → 线索 → 找材料实验 → 掌握矿石特性）：

| 途径 | 例 |
|:--|:--|
| **人物交流与学习** | 向优秀铁匠学习锻造知识 |
| **文献与历史资料** | 书籍 / 旧文明手稿 / 实验记录 / 交易购买稀有资料 |
| **观察与探索** | 生物、环境、异常现象、特殊材料中发现规律 |
| **主动实验** | 按已有线索对材料 / 工具 / 研究对象有目的地尝试验证 |
| **信息拼合与推理** | 跨地点、人物、物品的线索结合推导新知识 |
| **实践与经历** | 战斗、制造等实际经历中发现规律 |

- 🔴 **并非所有知识都走完整研究流程** —— 能直接学的直接获得；需要验证的才经研究与实验。

### 二、研究机制的设计原则（🔴 不模拟真实科学实验全过程）

| # | 原则 |
|:-:|:--|
| 1 | 研究操作围绕**有意义的**观察、实验和推理展开 |
| 2 | 特殊研究要有**合理线索与可理解的研究方向**，🔴 **避免穷举组合找答案** |
| 3 | 研究结果由**预先设计的知识、条件和逻辑**决定，🔴 **不单纯依靠随机奖励** |
| 4 | 🔴 **重复执行完全相同的操作，不应成为获取研究成果的主要手段** |
| 5 | **研究失败也提供有价值信息** —— 排除猜想 / 揭示材料限制 / 指出后续方向 |
| 6 | 不同知识可用不同获取流程，不要求都走观察-实验-推理三步 |

> 具体研究操作、资源消耗、研究时间与失败结果 → 待裁定㉙（依实际玩法需要另行设计）。

### 三、商队知识库与个人记忆（🔴 两层，不许混）

| 层 | 规则 |
|:--|:--|
| 🔴 **商队知识库**（纪事本） | **永久保存已发现并正式记录的知识**——不因队员遗忘、离队、更换而丢失；提供查询；允许队员**重新学习**（无须再找原始来源）。🔴 **「知识库里有」≠「角色会」—— 两个概念** |
| 🔴 **个人记忆槽** | 角色可**同时运用**的知识受**槽位限制**；容量不足时学新知识须先调整配置；**遗忘 ≠ 知识消失**——已记录即可重学。🔴 **设计目的 = 限制「同时运用的针对性能力」、逼玩家在战术方向间取舍，🔴 不是限制永久获得知识的数量** |

> 🔴 **与 §5.2（记忆植入不设上限）的关系（衔接口径）**：§5.2 说的是**领域记忆（旧文明植入，构筑核心）**——数量不设上限，因为与构筑不兼容的记忆自限无用；**本节的知识条目**（如「某野兽的弱点」「某矿石特性」）是**探索发现的针对性内容**——永久记录在商队知识库，但**同时运用受个人记忆槽限制**。两层并行不冲突。⚠️ **若项目主的本意是记忆槽也约束领域记忆，则 §5.2 需修订** —— 请明确（已并入待裁定㉙）。

### 四、记忆配置与旅途准备

- 玩家可按**下一段旅途的环境、敌人分布、预期风险**调整各角色的记忆配置（狼群路线配针对狼群的知识；换路线则换知识）。同一套配置使角色擅长应对某类敌人，**面对其他敌人缺少针对性优势**。
- 🔴 **配置更换的地点与限制待定** —— 倾向**限城市 / 驿站等休整地点**，不允许野外随时调整；此限制是「路线规划 / 出发前准备 / 风险评估有意义」的来源（待裁定㉙）。

### 五、知识向战斗能力的转化（指针）

🔴 **「有限的通用战斗技巧 + 知识提供的针对性强化」**——通用技巧执行行动；知识揭示弱点 / 改变条件 / 强化效果。三种强化形式（数值 / 条件 / 机制）与「特殊知识 → 独立技能」的例外通道 → **`第4A类 §2.5`**（本节不重复）。

### 六、设计约束（🔴 七条，违反即返工）

| # | 约束 |
|:-:|:--|
| 1 | 不要求玩家**重复相同操作**积累研究进度 |
| 2 | 不要求**每一种知识都对应一个独立技能** |
| 3 | 不让角色因永久收集大量知识，就能**不经准备同时发挥所有针对性能力** |
| 4 | 知识**不停留在图鉴 / 信息层面** —— 设计为可应用的知识必须有明确玩法效果 |
| 5 | 优先复用通用战斗规则；**独特机制留给少量重要内容** |
| 6 | 保留玩家**主动探索 / 学习 / 实验 / 推理**获得知识的空间 |
| 7 | 🔴 **商队知识库管「永久保存」，个人记忆槽管「当前掌握与运用」** |
