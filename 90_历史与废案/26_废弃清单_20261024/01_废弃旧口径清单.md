# 《余烬商队》废弃旧口径清单

> 本清单列出所有已废弃的旧口径，后续开发不应再使用这些内容。  
> 旧文件可保留作为历史参考，但不能作为实现依据。
>
> 🔴 **⚠️ 本文件写于 2026-06-29，晚于它的批次见下方「零、2026-09-20 批次」；且第一~八节中的"新口径"亦有多条已被再次覆盖**（最典型：本节把"护路人 68 / 修补师 46 / 射手 40"当作新口径，现已被 **120 / 70 / 85** 取代）。**一切以 `0A_权威系统文档/` 为准。**

|---|---|---|
| 补给耗尽"**当前血 −10%**"这种写法 | 🔴 改为「**减去该角色最大生命值的 10% 这么多点数**」—— 上限 100 → 上限 90 且当前血也 90；上限 240 → 216 | 第3A类 §1.6 |
| 抛锚"**必须修到 10 以上**才能动" | 🔴 **修到 20 以上**才能继续行动（修 10 太少，抛锚不疼） | 第3A类 §2.1/§2.2 · 第6A类 §11 |
| 城市自然恢复 **+2**、"普通城镇"、**大型城镇** | 🔴 **所有地点一律 +1** · 🔴 **没有"大型城镇"**（只五类）· **上限 = 城市 6 / 城镇·驿站 4** · 🔴 **冷却 20 天** | 第3A类 §4.6 · 第2A类 §7.2 |
| **核心成员 = 初始 6~7 人** | 🔴 **初始 14 人全部都是核心成员**（不领日薪） | 第3A类 §4.5.2 · 第6A类 §8.1 |
| 成员**被挖走** / 逃跑 / 减员 | 🔴 **全部不存在** —— **人数只增不减**；玩家只在城市里**选择谁出战**，**不出战 = 不领工资、不消失、不老** | 第3A类 §4.5.3 · 第6A类 §8.4 |
| 「**装备离队回收**」「**加装仅核心成员**」两条限制 | 🔴 **取消** —— 它们都是为防"人走了装备白费"，**人不会走所以前提消失**；现在**任何战斗人员都可加装** | 第6A类 §8.4 / §15 |
| 称呼「**杂役**」 | 🔴 **这个名称不存在** —— 从始至终只有「**后勤人员**」 | 第3A类 §4.5.1 · 第6A类 §8.1/§8.3 |
| 「**帮工**」 | 🔴 统一改为「**后勤人员**」 | 同上 |
| 车辆 = 「标准货车」+「单车」 | 🔴 **货车（小型 300 / 中型 600 / 大型 900）** + 🔴 **载人车（小型 / 大型）**；**初始 = 3 辆小型货车** | 第3A类 §4.5.5 · 第6A类 §11.1 |
| **联合商队**（2~5 支联合 / AI 同盟 / 战利品对分） | 🔴 **取消**（用户："这个设定不太好弄"） | 第3A类 §4.5.6 |
| 失败只有**两种**（士气归零 / 全队倒下） | 🔴 **三种** —— 加**手动撤退**（玩家主动认输，**代价明显更小**） | 第3A类 §5.1 |
| 撤退退到「**最近的安全点**」 | 🔴 退到「**出发时的安全点**」—— 沿途经过的城不作数（否则玩家会故意往坏地形冲，地图就没风险了） | 第3A类 §5.2 |
| 「**深处**」读起来像个地名 | 🔴 **改为描述性措辞**「后期最深灰区域 / 灰度最高处」+ 加注**不是地名**（`L1 = 750` 那个地方）；**设定与数值一个不动** | 第8A类 §1/§2/§4 |
| 🔴 **核心成员零工资的理由**曾写成"他们是商队本身、自己人" | 🔴 **不可信**（玩家不会因为"这是自己人"就不算这笔钱）→ 改为**机制性解释**：**"还没被雇佣"**（见下条） | 第3A类 §4.5.2 |
| 🔴 「不出战的人**留在城市里**」 | 🔴 **删掉这个状态** —— **商队走到哪人跟到哪**，**没有大本营 / 往返 / 传送**；不出战的人**还在车队上**，**构筑随时换回来、不需要重招** | 第3A类 §4.5.3 · 第6A类 §8.4 |
| 🔴 **牲畜系统**（每天饲料 1 份/头占车厢格 · 不喝水 · 种类载重/耐旱/稳定性差异 · 城市购买） | 🔴 **只作背景，不做系统** —— 无饲料 / 无水源 / 无耐力 / 无买卖 / 无疾病；**不进硬账**、不算编制、**不做提速轴**。保留的唯一意义是画面：「后末日商队用牲畜拉车」 | 第3A类 §4.5.4（**v4.1**）· 第2A类 §2 |
| 🔴 **「驼兽」**（动力轴来源之一） | 🔴 **改称「动力装置」** —— 驼兽本质是牲畜、牲畜系统不做；留着这个词会让人以为**牲畜能抬 `S`** = 凭空多一条提速轴 | 23 §2.2 · §5.4 |
| 🔴 「**驮畜**」当全集（"默认统一按驮畜处理"） | 🔴 **作废** —— 「牲畜」是类目（马/驴/驼），「驮畜」只是其中一类 | 第3A类 §4.5.4 |
| 🔴 「**购买牲畜**」是可交易项 | 🔴 **标为非可交易项** | 第2A类 §2 |

## 零之前、2026-10-05 批次（地图口径六条）

| 废弃旧口径 | 现行权威 | 权威来源 |
|---|---|---|
| 车轮档次 → 改每格消耗（标准 20 / 改良 16 / 精制 12） | 🔴 **整体作废** —— **速度恒定，每格恒 20 点、无任何提速手段**；只有天气 / 坏路况 / 超载 / 车况损坏让每格消耗**变高** | 第1A类 §2 / §5 / §5.1 |

| 补给耗尽只降血量**上限** | 🔴 **上限与当前血同步下降**（100/100 断食一天 → **90/90**；断水 → 80/80；皆零 → 70/70） | 第1A类 §5.2 · 第3A类 §1.6 |

| 信息等级 **0~5 档** | 🔴 **0~10 档**（等比加密 · 上限不变）：旧 5 档 ≡ 新 **0/2/4/6/8/10**；所有信源提升由 **+1 → +2** | 第1A类 §9.1~§9.6 · 第6A类 §9.1 |

## 三、攻击类型类废弃口径

| 废弃旧口径 | 新口径 | 废弃原因 | 影响范围 |
|-----------|--------|---------|---------|
| 破甲（作为正式术语） | 穿甲 | 术语统一，穿甲=无视护甲 | N2 战斗系统、第 6.1 类、所有战斗描述 |
| 拆解破甲 | 拆解穿甲 | 术语统一 | 修补师技能描述 |
| 破甲攻击 | 穿甲攻击 | 术语统一 | 攻击类型描述 |
| 破甲作为持续状态 | 穿甲是攻击类型，不是状态 | 穿甲是本次伤害结算时无视目标护甲，不是持续效果 | 状态系统设计 |

**穿甲定义：**
> 穿甲伤害无视护甲。穿甲不是削弱护甲，不是降低护甲，不是持续状态，是本次伤害结算时无视目标护甲。

**处理规则：**
- 后续所有正式资料中，不再使用"破甲"作为正式术语
- 旧文件中的"破甲"应改为"穿甲"或标注为旧名

## 四、状态机制类废弃口径

| 废弃旧口径 | 新口径 | 废弃原因 | 影响范围 |
|-----------|--------|---------|---------|
| 旧标记机制（2 层 +50%，3 层 +75%） | 标记可叠加次数，不叠倍率（每层都是 +25%，叠加触发次数） | 避免倍率爆炸 | 荒野射手技能设计、战斗平衡 |
| 标记无限叠倍率 | 标记层数代表可触发次数 | 控制伤害上限 | 所有涉及标记的技能 |
| 易伤状态 | 删除 | 与破甲、标记增伤定位重复 | N2 战斗系统 |
| 专注状态 | 删除 | 与标记、装填定位重复 | N2 战斗系统 |
| 万能净化 | 删除 | 净化只清灰蚀，避免修补师一个技能解决所有负面 | 修补师技能设计 |

**新标记机制：**
| 标记层数 | 效果 |
|---------:|------|
| 1 层 | 目标下一次受到我方直接伤害时，伤害 +25%，然后消耗 1 层 |
| 2 层 | 目标接下来两次受到我方直接伤害时，每次伤害 +25%，每次消耗 1 层 |
| 3 层 | 目标接下来三次受到我方直接伤害时，每次伤害 +25%，每次消耗 1 层 |

**明确禁止：**
- 2 层不是 +50%
- 3 层不是 +75%
- 标记不应无限叠倍率
- 标记层数代表可触发次数

## 八、使用规则

1. **本清单中列出的旧口径，后续开发不得再使用**
2. **如果旧文件中出现本清单列出的废弃口径，应：**
   - 标注【旧版本】或【历史参考】
   - 或移入 `90_历史版本归档/` 目录
   - 或直接替换为新口径（如果是明显错误）
3. **新开发的功能、技能、状态，必须使用新口径**
4. **如果不确定某个口径是否已废弃，查阅本清单或权威口径索引**
