## 一、🔴 为什么搬

| | 之前（外部目录） | 现在 |
|:--|:--|:--|
| 版本保护 | 🔴 **无** —— 写坏无法回退 | ✅ **跟着仓库走**，能回滚 |
| push 到 github | ❌ 不能（不是同一个仓库） | ✅ **能** |
| 文档 + 代码 | 🔴 两个地方，容易走散 | ✅ **同一个仓库** |
| 路径被搞坏的风险 | ⚠️ 桌面/同步软件可能弄坏 node_modules | ✅ 在仓库内，稳 |

## 二、🔴 你要做的搬家

```bash
# 1. 把代码目录整个搬进仓库（node_modules 建议不搬，重装更快更干净）
#    目标位置：游戏大纲\游戏本体\
#    要搬的东西：src\  package.json  vitest.config.ts  tsconfig.json
#                 基线_单元01开工前.txt

# 2. 在新目录重装依赖
cd 游戏大纲\游戏本体
npm install

# 3. 🔴 跑一次全量测试确认没丢东西
npx vitest run
```

### 🔴 搬的时候**不要**带这些

| 别搬 | 为什么 |
|:--|:--|
| 🔴 `node_modules/` | 🔴 重装更干净（避免平台/路径残留问题） |
| ⚠️ `ER0000.sl2` / `*.bak` / `ersave/` | 艾尔登法环存档，跟游戏无关 |

### 🔴 一定要带过来

| 必须带 | 为什么 |
|:--|:--|
| 🔴 **`基线_单元01开工前.txt`** | 那是判断"测试变红是我改坏的还是本来就红"的**唯一依据** |
| `src/b01/` | 你写的单元01 代码 |
| `package.json` / `vitest.config.ts` | 工程配置 |
