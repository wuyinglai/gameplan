## 2. 记忆 = 知识领域（Demo 实现口径）

### 2.1 基本规则

| 项 | 规则 |
|:--|:--|
| 名称 | 统一叫**记忆**，无"技能/技艺"名词 |
| 获得 | **完整获得**：要么拿到完整记忆，要么不获得；**不做碎片、不做熟练度、不做经验值** |
| 形态 | 记忆 = **知识领域**（化学 / 机械 / 草药 / 旧文明语 / 谈判 / 地形学……），**不是纯战斗技能** |
| 三卡 | **一个领域给三类卡**（见 2.2），一条记忆三种用 |
| 非战斗不耗体力 | 探索卡 / 跑商卡 = 被动加成或事件额外选项，**不消耗体力**；只有战斗卡才主动打出（接 17 §2） |

### 2.2 一个领域 → 三类卡

| 卡类 | 场景 | 形态 | 例子 |
|:--|:--|:--|:--|
| **战斗卡** | 战斗内 | 主动打出（占**起手 1 张记忆牌**的名额，见 17 §2） | 制毒、拆解、标记 |
| **探索卡** | 野外 / 事件 | 被动加成 或 事件额外选项（不耗体力） | 破译旧文明装置、配解毒剂 |
| **跑商卡** | 交易 / 讲价 | 被动加成 或 讲价选项（不耗体力） | 识破掺假货、地域行情判断 |

> 实现映射：战斗卡 → 17 的 `Card`（带 `cost`）；探索卡/跑商卡 → 事件与讲价的"额外选项钩子"（本文件 §8 事件接口同机制）。

### 2.3 领域槽位

| 阶段 | 可同时植入领域数 |
|:--|:--:|
| 初始 | **8 个** |
| 后期上限 | **15 个** |

- 实现：`Character` 增 `domains: list`（已植入领域），长度受 `DOMAIN_SLOTS_MAX` 约束。
- 每个领域提供自己的战斗卡池（战斗中从已植入领域里选 1 张记忆卡）。

### 2.4 领域理解标签（植入限制）

- 每个记忆有**领域标签**；角色有**领域理解标签**（来自职业 / 已植入领域）。
- **只有具备对应领域理解的角色才能植入该领域记忆**；不匹配则**无法植入**。
- Demo 简化：初始三人按职业给固定可理解领域（⚠️ 初值，可按实际战斗卡归属调整）：

| 角色 | 初始可理解领域 ⚠️ |
|:--|:--|
| 护路人 | 防护 / 地形学 / 机械 |
| 荒野射手 | 狩猎 / 草药 / 地形学 |
| 修补师 | 机械 / 草药 / 化学 |

> ⚠️ **待映射**：第6A类 §2~§4 的三人记忆表仍按旧「攻击/防御/辅助/消耗」分类，尚未归入知识领域。Demo 阶段**允许用"职业专属卡池"直接映射**（三人各 6 张动作卡 + 领域记忆卡），不阻塞开发；正式版再做领域重映射。

## 3. 零体力卡硬约束（全局核心约束，代码必须守）

> 与 17 §1 同一条红线，此处列出实现检查点。**任何新增记忆卡都要过这道检查。**

| 项目 | 规则 | 代码检查 |
|:--|:--|:--|
| 携带量 | 0 体力记忆**不占领域槽位**（⚠️ 但**仍占 1 个起手名额**，见 `04 §9.1`） | `cost==0` 不进 `domains` 计数 |
| 效果限制 | 只能**很弱**：轻度负面（挂 1 层标记）/ 轻度正面（少量护盾） | `value` 不超过弱阈值 ⚠️（伤=0，盾≤5） |
| ❌ 禁止 | 不能造成伤害 / 不能抽牌·产牌 / 不能挂强负面（灼烧、强迟滞） | 断言：`cost==0 → effect_type not in {attack, draw, burn, strong_slow}` |
| 推论 | **任何"抽牌 / 产牌"卡一律 > 0 体力** | 防止「0 体力产牌 + 低耗伤牌」无限循环 |

## 4. 记忆获取途径（设计红线 · 代码必须遵守）

> ⚠️ 记忆是**珍贵资源**。第6A类 §5.5：**严禁随机掉落，尤其禁止小怪掉落记忆。**

| 来源 | 是否产出记忆 | Demo 落地（⚠️初值） |
|:--|:--:|:--|
| **普通战斗胜利**（强盗 / 野兽 / 灰烬兽小股） | ❌ **绝不** | 只掉普通物资：零件 / 药包 / 货币 / 普通货；掉落表里**没有 memory 项** |
| **击败 Boss**（含遗迹 Boss、最终 Boss） | ✅ | 100% 掉 1 个记忆（主要战斗来源） |
| **搜索遗迹** | ✅ | **大遗迹**：搜索产出记忆 1~2 个；**小遗迹**：⚠️ 50% 概率产出 1 个 |
| **旧文明数据库 / 探索事件** | ✅ | 遗迹深处 / 灰烬城数据库事件，给稀有记忆 |
| **招募** | ✅ | 招募到的角色自带其记忆（接 13） |
| 记忆推演（§7） | — | 是**已有记忆的派生**，不改变"原始记忆从哪来"的红线 |

> **实现守卫**：战斗结算函数里，若掉落表出现 `memory` 类型，直接 `assert` 拦下（防止后续误加）。
> **原因**：记忆是旧文明知识领域的完整传承，衰败晚期极稀少；小怪随便掉 → 记忆贬值、成长失控，且背离"去废土里淘知识"的探索基调。

## 5. 记忆成长（成长核心 · **2026-09-24 重写**）

> 🔴 **整节重写。** 原 §5「数值升级 / 状态升级 / 火种升级」三小节 **全部作废** —— 那是**早于记忆系统改版**的老稿，且**火种词条概念已取消**（用户 2026-09-24 亲口定）。
> **权威口径见 `0A 第6A类 §5.4 + §6`**；本节只留 **Demo 要落地的东西**。

### 5.0 三层结构（先理解这个，代码才写得对）

| 层 | 是什么 | 例 |
|:--|:--|:--|
| **记忆（领域）** | **一门手艺 / 学科** | 「草药」「机械」「谈判」 |
| **用途** | 该领域下的**一件具体本事** | 「草药」下有：回血药 / 解毒药 / 驱兽剂 |
| **深度** | 挂在**单个用途**上的数值 | 回血药 **10 → 15** |

> 🔴 **玩家只看一个东西**：**这个领域里我会哪几件事、每件事多强。** 不需要算别的。
> **领域不是"卡包"** —— 它是"你会的一门本事"，一门本事下可以有好几件具体本事。

### 5.1 广度升级（解锁新用途）

**提升粒度 = 领域。一次升级 = 该领域 +1 个用途。**

- 例：「草药」原本只会做**回血药** → 广度升级后**学会做解毒药**。
- 新用途**从最弱档起步**，深度升级另行追。
- ⚠️ **每领域能解锁的用途数有上限**（不能无限广）—— 具体上限**待定**，先按"一层层开"实现即可。

### 5.2 深度升级（单个用途变强）

**提升粒度 = 用途 —— 🔴 逐项独立。**

| 规则 | 说明 |
|:--|:--|
| **逐项升** | 🔴 只升**点名的那个用途**：回血药 10 → 15 时，**解毒药不受任何影响** |
| **双向涨** | 同一用途**战斗里是卡 / 事件里是选项**（§2.2），深度升级**两边一起涨** |
| **纯数值** | 只改数字（伤害 / 层数 / 恢复量 / 成功率）；**机制变化归广度与推演** |
| ⚠️ **数值待定** | **每级加值 / 等级上限 / 成本递增曲线**全部 ⚠️ **待实测**（先定结构） |

### 5.3 Demo 落地

- 升级入口：城市（必有）/ 城镇（⚠️ 部分有）。**不做野外随地升级。**
- 每次升级消耗 **1 天 + 金币**（走日终结算，**不占体力**）。
- 数据结构：`Memory` 需含 `domain`（领域标签）、`uses`（用途列表），每个用途带 `depth`（该项深度）。**不再有 `numeric_level` / `status_level` / `fire_traits`。**

## 6. 记忆推演（保留 · 2026-09-24 补三条硬规则）

> **机制（2026-09-09 定，仍有效）**：旧"融合"（原记忆消失）→ 新"**推演**"（**原记忆保留**）。
> 定位：**用你能拿到的，换出你拿不到的。** 遗迹里找不到的记忆，可以靠手上已有的**推**出来。

### 6.1 消耗

| 项 | 规则 |
|:--|:--|
| 🔴 **素材记忆** | **不消耗、永久保留** —— **不是"以旧换新"**（6.2 规则 1） |
| 火种 | 每次推演消耗若干（⚠️ 初值 2~4 颗，待实测） |
| 金钱 | 推演费：**同标签 300 / 跨标签 500 金** ⚠️ **仅参考，非约束** |
| 设施 | 需**记忆设施**（城市；世界观见第7A类 §五 —— 损坏且简陋的旧机器） |

### 6.2 三条硬规则（🔴 代码必须实现）

| # | 规则 | 实现要求 |
|:--:|:--|:--|
| **1** | 🔴 **素材不消耗，永久保留** | 推演**只产不消耗** —— 推完素材照旧在角色身上。**禁止**把素材从 `Memory` 列表里删掉 |
| **2** | 🔴 **链长有限** | 组合表有限 → **推到头就推不动**（再也不产生新记忆）。**不做无限递归生成** |
| **3** | 🔴 **必须有线索** | 推演**不能盲试** —— 玩家要能**事先查到**"这几个记忆相合，能推出什么" |

> ⚠️ **链长的具体数字不是铁律**（用户原话"**我只是做个比喻**"）。上限由**标签组合表**天然决定，**不要硬编码一个数字**。

### 6.3 线索 = 标签组合表

**线索不是提示文本，是"哪几个标签能配出哪一个标签"的对照表。**

```js
// 组合表：输入标签集合 → 输出标签
COMBO = {
  "射击+标记": "精确射击",
  "制剂+解毒": "群体增益",
  // ...
}
```

**线索可见性分级**（⚠️ 提案，待实测）：

| 级别 | 玩家看到 |
|:--|:--|
| **基础** | 只有**已拿到**的记忆之间的组合可查 |
| **强化** | 遗迹 / 城市设施可**提前解锁**未持有记忆的组合线索 |

> 目的：**避免"盲试 → 失败 → 惩罚"的挫败感**（用户明确要求）。**多跑一趟遗迹，就多知道一条配方。**

### 6.4 领域标签约束

- 推演出的新记忆**同样带领域标签**，受 §2.4 植入限制约束。

### 6.5 Demo 落地（简化）

- 不做通用配方系统；提供 **2~3 条固定配方**做测试即可（⚠️ 例如：`射击+标记 → 精确射击`；`治疗+草药 → 灰烬治疗`）。
- 推演在**城市记忆设施**进行，消耗火种 + 金币，产出的新记忆自动加进推演角色。
- 🔴 **推演不吃升级**：素材上的深度升级**一律不丢失**（原记忆还在，升级也还在）。**旧的"继承升级点 + 重新分配"规则作废。**

## 8. 重伤系统

> 第6A类 §7。**角色不会永久死亡、不做永久伤残、不做不可逆惩罚。**

### 8.1 基本规则

| 项目 | 规则 |
|:--|:--|
| 生命归零 | 角色退出当前战斗，进入**重伤**状态 |
| 重伤后 | 该角色**不再出牌**（不再抽/选牌） |
| 休养期间 | **不能上场** |
| 战斗终止 | 🔴 **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）**，才触发强制撤退（见 17 §8 · `第3A类 §5`）—— 原"全部出战队员均重伤 + 货车耐久归零"已废（2026-10-12） |

### 8.2 重伤分级 🔴 **四级（2026-10-12 用户裁定）**

| 重伤次数 | 效果 | 恢复时间 |
|:--:|:--|:--:|
| 第 1 次 | 最大生命 **−10%** | 休养 **3 天** |
| 第 2 次（加重） | 最大生命 **−15%**（**累计 −25%**） | 休养 **4 天** |
| 第 3 次（加重） | 最大生命 **−25%**（**累计 −50%**） | 休养 **5 天** |
| 🔴 **第 4 次 = 严重重伤（全部失去战斗力）** | 🔴 **完全不能动 · 不能上场**，**只能到城市治疗**（野外没有任何手段能救） | 城市治疗 |

> ⚠️ **第二、三次显示名相同是有意的** —— 两者性质一致（都能动，只是更糟），差别在数值。
> ⚠️ **为什么第四次要单独一级**：前三次都能靠等待恢复（只是慢、要付代价），不构成"没救"；第四次才是真的动不了 —— 而它**不等于死**，是"活着，但站不起来"。
> 🔴 **术语**：原名「失能」已改名「**严重重伤**」（用户 2026-10-12 裁定：原名不好听、易误解为"要死了"）；第一次出现一律写成「**严重重伤（全部失去战斗力）**」。

### 8.3 恢复方式

| 方式 | 效果 |
|:--|:--|
| 自然休养 | 每天 +1 恢复进度，达到天数后自动恢复 —— 🔴 **只能恢复前三次** |
| 驿站 / 城镇 | 可**加速**重伤自然恢复，但**不能清除重伤次数、不能恢复最大生命惩罚** |
| 城市治疗 | 🔴 **唯一能治「严重重伤（全部失去战斗力）」的办法** —— 统一 **1 天 + 金币** |
| 补给耗尽 | 重伤恢复天数 **+1**（恶化，见 15） |

### 8.4 城市治疗价格 ⚠️

| 状态 | 价格 |
|:--|:--:|
| 第一次重伤 | 200 金 |
| 第二次重伤 | 350 金 |
| **严重重伤** | 500 金 |
| **整队严重重伤恢复上限** | 总成本 **不超过 500 金** |

> ⚠️ **第三次重伤没有单独报价** —— 它能自然休养恢复（5 天），不需要走城市治疗；权威表见 `第6A类 §7.4`（只有第一次 / 第二次 / 严重重伤三档）。
