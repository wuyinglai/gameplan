# 战斗卡牌分类与机制设计

## 一、设计目标

战斗系统以策略思考、行动决策和卡牌构筑为核心。玩家通过组合动作牌、配置记忆牌以及利用装备和特殊物品，形成不同的战斗方式。

1. 明确每种卡牌在战斗中的定位，避免不同系统承担重复职责。
2. 动作牌负责执行具体行为，记忆牌负责提供或改变战斗机制。
3. 不要求设计者预先设计所有可能的战斗行为与组合，允许玩家利用已有规则探索新的战术。
4. 让不同记忆配置产生不同的战斗逻辑，而不只是提供数值强化。
5. 鼓励玩家通过准备、积累、组合和资源投入获得更高收益，使认真构筑的玩家拥有更大的战术发挥空间。
6. 同一份知识可以在战斗、探索、贸易等不同场景中发挥作用，而不是仅服务于战斗系统。

## 二、卡牌的主要分类

### 1. 动作牌

**核心定位：执行具体行为，并产生相应的直接效果。** 动作牌回答：角色采取了什么行动？产生了什么结果？可以造成伤害、施加状态、获得防御、抽取卡牌、积累资源或执行其他特殊行为。不局限于攻击，也不要求每一种可执行的行为都制作成独立卡牌。

#### 1.1 武器招式
- **基础招式**：拥有相应武器就能执行的基本操作（砍击、刺击、横扫、基础格挡）。
- **特殊招式**：具有特定战术功能（缴械、打断、特殊攻防转换）；不一定复杂，可能跨武器通用。
- **复杂招式**：需要专门学习或训练（特殊剑术、复杂连招、武器套路）。特殊与复杂不一定互斥。

#### 1.2 准备与强化行为
- **基础准备与强化**：不需专门学习，具备物品和条件即可（给刀涂毒、使用现成药剂）。
- **特殊准备与强化**：需要特定知识、学习经历或前置（战前鼓舞、特殊强化方式、复杂战斗准备）。

⚠️ **不是所有基础行为都必须设计成独立卡牌**——给刀涂毒可由物品、时间和通用战斗规则决定，不一定需要专门的「涂毒」卡。

### 2. 记忆牌

**核心定位：提供知识，并引入或改变战斗机制。** 记忆牌不应只是动作牌的升级，也不应主要靠直接增加某张动作牌的伤害来体现价值。记忆牌回答：角色掌握了什么知识？这份知识使战斗中的哪些规则、效果或行为产生了变化？可以引入新机制、改变现有机制、让动作间产生新联动。例：防御值转伤害 / 满足条件自动触发 / 中毒提前一次性结算 / 资源转换 / 连续不同招式积累状态 / 改变行为限制成本收益。**作用是让玩家采用不同战斗策略、形成不同构筑体系。**

## 三、记忆牌的机制分类（五类 · 不要求每张记忆只属一类）

1. **效果转换型**：将已有数值/资源/状态转换成另一种效果（防御转伤害、剩余能量转蓄力、中毒层数转一次性伤害）。让独立资源产生新用途。
2. **条件触发型**：指定事件/条件发生时自动触发额外效果（格挡后获蓄力、敌人失衡后额外攻击、指定招式后回能量）。让玩家安排行动顺序主动创造触发。
3. **结算方式改变型**：改变结算时间/次数/顺序/计算方式（中毒提前全额触发、逐回合伤害一次结算、积累效果集中兑现）。
4. **累积与连锁型**：跨行动/回合积累的机制（持续准备积累势能、连续不同招式积累专注、积累交给终结招式兑现）。围绕持续运作机制构建战术。
5. **规则修改型**：改变行为的限制/收益/适用条件（耗防御代替能量、特定状态解锁平时不可用招式、准备行为特殊配合）。拓展可行行动方式。

## 四、卡牌的战斗职责（与卡牌类别是不同维度）

每张牌有**一个主要职责**，必要时可有次要职责：

| 战斗职责 | 主要作用 | 示例 |
|---|---|---|
| 直接输出 | 直接造成伤害 | 砍击、刺击、重击 |
| 防御与应对 | 降伤、抵挡、创造反击 | 格挡、卸力、反击 |
| 控制与破坏 | 影响敌人行动或防御 | 打断、缴械、制造失衡 |
| 准备与积累 | 产生后续收益的状态/资源 | 涂毒、蓄力、积攒势能 |
| 资源管理 | 获取/储存/转换/节省资源 | 能量储存、防御转化 |
| 机制与连锁 | 建立特殊规则使行为相互影响 | 毒素与失衡联动 |
| 终结与兑现 | 将积累转化为高额收益 | 消耗蓄力重击 |

职责不互斥，但应明确主要职责，方便设计与程序管理。

## 五、动作牌与记忆牌的关系

- 动作牌执行具体行为、按当前规则产生效果；记忆牌提供知识基础、引入或改变机制。
- 记忆牌可强化动作牌，但强化不是唯一作用。
- 动作牌没有特殊记忆也有基础效果；配置特定记忆后可能产生新效果或新用法。
- 多张记忆牌可共同构成一套机制，也可与不同动作牌组合成不同战术。
- 例：同一套「砍击/刺击/格挡/蓄力」基础行为——配蓄力记忆=准备爆发构筑；配防御反击记忆=格挡反击构筑。**基础动作相同、记忆配置不同 → 完全不同的战斗逻辑。**

## 六、准备、积累与伤害兑现机制

鼓励投入回合/能量/资源进行准备，在适当时机兑现高额伤害。一种值得探索的奖励方式是**指数或递增式成长**（示例非最终公式）：基础攻击 10 点 → 准备 1 回合 20 → 2 回合 40 → 3 回合 80 → 4 回合 160 → 5 回合 320。

核心意图：① 直接攻击=低但稳；② 投入准备=更高最终收益；③ 记忆牌可改变准备效率/积累方式/收益计算/终结效果；④ 不同准备行为+终结招式组合=不同爆发构筑。

**为避免准备越久必然越优，需明确准备过程中的成本与风险**：能量消耗、受到敌人攻击、准备被打断、维持状态的要求。**指数增长是可探索的构筑奖励机制，不要求所有攻击牌遵循同一增长规则。**

## 七、记忆与其他游戏场景

记忆牌代表角色掌握的知识，作用不限于战斗（毒理：战斗机制+探索识毒；动物学：战斗识敌+探索习性；机械：战斗装置+探索机关修理；医疗：战斗治疗+旅行处理伤势）。**记忆的统一性在于代表角色掌握的知识，而不是所有记忆都必须产生战斗增益。** 领域划分/获取方式/槽位/植入限制按知识与记忆系统整体规则另行规定（→ 6A §18 / §5.1）。

## 八、卡牌设计与程序实现要求

每张卡牌应有明确定义，建议至少记录：卡牌名称 / 卡牌类别 / 具体子类 / 主要战斗职责 / 执行方式（主动/持续/条件触发）/ 前置条件 / 行动成本 / 具体效果 / 触发条件 / 联动条件 / 持续与结束条件 / 获取来源。记忆牌还需明确引入或修改的机制（状态如何产生、积累、触发、结算、结束）。**并非每张卡都填所有字段，不适用的可留空，但涉及的规则必须明确。**

## 九、核心设计原则总结

① 动作牌执行行为、记忆牌提供/改变机制 ② 不要求每种行为都做成卡 ③ 武器招式与准备行为区分基础/特殊 ④ 记忆牌不能只做数值升级，要能引入新机制 ⑤ 职责与类别是不同维度，每张牌明确主职责 ⑥ 鼓励用已有规则自由组合，不穷举 ⑦ 准备积累有高额收益但必须有成本/风险/条件 ⑧ 知识与记忆同时服务战斗、探索、贸易等场景。
