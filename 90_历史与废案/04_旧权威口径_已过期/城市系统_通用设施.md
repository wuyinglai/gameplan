# 《余烬商队》城市系统 · 第一部分：通用设施

> 文档状态：草稿 v0.1
> 说明：每个城市都有的基础设施，各城差异详见后续部分。

---

## 一、通用设施总表

| 设施 | 功能 | 说明 |
|:----|:----|:------|
| **交易所** | 买卖货物、接订单、卖订单货物 | 城市经济中心 |
| **医馆** | 治疗角色、恢复重伤、买药包 | 可处理失能 |
| **工坊** | 修车、买零件、车辆升级、车辆改造 | 车辆相关全在这里 |
| **酒馆** | 提升士气、打听情报、招募新队员 | 信息集散地 |
| **驿站** | 补�的补给、收发消息 | 和野外驿站功能一致 |
| **记忆终端** | 记忆强化、记忆融合、查看记忆库 | 只有城市有 |
| **商会** | 余烬商会分会，声望相关 | 各城独立 |
| **市场** | 买普通装备、卖杂物 | 刷新随机 |
| **铁匠铺** | 买武器、防具、装备强化 | 工坊分出来的武装分支 |

---

## 二、各设施详情

### 交易所
- 购买补给、零件（量最大、价格最低）
- 接订单
- 售卖订单货物
- 城市经济核心指标

### 医馆
- 花钱恢复生命
- 恢复重伤/失能（只有城市能）
- 购买药包
- 不同类型城市的价格差异

### 工坊
- 修车（花钱恢复商队耐久）
- 买零件
- 买新车（小型/中型/大型）
- 车辆改造（扩容、负重、装甲）
- 加装配件

### 酒馆
- 消费提升士气
- 打听情报（路线风险、天气、特殊事件）
- 招募新队员（刷新随机）

### 驿站
- 出售补给（量少但便捷）
- 收发消息

### 记忆终端
- 查看已获得的记忆
- 金币强化记忆
- 火种强化记忆
- 记忆融合
- 只有城市有

### 商会（余烬商会分会）
- 各城独立声望
- 高声望解锁：更好价格、专属订单、稀有情报
- 商会任务
