# 支线系统设计方案 v2

> 状态：v0.2
> 说明：主线是主干，支线是旅途中的**长篇插曲**——不是一堆小任务，而是少数几条**长支线**（像小说的长篇章节）。
> 原则：分量感 > 数量。避免和订单系统重复。

---

## 一、定位

支线是主线故事中的插曲，作用：
- **丰富世界观**——通过长故事展示九城的人与事
- **给适当奖励**——钱、物品、声望、情报、线索
- **分量感**——玩家和NPC之间**发生了故事**，不是"NPC要求玩家干这干那"

---

## 二、长支线原则（核心！）

| 原则 | 说明 |
|:-----|:------|
| **数量少** | 支线不用很多——**重点做几条长支线** |
| **每条很长** | 一条支线可以贯穿**从游戏前期到很后期**（至少穿过两个幕） |
| **多类型混合** | 一条支线里可以包含多种内容：救人、纠纷、委托、探索…… |
| **不是跑腿** | 不是"帮NPC干这干那"——是有情节、有起承转合的故事 |
| **时间跨度** | 例如：第一幕遇到一个NPC → 第二幕再遇到 → 第三幕他的故事收尾 |

> 例：一条支线——你在灰原城遇到一个落魄商人的女儿，帮她找回被抢的货（救人/寻物）→ 过程中发现她父亲与枯林城猎首有旧怨（纠纷）→ 一路帮她到中圈 → 最后在第三幕她的故事迎来结局。贯穿多幕，混合多种类型。

---

## 三、自由原则（已定）

| 原则 | 说明 |
|:-----|:------|
| 大多数支线 | **无前置限制**——路上遇到就能接，想什么时候做都行 |
| 世界限制 | 部分支线需要条件解锁：主线做到某一步 / 点亮特定城市 |
| 不推主线也能玩 | 玩家可以只做支线，不做主线 |
| 非定死 | 支线推进跟随玩家正常发展，不强制按幕走 |

---

## 四、世界限制（少数支线）

| 限制类型 | 例子 |
|:---------|:-----|
| 主线进度 | "主线推进到第三幕"才解锁某支线的后续 |
| 城市点亮 | "激活黑石城节点"后，黑石城相关支线开放 |
| 位置 | 某些支线只在特定区域出现 |

> 目的：支线和世界进程联动——世界变了，故事才出现。

---

## 五、触发方式

| 触发 | 说明 |
|:-----|:-----|
| 路上遭遇 | 走格子时遇到（随机或固定点） |
| 酒馆传闻 | 酒馆里听人说起 |
| NPC求助 | 城市/驿站里有人主动求助 |
| 对话触发 | 和特定NPC聊出故事 |
| 支线连锁 | 一条支线的结尾引出另一条 |

---

## 六、支线类型（单条可混合）

| 类型 | 内容 |
|:-----|:-----|
| 救人 | 救被困/被劫/染病的人 |
| 寻物 | 找丢失/被偷的东西 |
| 纠纷 | 调解人或势力间的矛盾 |
| 委托 | 替人办一件事（护送遗物/传口信） |
| 探索 | 去某个地方看看/取东西 |
| 悬赏 | 讨伐指定目标 |

> 一条长支线可以横跨多个类型——救人引出纠纷，纠纷引出探索，探索引出悬赏。

---

## 七、难度曲线

| 项目 | 规则 |
|:-----|:------|
| 递增 | 长支线内部**难度递增**——前期支线轻松，后期支线有硬仗 |
| 节奏 | 跟随玩家成长，支线后期部分难度高于前期 |

## 八、支线结局与影响

| 项目 | 规则 |
|:-----|:------|
| **结局分支** | 支线可以有多种结局，玩家选择影响走向 |
| **影响主线结局** | 完成某些支线会**影响整个游戏的主线结局**——可能解锁不同结局（如灰烬共生结局需要特定支线铺垫） |
| **NPC命运** | 支线结束后NPC**可能还在**（变成老熟人），也可能**死掉**——取决于支线结局 |
| **世界影响** | 支线完成可能改变城市状态/商路/声望（后定） |

> 长支线不只是"小故事"——它们和主线结局挂钩，让玩家有动力去完成。

---

## 九、奖励

| 奖励 | 说明 |
|:-----|:------|
| 金币 | 常见 |
| 物品/装备 | 部分支线给好东西 |
| 声望 | 城市/商会声望 |
| 情报/线索 | 主线线索、遗迹位置 |
| 特殊 | 极少数支线给核心角色/特殊记忆（后定） |
