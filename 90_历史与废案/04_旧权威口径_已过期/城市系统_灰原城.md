# 城市系统：灰原城

> 文档状态：草稿 v0.2
> 九城区位：N1 灰原旷野
> 人口：约 10 万（参考）
> 联通：枯林城、鱼水城
> 定位：新手起点城，均衡型

---

## 一、概述

灰原城是大多数商队出发的地方，九城中位置最靠外的一座。什么都产一点，比较均衡，没有什么特别稀缺的东西。城墙用砾石和黏土夯筑，颜色和大地融为一体。

作为玩家到达的第一座城市，灰原城的设施最基础、最标准——让玩家在这里熟悉城市的使用方式。

---

## 二、初始状态

| 项目 | 状态 |
|:----|:------|
| 节点反应炉 | 未激活——需余烬核心激活 |
| 交易所 | 关闭——需激活节点后开放 |
| 医馆 | 关闭——需激活节点后开放 |
| 工坊 | 关闭——需激活节点后开放 |
| 酒馆 | 营业中（自发电/烛火），基本功能 |
| 驿站 | 营业中（基本通信和补给） |
| 记忆终端 | 无——灰原城没有记忆终端 |
| 余烬商会 | 有分会，初始声望 0 |

**激活节点反应炉后解锁：** 交易所、医馆、工坊
**后续条件解锁：** 无（灰原城没有特殊设施）

## 四、灰原城没有的特殊设施

灰原城是**基础型城市**，没有特殊设施。它的作用是让玩家：
1. 熟悉城市的基本操作流程
2. 完成最初的新手订单
3. 前往枯林城或鱼水城
