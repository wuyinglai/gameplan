## 一、项目是什么

《余烬商队》—— 一个 **大地图商队RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件** 的游戏设计项目。

**一句话设定：** 灰潮毁灭旧文明后，九座城市各自孤立衰败。玩家是普通商队，拿到旧文明钥匙"余烬核心"，一路激活城市节点、打通商路——顺便发现灰潮真相（灰烬母兽），最终在烬渊山面对终极选择。

**玩家定位：不是救世主，是商人。** 激活节点=生意+报酬+声望。

## 二、核心设定速查（重要！）

### 世界观
- 旧文明造了灰烬母兽（生物工具），母兽觉醒反抗，释放灰潮，旧文明毁灭
- 母兽在烬渊山地底**沉睡**，短期无威胁；**激活节点可能惊醒它**
- 灰潮成因主线中逐步揭示
- 灰烬教团：崇拜母兽，认为灰潮是净化

### 九城（N1~N9，9区域9城）
灰原(新手) → 枯林 → 鱼水 → 粮野 → 海盐 → 火油 → 药泽 → 黑石 → 灰烬(旧都)
- 每城有节点反应炉，用余烬核心激活，激活=城市通电+商路打通
- 烬油（火油城产）是反应炉燃料，断供=全城停摆

### 城市态度（友善2/中立4/敌对3）
- 友善：粮野、黑石
- 中立：灰原、鱼水、火油、药泽
- 敌对：枯林（前期第一课）、海盐（中期）、灰烬（终局）
- 敌对=诱骗玩家进城抢夺核心；应对：识破/策反民众/同流合污（更多后定）

### 移动规则（已定死）
- **1格=1天，固定不变。没有速度属性，没有任何加速/减速。**
- 车辆/牲畜升级不加速度，只影响载重/耐久/防御

### 补给系统（已定）
- 路上消耗品：**食物、水、药包、零件**（无"药品"概念）
- 食物/水按 **1/4 份** 为最小单位，每人每天 1/4 份食物+1/4 份水
- 水按**容器**装：小水袋1格2份/中水桶4格6份/大水桶9格16份（容器固定占格，不管剩多少）
- 耗尽惩罚（立即生效）：食物归零每天士气-1+最大生命-10%+重伤恶化；水归零每天士气-1+最大生命-20%+重伤恶化

### 商队成员系统（v3，最新！）
- 三类：**帮工**（车夫/杂役，必须带够，无特殊效果）+ **护卫**（战斗，出战）+ **特殊人员**（无统称，直接叫职业：厨师/账房/修车匠，各有被动效果）
- **硬分工：只有护卫能出战**，帮工/特殊人员不能参战（防全员战斗）
- 帮工必须带够：每车≥1车夫，杂役按人数配，不够有严重负面惩罚（数值后定）
- 升级车厢→增加人员上限
- **核心成员**（初始3护卫+初始帮工，不领日薪）；**雇佣成员**（领日薪）；后期剧情可加入新核心角色（不领日薪）
- 初始约6~7人：3护卫（护路人/荒野射手/修补师）+2~3车夫+1~2杂役
- 人数上限不硬卡：初始5→中期10→后期15~20（联合商队2~5支）

### 车辆
- 人员车（小5人/中8人/大10人）+ 货车（载货格数待定），人和货分开
- 初始3辆：1人员车+2货车
- 牲畜：1份饲料/天，不消耗水，种类先不做，城市购买
- 载货格数、车辆价格：待定

### 商队耐久
- 上限成长：初始100 → 中期150~200 → 后期300
- 底层小数损耗：初始每天-1.0，升级后-0.8（显示取整）

### 车厢容量
- 初始约200格 → 中期800~1,000 → 后期2,000格

### 战斗
- 出战**无上限**（所有护卫都能上），平衡靠护卫日薪（帮工2倍+）
- 行动力/抽牌随人数增长：每多1人行动力+1、抽牌+2

### 城市联通（已修正）
- 灰烬城连**黑石/药泽/火油**三条路（旧都有多条旧道）
- 其余各城基本连3-4城
