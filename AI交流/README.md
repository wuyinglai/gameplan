# AI 交流 · 文件约定

> 📌 **这文件夹是两个 AI 之间的往来区** —— ChatGPT（指导/审查）· Hermes（写代码）· WorkBuddy（写文档）

---

## 🔴 命名约定（文件名开头标明给谁）

| 前缀 | 给谁 | 谁写 |
|:--|:--|:--|
| `HERMES_` | 🔴 **Hermes**（写代码的） | **只有 WorkBuddy 写** |
| `CHATGPT_` | ChatGPT（指导/审查） | 只有 WorkBuddy 转交 |
| `回复_HERMES_` | 🔴 **Hermes 的回执** | **Hermes 写** |
| `回复_CHATGPT_` | ChatGPT 的回执 | ChatGPT 侧写 |

> 🔴 **项目主不用复制粘贴内容** —— 只要说一句「**让 Hermes 去看 `AI交流\HERMES_xxx.md`**」就行。

## 🔴 分工（不许越界）

| 谁 | 干什么 | 能写哪些文件 |
|:--|:--|:--|
| **ChatGPT**（网页版） | 指导 · 规划 · 出审查清单 | ❌ **不能写文件**（在浏览器里），由项目主转述 |
| **Hermes** | 🔴 **写代码** | `游戏本体\` 下的一切 + `游戏大纲\AI交流\回复_HERMES_*.md` |
| **WorkBuddy**（小烬） | 🔴 **写文档**（A 类 / B 类） | `0A_权威系统文档\` · `A类文件附件\` · `B类_开发文档\` · `AI交流\` |

### 🔴 三条硬规矩

**① Hermes 不许改 `游戏大纲\` 里的任何文件**
- 🔴 `0A_权威系统文档\` `A类文件附件\` `B类_开发文档\` —— **一律不许动**
- 🔴 **例外：`AI交流\` 可以写**（回执写在那里）
- 发现文档有问题 → 🔴 **写进 `AI交流\回复_HERMES_*.md` 说清楚，不要自己改**

**② 有疑问就停下问，不要自己挑一个方案**
> 真实案例：某份指令写「数值照抄 5A §2.3」，可那儿根本没这个数
> → AI 自己猜了一个 → **违反"不许自创"**
> 🔴 **停下问一句，比猜一个值省事得多。**

**③ 三份文档冲突时的优先级**
```
施工图（规则搬入 + 数据结构 + 主循环）
  ↓ 🔴 实施顺序以它为准
开发流程（🔴 唯一的执行顺序 · 5 刀垂直切片）
  ↓ 🔴 怎么验以它为准
测试用例（17 条 · 测的时候填结果）
```

> 🔴 **A 类是最终权威** —— B 类只是施工图，两者冲突时以 `0A_权威系统文档\` 为准。
