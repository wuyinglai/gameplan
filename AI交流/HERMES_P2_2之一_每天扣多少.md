## 1. 🔴 规则依据（A 类原文，🔴 不许自创）

| # | 规则 | 出处 |
|:-:|:--|:--|
| 1 | 🔴 **每人每天 = 1 份食物 + 1 份清水** | `3A:65` 🔴 **2026-10-13 用户亲口定** |
| 2 | 🔴 **14 人 = 14 份食物 + 14 份清水/天** | `3A:89` |
| 3 | 🔴 **消耗只按「出战人数」算** | `3A:85` |
| 4 | 🔴 **🔴🔴 两种资源永远分开写，禁止合并成「28 份」** | `3A:93` 🔴 **表述铁律** |

🔴 **`3A:89` 的原表**：

| 出战人数 | 每天食物 | 每天清水 |
|:--:|:--:|:--:|
| 3 人（初始出战基准） | 3 份 | 3 份 |
| 每 +1 名出战 | +1 份 | +1 份 |

> 🔴 **规则 6 的理由**（`3A:97` 原文）：「口粮他们自己买、工钱他们不领 ——
> 🔴 **因为还没被雇佣**（雇佣 = 建立关系 = 领工资 + 吃商队的粮）」

## 2. 🔴 本步只做一件事：**每天要扣多少 + 扣掉**

### 2.1 文件（🔴 1 个）

`游戏本体/src/p2/消耗补给.ts`

### 2.2 🔴 完整代码（照抄能写）

```typescript
// 🔴 src/p2/消耗补给.ts —— P2 第 2 步之一
//
// 🔴 规则依据：3A:65 / 3A:85 / 3A:89 / 3A:93 / 3A:97
// 🔴 本文件只做「算要多少」+「扣掉」两件事。
// 🔴 🔴 它不碰断粮惩罚（那是之三）· 不碰跨日 · 不碰士气 · 不碰血量。

import type { 商队状态 } from './资源';

// ============================================================================
// 🔴 要扣多少
// ============================================================================

/**
 * 每人每天 1 份食物 + 1 份清水。
 * 🔴 出处：3A:65（2026-10-13 用户亲口定）· 3A:89 的表
 *
 * 🔴🔴 返回值必须是两个字段，不许合并成一个总数。
 * 🔴 出处：3A:93「🔴 表述铁律：两种资源永远分开写，🔴 **禁止合并成「28 份」这类总数**」
 */
export function 每日消耗(出战人数: number): { 食物: number; 清水: number } {
  return { 食物: 出战人数, 清水: 出战人数 };
}

// ============================================================================
// 🔴 扣掉
// ============================================================================

export interface 扣补给结果 {
  /** 🔴 实际扣掉几份 —— 可能比要扣的少（不够的时候） */
  扣了多少食物: number;
  扣了多少清水: number;
  /** 🔴 扣完之后是 0 —— 🔴 本步**只报告**，🔴 不触发任何惩罚 */
  食物耗尽: boolean;
  清水耗尽: boolean;
}

/**
 * 从状态里扣掉今天要吃的。
 *
 * 🔴🔴 扣到 0 为止，**不许扣成负数** —— Math.max(0, ...)。
 * 🔴 🔴 本函数**不碰士气、不碰血量、不判断该不该受罚** —— 那是之二的事。
 */
export function 扣补给(状态: 商队状态): 扣补给结果 {
  const 要扣 = 每日消耗(状态.出战人数);
  const 原食物 = 状态.资源.食物;
  const 原清水 = 状态.资源.清水;

  状态.资源.食物 = Math.max(0, 原食物 - 要扣.食物);
  状态.资源.清水 = Math.max(0, 原清水 - 要扣.清水);

  return {
    扣了多少食物: 原食物 - 状态.资源.食物,
    扣了多少清水: 原清水 - 状态.资源.清水,
    食物耗尽: 状态.资源.食物 === 0,
    清水耗尽: 状态.资源.清水 === 0,
  };
}

// ============================================================================
// 🔴 描述 —— 给你自己看状态用
// ============================================================================

export function 描述补给(标签: string, 状态: 商队状态): string {
  const 要 = 每日消耗(状态.出战人数);
  return [
    `${标签}`,
    `  出战 ${状态.出战人数} 人 · 每天要 ${要.食物} 份食物 + ${要.清水} 份清水`,
    `  现有：食物 ${状态.资源.食物} 份 · 清水 ${状态.资源.清水} 份 · 士气 ${状态.资源.士气}`,
    `  ${状态.资源.食物 === 0 ? '🔴 食物 = 0' : '✅ 有食物'}`,
    `  ${状态.资源.清水 === 0 ? '🔴 清水 = 0' : '✅ 有清水'}`,
  ].join('\n');
}
```

## 3. 🔴 判据（8 条）

| # | 做什么 | 期望 |
|:-:|:--|:--|
| 1 | `每日消耗(14)` | `{ 食物: 14, 清水: 14 }` |
| 2 | `每日消耗(3)` | `{ 食物: 3, 清水: 3 }` |
| 3 | 🔴 **返回值不许有第三个字段** | 🔴 `Object.keys(每日消耗(14))` 🔴 **正好两个** |
| 4 | 14 人 · 食物 30 · 扣一次 | 剩 **16** 份 |
| 5 | 同上 · 清水 30 · 扣一次 | 剩 **16** 份 |
| 6 | 🔴 **食物 10 份 · 14 人** | 剩 **0** · 🔴 **不许是负数** |
| 7 | 🔴 **清水 10 份 · 14 人** | 剩 **0** · 🔴 不许负数 |
| 8 | 🔴 **扣完为 0 时，士气不许变** | 🔴 **本步不碰士气** —— 🔴 断粮惩罚是之二 |

### 🔴 判据 3 和 5 展开（这两条是 A 类铁律，🔴 最容易违反）

**判据 3** —— 返回对象的形状：

```typescript
// ✅ 对：两个字段
return { 食物: 出战人数, 清水: 出战人数 };

// 🔴 错：3A:93 明写「禁止合并成 28 份这类总数」
return { 总份数: 出战人数 * 2 };
```

**判据 5** —— 测试写法：

```typescript
// ✅ 对：两行分开断言
expect(状态.资源.食物).toBe(16);
expect(状态.资源.清水).toBe(16);

// 🔴 错：这行看着在测两样，实际只测了一样
expect(状态.资源.食物).toBe(状态.资源.清水);
```

### 🔴 判据 8 展开（「本步不碰士气」怎么查）
