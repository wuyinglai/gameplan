### 3.2 地图文件怎么读 🔴 这条有个坑

🔴 **地图 json 的唯一数据源**在：
```
B类_开发文档\基础文档\测试地图_v0.7\地图.json
```
🔴 **但 `游戏本体\src\p1\` 在它外面**，🔴 `../../B类_开发文档/...` 这种相对路径 **vitest 能读，tsc 会报模块找不到**。

🔴 **正确做法**：**把 json 复制到 `src/p1/地图.json`，并在文件头注明来源**。

```bash
# 🔴 这一步要跑，跑完 md5 要一致
cp "B类_开发文档\基础文档\测试地图_v0.7\地图.json" "游戏本体\src\p1\地图.json"
```

🔴 **跑法**（项目主已在根目录备好脚本）：
```
node 工具\地图同步.mjs --check
```
🔴 **退出码 0 = 两份一致**；🔴 非 0 = 不一致，**停下报告**。

🔴 **两份 json 的分工**（🔴 别搞混）：
| 位置 | 作用 |
|:--|:--|
| `基础文档\...\地图.json` | 🔴 **唯一数据源** · 项目主改地图改这里 |
| `游戏本体\src\p1\地图.json` | 🔴 **代码读的那份副本** · 🔴 由脚本同步，🔴 **不许手改** |

🔴 同步脚本 🔴 **本机之前有 bug**（`execSync` 跑带管道的命令会卡死）。
🔴 **如果 `node 工具\地图同步.mjs` 卡住不动 → 停下报告**，🔴 不要自己写个 cp 脚本绕过去。

### 3.3 读取 json 的方式 🔴 必须用 import，不是 readFileSync

```typescript
// ✅ 正确

// ❌ 错（tsc 会报 TS2307 —— tsconfig 的 types 里没有 node）

```
🔴 **这条旧代码踩过**（10-19 我自己踩的）—— 🔴 `tsc` 报 `Cannot find module 'node:fs'`。

### 3.4 json 的实际结构（🔴 实测过，不许猜）

```json
{
  "map": { "width": 400, "height": 400 },
  "start": [10, 199],
  "end": [390, 389],
  "note": "...",
  "locations": [ { "t": "big", "x": 10, "y": 199 }, ... ]   // 41,131 条
}
```

🔴 **`start` / `end` 是数组不是对象** —— `[10, 199]` 不是 `{x:10, y:199}`。
🔴 **加载时要转**：`起点 = { x: raw.start[0], y: raw.start[1] }`。

🔴 **`locations` 里每条只有 4 个字段**：`t` · `x` · `y` · `r`（`r` 可能没有）

🔴 **实测的类型分布与路况分布**（🔴 用来写断言，不是让你硬编码）：

| `t` | 含义 | 格数 | `r` |
|:--|:--|--:|:--|
| `big` | 大城 | 1 | 无 |
| `small` | 小城 | 3 | 无 |
| `town` | 城镇 | 18 | 无 |
| `village` | 村庄 | 41 | 无 |
| `inn1` | 驿站 | 34 | 无 |
| `special` | 🔴 映射成营地（见施工图 §6.4） | 10 | 无 |
| `road` | 商路 → 空地 | **4,840** | 🔴 **r=0 2,886 / r=2 1,954** |
| `blk_fr` | 可通行地形（桥/碎石） | 1,464 | 🔴 **r=2 1,255 / 无 209** |
| `block` | 🔴 **不可通行**（山/裂谷） | **32,823** | 无 |
| `blk_wt` | 🔴 **不可通行**（水/河） | **1,897** | 无 |

> 🔴 **`road` 里有 1,954 格标了 `r=2`（差路况）** —— 🔴 这是**数据疑点**（见施工图 §6.5），
> 🔴 **你不要"修正"它**，🔴 照实读，写进回执的「已知问题」。

## 6. 🔴 一条不许踩的坑（🔴 旧代码踩过）

**跨日只能有一个入口。**

```
主循环调 结算.跨日()  ✅
主循环自己也回体力   ❌  → 一天回两份（+100 而不是 +50）
```

🔴 旧代码实测过这个 bug：走 3 格剩 55 → 结束当天 → 第 2 天体力
🔴 应该是 `min(100, 55+50) = 100`，🔴 实际拿到过 **110**。

🔴 **怎么防**：🔴 `第几天` 和 `当前小时` 🔴 **只有 `结算.跨日()` 能改**，
🔴 其余任何文件碰这两个字段都是 bug。🔴 判据 §23 就是抓这个。
