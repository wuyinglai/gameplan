## 六、🔴 你问的那个结构问题，我定了

> `游戏状态.地图: Map<string, 格子>` 和你 `加载地图()` 返回的 `{宽,高,起点,终点,格子表}` **接不上**

**裁定**：🔴 **状态里改成 `地图: 地图对象`**，新增类型：

```typescript
export interface 地图对象 {
  宽: number;
  高: number;
  起点: { x: number; y: number };
  终点: { x: number; y: number };
  格子表: Map<string, 格子>;      // key = `${x},${y}`
}
```

> 🔴 理由：**尺寸和起终点是必需的，但裸 Map 装不下** —— 你的函数返回的字段一个都不能删。
> 🔴 `当前坐标` 另存，所以 `地图对象` 里的格子表就是全图数据。
