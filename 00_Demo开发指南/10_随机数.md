# 10 · 随机数（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 10/11 份
> 用途：定义**随机数系统**。核心诉求：封装 `random`、可设种子、**同种子可复现**（用户强调「数值一定要测了才知道」，复现是对比不同数值的前提）。
> 口径：纯 Python 标准库 `random` 模块。

---

## 1. RNG 封装（core/rng.py）

```python
import random

class RNG:
    def __init__(self, seed=None):
        self.seed = seed if seed is not None else random.randrange(2**32)
        self._r = random.Random(self.seed)

    def randint(self, a, b):       # 含端点
        return self._r.randint(a, b)

    def uniform(self, a, b):
        return self._r.uniform(a, b)

    def choice(self, seq):         # 空序列返回 None（对接文档 09 §6）
        return self._r.choice(seq) if seq else None

    def choices(self, seq, k=1):   # 可重复抽取
        return self._r.choices(seq, k=k) if seq else []

    def chance(self, p):           # p 为 0~1 概率
        return self._r.random() < p

    def shuffle(self, seq):
        self._r.shuffle(seq)
```

> **不用全局 `random`**：所有随机走 `RNG` 实例，保证种子可控、可复现。

---

## 2. 种子策略

- **默认（正式试玩）**：`seed=None` → 用系统熵随机（每局不同，正常玩有新鲜感）。
- **调试 / 测数值（关键）**：`python main.py --seed 12345` → 固定种子，同种子同局完全复现。
- 种子在 `main.py` 启动时创建一次 `RNG` 实例，传给所有模块（文档 06 §5），**不在子模块里新建 `Random`**。

```python
# main.py
import argparse
parser.add_argument("--seed", type=int, default=None)
args = parser.parse_args()
rng = RNG(seed=args.seed)
```

---

## 3. 可复现的意义（为什么重要）

用户原话：「数值一定要测了才知道对不对。」要科学测数值必须能**控制变量**：

- 同种子跑 A 套数值 → 记录结果（天数/金钱/战斗/通关率）。
- 同种子换 B 套数值 → 再跑 → 对比，才能判断「哪套更好玩/更平衡」。
- 若随机不可复现，两次跑的差异混入了随机噪声，无法归因到数值改动。

> 因此：**所有影响玩法结果的随机必须走同一个 `RNG` 实例**。日志里打印 `seed`（文档 11），方便复现某局。

---

## 5. 注意事项

- **不混用多个 Random 实例**：否则种子失效、不可复现。
- **不在循环外缓存 `random.random()` 结果**用于关键判定。
- **日志打印 seed**（文档 11）：`[init] seed=12345`，复现某局直接 `--seed 12345`。
- 概率 `p` 非法（<0 或 >1）时 `chance` 应 clamp，防 `random() < p` 永远真/假（对接文档 09 §6）。
