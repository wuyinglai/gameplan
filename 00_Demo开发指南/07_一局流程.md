# 07 · 一局流程（场景切换与胜负）

> 《余烬商队》Demo 程序编写指导 · **工程轨（施工图）**
> **只管两件事**：① 一局里**场景怎么切**（标题 ↔ 地图 ↔ 地点 ↔ 交易 ↔ 战斗 ↔ 结算）；② **什么时候算通关 / 撤退 / 退出**（**没有"输"这一档**，见 §4）。
> **不管**：走一格与每日结算（→ `15`）、野外掷骰遭遇怎么算（→ `19`）、Boss 怎么打（→ `21`）、每局观测指标（→ `22`）。
> 本文件**不含任何玩法数值**，只负责把各系统串成一条能跑完的线。

---

## 1. 顶层状态机

```
TITLE ──开始──▶ MAP ──踩到地点──▶ LOCATION ──出发──▶ MAP
                 ▲                     │
                 │                     ├─交易/接单────▶ TRADE ──▶ LOCATION
                 │                     ├─挑战灰烬─────▶ (见 20：Boss → RESULT)
                 │                     └─招募/改造/休整─▶ LOCATION
                 │
        ┌────────┴─────────┐
        │  移动中按 18 掷骰  │
        ▼        ▼         ▼
      EVENT   COMBAT   ASH_CONTACT      # 灰兽接触
        │        │         │
        └────────┴────┬────┘
                      ▼
              MAP（继续 / 撤退后回最近安全点） / RESULT（只有通关才进）
```

- 场景枚举（字符串常量）：`"title"` / `"map"` / `"location"` / `"trade"` / `"combat"` / `"event"` / `"ash_contact"` / `"result"`。
- `"event"` / `"combat"` / `"ash_contact"` 三者**只由地图移动过程进入**，内容规则见 `19`（怎么掷）/ `17`（怎么打）。
- 本文件只规定「谁在什么时候把场景切给谁」，不规定被切入的场景内部怎么算。

---

## 2. 主循环骨架（main.py / loop）

```python
def loop(state, cfg, rng, log, ui):
    scene = "map"                      # 开局即在大城，首轮进入 location 也可
    while state.outcome == "":         # 空 = 进行中；只有 "win"（通关）会退出
        if   scene == "map":         scene = run_map(state, cfg, rng, log, ui)
        elif scene == "location":    scene = run_location(state, cfg, rng, log, ui)
        elif scene == "trade":       scene = run_trade(state, cfg, rng, log, ui)
        elif scene == "event":       scene = run_event(state, cfg, rng, log, ui)
        elif scene == "combat":      scene = run_combat(state, cfg, rng, log, ui)
        elif scene == "ash_contact": scene = run_ash_contact(state, cfg, rng, log, ui)
        # RESULT 由战斗 / Boss 直接设 outcome 后跳出循环
    ui.show_result(state)              # 结算界面（见 `02` 功能清单）
```

> 每个 `run_*` 函数**返回下一个场景名**（字符串）。主循环本身不做任何判定，只按返回值切换。

---

## 3. 场景切换规则（每个场景返回什么）

| 场景 | 进入前先做什么 | 内部能做的事 | 可能返回 |
|:--|:--|:--|:--|
| `map` | — | 走一格、看状态、看地图、看帮助 | `location`（踩到地点）/ `event`·`combat`·`ash_contact`（移动中按 `19` 掷中）/ `map`（原地操作；**强制撤退后也回这里**） |
| `location` | — | 地点菜单（买卖、接单、招募、休整、修车） | `trade` / `map`（出发）/ `location`（留在原地）/ `combat`（攒够后挑战灰烬转 Boss，见 `21`） |
| `trade` | — | 买卖、讲价、接单 | `location`（退出交易） |
| `event` | — | 显示事件与选项 | `map` |
| `combat` | 由移动或挑战灰烬触发 | 卡牌战斗（规则见 `17`） | `map`（战斗结束；**若触发强制撤退，先退回最近安全点再回 `map`**）/ `result`（击败最终 Boss，置 `outcome="win"`） |
| `ash_contact` | — | 灰兽接触：**按态度给选项**（友善 / 中立可离开，敌对只能打，见 `03 §8`） | `map` / `combat` |
| `result` | 由 `outcome` 决定 | 显示结局摘要 | 结束进程（一局制） |

> **`map` 场景内部不做日终结算**：走一格只扣体力，日终结算在体力耗尽 / 主动休整时触发，规则见 `15`。

---

## 4. 胜负与退出

`state.outcome` 是唯一的结束开关：`""` = 进行中，`"win"` = 通关结束。**没有 `"lose"`。**

| 结果 | 触发条件 | 处理 |
|:--|:--|:--|
| **通关** | 攒够本钱后直接挑战灰烬（最终战）、击败即通关（规则见 `21`） | `outcome="win"` → `show_result` |
| **强制撤退** | 士气归零 / 全队倒下且耐久归零（判定规则见 `15` §8） | **不改 `outcome`**：位置退回**最近的安全点**、按 `15 §8.3` 结算损失，然后**回到 `map` 继续这一局** |
| **手动退出** | 玩家返回标题或 `Ctrl+C` | 直接退出进程（一局制，无存档） |

- **本版没有"失败结局"**（用户 2026-09-12，0A 第3A类 §5 同口径）：打不过只是**赔掉这一趟**——货和补给没了、人被送回安全点，**这一局继续**。
- **不设**"时间结局 / 天数上限"（那属正式版参考，本版不机械触发）。
- **防死循环**：玩家长期待在城里不移动属正常（`day` 不推进）；若某场景函数意外无限递归，靠代码审查 + 日志发现（见 `11`）。
- 玩家也可以一直跑商、不碰最终战；那 `outcome` 永远不会是 `win`，靠手动退出结束（本版以"攒够 → 打灰烬"为通关测试动作）。
