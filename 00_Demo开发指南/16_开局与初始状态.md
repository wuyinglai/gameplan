## 5. 裁决：单车 / 载人车**不计耐久**（AI 建议，已按此落地）

**问题**：多出来的那辆单车，要不要也算耐久？

**结论：不算。只有货车计耐久。**

**理由（按重要性排）：**

| # | 理由 |
|:--:|:-----|
| 1 | **耐久这个机制的全部意义是"威胁货物运力"**。货车抛锚 = 货装不下、拉不走，玩家必须做决定（修 / 丢货 / 绕路）。载人车不拉货，抛锚了人下车走路就行，**不产生任何玩法后果**——那它就是一根掉了也无所谓的血条。 |
| 2 | **玩家没有手段管它**。战斗里的护车牌全是"**货车**获得护盾"（迎击 / 稳住阵线 / 车队防护 / 车体修理）。给载人车加耐久，等于让它白白掉血、玩家却出不了牌干预——**能坏但救不了，这是坏手感**。 |
| 3 | **会牵动整套经济数值**。0A §2.3 的"60 天远行 ≈ 435 耐久"、零件/修理经济，全是按 3 车 × 60 = 180 算的。加一辆变 240，`04` / `15` / 修理价格都要跟着重算——为一个没有后果的血条，不值。 |
| 4 | **Demo 目标是验证跑商循环**，多一条不影响任何决策的数值，只是噪音。 |

**因此：**

- 0A 第3A类 §2 耐久上限 **3 车 × 60 = 180 保持不变**；§3 货容 **900 格不变**。
- ✅ **0A 第3A类 §3 / §4.5.5 已回写（2026-09-14）**：由"初始 3 辆标准货车、无单独运人车"改为「**初始 4 辆 = 3 辆货车 + 1 辆单车；单车不拉货、不计耐久**」。第6A类 §11 车辆系统（v2.2）同步重写。
- 载人车**在战斗中不被攻击、不吃护盾、不抛锚**（抽象为"随车人员的一部分"）。
- ⚠️ 待定：如果以后想给载人车一点存在感，可以走**事件**（如"车轴断了，队伍今天少走 1 格"），而不是耐久条——**本版不做**。
