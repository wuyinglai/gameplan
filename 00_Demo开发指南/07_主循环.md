# 07 · 主循环（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 7/11 份
> 用途：定义**顶层状态机 + 每日结算顺序 + 移动判定 + 激活→boss→结算**。AI 照此实现主循环，不漏每日结算、不卡死。
> 口径：2026-09-07 裁定——无剧情、200×200、3 城、一局制、纯测好玩与数值。

---

## 1. 顶层状态机

```
TITLE ──开始──▶ MAP ──进入地点──▶ LOCATION ──出发──▶ MAP
                  │                     │
                  │ 野外格移动结算        ├─交易/接单──▶ TRADE ──▶ LOCATION
                  ▼                     ├─激活节点────▶ (触发 BOSS)
              （掷骰事件）              └─招募/改造/休整─▶ LOCATION
                  │
          ┌───────┼───────────┐
          ▼       ▼           ▼
       EVENT    COMBAT      ASH_CONTACT
          │       │           │
          └───────┼───────────┘
                  ▼
                MAP（继续） / RESULT（结算）

BOSS（灰烬兽最终战，激活节点后）──胜──▶ RESULT(win)
                                └─败──▶ RESULT(lose)
```

状态枚举（字符串常量）：`"title"` / `"map"` / `"location"` / `"trade"` / `"combat"` / `"event"` / `"ash_contact"` / `"result"`。

## 2. 主循环伪代码（main.py / loop）

```python
def loop(state, cfg, rng, log, ui):
    scene = "map"                      # 开局即在大城，首轮进入 location 也可
    while state.outcome == "":         # 空=进行中；"win"/"lose" 退出
        if scene == "map":
            scene = run_map(state, cfg, rng, log, ui)      # 显示地图+状态栏，等移动/指令
        elif scene == "location":
            scene = run_location(state, cfg, rng, log, ui)  # 地点菜单
        elif scene == "trade":
            scene = run_trade(state, cfg, rng, log, ui)     # 交易/讲价/接单
        elif scene == "event":
            scene = run_event(state, cfg, rng, log, ui)     # 随机事件
        elif scene == "combat":
            scene = run_combat(state, cfg, rng, log, ui)    # 卡牌战斗
        elif scene == "ash_contact":
            scene = run_ash_contact(state, cfg, rng, log, ui)
        # RESULT 由战斗/boss 直接设 outcome 后跳出
    ui.show_result(state)              # 结算界面（文档 02 §4）
```

> `run_map` 返回下一场景：`"location"`（踩到地点）/ `"event"`（野外掷骰）/ `"combat"`（遇敌触发）/ `"ash_contact"`（灰兽接触）/ `"map"`（原地操作如看状态）/ `"result"`（失败判定）。

## 3. 每日结算顺序（走 1 格触发）

玩家在 MAP 按 `w/a/s/d` 走一格 → 调用 `move_step()`，严格按顺序：

```
1. 校验目标格合法（边界/障碍/未探索，见文档 09 §2）——非法则提示、不消耗天数、停留原地。
2. day += 1
3. 推进灰度波动层（ash.fluctuation 随机游走，文档 04 §8）
4. 推进天气（含灰烬风暴概率判定，文档 03 §6）
5. 补给消耗：food -= 0.75, water -= 0.75（3人；按人数缩放，文档 03 §2）
6. 耐久磨损：durability -= 1（基础）
7. 灰度额外磨损：若 current_gray(pos) >= 50 → durability -= 1（文档 03 §1/§6）
8. 腐蚀判定：若 current_gray >= 50 → 额外 -1/天（文档 03 §6，与7可合并或分级）
9. 断粮/断水惩罚：若 food<=0 → morale-1 + 全员-5HP；若 water<=0 → morale-1 + 全员-8HP（文档 04 §3）
10. 感染风险：若 current_gray >= 70 → 标记感染（城市治愈，文档 03 §6）
11. 死亡/抛锚判定：任一角色 hp<=0 → alive=False（可治疗复活）；durability<=0 → 抛锚（需修车脱困，文档 03 §2）
12. 失败判定：全队重伤无法继续 / 耐久0且无法就地脱困 → outcome="lose"（文档 03 §9）
13. 标记目标格 explored=True；若踩到地点 → 进入 LOCATION；若野外 → 进入事件掷骰（§5）
14. 重绘 MAP
```

> 顺序固定，避免「先扣耐久再判边界」之类 bug。每步写日志（文档 11）。

## 4. 移动与地点判定（run_map）

```python
def run_map(state, cfg, rng, log, ui):
    cmd = ui.get_map_input()           # w/a/s/d / m / i / h / q
    if cmd in ("w","a","s","d"):
        nx, ny = step(state.pos, cmd)
        if not map.valid(nx, ny):       # 边界/障碍
            ui.msg("无法通行")
            return "map"
        scene = move_step(state, cfg, rng, log, (nx, ny))   # 执行 §3 每日结算
        state.pos = (nx, ny)
        cell = map.cell(nx, ny)
        if cell.location_id:
            return "location"           # 进入地点
        if state.outcome:
            return "result"             # 移动中失败
        # 野外：掷骰事件
        return roll_wild_event(state, cfg, rng, log)   # → "event"/"combat"/"ash_contact"/"map"
    elif cmd == "m": ui.show_map(); return "map"
    elif cmd == "i": ui.show_status(); return "map"
    elif cmd == "h": ui.show_help(); return "map"
    else: ui.msg("无效指令"); return "map"
```

## 5. 野外事件掷骰（roll_wild_event）

```
p = 基础偶遇概率（⚠️ 25%，文档 04 §9）
p += 灰度加成（每+20灰，+10%，文档 04 §9）
if rng.chance(p):
    if 灰兽格: return "ash_contact"        # 进入灰兽接触选择（文档 03 §6）
    else:      return "combat"             # 强盗/野兽战斗（文档 03 §5）
else:
    # 非战斗随机：supply / merchant_help / storm_warning / 无事
    return "event"
```

> 起始区基准灰<30 几乎无偶遇（文档 03 §6 前期保护），自然由 p 低实现。

## 6. 节点激活 → Boss → 结算（主线）

```
LOCATION 中玩家选 "激活节点"（仅大城、且 ember_core==True）：
  1. node_activated = True
  2. 城市管理层大量奖励（gold += 大额；reputation += ；解锁高级舱/遗物专柜，文档 07A）：
     - 一次性赏金、声望、旧文明许可（实现：置标志位，地点 functions 升级）
  3. 触发 BOSS：spawn ash_beast_boss（⚠️ 150~250血，文档 04 §5）
  4. 进入 run_combat(context="boss")
  5. 胜 → outcome="win"  → RESULT(win)
     败 → outcome="lose" → RESULT(lose)
```

> 无剧情文本（文档 02 §3 / 03 §5）。boss 就是「最后打一下」。玩家**可完全不激活**照样跑商（文档 07A）；不激活则 `outcome` 永不为 win，靠失败/手动退出结束（本版以激活为通关测试动作）。

## 7. 退出条件

| 结局 | 触发 | 处理 |
|:--|:--|:--|
| 通关 | 击败灰烬兽（激活节点后） | outcome="win"，show_result |
| 失败 | 耐久0且无法修车 / 全队重伤无法继续 | outcome="lose"，show_result |
| 手动退出 | 玩家 `q` 反复退到标题或 `Ctrl+C` | 直接退出进程（一局制，无存档） |

> 不设置「时间结局 / 天数上限」（文档 07A：时间结局是正式版参考素材，本版不机械触发）。但主循环需防死循环：若玩家长期不移动只在城里，`day` 不推进，属正常；若某场景函数意外无限递归，靠代码审查+日志发现（文档 11）。
