# 01 · 总览与技术栈

> 《余烬商队》第一版试玩Demo · 开发指南第 1/11 份
> 用途：给编写代码的AI看的项目总览——先读这份，了解要做什么、用什么技术、怎么运行。

---

## 1. 项目是什么

《余烬商队》是一个**末世废土题材的商队跑商游戏**：玩家经营一支商队，在大地图上从一个城市跑到另一个城市，买货卖货、接订单送货赚钱，路上会遇到敌人进入卡牌战斗。本Demo是第一版试玩——验证核心玩法循环是否成立。

**核心玩法循环（Demo要验证的）：**
```
在城市接订单/买货 → 出发在大地图走格子 → 路上遇到事件/战斗 → 到达目的地卖货/交订单 → 赚钱 → 补补给 → 再次出发
```

**玩家定位：** 不是救世主，是商人。激活城市节点（让城市复活）首先是一笔生意。

---

## 2. Demo目标

| 目标 | 说明 |
|:-----|:-----|
| 验证核心循环 | 跑商 → 补给管理 → 战斗 → 赚钱 → 循环是否好玩 |
| 验证基础系统 | 地图移动、补给消耗、卡牌战斗、订单、激活节点 |
| 快速试玩 | 玩家能玩到"出发→战斗→到城→赚钱→激活节点→城市复活"的完整一局 |

**Demo不验证的（后续版本做）：** 遗迹探索、灰兽潮大事件、主线剧情、教团、支线、小城网络、招募车队扩展。

---

## 3. 技术栈（已定）

| 项目 | 要求 |
|:-----|:-----|
| 语言 | **Python 3.10+** |
| 第三方库 | **仅使用Python标准库**（不使用pygame、numpy等任何外部依赖） |
| 界面 | **有UI，但可以做得比较粗糙**（text-based / 简单命令行界面） |
| 交互 | 玩家通过键盘输入指令操作（如输入数字选择、输入方向移动） |
| 运行方式 | 命令行运行：`python main.py` |

> UI定位：第一版Demo有UI，但允许粗糙——重点是验证玩法和数值。用文字/简单界面呈现即可（如命令行菜单、ASCII布局），不做精美图形。

---

## 4. 运行环境要求

- Python 3.10 或更高版本
- 无任何第三方依赖（开箱即跑）
- 跨平台（Windows / macOS / Linux 均可运行）
