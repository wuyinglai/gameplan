## 1. 项目是什么

《余烬商队》是一个**末世废土题材的商队跑商游戏**：玩家经营一支商队，在大地图上从一个城市跑到另一个城市，买货卖货、接订单送货赚钱，路上会遇到敌人进入卡牌战斗。

**本版定位 = 极简测试版（数值验证原型）：**
- 目的不是做完整游戏，是**验证核心玩法循环到底好不好玩**，并**暴露需要改的机制和数值**。
- 所有系统从 `0A_权威系统文档/` 原样搬过来用，**不重新设计**。
- **没有任何剧情、没有任何支线、不需要任何「合理」解释**——只要能跑、能测就行。
- 数值一律给**初值/基准值**，全部带 ⚠️ 标记，必须靠实测调优后再锁。

**核心玩法循环（本版要验证的）：**
```
在城市接订单/买货 → 200×200 大地图走格子 → 路上事件/战斗/灰烬生态
→ 到达目的地卖货/交订单赚钱 → 补补给 → 激活大城节点反应炉
→ 灰烬兽最终战 → 击败即通关
```

**玩家定位：** 商人不是救世主。激活大城节点首先是一笔生意/一个目标，最终 boss 就是「最后打一下」，无需任何剧情包装。

---

## 2. 测试版目标

| 目标 | 说明 |
|:-----|:-----|
| 验证核心循环 | 跑商 → 补给管理 → 卡牌战斗 → 讲价 → 赚钱 → 激活节点 → 最终战，是否好玩 |
| 暴露问题 | 哪些机制「想得好玩实际不好玩」、哪些数值明显失衡（太肝/太无聊/太随机） |
| 快速试玩 | 玩家能玩到「出发→战斗→到城→赚钱→激活节点→打 boss→通关」的完整一局 |
| 数值基线 | 给出一套可测初值，跑几局后用日志核对、再调 |

**本版不追求：** 剧情叙事、世界观自洽、城市经营、长线内容。这些后续正式版再做。

## 3. 技术栈（已定）

| 项目 | 要求 |
|:-----|:-----|
| 语言 | **Python 3.10+** |
| 第三方库 | **仅使用 Python 标准库**（不使用 pygame、numpy 等任何外部依赖） |
| 界面 | **有 UI，但允许粗糙**（命令行 / ASCII 网格即可） |
| 交互 | 键盘输入指令（数字选择、w/a/s/d 移动） |
| 运行方式 | 命令行：`python main.py` |

> UI 定位：重点是验证玩法和数值，画面粗糙没关系。文字菜单 + ASCII 地图即可，不做精美图形。
> 一局制（无存档），方便反复开新局测不同数值。

- Python 3.10 或更高

## 5. Demo 范围边界（极简测试版）

### ✅ 要做（把体系全搬过来）
| 系统 | 范围（本版） |
|:-----|:-----|
| 大地图移动 | **200×200 网格**，1 格 = 1 天 |
| 地点 | 1 大城 + 2 小城 + 若干驿站（部分有节点信号中继 / 部分九城时代损坏无节点）+ 若干村庄 |
| 补给系统 | 食物、水、零件、商队耐久、士气、车厢 |
| 卡牌战斗 | 3 名初始角色，AP / 手牌按人数缩放，状态效果，可撤退 |
| 订单与讲价 | 送货/收购订单；买/卖/接单三类讲价（5 轮拉锯） |
| 灰烬生态 | 灰度两层、腐蚀(≥50)、感染(≥70)、灰兽原生+感染、接触选择、灰烬风暴短时天气 |
| 节点 | 大城节点反应炉 = 通关触发动作；驿站节点 = 信号中继 |
| 角色成长 | 3 初始角色 + 记忆/火种（轻量）；遗迹武器终极技门槛（轻量） |
| 遗迹 | 轻量 1~2 处（产遗迹武器/记忆手册，供终极技门槛测试） |
| 招募 | 轻量 1~2 人（特殊人员，如账房，影响讲价/补给） |
| 敌人 | 强盗、野兽、灰烬兽（普通）+ **灰烬兽（最终 boss，随便安、无剧情）** |
| 随机事件 | 路上随机：补给/伏击/商人/风暴预警/灰兽接触 |

### ❌ 不做（极简，明确排除）
| 不做 | 说明 |
|:-----|:-----|
| 剧情 / 支线 / 教团 | 完全无；开局无背景长文，最多 1~2 行设定提示 |
| 城市经营 / 建设 | 无 |
| 装备模块 | 无（感染防护仅留机制接口，本版感染靠城市治愈） |
| 存档 | 无（一局制，方便反复测） |
| 传送 | 无 |
| 灰烬母兽 / 全球灰兽潮大事件 | 无 |
| 联合商队 / 车队大扩展 | 仅轻量招募 1~2 人 |
| 九城复兴主线 | 无（仅 3 城测试） |
