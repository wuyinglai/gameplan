> 《余烬商队》极简测试版 · 开发指南第 4/4 份
> 用途：所有具体数值**初值**。带 ⚠️ 为参考梯度/初值，**平衡实测阶段必须跑几局核对后再锁**。
> 口径：2026-09-07 裁定——数值一律初值，本版目的就是测「好不好玩、对不对」。

---

## 0. 数值使用铁律（本版核心）

1. 所有数值都是**可测初值**，不是定稿。
2. 跑 3~5 局后，用日志核对：哪类数值让游戏太肝/太无聊/太随机 → 调。
3. 调完在文档里把 ⚠️ 去掉并写定稿值 + 一句理由。

## 7. 订单（⚠️ 2026-09-08 已重定，详见 `14_跑商系统数值.md` §五·B）

| 项 | 值 |
|:---|:---|
| 类型 | **4 大类**：送货(运X到Y)、护送(护送人/物)、收购(交X物给钱，**无期限、不用接**)、悬赏(击杀目标，**不用接**) |
| 同时持单 | **无上限**（可无限接单——多接顺路订单正是赚钱方法） |
| 移动基准 | **平均每天走 2 格**（天数 × 2 = 格数） |
| 分档 | 短途 ≤60天(≤120格) / 中途 60~120天(120~240格) / 长途 120~200天(240~400格) / 超长途 ≥200天(≥400格) |
| 期限 | 送货/护送期限(天) = **ceil(格距/2) × 1.3**（原 /3 已作废，改按 2 格/天）；收购/悬赏**无期限** |
| 交付结果 | **早到 → 额外声望奖励**；正常到 → 无奖惩；**延期 → 声望损失 + 佣金减少**；**严重超期 → 大量声望损失 + 不付报酬(失败)** |
| 报酬 | **天数 × 该档日均 × 倍率**；倍率：**短途 1.7 / 中途 2.0 / 长途 2.1 / 超长途 2.5**（利润 70%→100%→110%→150%，随阶段递增；倍率为中心值，实际上下浮动） |
| 采用日均开销 | 初期 250 / 中期 **700** / 后期 **1500** 金/天（12 人商队全口径） |
| 接单谈酬金 | 玩家可跟发布者讲价加钱 |

## 8. 灰度（0~100）

| 项 | 值 |
|:---|:---|
| 地区基准灰度 | 地图固定每区天生值；起始区 <30，灰烬边缘区可达 70+ |
| 时间波动灰度 | 随机游走，范围 ⚠️ ±20 |
| 探测仪显示 | 基准 + 波动 叠加 |
| 腐蚀阈值 | 显示灰度 ≥50 起每日额外 -1 耐久（随灰度递增） |
| 感染阈值 | 显示灰度 ≥70 才有；本版无装备 → 城市治愈 |
| 敌强/偶遇 | 灰度每 +20，灰兽攻击+1、偶遇概率+10% |
| 灰烬风暴 | 高基准区(≥70)触发概率↑；风暴期间波动层 +⚠️ 20~30 |
