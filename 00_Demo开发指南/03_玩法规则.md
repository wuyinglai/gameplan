# 03 · 玩法规则（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 3/4 份
> 用途：把各系统写成**可实现规则**，对齐 `0A_权威系统文档/`。AI 照此实现，不越界。
> 口径：2026-09-07 裁定——无剧情、200×200、3 城、最终 boss = 灰烬兽。

---

## 1. 地图与移动

| 规则 | 说明 |
|:-----|:-----|
| 网格 | **200×200** 方格地图（1 格 = 1 天行程）。格子类型：大城、小城、城镇、驿站、村庄、野外、障碍 |
| 移动 | `w/a/s/d` 上下左右走一格 = 1 天，天数 +1 |
| 1 天结算 | 食物/水消耗、商队耐久基础磨损(-1)、灰度额外磨损(见 §6)、推进天气/灰度波动 |
| 地形代价 | 高灰区(灰度≥50)地面软化/裂隙 → 移动额外 -1 耐久/天（宜绕路） |
| 斜走 | 不支持纯斜走；靠先横后竖交替走格 |
| 可见性 | 仅当前格 + 相邻格可见；未探索显「？」；到过的地点永久可见 |
| 灰度探测仪 | 常驻 UI 一角，显当前格灰度(0~100) + 趋势箭头（世界呼吸观测器，非警报） |

## 2. 补给与商队状态

| 资源 | 说明 |
|:-----|:-----|
| 金钱 | 交易/订单报酬；日补给消费上限 ⚠️ 30 金 |
| 食物(份) | 每人每天 1/4 份；3 人≈0.75/天（实现可向上取整每日扣 1 份档，或精确小数） |
| 水(份) | 同食物；水瓶可贸易（5 份/格） |
| 零件 | 修车/路上治伤；1 格/单位 |
| 商队耐久 | 0~100；基础 -1/天；高灰区额外 -1/天；战斗损耗 普通 -5 / 精英 -10 / Boss -50 |
| 士气 | 0~10；断粮或断水每天 -1；酒馆 150 / 宴席 400 / 豪华 800（无单城次数限） |
| 车厢 | 货车货舱格（粮袋/水箱/水瓶机制）；余烬核心/火种/金钱不占格 |
| 断粮 | 每天士气 -1 + 全员 -5 HP |
| 断水 | 每天士气 -1 + 更重生命惩罚（比断粮严重） |
| 抛锚(耐久0) | 无法移动；可转货/弃货/用零件修车/弃车；须进城或就地修车脱困 |

## 4. 交易与讲价

| 规则 | 说明 |
|:-----|:-----|
| 三类场景 | ①买货压价 ②卖货抬价 ③接订单谈酬金 |
| 触发 | 大单/订单默认谈判；小单默认价成交，玩家主动按键才进讲价 |
| 执行者 | 有「账房/商人」特质特殊人员 → 成交空间大；无特质也能讲但成功率低 |
| 核心机制 | NPC 隐藏三价(成本底价/满意价/急迫度)；出价→态度反馈(皱眉/眼神亮/叹气，不显数字)→最多 5 轮拉锯 |
| 影响变量 | 讲价者特质、声望(轻量)、个体信任(轻量)、城市态度(基准)、灰度(高灰区稀缺抬价)、你带货是否对方急需 |
| 声望+信任 | 宏观声望(城市级简单值) + 个体信任(固定 NPC 有名字/信任值，轻量)；公平成交升、欺诈降 |
| 谈崩处理 | 可妥协价成交 / 改日再来不涨价；稀缺货+订单有 1~2 周竞争者窗口 |
| 城市态度修正 | 城市态度只描述统治层政策，不裁定普通 NPC |

## 5. 卡牌战斗

| 规则 | 说明 |
|:-----|:-----|
| 触发 | 野外遇敌、订单护送遇袭、灰烬兽最终战 |
| 我方 | 3 名初始角色（护路人68血/荒野射手40血/修补师46血）；AP 3 / 抽 7（人数缩放：3人=3AP/7张） |
| 手牌(初始固定) | 攻击(费1,伤5~8)、防御(费1,护盾)、治疗(费1,回血)、修车(费1,耗1零件耐久+)、标记(费X,给标记)、流血(费X,持续伤) |
| 状态 | 标记/流血/穿甲/减速/灼烧/反击/护盾/超载；无回合上限；可布阵；可撤退 |
| 有随机 | 抽牌随机、未知数、变数保留（「意思」来源）；无实时压迫、节奏由玩家掌控 |
| 敌人(普通) | 强盗(20血/5攻)、野兽(15血/4攻)、灰烬兽(35血/8攻，原生+感染并存) |
| 灰度影响 | 灰度越高 → 灰兽偶遇概率↑、灰兽强度↑ |
| 撤退 | 战斗中 `r`；撤退回最近安全点(大城/小城)，损失部分补给 |

### 灰烬兽（最终 boss）
- **随便安、无剧情、无需解释成因**：激活大城节点反应炉后即在城外/城内刷出，打一场。
- 数值 ⚠️ 初值（待实测调优）：血量远高于普通灰烬兽（参考 ⚠️ 150~250），攻击 ⚠️ 12~18，带若干状态（如 灼烧/反击/超载）。
- 击败 = 通关。

## 6. 灰烬生态（世界底色）

> 灰烬 = 大陆自古自然生态（如沼泽）；危险来自旧文明清除实验后遗症（腐蚀性 + 感染动物）。**非大事件、无紧迫感、无母兽。**

| 规则 | 说明 |
|:-----|:-----|
| 灰度两层 | ①地区基准灰度：地图固定每区天生值 → 只它决定资源构成；②时间波动灰度：随机游走让灰度「呼吸」。探测仪显叠加值 |
| 资源构成 | 仅地区基准层影响：高灰区普通货少但灰烬特产(灰烬材料/火种富集)多 |
| 地貌通行 | 高灰区(≥50)额外 -1 耐久/天、宜绕路 |
| 腐蚀损耗 | 显示灰度≥50 每日额外 -1 耐久（随灰度递增，参考梯度） |
| 感染风险 | 仅显示灰度≥70 才有；本版无装备系统 → 感染后靠城市(药包/检疫)治愈 |
| 灰烬风暴 | 灰烬生态区短时天气：期间中立灰兽躲藏、掠食型活跃加强 → 鼓励避难/原地度过；高基准区更易触发 |
| 灰兽偶遇(接触选择) | 进入灰兽格 → 显「发现 X 只(种类/规模)」→ 选项：绕行(花 1~2 额外 AP)/强行通过(概率战斗)/驱离(队伍能力)。不做地图预知标格 |
| 中立 vs 敌对 | 中立(非攻击)可离开或主动攻击(反击不追)；敌对(掠食)可逃/驱离/强行通过 |
| 前期保护 | 起始区基准灰<30 几乎无偶遇；随贸易深入才遇强敌 |
| 灰兽分类 | 生态角色(掠食/食腐/群居/共生) × 灰度分层(低无/中感染变异/高原生) |
| 不做(本版) | 全球大潮、倒计时、强制守城、母兽相关、强度分级 Boss 化 |

## 7. 节点激活与主线（无剧情）

```
跑商攒资源 → 大城「激活节点」→ 插入余烬核心(激活钥匙，不消耗)
→ 灰烬兽最终战(随便安，无剧情) → 击败 = 通关
```

- 余烬核心：开局抵债包裹获得（混大量无用物，不给剧情、无特殊提示，玩家自行探索）。
- 激活后额外解锁 / 升级：高级记忆设施/工坊复产/高级改造舱/旧文明遗物专柜/节点网络连通/高级检疫（基础交易、医馆、记忆设施、工坊、改造舱激活前已有基础版）。激活另获城市管理层大量奖励（赏金/声望/旧文明许可）。
- 复兴九城/多城激活：不做。玩家可完全不激活、照样跑商（正式版非强制；本版以激活为通关测试动作）。
- 遗迹(轻量 4 处：2 产武器 / 2 产记忆手册)、招募(轻量 1~2 人)：供终极技门槛/讲价加成测试，不绑主线。

## 8. 随机事件（路上）

| 事件 | 效果 |
|:-----|:-----|
| 发现补给 | 获得随机食物/水/零件 |
| 遭遇伏击 | 进入战斗 |
| 商人求助 | 选择：帮忙(得报酬)/离开 |
| 灰烬风暴预警 | 提示区域将起风暴，建议避难 |
| 灰兽接触 | 进入 §6 接触选择流程 |

## 9. 结束条件

| 结局 | 触发 |
|:-----|:-----|
| 通关 | 击败灰烬兽（激活节点后）→ 结算（天数/金钱/战斗次数/订单完成数） |
| 失败 | 耐久归零且无法修车 / 全队重伤无法继续 → 结算(失败评价) |
