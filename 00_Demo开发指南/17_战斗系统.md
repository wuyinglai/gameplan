## 1. 战斗定位与红线（必读，不可破）

- **类型**：回合制战术卡牌；队列式 UI（非棋盘）。
- **三层目标**：杀敌 / 护人 / 护车（货车耐久）。
- **两条设计红线（最高优先级，任何数值/组合不得违反）**：
  1. **禁单回合无限出牌连锁**：出牌→产牌→再出牌的指数滚雪球。本作是 RPG，构筑永久保留，一旦拿到无限 combo 后期直接平推、游戏无聊。
  2. **禁伤害严重溢出**：一击秒全图 / 单回合清场。单体伤害应有合理上限；**Boss 单独设计**（血量 / 承伤 / 回合结构独立，见 `04 §9.3`）。
- **落地守门手段**（代码必须实现）：
  - **每人每回合起手抽 3 张 = 2 张动作牌 + 1 张记忆牌，仅此而已；回合结束清空**（§2）——**牌张闸门在"起手抽牌"这一侧**。
  - 🔴 **本作没有出牌上限** —— **回合内出多少张、抽多少张都不受任何限制**（抽完 → 全打出 → 洗一遍 → 再抽再打，重复多少遍都合法）。**唯一的约束是体力池**。
  - **体力池预算**：出牌消耗体力（**0 / 25 / 50 / 100 / 150 五档**，§2），池 = **各人相加**（基准 **50/人**）、**每回合回复、有上限、可攒**。
  - **零体力卡硬约束**：0 体力只能做轻度铺垫（标记类 / 少量护盾），**禁攻击 / 禁抽牌 / 禁再抽牌 / 禁强负面**（灼烧、强迟滞），**且仍占 1 个起手名额**（否则 0 耗 + 不占位 = 无限叠盾）。

## 2. 选牌与体力模型（Demo 实现口径 · **2026-09-20 更新**）

| 项 | 规则 |
|:--|:------|
| **体力（原 AP）** | 🔴 **全队共用一个池**，**池 = 各出战人员体力之和**（每人**基准 50**，**有个体差异**：有人高于 50、有人低于 50）。**谁花都行**——一个人可以把整池一次用光，也可以全队分着花；**不按人头分额度、没有"个人体力"** |
| **存量模型** | 🔴 体力**有上限、每回合回复、用不完可以攒**：**每回合回复 = 50 × 出战人数**；**上限 = 100 × 出战人数**（= 2 × 回复，即最多攒住一回合的量）；**起手 = 满** |
| **起手抽牌** | 每名出战战斗人员，回合开始从自己牌池**自选 3 张**：**1 张记忆卡 + 2 张动作卡**，**选完即定** |
| **出牌** | 🔴 **没有出牌上限** —— 抽出来的牌**全部打出**（顺序玩家定）；**回合内出牌数 / 抽牌数都不受限** |
| **体力消耗档** | **微 0 · 轻 25 · 标准 50 · 重 100 · 极限 150**（原"0/1/2/3+ 费"作废）。0 体力卡只能铺垫 |
| **手牌清空** | **回合结束弃掉未用手牌**，下回合重抽（防囤牌，红线手段） |
| **消耗品** | 药包 / 零件**不是牌、不占任何起手名额** —— 想给哪个角色用就**直接对他使用**（谁用都行），消耗 **25 点**共享体力 |
| **出战人数** | 无上限（所有护卫都能上）；Demo 默认 3 人（护路人/荒野射手/修补师） |

**推论（供数值平衡参考）**：3 人出战 → 体力池 **150（回复）/ 300（上限）**；每回合能打 **3 张标准招（50）**，攒满一次能连打 6 张。

> ⚠️ **别把"3 张"误读成出牌上限** —— 3 张是**起手抽牌量**，不是"一回合只能出 3 张"。**回合内出牌完全无限制**，闸门在**体力**（和"开始抽牌"这一侧）。

### 2.1 牌池来源（**四类来源 · 用户 2026-09-16 定**）

| 层 | 来源 | 谁给的 | 例 |
|:--:|:--|:--|:--|
| **动作卡**（选 2 张） | **老本行** | 角色**加入商队之前就会的**（不是"天生"，是"早就会"） | 医生 → **包扎** |
| | **武器** | 装备 | 剑 → 挥砍 + 轻格挡；重盾 → 重盾防御；**小盾 → 盾反**；长矛 → 刺击 |
| | **武学记忆** | **植入获得，但不占记忆槽**（"动作记忆"：有了它就会那个动作） | 某套剑法 / 招式 |
| **记忆卡**（选 1 张） | **记忆** | 旧文明植入（知识领域，第6A类 §5.1） | 化学 → 制毒（战斗）/ 制驱兽剂（探索） |
| **独立池 · 待定** | **商队牌** | 车载武器 · 特殊人员 | 车载武器；演讲家 → 全员 buff |

> **"老本行"本身不成长，但能被"相关记忆"强化**（例：植入治疗类记忆 → 包扎回得更多）。
> **药包 / 零件不在这四类里**：它们**不是牌**，直接使用、耗 **25 点共享体力**（见 §2 表）。
> ⏳ **商队牌怎么选、怎么打待定**——它是**全队共用的另一套池子**，不占个人"2 动作 + 1 记忆"名额。
> 角色动作卡池通常 >2（如初始三人各有 6 张动作卡），每回合从池中选 2 张；记忆卡从已植入领域选 1 张。

## 3. 战斗流程状态机（Demo 实现）

```
战斗开始
  ├─ 初始化：我方出战列表 / 敌方列表 / 货车耐久快照 / 状态清空
  ├─ 进入回合循环（无回合上限）
  │    ├─ 【我方起手抽牌】每名出战者自选 3 张（1记忆+2动作）入手牌
  │    ├─ 【我方出牌阶段】按玩家顺序打出（🔴 **无出牌上限**，**改由体力池约束**）；中途可用消耗品（药包/零件，不占牌，吃 **25 点**共享体力）
  │    │     触发：伤害结算 / 状态施加 / 护盾 / 治疗 / 修车 / 反击
  │    ├─ 【敌方行动阶段】每个敌人按 AI 行动（攻击/特殊/蓄力）
  │    ├─ 【回合结束】清空我方未用手牌；结算持续伤害（流血/灼烧）
  │    │     检查：敌方全灭？→ 胜利；我方全重伤+货车0？→ 强制撤退
  │    └─ 回到回合循环
  ├─ 战斗撤退判定（每回合可触发，第3回合起判定，见 §8）
  └─ 战斗结束
       ├─ 胜利：发奖励（物资/货币；Boss 给记忆）
       ├─ 撤退：无奖励（见 §8 总表）
       └─ 货车耐久损耗写入第3A类结算
```

**关键实现点**：
- 出牌顺序由玩家在 UI 决定；组合机制靠"记忆卡赋能 + 动作卡出手"跨角色串（§2.1）。
- 持续伤害（流血=内伤 / 灼烧=外伤）在"回合结束"统一结算，流血无视防御、灼烧可被护盾挡。
- 灰蚀（第4A类 §5.5）每回合 4 伤/层，满 3 层爆发；只由"灰烬治疗"清除。

## 5. 伤害 / 防御 / 状态结算（实现要点，规则见第4A类 §3~5）

- **伤害类型**：外伤（可被护盾/护甲/屏障挡）/ 内伤（流血，无视防御）。
- **攻击类型（三型 · 与武器绑定）**：**打击 / 斩击 / 刺击** —— 决定**打什么甲划算**，倍率作用于**整次伤害（一直算到生命）**：

  | 类型 | 对无甲 | 对软甲 | 对硬甲 |
  |:--|--:|--:|--:|
  | **打击** | ×0.95 | ×1.0 | **×1.3** |
  | **斩击** | ×1.1 | **×1.2** | ×0.9 |
  | **刺击** | ×1.1 | ×1.0 | ×1.0 |

  **防护档**：**无甲**（甲值 0 / 甲被打碎）· **软甲**（布·皮）· **硬甲**（铁·钢·灰烬甲壳）。**甲碎 → 当场转无甲档**。
- **防御三层（只挡外伤）**：**护盾**（**盾牌给的，回合末清空，可给队友叠**）> **屏障** > **护甲**（**防具给的，本场战斗内持久、战毕复位、只减不增**）。穿甲攻击无视护甲，**也不吃上面那张倍率表**。
- **状态上限**：标记（不限，消耗+25%/层）、反击（不限层）、流血（3伤/层，行动后触发-1）、灼烧（4伤/层，回合末触发-1，可挡）、迟滞（失败率上限50%）、灰蚀（≤3层，只灰烬治疗清）。
- **结算顺序（外伤）**：`面板 × 招式倍数 ×（1+角色加成%）× 攻击类型倍率` → 护盾 → 屏障 → 护甲 → 生命；内伤直接扣生命。

## 8. 撤退 / 重伤 / 旧文明武器（指针，规则见 0A）

- **战斗撤退**：每回合可选，第3回合起判定，基础成功率 50%；成功士气-1、无奖励、货不丢。Boss 默认不可普通撤。
- **敌方逃跑**：意愿只增不减（强盗抢货+100满）；灰烬兽不逃。基础成功率 50%。
- **地图撤退**（主动/崩溃/强制）：货损 25%/50%/75%，见第4A类 §8.2。
- **重伤**：生命归零退战；第1次-20%最大生命+休养3天，第2次-50%+4天，第3次失能（城市治）。详见第6A类 §7。
- **旧文明武器（终极爆发）**：弱发射免费≈普攻；强发射烧火种超高伤。火种稀缺，战略资源。详见第4A类 §6。Demo 先不接武器，留接口。
