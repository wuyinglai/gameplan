# 09 · 边界与异常（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 9/11 份
> 用途：列出**所有边界情况与异常**，确保「任意非法输入 / 极端状态都不崩溃」，并明确每类怎么处理。
> 核心原则：**不崩溃、不静默错、给玩家明确反馈、状态回到合法区间（clamp）**。

---

## 1. 补给边界

| 情况 | 处理 |
|:--|:--|
| 食物 < 0 | `food = max(0, food)`；触发断粮惩罚（文档 03 §2 / 04 §3） |
| 水 < 0 | 同上，断水惩罚更重 |
| 两者都断 | 每天 morale-1 + 全员扣血，直到补充或失败判定 |
| 零件 < 0 | `parts = max(0, parts)`；修车需零件时若不足 → 提示「零件不足，无法修车」，不崩溃 |
| 耐久 < 0 | `durability = 0` → 抛锚（文档 03 §2）；允许就地修车（耗零件+金）或转货弃车脱困 |
| 耐久 > 100 | `durability = min(100, durability)`（修车/补给恢复时 clamp） |
| 士气 < 0 / > 10 | clamp 到 [0,10] |

---

## 2. 移动边界

| 情况 | 处理 |
|:--|:--|
| 目标格越界（x<0 / x≥200 / y<0 / y≥200） | 提示「无法通行」，不消耗天数、停留原地（文档 07 §3 步骤1） |
| 障碍格 | 同越界处理 |
| 未探索格 | 允许进入（探索即揭示），不阻挡 |
| 走到地点格 | 进入 LOCATION，不重复掷骰事件 |
| 连续同向移动 | 每格独立结算 1 天，不批量；防「一按穿全图」 |
| 抛锚时移动 | 耐久0 不能走；提示「需先修车脱困」 |

---

## 3. 战斗边界

| 情况 | 处理 |
|:--|:--|
| 我方全员 hp≤0 | 全队重伤 → outcome="lose"（文档 03 §9） |
| 敌方 hp≤0 | 移除该敌；全灭 → 战斗胜，回 MAP |
| AP 不足出牌 | 提示「行动力不足」，不出牌、不扣 AP |
| 手牌空但牌库有 | 洗牌库进手牌（抽牌） |
| 手牌空且牌库空 | 跳过抽牌（疲劳机制可选）；不崩溃 |
| 撤退时补给不足 | 损补给 `min(持有, 随机1~3)`（文档 04 §5），不出现负数 |
| 撤退时已在安全点 | 直接回城，不重复 |
| Boss 战撤退 | 允许撤退（同普通），但 boss 仍在；再激活才再战（或视为放弃通关） |
| 状态负数/溢出 | 所有 status.stacks clamp ≥0；duration 正常递减 |
| 伤害溢出 | 目标 hp clamp ≥0，到0即死 |

---

## 4. 交易边界

| 情况 | 处理 |
|:--|:--|
| 金钱不足买 | 提示「金钱不足」，不成交 |
| 货舱满卖不入 | 卖出不占舱（减负），可成交；买入超舱 → 提示「货舱已满」，不成交 |
| 讲价 5 轮结束未达成 | 按最后一轮对方态度给「妥协价」或「谈崩」（改日再来不涨价，文档 03 §4） |
| 谈崩后继续讲 | 限制每日/每次最多重谈 1 次，防刷 |
| 卖价低于成本 | 允许（玩家自主亏本），不拦截 |
| 买价高于上限 | 允许（稀缺抬价），按讲价结果 |
| 货物数量为 0 | 不显示交易项 / 不可卖 |

---

## 5. 改造边界（身体改造轴，文档 06A 第15节 / 04 §12）

| 情况 | 处理 |
|:--|:--|
| 排异（掷骰命中 rejection_rate） | 植入无效 + 资源白费 + 短暂负面（休养天数/临时-属性），**不永久伤残、不影响已完成改造** |
| 技术失败 | 没做成，资源白费，轻微负面（短时虚弱） |
| 兼容冲突 | 与已装改造互斥/缺前置 → 无效或需先移除前置；提示明确 |
| 感染风险 | 高灰区/无高级医疗时改造，按概率标记感染，城市治愈 |
| 副作用 | 成功但附带轻微负面（trade-off），非 bug |
| 资源不足 | 提示「材料/火种/金不足」，不执行 |
| 神经反射(+AP) 改装后 AP 异常 | clamp AP 到合理上限（如 ≤5，对应5人队），不破坏战斗缩放 |
| 重复装同一项 | 允许（叠加）或互斥，按 `prerequisites` 判定 |

## 6. 数值边界（通用）

| 情况 | 处理 |
|:--|:--|
| 任意数值溢出 | 所有资源/属性在写入时 clamp 到合法区间（参考文档 08 §8 常量） |
| 负数金钱/数量 | clamp ≥0，并显示提示 |
| 天数过大 | 无上限（不设时间结局，文档 07 §7）；但主循环防死循环（见 §7） |
| 除零（如人均消耗） | 人数为0 不可能（至少1人存活才能移动）；若全员死亡已触发 lose |
| 浮点食物显示 | 显示四舍五入，内部保留 float 精确扣减 |
| 随机索引越界 | `choice()` 前判非空；空列表返回 None 并处理 |

---

## 7. 主循环防死循环 / 卡死

- 每个场景函数**必须返回下一场景字符串**，不允许无限递归（文档 07 §2）。
- 若 `outcome` 非空，主循环立即退出到 RESULT（文档 07 §2）。
- 输入解析：非法指令 → 「无效指令」回原场景（文档 02 §5），不抛异常。
- 任何意外异常：顶层 `try/except` 捕获，打印错误日志（文档 11）+ 提示「发生错误，回到地图」，不闪退。

---

## 8. 订单 / 声望 / 其他边界

| 情况 | 处理 |
|:--|:--|
| 订单超时 | status="failed"，扣声望（仅记录，文档 04 §7），不惩罚其他 |
| 同时持单≥3 | 拒绝接新单，提示「订单已满」 |
| 交付货物不足 | 提示「货物不足」，不交付 |
| 声望 < 0 / 异常 | clamp ≥0（或允许负，仅记录） |
| 招募超上限 | 本版轻量 1~2 人，满则提示「队伍已满」 |
| 灰烬感染未治愈就进高灰 | 感染状态持续，城市医馆/检疫治愈（文档 03 §6）；不自动死亡 |

---

## 9. 非法输入总处理

> 所有界面（`ui/cli.py`）输入解析：
> - 数字菜单：越界/非数字 → 「无效指令」，重显菜单。
> - 地图 `w/a/s/d`：其他键 → 「无效指令」。
> - 任意 `Ctrl+C` → 直接退出（一局制无存档，文档 01 §3）。
> - **绝不因输入抛未捕获异常**（文档 02 §5：「不能崩溃」）。
