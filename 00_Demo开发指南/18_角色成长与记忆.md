## 2. 记忆 = 知识领域（Demo 实现口径）

### 2.1 基本规则

| 项 | 规则 |
|:--|:--|
| 名称 | 统一叫**记忆**，无"技能/技艺"名词 |
| 获得 | **完整获得**：要么拿到完整记忆，要么不获得；**不做碎片、不做熟练度、不做经验值** |
| 形态 | 记忆 = **知识领域**（化学 / 机械 / 草药 / 旧文明语 / 谈判 / 地形学……），**不是纯战斗技能** |
| 三卡 | **一个领域给三类卡**（见 2.2），一条记忆三种用 |
| 非战斗不耗体力 | 探索卡 / 跑商卡 = 被动加成或事件额外选项，**不消耗体力**；只有战斗卡才主动打出（接 17 §2） |

### 2.2 一个领域 → 三类卡

| 卡类 | 场景 | 形态 | 例子 |
|:--|:--|:--|:--|
| **战斗卡** | 战斗内 | 主动打出（占**起手 1 张记忆牌**的名额，见 17 §2） | 制毒、拆解、标记 |
| **探索卡** | 野外 / 事件 | 被动加成 或 事件额外选项（不耗体力） | 破译旧文明装置、配解毒剂 |
| **跑商卡** | 交易 / 讲价 | 被动加成 或 讲价选项（不耗体力） | 识破掺假货、地域行情判断 |

> 实现映射：战斗卡 → 17 的 `Card`（带 `cost`）；探索卡/跑商卡 → 事件与讲价的"额外选项钩子"（本文件 §8 事件接口同机制）。

### 2.3 领域槽位

| 阶段 | 可同时植入领域数 |
|:--|:--:|
| 初始 | **8 个** |
| 后期上限 | **15 个** |

- 实现：`Character` 增 `domains: list`（已植入领域），长度受 `DOMAIN_SLOTS_MAX` 约束。
- 每个领域提供自己的战斗卡池（战斗中从已植入领域里选 1 张记忆卡）。

### 2.4 领域理解标签（植入限制）

- 每个记忆有**领域标签**；角色有**领域理解标签**（来自职业 / 已植入领域）。
- **只有具备对应领域理解的角色才能植入该领域记忆**；不匹配则**无法植入**。
- Demo 简化：初始三人按职业给固定可理解领域（⚠️ 初值，可按实际战斗卡归属调整）：

| 角色 | 初始可理解领域 ⚠️ |
|:--|:--|
| 护路人 | 防护 / 地形学 / 机械 |
| 荒野射手 | 狩猎 / 草药 / 地形学 |
| 修补师 | 机械 / 草药 / 化学 |

> ⚠️ **待映射**：第6A类 §2~§4 的三人记忆表仍按旧「攻击/防御/辅助/消耗」分类，尚未归入知识领域。Demo 阶段**允许用"职业专属卡池"直接映射**（三人各 6 张动作卡 + 领域记忆卡），不阻塞开发；正式版再做领域重映射。

## 3. 零体力卡硬约束（全局核心约束，代码必须守）

> 与 17 §1 同一条红线，此处列出实现检查点。**任何新增记忆卡都要过这道检查。**

| 项目 | 规则 | 代码检查 |
|:--|:--|:--|
| 携带量 | 0 体力记忆**不占领域槽位**（⚠️ 但**仍占 1 个起手名额**，见 `04 §9.1`） | `cost==0` 不进 `domains` 计数 |
| 效果限制 | 只能**很弱**：轻度负面（挂 1 层标记）/ 轻度正面（少量护盾） | `value` 不超过弱阈值 ⚠️（伤=0，盾≤5） |
| ❌ 禁止 | 不能造成伤害 / 不能抽牌·产牌 / 不能挂强负面（灼烧、强迟滞） | 断言：`cost==0 → effect_type not in {attack, draw, burn, strong_slow}` |
| 推论 | **任何"抽牌 / 产牌"卡一律 > 0 体力** | 防止「0 体力产牌 + 低耗伤牌」无限循环 |

## 4. 记忆获取途径（设计红线 · 代码必须遵守）

> ⚠️ 记忆是**珍贵资源**。第6A类 §5.5：**严禁随机掉落，尤其禁止小怪掉落记忆。**

| 来源 | 是否产出记忆 | Demo 落地（⚠️初值） |
|:--|:--:|:--|
| **普通战斗胜利**（强盗 / 野兽 / 灰烬兽小股） | ❌ **绝不** | 只掉普通物资：零件 / 药包 / 货币 / 普通货；掉落表里**没有 memory 项** |
| **击败 Boss**（含遗迹 Boss、最终 Boss） | ✅ | 100% 掉 1 个记忆（主要战斗来源） |
| **搜索遗迹** | ✅ | **大遗迹**：搜索产出记忆 1~2 个；**小遗迹**：⚠️ 50% 概率产出 1 个 |
| **旧文明数据库 / 探索事件** | ✅ | 遗迹深处 / 灰烬城数据库事件，给稀有记忆 |
| **招募** | ✅ | 招募到的角色自带其记忆（接 13） |
| 记忆推演（§7） | — | 是**已有记忆的派生**，不改变"原始记忆从哪来"的红线 |

> **实现守卫**：战斗结算函数里，若掉落表出现 `memory` 类型，直接 `assert` 拦下（防止后续误加）。
> **原因**：记忆是旧文明知识领域的完整传承，衰败晚期极稀少；小怪随便掉 → 记忆贬值、成长失控，且背离"去废土里淘知识"的探索基调。

## 5. 记忆强化（成长核心）

> 依赖**城市 / 城镇设施**，**不做野外随地升级**。记忆升级点记在 `Memory` 上。

### 5.1 数值升级（提升基础数值：伤害/护盾/治疗/修车）

**公式：第 N 次数值升级价格 = 300 + 20 × (N − 1)**

| 第几次 | 1 | 2 | 3 | 10 | 20 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 价格 | 300 | 320 | 340 | 480 | 680 |

> 线性增长（不用乘法），避免后期升不动。

### 5.2 状态升级（提升标记层数 / 流血层数 / 正面状态强度）

**公式：第 N 次状态升级价格 = 1000 + 200 × (N − 1)**

| 第几次 | 1 | 2 | 3 | 5 | 10 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 价格 | 1000 | 1200 | 1400 | 1800 | 2800 |

> 比数值升级贵——状态升级通常强于单纯 +1 数值。

### 5.3 火种升级（加词条 / 加特殊效果）

| 项 | 规则 |
|:--|:--|
| 资源 | **火种**（稀有战略资源） |
| 池子 | **每个记忆有自己的火种词条池，不随机**（玩家在池内选） |
| 作用 | 加词条（射箭【重击】）/ 加效果（【穿甲】）/ 改方向（治疗箭、车厢盾架）/ 解锁特殊处理（净毒、加固） |
| 与推演区别 | 火种升级 = 在**原记忆**上加后缀；推演 = 造**新记忆**（§7） |

### 5.4 Demo 落地

- 升级入口：城市（必有）/ 城镇（⚠️ 部分有）。
- 数据结构：`Memory` 需含 `numeric_level`（数值升级点）、`status_level`（状态升级点）、`fire_traits`（已加火种词条）。
- 每次升级走 15 的"每天 50 点体力"时间成本：⚠️ 升级消耗 **1 天 + 金币**（不占体力，直接日终结算）。

## 6. 记忆推演（原「融合」已改为「推演」）

> **机制变更（2026-09-09）**：旧"融合"（原记忆消失）→ 新"**推演**"（**原记忆保留**）。
> 定位：单一记忆效果有限，推演后 **1+1 > 2**，是玩家打造复合记忆的核心途径。

### 6.1 消耗

| 项 | 规则 |
|:--|:--|
| 素材记忆 | 参与推演的多个记忆 —— **原记忆保留，不消耗** |
| 火种 | 每次推演消耗若干（⚠️ 初值 2~4 颗，待实测） |
| 金钱 | 推演费：**同标签 300 / 跨标签 500 金**（第2.1类；⚠️ 初值） |
| 设施 | 需**记忆设施**（城市；世界观见第7A类 §五——损坏且简陋的旧机器） |

### 6.2 继承规则（代码直接照此实现）

```
新记忆数值升级点 = max(参与推演记忆的数值升级点)
新记忆状态升级点 = max(参与推演记忆的状态升级点)
新记忆普通总等级 = 数值升级点 + 状态升级点
```

推演后，玩家可在新记忆的可用升级项中**重新分配**继承来的升级点。

**示例：射击 + 标记 → 精确射击**
```
射击：数值升级点 5
标记：状态升级点 1
推演 → 精确射击：数值 5 / 状态 1 / 总等级 6
效果：造成伤害，并施加 2 层标记
```

### 6.3 领域标签约束

- 推演出的新记忆**同样带领域标签**，受 §2.4 植入限制约束。

### 6.4 Demo 落地（简化）

- 不做通用配方系统；提供 **2~3 个固定可推演配方**做测试即可（⚠️ 例如：射击+标记→精确射击；治疗+草药→灰烬治疗）。
- 推演在**城市记忆设施**进行，消耗火种 + 金币，产出的新记忆自动加进推演角色。

## 7. 能力槽系统（每人 4 个：2 数值被动 + 2 事件接口）

> 第6A类 §9。不是主动记忆，是**常驻被动 + 事件钩子**，用于给事件/讲价加权。

### 7.1 数值被动（固定生效，不叠触发概率）

| 角色 | 词条 | 效果 | 类型 |
|:--|:--|:--|:--|
| 护路人 | 【护卫】 | 敌对/夜袭/护送/内部恐慌事件中，最差混乱结果权重 ×0.8 | 数值被动 |
| 护路人 | 【护车】 | 货损/抢货/撤退结算中，订单货物/补给/零件损失权重 ×0.85 | 数值被动 |
| 荒野射手 | 【野外侦察】 | 路线、敌情、痕迹信息等级 +1，初始免费最高到 2 级 | 数值被动 |
| 荒野射手 | 【狩猎采集】 | 自然资源事件中，补给类结果权重 ×1.2 | 数值被动 |
| 修补师 | 【修理知识】 | 修车效率提高（1 零件 +16 耐久，无零件 +5 耐久） | 数值被动 |
| 修补师 | 【现场诊断】 | 结构、车损、普通设备故障信息等级 +1，初始免费最高到 2 级 | 数值被动 |

### 7.2 事件接口（只在对应事件中出现额外选项 / 结果修正）

| 角色 | 接口 | 说明 |
|:--|:--|:--|
| 护路人 | 挡在前面 / 维持秩序 | 遇敌拦路多保护选项 / 恐慌事件稳定选项 |

## 8. 重伤系统

> 第6A类 §7。**角色不会永久死亡、不做永久伤残、不做不可逆惩罚。**

### 8.1 基本规则

| 项目 | 规则 |
|:--|:--|
| 生命归零 | 角色退出当前战斗，进入**重伤**状态 |
| 重伤后 | 该角色**不再出牌**（不再抽/选牌） |
| 休养期间 | **不能上场** |
| 战斗终止 | **全部出战队员均重伤 + 货车耐久归零**，才触发战斗终止（强制撤退，见 17 §8） |

### 8.2 重伤分级 ⚠️

| 重伤次数 | 效果 | 恢复时间 |
|:--:|:--|:--:|
| 第 1 次 | 最大生命 −20%，恢复到当前最大生命的 20%（向上取整） | 休养 **3 天** |
| 第 2 次 | 累计最大生命 −50%，恢复到当前最大生命的 20%（向上取整） | 休养 **4 天** |
| 第 3 次（失能） | 不能上场，必须到**城市治疗**或替换 | 城市治疗 |

### 8.3 恢复方式

| 方式 | 效果 |
|:--|:--|
| 自然休养 | 每天 +1 恢复进度，达到天数后自动恢复 |
| 驿站 / 城镇 | 可**加速**重伤自然恢复，但**不能清除重伤次数、不能恢复最大生命惩罚** |
| 城市治疗 | 可治疗一/二次重伤、失能；统一 **1 天 + 金币** |
| 补给耗尽 | 重伤恢复天数 **+1**（恶化，见 15） |

### 8.4 城市治疗价格 ⚠️

| 状态 | 价格 |
|:--|:--:|
| 第一次重伤 | 200 金 |
| 第二次重伤 | 350 金 |
| 失能 | 500 金 |
| **整队失能恢复上限** | 总成本 **不超过 500 金** |
