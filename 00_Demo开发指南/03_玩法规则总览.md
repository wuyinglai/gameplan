## 0. 一局长什么样（骨架）

```
开局：站在大城（规模：14 人 · 4 辆车 → 16）
   │
   ├─ 接订单 / 买货（讲价）        ← 14
   │
   ├─ 走格赶路 ──▶ 野外遭遇（事件 / 灰兽 / 遇敌）──▶ 卡牌战斗    ← 15 / 19 / 17
   │
   ├─ 到地点：卖货 · 交单 · 补补给 · 修车 · 治疗 · 休整           ← 14 / 15
   │        └─ 攒钱 / 攒记忆 / 攒补给（车况得盯着修）            ← 18
   │
   └─ 本钱够了 ──▶ 直接挑战灰烬（最终战）──▶ 击败 = 通关         ← 17 / 21
```

**一句话定位**：玩家是**商人**，不是救世主。做生意（低买高卖 + 接单）就是核心，灰烬只是最后打一场。

## 1. 地图与移动

| 规则 | 说明 |
|:-----|:-----|
| 网格 | **400×400** 方格地图。格上有地点（大城 / 小城 / 城镇 / 驿站 / 村庄 / 大·小遗迹）与地形（野外 / 山 / 水 / 桥 / 林 / 废墟） |
| 走格 | 键盘 `w/a/s/d` 上下左右走一格，**走一格耗 20 点野外体力**；不支持纯斜走（先横后竖交替） |
| 一天怎么算 | 体力是**每天一份（基准 50 点，取全队战斗人员最低值）**；**当天体力耗尽 / 玩家主动休整**，才结算这一天（顺序见 `15 §1.3`），**不是每走一格算一天** |
| 地形代价 | 山 / 水 / 废墟**走不了**，桥 / 林地**能走**；高灰区地面软化→额外损耗（`15`） |
| 可见性 | 只看得见当前格与相邻格；未探索显「？」；到过的地点永久可见 |
| 灰度探测仪 | 常驻界面一角，显示当前格灰度 + 趋势箭头（**世界观测器，不是警报**） |

> 详：`12 世界与地图`（地形与地点分布）、`15 §1`（时间与体力）。

## 2. 商队资源（有哪些）

| 资源 | 拿来干嘛 |
|:-----|:-----|
| 金钱 | 交易、订单报酬、各项花销 |
| 食物 / 水 | 每天全队消耗；**断供**会掉士气、掉最大生命、拖慢重伤恢复 |
| 零件 / 药包 | 修车 / 治伤 |
| 货物 | 占车厢格，是赚钱的本体；压舱与卖货都靠它 |
| 商队耐久 | **只有货车有**；归零 = 抛锚，得修才能走 |
| 士气 | 影响队伍状态；靠休整与消费恢复，断供会掉 |

- 断粮 / 断水 / 抛锚 / 耐久分档的**具体后果 → `15`**。
- 人的构成、车的构成（几辆、谁坐哪）→ `16`。
- 一切的**具体数值都是未定的参考值** → `04` + `08`。

## 3. 地点：能做什么

| 功能 | 大城 | 小城 | 城镇 | 驿站 | 村庄 |
|:-----|:---:|:---:|:---:|:---:|:---:|
| 买 / 卖 | ✅ | ✅ | ✅ | ✅ | ✅（量极少、价最高） |
| 接订单 | ✅ 各类 | ✅ 各类 | ✅ 小单为主 | ✅ 小单为主 | ✅ 极小单 |
| 休整（恢复士气） | ✅ 城市 | ✅ | ✅ 城镇 | ✅ 驿站 | ❌ |
| 修车 | ✅ | ✅ | 🔸 少量 | ✅ 偏修车 | ❌ |
| 普通治疗（轻伤） | ✅ | ✅ | ✅ | ✅ | ❌ |
| **恢复重伤 / 失能** | ✅ **只有城市** | ✅ | ❌ | ❌ | ❌ |
| 招募 | ✅ | ✅ | ❌ | ❌ | ❌ |
| 打听情报 / 等天气 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 出发 | ✅ | ✅ | ✅ | ✅ | ✅ |

- **接订单：四类地点都能接**（城市 / 城镇 / 驿站 / 村庄）——驿站也有人生活、自己也缺零件补给。
- **招募：只有城市（大城 / 小城）能招**；城镇 / 驿站 / 村庄都不招。
- **地点只分四类**（城市 / 城镇 / 驿站 / 村庄）；大城与小城是"城市"这一类的两档。
- **城镇 / 驿站是"要东西"的那一头**：除了零散小单，也会有**从城市成批运生活物资（粮食 / 水 / 日用品）过来**的订单——它们是消费端，不是只有小单。
- **同一片区域的同类地点共用一套模板**：一片区域里的城镇（或驿站），价格与订单**共用同一套模板**，再按地理微调（例：靠着河的城，水更便宜）。
- 恢复士气、修车、治疗的具体规则与数值 → `15` / 0A 第2A类；**城市态度**（统治层政策：关税 / 准入）不裁定普通 NPC。

> 详：0A 第2A类（地点功能权威口径）。

## 4. 交易与讲价

| 规则 | 说明 |
|:-----|:-----|
| 三类场景 | ① 买货压价 ② 卖货抬价 ③ 接订单谈酬金 |
| 什么时候讲 | 大单 / 订单默认进讲价；小单按默认价成交，玩家主动按键才讲 |
| 谁来讲 | 有「账房 / 商人」特质的特殊人员成交空间大；没特质也能讲，但成功率低、对方底线硬 |
| 怎么讲 | NPC 心里有**隐藏三价**（成本底价 / 满意价 / 急迫度）；玩家出价 → 对方给**态度反馈**（不显数字）→ 最多 5 轮拉锯 |
| 价格怎么来 | **每城一套价**（大城最低、村庄最贵、有特产的城把该货调低）；**同一片区域的同类地点共用一套模板**，再按地理微调（例：靠河的城水更便宜）；**每天随机波动** |
| 还受什么影响 | 讲价者特质、商会声望、个体商人信任、城市态度、所在灰度、对方是否急需此货 |
| 信任分两层 | 宏观 = 商会城市分会声望；个体 = 有名字的固定商人（公平升、欺诈降 → 暗折扣 / 留好货 / 透情报） |
| 谈崩怎么办 | 可妥协价成交 / 改日再来（不涨价）；**稀缺货与订单有 1~2 周的竞争者窗口**，会被别家买走 / 接走 |
| 货能卖到哪 | **任何地点都收货**（城市 / 城镇 / 驿站 / 村庄），各按自己的收货价结算 |

> 详：`14 跑商系统数值`（交易 · 讲价）+ 0A 第10A类 §一。**讲价与交易是两件事，写在全都在 `14`。**

## 5. 订单

**4 大类**

| 类型 | 内容 | 时效 | 要接吗 |
|:-----|:-----|:----:|:----:|
| **送货** | 把货送到指定收货地（货可以是自己买的、也可以是替委托方代运） | 有期限 | ✅ 要接 |
| **护送** | 护送某人 / 某物到指定地点 | 有期限 | ✅ 要接 |
| **收购** | 指定物品高价收 | **有窗口**（不用接） | ❌ 交货就给钱 |
| **悬赏** | 击杀指定敌人 / Boss | **有窗口**（不用接） | ❌ 打掉就领赏 |

- **档位**：按距离分 **短途 / 中途 / 长途 / 超长途** 四档（分界与报酬算法 → `14 §五B`）。
- **报酬**：随档位与阶段递增（具体倍率 → `14`）。
- **期限**：按路程折算并留余量（公式 → `14`）。
- **同时持单无上限**——多接顺路单正是赚钱法（A→B 路上经过 C，两张单一起做）。
- **交付四档**：早到 / 正常 / 延期 / 严重超期（奖惩各不相同 → `14`）。**货物被毁不算订单失败**，只亏货。
- **两类不用接的单也有窗口期**：时长约等于"玩家正常跑完所需时间"的 **2~3 倍**；**过了会被别的商队 / 赏金猎人做掉，订单直接消失**。
  - 两个作用：① 订单不会永远挂在那儿等你 ② 让你感觉**世界上不只你一个商队**。
- **送货运的是什么**：常是城市往城镇 / 驿站运的**生活物资**（粮食 / 水 / 日用品），也有自己买来转卖的高价货。
- 接单时可以**讲价加酬**（见 §4）。

> 详：`14` + 0A 第10A类 §二。

## 6. 卡牌战斗

**怎么触发（每一类都要写清来源）**

| 触发场合 | 怎么进战斗 |
|:-----|:-----|
| 野外遇敌 | 走格时掷遭遇 → 强盗 / 野兽 / 灰兽进来打（判定 → `19`） |
| 灰兽接触（敌对） | 进灰兽格发现敌对灰兽 → **只能打**（友善 / 中立才有离开的选项，见 §8） |
| 订单护送遇袭 | 护送途中触发袭击事件 → 进战斗（→ `19` / `14`） |
| **城内遇袭** | **城市不是绝对安全区**：城里也有小偷、强盗，进城市后**小概率**在城内直接开打 |
| 最终战 | 本钱攒够后**主动挑战灰烬**（唯一 Boss 战） |

| 规则 | 说明 |
|:-----|:-----|
| 我方 | 初始 **3 名角色**（护路人 / 荒野射手 / 修补师），每人有各自的牌组 |
| 出牌 | **起手抽 3 张（2 张动作 + 1 张记忆）**；🔴 **没有出牌上限** —— 回合内出牌数 / 抽牌数都不受限制，**唯一闸门是体力池**。回合结束清空手牌 |
| 动作卡 | 每人 6 张基础卡（名单与数值 → `17 §4`） |
| 记忆卡 | 来自已植入的知识领域（见 §7） |
| 体力 | 牌消耗**具体体力点数**（微 0 / 轻 25 / 标准 50 / 重 100 / 极限 150）；**全队共享一个池 = Σ 各人体力（基准 50/人）**，可攒（上限 = 2 × 每回合回复） |
| 状态 | 标记 / 流血 / 穿甲 / 迟滞 / 灼烧 / 反击 / 护盾 / 超载 / 灰蚀 |
| 节奏 | 无回合上限、可布阵、有随机变数；**没有实时压迫**，节奏由玩家掌控 |
| 敌人 | 强盗 / 野兽 / 灰烬兽（原生 + 被感染变异并存）+ Boss |
| 灰度影响 | 灰度越高 → 灰兽越容易出现、越强 |
| 撤退 | 中后期可以撤（判定与代价 → `17`）；Boss 默认撤不了 |

**最终 Boss（灰烬）**：**它存在的唯一意义就是把这一局"走到头"**——本版**没有任何剧情、不做任何世界观包装**，打一场、赢了通关，用来验证**数值平不平衡、玩法顺不顺**。
**血量、伤害、回合阶段全部由战斗系统定 → `17`**（本文件一个字不写）。

> 详：`17 卡牌战斗`。

## 7. 角色成长与记忆

> **本游戏没有"技能"这个词，统一叫「记忆」。**

| 规则 | 说明 |
|:-----|:-----|
| 记忆是什么 | **知识领域**（化学 / 机械 / 草药 / 旧文明语 / 谈判 / 地形学……），不是纯战斗技能 |
| 怎么获得 | **完整获得**：要么拿到完整记忆，要么不获得——**无碎片、无熟练度、无经验值** |
| 一个领域 → 三类卡 | **战斗卡**（战斗内打出，占**起手 1 张记忆牌**的名额）· **探索卡**（野外 / 事件，被动或给额外选项）· **跑商卡**（交易 / 讲价，被动或给额外选项） |
| 槽位 | 有数量上限（初始值 / 上限 → `18`） |
| 谁能植入 | 角色有**领域理解标签**（来自职业与已植入领域）；**只有能理解的角色才植得进去** |
| 强化 | 数值强化 / 状态强化 / **火种词条**（给记忆加词条） |
| 推演 | 记忆可以推演（→ `18`）——成长不靠打怪刷经验 |
| 火种 | **稀有战略资源**：记忆强化、记忆融合、火种词条；**基本不卖**，鼓励去遗迹 / 高灰区探索获取 |
| 重伤 | 重伤 / 失能 → **只有城市能恢复**（见 §3） |

> 详：`18 角色成长与记忆`。

## 8. 灰烬生态 · 天气 · 野外遭遇

> **灰烬是世界的底色，不是"大事件"**——世界空旷，危险是一种存在感，不是血条压迫。

**灰度（0~100 的观测指标）= 基准 + 波动**

| 层 | 是什么 | 干嘛用 |
|:--|:--|:--|
| **基准灰度** | **只有地区天生自带的那一份**，固定不动 | **只决定这一带产什么**（高灰区普通货少、灰烬特产多） |
| **波动灰度** | 浮在基准之上那部分 = **时间随机游走** + **天气** | 让灰度"呼吸"；**不改变资源构成** |

- **天气就是波动的一种**（用户 2026-09-12）：灰烬风 / 灰烬风暴会把该区灰度顶上去，风退了再慢慢落回来。天气怎么触发归 0A 第5A类，它对灰度的影响归 0A 第8A类。
- **探测仪显示值** = 基准 + 波动，战斗与损耗都按这个值算。

**灰度带来的影响**

| 影响 | 规则 |
|:-----|:-----|
| 地貌通行 | 灰度高 → 地面软化 / 裂隙 → 走起来更贵，宜绕路 |
| 腐蚀损耗 | 灰度越高，每日额外磨损越多（阈值与幅度 → `15` / `19`） |
| 感染风险 | 只在高灰区才有；感染后进【感染】状态 → 城市检疫 / 药包治愈（本版无防护装备） |
| 灰兽 | 灰度越高 → 越容易遇到、遇到越强 |

**灰兽（生态居民，不是"怪物大军"）**

| 生态角色 | 态度 | 常见度 | 说明 | 危险度 |
|:-----|:--:|:--:|:-----|:----:|
| 掠食型 | **敌对** | **最常见** | 主动猎食（如虎类本能） | 高 |
| 群居迁徙型 | 中立 | 较少 | 像象群，聚集时危险（围城属此类） | 中~高 |
| 食腐清道型 | 中立 | 较少 | 吃灰烬沉积物，一般不咬人 | 低 |
| 共生型 | **友善** | 罕见 | 可理解 / 可互动 | 极低 |

> **敌对占多数**：灰兽是"敌人"这一类，**友善 / 中立要更少见**——不然这一整块就形同虚设（用户 2026-09-12）。

| 灰度分层 | 主要灰兽 |
|:----:|:-----|
| 低灰 | 几乎无灰兽（起始区就在这档，天然防暴毙） |
| 中灰 | 以**被灰烬感染变异的普通野兽**为主 |
| 高灰 | 以**灰烬生态自古演化的原生动物**为主 |

> 分界线为 ⚠️ 待定值 → `19`。

**路上遇到灰兽（选项随"态度"变，地图上不预标）**：进灰兽格 → 显示"发现 X（种类 / 规模 / 态度）" → 按态度给选项：

| 遇到的灰兽 | 能做什么 |
|:-----|:-----|
| **友善**（共生型，罕见） | 可**安全离开**，也可互动 |
| **中立**（食腐 / 群居，较少） | 可**安全离开**；也可主动攻击（它会反击，但**不追**） |
| **敌对**（掠食型，多数） | **没有绕行 / 驱离 / 强行通过这些回避选项——只能打**（进战斗后可撤退，撤退规则 → `17`） |

> 用户 2026-09-12：灰兽**看是哪种**再给选项；敌对就是硬碰硬。0A 第8A类 §5 / §7 已按此回写（v2.2）。

**灰烬风暴**：灰烬生态区的偶发短时天气（类比沙尘暴）——**中立灰兽躲起来、掠食型更活跃**，不鼓励继续推进，引导找避难所或就地挨过。

**常规天气与野外随机事件**：影响移动与视野的普通天气，以及路上会撞到的随机事件 → 表都在 `19`。

## 10. 通关与结束

| 结果 | 触发 |
|:-----|:-----|
| **通关** | 本钱攒够后**主动挑战灰烬**、击败它 → 结算（走过的天数 / 金钱 / 战斗次数 / 订单完成数） |
| **手动退出** | 玩家自己结束本局（一局制、无存档） |

> **本版没有"失败"这一档**（用户 2026-09-12）：打不过、走不动**不会被判负，也不会结束这一局**——触发的是**强制撤退**（0A 第3A类 §5）：丢掉货物与粮水零件、**退回最近的安全点**、全员休养、士气下降、耐久掉到低位，**然后接着玩**。
> 只有两种情况会触发撤退：**士气归零** / **全队倒下 + 耐久归零**（细则 → `15 §8`）。
> **本版没有任何剧情**——最终战也只是"走个流程"，**目的是测数值平衡与玩法手感**。
> 通关后的结局文本、遗迹产出 → `21`。
