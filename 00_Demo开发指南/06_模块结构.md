## 1. 文件清单

```
main.py                  # 入口：初始化、主循环、状态机调度
config.py                # 所有固定配置（城市坐标/货物价/敌人/记忆/改造/事件/数值常量）
state.py                 # Caravan / GameState 全局状态容器 + 初始化（开局抵债包裹）
core/
  rng.py                 # 随机数封装（可设种子、可复现，文档 10）
  log.py                 # 日志系统（战斗/经济/调试，文档 11）
world/
  map.py                 # 地图生成（200×200）、格子、可见性、移动、灰度场
  ash.py                 # 灰烬生态：腐蚀/感染/灰兽偶遇/灰烬风暴（文档 03 §6）
caravan/
  supply.py              # 补给消耗、断粮断水、耐久分档、修车
  character.py           # 角色创建、HP/状态、记忆植入（轻量）、改造（第三成长轴）
trade/
  trade.py               # 买卖、价格波动、货舱容量
  haggle.py              # 讲价 5 轮拉锯（文档 03 §4 / 04 §10）
  order.py               # 订单生成/接单/交付/超时
combat/
  combat.py              # 卡牌战斗主流程（AP/手牌/状态/撤退/boss）
  cards.py               # 卡牌定义与效果结算
event/
  event.py               # 随机事件触发与效果（文档 03 §8）
ui/
  cli.py                 # 命令行界面：标题/地图/地点/交易/战斗/事件/结算 渲染与输入
```

> 不强制按此目录层级建包（`world.` `caravan.` 等子包可选）；**核心是模块职责清晰、可单独测试**。若嫌包复杂，可扁平放根目录（如 `map.py` `combat.py`），只要文件名不冲突。

## 2. 模块职责表

| 模块 | 职责 | 不负责 |
|:--|:--|:--|
| main.py | 读配置→建 GameState→跑主循环状态机→分发到各界面 | 具体玩法逻辑（交给子模块） |
| config.py | 存全部常量与配置表 | 任何运行时状态 |
| state.py | 持有 `Caravan` 实例、开局初始化（角色/货车/抵债包裹）、全局查询 | 玩法规则 |
| core/rng.py | `roll()` / `choice()` / `chance()` 封装，种子管理 | — |
| core/log.py | 分级日志、战斗/经济观测、调试开关 | — |
| world/map.py | 生成地图、灰度场、移动 1 格结算（消耗/磨损/天气推进）、可见性 | 补给扣减细节（交 supply.py） |
| world/ash.py | 灰度→腐蚀/感染判定、灰兽偶遇概率、灰烬风暴 | 地图生成 |
| caravan/supply.py | 每日食物水扣减、断粮断水惩罚、耐久分档、零件修车 | 地图移动触发 |
| caravan/character.py | 角色对象、状态增删、记忆植入/强化、身体改造（排异/结果六态） | 战斗出牌 |
| trade/trade.py | 买/卖、城市价差、货舱满判断 | 讲价拉锯（交 haggle.py） |
| trade/haggle.py | 5 轮拉锯、NPC 三价、态度反馈、特质/声望/信任加成、谈崩 | 买卖执行（交 trade.py） |
| trade/order.py | 订单生成（按地点/距离）、接单、交付、超时扣声望 | — |
| combat/combat.py | 战斗状态机、AP、抽牌、出牌结算、撤退、胜负判定、boss | 卡牌数值（cards.py） |
| combat/cards.py | 卡牌库、效果映射（攻击/防御/治疗/修车/标记/流血） | 战斗流程 |
| event/event.py | 野外格掷骰选事件、执行效果 | 战斗触发（交 combat.py） |
| ui/cli.py | 所有界面渲染 + 键盘输入解析 | 玩法判定（只调子模块、显示结果） |

## 3. 依赖关系（禁止循环）

```
main.py
  ├─ config.py
  ├─ state.py ── config.py
  ├─ core/rng.py
  ├─ core/log.py
  ├─ world/map.py ── config.py, core/rng.py, core/log.py
  ├─ world/ash.py ── config.py, core/rng.py
  ├─ caravan/supply.py ── config.py, core/log.py
  ├─ caravan/character.py ── config.py, core/rng.py, core/log.py
  ├─ trade/trade.py ── config.py, core/rng.py, core/log.py
  ├─ trade/haggle.py ── config.py, core/rng.py
  ├─ trade/order.py ── config.py, core/rng.py
  ├─ combat/combat.py ── config.py, core/rng.py, core/log.py, combat/cards.py
  ├─ combat/cards.py ── config.py
  ├─ event/event.py ── config.py, core/rng.py, world/ash.py
  └─ ui/cli.py ── 所有玩法模块（仅调用、显示）
```

规则：
- `config.py` 与 `core/` 是被依赖叶子，不反向依赖玩法模块。
- `ui/cli.py` 在最上层，调用各玩法模块并渲染，**不把玩法逻辑写进 ui**。
- 玩法模块之间**尽量不直接互调**；需要共享状态时走 `Caravan` / `GameState`（由 main 传参）。

## 4. 入口与启动（main.py）

```python
# main.py 伪代码
def main():
    cfg = load_config()                 # 读 config.py 常量
    rng = RNG(seed=random_seed())       # 文档 10
    log = Log(level=cfg.LOG_LEVEL)
    state = init_game(cfg, rng, log)    # state.py：建 Caravan + 3 角色 + 抵债包裹，起点大城
    ui = CLI(state, cfg, rng, log)
    ui.show_title()                     # 标题界面（文档 02 §4）
    loop(state, cfg, rng, log, ui)      # 主循环（文档 07）

if __name__ == "__main__":
    main()
```

运行：`python main.py`（文档 01 §3）。可加 `--debug` / `--seed N` 便于复现测试（文档 10 / 11）。

## 5. 状态对象传递约定

- **`GameState` / `Caravan` 单一实例**：由 `main` 创建，作为参数传给各模块函数。不依赖全局单例（便于测试时构造隔离状态）。
- 模块函数签名示例：`move_step(state, cfg, rng, log)`、`start_combat(state, cfg, rng, log, context)`、`open_trade(state, cfg, rng, log, loc_id)`。
- `ui.cli` 持有 `state` 引用用于显示；输入后调用对应玩法函数修改 `state`，再重绘。

## 6. 实现注意（避免白做）

- 模块先写**骨架 + 接口**（函数签名、返回结构），再填规则，方便逐个测（用户强调"先能跑一局"）。
- `config.py` 集中所有 ⚠️ 初值，改数值只动这一处（文档 04 铁律：数值初值待实测调优）。
- 日志埋点在 `supply` / `trade` / `combat` / `character` 关键节点（文档 11），否则测不出"好不好玩/对不对"。
