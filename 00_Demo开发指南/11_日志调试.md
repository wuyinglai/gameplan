# 11 · 日志与调试（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 11/11 份
> 用途：定义**日志系统**——这是「测数值对不对」的眼睛。没有日志，玩家只能凭感觉，无法定位「太肝/太无聊/太随机」。
> 口径：纯 Python 标准库 `logging` 模块；分级；可开关。

---

## 1. 日志级别

```python
import logging
LOG_LEVEL = logging.INFO     # 默认 INFO；--debug 时 DEBUG
# 级别：DEBUG（细到每步）> INFO（关键节点）> WARN（异常/边界）> ERROR
```

| 级别 | 记录内容 |
|:--|:--|
| DEBUG | 每步结算细节（每日扣食物/水/耐久、灰度值、掷骰结果、抽牌、出牌数值、讲价每轮态度） |
| INFO | 关键节点（开局、移动天数、进入地点、接单/交付、战斗开始/结束、激活节点、通关/失败） |
| WARN | 边界触发（断粮、抛锚、排异失败、感染、非法输入） |
| ERROR | 未捕获异常（顶层 try/except 捕获，文档 09 §7） |

## 2. 战斗日志（combat）

每场战斗记录（DEBUG/INFO）：
```
[combat] start context=wild enemies=ash_beast(35hp)
[combat] day=12 round=1 ap=3 draw=[攻击,防御,标记,流血,治疗,修车,攻击]
[combat] ally=护路人 play=攻击 dmg=7 enemy_hp=28
[combat] enemy=ash_beast play=attack dmg=8 ally=荒野射手 hp=32
[combat] status apply=流血 stacks=2
[combat] end result=win turns=5 total_dmg=35
```

> 目的：核对 AP/手牌/伤害/状态是否如设计；定位「战斗太肝/太短」。

---

## 3. 经济日志（trade / supply）

每日与每笔交易记录（INFO/WARN）：
```
[econ] day=1 gold=300 food=10.0 water=8.0 dur=100 morale=6
[econ] day=2 food=9.25 water=9.25 dur=99  (move step)
[econ] trade buy food x5 cost=50 gold=250
[econ] haggle sell goods_tea rounds=3 final=+15% accept
[econ] order accept deliver tea->big_city reward=60 deadline=40
[econ] WARN starve food=0 morale=5 hp_all=-5
[econ] WARN durability=0 stranded(need repair)
```

> 目的：画出**金钱/食物/水/耐久曲线**，判断长距离补给是否太肝（文档 04 §2 备注）、讲价空间是否合理、订单报酬是否划算。

## 4. 调试开关

```bash
python main.py                 # 默认 INFO
python main.py --debug         # DEBUG 全量
python main.py --seed 12345    # 固定种子复现（文档 10）
python main.py --debug --seed 12345
```

`--debug` 同时：打印 seed、开启战斗/经济 DEBUG、异常打印堆栈（文档 09 §7）。

## 7. 日志实现要点

- 用 `logging` 模块，输出到 stderr（不混 stdout 的 UI 渲染）或文件 `game.log`。
- `--debug` 设 `logging.DEBUG`；否则 `INFO`。
- 关键处埋点：supply 每日结算、trade 每笔、combat 每回合、character 改造、map 移动、event 触发（文档 06 §6）。
- 不记录玩家隐私（本版无）；不记录无意义刷屏（DEBUG 才到每步）。
