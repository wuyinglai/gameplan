> 《余烬商队》·《Demo 程序编写指导》**大阶段一 · 基线 · 第 5 份（与 `04` 同批）**
> **⚠️ 2026-09-12 用户裁定：本文件按「空」计。** 下面所有数字**只是参考值，只能用来参考**；**数值框架尚未建立**，具体数值要**重新定**——不是定稿、不是依据。
> 用途：定义**代码里的全部固定配置与数值**（网页版 = `data.js`，**数据层**）。
> **本文件只放数据，不放逻辑**——规则计算归 `core.js`，绘制与输入归 `ui.js`（见 `01 §3.1`）。
> 口径：**HTML + CSS + 原生 JS（ES6）、零依赖**；`data.js` **引擎无关**，正式版整体搬走。
> 数值全部贴 `04_数值细化表` 的 ⚠️ 初值；调优时改 `04` → 同步此处。

## 1. 放在哪、怎么用

- 一个文件 `data.js`，**纯常量**，**不读外部 JSON / CSV**、**不发请求**（离线双击 `index.html` 即玩）。
- **不用 `import/export`**：`file://` 直开时 ES Module 会受 CORS 限制。用**全局常量**，`index.html` 里按 `<script src="data.js"></script>` 顺序引入。
- 所有表最终挂到 `GAME_DATA` 上，`core.js` / `ui.js` 只读它，**不改它**。

```html
<!-- index.html 引入顺序（不可颠倒） -->
<script src="data.js"></script>   <!-- 数据层：本文件 -->
<script src="core.js"></script>   <!-- 规则层：纯逻辑，禁止 DOM -->
<script src="ui.js"></script>     <!-- 表现层：绘制与输入 -->
```

## 17. 与 `core.js` 的边界（重要）

| 放这里（`data.js`） | 放 `core.js`（**禁止 DOM / canvas**） |
|:--|:--|
| 上表所有常量、价格、血量、概率 | 每日结算、伤害结算、订单判定、讲价拉锯、灰度推进 |
| 地点数组（由地图文件生成后贴入） | 地图查询、寻路、可见性计算 |
| 卡池名称 / id、升级公式的 base+step | 具体公式求值（`300+20*(n-1)` 等） |

> **一句话**：`data.js` 是"死的表"，`core.js` 是"活的算法"，`ui.js` 只负责把结果画出来。
