# 20 · 界面与操作

> 《余烬商队》·《Demo 程序编写指导》**界面与操作专项（单开一份）**
> **铁律（2026-09-11 用户定）**：界面长什么样、每一步怎么操作，**全部集中在这一份**。
> 其它文件**一律不写界面、不写键位**——改界面只动这里，查界面只来这。
> **只管**：界面构成 / 显示项 / 键位 / 界面之间怎么跳。
> **不管**：界面背后的规则与数值（→ `14` 跑商 / `15` 补给 / `17` 战斗 / `18` 成长 / `19` 灰烬 / `21` 遗迹）；场景切换条件 → `07 一局流程`。

---

## 1. 总原则

- **鼠标 + 键盘并用（2026-09-11 用户裁定）**：走格、切目标这类操作用键盘；**界面里的列表、选项、数量、按钮用鼠标点选**。全部靠键盘要记的快捷键太多，不现实。**两种都要能用，缺一不可。**
- **键盘常用键照旧保留**（见 §5 操作总表）；**界面上任何可选项都能用鼠标直接点**（点一行 = 选中，再点 / 确认 = 进入）。
- **单一焦点**：键盘操作时每个界面只有一处焦点，↑↓ 选、`Enter` 确认。
- **不崩**：非法输入只提示「无效指令」，不允许报错退出。
- **极简文字 UI**：方框 + 文字即可，不做美术、不做动画、不做音效。
- **HUD 常驻**：除标题界面与结算界面外，状态栏一直显示。

## 2. 常驻状态栏（HUD）

**固定顺序，一行显示：**

```
金钱 · 食物 · 水 · 零件 · 药包 · 车辆耐久 · 士气 · 位置 · 灰度 · 订单
```

| 显示项 | 显示成什么样 | 规则去哪看 |
|:-------|:-------------|:-----------|
| 金钱 | 数字 | `14` |
| 食物 / 水 | 数字（份） | `15` |
| 零件 | 数字 | `15` |
| **药包** | 数字（**2026-09-11 用户要求补上**） | `15` |
| 车辆耐久 | 数字（或按车分列） | `15` |
| 士气 | 数字 | `15` |
| 位置 | 坐标 + 地点名（无地点时只显坐标） | `12` |
| 灰度 | 数字 + 趋势箭头（↑↓→） | `19` |
| **订单** | **当前接单数 + 每单剩余天数**；**没有订单时整项不显示** | `14` / 0A 第10A类 |

> **不显示「第 N 天」（2026-09-11 用户裁定）**：天数不做常驻显示项。要看天数只有一条路——**挂在订单上**：接了几单、每单还剩几天。**没接单就一个天数都不出现。**
> HUD **不显示**生命条、手牌、记忆等——那些只在战斗界面与队伍状态界面里出现。
> HUD 只负责"显示"，数值本身一律不写在本文件；字段定义见 `05 数据结构`。

## 4. 各界面详述

### 4.1 标题界面
- 显示：游戏名 · 版本 · 「点击开始 / 按 Enter 开始」。
- 操作：鼠标点「开始」或 `Enter`；`Esc` 退出。

### 4.2 地图界面（平时）
- 布局：中间是地图网格（**只有当前格 + 相邻格可见**，未探索显「？」）；四周留 HUD 与提示行。
- 显示：当前格、可见格、地形（山/水/桥·林）、地点标记与名称、商队所在位置。
- 操作：
  - `w` `a` `s` `d` / 方向键 —— 上下左右**走一格**
  - **鼠标点相邻格** —— 同样**走一格**
  - `Enter` / 鼠标点当前格 —— 若站在地点格上，进入地点
  - `m` —— 展开整张地图（只看，不能走）
  - `i` —— 队伍状态
  - 空格 —— 原地休整 / 等待
  - `h` —— 帮助（键位表）
- 走格的消耗与结算时机 → `15`。

### 4.3 地点界面
- 显示：地点名 · 类型 · 一句话描述 · 可用功能菜单。
- 菜单项（**按地点类型不同，没有的功能直接不显示**）：
  交易 / 订单 / 休整 / 修车 / 治疗 / 招募 / 打听情报 / 出发
- 操作：**鼠标点菜单项**；或 `↑↓` 选 + `Enter` 进；`q` 回地图。
- 哪个地点有哪项功能 → 0A 第2A类。

### 4.4 交易界面
- 布局：**左右两栏 —— 左「买」、右「卖」**，中间是货物列表（名称 / 单价 / 本地库存）；顶部显示金钱与**车厢剩余容量**；底部一行操作提示。
- 流程：选货物 → 调数量 → 确认 → 立即结算。
- 操作：
  - 鼠标点货物行选中、点 `＋ / −` 调数量、点标签切买 / 卖
  - 键盘：`Tab` 切买 / 卖；`↑↓` 选货物、`←→` 调数量（也可直接数字键输入）
  - `Enter` / 点「确认」—— 成交
  - `P` / 点「讲价」—— **进入讲价界面**（谈这一单）
  - `q` —— 返回地点
- 价格、库存、容量、能否卖 → `14`。

### 4.5 讲价界面（独立界面，不塞进交易里）
- 布局：左 = 对方（态度表情 + 一句反馈话）；右 = 当前出价与被还价的记录；底部 = 本回合可选的出价档。
- 过程：**一轮一轮拉锯**（轮数上限与档位 → `14` / 0A 第10A类），每轮玩家选一个出价动作，对方给态度反馈。
- **不显示任何数字**（不显底价、不显成功率），只靠表情与文字反馈。
- 操作：**鼠标点出价档**；或 `↑↓` 选 + `Enter` 出价；`Esc` 收手（回原价）。
- 讲价规则、信任与声望影响 → `14` / 0A 第10A类。

### 4.6 订单界面
- 布局：左右两栏 —— 左「可接订单」、右「已接订单」。
- 列表每行：目的地 / 要求（货或人） / 报酬 / 期限 / 类型标签。
- 操作：**鼠标点订单行看详情、点「接单」**；或 `Tab` 切栏、`↑↓` 选、`Enter` 看详情或接单；`q` 返回。
- 订单有几类、怎么接、怎么交 → `14` / 0A 第10A类。

### 4.7 战斗界面
- 布局：
  - 上：**敌方区**，每个敌人一格（名称 + 生命条 + 状态图标）
  - 中：**我方区**，每个角色一格（名称 / 生命条 / 状态图标）
  - 下：**手牌区** + 行动提示
  - 角：回合数、当前行动的角色
- 操作：
  - **鼠标点牌选中、点敌人 / 角色选目标**
  - 键盘：数字键选牌；`Tab` 切换当前角色 / 切目标；`Enter` 打出选中的牌
  - `E` —— 结束回合
  - `R` —— 撤退
- 状态图标：标记 / 流血 / 穿甲 / 迟滞 / 灼烧 / 反击 / 护盾 / 超载 / 灰蚀（图标 + 一行说明）。
- 出牌规则、敌人、数值 → `17`。

### 4.8 遗迹界面
- 进入遗迹：显示遗迹名（大 / 小）+ 一段环境描述。
- 操作：**鼠标点搜索区域**；或 `↑↓` 选 + `Enter` 搜索；每次搜索给结果（拿到什么 → `21`）。
- 产出规则 → `21`。

### 4.9 事件界面
- 显示：事件文字 + 2~4 个选项。
- 操作：**鼠标点选项**；或 `↑↓` 选 + `Enter` 确认。
- 事件表 → `19`。

### 4.10 队伍状态界面（`i` 打开）
- 显示：逐个角色（名称 / 职业 / 生命 / 状态 / 已植入的记忆）+ 商队整体（金钱 / 货物 / 车辆耐久 / 士气 / 补给）。
- 操作：**鼠标点角色**；或 `←→` 切角色；`Esc` / `q` 返回。
- 数值 → `04` / `17` / `18`。

### 4.11 结算界面
- 显示：通关 or 失败 · 总天数 · 结束时金钱 · 战斗场次 · 完成订单数 · 一行结语。
- 操作：`Enter` / 点「确定」回标题。
- 记录什么 → `22`。

## 5. 操作总表（一处查全部键位）

| 场景 | 键 / 鼠标 | 作用 |

| 通用 | `↑↓` | 上下选项 |
| 通用 | `Enter` | 确认 / 进入 |
| 通用 | `Esc` `q` | 返回上一级 |
| 通用 | 数字键 | 直接选第 N 项 |
| 地图 | `w` `a` `s` `d` / 方向键 | 走一格 |
| 地图 | **鼠标点相邻格** | 走一格 |
| 地图 | `m` `i` `h` | 地图 / 队伍状态 / 帮助 |
| 地图 | 空格 | 原地休整 / 等待 |
| 交易 | `Tab` / 点标签 | 切买 / 卖 |
| 交易 | `←→` / 点 `＋ −` | 调数量 |
| 交易 | `P` / 点「讲价」 | 进讲价 |
| 讲价 | 点出价档 / `↑↓` `Enter` `Esc` | 选出价 / 出价 / 收手 |
| 订单 | `Tab` / 点标签 | 切「可接 / 已接」 |
| 战斗 | 点牌 / 数字键 | 选牌 |

| 战斗 | `R` | 撤退 |

## 6. 界面之间怎么跳（只画关系）

```
标题 → 地图 ⇄ 地点 → 子界面（交易 / 讲价 / 订单 / 修车 / 治疗 / 招募 / 打听）
                     ↕
                  回地图
地图 →（踩到遗迹）→ 遗迹界面 → 回地图
地图 →（遇敌）→ 战斗界面 → 回地图
地图 →（触发事件）→ 事件界面 → 回地图
任意 →（通关 / 失败）→ 结算界面 → 标题
```

> 这只是"谁能到谁"。**什么时候会触发**（怎么算遇敌、什么时候掷事件、胜负怎么判）→ `07 一局流程` 与 `15` / `19` / `21`。

## 7. 本版界面不做

| 不做 | 说明 |
|:-----|:-----|
| 设置界面 | 无（不做改键、音量、画面） |
| 存档 / 读档界面 | 无（一局制） |
| 美术皮肤 / 动画 / 音效 | 无（方框 + 文字） |
| 地图缩放 / 拖拽 | 先固定视图（`m` 只切"局部 / 全图"两种） |
| 教程 / 引导界面 | 无（`h` 里放键位表即可） |
