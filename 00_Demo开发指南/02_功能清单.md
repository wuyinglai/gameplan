# 02 · 功能清单

> 《余烬商队》第一版试玩Demo · 开发指南第 2/11 份
> 用途：明确Demo**要做什么、不做什么、界面长什么样、玩家怎么操作**——AI照此实现，不越界。

---

## 1. Demo目标回顾

玩家能完整体验：**开局 → 接订单买货 → 出发走格子 → 路上事件/战斗 → 到达小城/驿站交单赚钱 → 补补给 → 回灰原城激活节点 → 城市复活** 的一局。

**核心验证：跑商循环**（两城物价差 → 低买高卖 → 送货订单 → 赚钱 → 补给管理 → 战斗 → 激活节点）。

---

## 2. Demo城市方案（已定）

| 地点 | 类型 | 说明 |
|:-----|:-----|:-----|
| **灰原城** | 大城（唯一） | 起点、唯一有节点、有交易所/医馆/工坊（激活后开放） |
| **小城A** | 小城 | 灰原东南，农耕型，产粮 |
| **小城B** | 小城 | 灰原西北，猎户型，产兽皮 |
| **驿站** | 驿站 | 灰原与小城之间的中途补给点（1个） |

**贸易逻辑：**
- 灰原城：基准物价，产什么都一点，不特别缺
- 小城A：粮食便宜 → 运到灰原/小城B卖
- 小城B：兽皮/肉便宜 → 运到灰原/小城A卖
- 小城A缺盐缺零件、小城B缺粮缺水 → 玩家送货订单可赚

**小城无节点**——只有灰原城能激活节点（Demo核心目标唯一）。

|:-----|:-----|:-----|
| 通用 | `数字键` | 选择菜单项 |

| 地图 | `i` | 查看商队状态 |

## 5. 地图（Demo范围）

### 5.1 地图结构

网格地图（大小约 7×7），格子类型：

| 格子类型 | 说明 |
|:---------|:-----|
| 大城 | 灰原城（唯一） |
| 小城 | 小城A、小城B |
| 驿站 | 1个中途补给点 |
| 野外 | 普通移动格（可能遇敌/事件） |
| 障碍 | 不可通行 |

### 5.2 地点间距

- 灰原城 → 驿站：约2格
- 灰原城 → 小城A：约3格
- 灰原城 → 小城B：约3格
- 小城A → 小城B：约4格（可以绕）

### 5.3 可见性

- 玩家看到**当前格和相邻格**
- 未探索格子显示"？"
- 到达过的地点永久可见

### 5.4 野外事件概率（走野外格时）

- 约40%：无事发生
- 约25%：遭遇敌人（战斗）
- 约20%：发现补给（随机食物/水/零件）
- 约15%：特殊事件（商人求助等）

## 6. 要做功能（详细）

### 6.1 开局
- 标题界面 → 背景介绍（3~5行：灰潮、九城、商队、核心来历）
- 命名商队（回车用默认名）
- 初始状态（数值见文档03）：
  - 3角色（护路人/荒野射手/修补师）
  - 金钱、食物、水、零件（初始数值）
  - 1辆货车（车厢容量）、商队耐久
  - 拥有**余烬核心**（快死的老头送的，不知道干嘛用的——主线钩子）
  - 开局在灰原城

### 6.2 地图与移动
- 地图界面走格子（w/a/s/d）
- **走1格 = 1天**，天数+1
- 走格结算：消耗食物/水（每人1/4份）、耐久磨损
- 进入格子判定：大城→城市界面；小城/驿站→地点界面；野外→事件掷骰
- 障碍格不可走，有提示

### 6.3 商队状态
- 状态栏常驻（见3.2）
- `i`键查看明细

### 6.4 补给系统
- 食物/水消耗：每人每天1/4份食物+1/4份水（3人=每天各3/4份）
- 食物耗尽 → 每天士气-1 + 挨饿提示
- 水耗尽 → 每天士气-1 + 生命惩罚（比断粮严重）
- 零件：修车用（战斗中也能修车）
- 耐久归零 → 无法移动（需在城市修车）
- 补给在野外格偶发发现（见5.4）

### 6.5 城市/地点界面（灰原城/小城A/小城B/驿站）

| 功能 | 灰原城 | 小城 | 驿站 |
|:-----|:------:|:----:|:----:|
| 交易（买/卖） | ✅ | ✅ | ✅（有限库存） |
| 接订单 | ✅ | ✅ | ❌ |
| 休息（50金，士气+1） | ✅ | ✅ | ✅ |
| 修车（零件+钱） | ✅ | ❌ | ✅（偏修车） |
| 治疗（医馆，激活后） | ✅ | ❌ | ❌ |
| 激活节点 | ✅（核心目标） | ❌ | ❌ |
| 出发 | ✅ | ✅ | ✅ |

### 6.6 交易系统
- 买卖物品：食物、水、零件 + 特产（粮食、兽皮、肉、盐）
- 价格按地点不同（灰原基准/小城+10%）
- 卖货：玩家库存可卖；买货：地点库存有限（可卖空）
- 货物占车厢格

### 6.7 订单系统
| 项目 | 规则 |
|:-----|:-----|
| 类型 | 送货订单（运X到Y地）、收购订单（交X物给钱） |
| 接取 | 城市/小城接单，一队同时最多3个 |
| 送货 | 接到货物→送到目的地→自动交付得报酬 |
| 收购 | 有货直接交（不用接） |
| 期限 | 送货有期限（天数），超时失败扣声望 |
| 报酬 | 按距离和难度（数值见文档03） |

### 6.8 卡牌战斗（简化版）
- 触发：野外遇敌（25%）
- 我方：3角色，每回合**行动力3点、抽7张**
- 手牌（初始固定技能）：
  | 牌 | 费用 | 效果 |
  |:---|:---:|:-----|
  | 攻击 | 1 | 造成5~8伤害 |
  | 防御 | 1 | 获得护盾（挡X伤害） |
  | 治疗 | 1 | 恢复X生命 |
  | 修车 | 1 | 消耗1零件，耐久+X |
- 敌人AI：简单（优先打血量最低）
- 结束：胜利→战利品（金钱+随机补给）；失败→撤退回安全点损失补给
- 战斗中可撤退（`r`）

### 6.9 敌人（3种）
| 敌人 | 生命（参考） | 攻击（参考） | 分布 |
|:-----|:---:|:---:|:-----|
| 强盗 | 20 | 5 | 靠近小城B方向多 |
| 野兽 | 15 | 4 | 野外常见 |
| 灰烬兽 | 35 | 8 | 稀有（地图边缘） |

### 6.10 随机事件
| 事件 | 效果 |
|:-----|:-----|
| 发现补给 | 获得随机补给 |
| 遭遇伏击 | 进入战斗 |
| 商人求助 | 选择：帮忙（得报酬）/离开 |

### 6.11 激活节点（Demo核心目标）
- 灰原城"激活节点"选项 → 插入余烬核心 → 文字演出（城市亮了）→ **通关**
- 激活后：交易所/医馆/工坊解锁（可体验）

### 6.12 结束条件
- **通关**：激活灰原城节点 → 结算
- **失败**：耐久归零且无法修车 / 全队重伤无法继续 → 结算（失败评价）
- 结算显示：天数、金钱、战斗次数、订单完成数、结局文字

## 7. 不做功能（明确排除）

| 不做 | 说明 |
|:-----|:-----|
| 遗迹探索 | 无 |
| 灰兽潮 | 无 |
| 主线剧情/教团 | 仅开局背景文字 |
| 支线 | 无 |
| 枯林城等其余大城 | Demo只有灰原一座大城 |
| 99小城 | Demo只做2座小城 |
| 招募/车队扩展 | 固定3人+1车 |
| 联合商队 | 无 |
| 记忆系统 | 固定技能 |
| 天气系统 | 用随机事件代替 |
| 存档 | 无（一局制） |
| 装备系统 | 无 |
| 声望系统 | 简化（订单失败扣声望，无面板） |
| 医馆治疗细化 | 灰原城激活后才有，简版 |

## 8. 游戏时长目标

- 一局：**约15~25分钟**（熟悉后可10分钟）
- 地图：灰原城 + 2小城 + 1驿站 + 周边野外（约30格）
- 订单：同时存在4~6个
