# 02 · 功能清单

> 《余烬商队》第一版试玩Demo · 开发指南第 2/11 份
> 用途：明确Demo**要做什么、不做什么**——AI照此实现，不越界。

---

## 1. Demo目标回顾

玩家能完整体验：**开局 → 接订单买货 → 出发走格子 → 路上事件/战斗 → 到达目的地交单赚钱 → 补补给 → 激活城市节点 → 城市复活** 的一局。

---

## 2. 要做功能（详细）

### 2.1 开局
- [ ] 游戏启动，显示标题和简短背景介绍（2~3行文字）
- [ ] 玩家命名商队（可选：不输入就用默认名）
- [ ] 初始状态：3名角色、金钱、补给、1辆货车、商队耐久

### 2.2 地图与移动
- [ ] 大地图（灰原城周边），网格表示，格子类型：城市/驿站/村庄/野外/障碍
- [ ] 玩家在地图上走格子（输入方向 w/a/s/d 或 1-4 选择方向）
- [ ] **走1格 = 1天**，天数累计
- [ ] 每走1格：消耗补给（食物/水）、商队耐久磨损
- [ ] 地图显示：当前位置、可见格子（信息等级简化：能看到相邻格）

### 2.3 商队状态（HUD）
- [ ] 随时可查看：金钱、食物、水、零件、商队耐久、士气、天数
- [ ] 显示当前位置和目的地方向

### 2.4 补给系统
- [ ] 食物/水按1/4份消耗：每人每天1/4份食物 + 1/4份水
- [ ] 食物或水耗尽 → 每天扣士气/生命（惩罚）
- [ ] 零件：修车用（战斗中/休息时）
- [ ] 商队耐久：每天磨损，归零无法移动（需修车）

### 2.5 城市界面（灰原城）
在城市内可选择：
- [ ] **交易**：买/卖货物（食物、水、零件、货物）
- [ ] **接订单**：查看并接取送货订单
- [ ] **休息**：花费金钱恢复士气
- [ ] **修车**：花零件/钱恢复耐久
- [ ] **激活节点**：有核心时激活→城市复活（Demo核心目标）
- [ ] **出发**：离开城市回到地图

### 2.6 卡牌战斗（简化版）
- [ ] 遭遇敌人触发战斗（随机或固定点）
- [ ] 3名角色出战：护路人/荒野射手/修补师
- [ ] 每回合行动力 = 3，抽牌 = 7张
- [ ] 出牌：攻击/防御/治疗/修车
- [ ] 敌人AI：简单（攻击/偶尔防御）
- [ ] 战斗结束：胜利→战利品（金钱/食物/材料）；失败→撤退或队伍重伤
- [ ] 撤退功能（战斗中可撤退）

### 2.7 敌人（2~3种）
- [ ] 强盗（人类，普通）
- [ ] 野兽（普通/稍弱）
- [ ] 灰烬兽（强，稀有）
- [ ] 敌人有生命/攻击/简单技能

### 2.8 订单系统（简化）
- [ ] 送货订单：从A城运货到B城（Demo：灰原↔附近驿站/村庄）
- [ ] 接单后货物进入商队，到目的地交付得报酬
- [ ] 有期限（天数），超时失败扣声望

### 2.9 随机事件（1~2种）
- [ ] 路上遇到：发现补给（小奖励）/ 遭遇伏击（进入战斗）
- [ ] 事件有概率触发，事件后显示文字描述

### 2.10 激活节点（Demo核心目标）
- [ ] 玩家获得"余烬核心"（开局/剧情简单交代）
- [ ] 在灰原城激活节点 → 城市复活（文字演出）→ Demo通关/阶段完成
- [ ] 激活后：商路开通提示、Demo结束画面

### 2.11 结束条件
- [ ] 通关：激活节点后显示结束画面（记录天数/赚的钱/胜负）
- [ ] 失败：商队耐久归零且无法修复 / 全队重伤无法继续 / 金钱负数无法偿还
- [ ] 显示结算（天数、赚取、战斗次数）

---

## 3. 不做功能（明确排除）

| 不做 | 说明 |
|:-----|:-----|
| 遗迹探索 | 无 |
| 灰兽潮 | 无 |
| 主线剧情/教团 | 仅开局背景文字，无剧情系统 |
| 支线 | 无 |
| 小城/99城网络 | Demo只有灰原城+周边小地点 |
| 招募/车队扩展 | 固定3人+1车 |
| 联合商队 | 无 |
| 记忆系统 | 战斗用固定技能（不实现记忆融合/升级） |
| 天气系统 | 只做1-2个随机事件代替 |
| 存档 | 无（一局制） |
| 声望系统 | 简化（订单失败扣点声望，但不深入） |
| 装备系统 | 无 |

---

## 4. 游戏时长目标

- 一局 Demo：**约10~20分钟**
- 地图规模：**灰原城 + 周边8~15个格子**（1~2个驿站/村庄 + 野外）
- 订单数量：同时存在3~5个订单

---

## 5. 验收基本标准（AI自测用）

- [ ] `python main.py` 能启动，不报错
- [ ] 能走格子、天数增加、补给消耗
- [ ] 能进城市交易、接订单
- [ ] 能触发战斗并打完（胜/败/撤退都有处理）
- [ ] 能激活节点 → 通关
- [ ] 补给耗尽/耐久归零有惩罚，不会崩溃
- [ ] 输入非法指令有提示，不崩溃
