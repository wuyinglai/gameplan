# 02 · 功能清单（极简测试版）

> 《余烬商队》极简测试版 · 开发指南第 2/4 份
> 用途：明确本版**要做什么、不做什么、界面长什么样、玩家怎么操作**。AI 照此实现，不越界。
> 口径：2026-09-07 裁定——无剧情、200×200、3 城（1 大 + 2 小）、最终 boss = 灰烬兽。

---

## 1. 本版目标

玩家能完整体验一局：**开局 → 接单买货 → 200×200 地图走格 → 事件/战斗/灰烬生态 → 到城卖货交单赚钱 → 补补给 → 激活大城节点反应炉 → 灰烬兽最终战 → 击败通关**。

核心验证 = 跑商循环 + 卡牌战斗 + 讲价 + 灰烬生态 + 节点激活 + 最终战，**好不好玩、数值对不对**。

---

## 2. 城市 / 地点方案（已定 · 3 城）

| 地点 | 类型 | 说明 |
|:-----|:-----|:-----|
| **大城** | 大城（唯一，起点） | 有**节点反应炉**（通关触发点）；基础交易/工坊/改造舱激活前即有，激活后升级高级版 + 城市管理层大量奖励。持有余烬核心即激活 |
| **小城A** | 小城 | 无节点反应炉；比镇便宜、危险、可接受撤退（第2A类口径）；产某特产 |
| **小城B** | 小城 | 同上；产另一特产 |
| **驿站** | 驿站 | 中途补给/修车点；**部分有节点（信号中继）**，**部分九城时代损坏无节点**（随便分布，不需合理） |
| **村庄** | 村庄 | 轻量贸易点，可有少量买卖/订单 |

**贸易逻辑（随便定，能测即可）：**
- 大城：基准物价，啥都一点
- 小城A：特产甲便宜 → 运大城/小城B 卖
- 小城B：特产乙便宜 → 运大城/小城A 卖
- 两小城互缺不同货 → 送货订单可赚

**节点口径：** 节点反应炉仅大城有（激活=通关触发）；驿站节点=信号中继（只影响「接入」表现，机制上可简化，不强制影响玩法）。复兴九城/多城激活**不做**。**玩家可完全不激活、照样跑商**（正式版非强制；本测试版以激活为通关测试动作，但基础城市功能与三轴成长基础版激活前即全有）。**身体改造轴**：基础改造舱激活前即有，可做全部改造项（有排异风险，可重试）；激活后升级高级改造舱（无排异、解锁稀有大型项）。**激活奖励**：城市管理层给予一次性大额赏金 + 声望 + 旧文明许可（强激励非门槛）。

## 3. 主线（无剧情，极简）

```
跑商攒资源 → 抵达大城并激活节点反应炉（插入余烬核心，钥匙不消耗）
→ 灰烬兽作为最终 boss 出现（随便安，无剧情、无需解释成因）
→ 击败灰烬兽 = 通关
```

- 余烬核心：开局以抵债包裹获得（混在大量无用抵债物中，无特殊提示，玩家自行探索其用途；测试版不做邮件演出）
- 最终 boss 灰烬兽：激活节点后原地/城外刷出，打一场即结束，**不写任何剧情文本解释它为什么来**
- 失败：耐久归零且无法修车 / 全队重伤无法继续 → 结算（失败）

## 4. 界面结构（粗糙 UI 即可）

| 界面 | 何时显示 | 显示内容 |
|:-----|:---------|:---------|
| 标题界面 | 启动 | 游戏名 + 1~2 行极简提示 + 开始 |
| 地图界面 | 大地图 | 200×200 网格（仅当前+相邻可见）、商队状态栏、指令 |
| 城市/地点界面 | 进入地点 | 地点名、状态、菜单 |
| 交易界面 | 交易 | 买卖列表（名/价/量）、金钱；讲价拉锯反馈 |
| 订单界面 | 接单 | 订单列表（目的地/报酬/期限） |
| 战斗界面 | 遇敌 | 我方（血/状态）、敌方（血）、手牌、AP、指令 |
| 事件界面 | 路上事件 | 事件文字 + 选项 |
| 结算界面 | 结束 | 天数/金钱/战斗次数/订单数/通关 or 失败 |

### 商队状态栏（常驻）
`金钱 / 食物 / 水 / 零件 / 耐久 / 士气 / 天数 / 位置 / 灰度(探测仪)`

## 5. 操作指令（键盘）

| 场景 | 指令 | 说明 |
|:-----|:-----|:-----|
| 通用 | 数字键 | 选菜单项 |
| 地图 | `w/a/s/d` 或方向键 | 上下左右走一格（=1天） |
| 地图 | `m` `i` `h` | 看地图 / 看状态 / 帮助 |
| 战斗 | 数字键 / `r` | 出牌 / 撤退 |
| 任意 | `q` | 返回上级 |

> 非法输入提示「无效指令」，**不能崩溃**。

## 6. 地图（200×200）

| 项 | 值 |
|:---|:---|
| 尺寸 | **200×200 网格**（1 格 = 1 天行程） |
| 格子类型 | 大城、小城、驿站、村庄、野外、障碍 |
| 可见性 | 仅当前格 + 相邻格；未探索显「？」；到过的地点永久可见 |
| 灰度探测仪 | 常驻 UI 一角，显当前格灰度(0~100) + 趋势箭头（世界呼吸观测器，非警报） |
| 移动结算 | 走 1 格 = 1 天：食物/水消耗、耐久基础磨损、灰度额外磨损、推进天气/灰度波动 |
| 高灰通行 | 灰度≥50 地面软化/裂隙 → 额外 -1 耐久/天，宜绕路 |

> 200×200 很大，玩家实际只走一条贸易路线；空地图不影响「好玩」测试，反而测试长距离补给管理。若实测太肝，后续调小或加驿站密度。

## 7. 要做功能（详细）

### 7.1 开局
- 标题 → 1~2 行极简提示 → 命名商队（回车用默认）
- 初始：3 角色（护路人/荒野射手/修补师）、货车、金钱/食物/水/零件/耐久/士气（初值见文档 04）
- 开局获得抵债包裹（含余烬核心 + 大量无用旧件 + 一些食物/水/零件补给；不演邮件，状态栏标"抵债来的旧件，用途不明"）
- 起点：大城

### 7.2 地图与移动
- `w/a/s/d` 走格，1 格 = 1 天
- 进入格子判定：地点→地点界面；野外→事件掷骰；障碍不可走

### 7.3 补给系统
- 食物/水按人天消耗；耗尽→士气-1 + 生命惩罚
- 零件修车；耐久归零→无法移动需修车脱困
- 野外偶发补给

### 7.4 地点界面
| 功能 | 大城 | 小城 | 驿站 | 村庄 |
|:-----|:---:|:---:|:---:|:---:|
| 交易(买/卖) | ✅ | ✅ | ✅(有限) | ✅(轻) |
| 接订单 | ✅ | ✅ | ❌ | ✅(轻) |
| 休息(50金,士气+1) | ✅ | ✅ | ✅ | ❌ |
| 修车 | ✅ | ❌ | ✅(偏修车) | ❌ |
| 治疗(医馆) | ✅(基础即可；激活后解锁高级检疫/感染治愈) | ❌ | ❌ | ❌ |
| 改造舱(身体改造) | ✅(基础，有排异可重试；激活后升级高级舱) | ❌ | ❌ | ❌ |
| 激活节点 | ✅(通关触发) | ❌ | ❌ | ❌ |
| 招募 | ✅ | ✅ | ❌ | ✅(轻) |
| 出发 | ✅ | ✅ | ✅ | ✅ |

### 7.5 交易与讲价
- 买卖：食物/水/零件 + 特产（按地点价差）
- 讲价三类：买货压价 / 卖货抬价 / 接单谈酬金；大单默认谈、小单可选
- 5 轮拉锯，NPC 隐藏三价 + 态度反馈（不显数字）；账房特质加成；声望+信任两层（轻量）
- 谈崩可妥协 / 改日再来；稀缺货+订单有竞争者窗口

### 7.6 订单
- 送货（运 X 到 Y）、收购（交 X 物给钱）；同时最多 3 单；送货有期限；超时扣声望（仅记录）

### 7.7 卡牌战斗
- 触发：野外遇敌 / 订单护送遇袭 / 最终战
- 我方 3 人初始（AP 3 / 抽 7，人数缩放）；手牌初始固定技能 + 状态
- 敌人：强盗 / 野兽 / 灰烬兽（普通）；最终 boss = 灰烬兽（更强，⚠️ 数值待调）
- 可撤退（`r`）→ 回最近安全点，损部分补给

### 7.8 灰烬生态（世界底色）
- 灰度两层（地区基准 + 时间波动）；探测仪显示叠加值
- 腐蚀：显示灰度≥50 每日额外 -1 耐久
- 感染：显示灰度≥70 才有，城市治愈（无装备系统，本版不靠装备免疫）
- 灰兽偶遇：接触选择（绕行/强行通过/驱离），前期起始区灰<30 几乎无
- 灰烬风暴：灰烬区短时天气，鼓励避难

### 7.9 节点激活（通关触发）
- 大城「激活节点」→ 插入余烬核心（不消耗）→ 触发灰烬兽最终战
- 激活后城市管理层给予大量奖励（赏金 / 声望 / 旧文明许可）；基础改造舱升级为无排异高级舱

### 7.10 遗迹（轻量）
- 1~2 处；可获遗迹武器 / 记忆手册（终极技三重门槛测试用）

### 7.11 招募（轻量）
- 大城/小城/村庄可招募 1~2 名特殊人员（如账房），影响讲价/补给

### 7.12 结束
- 通关：击败灰烬兽 → 结算
- 失败：耐久归零无法修车 / 全队重伤 → 结算

## 8. 不做功能（明确排除）

| 不做 | 说明 |
|:-----|:-----|
| 剧情/支线/教团 | 完全无 |
| 城市经营/建设 | 无 |
| 装备模块 | 无（感染靠城市治愈，仅留机制接口） |
| 存档 | 无（一局制） |
| 传送 | 无 |
| 灰烬母兽/全球大潮 | 无 |
| 联合商队/大扩展 | 仅轻量招募 |
| 九城复兴 | 无（仅 3 城） |
| 声望面板 | 轻量记录，无复杂面板 |

## 9. 游戏时长目标（初估，待实测）

- 一局：⚠️ 约 30~60 分钟（200×200 长距离 + 多城贸易 + 最终战）；若实测太肝再调地图/补给
- 同时订单：4~6 个
- 灰烬兽最终战：1 场
