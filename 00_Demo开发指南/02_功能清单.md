# 02 · 功能清单

> 《余烬商队》·《Demo 程序编写指导》**大阶段一 · 基线 · 第 2 份**
> 用途：把本版**有哪些功能、不做什么**列全、划清范围。
> **本文件只列功能。不写机制、不写数值、不写血量、不写界面、不写开局。**
> 机制怎么运作 → 0A 各权威类 + 本指南系统专项 `12`~`21`；**界面与操作 → `20 界面与操作`（唯一出处）**；**开局与初始状态 → `16`**；数值 → `04` + `08`（**绝大多数尚未确定**）。
> 口径：2026-09-07 裁定 **无剧情、极简、纯测试**；2026-09-11 复核（400×400、76 地点、遗迹分大 / 小）。

---

## 1. 本版目标

玩家能完整走完一局：**开局 → 接单买货 → 400×400 地图走格 → 路上事件 / 战斗 / 灰烬生态 → 到城卖货交单 → 补补给 → 攒够本钱与本事 → 直接挑战灰烬（最终战）→ 通关**。

要测的是：**这条循环跑不跑得通、好不好玩**。数值不达标，后调。

## 2. 地点与数量（本版范围）

| 类型 | 数量 | 一句话定位 |
|:-----|:---:|:-----|
| 大城 | 1（唯一，起点） | 功能最全的大安全点 |
| 小城 | 2 | 正常设施齐全 |
| 城镇 | 12 | 路上的补给容错点，偏生活补给 |
| 驿站 | 10（**4 有节点 / 6 无节点**） | 商队专用休息点，偏零件与修车 |
| 村庄 | 36 | 最小聚落，功能最少 |
| 大遗迹 | 5 | 供终极技 / 记忆相关测试 |
| 小遗迹 | 10 | 同上，规模更小 |
| **合计** | **76** | 1 + 2 + 12 + 10 + 36 + 5 + 10 |

- 遗迹**只分大 / 小**，不按"产武器 / 产记忆"分。
- **驿站节点（2026-09-11 修正）**：只有**旧文明时代**修建的驿站带节点（信号中继）；**九城时代之后**新建的驿站**没有节点**（那时节点技术已经失传）。所以 **"没有节点"不等于"损坏"**——有的驿站压根就没建过节点。→ 0A 第7A类。
- 各地点**能做什么、物价、库存、士气、治疗、修车、订单类型** → 0A **第2A类 · 地点系统**（本文件不重复、不展开）。
- 地点**坐标** → `地图坐标.txt`；地图说明 → `12 世界与地图`。

**本版贸易简化（只为能测，非正式设计）**：大城基准价、小城 A / B 各有一味特产便宜、两小城互缺不同货——能跑通"低价买、高价卖"即可。价目 → `14`。

## 3. 主线（无剧情，极简）

```
跑商攒资源、攒本事（记忆 / 能力 / 补给 / 车辆）
→ 直接挑战灰烬 → 击败 = 通关
```

- 本钱攒够了，**直接去打灰烬**就结束。
- 最终战怎么打、敌人多强 → `17` / `21`。**本文件不定血量。**
- 这是本版**用来测通关的动作**。

## 6. 功能清单（逐项 · 只列"有什么"）

### 6.1 地图与移动
- 四方向走格；进入格子后：地点 → 地点界面；野外 → 掷事件；障碍 → 走不了

### 6.2 商队资源（只有哪几种，不写数值）
金钱 · 食物 · 水 · 零件 · **药包** · 车辆耐久 · 士气 · 货物（车厢容量）

> 消耗、断供、修复怎么算 → `15`。

### 6.3 地点功能矩阵（✅ = 能做；机制与价格 → 0A 第2A类）

| 功能 | 大城 | 小城 | 城镇 | 驿站 | 村庄 |
|:-----|:---:|:---:|:---:|:---:|:---:|
| 买 / 卖 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 接订单 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 休整（恢复士气） | ✅ | ✅ | ✅ | ✅ | ❌ |
| 修车 | ✅ | ✅ | 🔸 | ✅ | ❌ |
| 治疗 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 招募 | ✅ | ✅ | ❌ | ❌ | ❌ |

> - **接订单：四类地点（城市 / 城镇 / 驿站 / 村庄）都能接**（2026-09-11 用户裁定）。驿站里长期有人生活、他们自己也有需要（零件、补给等），所以驿站一样能接订单。→ 0A 第2A类。
> - **招募：只有城市（大城 / 小城）能招**（2026-09-11 用户裁定）；城镇 / 驿站 / 村庄都不能招募。
> - 上表**只回答"这里能干什么"**。哪类地点能处理重伤、价钱与库存多少 → 0A 第2A类。

### 6.4 交易与讲价
- 交易与讲价**分成两件事写清楚**：①交易怎么做（买、卖、数量、结算）②讲价怎么谈（怎么开价、一轮一轮怎么拉锯、怎么收手）——细节 → `14` + 0A 第10A类
- 界面（含讲价的独立界面）→ `20`

### 6.5 订单
- 订单**有哪几类、每类怎么接、怎么算完成 / 超时** → 全写在 `14` + 0A 第10A类
- 有目的地、期限、报酬；可同时持多单；**城市 / 城镇 / 驿站 / 村庄都能接**

### 6.6 战斗
- 触发场合：野外遇敌 / 订单护送遇袭 / 最终战（**每种怎么触发 → `17` / `19` 写清楚**）
- 可出战：初始 3 名角色（后续可增）
- 形式：回合制卡牌（手牌、行动点、状态），可撤退
- **本文件不写战斗**——牌、敌人、血量、数值全部 → `17`（**未定**）

### 6.7 灰烬生态
- 要写全：**灰烬生态到底是什么、里面有哪几种敌人、各是什么样** → `19`
- 灰度（显示 + 影响）· 感染 · 野外灰兽接触 · 灰烬风暴

### 6.8 遗迹
- 大遗迹 5 / 小遗迹 10；**按类型分**：研究所 / 工厂 / 军事基地 / 书库·学校（2026-09-12 改）；每类产出什么 → `21`

### 6.9 招募
- **只有城市（大城 / 小城）可招募**（轻量，1~2 人）；城镇 / 驿站 / 村庄不招募。名单与规则 → `13`

### 6.10 结束
- 通关：击败灰烬（最终战）→ 结算
- 失败：见 `15`
