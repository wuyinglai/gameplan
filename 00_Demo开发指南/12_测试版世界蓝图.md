## 1. 地图（具体是什么）

- **一张 200×200 连续方格大地图**，1 格 = 1 天行程。
- 非分块、非随机生成（Demo 不测「地图随机生成」，地块预设好）。
- **格子类型**：大城 / 小城 / 城镇 / 驿站 / 村庄 / 野外 / 障碍。
- **可见性**：仅当前格 + 相邻格可见；未探索显「？」；到过的地点永久可见。
- **灰度探测仪**常驻 UI 一角（显示当前格灰度 0~100 + 趋势箭头；是世界呼吸观测器，不是警报）。
- **稀疏性**：40000 格中仅约 47 个地点 + 4 遗迹，玩家实际只走一条贸易路线，绝大部分是空地——目的：测长距离补给管理会不会太肝（太肝再调小或加驿站密度）。
- **⚠️ 地点坐标已由用户手绘定稿（2026-09-08），见 §1.1；地图不随机生成。**
- **设计基准（用户旧版已定）**：驿站到最近补给点距离 ≈ **20~30 天** 即属正常边疆间距。当前实跑最大 24 天，落在范围内且偏短，**不补点**。
- **校验结论（2026-09-08 实跑 `地图校验脚本.py` + `地图分析_深度.py`）**：51 地点全互通、无孤岛；5 组桥全有替代路线（无单点失效）；地形占 6.7%；三城距离 45 / 92 / 135 天，天然撑起订单短/中/长三档。

## 3. 玩家具体要干嘛（目标）

- **身份**：商人，不是救世主。
- **一局目标（极简）**：
  ```
  接订单 / 买货跑商赚钱
  → 大城「激活节点」（插入余烬核心，激活钥匙不消耗）
  → 灰烬兽最终 boss 刷出（随便安，无剧情、无需解释成因）
  → 打一场 → 击败 = 通关
  ```
- **激活线非强制**：正式版玩家可完全不激活照样跑商；本测试版以「激活」为通关测试动作。
- **每局实际在做的几件事**：
  1. 跑商买卖 + 讲价（买货压价 / 卖货抬价 / 接单谈酬金）
  2. 管补给（食物 / 水 / 零件 / 商队耐久 / 士气）
  3. 路上卡牌战斗（强盗 / 野兽 / 灰烬兽）
  4. 自行探索发现余烬核心用途（开局抵债包裹里混着，无提示、无特殊演出）
  5. 可选：去遗迹摸武器 / 记忆手册、招募特殊人员、身体改造
- **失败**：耐久归零无法修车 / 全队重伤无法继续 → 结算（失败评价）。
