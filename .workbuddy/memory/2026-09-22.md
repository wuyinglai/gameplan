### 工具坑（新增两条硬事实）

1. 🔴 **git 写 `refs/remotes/origin/*` 在本机不落盘**：`git fetch` 回显 `* [new branch] main -> origin/main`、`git update-ref refs/remotes/origin/main <sha>` 也退出 0，但 `for-each-ref` / `show-ref` 里**始终没有这个 ref**（`refs/remotes` 目录空）→ `git status` 恒显 `## main...origin/main [gone]`。
   **解法 = 用 .NET 直写文件**：`New-Item .git/refs/remotes/origin` + `[System.IO.File]::WriteAllText('.git/refs/remotes/origin/main', <sha>+"\n")` → 立刻变 `## main...origin/main`。
2. **`git push` 的字面输出/退出码都不可信**：正常推送也会把 `To https://…` 写进 stderr，被 PowerShell 当 `NativeCommandError` 报红 —— **判据只看 `git ls-remote --heads origin` 的哈希**。
3. `Out-File -Encoding utf8`（PS 5.1）产出 **UTF-8 BOM** → `Read` 报「Cannot display content of binary file」。**一律用 `[System.IO.File]::WriteAllText(path, text, New-Object System.Text.UTF8Encoding($false))`**。
4. PowerShell 内嵌长中文数组失败时**整条命令不执行、无报错行**（本轮踩到一次）→ **长文本追加改用 Edit 工具**，不要走 PowerShell。
