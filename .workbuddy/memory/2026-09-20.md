## 🔴 护甲详细机制（用户指示：先不定武器表，先写护甲）

### 权威底座（`0A 第4A类 §4 §5.1`，**已有、不改**）

| 层 | 持续 | 挡什么 |
|:--|:--|:--|
| **护盾** | **当前回合末清空** | 外伤；**完全挡住可阻流血施加** |
| **护甲** | 直到被打掉 | **只挡普通攻击**；不挡穿甲攻击 / 流血 / 灼烧 |
| **屏障** | 直到被打掉 | 外伤 + 大多数负面 |

- **结算顺序（仅外伤）**：**护盾 → 屏障 → 护甲 → 生命**
- **穿甲攻击**：护盾 → 屏障 → 生命（**无视护甲**）
- **内伤**：不经过结算，**直接作用生命**
- 伤害两类：**外伤**（可挡）· **内伤**（不可挡）

### 🔴 核心串线：**甲值 = 防具的完整度**

**甲值归零 = 防具报废 → 同时失去 甲值 + 减伤率 + 转"无甲"档。**
→ 一条线串起三件事；且让"**破甲**"有额外战术价值（不只是打掉一层血，还把对方的减伤剥了）

### 结算位置

`面板 ×（1+角色加成%） × 攻击类型倍率 ×（1−减伤率）` → **护盾 → 屏障 → 护甲 → 生命**

- **减伤率与倍率同在"整次伤害"这一层**，**按目标是否还有甲判定生效**（甲碎 → 倍率转无甲列、减伤同时归零）
- **穿甲攻击**：跳过甲值（`0A §5.1` 已定）→ 因"无视甲" → **同时不吃减伤率**
- **内伤**：不经结算，直入生命（`0A §4` 已定）
- **✅ 不破坏三型平衡**：减伤率是**目标属性**，对所有攻击类型**同比例缩放** → "打击/斩击/刺击整场齐平"的结论**不受影响**，反而放大了"打对材质"的收益

## 🔴 职业局限性（用户提问："招进来什么职业，以后就一直是什么职业？"）

**判断**：问题**真实**，值得改。但**只改一半** —— 关键是区分**两种门槛**。

### 两种门槛（本轮核心区分）

| 门槛 | 性质 | 处理 |
|:--|:--|:--|
| **体格门槛** | **举不动就是举不动**（重盾 / 塔盾 / 重甲） | 🔒 **硬限制**（保留职业标签） |
| **熟练门槛** | **练出来的**（弓 / 弩 / 火枪 / 刀剑 / 长矛） | 🔓 **软代价** —— **能用**，但该武器**每张牌 +1 体力**（"不趁手"） |

### 机制：跨职业武器 = 贵 1 点体力

- 与已定的「**体力 = 费用**」天然咬合 → **零新增概念**
- 例：**护路人拿弓 → 能**，但每张射击牌 +1 体力；**弓箭手拿重盾 → 不行**（体格门槛）
- 🟢 **记忆可消除惩罚**：植入「**弓术记忆**」→ 弓对护路人不再额外耗体力 → **记忆系统多一个新用途**（且记忆稀有、贵，是长线目标）

### 职业的真正定位：**效率倾向，不是能力边界**

| 职业给什么 | 说明 |
|:--|:--|
| **老本行牌** | 入队自带、**永远保留**（护路人永远有「掩护」，弓手永远没有）→ **转型不是洗点，是扩展** |
| **效率优势** | 本职业武器不额外耗体力 → 本职永远更高效 |
| **（体格）准入** | 只有部分人拿得动重装 |

→ 玩家会自然形成"**主力用本职、兼用跨职**"的队伍，职业仍有辨识度，但不再是牢笼。

### 转型三条路（全部已有，一处不用新造）

1. **记忆**（武学记忆 → 消除跨职业体力惩罚）
2. **装备**（武器可转移，跟着人走）
3. **身体**（改造可拆装转移 —— 用户提的返还机制）

### 待统一改

- `0A §10`「匹配标签才能完整使用」→ 改为 **体格标签硬限制 + 熟练标签软代价（+1 体力）**
- `0A §1` / `§14.1` 那批旧口径（"角色基础数值固定不变" 等）

## 🔴🔴 熟练度 / 防刷（用户提问："用多了按理说就该会用了，但我不想让玩家刷熟练度"）

**解法一句话：成长挂「时间」，不挂「次数」。**

| | **次数**（❌ 可刷） | **同行天数**（✅ 不可刷） |
|:--|:--|:--|
| 玩家能刻意加速吗 | **能** —— 找弱怪反复打 | **不能** —— 多攒天数 = 多付 **300 金/天** + 补给 + 风险 |

→ 🔴 **次数禁用、天数采用**。这个游戏的**核心成本本来就是"天"**，所以挂在天数上的成长**天然免疫刷子**。

### 机制：「磨合」

| 项 | 定法 |
|:--|:--|
| 定义 | 跨职业武器（**熟练门槛**）的 **+1 体力惩罚**，随**同行天数**递减至 0 |
| 数值 | **同行 30 天 → 惩罚消失**（≈ 一个据点间距 —— "走完一段路，装备就顺手了"） |
| 计数 | **只按天数**，🔴 **与战斗次数无关**；**装备在身上即算**（不必打） |
| 粒度 | 按 **武器种类**（14 种之一）算，学会一种永久会；**每人单独计**（新人从 0 开始） |

### 「磨合 ↔ 记忆」分工（对称）

| 路径 | 速度 | 成本 |
|:--|:--|:--|
| **磨合** | **慢**（30 天） | **免费** |
| **记忆** | **立刻** | **昂贵**（火种 / 遗迹） |

→ 与"**恢复三条腿**"（药包·瞬时贵 / 据点·瞬时花钱 / 野外自愈·慢而免费）**同构**：
**这个游戏里所有成长都有"慢而免费"与"快而昂贵"两条路。**

### 职业不会因此消失

- **专属牌**：本职业独有（射手「精确射击」）→ 跨职业**永远拿不到**
- **老本行牌**：永远保留
→ 磨合只消除"**不趁手的体力惩罚**"，**消除不了"没有专属牌"**

## 🔴🔴🔴 职业惩罚机制 —— 推翻重做（用户批评："止疼药不治根"）

> **用户原话要点**：把"次数"换成"天数"**没解决任何问题**。**根本原因不是"刷"，是"惩罚期存在"本身** —— 只要有一段时间"带着这把武器你很弱"，玩家就必然去熬（刷 / 待城里 / 跑无聊短单），**熬法全是重复无聊的**。别拿止疼药糊弄。

### 根本原因
**"跨职业惩罚"这个设计本身。** 它为了保住职业辨识度，制造了一个"半废期"→ 玩家必须熬 → 苦活。
→ 🔴 **解法不是换形式，是把它删掉。**

### 新原则（本轮最重要的产出）

> **职业差异要落在「内容」上，不能落在「效率」上。**

| | **效率差异** ❌ | **内容差异** ✅ |
|:--|:--|:--|
| 长什么样 | "你用弓打八折 / 多耗体力" | "**你根本没有那张牌**" |
| 玩家反应 | 想办法把折扣补回来 → **刷 / 熬** | 决定"**要不要招个射手**" |
| 结果 | 制造苦活 | 制造选择 |

### 定案（**推翻上一节「磨合」**）

| 项 | 定法 |
|:--|:--|
| **跨职业武器** | 🔴 **正常用，零惩罚** —— **删掉「+1 体力」，删掉「磨合 30 天」** |
| **职业差异** | **只靠专属牌**（老本行 + 武器专属牌）→ 护路人永远没有「标记」「精确射击」 |
| **体格门槛** | **保留**（重盾 / 塔盾 / 重甲）→ 解法是**身体改造**（投入资源），**不是重复劳动** |
| **记忆** | 改定位为"**买那一手绝活**"（弓术记忆 → 护路人也有一手远程招式），**不再是"消除惩罚"** |
| **跨职业的物理代价** | 拿弓就占两手 → 没盾（**物理限制，不是惩罚**） |

### 职业还剩什么（这样就够）

**特长**（专属牌）+ **底子**（老本行）+ **体格**（准入）

→ **职业 = 你从哪儿来，不是你只能去哪儿。**

| # | 闸门 | 出处 | 拦什么 |

### 关键结论

| | 兼修后 |
|:--|:--|
| 能**做的事** | **变多**（选择面） |
| 能**同时带的东西** | 🔴 **不变**（手 2 只） |
| **强度上限** | 🔴 **不变**（点数池 + 体力池 + 选牌数） |

→ **兼修给"灵活"，不给"强度"。** 敌方数值**有明确天花板**可算：我方"**同时**火力上限"不涨。

### 具体例子（为什么不会高攻高防）

- **护卫学弓** → 拿弓占满两手 → **他的防御牌（要盾的那些）基本打不出来** → 他变成"**脆的远程**"，不是"高防远程"
- **射手学盾** → 举盾 → **没有远程输出**

### 补充原则：改造是「配平」，不是「叠加」

体征盘**不是加点，是分配有限点数** → 想举重盾（肌肉 + 骨骼）就得从别处抽点 → 血量 / 神经相对弱。
→ **这就是"防高"的代价：不可能样样都堆。**

### 否掉的理由（用户原话意）

2. **它根本没解决问题** —— 只是把"唯一解"从"重甲 + 远程"换成"重甲 + 单手"或"轻甲 + 远程"，**还是只有一个解**

   > **装备选择会退化成一条直线（前期一套 / 后期一套），没有任何选择意义。**
   
   **链条**：远程伤害高得多 → 后期没人用近战 → 后期偏重甲 → 轻甲优势消失 → **等于只有"前期装 / 后期装"两种** → **玩家觉得无聊，装备系统整个崩掉**

### 🟢 新洞察（本轮产出，重要）

> **"无聊"和"数值爆炸"是同一件事的两面。**
> 存在**无脑最优解** → 玩家只用它 → 设计者只能靠**抬数值**加难度 → **膨胀**。

→ **治法是"消灭唯一解"，不是"抬数值"。**

### 🟢 设计原则（建议立为铁律）

> **每件装备必须有自己的「做不到的事」，而不是「做得差的事」。**
>
> - **做得差** → 会被成长/升级**抹平**（后期数字够了就无所谓）→ 退化成上位替代
> - **做不到** → **永远不会被替代** → 装备永远有选择

### 🟢 新方向（AI 提案 · 待拍）

**① 重甲的问题不是"太强"，是"没代价"**（而不是"该禁武器"）：

| 代价 | 内容 | 为什么合理 |
|:--|:--|:--|
| **战斗** | **重甲 → 每张动作牌 +1 体力** | 甲沉，抬手就费劲；直接接上刚定的「**费 = 体力**」 |
| **野外** | **重甲 → 野外 AP 下降** | 赶路累；接上已有的「AP」体系 |

→ **轻甲** = 打得更多 · 跑得更快 · 武器不限；**重甲** = 更硬，但**每回合能打的牌更少**
→ **不是"后期换重甲"，是"打硬仗穿重甲、打快仗/赶路穿轻甲"** —— 且这条代价**永远不会被成长抹平**（体力永远稀缺）
→ **不再禁止任何武器**（重甲照样能用弓，只是更贵）✓ 合理性保住

**② "远程独大"其实不成立（前提被算错）**：

- **输出最高的不是远程**：**双手武器 ≈2.5 倍 > 远程 ≈1.5 倍**（单手 = 1.0 基准）
  → **远程的身份是「安全输出」，不是「最高输出」**
- **远程的代价是结构性的**（不能拿盾 / 不能格挡 / 不能自救）→ **永远不会被成长抹平**
- **"需要队友"→ 不可能全队远程**（用户已定："全输出队若一回合秒不掉对面一半人，损失就大得多"）
- **敌人血池按我方血池比例给（×0.5 / ×1.0）→ 比例不变 → "秒不掉"永不因成长而消失** ✓

**③ 一个待核的口径隐患**：若承伤是"**个人血池 × 百分比**"，则血少（70）与血多（110）挨同样一击各掉同比例 → **"远程脆"这个前提不成立**；若承伤是**固定值**，则血少者真的更脆。**此处口径未确认**，影响"远程脆"这条平衡基石。

### ① 「减伤率」是无相性的纯优乘数 → 只要它在，重甲必然赢

**用户原话意**："**我们之前伤害仅限于护甲呀……不就是说和生命值无关啊。但就是说如果和生命值无关，那重甲减伤率依旧会吸引玩家。**"

### 🟢 三条必须同时成立（缺一条就退化成一条线）

| # | 条件 | 作用 |
|:--:|:--|:--|
| 1 | 倍率作用于**整次伤害（含生命）** | 让"穿错甲"真的疼，厚度补不回来 |
| 2 | **取消通用减伤率**（改成分取向的抗性） | 拔掉重甲白拿的那 15% |
| 3 | 🔴 **甲值差距不能悬殊** —— 软甲甲值 ≈ 硬甲的 **80%**（**不要做成 1/3**） | 否则相性被厚度吃掉 |
