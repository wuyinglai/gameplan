## 铁律（违反即返工）

1. **先查文件**：写任何内容 / 数值前先查已有文件，禁凭空编。**用户最新口头指令 > 一切文件**。
2. **数值只是参考**：A 类文件里的数值**全都仅作参考** → 不把旧数当约束，**不许为凑旧数硬编设计**（先把结构算对，算出什么数就是什么数）。
3. **原文件"只查不改"**：未经点名"保存 / 改 / 写进去"，`0A` 与 `00_Demo开发指南` **一个字节都不动**；只能读，改法先在对话定案；"顺手发现"的不符只**口头报告**。
   - **唯一例外 = `04_数值细化表.md`**（正在写的报告）：讨论好直接写，**整表写完再统一保存**。
4. **工作流**：草稿先审 → 满意才落文件；**绝不擅自 push**；**一次一份**；**同一文件必须串行改**（并行 Edit 互相覆盖）。
5. **状态**：没有一份算"完成"——只有**骨架 🔶 / 空 ⏳**；禁写"已定稿"。
6. 作废的**直接不提**（不列"不做 XX"）；少建文件、不新建"第X类"目录；内容写透。
7. **惩罚只能"要价"不能"剥夺"**（掉钱 / 货 / 士气 / 强制撤退 / 多花天数），**绝不剥夺基础能力**；**迟到 ≠ 失败**。
8. **别用硬限制**：让玩家感到"太远养不起"，不是"系统不许"；大地图无硬边界。
9. **规模三层**：`§0.7.4` 没钱时（车 / 工资 / 货量）· `§0.7.7` 有钱后（管理成本）· `§0.7.8` 一次性事件（**距离即上限**）。凡约束规模先问在哪层。
10. **据点不能没有；村庄不算据点**（只能等，不能修车 / 治伤）。**危险来自"恢复跟不上"，不是"没有恢复"。**
11. **两条走法 = 两档订单**；**选路只在正式版，Demo 只测体力**。
12. 用户**语音输入**（错字 / 断句 / 口语），按上下文还原；要**明确单一答案**，反感反复追问；命名只改内容、不造新词。
13. **基调红线（2026-09-18）**：**不做"恐怖 / 惊悚 / 生物改造"感的内容** —— 身体强化一律用**机械·工程**语汇（装具 / 外骨骼 / 滤芯 / 泵 / 支架 / 护层），**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因）；强化件**可拆卸、可转给他人**（"脱下来给别人穿"，而非"挖出来换给别人"）。原"排异"表述 → 一律改 **"不兼容"**（同一套机械语汇）。
14. **设计原则（2026-09-20 新增）**：**每件装备必须有自己的「做不到的事」，而不是「做得差的事」**；**让「敌人」制造选择，不要让「数值」制造选择**。判据：这是"**更好的那件**"，还是"**另一种那件**"？—— 同一条线上的高低不是选择，不同维度上的取舍才是。
15. **旧稿处理法（2026-09-20 定）**：**归档旧稿不重写正文，只在第 1 行后插一条统一抬头**（"历史快照（2026-06~07）· 现行权威 = 0A + 00_Demo开发指南 · 不得据以开发"）。**只有"活文件"才改内容** —— 根 `README.md`、`00_当前权威口径/` 的 README / 索引 / 优先规则 / 废弃清单 / `已废弃早期文档_以0A权威为准.md`。**任何自称"当前权威 / 以本报告为准"的旧文件必须打掉**。

## 设定锚点

- 类型：大地图商队经营 + 战术卡牌战斗 + 订单护送 + 长线资源。**不是开放世界、不是 3D**。
- 开局：灰原城；**14 人 / 4 车**（3 货车 + 1 载人单车）；货舱 900 格。
- 车辆：货车 300 格 · 60 耐久 · 计耐久；**单车载人 · 不计耐久**；扩容 = 加挂货车；**可升级**（300 → 600 → 900）。
- **Demo 纯测试、无剧情**；通关 = 攒够钱主动打灰烬。**无"失败"结局** → 强制撤退（赔货粮水零件、士气 −2、耐久 →30、钱不扣，本局继续）；触发仅"士气归零 / 全队倒下 + 耐久归零"。城市也不是绝对安全区。
- 地图 **400×400 · 76 地点**；地点四类 = 城市 / 城镇 / 驿站 / 村庄（接单四类都可，**招募只有城市**）。
- 灰度 = 基准（地区天生）+ 波动（时间 + 天气）；灰兽按态度（友好可走 / 中立可打可走 / **敌对只能打**）。

### 体力（2026-09-20 全面取代 "AP / 行动力 / 费"）

- **战斗**：**全队共用一个池**，**池 = Σ 各出战人体力**（**基准 50 / 人**，像血量一样有**个体差异** 45~55；不是乘法）。**存量模型**：每回合回复 = Σ 各人体力，**上限 = 2 × 回复**，**起手 = 满**（"攒一波"= 集火，不增总量）。招式档 **微 0 · 轻 25 · 标准 50 · 重 100 · 极限 150**；消耗品（药包 / 零件）**25 点**、不占牌。
- 🔴 **出牌没有上限**（用户 2026-09-20 反复强调）：**"起手 3 张"= 回合开始抽的牌数（2 动作 + 1 记忆），仅此而已**；回合内**出牌数 / 抽牌数都不受任何限制**（抽完洗牌再抽再打，重复多少遍都合法）；**唯一闸门 = 体力池**。原"每回合最多 3 张 / 选牌上限 2+1"口径 **作废**。
- **野外**：**50 点 / 天**（与战斗同刻度但不通用），**取全队战斗人员最低值**；**走 1 格 20 · 侦察 1 次 10 · 休整 / 采集 20** → 标准打法 = 走 2 格(40) + 侦察 1 次(10)。🔴 **车轮改「每格消耗」**（标准 20 / 改良 16 / 旧时代 12 → 后期车队真能变快）；恶劣天气改每格消耗（+5 / +10）。**野外体力不挂器官**。日终结算一次（非每格）。
- **两个旋钮**：**人（全队最低体力）决定"今天有多少劲"，车（车轮 / 载重 / 路况）决定"每格费多少劲"**。
- **行军疲劳**：走满**当天全部野外体力**后接战 → 该场**体力上限 ×70%**（固定、人人一样、四舍五入）；**与心肺解耦**，少走一格即可避开。
- **迷雾默认全格**；侦察 = **5×5 · 信息等级 +1**（可见敌人武器类型 → 决定穿软甲还是硬甲）；敌人 / 资源点**预先摆好**。
- **出战无上限**；可撤退（**Boss 除外** —— Boss **单独设计、不锁血**、不可普通撤）。

### 伤害与装备（`04 §9.7`）

- **伤害总链**：`武器面板 ×(1+角色加成%) × 招式倍数 × 攻击类型倍率 →（护盾 → 屏障 → 护甲 → 生命）`。
- **攻击类型三型 × 防护档**（🔴 倍率作用于**整次伤害、一直进到生命**）：

| 攻击类型 | 无甲 | 软甲（布 / 皮） | 硬甲（铁 / 钢） |
|:--|--:|--:|--:|
| 打击 | ×0.95 | **×1.0** | **×1.3** |
| 斩击 | ×1.1 | **×1.2** | **×0.9** |
| 刺击 | ×1.1 | ×1.0 | ×1.0 |

- 🔴 **通用减伤率取消**（纯优乘数会压过相性）；**甲值差 ≤20%，相性差 ~50%** → "对上敌人武器"能真翻盘。
- **护甲**：只由**防具**给（开战赋值 · **本场持久、不随回合清空** · 只减不增 · **战毕自动复位** · 不跨场、不用修）→ 是"另一条血条"。**护盾**：只由**盾牌**给（回合末清空、可叠加、**可给队友**）。
- **升级链 × 取向轴要拆开**：武器 = 材质（升级 · 绝对）× 种类（14 种 · 选择 · 相对）；防具 = 材料（升级）× 防护取向（软 / 硬 · 选择）。
- **握持五型 · 盾四档 · 手 2 只**（弓/双手武器/盾互斥 —— 物理限制，非惩罚）。
- **职业**：**体格门槛硬限（重盾 / 塔盾 / 重甲，可用身体改造突破）· 熟练无门槛**（跨职业武器**零惩罚**，差异全靠**专属牌**；职业 = "你从哪儿来，不是你只能去哪儿"）。
- **身体改造 = 可拆卸机械装具**（动力肌束 / 支撑架 / 循环助搏泵 / 滤尘呼吸器 / 反应辅助线路 / 防护表皮 / 净化滤芯 / 解毒滤器）；**可转给他人**；不合 → **不兼容**（不叫排异）。

### 数值与手感

- **血量**：**基准 100（A13 尺子，不看职业）**；个体区间 **初始 70~130 · 满强化 240~380**；成长轴 前 **100** → 中 **200** → 满 **300**。**初期三角色 = 护路人 120 · 荒野射手 70 · 修补师 85**（原 68/40/46 低于个体下限，已重排）。
- **承伤 = 血池百分比 × 人数系数**：普通 **20%** · 精英 **40%**（**永久不变**，变的只是血池与敌人档次）；`√(3 ÷ 出战人数)`（§0.6.2）。
- **战斗中的恢复（`04 §9.5.1`）**：**战斗内回血唯一来源 = 药包**；**直接用药包** = **25 点共享体力** + 1 包；**治疗卡** = **同样 25 点 + 1 包**，另**占 1 个起手动作名额** → 该包 **×1.5**；**战斗内无自然恢复**。→ **拖战成本 = 烧药包**（50 金 + 1 格），收益 0，**无需任何"上限 / 疲劳 / 临时血"规则**。
- **恢复三条腿（`04 §0.6.3`）**：**药包**（**仅战斗内** · 瞬时 · 50 金 + 1 格 · 应急 · 覆盖 36%）· **据点治疗**（🔴 **瞬时回满 · 不占天数 · 花钱 · 低于药包** · 主力，60 天供血 ≈420）· **野外自愈**（**极慢 · 免费 · 保底**）。**任何一条变快都会顶掉另一条**。🔴 **"休息值"概念作废**。
- ✅ **心肺已定（2026-09-20 重定）**：**肺 = 战斗中每回合的体力回复**（**+3% / 点** → 满肺 +60%）；**心脏 = ① 战斗中体力上限（+2% / 点 → 满心 +40%）· ② 战斗外每日自愈速率**（**初始 ≈0.4 血/天（补一场损耗 50 天）→ 满级 ≈1 血/天（20 天）**；**随血池等比缩放**）。**上限由"不能替代药包"倒推**。原"心肺加成药包"、"肺 = 野外行动力增殖"**全部作废**；**野外体力与器官脱钩**。待定 = 心脏级数与速率表。
- **牌四类来源**（`04 §9.1.1`）：**老本行**（入队前就会的；不叫"本能"、非天生；本身不成长）· **武器**（装备）· **记忆**（旧文明植入；**武学 / 动作记忆走这条但不占记忆槽 → 进动作卡池**）· **商队牌**（车载武器 + 特殊人员，全队共用池，细则待定）。**药包 / 零件不是牌**。
- 记忆 = 知识领域（一领域三卡：战斗 / 探索 / 跑商）；**火种 3,000 金**；遗迹武器只在军事基地出（武器 + 说明书 + 火种，三缺一不可）。
- 敌人 3 类 = 强盗 / 野兽 / 灰烬兽。

## 口径要点（数字见 `04`）

- **日均消耗 = 硬账**（吃喝 + 工资 + 车损 + 药包），**软账不进**；**报价分母 = 硬账**。
- **报价 = 固定单价**（按档不按玩家阶段）；单笔只是底薪，顺路单 + 自带货另算。
- **据点服务 < 消耗品**（修车 / 治疗永远比自掏零件药包便宜）。
- **编制铁律**：**后勤 = 其余之和**；**总人数 = 2 ×（车夫 + 战斗 + 特殊）**；**车夫 = 车数**。
- **日薪 4 档**：护卫 > 特殊 > 车夫 > 帮工；**初期全核心、不领薪**；**欠薪只闲置、绝不挖走**。
- **规模上限**：车上限 12~15（宜取 12）；管理成本 = f(人数)；**距离即上限**；越往外补给点越稀 / 越废。
- **战斗耐久每车计**：普通 −5 / 精英 −10 / Boss −50+；据点间距 ≈30 天——硬约束是"**恢复**"不是"**耐久**"。
- **敌人数值（`§9.3`）**：**敌方总血池 = 我方血池 × 系数**（普通 **0.5** / 精英 **1.0**）；**个数只摊分、不进总血公式**；**Boss 单独设计**。三类敌人共用一份总血池，只分单体强度（1 只灰烬兽 ≈ 3 只强盗）。
- **回合数（已统一 2026-09-20）**：普通 **3~5** · 精英 **5~8** · Boss **8~12**（`0A 第4A类 §8.1` 已同步）。
- **敌人 AI（`§9.6`）**：**意图显示**（基础给"范围"，强化给"确值"；「战术大师」多看 1 回合）· 行为三模式（固定循环 / 权重随机 / 条件触发）· AI 三档（散 / 挑软 / 协同 = 全队共享目标）。
- **成长三轴**（`§10`）：记忆（推演补全）· 装备（材料 + 设备 + 工匠）· **体征盘**（`§10.1`：8 器官 + 血量；**器官联锁 = 一对落差 ≥3 → 弱侧成破口**；**肺 = 战斗每回合回体力 · 心脏 = 体力上限 + 每日自愈**）。
- **体征盘 → 事件（`§10.2`）**：**8 器官 + 血量，每一格都能挂接口**（不限力气；用户 2026-09-16「**所有都可以有接口**」）→ 战斗人员该系统**合计 ≥ 人份阈值** = 事件**多开一个选项**；**硬阈值 · 不掷骰 · 永远有保底选项（要价不剥夺）**；**只算战斗人员**。「人份」= 一个标准人在该系统的值（单格 5 点 / 运动对 10 点）。判定口径（**全队合计** vs **单体**）**由事件自定**（倒树=合计，陷阱=踩上去那个人）。**示例**：运动→搬开阻挡；**神经→踩陷阱收脚（零伤，否则掉血）**；皮肤→察觉埋伏；消化·肝→喝脏水不闹肚子；心肺→急行赶路；血量→硬扛。**不穷举、不定死**，具体阈值在 `19` 配。与「记忆事件接口」并列：**记忆 = 知识型解锁 · 体征 = 身体型解锁**。
