## 🔴 速度 / 时间 / 体力（2026-10-13 用户裁定 · 已全库落库）

## 本机工具坑

- 🔴 改完文件**必须读盘核实**（PowerShell 结果写临时文件再 Read —— 不回显 stdout）；关键词出现 0 次 = 被覆盖回旧版。
- **0A 文件行尾不统一**：多数 = LF，**3A = CRLF** → 插入行前必须探测（`$t.Contains([char]13)`）。
- ✅ **大批量改同一文件的有效模式**（2026-10-13 实测 95/96 一次过）：Write 工具写 UTF-8 数据文件（`MODE@@@OLD@@@NEW`，`\n` = 插入换行标记）→ **纯 ASCII 的 PowerShell 脚本**读数据文件逐条替换 + 计数断言 + 落盘日志 → Read 日志。避开本机 PowerShell 中文编码坑。
- 同一文件多处改动也可逐条 Edit（短锚点，别带表格对齐空格 / 尾随空格）；PowerShell 批量替换后 **grep 复核**；含中文 / emoji 的长内容别写成 `.py` 再跑。
- ⚠️ 批量替换典型后患：锚点不含句尾时，**原句尾巴会被挤到新段末尾**（2026-10-13 中了 2 次：1A §4 / §9.7）—— 锚点要**包含到句末标点**，或改完读盘检查上下文。
- 🔴 **补丁数据文件里绝不能有字面换行**（new 值一律写字面 `\n`，或改用下面的「整块插入」）—— 否则后续行被当成新规则、`old` 为空 → `Matches('')` 几万次 → 跑到超时（exit -1 且无日志）。
- 🔴 **PowerShell `[string]::Join("`n", $arrayList)` 会把 ArrayList 对象本身转成字符串**（得到 `"System.Collections.ArrayList"` 并写进文件）→ **一律用 `-join`**；改完 grep 文件里有无 `System.Collections`。
- ✅ **整块插入大段中文的可靠姿势**：数据文件用 `===文件名===` 分块（块内可多行）→ 脚本按块读、`-join "`n"` → `Regex.Match($t,'\A(?s)(.*?)\r?\n---\r?\n')` 定位抬头分隔线 → `Substring` 拼接插入。
