## 物价与经济（2026-09-08 定）
- **物价权威文件**：`01_系统大类/第02类_地点功能库存价格治疗士气订单系统/第2.1类_全局经济与物价锚点系统_v0.1.md`（用户已定的物价系统）。核心锚点：高面额金币；城市补给10/零件50/药包50，城镇15/75/70，驿站16/70/75；**出行消耗≈天数×30金**；订单收益=消耗×1.4~1.7（中心1.5）；长线一趟真实收益2~3万金；数值升级300起+20、状态升级1000起+200；记忆融合同标签300/跨标签500金。**火种本身无金币定价**（只有消耗量：词条1~4颗+300~600加工费）。
- **物价机制（用户定的最简单方案）**：不搞买入系数/价格指数。**每城一套价**（大城最低、村庄最贵、小城共用同一套模板、有特产的城把该货直接调低），**每日三角分布随机波动**——价格=正常价×(1+δ)，δ=`random.triangular(-0.2,+0.2,0)`，正常价概率最高、偏离越远概率越小；一般货±20%、战略资源±10%；卖出同理（各城有自己的收货正常价+波动）。逐城具体价目与地点坐标**由用户定，AI 不编**。
- **经济锚：三阶段日均消耗（用户给，2026-09-08 修正版）**：12人商队 **初期≈250金/天**、**中期≈700金/天**（要算招募新人工资+攒钱买东西）、**后期≈1500金/天**（满编+工资+高级维护）。（原写500/1000已作废）对照：第3A类 12人纯吃喝54金/天（每人每天1/4份食物+1/4份水，食物10/水8）；第2.1类小队口径30金/天。
- **订单系统（2026-09-08 二次重定，权威见 `00_当前权威口径/订单与贸易系统设计方案.md`）**：移动基准**每天2格**；四档 短途≤60天/中途60~120/长途120~200/超长途≥200；期限=ceil(格距/2)×1.3。**报酬=天数×档位日均×倍率，倍率 短途1.7/中途2.0/长途2.1/超长途2.5**（利润70%→100%→110%→150%，随阶段递增；为中心值，实际上下浮动；⚠️用户另说"后期120%"，与2.5有出入待实测）。**同时持单无上限**（可无限接单——多接顺路订单正是赚钱方法；doc04 原"≤3"是AI误写已改）。**订单4大类**：送货/护送(有期限需接)、收购/悬赏(**无期限、不用接**)。**交付四档**：早到→额外声望奖励；正常到→无奖惩；延期→声望损失+佣金减少；严重超期→大量声望损失+不付报酬(失败)；货物被毁不算失败。

## 游戏类型（已纠正）
- **不是开放世界**，是"大地图商队RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件"
- 大地图是格子（8×6或10×6），移动像下棋（上下左右走一格=1天+1补给）
- 战斗是回合制卡牌（共享行动力3点，每回合抽7牌，UI队列非棋盘）
- 3D开放世界是早期废弃方案（建不出模型），相关docx/xlsx全部丢弃不用

## 核心设定（来自第12类世界观报告 + 第6类，已按用户口头纠正更新）
- **余烬核心 = 激活密钥（不是动力源）**：旧文明遗留的"授权密钥"，**接入城市节点反应炉、授权启动其能源分配系统**；**不消耗、不损坏**（万能钥匙，可反复用于各城）。核心=钥匙，烬油=燃料，缺一不可。
- **节点反应炉（城市装置）**：旧文明能源枢纽，每城1座，靠烬油运行；烬油有储备但旧文明后无人会维护补充→耗尽熄火，熄火后需余烬核心重启。**激活前后功能差异（2026-09-07 重设计）**：激活前城市**基础功能**（交易/补给/零件/药包/普通治疗/修车/招募/接单/打听/休整）照常运转——城市是活聚居点、靠人力与中世纪末期技术、不依赖旧能源；激活后**额外**上线仅依赖旧文明的特殊设施（记忆设施/工坊复产/旧文明遗物专柜/节点网络连通/高级检疫），**并非"解锁城市"**。**玩家可完全不激活照样跑商（复兴九城/激活线为可选非强制主线）**。已写入第7A类「节点激活前后的城市功能差异」+第2A类城市段注。
- **节点（驿站装置，已定名）**：用户定名。驿站里的信号中继（类比电线/信号站），把已发电的城市连通；靠"维护+商队经过"接入网络，**不耗余烬核心**。驿站没有节点反应炉。
- **初始3角色（已确认为正式角色，非举例）**：护路人(68血/主承伤/护车/盾反)、荒野射手(40血/脆皮高输出/标记/流血/侦察)、修补师(46血/全能辅助/修车/加固/少量治疗)。不是筑垒者/寻烬者/斥候/鼓舞者。
- **记忆系统**：旧文明技术，让角色快速掌握强力能力，比普通学习好。完整获得无碎片。分类：攻击/防御/辅助/消耗。成长不靠经验/熟练度/碎片。
- **火种**：稀有战略资源。用于记忆强化、记忆融合、火种词条(技能加词条)。非碎片。
- **敌人3类**：强盗(含掠夺者车队)、野兽、灰烬兽。外加5个Boss。
- **主线（可选，非强制）**：携带余烬核心(激活密钥)，重启九城节点反应炉(城市)、通过驿站节点(信号中继)连通商路——这是"复兴九城"可选主线之一，玩家完全可不做。世界不逼玩家当英雄。
