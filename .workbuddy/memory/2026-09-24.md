## 六、骨架 · 挂点 · 负载（装具硬件层 · 2026-09-24 建）

### 用户原意（语音）

> 「有一个平台，我可能加的生命值多，它总共能装配的配件数量不一样、种类也不一样… 低级平台装高级部件可能撑不住，能量被占满就供不了别的… 跟格数和负重一样… 平台和装具之间也可能不兼容。」

### 定案

- **链条（用户澄清·关键）**：`装具（配件）→ 加能力点（装具盘 9 项）→ 能力点再换算成 血量 / 伤害 / 体力`。
  🔴 **装具不直接给血 / 给伤害**，它只推高盘上某格点数 —— **仍是一条链、一套结算**，玩家看的始终是盘上 9 格（不是三个数）。
- **三个新词（用户从 AI 三套候选里各取一个 · 2026-09-24 终定）**：
  | 词 | 是什么 | 取自 |
  |:--|:--|:--|
  | **骨架** | 穿在身上的基础框架（决定能挂几个位、挂哪儿） | A 方案 |
  | **接口** | 骨架上的安装位 | B 方案 |
  | **负载** | 骨架的承重上限（**超了就装不上**） | 三方案同 |
  | **超限** | 装不上的状态（负载不足所致） | C 方案 |
  - ⚠️ 中间曾用"挂点"，已全库改为**接口**（`04` 14 处 / `25` 1 处 / `第6A类` 7 处，共 22 处）。
  - `第6A类 §15.6` 原标题「接口 / 前置 / 互斥」改为「**前置 / 互斥**」，避免与"骨架接口"撞词。
- 🔴 **不引入"能量 / 供能"** —— 本作"能量"已被旧文明能源（烬油 / 反应炉）占用；且`格数 × 载重`两轴已够表达。"撑不住" = **负载不够**（物理上装不上），与 `0A 第3A类 §3.3`「格满或重满，任一满就装不下」同一条逻辑。
- **骨架分两轴（与武器同构）**：
  - **种类**选取向（**相对**）：运动型 / 循环型 / 代谢型 / 感知型 / **均衡型**。
  - **材质**作升级（**绝对**）：粗劣 → 常规 → 精良 → **旧时代**。
  - **理由**：只有拆开才不违反铁律 14（不拆 → "高级 = 全能"）。
- **骨架决定三件事**：总挂点数 · 每格挂点上限（专项骨架本行多、别行少甚至没有）· 负载上限。
- **天然封顶**：`挂点数 × 单件加值 ≤ 每格 200`（100→300 的空间）→ 骨架再好也到 300 封顶，**后期不会无敌**。
- **两个闸门**：**挂点占满** = 装不下了；**负载不够** = 低级骨架装不了高级件。

## 十一、速度轴定案：**速度锁 2 格/天，不改成 2/3/4**（用户裁定）

### 11.1 被否掉的提案

- 用户曾提"前期 2 · 中期 3 · 后期 4 格/天"，AI 一度建议"砍超长 250 天 → 80 天"。
- 🔴 **两条都被否**：砍天数不行（**250 天是绝对基础锚点，动不得**）；改速度不行（见下）。

### 11.2 为什么速度不能动（本轮的账）

- **硬账按天占比（`04 §0.3`）**：初期 **84%** · 中期 **91%** · 后期 **91.2%**（吃喝 + 工资）。
- **速度 = 天数的倒数** → 提速就是把 91% 的账本打折：2→3 格省 33%，2→4 格省 **50%**。
- 🔴 `23 §5.4` 的「按天（吃喝 + 工资）/ 按格（车损 + 油耗 + 药包）」划分**救不了** —— 按格那笔只占 8.8%，**体量差 10 倍，搬不动**。
- 🔴 **用户原话判据**：「**我 10 天的路程 5 天就到了，那我是不是可以少发 5 天的工资？**」→ 工资按天发（`04 §0.7.5`），**速度就是工资的折扣券**。

### 11.3 定案：后期变的是"能带的东西"，不是"速度"

| 成长轴 | 前 → 中 → 后 | 长的是 | 会不会砍 91% |
|:--|:--|:--|:--:|
| **单车格数 `q`** | 300 → 600 → 900 | 一趟能装多少 / 带多少天补给 | ❌ |
| **车数** | 4 → 12 | 一趟能装多少货 / 带多少张嘴 | ❌ |
| **补给密度 `ρ食`** | 5 → 7.5 → 10 | 同样货舱装更多天 | ❌ |
| ~~速度~~ | **恒 2 格/天** | ~~一趟用更少天~~ | ✅ **砍 91%** |

> 🔴 **用户原话**：「**后期玩家速度没有变化，变的是能带的东西。**」

### 11.4 连带：`q` 才是"跑更远"的唯一旋钮（算术验证）

- `单程可达 = 141 × 车数 ÷ (车数 + 战斗 + 特殊)` —— **`v` 不进这条公式**。
- 按新编成代入：初期 4 车/3 → 81 天 · 中期 7 车/8 → **66 天** · 后期 18 车/12 → 70 天
  → 🔴 **升级编成不会走得更远**（车数与战斗+特殊同步涨、互相抵消）！
- 救法：公式里 `141` 是"基准车 300 格"常数 → **`q` 升到 600 → 282；900 → 423**
  → 后期可达 **70 → 141 → 211 天**。**「跑更远」由 `q` 提供，不由编成提供**（逻辑闭环）。

## 十三、"无聊"的变量不是时长，是**重复 × 决策含量**（用户纠偏 · 设计方法论级结论）

### 13.1 用户纠偏

- 🔴 **口径改为只看"单程"**（不看往返）—— 单程才是玩家的体验单位。
- 🔴 **短途单程 ≈2 小时也会无聊**（不只是超长 8 小时）→ **否掉了 12.6 的"短途靠短本身不无聊"**。
- 🔴 **过程要重复**（商队经营本质 = 跑很多趟）→ **短途和长途都要加新玩法**，不是只给长途加余量。

### 13.2 结论（AI 本轮）

> **无聊 = 同一循环的重复次数 × 每次循环的决策含量。** 与"单趟绝对时长"无关。

- 短途 2h / 超长 8h **同一个病**，只是份数不同 → **期限余量（十二）只治长途，治不了短途**。
- **两条解法**：(a) 减循环次数 ❌（= 砍格数，用户已否）(b) **提高每次循环的决策含量** ✅ ← 本轮方向。
- 🔴 **重定义目标：用户要的不是"更多新内容"，是"可重玩性"** —— 同一套规则、变量在变、每次结果不同（棋类/卡牌/经营的共性）。
- 🔴 **关键句**：**不是"内容不够"，是"内容不会变"。**

### 13.3 🔴 发现的"空"：四档只写了数值，从没写过玩法

- `1A §7.1` 只有格距表 · `04 §8` 只有天数/格数/单价表 · **全库没有任何一处写"这一档玩什么"**。

## 十六、用户公式定案 + 自检发现的 6 处问题

### 16.1 🔴 用户最终公式（**已澄清 AI 上一轮的误读**）

> **AI 误读**：以为"早交 = 有奖励"。
> **用户正解**：早交 = **省消耗但少收获**；绕路 = **多消耗但多收获**。**两者都是玩家的选择，没有哪个"有奖励"。**

```
最少消耗 = 日均消耗 × 最短路程        ← 跑这条路最少要烧多少
预期消耗 = 最少消耗 × 1.5             ← "正常绕一下、不卡时间"要烧多少
报酬     = 预期消耗 × 2               ← 多出来的那一倍 = 玩家赚的
```
**合并 → `报酬 = 日均消耗 × 最短路程 × 3`**

- 🔴 **与 `04 §8.1` 备注完全同构** —— 原文：单价 = 定价基准 × 档位倍率（`300×1.8` / `934×2.0` / `1493×2.2` / `1493×2.5`）。

### 18.3 定案口径

**头号铁律**：🔴 **信物不提供任何战斗数值，一格都不给。**
它管的是**"人"，不是"命"** —— **强盗挡路时有用，野兽 / 灰兽冲上来时完全没用**。
→ 与**装具盘**彻底分开：**装具改你的能力**（身体 · 仅限战斗人员）· **信物改世界的态度**（物品 · 全商队）。**两者永不互相淘汰。**

**四位按「场合」分（不按件数）** —— 一个场合一个位（同场合装两件是**冗余**，不是叠加）：

| 位 | 信物 | 管什么 | 做不到什么 |
|:--|:--|:--|:--|
| **路** | **凭证** | 关卡 / 拦路：降过路费 · 多一个「亮牌子」选项 | 🔴 **对强盗无效**（强盗不认牌子） |
| **野** | **铭牌** | 遗迹 / 旧文明设备：多一个「物品解」选项 | 野外 / 城里都用不上 |
| **队** | **护符** | 队伍状态：内部事件最差结果权重 ×0.85 · **灰度读数** | 🔴 战斗里零数值；🔴 **只读数不防护**（本作无防护装备，`04 §1559`） |
| **城** | **城契** | 该城：声望涨更快 · 解锁专属订单 | **只对那一座城有效**，换城即废 |

**唯一成长位 = 城契 1 → 2 → 3**（其余三位恒 1）→ 前 / 中 / 后合计 **4 / 5 / 6**。

> **为什么只有城契长大**：一趟只需一张通行凭证 · 一次只能探一处遗迹 · 队伍只有一个状态 —— 但**你跑的城在变多**（前 1~2 座 → 后九座）。**城契 = 关系网大小**，且**是长出来的不是买的**（在某城做够声望 `10A §1.6` → 那座城认你）。
> → 与 `q`（单车格数）· 车数并列的**第四条「横向长大」的成长轴**。

**其他口径**：
- **不占车厢格**（资质不是货物）—— 与表中"装甲槽 / 环境槽**不占**"同类。旧「商队凭证槽 2 格」一并取消。

- 🟢 **世界会收回它**：城被灰兽攻破（`8A`）→ 城契作废；与某城转敌对 → 城契吊销。

**解锁类型三足已齐**（补 `04 §10.2`）：**记忆 = 知识型** · **装具盘 = 身体型** · 🆕 **信物 = 物品型**。

**它不鸡肋的原因**：**不决定"你多强"，决定"这趟你打算怎么走"** —— 接了什么单、走什么路 → 才知道配哪几件（超长穿灰烬区 → 护符 + 铭牌；短途关卡多 → 凭证）。**出发前的配装题。**

## 二十、🔴 车队改造改口：**扩容箱 / 外挂箱 不删，改为"开生态位"**（用户纠正 AI）

### 20.1 用户纠正（本轮最重要）

> 「**既然互相冲突，那你的想法是删掉还是保留还是怎么样？我需要知道你的想法。**」
> → AI 答"删" → 用户**明确否掉**：
> 「它现在**不是没有生态位吗，我们可以专门给它开一个生态位啊**……**你不能说因为它没有生态位你就给它删了呀，生态位是可以加的呀。**」
> 「**很多设计只是一个想法，它还没有写详细的设计，你不要看它里面什么东西都没有你就给它删了。**」

🔴 **AI 的方法错误（已进 skill）**：把"**还没写详细设计**"当成"**不该存在**"。
**正确判据**：问它**有没有独占的场合 / 代价空间** —— 空 = **待补**，不代表该删。**删是最后手段。**

### 20.2 用户给的新方向（加格三段）

> 「买的车**初始车可能是 300 格**，中期车可能是 **600 格**，最后车买到的可能只有 **700 格** —— 然后**靠外挂箱 / 扩容箱来增加格数**。」
> 目的：**成长曲线更平缓** —— 「玩家可能**相对空间差一点就够了**，不必要重新买一辆车」。

🔴 **生态位的开法 = 把 `q` 的上限降下来，把余量交给箱子**：
| 段 | 手段 | 幅度 | 代价 |
|:--|:--|:--|:--|
| 大跳 | 换车（`q`） | **300 → 600 → 700** | 贵 · 一次到位 |
| 中步 | **扩容箱**（装车内） | +20 格/件 | **自身占 10 格**（净 +10）· 改装费 · 安全 |
| 小步 | **外挂箱**（挂车外） | +20 格/件 | **不占内部格**，但会被抢 / 会坏 / 只能放低价值货 |
| 上限 | 车 + 箱 | → **900** | 对上现行顶格（`§15.2` 范围 200~900） |

**扩容箱 vs 外挂箱 = 「另一种那件」**（过铁律 14）：**一个安全低效 · 一个高效高风险。**

### 20.3 用户给的全部"代价"素材（原文要点）

- 「**它自己也是有厚度的，所以它可能自身还要占格子**」；
- 「**安全性可能就会大打折扣** —— 比如**会被劫匪优先抢劫**，然后可能也**会优先损坏**」；
- 「**里面只能放一些便宜的货物**，不然损坏就是严重的亏损」；
- 「**改造也是需要钱的**」；
- 「**你光加格子没有用啊，你还要同步的增加负重**」；
- 「运新鲜的东西就需要**保温箱**，保温箱就要占格子」；
- 「**封存箱**……反而货车空间会更小，只是说能带有污染的或者说难以保存的物品」。

### 20.4 🔴 查证发现（用户直觉对了，地基早就在）

1. **`6A §11.2` 明写**：「**配件加成（扩容箱 / 外挂箱）在此之上另计**」→ 它们**在文件里是有位置的**（不是凭空）。
2. **`6A §11.4 储存容器` 已经有 4 种箱子** —— **防潮箱 / 灰烬封存箱 / 药品箱 / 材料箱**，且明确「**不占模块槽，只占车厢容量**」→ 🔴 **用户说的"封存箱"就是这一族**！
3. 🔴 **负重不用另设配件**：`§11.2` 公式 = **`负重上限 = 货舱格数 × 2`** —— **格数一涨，负重自动跟着涨**。
   → 所以 `§11.1` 那句「外挂箱 = **增加负重上限**」**是重复定义，应改为"加格 + 高风险"**。
4. **整块应归族**：**「货舱模块」= 加格的（扩容箱 / 外挂箱）+ 换功能的（保温 / 封存 / 防潮 / 药品 / 材料）**
   → **"用格换容量" vs "用格换功能"** —— 这才是它们的生态位。
