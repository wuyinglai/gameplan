## 四之四 🔴 跑商 vs 探索的分工（**设计理念** · 2026-10-15 用户提出）

> 🔴 **本节只定理念，不定内容** —— 它是**设计导向**，不是机制清单。**具体产出**（遗迹里出什么、传闻给什么、收藏品有哪些、隐藏地点怎么发现）**按本理念另行设计**，本节**不预设、不编造**。

### 核心问题：**避免所有玩法最终都变成"赚钱效率的计算"**

跑商和探索都能让玩家赚更多钱 —— 如果不刻意区分，玩家长线最优解永远只有一条："优化路线、压缩成本、提高周转"。

**要避免的不是"两种玩法不同"，而是"某一种在长期收益上明显压倒其他"**，以及**玩家觉得"只要不追求最高效率就是浪费时间"**。

### 两者的分工

> 🔴 **跑商让玩家获得更多「资源」，探索让玩家获得更多「可能性」。**

| | 🔴 跑商 | 🔴 探索 |
| :-- | :-- | :-- |
| **给什么** | 金币 · 常规物资 · 稳定收入 · 经营成长 | 独特物品 · 隐藏地点 · 未知路线 · 特殊人物 · 世界信息 · 新任务机会 |
| **作用** | 积累财富、改善商队条件、**有能力承担更远的旅程** | 发现此前不知道的东西、**拓展后续旅行的选择** |

**互相促进，但不可互相替代**：跑商为探索提供资金和补给；探索发现新城市、新商路与新贸易机会（例：**探索发现一座城 → 之后可以去那儿做买卖、接订单、建商路** —— 探索不只给一次性奖励，还能改变之后很长一段旅程的经营选择）。

### 探索专属奖励的三种类型

| # | 类型 | 是什么 | 核心价值 |
| :-: | :-- | :-- | :-- |
| **1** | 🔴 **功能型** | 特殊工具 · 独特装备 · 路线信息 · 特殊行动能力 | 🔴 **改变玩家能做什么** —— **不是单纯提高数值，而是扩展行动可能性** |
| **2** | 🔴 **发现型** | **收藏**：旧时代遗物 / 纪念品 / 纪念货币　**世界观**：日记 / 信件 / 录音 / 历史线索　**世界发现**：新城市 / 隐藏聚落 / 遗迹 / 旧商路 | 🔴 **让玩家发现和理解世界** —— **不必全有实用价值，也不必全能出售** |
| **3** | 🔴 **复合型** | 少数重要奖励**同时**具备前两者（例：旧商队日志 = 失踪商队的故事 + 一条旧路线的线索） | 🔴 **连接故事、探索与经营** —— **少数即可，不必每件都这样**（控内容成本） |

**功能型奖励的设计原则**：
- 尽可能带来**新的选择**，而不只是更高攻击力 / 更低消耗
- 🔴 **普通装备应能满足基本旅行与生存** —— **必要能力不得全部锁在探索奖励里**
- 独特功能**可以针对特定场景**，不必处处优于普通装备
- **没拿到某件探索奖励的玩家，仍然能正常旅行和成长**

### 🔴 与铁律 22 的关系（防误判）

| | 说明 |
| :-- | :-- |
| 🔴 **"奖励"≠"乞求"** | ❌ 作废的是「**用奖励替代代价**」（路过就发奖励、求玩家慢下来）；✅ 探索**本身有代价**（时间 + 钱粮 + 风险，**探索时遇敌不比跑商少**），探索**产出**独特物品 / 地点 / 故事 —— 这是**"付出后得到"**，不是"不发奖励就没人来" |

### 六条设计原则

1. 🔴 **跑商让玩家获得更多资源，探索让玩家获得更多可能性**
2. 探索专属物品可同时含功能型与发现型，**但并非每件都必须强大或实用**
3. 🔴 **普通成长不应强迫玩家探索；独特发现也不应被金钱完全替代**
4. 经营可以支持探索，探索可以拓展经营，**但两者不必互相提供完全相同的奖励**
5. 🔴 **不必把所有路线的收益严格做成相等** —— 不同选择有各自合理的价值与适用场景
6. 🔴 **旅行本身也可以有价值** —— 不要求每段旅程都必须赚到钱、解锁机制或获得稀有物品

### 🔴 要避免的五个问题

| # | ❌ 问题 | 后果 |
| :-: | :-- | :-- |
| 1 | **所有奖励都能折算成金币** | 遗物 / 路线 / 人脉若最终只体现为售价或利润提升，**探索仍被经营效率主导** |
| 2 | **所有稀有物品都是最强装备** | **迫使不喜欢探索的玩家为了成长去探索** |
| 3 | **探索成为强制清单** | 每次探索都解锁新机制 / 任务 / 城市 → **探索本身变成效率任务** |
| 4 | **跑商与探索完全割裂** | 无法通过探索拓展商路，也无法通过经营为远行创造条件 |
| 5 | **每次探索都必须有实用回报** | 安静的旅程、普通的收藏品、没有重大后续的发现，**也是完整的旅行体验** |

> 🔴 **最终目标**：让玩家既可以把商队经营得越来越好，也可以因为对远方的好奇而走上一条未知的路 —— **经营帮助玩家继续旅行，而探索让玩家发现值得继续旅行的理由。**
