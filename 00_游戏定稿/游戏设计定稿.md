## 一、这是一款什么样的游戏

《余烬商队》是一款**末世废土题材的商队跑商游戏**，核心玩法是"经营一支商队，在大地图上跑商赚钱、探索冒险、逐步打通九座城市之间的商路"。

**玩法循环：** 你在城市里接订单、买货物 → 带着商队（人和车）出发，在大地图上走格子赶路 → 路上可能遇到强盗野兽、天气灾害、随机事件，也可能发现旧文明遗迹去探索挖宝 → 到达目的地卖货、交订单、赚金币 → 用金币升级商队（招人、加车、强化队员记忆、买好装备）→ 然后去更远、更危险的城市赚更多的钱。

**战斗是卡牌回合制**：每个角色有技能卡，全队共享行动力，出牌做取舍（打伤害/防御/治疗/修车）。**成长靠"记忆"系统**：旧文明技术让角色瞬间掌握技能，记忆可以升级、融合、加词条，打造专属战斗套路。

**玩家的定位很特别——不是救世主，是商人。** 激活城市节点（让城市复活）首先是一笔生意：城市活了，商路就通了，商路通了就能赚钱。至于"顺便拯救世界"，那是玩家自己的选择。

## 二、世界观（背景故事）

世界曾经是亮的。旧文明依靠一张覆盖大陆的能源网络维持运转，九座城市灯火通明，商路繁忙。但旧文明犯下了一个致命的错误——他们制造了**灰烬母兽**，一头能适应任何极端环境的巨型生物工具，用来在高辐射矿区、地下深渊等地带作业。母兽被当工具使唤，从未被当作生命对待；它在漫长劳作中长出了自我意识，当人类试图为它植入最终安全锁时，它反抗了——它学会把吸收的能量反向释放，制造了**灰潮**：一种具有侵蚀性和传播性的灰色污染，像海一样漫过大地，所过之处能源失效、灯塔熄灭、机械失控、动物狂暴。

旧文明倾尽全力压制了灰潮，代价是文明本身几乎毁灭：能源网络瘫痪、技术失传、人口锐减。灰烬母兽没有死，它重伤后沉睡在**烬渊山**的地底，至今仍在向外渗漏灰烬能量——灰潮是它制造的，而且从未真正停止。

幸存者在废墟上建起九座城市（灰原、枯林、鱼水、粮野、海盐、火油、药泽、黑石、灰烬），分布在九个自然区域，各自孤立衰败。城市中心的**节点反应炉**（旧文明的"心脏"）大多停摆，只有火油城产的**烬油**才能驱动它们——而商路断绝，烬油运不出去，城市就永远醒不过来。

在这片灰烬的世界里，还有一群崇拜母兽的狂热者——**灰烬教团**，他们认为灰潮是"净化"，母兽将清除旧文明的一切，在灰烬上建立新秩序。他们人数极少，但每一个都极其危险。

**玩家就是一支普通商队**——没有使命，没有预言，只想跑商赚钱。但当你手里握着旧文明的钥匙（余烬核心），当一座座城市因你重新亮起，当灰潮的真相一点点浮出水面，你才发现：自己已经走得太远，远到必须做出选择。

## 三、主线剧情

商队在灰原城（九城最边缘的城市）跑商时，一个快老死的人把祖传的旧文明钥匙——**余烬核心**——随手送给了玩家。没人知道它有什么用，直到有人发现它能插进灰原城中心的铁塔（节点反应炉）：插进去，拉闸，**城市亮了**。水井出水、路灯亮起、工坊的锤声重新响起来。

老商人告诉玩家：像灰原城这样的城市还有八座，它们的"铁心脏"都停着。要是都能点着，整个九城就活了——那是多大的买卖。**商队出发了，为了生意。**

一路激活节点，一路打通商路。但旅程并不全是生意：
- **枯林城**：猎首表面热情，实际设局想抢核心——玩家第一次吃大亏，从此学会提防（九城里有友善有中立有敌对，敌对的会诱骗你）
- **中圈城市**：水司难缠、盐场主设局、农长最实在……每座城都有自己的性格和算计
- **火油城油主**问了一句改变一切的话："你到底是来赚钱的，还是来当救世主的？"
- **药泽城**的旧文献里，玩家读到旧文明记载的残页——关于"母兽"的只言片语
- **黑石城**的老工人告诉玩家：灰烬城那边有一群疯子，信一个叫"灰烬母兽"的东西，说灰潮是净化
- **灰烬城**（旧都遗址）：玩家在节点反应炉的数据库里读到完整真相——灰潮是母兽制造的，母兽还活着，在烬渊山沉睡。而教团领袖质问："你觉得你是在救人，还是在招灾？——你一路点亮节点让网络恢复，网络恢复的尽头是唤醒母兽。"

**故事的悬念全部指向烬渊山**：灰烬城以北最大的山脉，母兽沉睡在山底一座超巨型矿山遗迹里。去，或不去，取决于玩家——结局有4个方向（灰烬止息/灰烬吞噬/时间结局/灰烬共生，方案已讨论待写入）。

**主题：**"在灰烬里找活路——你是商人，什么都标价，但有些东西没法标价。"

## 四、基础名词解释（先看懂这些，才能看懂后面）

| 名词 | 意思 |
|:-----|:-----|
| **食物** | 商队口粮。按1/4份算，每人每天吃1/4份（1份够1人吃4天）。没粮会死人 |
| **水（清水）** | 商队饮水。同样按1/4份算，要用水桶/水袋装。断水比断粮更致命 |
| **药包** | 治疗用品。队员受伤时用，战斗中和城市里都能用 |
| **零件** | 修车材料。商队车辆坏了要用零件修 |
| **补给** | 食物、水、药包、零件的统称——出门前要带够的"口粮弹药" |
| **商队耐久** | 车辆的"血量"。每天行驶磨损，归零抛锚；上限可从100升到300 |
| **车厢容量** | 商队能带多少东西（按"格"算）。初始200格，后期2,000格 |
| **金钱** | 通用货币。一切交易、工资、修理都靠它 |
| **火种** | 极稀有的旧文明能量结晶（"电池"）。强化记忆、驱动旧文明武器，后期最宝贵 |
| **烬油** | 旧文明燃料，只有火油城能产。节点反应炉靠它运转 |
| **余烬核心** | 旧文明的"激活钥匙"。插进节点反应炉，城市复活 |
| **节点反应炉** | 城市中心的"心脏"。激活=城市通电复活 |
| **记忆** | 本游戏的"技能"统称。旧文明技术，角色获得即掌握。分攻击/防御/辅助/消耗 |
| **记忆位** | 角色能同时携带的记忆数量（8个→15个） |
| **灰潮** | 毁灭旧文明的灰色污染灾难，真相是母兽制造的 |
| **灰烬母兽** | 旧文明造的巨型生物工具，反抗后制造灰潮，沉睡在烬渊山 |
| **灰烬兽** | 被灰烬污染变异的怪物，主要敌人之一 |
| **灰烬教团** | 崇拜母兽的狂热组织，认为灰潮是净化 |
| **遗迹** | 旧文明废墟，有宝贝也有危险 |
| **商队声望/世界声望** | 玩家在九城的名誉。影响交易优惠、高级订单、联合商队 |
| **士气** | 队员的心情。太低会出事（逃跑、消极） |
| **帮工** | 基础人员（车夫、杂役）。不参战但必须带够 |
| **护卫** | 战斗人员。只有他们能出战 |
| **特殊人员** | 专业人员（厨师、账房、修车匠等），各有特殊效果 |

## 五、大系统（16个，逐一说明）

---

### 1. 地图与商路系统

玩家在一张大世界地图上活动，地图由城市、商路和野外区域组成。城市之间通过商路相连，商路有长短和危险度；玩家移动是"走格子"——走一格消耗1天，没有速度概念，谁走都一样快，所以路线规划（走安全大路还是抄危险近道）就是核心策略。地图上有**信息等级**系统：你能看到多远的格子、提前知道什么情报，取决于侦察能力。

**关联系统：** 地点系统、天气事件、敌人系统、订单系统、情报系统。

---

### 2. 地点系统

定义所有能"落脚"的地方：**大城（九城）**（功能最全：交易/治疗/修理/招募/接订单/激活节点，物价最低）、**小城**（九城失败后民众自发聚集的定居点，无节点无旧文明特殊设施但正常设施都有，物价便宜，治安比大城危险，受兽潮影响）、**城镇**（补给点）、**驿站**（修车点，不接收撤退）、**村庄**（最简陋物价最高）。每个地点有自己物价、库存（会卖空）、限购。撤退只会撤到城市（大城或小城），不会撤到驿站。

**关联系统：** 地图商路、经济物价、治疗修理、声望、商队成员招募。

---

### 3. 商队资源与失败系统

管理商队"能不能活下去"：食物、水、药包、零件、耐久、金钱六类资源+火种。消耗规则（1/4份、水容器）、耐久磨损与成长、车厢容量、士气系统、资源耗尽的惩罚、失败条件、撤退。这是商队生存压力的核心。

**关联系统：** 补给系统、战斗（战损）、城市（休整）、商队成员（人吃马嚼）。

---

### 4. 战斗系统

回合制卡牌战斗。全队共享行动力（3~5点/回合），出牌取舍（伤害/防御/治疗/修车）。伤害分外伤（能挡）和内伤（无视防御）；状态系统（标记/流血/穿甲/迟滞/护盾/反击/灼烧等）提供配合深度。所有护卫可出战（人越多越强越贵）。后期有**旧文明武器系统**：说明书(记忆)+武器(遗迹)+火种(电池)三重门槛，操作旧文明大型武器一击秒精英、重创Boss。

**关联系统：** 角色成长（技能）、敌人系统（对手）、商队资源（战损）、记忆系统（技能牌）。

---

### 5. 天气与事件系统

让世界"活"起来：天气（暴雨/沙暴/酷热）影响移动补给；路上随机事件（遇旅人/发现废墟/遭伏击）；城市事件（市场波动/谣言/治安）。事件有冷却机制防重复。打破跑商单调感。

**关联系统：** 地图商路、战斗（伏击）、经济（市场波动）、城市（聚落事件）。

---

### 6. 角色技能与成长系统

玩家变强的途径。初始3角色（护路人坦克/荒野射手输出/修补师辅助）。核心是**记忆系统**：记忆升级（花钱）、融合（多个合成复合记忆1+1>2）、火种词条（加特效）。0费记忆不占位不限量但必须弱。重伤系统（倒下休养）。能力槽（数值被动+事件接口）、装备栏。

**关联系统：** 战斗系统、商队成员、火种、城市（升级设施）、队伍被动。

---

### 7. 世界观与设定

游戏的背景故事和世界规则（详见本文"二、世界观"）：灰潮、灰烬母兽、旧文明技术（节点/烬油/余烬核心/记忆）、九城地理物产、灰烬教团、社会阶层。解释一切"为什么"。

**关联系统：** 主线剧情（故事土壤）、城市系统（城市性格）、敌人系统（灰烬兽来源）、遗迹系统（旧文明残留）。

---

### 8. 灰兽潮大事件系统

周期性"天灾事件"：灰烬兽成群来袭。兽潮期间风险极高但打赢收益巨大（火种、材料）——玩家后期变强的主要动力。每次兽潮后野外敌人整体提升一档，世界越来越难。

**关联系统：** 战斗、敌人（强度）、奖励经济（火种）、主线（世界压力）。

---

### 9. 城市系统

九座城市完整设定：特产、特殊设施、城市人格、联通关系、统治结构（掌权者有好有坏——有的欢迎玩家，有的想骗玩家抢核心）、城市状态（衰败/恢复/繁荣）、声望系统。九城态度分布：友善2座（粮野/黑石）、中立4座、敌对3座（枯林/海盐/灰烬）。

**关联系统：** 地点、世界观、声望、主线（九城激活）、商队成员（招募）。

---

### 10. 遗迹系统

旧文明废墟探索：城市遗迹/研究所/工厂/大书库/矿山/地下/高险。位置固定、越靠近灰烬城越多越大越危险。遗迹内以战斗为主（旧文明机关机器人，比野外强25%），奖励记忆/零件/火种/图纸/装备。特殊格子宝藏一次性（二次探索意义不大）。灰烬母兽就在烬渊山超巨型矿山遗迹地底。

**关联系统：** 地图、战斗、敌人（机械）、角色成长（记忆产出）、主线（烬渊山）。

---

### 11. 敌人与Boss系统

四大类敌人：强盗（会埋伏会逃跑）、野兽（野化动物）、灰烬兽（污染变异）、旧文明机械（只在遗迹）。区域分布不同（越靠近灰烬城灰烬兽越多），精英有特殊机制（叫援军/扩散污染）。强度平时不涨，每过一次灰兽潮升一档。Boss详细后做，灰烬母兽是最终Boss。

**关联系统：** 战斗、地图商路、遗迹、灰兽潮。

---

### 12. 订单与贸易系统

玩家赚钱的"饭碗"。订单四类：送货（限时）、护送（限时）、收购（无限时交货给钱）、悬赏（击杀领赏）。收购/悬赏不用接取（可能不知情完成）。世界是活的：订单有随机时限可能被NPC抢先完成。5档难度。贸易=低买高卖，货物有品级（精/普通/劣），污染货没人要。无限接单。

**关联系统：** 地图商路、经济、声望、城市、战斗（悬赏）。

---

### 13. 商队成员系统

人员管理。三类：帮工（车夫杂役，必须带够否则瘫痪，无特殊效果便宜）、护卫（战斗，能出战，日薪2倍+）、特殊人员（厨师/账房/修车匠，各有被动效果）。硬分工：只有护卫能出战。核心成员不领日薪，雇佣成员领日薪，后期剧情可加入新核心角色。升级车厢才能带更多人。后期联合商队（2~5支）。

**关联系统：** 商队资源（工资口粮）、战斗（护卫出战）、角色成长、城市（招募）、经济。

---

### 14. 补给系统

"出门带多少粮"。食物水按1/4份、水用容器。出发有推荐/保守/冒险三种带法。断粮断水惩罚（掉血/士气/重伤恶化），路上基本找不到天然水源。补给决定商队能走多远。

**关联系统：** 商队资源、地点（购买）、地图（路线长度）、车厢（容量）。

---

### 15. 主线剧情

详见"三、主线剧情"。弱引导开放世界：不做任务队列，靠传闻线索推动。玩家体验分7段（起步→上路→立足→扩张→深入→决战前夜→终局），每段有大致数值。结局4方案待写入。

**关联系统：** 世界观、城市、遗迹、商队、敌人（教团Boss）。

# 第一部分：世界背景

## 一、灰潮之前——旧文明时代

在灰潮之前，存在一个高度发达的旧文明。没有人知道它存在了多久，但它曾遍布整片大陆。

### 旧文明的特点

旧文明不是全面超越现代的那种"完美先进文明"，而是一个**偏科的天才文明**：

**先进的方面：**
- **生物技术**：能够改造和创造生物体，制造了灰烬母兽
- **能源技术**：节点反应炉和能源网络覆盖大陆，火种作为高密度能量结晶
- **信息传递**：记忆技术可以直接将知识灌输给使用者，存储在"大书库"中
- **自动化技术**：防御机械、守门机、自动维修系统遍布各地

**脆弱的方面：**
- 技术体系依赖高度集中的能源网络——一旦网络断裂，整个文明都会瘫痪
- 知识高度集中在大型记忆书库中——灰潮中被大量摧毁，知识无法恢复

### 能源网络

旧文明最核心的技术成就是一张覆盖广阔区域的能源网络，由无数座节点反应炉支撑。城市是网络上的大型枢纽，驿站是中继点，矿场、农场、哨站是网络的末梢。只要网络在运转，世界就是亮的。

### 社会与生活

旧文明拥有几十座大型城市，有完整的供能、供水、医疗和防御系统。城市之间有稳定的商路和驿站网络。商队运输货物、传递消息。那时，世界是亮的、连通的、有秩序的。

---

## 二、灰潮发生

### 灰烬母兽的创造

旧文明创造灰烬母兽，目的是制造一种能适应任何极端环境的巨型生物工具——在高辐射矿区、地下深渊、灰烬弥漫的裂谷等人类和机械都无法生存的地带作业。它被设计成可以吸收和转化各种能量、拥有超强自我修复能力、可作为移动能源中继站的生物。它被当作工具来制造，从未被当作有生命的个体来对待。

### 灰烬母兽的反抗

但灰烬母兽在漫长的作业中逐渐发展出了远超设计规格的自我意识和智力。当创造者们试图为它植入最终的安全控制协议时，它反抗了。

### 灰潮——灰烬母兽的造物

研究员在设计母兽时赋予了它吸收和转化能量的能力，但他们没有预料到母兽可以将这种能力反向释放——将自身的能量转化为一种具有侵蚀性和传播性的污染物质。**灰潮不是自然现象。它是灰烬母兽制造出来的。**

### 灰潮的扩散

灰潮像海潮一样漫过大陆。它所到之处，灯塔熄灭，机械失控，通信断绝。野兽暴露在灰潮中后变异狂暴。灰潮中还诞生了全新的生物——从灰色的雾气中直接凝聚而成。旧文明的几十座城市，在灰潮中一座接一座陷落，绝大多数被彻底摧毁，变成了遗迹。

### 旧文明的抵抗与结局

旧文明调动了一切力量，最终压制住了灰潮——灰烬母兽被重创，陷入深度沉睡。灰潮的大规模扩散停止了。**代价是旧文明几乎毁灭。** 能源网络瘫痪，技术失传，城市失联，人口锐减。旧文明时代结束了。

---

## 三、九城时代

### 废墟上的重建

灰潮被压制后，幸存者在废墟上艰难地重建。旧文明的技术大量失传，但残存的技术和材料还在。幸存者们利用这些残片，建起了九座城市——分布在九个自然区域中，各自独立。

九座城市不是旧文明巅峰期的造物，它们建在文明已经衰败之后。但它们是残存的人类能拼尽全力建起来的全部了。

### 九城时代的兴衰

九城时代持续了大约两到三百年。
- 最初，九城之间有联系，商队往来，传递货物、消息和技术残片
- 但衰败是缓慢而不可逆的：科技在继续没落，灰潮时有时无，人口持续减少，技术彻底丢失
- 九座城市之间的联系越来越稀疏，最终断裂了

城市没有毁灭。城墙还在，建筑还在，节点反应炉还在。设施都是完好的——只是没有人会用了。

九城时代就这样在平静中落幕了。不是因为战争或灾难，只是因为衰败到了无法维持联络的程度。

### 现在的世界

九处时代结束后的世界，比九城时代更暗淡。九座城市各自孤立，有的可能还在运转，有的可能已经废弃。没有人知道哪座城市还存在，哪座已经空了。

城镇和驿站是沿途的小型聚居点，灰潮后人们自发建的。如果有人维护、有商队经过，驿站就会被"接入"商路网络。如果没有商队，它就只是路边几间没人住的破房子。

**商队是连接这一切的唯一希望。玩家就是一支商队。**

### 玩家的目标

玩家的目标不是让文明回到旧文明时代的巅峰，那个时代已经永远过去了。玩家的目标是：**让九座城市重新连接起来。** 激活沿途驿站的节点反应炉，恢复驿站的功能，打通城市之间的商路，让消息、货物和人在九座城市之间重新流动起来。

不是恢复一个辉煌的文明，是让这个世界从"正在慢慢熄灭"变成"还能继续维持下去"。

# 第三部分：阵营与势力

## 一、余烬商会（可加入）

余烬商会是九城中唯一一个曾在各城设有分部的商业组织。灰潮之后各城分会失去联系，但每个分会都没有解散，在各自城市周边继续运转。

玩家不需要"加入"商会——商队本身就是余烬商会的一部分，是流动的分会。玩家在某城分会的声望高了，该城分会才会提供更好的价格和订单。

**分会分布：** 灰原城（活跃）、枯林城（活跃）、鱼水城（活跃）、粮野城（活跃）、海盐城（活跃）、火油城（小型）、药泽城（小型）、黑石城（活跃、规模最大）、灰烬城（无）。

## 二、强盗（敌对·常见）

各路强盗、流寇、劫匪的统称，不是统一的组织。分为路匪（三五成群）、匪帮（有组织有据点、多达数十人）、流寇（无固定据点）三种。

**强盗的动机：** 他们不是生性凶恶。灰潮之后土地不适宜耕种，动物狂暴，没有粮食，快要饿死了，才被迫出来打劫过路的商队来勉强糊口。没有真正的反派，只是立场不同。一些小型匪帮会选择避让强大的商队，少数匪帮可以谈判交"过路费"换平安通过。

## 三、灰渊信徒（敌对·极罕见）

崇拜灰烬母兽的狂热教派。认为灰潮是"净化"，母兽将清除旧文明的一切，然后在灰烬上建立新的秩序。人数极少但每一个都极其危险，不怕死。只出现在特定剧情和特定地点。

## 四、灰兽（敌对）

灰烬兽（感染型，被灰潮污染的普通野兽变异而成）和灰渊兽（原生型，从灰潮能量中凝聚诞生，更强）的统称。越靠近灰烬污染区越多越强。

# 第四部分：旧文明技术

## 一、旧文明概述

灰潮之前的旧世界拥有一张庞大的能源和技术网络。旧文明技术不是魔法，而是高度发达但已失去完整知识体系的高科技。

### 核心特征
- **高度集成**：功能复杂但操作简单，多为"接入即用"式设计
- **不可复制**：当前人类无法重新制造，只能从遗迹中回收和修复
- **依赖特殊能源**：多数旧文明设备需要特定能源（烬油、火种）才能运行
- **效果强大但有限**：不是无限能源，使用有代价

## 二、节点反应炉

**只有城市有节点反应炉**，驿站没有。每个城市拥有1座节点反应炉，运作高度依赖烬油供应。一旦商路中断，烬油无法运达，节点反应炉就会失去能源无法工作。

## 三、烬油

风蚀沙漠的火油城出产烬油，这是节点反应炉运作的核心能源。不是普通石油，而是含有微弱灰烬能量的特殊油质。火油城的提炼技术最好，其他城市无法自行生产烬油。商路一旦中断，烬油无法从火油城运往其他城市，城市就会逐渐停摆。

## 四、余烬核心

**激活密钥，不是动力源。** 它不提供能源，而是授权启动能源分配系统。不消耗，不会损坏。接入城市节点反应炉后激活该反应炉的能源分配系统。余烬核心是"钥匙"，烬油是"燃料"，两者缺一不可。

## 五、记忆技术

记忆是旧文明遗留下来的战斗协议、操作经验或意识模板，存储在各种记忆载体中。不是知识教育，而是意识层面的能力植入。分为攻击、防御、辅助、消耗四类。出战记忆位初始8个，后期可达15个。

## 六、火种

旧文明遗留的高密度能源结晶。稀有战略资源，获取途径有限。不做火种碎片，是完整单位。用于记忆强化、记忆融合、旧时代装备启动。

## 七、旧时代装备

灰潮前的高科技物品，效果比普通装备更强。获取概率低，每一件都是独特的，但不是普通装备的上位替代。部分需要火种才能完全启动。车载旧文明巨物只能装在商队模块的旧时代装备槽上，消耗火种激发，效果极强。

# 第五部分：灰烬污染与灰兽潮

## 一、灰烬污染的起源

灰烬污染不是自然现象。它的根源是旧文明的生物技术失控产物——灰烬母兽。灰烬母兽至今仍然存活着，在灰烬城远处的**烬渊山**地底深处沉睡，不断向外释放灰烬能量。烬渊山是这一带最大的山脉，山体蕴藏大量稀有矿物，但环境极其恶劣。

## 二、灰潮

灰潮是灰烬母兽释放的灾变性能量潮汐，不是普通风暴。不再像初期那样持续爆发，但仍有周期性波动。灰潮的成因留悬念，主线推进中逐步揭示。

## 三、灰烬兽

统称灰烬兽，分为两大类：
| 类型 | 来源 | 强度 |
|:----|:----|:----:|
| **灰蚀兽**（变异型） | 普通野兽被灰烬污染侵蚀后变异 | 中低 |
| **灰渊兽**（原生型） | 灰潮能量直接凝聚诞生 | **更强** |

灰渊兽比灰蚀兽强大得多，分布更稀少，只在灰烬污染浓度高的区域出现。灰蚀兽原本是普通野兽，污染越深变异程度越高。

## 四、灰兽潮

灰烬兽周期性成群活动的现象，大事件级别的危机。与灰潮的周期性波动有关。风险极高，但兽潮后灰烬材料大量富集，收益极高。具体玩法机制归入第8类。

## 五、灰烬污染对世界的影响

- **土地退化**：灰烬污染使土地失去肥力——这是强盗产生的根本原因
- **城市依赖烬油**：商路中断→烬油断供→城市停摆
- **商队风险**：货物被污染会变成新污染源，需清除

## 三、社会阶层（通用九城结构）

九城时代末期，每个城市大体划分为以下阶层：

| 阶层 | 包含人群 | 社会地位 | 说明 |
|:----|:--------|:--------|:------|
| **统治者** | 城主/油主/大药师等 + 他们的家族 | 最高 | 掌握城市命脉资源（土地、能源、水源、武力） |
| **大商人/工头** | 商会负责人、大商队主、铁匠公会核心成员 | 高 | 经济实力强，能影响城市决策。城主也得给他们面子 |
| **技术工匠** | 会修旧设备的人、铁匠、药剂师、炼油师傅 | 较高 | 掌握实用技术的人，到哪都有人要。人数稀少但受尊重 |
| **普通市民** | 小商贩、手艺���、猎人、农民、渔民 | 中 | 自给自足，勉强糊口 |
| **底层** | 无地农民、搬运工、临时工、老人 | 低 | 生活在城市边缘，干最苦的活赚最少的钱 |
| **边缘人** | 流浪汉、拾荒者、被灰烬污染的人 | 极低 | 不被当城市一员，基本自生自灭 |

### 各阶层详细描述

**统治者**
每个城市只有极少数人处于这个阶层——世袭的城主、油主，以及他们的直系亲属。他们掌握着城市最重要的资源（土地、水源、能源、武力）。住在城市最好的区域，有仆人，有卫队。但也并非高枕无忧——如果城市长期衰败，统治者的地位也会动摇。火油城的油主是其中最稳固的（烬油谁都离不开），灰原城的城主是最虚的（啥也不掌握，说话没分量）。

**大商人/工头**
商会负责人、大商队主、铁匠公会的核心成员。财富雄厚，能左右城市的经济决策。城主缺钱了也得找他们借。这一阶层和玩家关系最密切——玩家本身就是商队，到各个城市都要和商会打交道。

**技术工匠**
人数稀少但非常受尊重的一群人。他们掌握着旧设备的维修和操作知识——铁匠铺的师傅知道怎么打一把好刀，炼油厂的老技工知道怎么提炼烬油。无论到了哪个城市，技术工匠都不会饿死。他们通常不太关心政治，更在乎自己的手艺。

**普通市民**
城市里的大多数人——小商贩、猎人、农民、渔民、手艺人。每天为了生计奔波，勉强糊口。他们不太关心城主是谁，更在乎明天的粮价和今天的治安。他们是市场的主要交易对象，也是各种消息的源头。

**底层**
无地农民、搬运工、临时工。干的是最苦最累的活，赚的是最少的钱。住在城市外围的破旧棚屋里。如果有人生病或受伤，往往没钱去医馆，只能硬扛。灰潮对他们影响最大——土地退化后他们第一批失去生计。

**边缘人**
流浪汉、拾荒者、被灰烬污染的人。他们不被视为城市的一员。灰烬污染者身上有明显的灰蚀痕迹，其他人会刻意避开他们。这些人通常出现在城市外围的废墟和灰烬污染区附近。偶尔可能知道一些别人不知道的秘密——毕竟他们整天待在别人不去的地方。

### 阶层流动性

九城时代的社会结构不是铁板一块——**阶层有一定的流动性**，但不高：

| 向上途径 | 难度 | 说明 |
|:---------|:----:|:------|
| 做生意发财 | 中 | 有本钱+运气，小贩可以变成大商人 |
| 学徒出师 | 低 | 跟师傅学手艺，学成了就是工匠，生活立刻上去 |
| 保卫城市立功 | 中 | 兽潮中表现突出，可能被领主赏识 |
| 发现旧文明遗物 | 高 | 找到有价值的旧设备或记忆，一夜暴富，但概率极低 |

> 玩家作为外来商队，不受这个阶层体系的限制。玩家和哪个阶层打交道都可以。

## 一、世界观基调

## 二、玩家为什么心甘情愿激活节点（驱动力）

## 四、序幕：灰原城——一把钥匙

故事从灰原城开始。这是九城最边缘的城市，破败，但还活着——有市集、有酒馆、有人。

商队三人在灰原城跑商。某天酒馆里，一个快老死的人把他们叫住。老人从怀里摸出一件旧东西——**余烬核心**。他不知道这是干什么的，只说是祖上传下来的，可能是他爷爷的爷爷的爷爷哪辈子出门捡的、换的、还是偷的，时间太久，他也说不清了。反正传到他手上，他也没后代，快老死了，就想随便找个人把东西送出去，免得烂在箱底。

商队一开始没当回事。直到有人发现：核心能插进灰原城中心那个废弃的铁塔——节点反应炉。插进去，拉闸，**灰原城亮了**。水井出水，路灯亮起，工坊的锤声重新响起来。

灰原城的人第一次在夜里看见全城亮灯。城主站在城头说不出话，商会连夜给商队送钱。

**传说**：老商人告诉玩家，灰原城只是九城之一——像这样停摆的城市还有八座。它们的"铁心脏"都熄着。要是都能点着，整个九城就活了，那得是多大的买卖。

老商人送玩家一句话："**世界是灰的，但路是人走出来的。** 八座城还黑着呢，你要是愿意跑，这买卖够你做一辈子。"

商队出发了。为了生意——顺路，也让几座城市亮起来。

## 五、第一幕：商路初开——枯林城（第一次吃大亏）

第一站是枯林城。猎户之城，几个猎户家族把持一切，排外。

枯林城猎首**表面热情**：欢迎商队，说愿意谈激活节点的事，请商队进城详谈，许诺重酬。

**然后玩家吃了一个大亏**——进城后被设局：猎首翻脸，想抢夺余烬核心。玩家被迫应战/逃跑/交涉，损失惨重（货物被扣、队员受伤、声望受损），但**死不了**——核心没被抢走，还能继续玩。

**这一课玩家永远记住：不是每个笑脸背后都是好意。** 从此学会提防。

- 火油城炼油厂：老技工说烬油"不干净"，里头有"活的东西"的痕迹

### 鱼水城：水源即权力（中立）
水司掌握净水厂，城主是傀儡。水司**想抢核心但没动手**——他谈判刁钻、处处防着玩家、条件苛刻，但始终守住了"生意"的底线。玩家吃过枯林城的亏，在这里会格外提防，但最终发现：水司只是难缠，不是骗子。

### 海盐城：投票与盐场（敌对·中期）
公会内斗。某个盐场主想借激活节点夺权——他许诺重酬把玩家骗进城，设局想抢核心。玩家这时已有枯林城的经验，有机会识破。节点炉埋在旧盐场底下被盐壳封死，激活需要组织人手挖开（无论谁掌权都要做这件事）。

### 粮野城：最实在的地方
农长直接问玩家："你要什么？"玩家报个价，他点头。整个游戏里最干脆的一次交易。

---

## 七、第三幕：烬油与命脉（火油/药泽/黑石）

火油城油主那句"**你到底是来赚钱的，还是来当救世主的？**"——全篇主题句。

药泽城文献触到真相边缘、黑石城撞见教团正面势力。此时玩家回头看，会发现教团的网早就存在——只是现在才浮出水面。

**每座城都有教团的影子**——前期隐藏极深：
- 枯林城酒馆角落里那个总念叨"净化"的老酒鬼
- 鱼水城码头上帮人搬货的沉默力工
- 粮野城集市上低价卖"护身符"的货郎

玩家前期不会注意到他们是一伙的。只有走到黑石城之后回看，才惊觉教团的网早就撒遍了九城。

---

## 八、第四幕：旧都真相（灰烬城）

教团领袖质问："**你觉得你是在救人，还是在招灾？**"

（此幕细节保留，灰烬城数据库揭示母兽来历——见世界观。）

## 九、终幕：烬渊山（母兽沉睡之地）

**烬渊山**——灰烬城以北最大的山脉，山体蕴藏大量稀有矿物，但环境极其恶劣。灰烬母兽沉睡在山体的地底深处（一座超巨型矿山遗迹内部）。

**玩家怎么知道烬渊山：**
- 传闻：老商队、灰烬城拾荒者、教团只言片语
- 地图/线索：灰烬城数据库里有旧文明矿脉图，标注了烬渊山的位置
- 教团：他们知道烬渊山的一切，甚至守护着它

**进入方式：**
- 烬渊山必须经过灰烬区域（地理限制）
- 山体内部 = 超巨型矿山遗迹（1,000格以上）
- 遗迹里：旧文明机关、机械守卫、灰烬兽——战斗强度最高的区域

**玩家去烬渊山意味着什么（此时玩家已知）：**
- 激活节点让网络恢复，而网络恢复的尽头是唤醒母兽
- 教团认为"网络恢复 = 给母兽续命"，阻止玩家
- 但不去烬渊山，灰潮永远不会停止——九城还是会慢慢被灰吞掉

**选择：** 去，或不去（结局部分写）。故事到此，所有悬念都指向山底的母兽。

---

## 十、结局（四个方向）

### 结局A：「灰烬止息」（好结局）

**达成条件：** 最终战胜利。

**过程：** 玩家在烬渊山超巨型矿山遗迹深处找到旧文明的巨型装置（巨型武器/封印装置）。母兽苏醒后，玩家利用巨型装置对抗它——先铺状态削弱（标记/穿甲/迟滞），再用旧文明武器强发射（烧火种）重创，最终终结或封印母兽。

**结局画面：** 灰潮停止扩散，九城重连，世界重新亮起来。商队成了传奇——但玩家很清楚：自己只是把路走通的那个人。灰烬教团失去信仰崩溃；各城恢复运转，商路繁忙。

### 结局B：「灰烬吞噬」（坏结局）

**达成条件：** 最终战失败。

**结局画面：** 母兽彻底苏醒，暴怒失控。灰潮再次大规模爆发，吞没九城——这一次没有旧文明能压制它。整个世界被灰烬吞噬。商队的名字和最后的身影一起，消失在灰色的海里。

### 结局C：「时间结局」（经商结局）

**达成条件：** 玩家长期不做主线（约5000~10000天），触发时间结局。

**按玩家积累的财富给不同结局：**
- **富可敌国**：多年经商，商队成为九城最大的商行。世界维持灰，但你的钱包是亮的。你听说过烬渊山有个"传说"，但你没去过——那与你无关。
- **穷困潦倒**：多年漂泊，商队散了，车卖了，你一个人在驿站里喝着最便宜的劣酒。你怀里还揣着那把没人要的旧钥匙——但你已经不再想它了。
- （中间状态：普通商人了此一生，待细化）

### 结局D：「灰烬共生」（共存结局）

**达成条件：** 玩家在旅途中满足特定条件（灰烬城数据库读到"最终安全协议"真相、持有旧文明沟通装置、或旅途中某些选择被母兽"看见"），并在最终战选择不启动巨型装置攻击母兽，而是尝试与它建立联系。

**过程：** 母兽醒来，暴怒——但它没有立刻攻击，它在"观察"这个和旧文明不一样的人。玩家放下武器/启动沟通装置/说出关键的话。母兽第一次遇到"不把它当工具也不把它当神"的人。

**结局画面：** 灰潮没有完全停止，但**不再扩散**——母兽学会控制自己的力量，只守护灰烬区域。九城重连，商路恢复。烬渊山不再是绝地，而是世界的"边界"。母兽沉睡在烬渊山，偶尔醒来，看着商队从山下走过。玩家的商队成了唯一能"进出烬渊山"的商队——因为母兽认得他们。

**代价：** 灰潮仍在（没消失），灰烬区域依然是禁区；教团视玩家为"背叛者"；部分城市不信任这个结局（母兽还活着）。

# 支线系统设计方案 v2

> 状态：v0.2
> 说明：主线是主干，支线是旅途中的**长篇插曲**——不是一堆小任务，而是少数几条**长支线**（像小说的长篇章节）。
> 原则：分量感 > 数量。避免和订单系统重复。

---

## 一、定位

支线是主线故事中的插曲，作用：
- **丰富世界观**——通过长故事展示九城的人与事
- **给适当奖励**——钱、物品、声望、情报、线索
- **分量感**——玩家和NPC之间**发生了故事**，不是"NPC要求玩家干这干那"

---

## 二、长支线原则（核心！）

| 原则 | 说明 |
|:-----|:------|
| **数量少** | 支线不用很多——**重点做几条长支线** |
| **每条很长** | 一条支线可以贯穿**从游戏前期到很后期**（至少穿过两个幕） |
| **多类型混合** | 一条支线里可以包含多种内容：救人、纠纷、委托、探索…… |
| **不是跑腿** | 不是"帮NPC干这干那"——是有情节、有起承转合的故事 |
| **时间跨度** | 例如：第一幕遇到一个NPC → 第二幕再遇到 → 第三幕他的故事收尾 |

> 例：一条支线——你在灰原城遇到一个落魄商人的女儿，帮她找回被抢的货（救人/寻物）→ 过程中发现她父亲与枯林城猎首有旧怨（纠纷）→ 一路帮她到中圈 → 最后在第三幕她的故事迎来结局。贯穿多幕，混合多种类型。

---

## 三、自由原则（已定）

| 原则 | 说明 |
|:-----|:------|
| 大多数支线 | **无前置限制**——路上遇到就能接，想什么时候做都行 |
| 世界限制 | 部分支线需要条件解锁：主线做到某一步 / 点亮特定城市 |
| 不推主线也能玩 | 玩家可以只做支线，不做主线 |
| 非定死 | 支线推进跟随玩家正常发展，不强制按幕走 |

---

## 四、世界限制（少数支线）

| 限制类型 | 例子 |
|:---------|:-----|
| 主线进度 | "主线推进到第三幕"才解锁某支线的后续 |
| 城市点亮 | "激活黑石城节点"后，黑石城相关支线开放 |
| 位置 | 某些支线只在特定区域出现 |

> 目的：支线和世界进程联动——世界变了，故事才出现。

---

## 五、触发方式

| 触发 | 说明 |
|:-----|:-----|
| 路上遭遇 | 走格子时遇到（随机或固定点） |
| 酒馆传闻 | 酒馆里听人说起 |
| NPC求助 | 城市/驿站里有人主动求助 |

# 第六部分：动态经济
============================================================

# 动态经济系统设计方案（独立大类）

> 状态：v0.1
> 说明：**全局系统**——不属于商会、也不属于城市。玩家自己运货、NPC运货、一切商业活动都会影响供需和价格。
> 关联：订单与贸易系统、城市系统、商会系统、主线

---

## 一、核心机制

**运输改变供需，供需改变价格。**

- 玩家（和NPC商队）运货到某城市 → 该城市此货物变多 → 价格下降
- 城市货物被买走/消耗 → 变少 → 价格上涨
- 世界物价不是固定的，是被"做生意"这件事动态改变的

---

## 二、例子

| 情况 | 结果 |
|:-----|:-----|
| 运大量食物和水到火油城（沙漠城市） | 火油城食物水**降价**、**不再短缺** |
| 长期没人给黑石城送粮 | 黑石城粮价上涨、短缺加重 |
| 大量采购海盐城的海盐 | 海盐城盐价上涨（供不应求） |

---

## 三、玩家能利用它做什么

| 玩法 | 说明 |
|:-----|:------|
| **低买高卖** | 看准供需缺口：缺货的城市运去→卖高价 |
| **解决短缺** | 城市缺什么运什么→价格回落→城市感激（声望） |
| **制造机会** | 大量买入某地货物→拉高当地价→再高价卖出（投机） |
| **长期供应** | 挂长期订单稳定供应→稳定价格→稳定收入 |

---

## 四、对城市的影响

- 城市"短缺"状态可以**被玩家治好**（运货解决）
- 城市繁荣度/价值受供需影响（配合城市经营）
- **跑商不是单纯赚钱——你在改变每一座城市的生活**

---

## 五、防刷限制（避免被滥用）

| 限制 | 说明 |
|:-----|:------|
| 价格波动幅度 | 有上下限，不会崩盘/暴涨到离谱（后定） |
| 恢复速度 | 价格会缓慢向基准回归（供需平衡），不会一劳永逸 |
| 情报可见 | 玩家能看到各城供需/价格状态（情报系统配合） |

---

## 六、待定项

| 待定项 | 说明 |
|:-------|:------|
| 供需公式 | 运输量/时间对价格的影响（后定） |
| 波动上下限 | 价格范围（后定） |
| 基准恢复 | 回归速度（后定） |

# 《余烬商队》第 1A 类：地图与商路系统 · 权威口径

## 1. 游戏类型定位

- **游戏类型**：大地图商队 RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件
- **地图形式**：格子地图，不采用爬塔路线，不采用自由移动
- **移动方式**：像下棋——向上、下、左、右移动一格
- 不是 3D 开放世界（早期废弃方案，已全部丢弃）

---

## 2. 时间系统

游戏所有系统统一到 **"天数"** 上计算。

| 项目 | 规则 |
|---|---|
| 移动 1 步（1 格） | 消耗 1 天 |
| 休养 1 天 | 重伤恢复进度 +1 |
| 等待 1 天（城市/城镇/驿站/村庄） | 天气推进 +1，消耗补给 |
| 订单期限 | 按天计算 |
| 天气持续 | 按天计算 |
| 补给消耗 | 按天消耗 1 份 |

每段天气持续约 5–10 天；大多数时间是晴朗或轻微天气。

> 核心体验：每一步都是一天，每一天都在消耗，每一次等待都在赌订单，每一次坏天气都可能是灾难，也可能是机会。

---

## 3. 地图规格

| 项目 | 规则 |
|---|---|
| 地图尺寸 | 8×6 或 10×6 的格子 |
| 出发位置 | 左下角 |
| Boss 位置 | 远端（右上角方向） |
| 移动方式 | 向上、下、左、右移动一格 |
| 每移动一格 | 消耗 1 天 + 1 份补给 |
| 第一版地图 | 固定地图，不需要随机生成 |

> 地图详细设计（具体每张地图的格子布局）已搁置，留到正式开发时再做。

## 4. 地图节点（格子）类型

地图上每一格可能是以下类型之一：

| 序号 | 节点类型 | 功能 |
|:---:|----------|------|
| 1 | **空地** | 只消耗资源，无事件 |
| 2 | **战斗** | 进入普通战斗 |
| 3 | **事件** | 触发随机事件（正面/负面/选择分支） |
| 4 | **营地** | 可以休息、修车、鼓舞士气 |
| 5 | **补给点** | 可以补充少量补给和零件 |
| 6 | **危险区** | 可能战斗，也可能获得奖励（高风险高回报） |
| 7 | **Boss** | 区域最终战 |

## 5. 移动消耗

**移动规则（已定）：1 格 = 1 天，固定不变。没有速度属性，没有任何加速/减速。** 车辆/牲畜升级不加速度，只影响其他维度（载重/耐久/防御等）。

每移动一格的消耗：

| 消耗项 | 规则 |
|---|---|
| 当前天数 | +1 |
| 补给 | -1 份（食物/水按 1/4 份粒度消耗，详见第 3A 类） |
| 重伤角色休息倒计时 | -1（休息节点数 -1） |

### 5.1 补给耗尽惩罚

补给 = 0 后，每天：
- 士气 -1
- 全队每人失去 5 点生命
- 重伤恢复天数 +1（不恢复反而恶化）

> 补给归零不直接失败，但三个惩罚叠加会迅速把商队拖垮。没有额外惩罚。

---

## 6. 路线分类

每段路（城市到驿站、驿站到驿站）之间的距离约为 **30 天**。

### 6.1 路线长度分类

| 路线类型 | 总距离 | 定位 |
|:-------:|:------:|------|
| **短途** | 30 天以上，60 天以下 | 新手路线 / 短途跑商 |
| **中途** | 60 天以上，120 天以下 | 有规划压力的主力路线 |
| **长途** | 120 天以上，180 天以下 | 真正远征 |
| **超长** | 180 天以上 | 后期大订单 / 边境商路 |

### 6.2 推荐补给携带量

| 路线类型 | 理论最低补给 | 推荐携带 |
|:-------:|:----------:|:--------:|
| 短途（30–60 天） | 30–60 | 40–80 |
| 中途（60–120 天） | 60–120 | 80–150 |
| 长途（120–180 天） | 120–180 | 150–220 |
| 超长（180 天以上） | 180+ | 220+ |

### 6.3 中继点

**中继点只有城镇和驿站**，是路线中途的安全休息点，用于补给、修车、休整。村庄不算中继点。

路线节点密度：约每 **2-3 格** 一个中间休息点。

### 6.4 中程商路参考参数

| 项目 | 参考值 |
|---|---|
| 标准路线 | 约 100 天 |
| 订单期限 | 130–150 天 |
| 路线结构 | 4 段路 |
| 中继点 | 3 个 |
| 每段距离 | 20–30 天 |

### 6.5 超长商路

超长路线（180 天以上）中间可以有一座城市作为大休整点，但到达该城市**不代表订单结束**，玩家只是中途整备后继续完成订单。

### 6.6 订单期限

```
订单期限 = 路程天数 × (1.3 ~ 1.5)
```

例：100 天路程 → 订单期限 130–150 天。200 天路程 → 订单期限 260–300 天。

## 7. 玩家路线决策

出发前需要判断以下事项：

| 决策项 | 说明 |
|--------|------|
| 到下个驿站大概多少天 | 评估路线长度，决定出发时机 |
| 要带多少补给 | 按 1 天 1 补给估算，留出余量应对绕路和坏天气 |
| 要带多少零件 | 用于修车、技能、事件，零件不够可能在半路抛锚 |
| 是否少带货、多带生存物资 | 货物与生存资源之间的取舍，多带货赚钱但可能不够吃 |
| 天气是否适合出发 | 判断当前与未来天气，坏天气可能增加消耗和风险 |
| 订单期限是否允许等待 | 评估容错空间，等待可能让订单超时 |
| 遇到坏天气是否硬闯、绕路或等待 | 途中风险决策，需要兼顾补给、时间和订单 |

绕路和走近路有两种形式：
- **棋盘上主动规划**：玩家在地图上选路时选更长更安全的路径，或更短更高风险的路径
- **事件触发**：通过外部事件（E10 路线判断事件）临时出现的路线选择

## 8. 地图侦察机制（信息等级系统）

玩家在地图上移动时，前方格子的信息通过**信息等级**系统决定能看到什么。

### 8.1 信息等级定义

| 等级 | 名称 | 玩家知道什么 | 示例 |
|:---:|:----|-------------|------|
| 0 | 无信息 | 什么都不知道，只知道有异常 | "前方出现异常。" |
| 1 | 模糊信息 | 知道可能有危险，但不知道类型 | "前方情况不太对，可能有危险。" |
| 2 | 类型信息 | 知道大概类型 | "前方像是有人活动过，可能是敌对风险。" |
| 3 | 关键信息 | 知道具体类别 | "前方大概率是强盗活动痕迹。" |
| 4 | 详细信息 | 知道大致数量、方向、位置范围 | "约 5-8 人，位置在北侧断路附近。" |
| 5 | 精确信息 | 知道具体人数、具体格子、具体触发条件 | "强盗 6 人，埋伏在前方第 3 格右侧。" |

### 8.2 信息类型

信息分为6大类，不同角色只影响自己专业的信息类型：

| 信息类型 | 说明 | 初始角色来源 | 提升幅度 |
|:--------|------|-------------|:--------:|
| **路线信息** | 前路、岔路、雾天、危险地形 | 荒野射手【野外侦察】 | +1 级 |
| **敌情信息** | 强盗、野兽、灰烬兽、伏击、夜袭 | 荒野射手【野外侦察】 | +1 级 |
| **资源信息** | 补给、水源、草药、材料、猎物 | 荒野射手【狩猎采集】（偏结果权重，不直接加信息等级） | — |
| **结构信息** | 桥梁、车轴、道路、坡道、废墟结构 | 修补师【现场诊断】 | +1 级 |
| **车损信息** | 车轴、车厢、车轮、抛锚隐患 | 修补师【现场诊断】 | +1 级 |
| **异常/旧文明信息** | 灰烬、火种、旧文明设备 | 初始修补师暂不专精 | — |

> 护路人不提供信息等级。护路人负责稳定结算，不负责侦察。

### 8.3 信息计算方式

```
最终信息等级 = 事件基础信息 + 区域信息 + 角色词条信息 + 装备信息 + 路线情报/记忆信息
最高不超过 5 级
```

| 信息来源 | 范围 | 说明 |
|---------|:---:|------|
| 事件基础信息 | 0-2 | 事件本身给出的可见程度 |
| 区域信息 | 0-1 | 该区域是否有明显特征 |
| 角色词条信息 | 0-1 | 随行角色是否有对应信息词条 |
| 装备/工具信息 | 0-1 | 望远镜、探测器、地图等 |
| 记忆/路线情报信息 | 0-2 | 旧文明记忆、驿站情报、商队传闻 |

### 8.3 初始信息上限

在没有装备、记忆、路线情报的初始阶段，最高可看到 **2 级（类型信息）**。

| 阶段 | 信息上限 |
|:----|:--------:|
| 初始三人，无装备/无记忆/无情报 | 最高 2 级 |
| 加上路线情报、驿站预警、基础工具 | 可到 3 级 |
| 中后期专用装备、专精角色、特殊记忆 | 可到 4 级 |
| 高级记忆、高级设备、剧情关键情报 | 可到 5 级 |

### 8.4 角色信息能力（关联第 6 类）

角色词条信息的具体设定属于第 6 类，此处仅列接口：

| 角色 | 词条 | 影响的信息类型 |
|:----|:----|---------------|
| 荒野射手 | 【野外侦察】 | 路线信息、敌情信息、痕迹信息等级 +1 |
| 修补师 | 【现场诊断】 | 结构信息、车损信息等级 +1 |
| 护路人 | — | 不提供信息等级，负责稳定结算 |

| 100 天 | 3,000 | 4,200–5,100 |
| 150 天 | 4,500 | 6,300–7,650 |
| 220 天 | 6,600 | 9,240–11,220 |

长线真实总收益（含顺路订单、自营贸易、战斗收益等）可达 20,000–30,000 金币。

## 1. 地点分类总览

游戏中安全点分以下五类：

| 地点 | 定位 | 核心特征 |
|:---:|------|---------|
| **大城（九城）** | 唯一真正的大安全点 | 唯一有节点反应炉、可处理重伤/失能、功能最完整、物价最低 |
| **小城** | 自发聚集定居点 | 无节点/无旧文明特殊设施（工坊等），但正常设施都有；物价便宜（比城镇低、比大城高）；治安比大城危险；有聚落事件；受灰兽潮影响 |
| **城镇** | 路上的补给容错点 | 补给、生活物资、普通治疗、偏生活 |
| **驿站** | 商队专门休息点 | 零件、修车、路线服务、偏车队；**不接收撤退** |
| **村庄** | 小型聚落 | 功能最少、小订单、少量交易、情报、物价最高 |

> 各地点功能为参考框架，具体功能以实际设定为准。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同，不是上下级。

### 小城（新增地点类型）

| 项目 | 设定 |
|:-----|:------|
| 来源 | 九城网络失败后，民众**自发聚集**形成的新定居点（不是旧文明城市） |
| 人口 | 约 1 万（参考） |
| 数量 | **99 座**（已定），铺开在商路上 |
| 节点 | **没有**节点反应炉 |
| 设施 | **大城有的功能小城都有**——除了**涉及旧文明的设施**（锻造坊、工坊、记忆设施等）——因为小城是九城时代之后才建的，只是聚集点 |
| 物价 | 跟大城**一档**，但**比大城稍贵一点**（参考） |
| 治安 | 比大城危险一点 |
| 事件 | 有聚落事件 |
| 声望 | 无城市声望；有**世界声望 + 商会声望** |
| 兽潮 | 受灰兽潮影响 |
| 安全点 | ✅ 是（接收撤退） |
| 命名 | 暂不命名（后补） |

### 撤退规则（已定）

- 撤退**不会撤到驿站**（驿站不接收撤退）
- 城镇/村庄撤退**只会撤到城市**——大城或小城都可以

## 2. 城市

城市是游戏中唯一真正的大安全点，也是唯一设有 **节点反应炉** 的地点。

### 2.1 城市能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 大量供应，价格最低 |
| 购买零件 | 大量供应，价格最低 |
| 购买药包 | 大量供应，价格最低 |
| 治疗角色 | 花钱恢复生命，可处理轻伤 |
| 恢复重伤/失能 | 只有城市可以恢复重伤和失能状态 |
| 修理商队耐久 | 花钱恢复商队耐久 |
| 招募新队员 | 替换失能角色或补充后备 |
| 接订单 | 各类订单 |
| 卖货 | 处理贸易收益 |
| 打听情报 | 路线风险、天气、特殊事件信息 |
| 消费提升士气 | 酒馆/宴席/休整 |
| 购买旧文明遗物与装备 | 数量有限、刷新慢、有概率随机出现 |
| 工坊与特殊系统 | 工坊复产、古代记忆等后续系统 |
| **购买车辆** | 人员车/货车在城市工坊购买（小型/中型/大型） |
| **购买牲畜** | 驮畜在城市购买 |

### 2.2 城市不能做什么

- 城市不能无限刷新订单（订单种类和数量受限于城市状态）
- 城市不能直接传送（没有传送系统）

### 2.3 设计口径

> 城市是"大修整"——玩家应在城市完成完整整备后再出发。
> 城市是唯一能处理重伤和失能的地方。
> 城市的价格最便宜，是为了鼓励玩家在城市带足资源，而不是到了路上再补。

---

## 3. 城镇

城镇是路上的补给容错点，不是低成本完整整备点。

### 3.1 城镇能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存较少 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/失能 |
| 接小订单 | 短途订单为主 |
| 打听消息 | 路线情报（精度和可信度有限） |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 3.2 城镇不能做什么

- 不能恢复重伤/失能
- 不能招募新队员（遇特殊事件除外）
- 不能修理商队耐久（或只能极少量）
- 没有节点反应炉
- 没有工坊等城市特殊系统

### 3.3 设计口径

> 城镇有人长期生活，所以补给比驿站便宜。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同。
> 城镇偏向：补给、药包、普通治疗、生活物资。

---

## 4. 驿站

驿站是专门给商队的休息点，和城镇是平级关系，功能与城镇基本相同。

驿站的历史背景：旧文明时代的驿站网络，灰潮失联后驿站工作人员留在原地生活，商路断了多年。玩家重新接入商路后，驿站恢复功能。

### 4.1 驿站能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存比城镇略多 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/失能 |
| 修理商队耐久 | 驿站偏向修车服务 |
| 接小订单 | 短途订单为主 |
| 打听路线信息 | 获得下一段路的风险提示 |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 4.2 驿站不能做什么

- 不能恢复重伤/失能
- **没有**节点反应炉（只有城市有节点反应炉）
- 不能招募新队员
- 没有工坊等城市特殊系统
- 没有传送功能

### 4.3 设计口径

> 驿站是"续命点"——主要解决路上的零件和修车问题。
> 驿站偏向：零件、商队耐久修理、路线服务、旅人消息。
> 驿站不是每个都有节点反应炉，只有城市才有。

---

## 5. 村庄

村庄是最小型的安全点，功能最少。

| 功能 | 说明 |
|------|------|
| 购买补给 | 数量极少，价格最高 |
| 接极小订单 | 顺路小任务 |
| 打听情报 | 可获取免费传闻级别的信息 |
| 等待天气 | 消耗补给和天数 |

> 村庄不恢复士气。村庄不能治疗、不能修车、不能招募。

## 9. 收入结构

游戏不只有跑商赚钱。战斗、事件、自营贸易都有价值。

| 收入来源 | 定位 | 收入强度 |
|---------|------|:--------:|
| **主订单** | 最稳定收入，路线主收益 | **高** |
| **顺路订单/中途订单** | 路线规划收益核心 | **中高** |
| **战斗收益** | 鼓励玩家愿意打 | 中到中高 |
| **精英/高风险战斗** | 高风险对应高价值 | **高** |
| **事件收益** | 补充收入，随风险变化 | 中 |
| **自营贸易** | 未来重要收入来源 | 中高 |
| **Boss/关键战斗** | 保货、解锁、推进剧情 | 特殊高价值 |

> 战斗收益不能压过所有订单收益，但必须足够有吸引力让玩家愿意承担风险。

## 5. 失败条件


### 6.1 真正失败条件

只有以下两种情况触发强制撤退（不是游戏结束）：

1. **士气归零** → 士气崩溃，触发强制撤退
2. **全队倒下 + 商队耐久归零** → 无法继续行动，触发强制撤退

> 失败本质是商队被迫撤退止损，不是游戏结束。
> 没有其他失败条件。

### 6.2 全队倒下

全队倒下后不直接游戏结束，触发后果：

| 惩罚项 | 内容 |
|:------|------|
| 货物 | 全部损失 |
| 食物/水/零件 | 全部损失 |
| 位置 | 退回最近的安全点 |
| 所有角色 | 强制进入休养状态 |
| 士气 | -2 |
| 商队耐久 | 降到 20 |
| 当前订单 | 大概率失败或严重降级 |
| 金钱 | 暂不扣（避免彻底死档） |

> 这会非常痛，但还能继续。

## 1. 战斗定位与目标

- **战斗类型**：回合制战术卡牌，全队共享行动力
- **UI 形式**：队列式 UI，不是棋盘
- **核心目标**：不只是杀敌，还要保护商队、保护货物、避免重伤
- **与杀戮尖塔区别**：
  - 三人小队共享行动力，不是单角色构筑
  - 三层防御结构
  - 战斗结果会影响大地图旅程
  - 伤害分内伤/外伤，内伤不可阻挡

---

## 2. 行动力系统

### 2.1 基础规则

- 全队共享行动力
- 每回合在攻击、防御、治疗、修车之间取舍
- 技能费用：
  - **0 费**：铺垫、小辅助类
  - **1 费**：主力技能，大部分基础技能
  - **2 费**：强力技能、爆发技能、关键技能

### 2.2 商队人数与行动力

**出战规则（已定）：战斗出战无上限——商队里所有护卫（战斗成员）都能出战。** 平衡靠护卫日薪（帮工的2倍以上）自然限制，不限制出战人数。

行动力按出战战斗成员数计算：

| 出战战斗成员数 | 每回合行动力 |
|:-------------:|:----------:|
| 3 人 | 3 点（基础） |
| 4 人 | 4 点 |
| 5 人 | 5 点 |
| 每多 1 人 | +1 点（无上限） |

### 2.3 每回合卡牌数

| 出战战斗成员数 | 每回合抽牌数 | 计算方式 |
|:-------------:|:----------:|:--------:|
| 3 人 | 7 张 | 每人 2 张 × 3 + 商队牌 1 张 |
| 4 人 | 9 张 | 每人 2 张 × 4 + 商队牌 1 张 |
| 5 人 | 11 张 | 每人 2 张 × 5 + 商队牌 1 张 |
| 每多 1 人 | +2 张 | 每人 2 张 + 商队牌 1 张不变 |

### 2.4 消耗品消耗行动力

在战斗中使用消耗品（药包、零件等）需要消耗行动力：
- 使用药包：消耗 **1 点行动力**
- 使用零件修车：消耗 **1 点行动力**
- 其他消耗品同理

> 战斗中的每个行动都需要消耗行动力，包括使用消耗品。这是为了让玩家在"打伤害"、"防御"、"治疗"、"修车"之间做取舍。

## 3. 伤害类型：内伤与外伤

伤害分为两大类：

| 类型 | 说明 | 举例 |
|:----|------|:----|
| **外伤** | 可以被防御阻挡 | 普通攻击、穿甲攻击、灼烧 |
| **内伤** | **不可被防御阻挡**，无视护盾/护甲/屏障 | 流血伤害、已施加的持续伤害 |

> 防御系统只对外伤生效。内伤一旦施加，伤害无法通过防御减免。

---

## 4. 防御系统

三层防御结构，均只对外伤生效：

| 类型 | 特性 | 持续 | 说明 |
|:----|:----|:----:|------|
| **护盾** | 临时防御，回合结束清空 | 当前回合 | 挡外伤。若完全挡住攻击，可阻止流血施加 |
| **护甲** | 长期普通防御 | 直到被打掉 | 只挡普通攻击。不挡穿甲攻击、流血、灼烧 |
| **屏障** | 高级防御 | 直到被打掉 | 挡外伤、大多数负面施加。不挡已有流血伤害 |

### 伤害结算顺序（仅外伤）

```
护盾 → 屏障 → 护甲 → 生命
```

> 护盾优先结算，因为护盾过一回合就消失。屏障在护盾之后。

**穿甲攻击**的结算顺序：护盾 → 屏障 → 生命（**无视护甲**）

> 内伤不经过上述结算，直接作用于生命。

## 6. 旧文明武器系统（终极爆发·已定）

**定位：** 大后期终极爆发手段——一击秒精英、重创Boss的超高伤害招式。

### 6.1 世界观

- **记忆 = 旧文明大型武器的操作说明书**（不是武功秘籍——玩家是"看懂说明书"才能操作武器）
- **武器 = 旧文明仪器**（遗迹里找到的大型武器）
- **火种 = 电池**（高密度能量结晶，给武器供电）
- 三者缺一不可：没有说明书不会用，没有武器没得用，没有火种用不了

### 6.2 获取（双重门槛）

| 门槛 | 来源 |
|:-----|:-----|
| 说明书（奥义记忆） | 大后期：遗迹深处 / 灰烬城数据库 / Boss掉落 |
| 武器（旧文明仪器） | 遗迹探索获得 |

### 6.3 发射模式

| 模式 | 消耗 | 威力 |
|:-----|:-----|:-----|
| **弱发射**（免费） | 不消耗火种/烬油 | ≈普通攻击，甚至略弱——应急用 |
| **强发射**（终极爆发） | 消耗**火种**（电池） | 超高伤害——一击秒精英、重创Boss |
| （可选）烬油增幅 | 额外消耗烬油 | 伤害再提升 |

### 6.4 使用规则

- 战斗中操作武器攻击，消耗行动力
- 弱发射免费但弱——平时用普通技能，武器是"保险"
- 强发射烧火种——火种同时用于记忆强化，玩家自己权衡（强化记忆 or 攒着放大招）
- 火种稀有 → 大招不能乱放，是战略资源

> 与烬油的分工：烬油维持节点网络（城市），火种驱动武器（战斗）。两者都是命脉。

## 9. 撤退系统

撤退分为两大类：**战斗撤退**（战斗中）和 **地图撤退**（大地图上）。

### 8.1 战斗撤退

在战斗中可以选择撤退。某些特定 Boss 不可撤退。

#### 判定规则

| 项目 | 规则 |
|:----|:----|
| 出现时机 | **每回合都**可以选择撤退（含战斗开始），**第 3 回合起**开始判定 |
| 基础成功率 | **50%** |
| 判定结果 | 成功→撤离战斗；失败→继续战斗，后续可再次尝试 |

#### 成功率修正

| 影响因素 | 修正 | 说明 |
|:--------|:----:|------|
| Boss 战 | 默认不能普通逃跑 | 剧情允许逃跑的 Boss 战成功率 25%–35% |
| 严重超重 | 无法逃跑 | 超重状态下不能撤退 |
| 敌方平均迟滞 | 提高逃跑成功率 | 逃跑加成 = 向下取整（所有敌人的迟滞失败率之和 ÷ 敌人数量） |

#### 撤退结果

| 项目 | 规则 |
|:----|:----|
| 士气变化 | **-1** |
| 货物 | **不损失货物** |
| 战斗奖励 | **无法获得**（敌人没打完，奖励无法获取） |

### 8.2 敌方逃跑

敌人分为三类：**野兽**、**强盗**、**灰烬兽**。逃跑机制各不相同。

#### 基本规则

- 每个敌人**独立累计**逃跑意愿
- **第 1 回合起**即可开始累计逃跑意愿
- **第 3 回合后**开始判定
- 逃跑意愿达到 **100** → 显示"敌人将要逃跑"提示
- 提示后**第 3 回合**开始判定（玩家有准备时间）
- 判定成功→敌人逃跑；判定失败→继续战斗，后续可再次判定
- **灰烬兽不会逃跑**

#### 逃跑意愿增加

| 条件 | 增加 | 说明 |
|:----|:----:|------|
| 敌方数量少于一半 | +30 | 单次触发 |
| 自身血量低于 50% | +20 | 单次触发 |
| 自身血量低于 30% | +30 | 单次触发 |
| 队友被击杀 | +10 | 每死一个队友触发一次 |
| 精英被击杀 | +30 | 精英死亡时触发 |
| Boss 被击杀 | +50 | Boss 死亡时触发 |
| 野兽初始倾向 | +20 | 野兽天生容易逃跑 |
| 野兽每回合自然累计 | +5/回合 | 仅野兽 |
| 强盗抢到货物 | **+100** | 直接满，立刻准备逃跑 |

> 逃跑意愿**只增不减**。没有减少逃跑意愿的手段。

#### 判定成功率

| 项目 | 数值 |
|:----|:----:|
| 基础成功率 | **50%** |
| 迟滞修正 | 每层迟滞增加行动失败概率（对所有行动生效，逃跑也受迟滞影响） |

#### 逃跑结果

| 结果 | 说明 |
|:----|------|
| 判定成功 | 敌人逃跑，离开战斗 |
| 判定失败 | 敌人继续战斗，后续可再次判定 |

### 8.2 地图撤退

地图撤退分为三种情况：

#### ① 主动撤退
玩家在大地图上主动选择撤退：

| 项目 | 规则 |
|:----|:----|
| 触发方式 | 玩家主动选择撤退 |
| 士气变化 | **-2** |
| 货物损失 | **25%** |
| 撤离目标 | 最近的安全点（城市/城镇/驿站） |

#### ② 士气崩溃撤退

| 项目 | 规则 |
|:----|:----|
| 触发条件 | **士气归 0** 时自动触发 |
| 士气变化 | 士气已为 0，不额外扣除。到达安全点后**恢复到 1** |
| 货物损失 | **50%** |
| 撤离目标 | 最近的安全点（城市/城镇/驿站） |

#### ③ 全员重伤 + 商队耐久归零（强制撤退）

## 0. 总定位

第 5 类由五个子模块组成：

| 模块 | 名称 | 作用 |
|:---:|------|------|
| 5.1 | 天气系统 | 决定当前天气段与天气对远行、事件、战斗、货物、内部压力的影响 |
| 5.2 | 外部事件系统 | 决定玩家在野外格子上遇到什么外部世界事件 |
| 5.3 | 内部事件系统 | 决定商队内部是否因压力爆发争执、抱怨、恐惧、互助等事件 |
| 5.4 | 事件冷却系统 | 对刚发生过的同类事件降权，避免重复刷屏 |
| 5.5 | 时间结算系统 | 统一处理走格、停留、绕路、搜索、修理、休整、撤退等时间口径 |

### 运行顺序

1. 玩家走 1 格，基础时间 +1 天
2. 根据当前天气段，应用当天有效天气
3. 根据当前自然区域，判断是否发生外部强事件
4. 若发生强事件，从 E1-E13 事件池抽取（去除 E5/E8），先应用冷却降权
5. 事件发生后，按时间规则和资源结算规则落账
6. 外部事件写入压力标签，供内部事件系统使用
7. 若商队压力达到检查条件，再判断内部事件
8. 内部事件同样写入同类型降权

> 核心口径：天气不是随机惩罚，而是远行决策系统。路上经常有事，但不是经常打架，也不是经常白捡资源。

## 1. 时间结算系统（5.5）

### 1.1 基础规则

- **走 1 格 = 1 天**
- 事件要么不额外加天数，要么额外 +1 天 / +整数天
- 不存在 0.5 天、半天、小数天
- "正常移动 +1 天"是基础移动时间，不是事件额外时间
- 事件里写"+1 天"，意思是在走这一格已经消耗 1 天的基础上，额外再增加 1 天

### 1.2 行为时间消耗

| 行为 | 时间消耗 | 说明 |
|:----|:--------:|------|
| 正常移动 1 格 | 1 天 | 基础移动 |
| 快速查看 / 简单交谈 / 快速处理 | 不额外消耗 | 事件本身不延长时间 |
| 停留采集 / 深入搜索 / 仔细侦察 | 额外 +1 天 | 在当前格多停留一天 |
| 绕路（棋盘上主动选择） | 后续路线变长 | 玩家在地图上规划路线时选更长但更安全的路径 |
| 走近路（棋盘上主动选择） | 后续路线变短 | 玩家选更短但风险更高的路径 |
| 强行通过 | 当前格结算风险 | 如车损、货损、遇敌 |
| 扎营 | 1 天 | 双倍补给（仅首日） |
| 等待（城市/城镇/驿站/村庄） | 1 天/次 | 消耗补给和天数，安全点内等待 |

> 绕路和走近路有两种形式：一种是在棋盘地图上玩家主动规划的路线选择；另一种是通过 E10 路线判断事件触发的临时路线选择。

## 2. 天气系统（5.1）

### 2.1 天气段规则

天气不再按"每走一格重新随机一个天气"处理，而是按**天气段**生成。

**生成流程：**
1. 当前天气段剩余天数每天 -1
2. 若剩余天数 > 0，继续使用当前天气
3. 若剩余天数为 0，按天气基础概率抽取下一段天气
4. 根据抽到的天气类别，生成持续天数
5. 写入当前天气和剩余天数
6. 每天按当前天气结算补给、货物、战斗、外部事件权重、内部事件压力等

**天气段持续时间：**
| 天气类别 | 包含天气 | 持续时间 |
|:--------|---------|:--------:|
| 普通天气 | 晴朗、阴天 | 5-7 天 |
| 特殊天气 | 小雨、暴雨、高温、酷热、寒潮、严寒、浓雾、重雾 | 3-6 天 |
| 灰烬风 | 灰烬风 | 4-5 天 |
| 灰烬风暴 | 灰烬风暴 | 2-3 天 |

### 2.2 基础天气概率

| 天气 | 基础概率 | 恶劣天气 | 大类 | 定位 |
|:----|:-------:|:--------:|:----|------|
| **晴朗** | 0.34 | 否 | 正常天气 | 稳定赶路 |
| **阴天** | 0.34 | 否 | 正常天气 | 轻微不安 |
| **小雨** | 0.05 | 否 | 下雨类 | 火焰削弱、防潮压力、雨水收益 |
| **暴雨** | 0.03 | **是** | 下雨类 | 更强雨天效果 |
| **高温** | 0.05 | 否 | 高温类 | 补给压力、水源价值提高 |
| **酷热** | 0.02 | **是** | 高温类 | 更强补给压力 |
| **寒潮** | 0.05 | 否 | 低温类 | 低温事件、野兽迟滞 |

## 5. 内部事件系统（5.3）

### 4.1 核心原则

- 内部事件不是每日随机骚扰
- 只有商队出现明显压力时才检查概率
- 状态好时概率可为 0%
- 内部事件必须有解决手段（花补给、花时间、花零件、改路线等）

### 4.2 不触发的情况

正常状态普通移动不触发。士气 5-7、补给够、车况好、无重伤时不触发。

### 4.3 触发条件

| 情况 | 是否检查内部事件 |
|:----|:--------------:|
| 士气 ≤ 4 | ✅ |
| 补给不足到下个安全点 | ✅ |
| 补给为 0 | ✅ |
| 零件为 0 | ✅ |
| 车况低/抛锚 | ✅ |
| 有重伤员 | ✅ |
| 恶劣天气后 | ✅ |
| 灰烬污染扩散 | ✅ |
| 货损严重 | ✅ |

### 4.4 概率公式

```
内部事件概率 = 
  士气修正 + 补给修正 + 零件修正 + 车况修正 
  + 重伤修正 + 天气修正 + 灰烬污染修正 
  + 订单/货损修正 + 扎营修正 - 安全缓冲
```

- 最低 0%，最高 100%
- 安全缓冲最多抵消 40%

## 6. 事件冷却系统（5.4）

### 6.1 核心原则

- 所有事件冷却都是**降权冷却**，不采用强制禁止的硬冷却
- 冷却中的事件保留在池中，只是权重乘以保留比例
- 冷却不制造绝对安全窗口，只降低重复概率
- 内部事件不设总冷却，只做同类型降权（商队崩溃时可连续触发）

### 6.2 外部事件降权冷却总表

## 5. 记忆系统

### 5.1 基本规则

- 本游戏**没有"技能"这个名词**，统一称为**记忆**
- 记忆是旧文明技术，**完整获得**，要么获得完整记忆，要么不获得
- **不做记忆碎片**、技能碎片、熟练度
- 记忆分为四类：**攻击、防御、辅助、消耗**

### 5.2 出战记忆位

| 阶段 | 可出战记忆位数量 |
|:----|:--------------:|
| 初始 | **8 个** |
| 后期 | 可成长到 **15 个** |

### 5.3 0费记忆规则（已定）

| 项目 | 规则 |
|:----|:------|
| 携带量 | **0费记忆不限量、不占出战记忆位**（可任意携带） |
| 效果限制 | **必须很弱**——只能做简单铺垫（如给目标挂 1 层标记等） |
| 禁止效果 | 不能抽牌、不能直接造成伤害、不能挂强力负面（灼烧、强迟滞等） |

> 原因：如果 0 费记忆不限量还能抽牌/打伤害/挂强负面，玩家会无脑堆 0 费技能破坏平衡。弱效果+不限量=免费铺垫但不破坏平衡。

### 5.4 记忆强化

| 方式 | 说明 |
|:----|------|
| **金币升级（数值升级）** | 提升记忆的基础数值。依赖城市/城镇设施，不做野外随地升级 |
| **金币升级（状态升级）** | 提升状态层数、强度等。比数值升级更贵 |
| **火种升级** | 稀有资源，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机 |
| **记忆融合** | 多个记忆融合成新复合记忆 |

## 6. 记忆升级价格

记忆成长主要依赖城镇/城市设施，不做野外随地升级。

### 6.1 数值升级

提升伤害、护盾、治疗、修车等基础数值。

**公式：第 N 次数值升级价格 = 300 + 20 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 300 金 |
| 第 2 次 | 320 金 |
| 第 3 次 | 340 金 |
| 第 10 次 | 480 金 |
| 第 20 次 | 680 金 |

> 不用乘法增长，避免后期升不动。

### 6.2 状态升级

提升标记层数、流血层数、正面状态层数/强度等。

**公式：第 N 次状态升级价格 = 1000 + 200 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 1000 金 |
| 第 2 次 | 1200 金 |
| 第 3 次 | 1400 金 |
| 第 5 次 | 1800 金 |
| 第 10 次 | 2800 金 |

> 状态升级比数值升级贵，因为状态升级通常强于单纯 +1 数值。

### 6.3 火种升级

火种升级独立于普通等级，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机。

| 作用 | 示例 |
|:----|:----|
| 添加词条 | 射箭【重击】 |
| 添加特殊效果 | 射箭【穿甲】 |
| 改变方向 | 治疗箭、车厢盾架 |
| 解锁特殊处理 | 治疗【净毒】、车体修理【加固】 |

### 6.4 记忆融合规则

**设计定位：单一记忆效果有限，融合后 1+1>2——这是玩家打造强力复合记忆的核心途径。**

记忆融合**不设主记忆/副记忆**。多个记忆可以融合成新复合记忆。

**融合继承规则：**
```
新记忆数值升级点 = 参与融合记忆中最高的数值升级点
新记忆状态升级点 = 参与融合记忆中最高的状态升级点
新记忆普通总等级 = 新记忆数值升级点 + 新记忆状态升级点
```

融合后，新记忆允许玩家在新记忆可用升级项中**重新分配**继承来的升级点。

**融合示例：射击 + 标记 → 精确射击**

假设：
```
射击：数值升级点 5（伤害累积提升）
标记：状态升级点 1（标记从 1 层变 2 层）
```

融合 → 精确射击：
```
数值升级点：5（继承射击）
状态升级点：1（继承标记）
普通总等级：6
```

效果：造成伤害，并施加 2 层标记。

> 高等级伤害记忆不会因为融合被清零；已经升级过的状态记忆也不会浪费。

### 6.5 火种词条融合

火种词条融合时原则上尽量保留，但必须通过新记忆词条池检查。

## 7. 重伤系统

### 7.1 基本规则

| 项目 | 规则 |
|:----|:----|
| 生命归零 | 角色退出当前战斗，进入重伤状态 |
| 重伤后 | 该角色不再抽牌，不再使用专属牌 |
| 休养期间 | **不能上场** |
| 战斗终止 | 所有出战队员均重伤退出 + 货车耐久归零，才触发战斗终止 |

### 7.2 重伤分级

| 重伤次数 | 效果 | 恢复时间 |
|:-------:|:----|:--------:|
| 第一次重伤 | 最大生命 -20%，恢复到当前最大生命的 20%（向上取整） | 休养 3 天 |
| 第二次重伤 | 累计最大生命 -50%，恢复到当前最大生命的 20%（向上取整） | 休养 4 天 |
| 第三次重伤（失能） | 不能上场，必须到城市治疗或替换 | 城市治疗 |

> 正常游玩不做永久死亡、不做永久伤残、不做不可逆惩罚。

### 7.3 恢复方式

| 方式 | 效果 |
|:----|:----|
| 自然休养 | 每天恢复进度 +1，达到天数后自动恢复 |
| 驿站/城镇 | 可以加速重伤自然恢复，但不能清除重伤次数，也不能恢复最大生命惩罚 |
| 城市治疗 | 可以治疗一次重伤、二次重伤、失能；统一花费 1 天 + 金币 |
| 补给耗尽 | 重伤恢复天数 +1（不恢复反而恶化） |

### 7.4 城市治疗价格

| 状态 | 价格 |
|:----|:----:|
| 第一次重伤 | 200 金币 |
| 第二次重伤 | 350 金币 |
| 失能 | 500 金币 |
| 整队失能恢复上限 | 总成本不超过 500 金币 |

| 照明/警戒槽 | ×2 | 4 格/个 | 探照灯、警戒装置 | 降低伏击率、提高视野 |
| 环境槽 | ×1 | **不占** | 防雨篷、隔热板 | 外部加装，不占车厢空间 |
| 车体结构槽 | ×2 | 6 格/个 | 加固车架、减震器 | 提高结构强度 |

| 战术道具槽 | ×3 | 2 格/个 | 战术道具 | 战斗中使用的战术物品 |

> 同类型/同子类模块互斥。旧时代装备槽消耗火种激发，效果强大但火种稀有。

## 13. 灰烬扩散系统

### 13.1 污染分级

灰烬污染分为三级，从轻度到重度：

| 等级 | 名称 | 说明 |
|:---:|:----|------|
| 1 | **轻度污染** | 货物首次被灰烬污染 |
| 2 | **中度污染** | 被污染货物再次扩散，二次沾染 |
| 3 | **重度污染** | 第三次污染后达到上限，不可再升级 |

### 13.2 扩散规则

- **污染源**向自身周围**一圈**扩散（相邻的货物格子）
- 被污染的货物也会变成新的污染源，继续向周围扩散
- **被污染次数叠加**：第一次污染→轻度，第二次→中度，第三次→重度

#### 扩散周期

| 天气 | 扩散周期 | 说明 |
|:----|:--------:|------|
| 正常天气 | 每 3 天 | 标准扩散速度 |
| 灰烬风 | 每 2 天 | 加速扩散 |
| 灰烬风暴 | **每天** | 最快扩散 |

### 13.3 清除方式

清除按污染等级计费：轻度污染算 **1 倍**，中度算 **2 倍**，重度算 **3 倍**。

| 地点 | 可清除等级 | 参考价格（基数） | 说明 |
|:----|:---------|:--------------:|------|
| **城市** | 轻/中/重度 | **40 金/倍** | 最便宜，但路程远，适合集中处理 |
| **驿站** | 轻/中/重度 | **60 金/倍** | 应急清除，价格适中 |
| **城镇** | 轻/中/重度 | **70 金/倍** | 最贵，应急使用 |

**示例：**
```
一件重度污染货物（3倍）：
  城市清除：40 × 3 = 120 金
  驿站清除：60 × 3 = 180 金
  城镇清除：70 × 3 = 210 金
```

**示例：**
```
一件重度污染货物（3格）在城市净化：30 × 3 = 90 金
同一件在驿站：50 × 3 = 150 金（但驿站不能净化重度）
同一件在城镇：80 × 3 = 240 金（但城镇不能净化重度）
```

### 13.4 阻断扩散

| 方式 | 效果 |
|:----|:------|
| **灰烬封存箱** | 放入其中的货物不会向外扩散污染，也不会被外部污染沾染 |
| **隔离存放** | 将灰烬货物与其他货物分开存放，降低扩散风险 |
| **天气保护** | 灰烬风/灰烬风暴期间加速扩散，应尽快处理污染源 |

| 内容 | 说明 |
|:----|:-----|
| 死亡系统 | 角色不会永久死亡 |
| 永久伤残 | 不做永久不可逆惩罚 |
| 经验值/熟练度 | 不做普通 RPG 成长 |
| 记忆碎片 | 记忆完整获得，不做碎片 |
| 临时雇员 | 不做短期雇佣 |
| 单车独立装备 | 商队统一结算 |
| 装备耐久 | 不做装备损耗 |
| 随机词条 | 不做装备随机属性 |
| 传统品质等级 | 不做白绿蓝紫品质 |
| 重伤觉醒 | 不做重伤后获得特殊能力 |

## 14. 角色成长·装备驱动

角色不通过经验值或金币直接升级属性。角色的成长通过**装备驱动**实现。

### 13.1 核心理念

- 角色基础数值（生命值、攻击力等）**固定不变**
- 角色的变强主要依靠**更好的装备**和**更强的记忆**
- 每件装备都有自己的特点，**不存在某把武器是另一把的完全上位替代**

### 13.2 武器系统

| 项目 | 规则 |
|:----|:-----|
| 武器定位 | 每把武器有**独特特点**，初始数值相近 |
| 上位替代 | **不存在**——不会有某把武器完全碾压另一把 |
| 攻速设定 | **不存在**——回合制游戏不设攻速概念 |
| 记忆加成 | 武器对特定类型的记忆有加成。例如重锤对【重击】类记忆伤害+15%，让玩家使用与自己的记忆匹配的武器 |
| 强化方式 | 消耗**灰烬材料 + 火种 + 金币**进行强化 |
| 强化效果 | 提升武器数值，但不改变武器核心特点 |

**示例：**
```
武器 A（弓）：基础伤害 10，对【精确射击】记忆 +15% 伤害
武器 B（重锤）：基础伤害 10，对【重击】记忆 +15% 伤害
→ 两者基础数值相近，但加成方向不同
→ 都可用材料+火种+金币强化
```

### 13.3 护甲系统

同理，护甲也没有上位替代：

| 项目 | 规则 |
|:----|:-----|
| 护甲定位 | 每件护甲有不同侧重（高护甲低抗性、均衡型、轻甲等） |
| 上位替代 | **不存在** |
| 强化方式 | 同武器系统：灰烬材料 + 火种 + 金币 |
| 强化效果 | 提升护甲数值，但不改变核心特点 |

### 13.4 装备分类与价格

装备分为两类，**不存在品质等级（普通/精良/特殊）的区分**，只有装备本身的差异：

| 类型 | 说明 | 参考价格 | 获取方式 |
|:----|:-----|:--------:|:--------|
| **普通装备** | 当代工艺制造的武器和护甲，各有不同特点 | **约 2,000 金** | 城市购买 |
| **旧时代装备** | 旧文明遗留的高科技装备，效果更强 | **约 6,000 金** | 遗迹探索，**出现概率低**。更稀有的可达 **7,000~8,000 金** |

> 旧时代装备不是普通装备的上位替代，只是效果方向不同。两者都可用灰烬材料 + 火种 + 金币强化。

## 一、总定位

灰兽潮是**定期定时的大事件**，不是随机事件，也不是天气事件。它覆盖**整个大地图**——无论玩家在哪个区域，都会受到兽潮影响。

### 1.1 对比

| 对比项 | 普通事件/战斗 | 灰兽潮 |
|:------|:------------|:------:|
| 性质 | 随机/局部 | 定期定时，全地图 |
| 频率 | 频繁 | **极其罕见** |
| 间隔 | 随时 | **约 200 天一次** |
| 整个游戏经历次数 | — | **不超过 10 次** |
| 严重程度 | 可控 | **极为严重**——无法在野外单独对抗 |
| 野外战斗 | 常规 | **基本不可能扛过去**，必须进入城市/驿站防御 |
| 玩家感受 | 日常跑商的一部分 | **需要专门准备的重大事件** |

### 1.2 设计目的

- 给玩家提供明确的**长期目标**——每一次兽潮都是一次"大考"
- 驱动玩家变强——如果商队实力不够，兽潮来临时只能躲进城市，拿不到守城奖励
- 制造世界危机的真实感——让玩家感受到灰潮和灰烬兽对世界的持续威胁

## 二、预兆与倒计时

### 2.1 倒计时

玩家**始终可以看到**距离下次兽潮还有多少天的倒计时，显示在界面的固定位置。

> 示例：距下次灰兽潮：187 天

### 2.2 预警阶段

| 时间点 | 提示 | 表现 |
|:------|:----|:------|
| 持续显示 | "距下次灰兽潮：XX 天" | 界面固定显示 |
| 前 30 天 | **强预警** | 系统明确提示"灰兽潮预计在 30 天后到来，建议靠近城市"。天气开始出现异变征兆 |
| 前 15 天 | 精确预警 | 天气异变明显——天色持续发灰、风沙加剧、远处有低沉的声响。沿途驿站开始发出警告，灰烬兽活动显著增多 |
| 前 7 天 | 紧急状态 | 城市/驿站进入戒备状态，城门加固，守卫加倍。灰烬风暴开始酝酿 |
| 前 2 天 | **灰烬风暴爆发** | 灰烬风暴提前 2 天到达，持续到兽潮当天，然后继续持续 2 天——总共 **5 天灰烬风暴** |

### 2.3 预警期间玩家可做的事

玩家在预警期间（尤其是前 30 天）可以：

| 行动 | 说明 |
|:----|:------|
| **前往城市** | 城市是兽潮期间最安全的地方，防御最强 |
| **建立防御工事** | 在城市中消耗零件和金币加固城墙、准备防御设施 |
| **补充物资** | 准备药包（约 20 个）、零件（约 10 个）、补给 |
| **接守城任务** | 城市可能发布临时守城任务，完成后有额外奖励 |
| **提前规划路线** | 确保兽潮来临时自己位于安全点内 |

## 三、灰烬风暴与兽潮的关联

灰兽潮到来前后会伴随**灰烬风暴**，形成连续的极端天气周期：

| 阶段 | 时间 | 天气 | 说明 |
|:----|:---:|:----|:------|
| 兽潮前 | 2 天 | **灰烬风暴** | 风暴提前到达，灰烬兽活动开始剧增 |
| **兽潮当天** | 1 天 | **灰兽潮** | 大量灰烬兽攻城，风暴达到顶峰 |
| 兽潮后 | 2 天 | **灰烬风暴** | 风暴逐渐消退，但灰烬污染扩散加快 |
| **合计** | **5 天** | **极端天气期** | 玩家应全程待在安全点内 |

> 灰烬风暴期间的加速扩散效果见第 5A 类。兽潮本身消耗 1 天，但前后共 5 天处于极端天气中。

## 四、强度分级

按回合数衡量强度，分为五级：

| 等级 | 名称 | 总回合数 | 敌人数量 | 相当于 |
|:---:|:----|:--------:|:--------:|:------|
| 1 | 小规模 | **20 回合以上** | 较少 | 相当于较弱的 Boss |
| 2 | 较小规模 | 25~30 回合 | 中等 | 相当于中等 Boss |
| 3 | **中规模** | **40 回合以上** | 较多 | **相当于较强的 Boss** |

## 六、战斗规则

### 6.1 野外遭遇

- 在野外遭遇兽潮时**基本不可能扛过去**
- **无法逃跑**——兽潮围困，没有撤退路线
- 玩家应尽可能在预警期间进入安全点
- 如果被迫在野外迎战，目标是**坚持到兽潮结束**而不是击败全部敌人

### 6.2 守城战

在城市/驿站/城镇内可以触发守城战，不同地点的防御强度不同：

| 地点 | 防御强度 | 面对敌人比例 | 说明 |
|:----|:-------:|:-----------:|------|
| **城市** | 最强 | **野外的 30%** | 最安全，有正规守卫和坚固城墙 |
| **驿站** | 中等 | **野外的 50%** | 有少量守卫，能提供基本保护 |
| **城镇** | 中等 | **野外的 50%** | 民兵守卫，与驿站同级 |
| **临时避难**（山洞/废弃建筑） | 较弱 | **野外的 75%** | 利用事件接口发现临时避难点。需要前置条件（侦察成功、发现旧营地等）。比露天好，但不如驿站安全 |

> 临时避难对应角色能力槽的事件接口（如荒野射手的看懂痕迹、护路人的挡在前面），在野外找到可避难点后可降低遭遇的敌人数量至 75%。

**守城战规则：**

| 项目 | 规则 |
|:----|:------|
| 战斗方式 | 仍为分配敌人的战斗机制，但敌人**弱很多**（有城墙和守卫分担） |
| 出战 | **所有队员都会出战** |
| 波次间隔 | 每波之后有 **3 回合**喘息时间，可治疗和修车 |
| 无法逃跑 | 守城战也无法逃跑 |
| 失败条件 | 所有队员重伤退出 + 商队耐久归零 |
| 失败结果 | 强制撤退到该安全点内，损失部分货物，但不会灭队 |

### 6.3 防御工事

玩家可在预警期间（前 30 天）在城市中建立防御工事：

| 工事类型 | 消耗 | 效果 |
|:--------|:----|:------|
| **城墙加固** | 零件 5 个 + 500 金 | 降低兽潮对商队耐久的伤害约 20% |
| **陷阱布置** | 零件 3 个 + 300 金 | 第一波敌人额外损失 10% 血量 |
| **补给储备** | 500 金 | 确保守城期间补给充足 |
| **全面防御** | 零件 10 个 + 药包 20 个 + 1,000 金 | 城墙加固 + 陷阱布置 + 补给储备 |

## 城市联通关系

**九城时代后商路稀疏，但旧文明时代网络更密。玩家激活节点、打通商路后，城市间的实际通路如下：**

```
         枯林 ── 海盐
        /  |      |  \
     灰原   |      |   粮野
        \  |      |  /   |
         鱼水 ── 火油 ── 药泽
                  |      |  \
                  |      |   黑石
                粮野 ── 黑石 ── 灰烬
```

| 城市 | 可直达 |
|:----|:-------|
| 灰原城 | 枯林城、鱼水城 |
| 枯林城 | 灰原城、鱼水城、海盐城 |
| 鱼水城 | 灰原城、枯林城、火油城、粮野城 |
| 粮野城 | 鱼水城、火油城、药泽城、黑石城 |
| 海盐城 | 枯林城、火油城、粮野城 |
| 火油城 | 鱼水城、海盐城、粮野城、药泽城 |
| 药泽城 | 粮野城、火油城、黑石城 |
| 黑石城 | 粮野城、药泽城、灰烬城 |
| 灰烬城 | **黑石城** |

> **灰烬城只连黑石城**——它上面（北边）就是黑石城。
> 药泽城西边连着火油城。
> **隐藏路**：灰烬城其实还有其他旧道（如通往药泽/火油方向），但这些是**隐藏路**——一般玩家不会发现，接了特定支线或特殊任务后才可能出现路的提示；不过玩家直接走过去也是有的（探索发现）。

## 二、遗迹分布规律（已定）

**越靠近灰烬城，遗迹越多、越大、越危险。**

世界观依据：灰烬城建在旧文明旧都遗址上，是旧文明的核心区域。越靠近旧都，旧文明设施越密集。

| 区域 | 遗迹密度 | 遗迹等级 |
|:-----|:--------:|:---------|
| 灰原城周边（起点） | 稀疏 | 小型为主 |
| 中部区域 | 中等 | 中/小型 |
| 黑石城附近 | 较密 | 中/大型 |
| 灰烬城周边（旧都遗址） | **最密** | 大型/巨型为主 |

## 三、空间维度

| 维度 | 说明 | 入口方式 |
|:----|:------|:---------|
| **地面遗迹** | 直接暴露在地表 | 到达即进 |
| **地下遗迹** | 埋在地下（防空洞、地下城、掩体） | 需要特殊渠道/钥匙/任务解锁 |
| **高险遗迹** | 建在悬崖/高山顶，因能源丧失已坠落，但地形险要 | 需要升降装置等特殊渠道才能上去 |

> 高险遗迹世界观：旧文明浮空/高空设施因能源丧失大量坠落，但坠落位置地形险要，需要升降梯等旧装置才能到达。

## 六、探索机制（同常规地图）

**遗迹探索和常规大地图探索一样：**
- 消耗：与常规移动相同（时间+补给）
- 形式：在遗迹范围内移动探索
- 事件概率调整：
  - 常规随机事件概率**大幅降低**
  - 战斗随机事件概率**大幅提升**

**战斗配置（已定）：**
- **主体**：旧文明机关、旧文明机器人（遗迹守卫）
- **辅助**：灰烬兽、普通野兽（被吸引进遗迹的）
- **没有强盗**——强盗不会进遗迹

**战斗强度：**
- 比遗迹外正常跑商战斗**强约 25%**
- 数量更多、更密集

**撤离：** 可中途撤离，已消耗的时间和补给不返还。

# 第10类：订单与贸易系统设计方案 v2
> ⚠️ **数值参考声明**：本文件的**所有数值均为参考值**（数值系统待重调）。设计规则有效，具体数字可能调整。

---

## 一、订单类型

**订单分两类维度：类型 + 发起人。**

### 1.1 订单类型（4大类）

| 类型 | 内容 | 时效 | 失败条件 |
|:-----|:-----|:----:|:---------|
| **送货订单** | 把货物运到指定收货地 | 有期限 | 严重超时→失败 |
| **护送订单** | 护送某人/某物到指定城市 | 有期限 | 严重超时→失败 |
| **收购订单** | 高价收购指定物品（城市/个人） | **无期限** | 无——交货就给钱 |
| **悬赏订单** | 击杀指定敌人/Boss | 无期限 | 无 |

> 收购订单来源多样：城市缺货、商人收购、个人求购都行。玩家把要求的货物交过去就结算。

### 1.2 发起人（订单的来源身份）

| 发起人 | 说明 |
|:-------|:------|
| 市场/交易所 | 各城常规订单 |
| 商会 | 专属订单（需要声望等级） |
| 悬赏板 | 击杀悬赏（初始开放） |
| **领主/城主** | 城市重建需求——**就是领主发起的送货/收购订单**（建设订单不单独成类） |
| 个人NPC | 个人求购（高价收购） |
| 酒馆 | 打听来的特殊订单 |

> **建设订单 = 领主发起人的送货/收购订单。** 城市要修建筑，领主发订单收购材料（收购类）或要求运材料过去（送货类）。本质上和普通订单一样，只是发起人不同，奖励可能更丰厚（图纸等）。

### 1.3 订单接取规则（已定）

| 订单类型 | 需要接取？ | 说明 |
|:---------|:----------:|:------|
| **送货订单** | ✅ 需要接取 | 接取后开始计时 |
| **护送订单** | ✅ 需要接取 | 接取后开始计时 |
| **收购订单** | ❌ **不用接取** | 玩家有货直接交，当场结算 |
| **悬赏订单** | ❌ **不用接取** | 玩家击杀目标，拿凭证（目标身上物品）给发布人看，领奖励 |

> **收购/悬赏不接取**：玩家可能完全不知情地杀了悬赏目标，或顺手带着要收购的货，到了城市直接交付/出示凭证就能拿奖励。世界更活，不用专门跑一趟接任务。

### 1.4 订单失效规则（世界会动）

**收购/悬赏订单有随机时限**——既然有人高价收购、有人悬赏，就会有其他人去完成：

| 项目 | 规则 |
|:-----|:------|
| 时限 | 随机（不固定） |
| 其他NPC完成 | 订单会**消失**（被别的商队/赏金猎人完成了） |
| 玩家感受 | 好订单要抓紧，晚了可能没了 |

> 送货/护送订单在玩家接取后有期限，不接取则一直存在（刷新机制待定）。

### 1.5 订单失败规则（已定）

- 只有**有期限的订单**（送货/护送）才会因**严重超时**失败
- **货物被毁不算订单失败**（只损失货物本身）
- 收购/悬赏订单无接取，不存在失败，只有可能被其他人完成而消失

## 一、成员结构（已定）

**两大类：**

| 大类 | 细分类 | 说明 |
|:-----|:-------|:-----|
| **基础人员** | 帮工（车夫、杂役） | **必须带够数量**，无特殊效果，价格差不多 |
| **护卫** | 战斗人员 | 可选，能出战，贵 |
| **（无统称的特殊人员）** | 厨师、账房、修车匠等 | 可选，各有特殊效果，**直接叫具体职业，没有统称** |

### 基础人员（帮工：车夫/杂役）

| 项目 | 规则 |
|:-----|:------|
| 特殊效果 | **没有任何特殊效果**（不给加成） |
| 价格 | 帮工之间价格差不多（便宜） |
| 必须带够 | 每次商队出发，按车辆数量/人数**必须带够一定量** |
| 不够的惩罚 | **严重负面惩罚**（具体后定） |

**车夫（硬性）：** 商队有几辆车，就要配几个车夫——否则车辆无法行驶。

**后勤/杂役（硬性）：** 商队里有多少人（**不包括后勤人员自己**），就需要多少个后勤人员。
- 例：商队有3个车夫+2个战斗人员=5人需要服务，就要配5个后勤
- **后勤不足 → 补给消耗翻倍**（食物翻倍、水翻倍、饲料也翻倍）
- 数值为参考（后调）

### 护卫（战斗人员）

| 类型 | 说明 |
|:-----|:------|
| **护卫** | 像初始3人一样，能出战（出战规则见第4A类：无上限，日薪2倍+） |

| 项目 | 规则 |

| 命名 | **没有统称**——直接叫具体职业：厨师、账房、修车匠、兽医等 |
| 效果 | 每个职业提供一种固定被动效果（如厨师：每隔几天给商队+1士气） |
| 招募 | 可选，贵于帮工 |

## 一、水容器系统

水必须用容器装。**容器本身占格固定，不管里面还剩多少水。**

| 容器 | 占格 | 满水容量 | 够3人喝 | 单位效率 |
|:----|:----:|:--------:|:--------:|:--------:|
| **小水袋** | 1格 | 2份 | 不足1天 | 2份/格 |
| **中水桶** | 4格 | 6份 | 2天 | 1.5份/格 |
| **大水桶** | 9格 | 16份 | 约5.3天 | 1.78份/格 |

规则：
- 容器不管装满还是只剩1份水，都占同样格数
- 买水时：可以买容器+水，也可以只买水装进已有的容器里
- 容器本身可重复使用，不会消耗

## 二、食物
