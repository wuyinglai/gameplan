> 一款「商队经营 + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件」的游戏。

## 🔴 三条铁律

**① 设定只认 `0A_权威系统文档/`。**

`90_历史与废案/` 里的**任何内容都不是现行设定**。

> 🔴 **特别警告**：归档里有两个目录名字骗人 ——
> **`04_旧权威口径_已过期`** 和 **`05_游戏设计定稿_已过期`**。
> 它们叫"当前权威"和"定稿"，但内容**全部过期**（我核查过：`游戏设计定稿.md` 里的撤退条件还是「全队倒下+耐久归0」）。
> **别被名字骗了。**

**② 数值只有一个家。**

`0A §0.1`（锚）· `01_Demo计划/23_数值推导规则`（公式）· `24_数值执行器`（执行）
—— **改数只改这三处**，别处一律不写死数字。

**③ 写任何东西之前，先查已有文件。**

不许凭空编。**「我是写过的，你去查文件」** —— ��部分"想不起来"的东西其实都写在某一处。
