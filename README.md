> **`04_旧权威口径_已过期`** 和 **`05_游戏设计定稿_已过期`**。
> 它们叫"当前权威"和"定稿"，但内容**全部过期**。
> **别被名字骗了。**

**② 数值只有一个家。**

`04 §0.1`（锚）· `23 数值推导规则`（公式）· `24_数值计算器.html`（执行）
—— **改数只改这三处**，别处一律不写死数字。

**③ 写任何东西之前，先查已有文件。**

不许凭空编。**「我是写过的，你去查文件」** —— 大部分"想不起来"的东西其实都写在某一处。
