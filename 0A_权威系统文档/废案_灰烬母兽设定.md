# 【废案】灰烬母兽设定

> **状态：已废止（2026-09-07 重做世界观时正式废止）**
> 本文档仅作历史记录与追溯，**不代表现行权威设定**。现行灰烬生态权威见《第7A类_世界观与设定_权威口径.md》。

---

## 一、原设定摘要（已废止，勿用）

灰烬母兽是早期版本的核心悬念与最终 Boss 设定，要点如下：

- **起源**：旧文明生物技术失控产物——被设计成"能适应任何极端环境的巨型生物工具"，用于高辐射矿区、地下深渊、灰烬裂谷作业；具备吸收/转化能量、超强自愈、可作移动能源中继。
- **反抗**：在长期作业中发展出自我意识，旧文明试图植入最终安全控制协议时反抗、挣脱控制。
- **灰潮**：母兽将自身能量反向释放，转化为具有侵蚀性、传播性的污染物质——**灰潮被设定为"母兽制造的"**，不是自然现象。
- **沉睡**：旧文明倾力压制，母兽被重创、陷入深度沉睡于**烬渊山**地底（一座超巨型矿山遗迹内部），持续向外渗漏灰烬能量。
- **与玩家关系**：玩家激活节点恢复能源网络，"网络恢复的尽头是唤醒母兽"；激活节点可能惊醒它。
- **灰烬教团 / 灰渊信徒**：崇拜母兽的狂热组织，认为灰潮是"净化"，人数极少但极危险。
- **原生灰烬兽溯源**：设定"所有原生型灰烬兽由母兽散逸能量凝聚而成"的碎片生物说。
- **结局绑定**：4 结局（灰烬止息 / 吞噬 / 时间 / 共生）围绕"去不去烬渊山、如何对待母兽"展开；母兽为最终 Boss。

## 二、废止原因

2026-09-07 重做世界观，确定以下方向，使母兽设定不再成立：

1. **灰烬本质重做**：灰烬 = 大陆自古自然生态（如沼泽 / 沙漠）+ 旧文明清除实验的后遗症；不再是某个生物造物，"灰潮由母兽制造"的悬念被移除。
2. **成长驱动重做**：从"不变强就死"的恐惧，改为"想进高灰区淘好货"的向往；母兽作为"变强动力核心"的定位被降级。
3. **多主线 + 玩家选择结局**：结局由玩家选择触发，非系统到点发放；不再有"母兽 = 唯一最终 Boss"的强制结构。
4. **世界不逼玩家当英雄**：母兽"沉睡威胁 / 激活惊醒"的叙事压力与"孤旅、非强制主线"基调冲突。
5. **烬渊山仅作地名保留**，不再与母兽关联。

## 三、现行替代设定（权威口径，见第7A类）

- **灰烬生态**：自然生态 + 旧文明实验后遗症；灰度波动是生态活跃度表现，非生物释放。
- **灰潮**：灰烬生态周期性波动（世界底色），无"Boss 释放"叙事。
- **灰兽**：原生灰烬动物（自古演化）+ 被感染变异常兽（旧文明实验后遗症），二者并存；无"母兽碎片生物"溯源说。
- **阵营**：无"灰烬教团 / 灰渊信徒"崇拜母兽的教派；如需极端敌对势力，应另行设计为针对灰烬生态 / 旧文明实验的组织。
- **烬渊山**：仅作地名，与任何生物无关。
