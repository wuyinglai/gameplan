## 7.4 旧文明技术

### 7.4.1 旧文明概述

灰潮之前的旧世界拥有一张庞大的能源和技术网络。灰潮之后，这些技术大多失传或失效，但遗迹中仍有部分留存。旧文明技术并非魔法或超自然力量，而是高度发达但已失去完整知识体系的高科技。

旧文明技术的核心特征：
- **高度集成**：功能复杂但操作简单，多为"接入即用"式设计
- **不可复制**：当前人类无法重新制造，只能从遗迹中回收和修复
- **消耗特殊资源**：多数旧文明设备需要火种或特定条件才能启动
- **效果强大但有限**：不是无限能源，使用有代价

---

### 7.4.2 余烬核心

**定位：** 激活密钥（不是动力源）

余烬核心是旧世界遗留下来的高阶启动核心。它不是普通能源电池，无法一次性点亮整个世界，但可以重新启动旧能源网络中的关键节点。

| 项目 | 内容 |
|:----|:------|
| 性质 | 主线持有物品，不消耗，不属于资源类 |
| 功能 | 插入节点反应炉，激活驿站/城市能源系统 |
| 玩法作用 | 每激活一座驿站就点亮一个永久进度点，解锁驿站功能 |
| 最终目标 | 接入灰烬城主反应炉，恢复城市供电 |
| 初始持有 | **不持有**，在游戏过程中获得 |

> 余烬核心是"钥匙"不是"电池"。它不提供能源，而是授权启动能源系统。没有余烬核心，节点反应炉无法响应。余烬核心不会消耗，不会损坏，始终跟随商队。

---

### 7.4.3 节点反应炉

**定位：** 城市/驿站的核心装置

节点反应炉是每座旧驿站和城市里的核心装置。旧世界时期负责供能并维持通信、导航、防御和回传系统。灰潮之后，大部分节点炉熄灭。

| 项目 | 内容 |
|:----|:------|
| 分布 | 每座城市都有，部分大型驿站也有 |
| 状态 | 灰潮后全部熄灭，等待余烬核心激活 |
| 激活方式 | 将余烬核心接入节点反应炉 |
| 激活效果 | 该节点被永久激活：恢复供能、记录地图、解锁功能 |
| 回传机制 | 已激活的节点之间可通过旧网络快速返回（即"传送"） |

> 节点反应炉不是电池，而是能源中继和控制系统。激活后的节点成为商队在灰潮荒原上的永久坐标。

**主线路线（5座节点）：**
- 黑石驿站 → 锈桥驿站 → 白盐驿站 → 北境中继站 → 灰烬城

### 7.4.4 记忆技术

**定位：** 旧文明战斗协议与经验模板

记忆是旧文明遗留下来的技术、战斗协议、操作经验或意识模板。它可以让角色快速掌握某种强力攻击、防御、辅助或消耗能力。通过记忆释放出来的能力，通常比角色自身普通能力更强。

| 项目 | 内容 |
|:----|:------|
| 性质 | 完整获得，要么获得完整记忆，要么不获得 |
| 分类 | 攻击、防御、辅助、消耗 |
| 获取方式 | 遗迹探索、任务奖励、特殊事件 |
| 使用方式 | 装配到出战记忆位，战斗中作为技能使用 |
| 成长方式 | 金币强化、火种强化、记忆融合 |

> 本游戏中"技能"统一称为"记忆"，记忆即技能，两者是一回事。

---

### 7.4.5 火种

**定位：** 稀有战略资源

火种是旧文明遗留的高密度能源结晶。它不是货币，不用于普通交易，只在旧文明技术相关的场合使用。

| 项目 | 内容 |
|:----|:------|
| 稀有度 | **高**，获取途径有限 |
| 主要用途 | 记忆强化、记忆融合、火种词条、旧时代装备启动 |
| 普通装备 | 不用火种强化 |
| 非碎片 | 火种是完整资源，不做火种碎片 |

> 火种在游戏中的定位类似"特殊燃料"——只有在涉及旧文明技术时才需要消耗它。普通装备、普通升级都不使用火种。它也不是货币。

---

### 7.4.6 旧时代装备

**定位：** 旧文明遗留的高科技物品

旧时代装备是灰潮前的高科技物品，效果比普通装备更强。分为两类：

| 类型 | 说明 | 价格 | 获取方式 |
|:----|:-----|:----|:--------|
| 小型旧时代装备 | 武器、护甲等个人装备 | 约 6,000 金 | 遗迹探索，概率低 |
| 车载旧时代巨物 | 只能装在车上，消耗火种激发 | 需火种启动 | 特殊遗迹/事件 |

**旧时代装备槽（车载）：**
- 占用 1 个商队模块槽 + 视装备大小占用车厢空间
- 通过商队牌 + 火种激发
- 效果极其强大，但消耗火种（稀有资源）
- 适合 Boss 战或绝境翻盘

> 旧时代装备不是普通装备的上位替代，只是效果方向不同。两者都可用灰烬材料 + 火种 + 金币强化。

### 7.4.7 灰潮

| 项目 | 内容 |
|:----|:------|
| 性质 | 灾变本身，不是普通风暴 |
| 表现 | 像灰色的海一样漫过荒原，所到之处能源失效、灯塔熄灭、机械失控、动物狂暴 |
| 后果 | 城市之间的道路和信号被切断，世界慢慢暗下去 |
| 当前状态 | 灰潮仍在继续，但不再是持续不断的爆发状态 |
| 灰潮之后 | 不是官方纪年，是普通人说的"灰潮之后，路就断了" |
