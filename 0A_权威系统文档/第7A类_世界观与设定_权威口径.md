# 第零部分：游戏基调与核心情感

> 本部分定义《余烬商队》的灵魂，是所有系统设计的对齐基准。

## 核心情感：孤旅

玩家**不是来拯救世界的救世主，而是一支在持续衰败却仍有人活着的废土上认真做生意、看风景、偶尔理解灰烬的商队**。

- **悠然 + 末日孤独 + 稀疏的生机**：世界空旷、人烟稀少，但处处有"别人也在活"的痕迹（远处炊烟、别的商队车辙、城里零星的人）。你是孤独的旅人，不是末日唯一幸存者。
- **不刺激、不压迫**：危险是世界底色的"存在感"（远方灰兽的动静），不是"血条见底"的压迫。灰度缓慢波动，玩家从容观测与应对。
- **世界不逼你当英雄**：没有"必须拯救世界"的强制主线。目标由玩家自己定义——连接九城、做生意、探索、理解灰烬，或只是一直跑商。

## 多主线与可选结局

世界不止一条主线。玩家走哪条线，才可能面对那条线的终点挑战（Boss 为可选、非强制、非每条都有、非全局唯一）。结局由玩家的选择与行动触发，而非系统到点发放。

# 第一部分：世界背景

## 一、灰潮之前——旧文明时代

在灰潮之前，存在一个高度发达的旧文明。没有人知道它存在了多久，但它曾遍布整片大陆。

### 旧文明的特点

旧文明不是全面超越现代的那种"完美先进文明"，而是一个**偏科的天才文明**：

**先进的方面：**
- **生物技术**：能够改造和创造生物体，曾用于极端环境生物工程（早期"制造灰烬母兽"设定已废止，见第五部分废案标注）
- **能源技术**：节点反应炉和能源网络覆盖大陆，火种作为高密度能量结晶
- **信息传递**：记忆技术可以直接将知识灌输给使用者，存储在"大书库"中
- **自动化技术**：防御机械、守门机、自动维修系统遍布各地

**脆弱的方面：**
- 技术体系依赖高度集中的能源网络——一旦网络断裂，整个文明都会瘫痪
- 知识高度集中在大型记忆书库中——灰潮中被大量摧毁，知识无法恢复

### 能源网络

旧文明最核心的技术成就是一张覆盖广阔区域的能源网络，由无数座节点反应炉支撑。城市是网络上的大型枢纽，驿站是中继点，矿场、农场、哨站是网络的末梢。只要网络在运转，世界就是亮的。

### 社会与生活

旧文明拥有几十座大型城市，有完整的供能、供水、医疗和防御系统。城市之间有稳定的商路和驿站网络。商队运输货物、传递消息。那时，世界是亮的、连通的、有秩序的。

## 二、灰烬生态与灰烬区的形成（重做）

### 灰烬是一种自然生态

灰烬并非灾变，而是大陆上自古就存在的自然生态类型，如同现实里的沼泽、沙漠、森林——有自己特有的地貌、植被与原生动植物（原生灰兽）。它不针对任何生命，只是"那样存在着"。

### 旧文明的开采与失衡

旧文明在灰烬生态区及周边大肆开采资源，破坏了原有生态的平衡，导致灰烬像土地荒漠化一样从原点向外蔓延，吞没了原本宜居的地带。

### 清除实验与反效果

旧文明后期试图减缓甚至彻底清除灰烬，开展了大量实验。结果适得其反——实验反而造成了**腐蚀性**，并让灰烬获得了**感染正常动物**的能力。中性的灰烬生态被污染成了病态、危险的存在，且蔓延进一步加速。

> 【废案标注】早期设定中"灰烬母兽创造灰潮"（母兽被旧文明制造、反抗、释放灰潮、后被重创沉睡于烬渊山）**已废止**。灰烬的本质是自然生态 + 旧文明实验后遗症，不再是某个生物造物。相关"灰渊信徒崇拜母兽""灰渊兽由母兽能量凝聚"等设定一并作废。烬渊山作为既有地名保留，但不再与母兽关联。

### 走向衰败

灰烬问题从未被根治。虽有抵抗手段，但无效。旧文明因此慢慢枯萎、走向衰败。

### 九城时代与现在：持续的衰败

九城时代继承废墟，同样因灰烬未解，一点一点走向衰败——与旧文明的衰败模式一致。如今（游戏时代）已处于**衰败晚期**：

- 旧文明与九城时代的大多数科技已经丢失；
- 残余技术稀少，且**并非高深**，整体约为中世纪末期水平（黑石城冶炼、火油城烬油提炼相对领先）；
- 文明仍在缓慢熄灭，但人类在灰烬地貌中依旧挣扎存活（如同荒漠、沼泽中也有城市）。

### 玩家的定位（非强制）

玩家的目标可以是连接九城、做生意、探索、理解灰烬，或什么都不做只是一直跑商——**没有"必须拯救世界"的强制主线**。灰烬生态是世界的底色与风险，不是等待被打败的敌人。

## 三、九城时代

### 废墟上的重建

灰潮被压制后，幸存者在废墟上艰难地重建。旧文明的技术大量失传，但残存的技术和材料还在。幸存者们利用这些残片，建起了九座城市——分布在九个自然区域中，各自独立。

九座城市不是旧文明巅峰期的造物，它们建在文明已经衰败之后。但它们是残存的人类能拼尽全力建起来的全部了。

### 九城时代的兴衰

九城时代持续了大约两到三百年。
- 最初，九城之间有联系，商队往来，传递货物、消息和技术残片
- 但衰败是缓慢而不可逆的：科技在继续没落，灰潮时有时无，人口持续减少，技术彻底丢失
- 九座城市之间的联系越来越稀疏，最终断裂了

城市没有毁灭。城墙还在，建筑还在，节点反应炉还在。设施都是完好的——只是没有人会用了。

九城时代就这样在平静中落幕了。不是因为战争或灾难，只是因为衰败到了无法维持联络的程度。

### 现在的世界

九处时代结束后的世界，比九城时代更暗淡。九座城市各自孤立，有的可能还在运转，有的可能已经废弃。没有人知道哪座城市还存在，哪座已经空了。

城镇和驿站是沿途的小型聚居点，灰潮后人们自发建的。如果有人维护、有商队经过，驿站就会被"接入"商路网络。如果没有商队，它就只是路边几间没人住的破房子。

**商队是连接这一切的唯一希望。玩家就是一支商队。**

### 玩家的目标

玩家的目标不是让文明回到旧文明时代的巅峰，那个时代已经永远过去了。玩家**可以选择去做的其中一条主线**是：**让九座城市重新连接起来**——接入沿途驿站的**节点**（信号中继），恢复驿站的功能，打通城市之间的商路，让消息、货物和人在九座城市之间重新流动起来。但这条主线并非强制，玩家完全可以只经营自己的商队、走自己的路；世界不会因你不做这件事而逼你当英雄。

不是恢复一个辉煌的文明，是让这个世界从"正在慢慢熄灭"变成"还能继续维持下去"。

## 九城概况

**灰原城（约2万人）**：位置最靠外的一座，灰褐色的平坦大地。什么都产一点，均衡。联通：枯林城、鱼水城。

**枯林城（约1.5万人）**：灰褐色枯死森林区域。猎人和伐木者聚集。出产木材、皮革、肉食。缺食盐。联通：灰原城、鱼水城、海盐城。

**鱼水城（约3万人）**：河谷区域，有地表水。最重要的水源补给点。出产干净水、鱼类。缺皮革和木材。联通：灰原城、枯林城、火油城。

**粮野城（约1.8万人）**：开阔丘陵草原。粮食和驮畜主要来源。缺食盐和金属工具。联通：火油城、药泽城、黑石城。

**海盐城（约1万人）**：灰黑色海岸线，旧港口遗址。九城唯一的沿海城市，出产最好的食盐。缺木材和草药。联通：枯林城、火油城。

**火油城（约1万人）**：风蚀沙漠，旧文明燃料仓库所在地。产出烬油（节点反应炉核心能源）、拆解零件。极度缺水缺食物。联通：鱼水城、粮野城、海盐城、药泽城。

**药泽城（约1.2万人）**：沼泽湿地，吊脚楼和木栈道连接。出产草药和净水矿物。保存了旧时代的记录。缺食盐和金属。联通：粮野城、火油城、黑石城。

**黑石城（约2.5万人）**：裸露黑色岩层的丘陵，旧文明矿场遗迹。九城的工业中心，锻钢工艺最强。缺粮食和驮畜。联通：粮野城、药泽城、灰烬城。

**灰烬城（约一两千人，半废弃）**：灰白色粉末覆盖一切，灰蒙蒙的天空。曾经是最大的城市之一，大部分居民已撤离。产出高纯度灰烬材料和旧文明科技造物。什么都缺。埋藏着节点反应炉核心数据和旧文明灰烬实验的真相。联通：黑石城。

## 科技水平

如今（游戏时代）处于**衰败晚期**：旧文明与九城时代的大多数科技已经丢失，残余技术稀少且**并非高深**，整体约为中世纪末期水平。黑石城的金属冶炼技术相对领先，火油城的烬油提炼技术最精。文字记录在减少，口口相传是主要的知识传递方式。

# 第三部分：阵营与势力

## 一、余烬商会（可加入）

余烬商会是九城中唯一一个曾在各城设有分部的商业组织。灰潮之后各城分会失去联系，但每个分会都没有解散，在各自城市周边继续运转。

玩家不需要"加入"商会——商队本身就是余烬商会的一部分，是流动的分会。玩家在某城分会的声望高了，该城分会才会提供更好的价格和订单。

**分会分布：** 灰原城（活跃）、枯林城（活跃）、鱼水城（活跃）、粮野城（活跃）、海盐城（活跃）、火油城（小型）、药泽城（小型）、黑石城（活跃、规模最大）、灰烬城（无）。

## 二、强盗（敌对·常见）

各路强盗、流寇、劫匪的统称，不是统一的组织。分为路匪（三五成群）、匪帮（有组织有据点、多达数十人）、流寇（无固定据点）三种。

**强盗的动机：** 他们不是生性凶恶。灰潮之后土地不适宜耕种，动物狂暴，没有粮食，快要饿死了，才被迫出来打劫过路的商队来勉强糊口。没有真正的反派，只是立场不同。一些小型匪帮会选择避让强大的商队，少数匪帮可以谈判交"过路费"换平安通过。

## 三、灰渊信徒（敌对·极罕见）【已废止】

> 该阵营基于早期"灰烬母兽"设定（母兽崇拜），随母兽设定废止而一并作废。灰烬生态重做后，不再存在"崇拜母兽"的教派。如有类似敌对势力需求，应另行设计为针对灰烬生态 / 旧文明实验的极端组织。

## 四、灰兽

灰兽是灰烬生态中的动物统称，其分类与分布由「生态角色」与「灰度分层」共同决定（玩法细节见第 8A 类）：

- **按生态角色分四类**：掠食型（主动猎食，危险）/ 食腐清道型（吃灰烬沉积物，一般不咬人）/ 群居迁徙型（像象群，围城属此类）/ 共生型（罕见，可理解互动）。
- **按灰度分层分布**：低灰区（灰度 < 30）几乎无灰兽；中灰区（30–70）以被灰烬感染变异的普通野兽为主（食腐 / 群居多见）；高灰区（> 70）以灰烬生态自古演化的原生动物为主（掠食 / 共生多见）。
- **灰蚀**：高灰区接触或战斗中施加的共有环境危险状态，是灰烬"腐蚀性后遗症"的体现，并非某一类的专属标签（接入第 4A 类状态系统）。

灰兽是生态住户，除掠食型本能猎食外不恶意；玩家进灰区才是闯入者。

# 第四部分：旧文明技术

## 一、旧文明概述

灰潮之前的旧世界拥有一张庞大的能源和技术网络。旧文明技术不是魔法，而是高度发达但已失去完整知识体系的高科技。

### 核心特征
- **高度集成**：功能复杂但操作简单，多为"接入即用"式设计
- **不可复制**：当前人类无法重新制造，只能从遗迹中回收和修复
- **依赖特殊能源**：多数旧文明设备需要特定能源（烬油、火种）才能运行
- **效果强大但有限**：不是无限能源，使用有代价

## 二、节点反应炉

**只有城市有节点反应炉**，驿站没有。每个城市拥有1座节点反应炉，运作高度依赖烬油供应。一旦商路中断，烬油无法运达，节点反应炉就会失去能源无法工作。

### 节点激活前后的城市功能差异（重新设计 · 2026-09-07）

**核心原则**：节点反应炉（旧文明能源枢纽）熄火 = 城市只是普通聚居点，**基础生活功能与三轴成长基础版照常运转**；插入余烬核心重启反应炉 = 旧文明能源恢复 → **额外上线依赖旧能源的特殊设施 + 城市管理层大量奖励**。激活不是"解锁城市"，而是"给城市接上旧文明的电 + 拿到回报"。

**激活前（反应炉熄火，城市本就活着，中世纪末期人力手段）：**
基础功能 + 核心成长设施的基础版，全部可用，不依赖旧文明能源：
- 买卖补给 / 零件 / 药包（物价最低）
- 普通治疗（恢复生命；重伤/失能仍可处理，仅更贵/更慢）
- 修车、招募、接订单、卖货
- 打听情报、消费休整提升士气
- **基础记忆设施**：人工读取旧载体，慢、选项少、易出错（接第 6A 类记忆轴）
- **基础工坊**：铁匠打普通件 / 修普通装备（非旧时代自动产线）
- **基础改造舱**：可做全部身体改造项，有排异风险、可重试（接第 6A 类身体改造轴）
- 即：第 2A 类「城市能做什么」表中，除旧文明专属项外的全部功能。

**激活后（反应炉重启，旧能源上线）额外解锁 / 升级：**
仅"依赖旧文明能源的特殊设施 + 城市管理层回报"，是激活的额外奖励，不是玩游戏的门槛：
- **高级记忆设施**：更多记忆位、更强植入、无排异
- **工坊复产**：制造特殊模块、修复旧时代装备（接第 7A 类「旧时代装备」）
- **高级改造舱**：强改造、低风险、解锁稀有大型项（如神经反射接口 +行动力）
- **节点网络连通**：该城接入沿途驿站节点信号网 → 跨城情报共享、特殊跨城委托、恢复烬油稳定供应（城市不再因商路断供停摆）
- **高级医疗 / 检疫**：治愈灰度感染、更高效处理重伤（激活前只能靠基础药包 / 城市普通治疗）
- **城市管理层大量奖励**：见下文

#### 节点激活的额外奖励（城市管理层）

激活 = 你为城市重新接上旧文明能源，统治层（城主 / 油主 / 大药师等，见本文件「第7A 补充：统治结构与社会阶层」）给予**一次性大额回报 + 持续特权**，是强激励但不是门槛：
- **一次性大额赏金**：大量金币 + 稀缺物资（火种 / 灰烬材料 / 旧时代装备图纸）
- **城市声望大涨**：直接开启该城专属高价订单、特殊跨城委托
- **旧文明许可**：解锁使用高级改造舱、进入遗迹禁区、购买遗物专柜
- **烬油稳供**：城市不再因商路断供停摆（接「城市依赖烬油」）
- **节点网络特权**：跨城情报共享、特殊委托

> 协调「不激活也难受」：奖励是**拉**不是**推**——不激活 = 三轴基础版全有、能跑商能通关，只是少这层省心 + 淘宝 + 大额赏金；激活 = 强烈吸引但不强制。

> **设计意义**：玩家**完全可以不走"激活九城 / 复兴商路"这条线**——城市基础功能与三轴成长基础版始终可用，想跑商就跑商；激活只是多一层旧文明便利、大额赏金与推进可选主线的钥匙，**绝不强制**。

## 三、烬油

风蚀沙漠的火油城出产烬油，这是节点反应炉运作的核心能源。不是普通石油，而是含有微弱灰烬能量的特殊油质。火油城的提炼技术最好，其他城市无法自行生产烬油。商路一旦中断，烬油无法从火油城运往其他城市，城市就会逐渐停摆。

## 四、余烬核心

**激活密钥，不是动力源。** 它不提供能源，而是授权启动能源分配系统。不消耗，不会损坏。接入城市节点反应炉后激活该反应炉的能源分配系统。余烬核心是"钥匙"，烬油是"燃料"，两者缺一不可。

### 余烬核心 · 来历与获取（正式版叙事设计）

**设计纪律（禁用俗套来路）**：禁用「神秘老头/快死老人/落魄商人赠送」「从家里翻出/祖产传承」「大街上捡到/不小心挖出」等把"拿到核心"写成"主角个人命运事件"的套路。核心道具不当命运物、**当货**。

**来路（商业行为，非命运事件）**：
余烬核心在设定上是旧文明仍在流通的硬件——一枚封存零件，箱面刻「节点备件·用途未明」。玩家作为商人，通过一桩普通的生意将它收进商队：早先垫货/借款给另一支跑单帮的商队，约期对方还不上 → 以一批旧件抵债。本质是**买卖/抵债**，不是主角命运事件。

**开局获得方式（抵债包裹）**：
开局以一封抵债信/单据（信使送达，类"邮件"）通知玩家：那支商队还不上债，依约把一批抵债物寄到你手里。包裹里是乱七八糟一堆——**大多数没用**（来历不明的旧齿轮/仪表/封存模块，纯破烂）、**夹杂一些实用补给**（食物、水、零件）、**还有这枚余烬核心**。余烬核心混在大量无用物里，并不显眼，玩家大概率不会多想它。

**无特殊演出、自行探索**：
- 不写任何"揭示剧情"演出，不弹窗、不 NPC 告知"这是关键道具"。
- 余烬核心在状态栏只标「抵债来的旧件，用途不明」（或类似平实描述），不标"关键道具"。
- 玩家自己带着它走到熄火的节点反应炉前，修车匠/账房瞅见纹路、顺手插进槽——城市灯亮，玩家此刻才自行意识到"这破铁是钥匙"。
- 重要性来自「花代价换来（垫的货/钱）+ 用的时候才发现它能点亮城市」的发现感，不靠来路包装。
- 来历留白（谁造的、为什么还在流通）不解释，贴末世废土调性。

> 极简测试版不演邮件/包裹演出，仅状态栏标注"抵债来的旧件"；本段为以后写正式版主线的权威口径。

## 五、记忆技术

记忆是旧文明遗留下来的战斗协议、操作经验或意识模板，存储在各种记忆载体中。不是知识教育，而是意识层面的能力植入。分为攻击、防御、辅助、消耗四类。出战记忆位初始8个，后期可达15个。

## 六、火种

旧文明遗留的高密度能源结晶。稀有战略资源，获取途径有限。不做火种碎片，是完整单位。用于记忆强化、记忆融合、旧时代装备启动。

## 七、旧时代装备

灰潮前的高科技物品，效果比普通装备更强。获取概率低，每一件都是独特的，但不是普通装备的上位替代。部分需要火种才能完全启动。车载旧文明巨物只能装在商队模块的旧时代装备槽上，消耗火种激发，效果极强。

# 第五部分：灰烬生态与灰兽潮

## 一、灰烬生态与灰烬污染的起源

**灰烬区（灰烬生态区）**：灰烬是大陆上自古存在的自然生态类型（如沼泽、沙漠），有特有的地貌、植被与原生动植物，不针对任何生命。

**灰烬污染（人为后遗症）**：旧文明后期为清除灰烬开展实验，结果适得其反——造成了**腐蚀性**，并让灰烬获得**感染正常动物**的能力。中性的灰烬生态因此被污染成病态、危险的存在。今天灰烬区的危险（腐蚀、感染），根源是**旧文明实验的后遗症**，而非生态本身之恶。

> 【废案标注】早期设定"灰烬母兽创造灰潮、沉睡于烬渊山地底"已废止。烬渊山作为既有地名保留，但不再与母兽关联。

## 二、灰潮（灰烬生态波动）

灰潮是灰烬生态活跃度（灰度）的周期性波动现象，不是某生物释放的灾变。它随区域、时段缓慢变化并带随机性。灰潮的成因已明确：旧文明开采破坏生态 + 清除实验反效果，而非神秘悬念。

## 三、灰兽（与第三部分统一）

| 类型 | 来源 | 强度 |
|:----|:----|:----:|
| **原生灰烬动物** | 灰烬生态自古演化出的原住民 | 视种类 |
| **感染变异常兽** | 普通野兽被灰烬污染（旧文明实验后遗症）感染变异 | 中~高 |

原生动物不恶意；感染兽因变异更具攻击性。灰度越高的区域，灰兽越多越强。

## 四、灰兽潮（世界底色，非大事件）

灰兽潮是灰烬生态的周期性波动表现，是**世界的底色**而非突发大事件：

- 灰度随区域 / 时段缓慢漂移 + 随机波动，玩家用灰度探测仪从容观测；
- 路上偶遇小股灰兽（几只~十几只），可避可战；
- 偶发某**单座**城市被几十~几百只灰兽围攻（罕见、非定时、非全球），玩家可介入可路过；
- **绝无**铺天盖地、全城被屠、全球同时遭攻。

> 第 8A 类_灰烬生态系统_权威口径.md 已按此"生态底色"基调重做完成（原"大事件"框架已废止，旧文件改重定向）。

## 五、灰烬（生态与污染）对世界的影响

- **土地退化**：灰烬生态蔓延 + 污染使土地失去肥力——这是强盗产生的根本原因
- **城市依赖烬油**：商路中断→烬油断供→城市停摆（城市在灰烬地貌中挣扎存活，如荒漠中的城）
- **商队风险**：货物被污染会变成新污染源，需清除
- **灰度指标**：某区域灰烬生态活跃 / 污染程度（0-100）称"灰度"，随区域、时段、随机缓慢波动，玩家以灰度探测仪观测。

## 一、九城时代后的统治格局

九城时代结束后，城市之间彻底失联。每座城市各自为政，没有统一的政权，也没有从属关系。

## 二、各城统治结构

| 城市 | 统治形式 | 统治者称呼 | 说明 |
|:----|:--------|:----------|:------|
| **灰原城** | 世袭城主 | **城主** | 威信不高但没人反对。城中事多由商会和几个大商人商量着办，城主只管收税和维持秩序 |
| **枯林城** | 猎头议会 | **猎首** | 几个大猎户家族的族长联合议事，城主由各族轮流担任——实际上就是挂个名 |
| **鱼水城** | 水业垄断 | **水司** | 掌握净水厂的人才是真正掌权者。水源就是权力。城主是傀儡 |
| **海盐城** | 公会联合 | **港务长** | 渔民公会和盐场主联合治理，大事投票决定，投票按盐场大小算权重 |
| **粮野城** | 农场主联合 | **农长** | 粮食是硬通货，种粮的人最有话语权。名义上有城主但没什么实权 |
| **火油城** | 世袭油主 | **油主** | 掌握炼油技术和油矿的人。烬油是九城命脉，油主同时也是炼油厂主 |
| **药泽城** | 长老会 | **大药师** | 几位年长的药师和学者组成议会。药泽城闭塞但文化保存最好 |
| **黑石城** | 铁匠公会 | **工头长** | 锻钢坊的工头和老师傅们联合治理，公会推选领主 |
| **灰烬城** | **无政府** | 无 | 城市半废弃，只住了一两千人，人人自顾不暇，没人管也没人想被管 |

## 三、社会阶层（通用九城结构）

九城时代末期，每个城市大体划分为以下阶层：

| 阶层 | 包含人群 | 社会地位 | 说明 |
|:----|:--------|:--------|:------|
| **统治者** | 城主/油主/大药师等 + 他们的家族 | 最高 | 掌握城市命脉资源（土地、能源、水源、武力） |
| **大商人/工头** | 商会负责人、大商队主、铁匠公会核心成员 | 高 | 经济实力强，能影响城市决策。城主也得给他们面子 |
| **技术工匠** | 会修旧设备的人、铁匠、药剂师、炼油师傅 | 较高 | 掌握实用技术的人，到哪都有人要。人数稀少但受尊重 |
| **普通市民** | 小商贩、手艺���、猎人、农民、渔民 | 中 | 自给自足，勉强糊口 |
| **底层** | 无地农民、搬运工、临时工、老人 | 低 | 生活在城市边缘，干最苦的活赚最少的钱 |
| **边缘人** | 流浪汉、拾荒者、被灰烬污染的人 | 极低 | 不被当城市一员，基本自生自灭 |

### 各阶层详细描述

**统治者**
每个城市只有极少数人处于这个阶层——世袭的城主、油主，以及他们的直系亲属。他们掌握着城市最重要的资源（土地、水源、能源、武力）。住在城市最好的区域，有仆人，有卫队。但也并非高枕无忧——如果城市长期衰败，统治者的地位也会动摇。火油城的油主是其中最稳固的（烬油谁都离不开），灰原城的城主是最虚的（啥也不掌握，说话没分量）。

**大商人/工头**
商会负责人、大商队主、铁匠公会的核心成员。财富雄厚，能左右城市的经济决策。城主缺钱了也得找他们借。这一阶层和玩家关系最密切——玩家本身就是商队，到各个城市都要和商会打交道。

**技术工匠**
人数稀少但非常受尊重的一群人。他们掌握着旧设备的维修和操作知识——铁匠铺的师傅知道怎么打一把好刀，炼油厂的老技工知道怎么提炼烬油。无论到了哪个城市，技术工匠都不会饿死。他们通常不太关心政治，更在乎自己的手艺。

**普通市民**
城市里的大多数人——小商贩、猎人、农民、渔民、手艺人。每天为了生计奔波，勉强糊口。他们不太关心城主是谁，更在乎明天的粮价和今天的治安。他们是市场的主要交易对象，也是各种消息的源头。

**底层**
无地农民、搬运工、临时工。干的是最苦最累的活，赚的是最少的钱。住在城市外围的破旧棚屋里。如果有人生病或受伤，往往没钱去医馆，只能硬扛。灰潮对他们影响最大——土地退化后他们第一批失去生计。

**边缘人**
流浪汉、拾荒者、被灰烬污染的人。他们不被视为城市的一员。灰烬污染者身上有明显的灰蚀痕迹，其他人会刻意避开他们。这些人通常出现在城市外围的废墟和灰烬污染区附近。偶尔可能知道一些别人不知道的秘密——毕竟他们整天待在别人不去的地方。

### 阶层流动性

九城时代的社会结构不是铁板一块——**阶层有一定的流动性**，但不高：

| 向上途径 | 难度 | 说明 |
|:---------|:----:|:------|
| 做生意发财 | 中 | 有本钱+运气，小贩可以变成大商人 |
| 学徒出师 | 低 | 跟师傅学手艺，学成了就是工匠，生活立刻上去 |
| 保卫城市立功 | 中 | 兽潮中表现突出，可能被领主赏识 |
| 发现旧文明遗物 | 高 | 找到有价值的旧设备或记忆，一夜暴富，但概率极低 |

> 玩家作为外来商队，不受这个阶层体系的限制。玩家和哪个阶层打交道都可以。
