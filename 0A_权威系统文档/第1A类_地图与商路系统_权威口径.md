## 1. 游戏类型定位

- **游戏类型**：大地图商队 RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件
- **地图形式**：格子地图，不采用爬塔路线，不采用自由移动
- **移动方式**：像下棋——向上、下、左、右移动一格
- 不是 3D 开放世界（早期废弃方案，已全部丢弃）

## 2. 时间系统与行进能量

游戏所有系统统一到 **"天数"** 上计算；但**移动不再按"走一格 = 一天"**，而是采用 **行进体力（每日体力预算）** 模型。🔴 **2026-09-20 改口径**：野外体力**放大到 50 点/天**（原 3 AP），且**与战斗体力同源**（同一把尺子）。

| 项目 | 规则 |
|---|---|
| 每个自然日 | 商队获得 **50 点野外体力** 预算（**基准**；**取全队战斗人员的最低值** —— 一个人走得慢，全队就快不了） |
| 移动 1 格 | 消耗 **20 点**（**基准车**；**车轮 / 路况 / 载重可改每格消耗**，见 §5） |
| 满速行进 | 1 天最多约 **2.5 格**（标准轮；改良轮 3.1 格 / 精制轮 4.2 格） |
| 平均速度 | 不全速（装货、夜行、探路、休整穿插）取 **约 2 格/天**，路线天数按此折算 |
| 恶劣天气 / 坏路况 | **每格消耗上升**（暴雨 / 暴雪 / 灰烬风 **+5**、灰烬风暴 **+10**，见第 5A 类）→ 最差 1 天只够 1~1.5 格 |
| 休养 1 天 | 重伤恢复进度 +1（不移动，体力不用于赶路） |
| 等待 1 天（城市/城镇/驿站/村庄） | 天气推进 +1，消耗补给 |
| 订单期限 | 按天计算 |
| 天气持续 | 按天计算 |
| 补给消耗 | 按**天**消耗（与走几格无关，见 §5） |

> **野外体力 ≠ 战斗体力（但同一把尺子）**：两套都用 **50 点/人** 的刻度（**玩家只学一套刻度**），但**互不通用**（野外按"天"结算、战斗按"回合"结算）—— 唯一接口见 §2.1 疲劳接战。战斗侧见第 4A 类 §2。
>
> 核心体验：每一步消耗的是体力而非天数——一天能走几格取决于你舍得/能花多少体力；**好车轮让你走得更远、坏天气和超载让你走得更近**。每一天都在消耗补给，每一次等待都在赌订单，每一次坏天气都可能是灾难，也可能是机会。

### 2.1 每日 50 点野外体力的用途（一天的预算怎么花）

**50 点是"一天的预算"，不是"每天必须走满"。** 四种花法：

| 用途 | 消耗 | 说明 |
|:--|:--|:--|
| **移动** | **20 点 / 格** | 满速约 2.5 格/天（标准轮，见 §5） |
| **主动侦察** | **10 点** | 把自身周围一片区域的信息等级抬升一级（见 §9.6） |
| **采集** | **20 点** | 就地拾取资源点（§4 节点类型中的补给点；食物 / 水 / 零件 / 草药等） |
| **休整** | **20 点** | 原地停留：养伤、整备、修车，不移动 |

> **标准打法 = 走 2 格（40）+ 侦察 1 次（10）= 50**，正好花完一天（对应旧口径"3 AP 走 2 格 + 侦察 1"）。
> **全速赶路 = 把 50 点全用在移动上（不做侦察 / 采集 / 休整）。** 这是"快"的第一重代价，也是订单分化的来源：**普通单**期限宽裕、早到无用 → 留点侦察采集；**急单**不走就赶不上 → 全速赶路（代价即"今天什么都别想干"）。

**疲劳接战（跨系统机制 · 方向已定，数值待战斗层）**

当天**把体力全用在赶路上（没做侦察 / 采集 / 休整）**后进入战斗 → **该场战斗的体力上限 ×70%**（**固定、人人一样、四舍五入**；**不清零、只这一场、不叠加**）。

- ⚠️ **触发条件必须是"全速赶路"（体力全用在移动上），不是"体力用光"**：若写成"体力归零/耗尽"，则"走 2 格 + 花 10 点侦查"也照样触发 → **侦查反而挨罚，逻辑正好反了**（侦查本就是为了避险）。
- ⚠️ **不得写成"清零"**：清零会让 3 人队与 5 人队同罚，强队一样打不过 → 门槛失效。**上限打折（×70%）** 才能做到"池子越小越疼"，这才是"实力不够就别赶路"的门槛。
- 与上文"两套同刻度但不通用"的关系：**默认互不影响，仅此一项为例外**。

## 4. 地图节点（格子）类型

地图上每一格可能是以下类型之一：

| 序号 | 节点类型 | 功能 |
|:---:|----------|------|
| 1 | **空地** | 只消耗资源，无事件 |
| 2 | **战斗** | 进入普通战斗 |
| 3 | **事件** | 触发随机事件（正面/负面/选择分支） |
| 4 | **营地** | 可以休息、修车、鼓舞士气 |
| 5 | **补给点** | 可以补充少量补给和零件 |
| 6 | **危险区** | 可能战斗，也可能获得奖励（高风险高回报） |
| 7 | **Boss** | 区域最终战 |

## 5. 移动消耗

**移动规则（已定）**：移动按**野外体力**结算，**1 格 = 20 点（基准）**；每天基础 **50 点**（恶劣天气 / 坏路况**加每格消耗**，见 §2）。每移动一格的消耗：

| 消耗项 | 规则 |
|---|---|
| 野外体力 | **−20 点**（基准车；满速约 2.5 格/天；**车轮 / 路况 / 载重改每格消耗**） |
| 当前天数 | +1（每过完一个自然日） |
| 补给 | 每人 −1 份食物、−1 份水（整数份，不拆份；详见第 3A 类 §1.3） |
| 重伤角色休息倒计时 | −1（休息节点数 −1） |

**车轮 → 改变每格消耗（2026-09-20 新增）**

| 车轮 | 每格消耗 | 一天能走（50 点） |
|:--|--:|--:|
| 破旧 / 标准 | **20** | 约 2.5 格 |
| 改良 | **16**（−20%） | 约 3.1 格 |
| 精制 / 旧时代 | **12**（−40%） | 约 4.2 格 |

> **减速同理**：坏路况 / 超载 → 每格消耗上升（走 1 格 25 / 30）。**这就是"后期车队能真的变快"的实现方式** —— 车轮从"纯数字配件"变成**能感知的装备**，且野外 / 战斗用同一把尺子、零新增概念。

### 5.1 补给耗尽惩罚

补给 = 0 后，每天：
- 士气 −1
- 全体角色**最大生命值降低**（食物归零 −10%，水归零 −20%；二者皆零则叠加）
- 重伤恢复天数 +1（不恢复反而恶化）

> 与第 3A 类 §1.6 保持一致。补给归零不直接失败，但三项惩罚叠加会迅速把商队拖垮。没有额外惩罚。

## 6. 安全点（地图休整与撤退）

**安全点 = 地图上可让商队安全休整、补给、修车、恢复士气、处理重伤的地点**，是长途商路的"锚"。

安全点分五类（详细功能/物价/治疗/库存见第 2A 类地点系统）：

| 地点 | 安全等级 | 定位 | 接收撤退？ |
|:---:|:---:|------|:---:|
| **大城（九城）** | ★★★★★ | 唯一真正的大安全点；唯一有节点反应炉、可处理重伤/失能、功能最完整、物价最低 | ✅ |
| **小城** | ★★★★ | 自发聚集定居点；正常设施齐全（除旧文明特殊设施），物价比大城稍贵、比城镇低；治安更危险 | ✅ |
| **城镇** | ★★★ | 路上的补给容错点；补给、生活物资、普通治疗 | ❌（撤退只撤到大城/小城） |
| **驿站** | ★★★ | 商队专门休息点；零件、修车、路线服务；**不接收撤退** | ❌ |
| **村庄** | ★★ | 小型聚落；功能最少、少量交易/情报、物价最高 | ❌ |

**撤退规则（已定）**：战斗/危机撤退只撤到**大城或小城**；城镇与驿站不接收撤退（只作中途补给/修车）；村庄不接收。详见第 4A 类撤退机制、第 2A 类地点系统。

> 中继点（见 §7.3）是安全点里的"城镇 + 驿站"子集，是路线中途的常规休整点；大城/小城是真正的后方安全锚。

## 7. 路线分类

每段路（城市到驿站、驿站到驿站、城市到城市）之间的距离：

### 7.1 路线长度分类

| 路线类型 | 总距离（天） | 折算格距（约） | 定位 |
|:-------:|:------:|:------:|------|
| **短途** | 30 天以上，60 天以下 | 60–180 格（满速 3/天）/ 60–120 格（均速 2/天） | 新手路线 / 短途跑商 |
| **中途** | 60 天以上，120 天以下 | 120–360 / 120–240 格 | 有规划压力的主力路线 |
| **长途** | 120 天以上，200 天以下 | 240–600 / 240–400 格 | 真正远征 |
| **超长** | 200 天以上 | 400+ 格 | 后期大订单 / 边境商路 |

> 格距按"满速 3 格/天、均速 2 格/天"折算（见 §2）。

### 7.2 补给携带（不推荐，由玩家自定）

**本文件不提供推荐携带量，也不假设"推荐玩法"。** 玩家按实际商队规模与路程自行估算：

- 消耗基准见第 3A 类 §1.5：初始 **14 人 → 每天 14 份食物 + 14 份水 = 28 份/天**（每人每天 1 食物 + 1 水）。
- 所需总量 ≈ 路程天数 × 28 份 + 绕路/坏天气余量 + 沿途据点可补货程度。
- 想怎么买就怎么买（见第 3A 类 §1.4 出发采购）。

> ⚠️ **已废止的旧表（曾写"短途最低 30–60 份、推荐 40–80 份"）严重低估**：30–60 份仅够 14 人约 1–2 天，远不够 30–60 天路程；属早期"1/4 份/人/日"小队口径残留，已删除。

### 7.3 中继点（休整点）与间距

**中继点只有城镇和驿站**，是路线中途的安全休息点，用于补给、修车、休整；村庄不算中继点。

- **两个相邻中继点之间**：**约 30 天左右**（**20–30 天区间、不固定**；按均速 2 格/天 ≈ 60 格）。⚠️ **不是固定 30 天**——是量级，不是一个硬值。
  - ⚠️ **为什么能到 30 天（2026-09-14 校正）**：单辆货车**纯自持**（完全不修）只有 **≈24 天**（地形 1.5 + 战斗摊销 1.0 = **2.5 耐久/天**，见第 3A 类 §2.3）——**但玩家随身带零件、能在路上自助修车**（**1 零件 = 10 耐久**，见第 3A 类 §2.4）→ **24~30 天之间的缺口由随身零件补掉**，所以中继点**不必卡在 24 天**。**这正是"零件消耗率 ≈0.73 个/天"存在的意义**（`04 §0.1` 锚 A14）。
  - ⚠️ **旧写法"相邻中继点必须 ≤24 天"已废止**：它只算了车的自持力、**漏了随身零件**，会把据点摆得过密。
  - **真正的硬约束不是"耐久"，是"恢复"**：药包只能应急（回血少、还要花钱）→ **真正让队伍回满的是中继点**（治伤 / 修车 / 补给）→ **所以每段路必须有中继点**。
- 每段路（城市↔驿站、驿站↔驿站、城市↔城市）整体约 **30 天**量级（**中间必含至少 1 个中继点**）。
- 途中的"营地 / 落脚点"类格子（见 §4 节点类型）是更小型的临时休息与事件点，**不替代**中继点的补给/修车功能。

### 7.4 中程商路参考参数

| 项目 | 参考值 |
|---|---|
| 标准路线 | 约 100 天 |
| 订单期限 | 130–150 天 |
| 路线结构 | 4 段路 |
| 中继点 | 3 个（相邻 **≈30 天左右**，20~30 不固定） |
| 每段距离 | **≈30 天左右**（单车纯自持 24 天，**缺口靠随身零件补**；2026-09-14 校正） |

### 7.5 超长商路

超长路线（200 天以上）中间可以有一座城市作为大休整点，但到达该城市**不代表订单结束**，玩家只是中途整备后继续完成订单。

### 7.6 订单期限

```
订单期限 = 路程天数 × (1.3 ~ 1.5)
```

例：100 天路程 → 订单期限 130–150 天。200 天路程 → 订单期限 260–300 天。

## 8. 玩家路线决策

出发前需要判断以下事项：

| 决策项 | 说明 |
|--------|------|
| 到下个驿站大概多少天 | 评估路线长度，决定出发时机 |
| 要带多少补给 | 按第 3A 类 §1.5 实际消耗（14 人 ≈ 28 份/天）估算，留出余量应对绕路和坏天气；本文件不推荐具体数量 |
| 要带多少零件 | 用于修车、技能、事件，零件不够可能在半路抛锚 |
| 是否少带货、多带生存物资 | 货物与生存资源之间的取舍，多带货赚钱但可能不够吃 |
| 天气是否适合出发 | 判断当前与未来天气，坏天气可能减少当日行进能量、增加消耗和风险 |
| 订单期限是否允许等待 | 评估容错空间，等待可能让订单超时 |
| 遇到坏天气是否硬闯、绕路或等待 | 途中风险决策，需要兼顾补给、时间和订单 |

绕路和走近路有两种形式：
- **棋盘上主动规划**（**正式版**）：玩家在地图上选路时选更长更安全的路径，或更短更高风险的路径 —— **Demo 不实现选路**（`04 §0.5`）
- **事件触发**：通过外部事件（E10 路线判断事件）临时出现的路线选择

## 9. 地图侦察机制（信息等级系统）

玩家在地图上移动时，前方格子的信息通过**信息等级**系统决定能看到什么。

### 9.0 迷雾与可见范围（一切信息的前提）

**地图默认覆盖迷雾**：玩家没有全局视角，只能看到"信息等级允许他看到的那一片"。迷雾中的格子**在未被侦察 / 情报揭示前一律显示为"未知"**——不是"空地"，是"不知道"。

- **基准可见范围 = 自身格 + 十字四邻**（上下左右各 1 格）。
- **信息等级越高，看得越远、越清**：等级决定"半径"与"粒度"，0 级几乎只知脚下，逐级向外扩展。
- 范围 / 半径的**具体对照表属数值细化，待填**（见 §12）。

### 9.1 信息等级定义（迷雾里"能看到多清"）

| 等级 | 名称 | 玩家知道什么 | 示例 |
|:---:|:----|-------------|------|
| 0 | 无信息 | 什么都不知道，只知道有异常 | "前方出现异常。" |
| 1 | 模糊信息 | 知道可能有危险，但不知道类型 | "前方情况不太对，可能有危险。" |
| 2 | 类型信息 | 知道大概类型 | "前方像是有人活动过，可能是敌对风险。" |
| 3 | 关键信息 | 知道具体类别 | "前方大概率是强盗活动痕迹。" |
| 4 | 详细信息 | 知道大致数量、方向、位置范围 | "约 5-8 人，位置在北侧断路附近。" |
| 5 | 精确信息 | 知道具体人数、具体格子、具体触发条件 | "强盗 6 人，埋伏在前方第 3 格右侧。" |

> **低等级的"不确定"来自信息不足，不是"敌人生成靠随机"**：敌人与资源点在地图上是**预先摆好的、占具体格子的**，只是你看不清。所以"侦察 → 绕开"才成立——你绕开的是**真实存在的那一队人 / 那一片危险**。
>
> 等级越高知道的越多，可细到：**在第几格、几人、是否被悬赏、击败能得多少战利**。

### 9.2 信息类型

信息分为6大类，不同角色只影响自己专业的信息类型：

| 信息类型 | 说明 | 初始角色来源 | 提升幅度 |
|:--------|------|-------------|:--------:|
| **路线信息** | 前路、岔路、雾天、危险地形 | 荒野射手【野外侦察】 | +1 级 |
| **敌情信息** | 强盗、野兽、灰烬兽、伏击、夜袭 | 荒野射手【野外侦察】 | +1 级 |
| **资源信息** | 补给、水源、草药、材料、猎物 | 荒野射手【狩猎采集】（偏结果权重，不直接加信息等级） | — |
| **结构信息** | 桥梁、车轴、道路、坡道、废墟结构 | 修补师【现场诊断】 | +1 级 |
| **车损信息** | 车轴、车厢、车轮、抛锚隐患 | 修补师【现场诊断】 | +1 级 |
| **异常/旧文明信息** | 灰烬、火种、旧文明设备 | 初始修补师暂不专精 | — |

> 护路人不提供信息等级。护路人负责稳定结算，不负责侦察。

### 9.3 信息计算方式

```
最终信息等级 = 事件基础信息 + 区域信息 + 角色词条信息 + 装备信息 + 路线情报/记忆信息
最高不超过 5 级
```

| 信息来源 | 范围 | 说明 |
|---------|:---:|------|
| 事件基础信息 | 0-2 | 事件本身给出的可见程度 |
| 区域信息 | 0-1 | 该区域是否有明显特征 |
| 角色词条信息 | 0-1 | 随行角色是否有对应信息词条 |
| 装备/工具信息 | 0-1 | 望远镜、探测器、地图等 |
| 记忆/路线情报信息 | 0-2 | 旧文明记忆、驿站情报、商队传闻 |

### 9.4 初始信息上限

在没有装备、记忆、路线情报的初始阶段，最高可看到 **2 级（类型信息）**。

| 阶段 | 信息上限 |
|:----|:--------:|
| 初始三人，无装备/无记忆/无情报 | 最高 2 级 |
| 加上路线情报、驿站预警、基础工具 | 可到 3 级 |
| 中后期专用装备、专精角色、特殊记忆 | 可到 4 级 |
| 高级记忆、高级设备、剧情关键情报 | 可到 5 级 |

### 9.5 角色信息能力（关联第 6 类）

角色词条信息的具体设定属于第 6 类，此处仅列接口：

| 角色 | 词条 | 影响的信息类型 |
|:----|:----|---------------|
| 荒野射手 | 【野外侦察】 | 路线信息、敌情信息、痕迹信息等级 +1 |
| 修补师 | 【现场诊断】 | 结构信息、车损信息等级 +1 |
| 护路人 | — | 不提供信息等级，负责稳定结算 |

### 9.6 主动侦察（花体力买信息）

§9.3 那套是**被动叠加**（带了谁、带了什么，就看得多清）。在此之上，玩家可以**主动花资源买一次侦察**：

| 项目 | 规则 |
|:--|:--|
| **消耗** | **10 点野外体力**（从当日 50 点预算里出，见 §2.1） |
| **作用范围** | 自身周围 **5×5 = 25 格** |
| **效果** | 该范围内**信息等级 +1**（仍受 5 级上限约束） |
| **能揭示** | 敌人（在第几格 / 几人 / 是否被悬赏 / 战利）· 资源点（哪一格有物资）· 据点（驿站 / 城镇精确到格）· 地形与障碍 |
| **门槛** | **基础侦察人人可用**；**记忆 / 角色词条 / 装备** 提供强化版（范围更大、提升更多、甚至不耗体力） |

**典型用法**：远处只知"这一带有个驿站"（模糊，不知具体格）→ 花 10 点侦察 → **精确定位到某一格** → 直接走过去，不走冤枉路。同理可用于"哪一格有物资""敌人在第几格"。

- ⚠️ **侦察只揭示"预先摆在那儿的实体"，不预知随机结果**：它会告诉你"第 3 格有 6 个强盗"，不会告诉你"走哪一格会掷出遭遇"。
- ⚠️ **不是免费万能**：花体力就少走一格 / 少采一次（§2.1），而**绕开一格 ≈ 0.4 天 ≈ 120 金**、与打一场普通仗的开销同量级——两边都得付钱，玩家才会真权衡，而不是"见敌必绕"。
- **关联**：荒野射手【野外侦察】（第 6A 类）在本动作之上再 +1 级；E13 地标 / 视野事件（第 5A 类 §3.15）是**免费的一次性侦察**，与本动作并列。

### 9.7 世界会变：概率占格 + 情报时效

**"概率占格" —— 地图上的敌人与资源点是两段式：**

| 阶段 | 机制 |
|:--|:--|
| **生成（概率）** | 按区域灰度 / 事件权重**掷骰**，决定"这一带刷出什么、刷在哪一格" |
| **存在（占格）** | 一旦刷出，它就是**占着某一格的实体** —— 看得见、摸得着、能侦查、能绕开、能打（或采） |

> **既不是"走上去才掷骰的纯概率遇敌"，也不是"永久固定的地图"。概率决定它生在哪，占格决定它怎么被处理。**

**① 刷新**：地图实体**每隔一段时间重新生成**（周期待定）—— 敌人会走开 / 换格，物资会**新长出来**（如野果），也可能原地换成别的东西。

**② 情报会过期**：因此**侦察看到的不是永久真相**——
- 情报只在**有效期内**可信；过期后该格**回到未知**（或降级标为"旧情报"）。
- 界面**必须标出"这是几天前的情报"**，否则玩家无从判断该不该信。
- ⚠️ 这才是侦察值 **10 点** 的理由：**它不是一次买断，是"一段时间的确定性"。**

**③ 顺带澄清一个矛盾**：玩家**每天花 10 点侦察是正常打法、不是漏洞**——因为世界会变，"上次看过"不等于"这次安全"。它天然抵消了"侦查一次就永久安全"的退化。

**④ 与"资源构成稳定"不冲突**：第8A类 §3.4 说的是**"这一带产什么"稳定**（区域属性），本节说的是**"具体哪一格有没有野果"可变**（单格实体）。一个是区域、一个是格子，两层，不打架。

**⑤ 灰兽同样纳入"可侦查占格实体"（2026-09-14 定案）**

- **原口径作废**：`第 8A 类` 旧版曾明文"灰兽**不靠地图预知** / 不做侦察后标出灰兽活动格"（v2.1，以"避免前期暴毙 + 保留临场抉择"为由）。**该条已删**（第 8A 类 v2.3，2026-09-14 同步）。
- **为什么删**：地图**默认全格迷雾**、**情报是核心资源**——"不许看"等于把信息系统挖掉一块；而且它和"概率占格"**自相矛盾**（既然占格，就该能被看见、被绕开）。
- **灰兽照此办理**：也会被刷在某一格、**能侦查、能绕开**；但**刷新时会移动 / 消失**，情报同样**会过期**（见上文 ②）。
- **三档态度的差异只在"遇上之后能不能不打"**（友善 / 中立可离开，**敌对只能打**）——**不影响"能不能提前看见"**。
- **防暴毙改由区域灰度承担**：起始区显示灰度 < 30 几乎无偶遇（`第 8A 类 §5`）。
