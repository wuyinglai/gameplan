## 1. 游戏类型定位

- **游戏类型**：大地图商队 RPG + 战术卡牌战斗 + 订单护送 + 长线资源管理 + 天气风险事件
- **地图形式**：格子地图，不采用爬塔路线，不采用自由移动
- **移动方式**：像下棋——向上、下、左、右移动一格
- 不是 3D 开放世界（早期废弃方案，已全部丢弃）

---

## 2. 时间系统与行进能量

游戏所有系统统一到 **"天数"** 上计算；但**移动不再按"走一格 = 一天"**，而是采用 **行进能量（每日 AP 预算）** 模型。

| 项目 | 规则 |
|---|---|
| 每个自然日 | 商队获得 **3 点行进能量（AP）** 预算 |
| 移动 1 格 | 消耗 **1 AP** |
| 满速行进 | 1 天最多走 **3 格** |
| 平均速度 | 不全速（装货、夜行、探路、休整穿插）取 **约 2 格/天**，路线天数按此折算 |
| 恶劣天气 | 当日 AP 减少（暴雨 −1 / 暴雪 −1 / 灰烬风 −1 / 灰烬风暴 −2，见第 5A 类）；最差 1 天仅 1 格 |
| 休养 1 天 | 重伤恢复进度 +1（不移动，AP 不用于赶路） |
| 等待 1 天（城市/城镇/驿站/村庄） | 天气推进 +1，消耗补给 |
| 订单期限 | 按天计算 |
| 天气持续 | 按天计算 |
| 补给消耗 | 按**天**消耗（与走几格无关，见 §5） |

> **行进能量 ≠ 战斗行动力**：此处 AP 是地图上的"每日可走步数预算"；战斗中的行动力是另一套（见第 4A 类），二者互不影响。
>
> 核心体验：每一步消耗的是能量而非天数——一天能走几格取决于你舍得/能花多少能量；坏天气会卡住你。每一天都在消耗补给，每一次等待都在赌订单，每一次坏天气都可能是灾难，也可能是机会。

## 4. 地图节点（格子）类型

地图上每一格可能是以下类型之一：

| 序号 | 节点类型 | 功能 |
|:---:|----------|------|
| 1 | **空地** | 只消耗资源，无事件 |
| 2 | **战斗** | 进入普通战斗 |
| 3 | **事件** | 触发随机事件（正面/负面/选择分支） |
| 4 | **营地** | 可以休息、修车、鼓舞士气 |
| 5 | **补给点** | 可以补充少量补给和零件 |
| 6 | **危险区** | 可能战斗，也可能获得奖励（高风险高回报） |
| 7 | **Boss** | 区域最终战 |

## 5. 移动消耗

**移动规则（已定）**：移动按**行进能量（AP）**结算，**1 格 = 1 AP**；每天基础 3 AP（恶劣天气减，见 §2）。每移动一格的消耗：

| 消耗项 | 规则 |
|---|---|
| 行进能量（AP） | −1（满速 1 天 3 格；平均约 2 格/天） |
| 当前天数 | +1（每过完一个自然日） |
| 补给 | 每人 −1 份食物、−1 份水（整数份，不拆份；详见第 3A 类 §1.3） |
| 重伤角色休息倒计时 | −1（休息节点数 −1） |

### 5.1 补给耗尽惩罚

补给 = 0 后，每天：
- 士气 −1
- 全体角色**最大生命值降低**（食物归零 −10%，水归零 −20%；二者皆零则叠加）
- 重伤恢复天数 +1（不恢复反而恶化）

> 与第 3A 类 §1.6 保持一致。补给归零不直接失败，但三项惩罚叠加会迅速把商队拖垮。没有额外惩罚。

## 6. 安全点（地图休整与撤退）

**安全点 = 地图上可让商队安全休整、补给、修车、恢复士气、处理重伤的地点**，是长途商路的"锚"。

安全点分五类（详细功能/物价/治疗/库存见第 2A 类地点系统）：

| 地点 | 安全等级 | 定位 | 接收撤退？ |
|:---:|:---:|------|:---:|
| **大城（九城）** | ★★★★★ | 唯一真正的大安全点；唯一有节点反应炉、可处理重伤/失能、功能最完整、物价最低 | ✅ |
| **小城** | ★★★★ | 自发聚集定居点；正常设施齐全（除旧文明特殊设施），物价比大城稍贵、比城镇低；治安更危险 | ✅ |
| **城镇** | ★★★ | 路上的补给容错点；补给、生活物资、普通治疗 | ❌（撤退只撤到大城/小城） |
| **驿站** | ★★★ | 商队专门休息点；零件、修车、路线服务；**不接收撤退** | ❌ |
| **村庄** | ★★ | 小型聚落；功能最少、少量交易/情报、物价最高 | ❌ |

**撤退规则（已定）**：战斗/危机撤退只撤到**大城或小城**；城镇与驿站不接收撤退（只作中途补给/修车）；村庄不接收。详见第 4A 类撤退机制、第 2A 类地点系统。

> 中继点（见 §7.3）是安全点里的"城镇 + 驿站"子集，是路线中途的常规休整点；大城/小城是真正的后方安全锚。

## 7. 路线分类

每段路（城市到驿站、驿站到驿站、城市到城市）之间的距离：

### 7.1 路线长度分类

| 路线类型 | 总距离（天） | 折算格距（约） | 定位 |
|:-------:|:------:|:------:|------|
| **短途** | 30 天以上，60 天以下 | 60–180 格（满速 3/天）/ 60–120 格（均速 2/天） | 新手路线 / 短途跑商 |
| **中途** | 60 天以上，120 天以下 | 120–360 / 120–240 格 | 有规划压力的主力路线 |
| **长途** | 120 天以上，200 天以下 | 240–600 / 240–400 格 | 真正远征 |
| **超长** | 200 天以上 | 400+ 格 | 后期大订单 / 边境商路 |

> 格距按"满速 3 格/天、均速 2 格/天"折算（见 §2）。

### 7.2 补给携带（不推荐，由玩家自定）

**本文件不提供推荐携带量，也不假设"推荐玩法"。** 玩家按实际商队规模与路程自行估算：

- 消耗基准见第 3A 类 §1.5：初始 **14 人 → 每天 14 份食物 + 14 份水 = 28 份/天**（每人每天 1 食物 + 1 水）。
- 所需总量 ≈ 路程天数 × 28 份 + 绕路/坏天气余量 + 沿途据点可补货程度。
- 想怎么买就怎么买（见第 3A 类 §1.4 出发采购）。

> ⚠️ **已废止的旧表（曾写"短途最低 30–60 份、推荐 40–80 份"）严重低估**：30–60 份仅够 14 人约 1–2 天，远不够 30–60 天路程；属早期"1/4 份/人/日"小队口径残留，已删除。

### 7.3 中继点（休整点）与间距

**中继点只有城镇和驿站**，是路线中途的安全休息点，用于补给、修车、休整；村庄不算中继点。

- **两个相邻中继点之间**：典型距离约 **20–30 天路程**（按均速 2 格/天 ≈ **40–60 格**；满速 3 格/天 ≈ 60–90 格）。
- 每段路（城市↔驿站、驿站↔驿站、城市↔城市）整体约 **30 天**量级。
- 途中的"营地 / 落脚点"类格子（见 §4 节点类型）是更小型的临时休息与事件点，**不替代**中继点的补给/修车功能。

### 7.4 中程商路参考参数

| 项目 | 参考值 |
|---|---|
| 标准路线 | 约 100 天 |
| 订单期限 | 130–150 天 |
| 路线结构 | 4 段路 |
| 中继点 | 3 个（相邻约 20–30 天） |
| 每段距离 | 20–30 天 |

### 7.5 超长商路

超长路线（200 天以上）中间可以有一座城市作为大休整点，但到达该城市**不代表订单结束**，玩家只是中途整备后继续完成订单。

### 7.6 订单期限

```
订单期限 = 路程天数 × (1.3 ~ 1.5)
```

例：100 天路程 → 订单期限 130–150 天。200 天路程 → 订单期限 260–300 天。

## 8. 玩家路线决策

出发前需要判断以下事项：

| 决策项 | 说明 |
|--------|------|
| 到下个驿站大概多少天 | 评估路线长度，决定出发时机 |
| 要带多少补给 | 按第 3A 类 §1.5 实际消耗（14 人 ≈ 28 份/天）估算，留出余量应对绕路和坏天气；本文件不推荐具体数量 |
| 要带多少零件 | 用于修车、技能、事件，零件不够可能在半路抛锚 |
| 是否少带货、多带生存物资 | 货物与生存资源之间的取舍，多带货赚钱但可能不够吃 |
| 天气是否适合出发 | 判断当前与未来天气，坏天气可能减少当日行进能量、增加消耗和风险 |
| 订单期限是否允许等待 | 评估容错空间，等待可能让订单超时 |
| 遇到坏天气是否硬闯、绕路或等待 | 途中风险决策，需要兼顾补给、时间和订单 |

绕路和走近路有两种形式：
- **棋盘上主动规划**：玩家在地图上选路时选更长更安全的路径，或更短更高风险的路径
- **事件触发**：通过外部事件（E10 路线判断事件）临时出现的路线选择

## 9. 地图侦察机制（信息等级系统）

玩家在地图上移动时，前方格子的信息通过**信息等级**系统决定能看到什么。

### 9.1 信息等级定义

| 等级 | 名称 | 玩家知道什么 | 示例 |
|:---:|:----|-------------|------|
| 0 | 无信息 | 什么都不知道，只知道有异常 | "前方出现异常。" |
| 1 | 模糊信息 | 知道可能有危险，但不知道类型 | "前方情况不太对，可能有危险。" |
| 2 | 类型信息 | 知道大概类型 | "前方像是有人活动过，可能是敌对风险。" |
| 3 | 关键信息 | 知道具体类别 | "前方大概率是强盗活动痕迹。" |
| 4 | 详细信息 | 知道大致数量、方向、位置范围 | "约 5-8 人，位置在北侧断路附近。" |
| 5 | 精确信息 | 知道具体人数、具体格子、具体触发条件 | "强盗 6 人，埋伏在前方第 3 格右侧。" |

### 9.2 信息类型

信息分为6大类，不同角色只影响自己专业的信息类型：

| 信息类型 | 说明 | 初始角色来源 | 提升幅度 |
|:--------|------|-------------|:--------:|
| **路线信息** | 前路、岔路、雾天、危险地形 | 荒野射手【野外侦察】 | +1 级 |
| **敌情信息** | 强盗、野兽、灰烬兽、伏击、夜袭 | 荒野射手【野外侦察】 | +1 级 |
| **资源信息** | 补给、水源、草药、材料、猎物 | 荒野射手【狩猎采集】（偏结果权重，不直接加信息等级） | — |
| **结构信息** | 桥梁、车轴、道路、坡道、废墟结构 | 修补师【现场诊断】 | +1 级 |
| **车损信息** | 车轴、车厢、车轮、抛锚隐患 | 修补师【现场诊断】 | +1 级 |
| **异常/旧文明信息** | 灰烬、火种、旧文明设备 | 初始修补师暂不专精 | — |

> 护路人不提供信息等级。护路人负责稳定结算，不负责侦察。

### 9.3 信息计算方式

```
最终信息等级 = 事件基础信息 + 区域信息 + 角色词条信息 + 装备信息 + 路线情报/记忆信息
最高不超过 5 级
```

| 信息来源 | 范围 | 说明 |
|---------|:---:|------|
| 事件基础信息 | 0-2 | 事件本身给出的可见程度 |
| 区域信息 | 0-1 | 该区域是否有明显特征 |
| 角色词条信息 | 0-1 | 随行角色是否有对应信息词条 |
| 装备/工具信息 | 0-1 | 望远镜、探测器、地图等 |
| 记忆/路线情报信息 | 0-2 | 旧文明记忆、驿站情报、商队传闻 |

### 9.4 初始信息上限

在没有装备、记忆、路线情报的初始阶段，最高可看到 **2 级（类型信息）**。

| 阶段 | 信息上限 |
|:----|:--------:|
| 初始三人，无装备/无记忆/无情报 | 最高 2 级 |
| 加上路线情报、驿站预警、基础工具 | 可到 3 级 |
| 中后期专用装备、专精角色、特殊记忆 | 可到 4 级 |
| 高级记忆、高级设备、剧情关键情报 | 可到 5 级 |

### 9.5 角色信息能力（关联第 6 类）

角色词条信息的具体设定属于第 6 类，此处仅列接口：

| 角色 | 词条 | 影响的信息类型 |
|:----|:----|---------------|
| 荒野射手 | 【野外侦察】 | 路线信息、敌情信息、痕迹信息等级 +1 |
| 修补师 | 【现场诊断】 | 结构信息、车损信息等级 +1 |
| 护路人 | — | 不提供信息等级，负责稳定结算 |

## 10. 经济参考（关联第 2A 类）

以下数据仅引用与路线消耗直接相关的部分，完整经济系统参见第 2A 类与 `14_跑商系统数值.md`。

### 10.1 基础物资价格（城市基准价）

| 物资 | 城市基准价 |
|:---:|:---------:|
| 补给（食物/水各） | 食物 10 / 水 8 金币 / 份 |
| 零件 | 50 金币 / 个 |
| 药包 | 50 金币 / 个 |

### 10.2 路线消耗模型（14 人基准）

```
每天折算成本（14 人全口径）：
  食物        14 × 10 = 140 金币
  水          14 × 8  = 112 金币
  零件折算      约 20 金币
  药包折算      约 10 金币
  事件/修理预留 约 18 金币
  ─────────────────
  合计        ≈ 300 金币 / 天（详见 14_跑商系统数值.md 的 300 金/天基准）
```

**出行预计消耗 ≈ 天数 × 300 金币**

| 路线天数 | 预计消耗 |
|:-------:|:-------:|
| 50 天短途 | 约 15,000 金币 |
| 100 天中途 | 约 30,000 金币 |
| 150 天长途 | 约 45,000 金币 |
| 200 天超长 | 约 60,000 金币 |

### 10.3 订单奖励参考

```
单个订单奖励 ≈ 预计消耗 × (1.4 ~ 1.7)（中心 1.5；分档倍率见 14_跑商系统数值.md）
```

| 路线天数 | 预计消耗 | 订单奖励（约） |
|:-------:|:-------:|:-------------:|
| 30 天 | 9,000 | 12,600–15,300 |
| 60 天 | 18,000 | 25,200–30,600 |
| 100 天 | 30,000 | 42,000–51,000 |
| 150 天 | 45,000 | 63,000–76,500 |
| 200 天 | 60,000 | 84,000–102,000 |

长线真实总收益（含顺路订单、自营贸易、战斗收益等）可达 **100,000+ 金币**（详见 `14_跑商系统数值.md`）。
