## 0. 总定位

第 5 类由五个子模块组成：

| 模块 | 名称 | 作用 |
|:---:|------|------|
| 5.1 | 天气系统 | 决定当前天气段与天气对远行、事件、战斗、货物、内部压力的影响 |
| 5.2 | 外部事件系统 | 决定玩家在野外格子上遇到什么外部世界事件 |
| 5.3 | 内部事件系统 | 决定商队内部是否因压力爆发争执、抱怨、恐惧、互助等事件 |
| 5.4 | 事件冷却系统 | 对刚发生过的同类事件降权，避免重复刷屏 |
| 5.5 | 时间结算系统 | 统一处理走格、停留、绕路、搜索、修理、休整、撤退等时间口径 |

### 运行顺序

1. 玩家走 1 格，基础时间 +1 天
2. 根据当前天气段，应用当天有效天气
3. 根据当前自然区域，判断是否发生外部强事件
4. 若发生强事件，从 E1-E13 事件池抽取（去除 E5/E8），先应用冷却降权
5. 事件发生后，按时间规则和资源结算规则落账
6. 外部事件写入压力标签，供内部事件系统使用
7. 若商队压力达到检查条件，再判断内部事件
8. 内部事件同样写入同类型降权

> 核心口径：天气不是随机惩罚，而是远行决策系统。路上经常有事，但不是经常打架，也不是经常白捡资源。

## 1. 时间结算系统（5.5）

### 1.1 基础规则

- **走 1 格 = 1 天**
- 事件要么不额外加天数，要么额外 +1 天 / +整数天
- 不存在 0.5 天、半天、小数天
- "正常移动 +1 天"是基础移动时间，不是事件额外时间
- 事件里写"+1 天"，意思是在走这一格已经消耗 1 天的基础上，额外再增加 1 天

### 1.2 行为时间消耗

| 行为 | 时间消耗 | 说明 |
|:----|:--------:|------|
| 正常移动 1 格 | 1 天 | 基础移动 |
| 快速查看 / 简单交谈 / 快速处理 | 不额外消耗 | 事件本身不延长时间 |
| 停留采集 / 深入搜索 / 仔细侦察 | 额外 +1 天 | 在当前格多停留一天 |
| 绕路（棋盘上主动选择） | 后续路线变长 | 玩家在地图上规划路线时选更长但更安全的路径 |
| 走近路（棋盘上主动选择） | 后续路线变短 | 玩家选更短但风险更高的路径 |
| 强行通过 | 当前格结算风险 | 如车损、货损、遇敌 |
| 扎营 | 1 天 | 双倍补给（仅首日） |
| 等待（城市/城镇/驿站/村庄） | 1 天/次 | 消耗补给和天数，安全点内等待 |

> 绕路和走近路有两种形式：一种是在棋盘地图上玩家主动规划的路线选择；另一种是通过 E10 路线判断事件触发的临时路线选择。

## 2. 天气系统（5.1）

### 2.1 天气段规则

天气不再按"每走一格重新随机一个天气"处理，而是按**天气段**生成。

**生成流程：**
1. 当前天气段剩余天数每天 -1
2. 若剩余天数 > 0，继续使用当前天气
3. 若剩余天数为 0，按天气基础概率抽取下一段天气
4. 根据抽到的天气类别，生成持续天数
5. 写入当前天气和剩余天数
6. 每天按当前天气结算补给、货物、战斗、外部事件权重、内部事件压力等

**天气段持续时间：**
| 天气类别 | 包含天气 | 持续时间 |
|:--------|---------|:--------:|
| 普通天气 | 晴朗、阴天 | 5-7 天 |
| 特殊天气 | 小雨、暴雨、高温、酷热、寒潮、严寒、浓雾、重雾 | 3-6 天 |
| 灰烬风 | 灰烬风 | 4-5 天 |
| 灰烬风暴 | 灰烬风暴 | 2-3 天 |

### 2.2 基础天气概率

| 天气 | 基础概率 | 恶劣天气 | 大类 | 定位 |
|:----|:-------:|:--------:|:----|------|
| **晴朗** | 0.34 | 否 | 正常天气 | 稳定赶路 |
| **阴天** | 0.34 | 否 | 正常天气 | 轻微不安 |
| **小雨** | 0.05 | 否 | 下雨类 | 火焰削弱、防潮压力、雨水收益 |
| **暴雨** | 0.03 | **是** | 下雨类 | 更强雨天效果 |
| **高温** | 0.05 | 否 | 高温类 | 补给压力、水源价值提高 |
| **酷热** | 0.02 | **是** | 高温类 | 更强补给压力 |
| **寒潮** | 0.05 | 否 | 低温类 | 低温事件、野兽迟滞 |
| **严寒** | 0.02 | **是** | 低温类 | 冰面路线判断 |
| **浓雾** | 0.05 | 否 | 雾类 | 伏击提高、线索增加 |
| **重雾** | 0.02 | **是** | 雾类 | 更强伏击与迷路风险 |
| **灰烬风** | 0.02 | **是** | 灰烬天气 | 灰烬兽、污染、材料收益 |
| **灰烬风暴** | 0.01 | **是** | 灰烬天气 | 最高风险灰烬天气 |

> 正常天气合计 0.68，特殊天气合计 0.32。大多数时候正常跑商，约三分之一时间出现特殊天气。

### 2.3 各天气详细效果

#### 晴朗
- 战斗：伏击率 -10%
- 补给消耗：正常
- 货物风险：正常
- 重伤恶化修正：0
- 正向收益：最适合赶路、赶订单、推进路线

#### 阴天
- 战斗：伏击率 +10%
- 补给消耗：正常
- 货物风险：正常
- 重伤恶化修正：0
- 正向收益：无额外收益，但有轻微风险感

#### 小雨
- 战斗：火焰伤害 75%
- 补给消耗：正常，可收集雨水减 1
- 货物风险：怕潮货风险提高
- 重伤恶化修正：0
- 正向收益：雨水补给、雨后痕迹提示

#### 暴雨（恶劣天气）
- 战斗：火焰伤害 50%
- 补给消耗：正常，收集雨水减 2
- 货物风险：怕潮货风险更高
- 重伤恶化修正：+5%/天
- 正向收益：更多雨水、更明显痕迹

#### 高温
- 战斗：普通遇敌率 -10%
- 补给消耗：每 2 天额外 +1
- 货物风险：怕热货风险提高
- 重伤恶化修正：0
- 正向收益：水源价值提高、绕路找水更值得

#### 酷热（恶劣天气）
- 战斗：普通遇敌率 -20%
- 补给消耗：每天额外 +1
- 货物风险：怕热货风险更高
- 重伤恶化修正：+5%/天
- 正向收益：战斗更少补给更紧

#### 寒潮
- 战斗：普通野兽开局 1 层迟滞
- 补给消耗：正常
- 货物风险：保鲜收益
- 重伤恶化修正：0
- 正向收益：野兽迟滞、狩猎窗口、保鲜

#### 严寒（恶劣天气）
- 战斗：普通野兽开局 2 层迟滞
- 补给消耗：正常
- 货物风险：保鲜更强，可能有冻损风险
- 重伤恶化修正：+5%/天
- 正向收益：冰面捷径可能、冷藏订单有利

#### 浓雾
- 战斗：伏击率 +20%
- 补给消耗：正常
- 货物风险：无直接影响
- 重伤恶化修正：0
- 正向收益：雾中鹿影等猎物线索、旧路标等异常线索

#### 重雾（恶劣天气）
- 战斗：伏击率 +40%
- 补给消耗：正常
- 货物风险：无直接影响
- 重伤恶化修正：+5%/天
- 正向收益：异常线索更多，但迷路风险更高

#### 灰烬风（恶劣天气）
- 战斗：灰烬兽遭遇率提高、灰烬兽轻微强化
- 补给消耗：正常
- 货物风险：灰烬污染扩散加速（每 2 天一次，详见第 6A 类灰烬扩散系统）
- 重伤恶化修正：+5%/天
- 正向收益：灰烬材料采集、残骸线索

#### 灰烬风暴（恶劣天气，最高级）
- 战斗：灰烬兽大幅强化、灰蚀压力更高
- 补给消耗：正常
- 货物风险：灰烬污染扩散加速（每天一次，详见第 6A 类灰烬扩散系统）
- 重伤恶化修正：+10%/天
- 正向收益：风暴后旧设施显露、高价值灰烬材料

### 2.4 恶劣天气重伤恶化

只有处于重伤状态的队员受此影响。正常队员不会因天气直接受伤。

| 恶劣天气 | 重伤恶化概率 |
|:--------|:----------:|
| 暴雨 | +5%/天 |
| 酷热 | +5%/天 |
| 严寒 | +5%/天 |
| 重雾 | +5%/天 |
| 灰烬风 | +5%/天 |
| 灰烬风暴 | +10%/天 |

### 3.5 E1 遇敌事件

商队遭遇敌对力量。可进入战斗，也可先出现伏击前兆、拦路威胁、追踪痕迹等战前状态。

**敌对阵营：**
- **强盗** — 普通敌人基准（路匪、抢货强盗、火瓶匪、拦路队）

- **灰烬兽** — 高危险敌人（灰爪兽、灰蚀兽、灰烬虫群）

### 3.6 E2 道路事件

道路、通行、车损和路线选择事件，给玩家商队做选择题：修还是绕、花零件还是花时间。

**子类型：**
| 编号 | 类型 | 说明 |
|:---:|------|------|
| R1 | 通行受阻 | 原路线被挡住，需修、绕、等或强行清障 |
| R2 | 难行代价 | 路能走但通过需额外代价 |
| R3 | 车损/货损风险 | 车辆或货物损失检定 |
| R4 | 路线机会/绕路选择 | 出现近路、旧路、隐藏路径 |

### 3.7 E3 资源事件

发现资源机会，但不是白送资源。快速采集只拿一点，想拿更多需额外停留一天。

**子类型：**
| 编号 | 类型 | 例子 |
|:---:|------|------|
| G1 | 水源/补给类 | 水源、干粮、鱼、旧粮袋 |
| G2 | 狩猎/采集类 | 猎物、药草、干柴、兽骨 |
| G3 | 零件/材料类 | 备用零件、木材、金属残料 |
| G4 | 废弃货物/可交易物 | 遗落货箱、旧商队货 |
| G5 | 特殊/高风险资源 | 灰烬材料、污染残骸、旧时代样本 |

**给量限制：**
- 快速采集：通常 +1 补给/材料，零件低概率 +1
- 停留采集：+2 补给/材料，零件 +1
- 特殊资源：通常只给线索，实物有风险

## 5. 内部事件系统（5.3）

### 4.1 核心原则

- 内部事件不是每日随机骚扰
- 只有商队出现明显压力时才检查概率
- 状态好时概率可为 0%
- 内部事件必须有解决手段（花补给、花时间、花零件、改路线等）

### 4.2 不触发的情况

正常状态普通移动不触发。士气 5-7、补给够、车况好、无重伤时不触发。

### 4.3 触发条件

| 情况 | 是否检查内部事件 |
|:----|:--------------:|
| 士气 ≤ 4 | ✅ |
| 补给不足到下个安全点 | ✅ |
| 补给为 0 | ✅ |
| 零件为 0 | ✅ |
| 车况低/抛锚 | ✅ |
| 有重伤员 | ✅ |
| 恶劣天气后 | ✅ |
| 灰烬污染扩散 | ✅ |
| 货损严重 | ✅ |

### 4.4 概率公式

```
内部事件概率 = 
  士气修正 + 补给修正 + 零件修正 + 车况修正 
  + 重伤修正 + 天气修正 + 灰烬污染修正 
  + 订单/货损修正 + 扎营修正 - 安全缓冲
```

- 最低 0%，最高 100%
- 安全缓冲最多抵消 40%

#### 士气修正

| 士气 | 内部事件概率修正 | 说明 |
|:---:|:--------------:|------|

## 6. 事件冷却系统（5.4）

### 6.1 核心原则

- 所有事件冷却都是**降权冷却**，不采用强制禁止的硬冷却
- 冷却中的事件保留在池中，只是权重乘以保留比例
- 冷却不制造绝对安全窗口，只降低重复概率
- 内部事件不设总冷却，只做同类型降权（商队崩溃时可连续触发）

### 6.2 外部事件降权冷却总表

| 事件 | 冷却时长 | 冷却方式 | 保留权重 | 说明 |
|:---:|:--------:|:--------:|:--------:|------|
| **E1 遇敌** | 4 步 | 极重降权 | **0.15** | 不完全禁止，但大幅降低连续战斗概率。精英战后 5 步/保留 0.10 |
| **E2 道路** | 3 步 | 重度降权 | **0.30** | 避免连续塌方、泥坑、断桥 |
| **E3 资源** | 3 步 | 中度降权 | **0.40** | 避免连续刷资源，高价值资源后 5 步/保留 0.20 |
| **E4 商队/旅人** | 0 步 | 不设冷却 | **1** | 人烟、交易、信息事件，不强制压制 |
| **E7 小型遗迹** | 6 步 | 极重降权 | **0.20** | 保持遗迹稀有感 |
| **E9 痕迹/情报** | 0 步 | 不设冷却 | **1** | 可连续形成线索链 |

## 7. 最终覆盖口径

### 7.1 天气段已更新
当前天气段持续时间：普通 5-7 天，特殊 3-6 天，灰烬风 4-5 天，灰烬风暴 2-3 天

### 7.2 抛锚归属
货车耐久 0 = 抛锚，详细见第 3A 类。第 5 类引用该规则。

### 7.3 货损≥70%
货损 ≥ 70% = 当前订单失败。未达到时按比例扣奖励。

### 7.4 已删除
- **E5 订单相关事件** — 已删除。订单是远行目标，不是随机事件。订单压力由期限、货损、天气、道路自然产生。
- **E8 灰烬独立事件** — 已删除。灰烬不是独立事件，而是世界观状态、覆盖影响和风险标签。灰烬内容归入 E1（灰烬兽）、E3（灰烬资源）、E7（灰蚀遗迹）、E9（灰爪印）、E10（灰烬路线）。

### 7.5 经济数据归属
补给、零件、金币、修车、治疗等基础经济数值已在第 2A 类、第 3A 类确定。第 5 类只规定天气/事件如何调用这些资源。
