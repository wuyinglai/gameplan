## 一、总定位

灰烬生态系统**不是"事件"**，而是灰烬生态在世界中持续运行的**机制与底色**。它包含三层始终存在于世界中的要素：

- **灰度**：灰烬生态活跃 / 污染程度（0–1000），由「**区域 + 随机 + 天气**」**三层**叠加（2026-09-29 用户定，见第二节）；
- **灰兽**：灰烬生态中的动物（生态角色 + 灰度分层共同决定），旅途中的自然风险；
- **灰烬风暴**：灰烬生态区内的短时天气现象（类比沙漠沙尘暴）。

**设计原则（与本游戏「孤旅」基调一致）：**

- 不刺激、不压迫：危险是"远方灰兽的动静"那种**存在感**，不是"血条见底"的压迫；
- 无倒计时、无强制准备：灰度可从容观测，灰兽**可避可战**；
- 成长靠"向往"而非"恐惧"：高灰区有稀缺好货，玩家想进去才想变强，**但不逼迫**；
- **不照搬天气层效果**：灰度是长期生态底色，不重复第 5A 类天气的"降视野 / 物资稀缺"逻辑。

> 灰烬的本质（自然生态 + 旧文明实验后遗症）、母兽已废止等世界观设定见第 7A 类，本节不重复定义。

## 二、灰度模型（**三层叠加** · 2026-09-29 用户定）

灰度不是单一数值，由**三层相加**而成，玩家在灰度探测仪上只看到**叠加后的结果**：

| 层 | 名称 | 性质 | 取值方式 | 作用 |
|:--:|:----|:----|:----|:----|
| **L1** | **区域灰度**（基准） | 地图固定，每个区域天生自带（旧文明边缘低、深灰区天生高） | 由**地点锚点 + 距离插值**生成**连续场**（相邻区域必然接近，无硬边界） | 决定该区**资源构成**（稳定，不随时间变） |
| **L2** | **随机灰度**（游走） | 区域灰度之上的**上下浮动** | `L1 × ±20%`，**封顶 ±40**（预算余量，见铁律 2）；每 **3 天**重掷一次 | 让灰度"呼吸"（这几天高、过几天回落） |
| **L3** | **天气灰度**（短时） | **特殊天气的加值**，天气段结束即消失 | 灰烬风 **+100** · 灰烬风暴 **+200** | 让天气**短期**把环境顶上去 |

> **显示灰度 = 夹(L1 + L2 + L3, 0, 1000)** —— 即灰度探测仪显示、并参与战斗 / 损耗计算的那个值。
>
> 🔴 **读数一律整数**（1000 制，**不引入小数**）；且 **`夹` 只是兜底、永不触发** —— 三层之和由**预算**保证最高 **990**（见铁律 2）。
> ⚠️ **灰度探测仪是 UI，不是真实仪器** —— **不需要「仪表盘报表 / 刻度盘 / 报数」**，只需要**一眼可判的量级**（看到 **870** 就知道待不住，不需要去算百分比）。

**算例**（仅为说明**算法**，非真实区域值）：
- **浅灰区**：L1 **100** → L2 在 **80 ~ 120** 间游走 → **无天气** → 显示灰度 **80 ~ 120**；逢灰烬风暴 **+200** → **280 ~ 320**。
- **中灰区**：L1 **550** → L2 在 **510 ~ 590** 间游走 → **平时够不着 ≥700 的感染线**；逢灰烬风暴 **+200** → **710 ~ 790** —— 🔴 **平时安全、风暴一来就够得着感染线**，这就是"**灰度会呼吸**"的玩法含义。
- **后期最深灰区域**（⚠️ **描述性说法、不是地名**）：L1 **750** → L2 **710 ~ 790**；逢灰烬风暴 **+200** → **910 ~ 990** —— 🔴 **世界最高读数**，**仍留余量、不到满格**。

### 三条铁律

1. 🔴 **只有 L1 决定资源构成** —— L2 / L3 只改"**当下有多危险**"，**不改"这一带产什么"**（见第三节「资源构成」）。
2. 🔴 **L1 的「量程」是 `0 ~ 1000`、但「设计分配上限」是 `750`（**1000 制** · 2026-09-29 用户定）** —— 上下都有讲究：
   - **刻度 = 1000 制**：🔴 **「量级即语言」** —— 灰度是**世界尺度**（环境压力），天生比身体尺度（血量 `A13` / 装具盘 `A21` 的 100 制）**大一个量级**。读数 **870** 一眼就是"待不住了"，**87 只是个"像数值的数值"**；且 **1000 制下档距天然取整**（100 / 150 / 200），后期加档**不用动刻度**、也**不必引入小数点**。
   - 🔴 **上限 750、不是 1000** —— **`L1 + L2 + L3 ≤ 1000` 必须由「预算」保证，不能靠「夹」**：
     `1000（满格）= L1 上限 750 + L2 封顶 40 + L3 风暴 200` → **最坏叠加 = 990**，留 **10** 点余量。
     ⚠️ **理由**：灰度探测仪是 **UI**（不是真实仪器）—— **读数必须一眼可判、且永远顶不到格**。**一旦需要靠「夹」来收场，就说明刻度设计错了。**
     → **灰度最高处（烬渊山一带）取 `750`**：**`750 + 40 + 200 = 990`** 就是「**风暴把最深灰区推到接近满格**」的兑现者。
     > ⚠️ **"最深处"只是描述，不是地名** —— 指**灰度最高的那片区域**（烬渊山一带），**世界地图上不存在一个叫"深处"的地方**。
   - **下限 0（只是刻度下界）**：**灰烬是世界的底色，没有绝对干净的地方** —— 但**实际最低的区域 ≈ 200**（前期带），`0` 只是为了让量程与显示灰度同尺，**没有区域真的落在那里**。
   - ✅ **「顶格代价」已不复存在**：既然 `L1` 上限是 **750**、不是 1000，**任何区域都还能被 L2 / L3 推动** —— 旧写法"最灰的地方不会更灰"所描述的问题**已被预算制消掉**。
3. 🔴 **L1 是连续场，不是硬分区** —— 灰度**不按行政边界跳变**：相邻两片区域值必然接近、中间有过渡。→ 这也是**"相近的两条路灰度 ≈ 一致"**的原因（路线差异只能挂 **地形 / 人烟 / 据点 / 长度**，不能挂灰度，见 `04 §0.5.3`）。

### 分区刻度（按**显示灰度**判）

| 区间 | 名 | 环境表现 |
|:----:|:--|:--|
| **0 ~ 300** | 低灰 | 几乎无灰兽 · 无腐蚀 · 无感染（**起始区**在这一档） |
| **300 ~ 500** | 中低灰 | 灰兽出现（以感染变异的普通野兽为主）· 仍无额外腐蚀 |
| **500 ~ 700** | 中高灰 | 每车 **−1 耐久 / 天** |
| **700 ~ 850** | 高灰 | **感染风险**（≥700）· 每车 **−2 耐久 / 天** |
| **850 ~ 1000** | 极灰 | 每车 **−3 耐久 / 天** · 掠食型与原生兽为主 |

> 🔴 **"极灰"够不到常态** —— `L1` 最高 **750** + `L2` 最高 **40** = **790**，落在"**高灰**"。**要越过 850，必须靠天气**（后期最深灰区域逢风暴 = **910 ~ 990**）。这正是想要的：**极灰是天气造成的罕见状态，不是常驻的地图属性。**

### 区域灰度怎么铺（**生成原则**）

- **锚点**：每个**地点**（城市 / 城镇 / 驿站 / 村庄）自带一个区域灰度值；
- **插值**：地图上任意格子的区域灰度 = **周边锚点的反距离加权平均** → 得到**连续场**（无硬边界、无跳变）；
- **分布建议**（⚠️ 暂定）：起始区（灰原城周边）**≤ 250** · 前期带 **200 ~ 300** · 中期带 **450 ~ 550** · 后期带 **700 ~ 750**（**灰度最高处 = 750**，如烬渊山一带 —— 🔴 **这是描述、不是地名**）；
- 具体锚点值**随地图生成时分配**（`12 世界蓝图` 重做时落地），**本文件不手写**。

### 前期保护（落地方式）

起始区域 / 新手区地处旧文明边缘，破坏轻、蔓延少 → **L1 低（≤ 250）** → **常态显示灰度 < 300** → **几乎无灰兽、不腐蚀、不感染**，天然安全；随贸易深入高灰区才遇强风险。

⚠️ **唯一例外 = 灰烬风暴**：L3 **+200** 会把它**短暂**顶到 **450 ~ 490**（罕见，基础概率 0.01）—— **逼近 500 的「−1 耐久」线，但过不去**。**这是设计允许的** —— 风暴本就是"**不鼓励前进**"的信号（`§4`），落在起始区正好当一次**低成本的"该躲了"教学**。

## 三、灰度的玩法影响（生态特性，**不重复天气逻辑**）

以下效果均由**显示灰度**（= `L1 + L2 + L3`）驱动（除特别标注外）：

1. **地貌通行性**：灰度高 → 地面被灰烬沉积物覆盖软化、出现裂隙，车队**移动消耗增加 / 易陷车 / 需绕路**（生态改地貌，非天气）。
2. **腐蚀损耗（耐久）**：灰度高 → 车与装备在路上的**额外每日耐久损耗**递增。示例：显示灰度 ≥ 500 时每日额外 -1 耐久，≥ 700 时额外 -2，≥ 850 时额外 -3（参考值，以平衡为准）。呼应第 7A 类"腐蚀性后遗症"。
3. **感染风险**：**仅当显示灰度 ≥ 700（约七成以上）才有路上感染风险**；低于此无感染。
   - **应对方案**：特定**防护装备**穿戴后可**减免 / 免疫感染风险**；装备模块尚未统一设计（当前全游戏装备仅预留"会有这类东西"的接口，具体名目、占格、数值均待装备系统设计时再定），此处仅预留该机制接口，不写具体装备。
   - **感染后处理**：进入【感染】状态，可在城市**检疫 / 用药包治疗**痊愈（接入第 4A 类状态系统）。
4. **资源构成（只看 L1）**：高 L1 灰区普通货少，但**灰烬特产（灰烬材料 / 火种）富集**——是"换了一种资源"，不是"变稀缺"；中低 L1 灰区反之。该构成**稳定，不受 L2 / L3 影响**。
5. **灰兽概率与强度**：显示灰度越高 → 路上灰兽偶遇概率与强度越高（见第五、七节）。

> 明确**不做**：灰度降视野（那是第 5A 类雾天 / 第 1A 类迷雾的效果）、灰度造成普通物资随机稀缺（与"资源构成稳定"冲突）。

## 四、灰烬风暴（短时天气）

- **定位**：灰烬生态区内**偶发的短时天气**，如同沙漠刮沙尘暴——局部、短期（数天），归第 5A 类天气系统管辖；本节描述其在灰烬生态语境下的行为。
- **与灰度的双向关系**：
  - 风暴期间该区 **L3 天气层 +200**（`§2`），天气段结束即消失 → 显示灰度短期飙升：**后期最深灰区域（`L1 = 750`）遇风暴可达 `750 + 40 + 200 = 990`** —— 这是**世界最高读数**（**仍不到满格**）；
  - **区域灰度（L1）高的区域，灰烬风暴触发概率显著更高**。
- **行为规则（ discourages 前进）**：
  - **中立灰兽**（食腐 / 非攻击性）风暴时**躲藏**；
  - **掠食 / 攻击性灰兽**反而**活跃且强度上扬**；
  - 整体构成"**恶劣天气，不鼓励继续推进**"的信号——引导玩家找避难所或原地度过，**绝不在风暴中给前进奖励**（避免"看到风暴反而冒险冲"的矛盾）。
- 具体天气频率 / 表现归第 5A 类。

## 五、路上灰兽偶遇（概率占格 · 可侦查 · 接触选择）

- **形态**：小股（几只 ~ 十几只）随机遭遇，概率与强度由显示灰度决定。
- **可侦查 · 概率占格（2026-09-14 定）**：灰兽**同样受第 1A 类 §9.7「概率占格」管辖**——**生成是概率**（按灰度 / 事件权重掷骰，决定这一带刷不刷、刷在哪一格），**生成后是占格实体**（看得见、能侦查、能绕开、能打）。通用侦察系统（第 1A 类 §9：迷雾 / 信息等级 / 主动侦察）**对灰兽同样适用**。
  - **原"不做灰兽地图预知"条已作废**（曾被以"避免前期暴毙 + 保留临场抉择"为由写进 v2.1）。**防暴毙改由区域灰度承担**：起始区显示灰度 < 300 几乎无偶遇（见下条）。
  - **情报会过期**：灰兽会随刷新移动 / 消失，侦察看到的是"**一段时间的确定性**"，不是买断（第 1A 类 §9.7 ②）。
- **接触状态（非直接战斗）**：进入有灰兽的格 / 触发偶遇 → 显示"发现 X（种类 / 规模 / 态度）"，**选项随"态度"变**：
  - **友善（共生型，罕见）**：可**安全离开**，也可互动；
  - **中立（食腐型 / 群居迁徙型，较少见）**：可**安全离开（不构成威胁）**，也可**主动攻击**（灰兽会反击，但不追你）；
  - **敌对（掠食型，遭遇中的多数）**：**没有回避选项**——不给逃跑 / 驱离 / 强行通过，**只能进入战斗**（战斗内可撤退，撤退规则见第 4A 类）。
- **遭遇配比（2026-09-12 定）**：**掠食型（敌对）占多数**，食腐 / 群居（中立）较少、共生型（友善）罕见——灰兽属"敌人"这一类，能绕开的太多会让这套机制形同虚设。
- **前期保护落地**：起始区显示灰度 < 300 几乎无偶遇，玩家随深入才遇敌，天然防暴毙。

## 六、偶发单城围攻（守城还原）

- **形态**：偶发某**单座**城市 / 聚落被几十 ~ 几百只灰兽**聚集围攻**。类比象群过路，是兽群受迁徙 / 食物 / 受惊驱动的聚集，**不是"母兽派来的军队"**。
- **性质**：罕见、非定时、非全球；玩家**可介入可路过**——路过不受影响，介入则触发守城。
- **守城（🔴 机制待建 · 引用归档件）**：方向沿用 `90_历史与废案/04_旧权威口径_已过期/城市防守战设计方案.md`，**该方案尚未重建为权威口径**，以下三条是**方向记录、不是现行规则**：
  - 围攻发生在**玩家已复兴激活（节点反应炉已重启）的城市** → 触发**指挥官模式**（用指挥牌，队长不上场，统筹守军）；
  - 围攻发生在**其他城市（路过）** → 玩家作为**援军加入守军**（用普通角色牌组，可选参战）；
  - 成功：城市声望提升 + 守城报酬（金币）+ 灰烬材料 / 火种掉落；失败：撤入城内，损失部分货物，不灭队。
  - **删除旧框架"提前 30 天预警、强制加固城墙、全面防御"流程**——围攻是偶发事件，不是可倒计时准备的考试。

## 七、灰兽分类（生态角色 × 灰度分层，二者合并）

> 灰兽是生态居民，不是"污染怪物大军"。分类主轴用「生态角色」，分布用「灰度分层」，两条轴合并（世界观定义见第 7A 类）。

**按生态角色：**

| 角色 | 行为 / 态度 | **遭遇配比** | 危险度 |
|:----|:----|:----|:----:|
| **掠食型** | 主动猎食（如虎），**敌对** | **多数** | 高 |
| **群居迁徙型** | 像象群，聚集时危险（围城属此类），中立但量大 | 较少 | 中 ~ 高 |
| **食腐清道型** | 吃灰烬沉积物，一般不咬人，中立 | 较少 | 低 |
| **共生型** | 罕见，可理解 / 互动，**友善** | 罕见 | 极低 |

**按灰度分层分布（显示灰度）：**

| 灰度区间 | 主要灰兽 |
|:----:|:----|
| < 300（低灰） | 几乎无灰兽 |
| 300–700（中灰） | 以**被灰烬感染变异的普通野兽**为主（食腐 / 群居多见） |
| > 700（高灰） | 以**灰烬生态自古演化的原生动物**为主（掠食 / 共生多见） |

> ⚠️ **本表是「生态分层」（粗分三档），与 `§2` 的「分区刻度」（细分五档）不是同一张表** —— 生态分层管"**这一带出什么灰兽**"，分区刻度管"**这一带走起来多难受**"（腐蚀 / 感染）。**两者都用「显示灰度」判**，只是切法不同。

- **灰蚀状态**：高灰区接触或战斗中施加的共有环境危险状态，是灰烬"腐蚀性后遗症"的体现，**并非某一类的专属标签**（接入第 4A 类状态系统）。
- 废弃旧「灰蚀兽（变异型）/ 灰渊兽（原生型由能量凝聚）」分区——后者依托已废止的母兽设定，一并作废。

## 八、与玩家的关系（成长驱动）

- 灰兽是生态住户，玩家是访客；进灰区才是闯入者。
- 高灰区有稀缺高价值资源（向往驱动玩家强化装备 / 记忆 / 队伍去淘），而非"再不变强就死"的恐惧。
- 灰烬生态是笼罩一切的环境，影响每一条贸易线——**世界本身就是角色之一**。
