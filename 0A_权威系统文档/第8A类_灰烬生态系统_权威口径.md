# 《余烬商队》第 8A 类：灰烬生态系统 · 权威口径

> 文档状态：权威口径 v2.1（A 级）
> 生效日期：2026-09-07
> 由「第 8A 类_灰兽潮大事件系统」整体重做而来
> 关联系统：第 7A 类（灰烬生态世界观）、第 5A 类（天气系统）、第 4A 类（战斗 / 状态）、第 3A 类（商队资源与耐久）、第 1A 类（侦察 / 迷雾）、第 2A 类（地点 / 城市防守战）

## 一、总定位

灰烬生态系统**不是"事件"**，而是灰烬生态在世界中持续运行的**机制与底色**。它包含三层始终存在于世界中的要素：

- **灰度**：灰烬生态活跃 / 污染程度（0–100），由「地区基准 + 时间波动」两层叠加；
- **灰兽**：灰烬生态中的动物（生态角色 + 灰度分层共同决定），旅途中的自然风险；
- **灰烬风暴**：灰烬生态区内的短时天气现象（类比沙漠沙尘暴）。

**设计原则（与本游戏「孤旅」基调一致）：**

- 不刺激、不压迫：危险是"远方灰兽的动静"那种**存在感**，不是"血条见底"的压迫；
- 无倒计时、无强制准备：灰度可从容观测，灰兽**可避可战**；
- 成长靠"向往"而非"恐惧"：高灰区有稀缺好货，玩家想进去才想变强，**但不逼迫**；
- **不照搬天气层效果**：灰度是长期生态底色，不重复第 5A 类天气的"降视野 / 物资稀缺"逻辑。

> 灰烬的本质（自然生态 + 旧文明实验后遗症）、母兽已废止等世界观设定见第 7A 类，本节不重复定义。

## 二、灰度模型（两层叠加）

灰度不是单一数值，由两层相加而成，玩家在灰度探测仪上只看到**叠加后的结果**：

| 层 | 名称 | 性质 | 作用 |
|:----|:----|:----|:----|
| 基准层 | **地区基准灰度** | 由地图固定，每个区域天生自带（深灰区天生高、旧文明边缘天生低） | 决定该区**资源构成**（稳定，不随时间变） |
| 波动层 | **时间波动灰度** | 每个区域随时间随机游走（如前几天低、最近高、过两天又回落），幅度约 ±15~20 | 让灰度"呼吸"，但不改变资源构成 |

- **显示灰度 = 地区基准灰度 + 时间波动灰度**（限幅 0–100），即灰度探测仪显示并参与战斗 / 损耗计算的值。
- **关键约束**：**资源构成只由「地区基准灰度」决定**，与波动层无关——某区域的货物流通是稳定的，不会随波动层忽好忽坏（详见第三节「资源构成」）。
- **设计注（前期保护）**：起始区域 / 新手区地处旧文明边缘，破坏轻、蔓延少，地区基准灰度低（< 30），天然安全；随贸易深入高灰区才遇强风险。

## 三、灰度的玩法影响（生态特性，不碰天气层）

以下效果均由**显示灰度**驱动（除特别标注外）：

1. **地貌通行性**：灰度高 → 地面被灰烬沉积物覆盖软化、出现裂隙，车队**移动消耗增加 / 易陷车 / 需绕路**（生态改地貌，非天气）。
2. **腐蚀损耗（耐久）**：灰度高 → 车与装备在路上的**额外每日耐久损耗**递增。示例：显示灰度 ≥ 50 时每日额外 -1 耐久，≥ 70 时额外 -2，≥ 85 时额外 -3（参考值，以平衡为准）。呼应第 7A 类"腐蚀性后遗症"。
3. **感染风险**：**仅当显示灰度 ≥ 70（约七成以上）才有路上感染风险**；低于此无感染。
   - **应对方案**：特定**防护装备**穿戴后可**减免 / 免疫感染风险**；装备模块尚未统一设计（当前全游戏装备仅预留"会有这类东西"的接口，具体名目、占格、数值均待装备系统设计时再定），此处仅预留该机制接口，不写具体装备。
   - **感染后处理**：进入【感染】状态，可在城市**检疫 / 用药包治疗**痊愈（接入第 4A 类状态系统）。
4. **资源构成（只看基准层）**：高基准灰区普通货少，但**灰烬特产（灰烬材料 / 火种）富集**——是"换了一种资源"，不是"变稀缺"；中低基准灰区反之。该构成稳定，不受波动层影响。
5. **灰兽概率与强度**：显示灰度越高 → 路上灰兽偶遇概率与强度越高（见第五、七节）。

> 明确**不做**：灰度降视野（那是第 5A 类雾天 / 第 1A 类迷雾的效果）、灰度造成普通物资随机稀缺（与"资源构成稳定"冲突）。

## 四、灰烬风暴（短时天气）

- **定位**：灰烬生态区内**偶发的短时天气**，如同沙漠刮沙尘暴——局部、短期（数天），归第 5A 类天气系统管辖；本节描述其在灰烬生态语境下的行为。
- **与灰度的双向关系**：
  - 风暴期间该区**波动层大幅拉升**（如 +20~30），风暴退去缓慢回落 → 显示灰度短期飙升；
  - **地区基准灰度高的区域，灰烬风暴触发概率显著更高**。
- **行为规则（ discourages 前进）**：
  - **中立灰兽**（食腐 / 非攻击性）风暴时**躲藏**；
  - **掠食 / 攻击性灰兽**反而**活跃且强度上扬**；
  - 整体构成"**恶劣天气，不鼓励继续推进**"的信号——引导玩家找避难所或原地度过，**绝不在风暴中给前进奖励**（避免"看到风暴反而冒险冲"的矛盾）。
- 具体天气频率 / 表现归第 5A 类。

## 五、路上灰兽偶遇（接触选择，不靠地图预知）

- **形态**：小股（几只 ~ 十几只）随机遭遇，概率与强度由显示灰度决定。
- **不提供地图预标**：**不做**"侦察后在地图上标出灰兽活动格"的预知机制（避免前期莫名其妙暴毙、也避免剥夺临场抉择）。通用侦察系统（第 1A 类：迷雾 / 敌情信息）仍用于据点 / 地形，不适用于灰兽预知。
- **接触状态（非直接战斗）**：进入有灰兽的格 / 触发偶遇 → 显示"发现 X（种类 / 规模 / 态度）"，按态度给选项：
  - **中立（非攻击性，如食腐型 / 像路遇几头鹿）**：可**主动离开（安全）**，也可**主动攻击**（灰兽会反击，但不追你）；
  - **敌对（掠食型，如虎类本能猎食）**：可**逃跑**（花额外 AP）、可**驱离**（靠队伍能力：荒野射手标记 / 护路人威慑 / 特定记忆，成功率随能力 + 随灰度降）、可**强行通过**（概率被拦入战）。
- **前期保护落地**：起始区显示灰度 < 30 几乎无偶遇，玩家随深入才遇敌，天然防暴毙。

---

## 六、偶发单城围攻（守城还原）

- **形态**：偶发某**单座**城市 / 聚落被几十 ~ 几百只灰兽**聚集围攻**。类比象群过路，是兽群受迁徙 / 食物 / 受惊驱动的聚集，**不是"母兽派来的军队"**。
- **性质**：罕见、非定时、非全球；玩家**可介入可路过**——路过不受影响，介入则触发守城。
- **守城（还原既有设计，非弱化）**：沿用《城市防守战设计方案》
  - 围攻发生在**玩家已复兴激活（节点反应炉已重启）的城市** → 触发**指挥官模式**（用指挥牌，队长不上场，统筹守军）；
  - 围攻发生在**其他城市（路过）** → 玩家作为**援军加入守军**（用普通角色牌组，可选参战）；
  - 成功：城市声望提升 + 守城报酬（金币）+ 灰烬材料 / 火种掉落；失败：撤入城内，损失部分货物，不灭队。
  - **删除旧框架"提前 30 天预警、强制加固城墙、全面防御"流程**——围攻是偶发事件，不是可倒计时准备的考试。

## 七、灰兽分类（生态角色 × 灰度分层，二者合并）

> 灰兽是生态居民，不是"污染怪物大军"。分类主轴用「生态角色」，分布用「灰度分层」，两条轴合并（世界观定义见第 7A 类）。

**按生态角色：**

| 角色 | 行为 / 态度 | 危险度 |
|:----|:----|:----:|
| **掠食型** | 主动猎食（如虎），敌对态度 | 高 |
| **食腐清道型** | 吃灰烬沉积物，一般不咬人，中立 | 低 |
| **群居迁徙型** | 像象群，聚集时危险（围城属此类），中立但量大 | 中 ~ 高 |
| **共生型** | 罕见，可理解 / 互动 | 极低 |

**按灰度分层分布（显示灰度）：**

| 灰度区间 | 主要灰兽 |
|:----:|:----|
| < 30（低灰） | 几乎无灰兽 |
| 30–70（中灰） | 以**被灰烬感染变异的普通野兽**为主（食腐 / 群居多见） |
| > 70（高灰） | 以**灰烬生态自古演化的原生动物**为主（掠食 / 共生多见） |

- **灰蚀状态**：高灰区接触或战斗中施加的共有环境危险状态，是灰烬"腐蚀性后遗症"的体现，**并非某一类的专属标签**（接入第 4A 类状态系统）。
- 废弃旧「灰蚀兽（变异型）/ 灰渊兽（原生型由能量凝聚）」分区——后者依托已废止的母兽设定，一并作废。

---

## 八、与玩家的关系（成长驱动）

- 灰兽是生态住户，玩家是访客；进灰区才是闯入者。
- 高灰区有稀缺高价值资源（向往驱动玩家强化装备 / 记忆 / 队伍去淘），而非"再不变强就死"的恐惧。
- 灰烬生态是笼罩一切的环境，影响每一条贸易线——**世界本身就是角色之一**。

---

## 九、资源与损耗（参考框架）

> 以下数值为参考值，具体以平衡测试为准，非锁定。

- **偶遇战**：按普通战斗消耗处理（接第 4A 类 / 第 3A 类）。
- **腐蚀损耗**：显示灰度 ≥ 50 起每日额外耐久 -1，随灰度升高递增（见第三节）。
- **感染**：显示灰度 ≥ 70 有路上感染风险；穿戴防护装备免疫；感染后城市检疫 / 药包治愈（见第三节）。
- **围攻守城**：商队耐久损失视规模（轻 ~ 中，非必损毁）；队员重伤概率中等；消耗零件 / 药包 / 补给（参考旧框架：零件约 10、药包约 20，按规模缩放）。

## 十、不做内容

| 内容 | 说明 |
|:----|:----|
| 全球大潮 / 全图覆盖 | 灰兽是局部生态，绝无铺天盖地 |
| 倒计时与强制预警 | 无紧迫感，灰度从容观测 |
| 强制守城准备流程 | 围攻偶发可选，非考试 |
| 母兽及灰渊兽 | 已废止（见第 7A 类废案标注） |
| 强度分级 Boss 化 | 不把灰兽潮写成接近最终 Boss 的事件 |
| 灰渊信徒等关联势力 | 随母兽废止一并作废 |
| 地图预标灰兽活动格 | 不做灰兽专属侦察预知，避免前期暴毙、保留临场抉择 |
| 灰度降视野 / 物资随机稀缺 | 不照搬天气层逻辑；资源构成只看地区基准灰度 |
