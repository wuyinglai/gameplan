## 1. 战斗定位与目标

- **战斗类型**：回合制战术卡牌，**全队共享一个体力池**
- **UI 形式**：队列式 UI，不是棋盘
- **核心目标**：不只是杀敌，还要保护商队、保护货物、避免重伤
- **与杀戮尖塔区别**：
  - 三人小队**共享一个体力池**，不是单角色构筑
  - 三层防御结构
  - 战斗结果会影响大地图旅程
  - 伤害分内伤/外伤，内伤不可阻挡

### 1.1 核心设计红线（最高优先级 · 不可违反）

> ⚠️ **本红线高于一切数值与组合设计。任何新卡牌、新组合、新机制在加入前必须通过本红线审查。**

- **游戏类型约束**：本作是 **RPG（角色养成类）**，不是 Roguelike。玩家一旦获得的卡组 / 构筑会**永久保留**，不会随单局重置。
- **禁止单回合无限出牌**：严禁出现「某组卡组合可在单回合内打出几十 / 上百张牌」的连锁（如 出牌→产牌→再出牌 的指数级滚雪球）。**本作没有"出牌张数上限"** —— 闸门设在另外两处：**① 每回合起手只能选 3 张牌**（2 动作 + 1 记忆，§2.3）；**② 出牌消耗「体力」**，而体力池每回合按出战人数固定（§2.2）。**打出过程中新生成的牌不计入本回合可继续打出**，进入手牌留待下回合。
- **禁止伤害严重溢出**：严禁出现「一击秒全图 / 单回合清场」的溢出组合。单体伤害应有合理上限；**Boss 单独设计**（血量 / 承伤 / 回合结构全独立，见 §8.1），清杂兵靠数值平衡而非无限连。
- **原因**：Roguelike 里无限 combo 是「付出不小成本、且每局重置」的可接受爽点；但本作构筑永久保留，一旦玩家拿到此类 combo，后期将直接平推、整个游戏变得极度无聊。故宁可少给爽点，也绝不放出破坏长期可玩性的连锁。
- **现有守门机制**：§2.3 起手选牌上限 + 手牌每回合清空、§2.2 体力池预算、§2.3.3 零耗卡硬约束（禁攻击 / 禁产牌 / 再选牌必耗体力）正是本红线的落地手段；后续新增内容不得绕过。
- **🔴 出牌口径（2026-09-20 明确）**：**一回合抽 3 张牌 = 2 张动作牌 + 1 张记忆牌，仅此而已** —— 这是**起手抽牌量**，**不是出牌上限**。**回合内出多少牌、抽多少牌都没有任何限制**（把抽牌堆抽完、全打出、再洗一遍再抽再打，重复多少遍都合法），**唯一的约束是体力**。

## 2. 体力系统（原「行动力系统」· **2026-09-20 改口径**）

> 🔴 **术语**：文件里统一写 **「体力」**（不写 AP、不写"费"）。牌的消耗一律写**具体点数**（"消耗 50 点体力"），**不再写"1 费 / 2 费"**。
> 🔴 **模型 = 存量（不是流量）**：体力有**上限**、每回合**回复**、**用不完可以攒**。

### 2.1 基础规则

- **全队共享一个体力池**（谁花都行，一个人可以一次把整池用光）
- 每回合在攻击、防御、治疗、修车之间取舍
- **牌的消耗 = 体力**（原"费"），按效果强度分五档：

| 档 | 消耗 | 用途 |
|:--|--:|:--|
| **微** | **0** | 纯铺垫 / 辅助，**只能**做轻度负面（标记类）、轻度正面（少量护盾 / 小增益）。**禁止伤害、禁止抽牌 / 再选牌 / 加手牌、禁止强负面**（见 §2.3.3 零耗硬约束） |
| **轻** | **25** | 格挡 · 快速射击 · 收招 |
| **标准** | **50** | 常规主力，大部分基础技能（挥砍 / 射击 / 刺击） |
| **重** | **100** | 强力 / 爆发 / 关键技能（重击 · 精确射击 · 盾反 · 重盾防御） |
| **极限** | **150** | 后期大招级（塔盾铁壁 · 终极爆发 · 强 combo 收尾）—— **前期 3 人队一次吃掉全池**，后期人数多了才流畅 |

### 2.2 商队人数与体力池

**出战规则（已定）：战斗出战无上限——商队里所有护卫（战斗成员）都能出战。** 平衡靠护卫日薪（帮工的2倍以上）自然限制，不限制出战人数。

**体力刻度（2026-09-20 定）**：

| 项 | 值 |
|:--|:--|
| **每人基准体力** | **50** |
| **个体差异** | 🔴 **有** —— 与血量同理：**50 只是基准**，不同角色**高于或低于 50**（按招募到的人定）。所以**全队池 = 各人相加**，**不是"50 × 人数"** |
| **每回合回复** | **50 × 出战人数**（个体差异照加，即"每个人回满自己那一份"） |
| **体力上限（存量池）** | **100 × 出战人数**（= 2 倍回复，即**最多攒住一回合的量**） |
| **起手** | **= 上限（满）** |

| 出战人数 | 每回合回复 | 上限 | 相当于几张标准招（50） |
|:--:|--:|--:|:--:|
| 3 人 | 150 | **300** | 3 张 / 回合 · 最多攒 6 张 |
| 4 人 | 200 | 400 | 4 张 / 回合 |
| 5 人 | 250 | 500 | 5 张 / 回合 |

> **为什么刻度从"3 点"放大到"50 点"（2026-09-20）**：旧刻度太粗 —— 池只有 3 点，**任何调整的最小步长就是 1 点 = 池的 33%**，导致"重甲每张牌 +1 体力"这类代价**要么砍掉三分之一（没人穿）、要么没感觉**。放大到 50 之后，**最小步长 1 点 = 2%**，中间地带才存在，加成 / 减益 / 装备差异**全都能落在数值上**。
> **为什么个体差异（2026-09-20）**：体力基准 50 与血量基准 100 是**同一类"人的底子"** —— 有人体力好、有人差。于是**"招募谁"多了一个维度**（血量 / 体力 / 体征 / 卡池），也让"体质差的角色连招都放不利索"变得可表达。
> **"攒"的价值 = 集火，不是变强**：每回合回复总量固定，攒**不出一滴多余的体力**，只是把"两回合的量压进一回合" —— 用来**快速点掉一个敌人**（少挨一回合打）。所以**「每回合打满」（稳）与「憋一波」（爆发）两种打法天然并存**，不需要额外规则去平衡。

**体力池怎么被削减（这就是各种"代价"的落点）**：
- **重甲**：该角色体力上限 / 回复按比例下降（具体值待装备表定）
- **双持 / 高消耗招式**：靠**牌本身的消耗**自然拉开（一半 25、一半 50~100）
- **行军疲劳**（野外接战）：该场**体力上限 ×70%**

### 2.3 每回合选牌（**起手 3 张 · 出牌无上限**）

> 旧版「每回合随机抽 7~11 张」已废除；旧版"Qa/Qm 配额 + AP 闸门"表述**同步作废**。现行口径见下。

- **持有牌（牌池）无上限**：角色能用的所有动作卡 + 记忆卡，数量不设限
- **每回合起手抽 3 张**：**2 张动作牌 + 1 张记忆牌**，从自己牌池里自由选，**选完即定**
- 🔴 **没有出牌上限** —— 抽出来的牌**全部打出**（顺序玩家定）；**回合内出牌数、抽牌数都不受任何限制**（抽完再洗再抽再打，重复多少遍都合法），**唯一的约束是体力池**
- **手牌每回合清空**：回合结束弃掉未用手牌，下回合重新抽（防止「再抽牌」变囤牌引擎）
- **体力当闸门**：每张牌按档收体力（§2.1）；**体力耗尽则本回合不能再出牌**
- **记忆卡不限次**：只按体力收费，无单独冷却

#### 2.3.1 卡牌双层（UI 上下两排）

| 层 | 名称 | 来源 | 定位 |
|:--:|:----|:-----|------|
| 下层 | **动作卡** | 角色自带基础攻击 + 装备（武器 / 护甲）提供 | 普通攻击、防御、修车等 |
| 上层 | **记忆卡** | 知识领域（记忆系统 §5.1）提供 | 赋能 / 铺垫 / 特殊知识 |

#### 2.3.2 组合机制（1+1>2 的来源）

记忆卡做**赋能 / 铺垫**、动作卡做**出手**，可跨角色串：
> 例：射手**标记(0)** → 化学**制毒(记忆，攻击附带中毒状态)** → 护路人**穿甲重击(100 体力)** = 中毒内伤 + 标记增伤 + 穿甲，远超单卡。

#### 2.3.3 零体力卡硬约束（核心：杜绝无限循环）

- 零体力卡**只能是铺垫 / 辅助**：给敌方上轻度负面（标记）、给我方上轻度正面（少量护盾）
- ❌ **禁止攻击牌**（任何直接伤害）
- ❌ **禁止抽牌 / 再抽牌 / 加手牌**（任何增加手牌的牌）
- ❌ 禁止强负面（灼烧 / 强迟滞）
- **原因**：若 0 体力能「再抽 2 张」，玩家带「1 点伤害牌 + 0 耗再抽牌」→ 无限抽无限打。故**任何「再抽牌」牌一律 > 0 体力**，靠体力当闸门，不可能零成本循环。
- ⚠️ **零体力卡仍然占 1 张起手名额**（每回合只有 2 动作 + 1 记忆）→ **不会出现"无限叠盾 / 无限铺标记"**

### 2.4 消耗品消耗体力

在战斗中使用消耗品（药包、零件等）需要消耗体力，**与出牌共用同一个池**：
- 使用药包：消耗 **25 点体力**
- 使用零件修车 / 补甲：消耗 **25 点体力**
- 其他消耗品同理

> 战斗中的**每个行动都要花体力**，包括使用消耗品。这是为了让玩家在"打伤害"、"防御"、"治疗"、"修车"之间做取舍。

## 3. 伤害类型：内伤与外伤

伤害分为两大类：

| 类型 | 说明 | 举例 |
|:----|------|:----|
| **外伤** | 可以被防御阻挡 | 普通攻击、穿甲攻击、灼烧 |
| **内伤** | **不可被防御阻挡**，无视护盾/护甲/屏障 | 流血伤害、已施加的持续伤害 |

> 防御系统只对外伤生效。内伤一旦施加，伤害无法通过防御减免。

## 4. 防御系统

三层防御结构，均只对外伤生效：

| 类型 | 特性 | 持续 | 来源 | 说明 |
|:----|:----|:----:|:----|------|
| **护盾** | 临时防御 | **回合结束清空** | **盾牌卡** | 挡外伤。若完全挡住攻击，可阻止流血施加。🔴 **可给任意队友叠**（不限于自己） |
| **护甲** | **本场战斗内的持久防御** | 直到被打掉（**战毕自动复位**） | **防具**（5 部位） | 只挡普通攻击。不挡穿甲攻击、流血、灼烧 |
| **屏障** | 高级防御 | 直到被打掉 | 旧文明手段 / 特殊物品 | 挡外伤、大多数负面施加。不挡已有流血伤害 |

> **护盾与护甲两条渠道互不混淆**：**护盾只由盾牌提供**（举盾挡住的那一下），**护甲只由防具提供**（穿在身上扛的）。

### 4.1 防护档（敌我通用）

> **"档"= 目标当前的**整体防护水平** —— 不是"甲在不在"的开关，而是一个**状态分级**。
> 🔴 **护盾和护甲都吃这个倍率**：打它的盾、打它的甲、还是打进它的血，**都按它当前所处的档那一列算**（用户 2026-09-18 原话："无论是护甲还是护盾，都造成这个倍率的伤害"）。

| 档 | 判定 | 例 |
|:--|:--|:--|
| **无甲** | 甲值 = **0**（没穿防具，**或甲已被打碎**） | 野兽、破甲后的目标 |
| **软甲** | 甲值 > 0 · 材质 **布 / 皮 / 薄壳** | 强盗 |
| **硬甲** | 甲值 > 0 · 材质 **铁 / 钢 / 灰烬甲壳** | 灰烬兽、重装强盗 |

- **档是动态的**：甲的数值被打碎 → **当场转「无甲」档** → 之后挨打按无甲那一列算。
- **无甲 ≠ 打不动**：无甲单位照样能叠护盾 / 护甲，只是**它自己叠不出多少**（敌人侧写在敌人数值表里；我方是因为没有能撑住的防具）。
- **混穿按最高的那件算**：全布 / 皮 = 软甲；**只要含一件铁或钢 = 硬甲**。

### 4.2 攻击类型与倍率表（**核心机制 · 2026-09-20 定**）

> 你手里拿什么武器，决定你**打什么甲划算**。这是"武器除了数字之外的第二重身份"。

**攻击类型三型（敌我通用）**：

| 类型 | 武器例 |
|:--|:--|
| **打击** | 锤 / 棍 / 钝斧 / **弩** / **火枪** |
| **斩击** | 剑 / 刀 / 斧 |
| **刺击** | 长矛 / 匕首 / **弓** |

**倍率表**：

| 类型 | 对无甲 | 对软甲 | 对硬甲 |
|:--|--:|--:|--:|
| **打击** | ×0.95 | ×1.0 | **×1.3** |
| **斩击** | ×1.1 | **×1.2** | ×0.9 |
| **刺击** | ×1.1 | ×1.0 | ×1.0 |

**三型的性格**：

| 类型 | 性格 | 什么时候带 |
|:--|:--|:--|
| **打击** | 克硬甲，但破甲后垫底（**前半场武器**） | 明知前面是硬壳（灰烬兽） |
| **斩击** | 偏科 —— 克软甲最强，也最怕硬甲 | 打人形敌人（强盗） |
| **刺击** | **中性，不挑敌人** | 情报不足时的省心选项 |

**判定规则**：

- 倍率作用于**整次伤害**（不做溢出分段）—— 🔴 **必须一直算到生命**，不能只打在甲上。否则"甲厚的人总撑得久"，**相性会被厚度吃掉**。
- **只在目标当前"有档"时生效**；甲碎 → 转无甲档。
- **统一作用于 护盾 / 护甲 / 屏障 三层**。
- **穿甲攻击不吃这张表**（它本来就无视护甲）。
- **内伤不吃**（直接进生命）。

**设计约束（防失衡，必须守）**：

| # | 约束 | 理由 |
|:--:|:--|:--|
| 1 | 倍率区间 **×0.9 ~ ×1.3** | 幅度再大就变成"带错武器打不动" = 事实上的硬限制 |
| 2 | 🔴 **打击对无甲必须 < 1.0** | **保险丝** —— 让打击只是"前半场武器"，防止"无脑选打击"变成唯一解 |
| 3 | 三型**整场加权总量齐平**（差 4% 内） | 差异体现在**节奏**（回合数 → 药包消耗），**不在总量** |
| 4 | 敌人的武器类型**必须混着来** | 全是一种，玩家的选择就死了 |

> 🔴 **取消"通用减伤率"**（2026-09-20）：曾经设想过防具给一条无相性的"减伤率"（皮 5% / 铁 10% / 钢 15%）—— **该条作废**。因为它是**纯优乘数**（谁高谁永远更抗打），会把软硬甲的相性差异直接抹平，等于把上面这张表废掉。**防具的差异全部由本节这张倍率表承担。**
> （`第6A类 §11.1` 车辆配件「**装甲板：提升减伤率**」**是车的**，不受本条影响。）

### 4.3 伤害结算顺序（仅外伤）

```
面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率 → 护盾 → 屏障 → 护甲 → 生命
```

> **攻击类型倍率与角色加成都在"整次伤害"这一层**，**扣血之前全部算完**。
> 护盾优先结算，因为护盾过一回合就消失。屏障在护盾之后。

**穿甲攻击**的结算顺序：护盾 → 屏障 → 生命（**无视护甲**）

> 内伤不经过上述结算，直接作用于生命。

### 4.4 护盾（只由盾牌提供）

| 盾 | 占手 | 消耗体力 | 护盾值 |
|:--|:--|:--|:--|
| **小盾** | 1 | **0 ~ 25** | 5~6 / 12 |
| **中盾** | 1 | **50** | 26 |
| **重盾** | 1 | **100** | 55 / 全队 20 × 出战人数 |
| **塔盾** | **2** | **150** | 100 |

- 🔴 **护盾可以给任意队友叠**（不限于自己）—— 这直接决定了"远程必须有人护"：**远程是双手武器，拿不了盾，连自救能力都没有**。
- ⚠️ **0 体力消耗的盾卡仍然占 1 个动作位**（每人每回合只有 2 动作 + 1 记忆）→ 否则 0 耗 + 不占位 = **无限叠盾 = 无敌**。

### 4.5 护甲（只由防具提供）

| # | 条目 | 定法 |
|:--:|:--|:--|
| 1 | **甲值** | **开战赋值**（头 / 躯干 / 手 / 腿 / 足 **5 部位相加**，躯干权重最大）· **战内只减不增** · 甲值归零 = **防具报废** → 同时失去甲值 + 转「无甲」档 |
| 2 | **战毕复位** | **战斗结束自动回满**，不花钱、不占天数、不用修（与"不做装备耐久"一致） |
| 3 | **可补充** | 🔴 **甲在战内并非绝对不可恢复** —— **修补师可用「紧急加固」补甲**（1 点体力 + 1 零件 → 队友 +12 甲） |
| 4 | **完全吸挡** | 本次伤害**被甲完全吸收（无溢出到生命）** → **不施加流血 / 迟滞** |
| 5 | **厚度目标** | **总甲 ≈ 血池 ÷ 3**（≈ 总耐久的 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具数值必须跟着血池一起升级**，否则后期被甩开 |
| 6 | **软硬甲值差 ≤ ~20%** | 例：软 36 ∶ 硬 45（≈80%）—— **别让厚度把相性吃掉** |

> **甲 vs 护盾**：**甲**开战满 / 回合末不清空 / 只给自己 / 战毕复位；**护盾**开战 0 / 回合末清空 / **可给队友** / 每回合能重叠。

## 5. 状态系统

### 5.1 攻击类型状态

> **攻击类型有两个层次**：① **常规三型 —— 打击 / 斩击 / 刺击**（决定"打什么甲划算"，完整倍率表与控制规则见 **§4.2**）；② **特殊攻击类型 —— 穿甲**（无视护甲，见下表）。三型的归属由**武器**决定（剑 = 斩击 · 锤 = 打击 · 弓 = 刺击）。

| 状态 | 类型 | 说明 | 上限 |
|:----|:----|------|:---:|
| **穿甲** | 攻击类型 | 无视护甲的伤害类型（不是状态），**且不吃 §4.2 的倍率表** | — |
| **标记** | 增益/铺垫 | 攻击命中后消耗 1 层，本次伤害 +25%。每击最多消耗 1 层，可连续触发 | **不限** |

### 5.2 持续伤害状态

| 状态 | 类型 | 说明 | 上限 |
|:----|:----|------|:---:|
| **流血** | 持续伤害 | **内伤**。每层 3 伤害，目标每次行动后触发，触发后层数 -1。伤害无视所有防御 | 不限 |
| **灼烧** | 持续伤害 | **外伤**。每层 4 伤害，回合结束触发，触发后层数 -1。可被护盾和屏障挡 | 不限 |

### 5.3 控制与干扰状态

| 状态 | 说明 | 上限 |
|:----|------|:---:|
| **迟滞** | 增加目标**行动失败概率**，对所有行动生效（攻击、治疗、逃跑等）。触发后消耗 1 层。可无限叠加，但最高失败概率 50%，多余层数作为储备 | 不限层数，概率上限 50% |
| **蓄力** | 敌我双方都可拥有的准备状态，多用于敌人强技能预警 | — |
| **狂化** | 敌人强化状态，每层提高伤害。主要用于精英、Boss | — |

## 6. 旧文明武器系统（终极爆发·已定）

**定位：** 大后期终极爆发手段——一击秒精英、重创Boss的超高伤害招式。

### 6.1 世界观

- **记忆 = 旧文明大型武器的操作说明书**（不是武功秘籍——玩家是"看懂说明书"才能操作武器）
- **武器 = 旧文明仪器**（遗迹里找到的大型武器）
- **火种 = 电池**（高密度能量结晶，给武器供电）
- 三者缺一不可：没有说明书不会用，没有武器没得用，没有火种用不了

### 6.2 获取（双重门槛）

| 门槛 | 来源 |
|:-----|:-----|
| 说明书（奥义记忆） | 大后期：遗迹深处 / 灰烬城数据库 / Boss掉落 |
| 武器（旧文明仪器） | 遗迹探索获得 |

### 6.3 发射模式

| 模式 | 消耗 | 威力 |
|:-----|:-----|:-----|
| **弱发射**（免费） | 不消耗火种 | ≈普通攻击，甚至略弱——应急用 |
| **强发射**（终极爆发） | 消耗**火种**（电池） | 超高伤害——一击秒精英、重创Boss |

### 6.4 使用规则

- 战斗中操作武器攻击，**消耗体力**
- 弱发射免费但弱——平时用普通技能，武器是"保险"
- 强发射烧火种——火种同时用于记忆强化，玩家自己权衡（强化记忆 or 攒着放大招）
- 火种稀有 → 大招不能乱放，是战略资源

> 烬油是**城市节点反应炉**的燃料（详见第 7A 类），不属于玩家随身携带的战斗消耗品；战斗侧的能源只剩火种电池。

### 6.5 战场规则型旧文明物品（新增）

> 旧文明特殊物品不止「武器·终极爆发」（§6.1~6.4），新增一类改变整场战斗规则的物品。

- **定位**：消耗火种、持续 N 回合改变整场**战斗规则**、敌我双方都吃
- **例**：毒雾场——带中毒状态的单位每回合受毒伤，第 N 回合全场爆炸（玩家方中毒也生效）
- **使用门槛**：仅精英 / Boss 战等难度大的战斗使用；普通战斗不需要（不耗火种）
- 与「武器·终极爆发」共用火种资源，玩家权衡（放大招 or 改战场）

## 9. 撤退系统

撤退分为两大类：**战斗撤退**（战斗中）和 **地图撤退**（大地图上）。

### 8.1 战斗撤退

在战斗中可以选择撤退。某些特定 Boss 不可撤退。

#### 判定规则

| 项目 | 规则 |
|:----|:----|
| 出现时机 | **每回合都**可以选择撤退（含战斗开始），**第 3 回合起**开始判定 |
| 基础成功率 | **50%** |
| 判定结果 | 成功→撤离战斗；失败→继续战斗，后续可再次尝试 |

#### 成功率修正

| 影响因素 | 修正 | 说明 |
|:--------|:----:|------|
| Boss 战 | 默认不能普通逃跑 | 剧情允许逃跑的 Boss 战成功率 25%–35% |
| 严重超重 | 无法逃跑 | 超重状态下不能撤退 |
| 敌方平均迟滞 | 提高逃跑成功率 | 逃跑加成 = 向下取整（所有敌人的迟滞失败率之和 ÷ 敌人数量） |

#### 撤退结果

| 项目 | 规则 |
|:----|:----|
| 士气变化 | **-1** |
| 货物 | **不损失货物** |
| 战斗奖励 | **无法获得**（敌人没打完，奖励无法获取） |

### 8.2 敌方逃跑

敌人分为三类：**野兽**、**强盗**、**灰烬兽**。逃跑机制各不相同。

#### 基本规则

- 每个敌人**独立累计**逃跑意愿
- **第 1 回合起**即可开始累计逃跑意愿
- **第 3 回合后**开始判定
- 逃跑意愿达到 **100** → 显示"敌人将要逃跑"提示
- 提示后**第 3 回合**开始判定（玩家有准备时间）
- 判定成功→敌人逃跑；判定失败→继续战斗，后续可再次判定
- **灰烬兽不会逃跑**

#### 逃跑意愿增加

| 条件 | 增加 | 说明 |
|:----|:----:|------|
| 敌方数量少于一半 | +30 | 单次触发 |
| 自身血量低于 50% | +20 | 单次触发 |
| 自身血量低于 30% | +30 | 单次触发 |
| 队友被击杀 | +10 | 每死一个队友触发一次 |
| 精英被击杀 | +30 | 精英死亡时触发 |
| Boss 被击杀 | +50 | Boss 死亡时触发 |
| 野兽初始倾向 | +20 | 野兽天生容易逃跑 |
| 野兽每回合自然累计 | +5/回合 | 仅野兽 |
| 强盗抢到货物 | **+100** | 直接满，立刻准备逃跑 |

> 逃跑意愿**只增不减**。没有减少逃跑意愿的手段。

#### 判定成功率

| 项目 | 数值 |
|:----|:----:|
| 基础成功率 | **50%** |
| 迟滞修正 | 每层迟滞增加行动失败概率（对所有行动生效，逃跑也受迟滞影响） |

#### 逃跑结果

| 结果 | 说明 |
|:----|------|
| 判定成功 | 敌人逃跑，离开战斗 |
| 判定失败 | 敌人继续战斗，后续可再次判定 |

### 8.2 地图撤退

地图撤退分为三种情况：

#### ① 主动撤退
玩家在大地图上主动选择撤退：

| 项目 | 规则 |
|:----|:----|
| 触发方式 | 玩家主动选择撤退 |
| 士气变化 | **-2** |
| 货物损失 | **25%** |
| 撤离目标 | 最近的安全点（城市/城镇/驿站） |

#### ② 士气崩溃撤退

| 项目 | 规则 |
|:----|:----|
| 触发条件 | **士气归 0** 时自动触发 |
| 士气变化 | 士气已为 0，不额外扣除。到达安全点后**恢复到 1** |
| 货物损失 | **50%** |
| 撤离目标 | 最近的安全点（城市/城镇/驿站） |

#### ③ 全员重伤 + 商队耐久归零（强制撤退）

| 项目 | 规则 |
|:----|:----|
| 触发条件 | **全队倒下 + 商队耐久归 0** 时强制触发 |
| 士气变化 | 到达安全点后**恢复到 1** |
| 货物损失 | **75%** |
| 撤离目标 | 最近的安全点（城市/城镇/驿站） |

### 8.3 撤退总表

| 撤退类型 | 分类 | 触发方式 | 货物损失 | 士气 | 能否获得战斗奖励 |
|:--------|:---:|:--------|:--------:|:----:|:--------------:|
| **战斗撤退** | 战斗撤退 | 战斗中选择 | 0% | -1 | ❌ 不能 |
| **主动撤退** | 地图撤退 | 玩家主动 | 25% | -2 | — |
| **士气崩溃撤退** | 地图撤退 | 士气归 0 | 50% | 到达后恢复 1 | — |
| **强制撤退** | 地图撤退 | 全队倒下+耐久归 0 | 75% | 到达后恢复 1 | — |

> 主动撤退惩罚最低，给玩家止损机会。崩溃类撤退代价更高，但不会死档。
