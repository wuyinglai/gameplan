## 5. 记忆系统

### 5.1 基本规则（记忆 = 知识领域，去战斗化）

- 本游戏**没有"技能"这个名词**，统一称为**记忆**
- 记忆是旧文明技术，**完整获得**，要么获得完整记忆，要么不获得
- **不做记忆碎片**、技能碎片、熟练度
- 记忆 = **知识领域**（化学 / 机械 / 草药 / 旧文明语 / 谈判 / 地形学……），**不再是纯战斗技能**
- **一个领域给三类卡**，一条记忆三种用：
  - **战斗卡**（上层记忆卡）：战斗中主动打出（制毒、拆解……）
  - **探索卡**：非战斗被动 / 事件额外选项（破译旧文明装置、配解毒剂）
  - **跑商卡**：非战斗被动 / 讲价加成 / 识破掺假货
- 非战斗场景记忆 = 被动加成或事件选项，**不消耗体力**（战斗场景才是主动卡，见第 4A 类 §2.3.1）

### 5.2 记忆领域槽位（原「出战记忆位」）

| 阶段 | 可植入领域数量 |
|:----|:--------------:|
| 初始 | **8 个** |
| 后期 | 可成长到 **15 个** |

> 重做后「记忆位」= 能同时植入几个知识领域；每个领域提供战斗 / 探索 / 跑商三类卡。

### 5.3 零体力卡硬约束（全局核心约束，已定）

| 项目 | 规则 |
|:----|:------|
| 携带量 | **0 体力记忆不限量、不占领域槽位**（可任意携带） |
| 效果限制 | **必须很弱**——只能做简单铺垫（给目标挂 1 层标记等轻度负面、给我方少量护盾等轻度正面） |
| 禁止效果 | ❌ 不能直接造成伤害（攻击牌）❌ 不能抽牌 / 再抽牌 / 加手牌 ❌ 不能挂强力负面（灼烧、强迟滞等） |
| 🔴 占位 | **仍然占 1 个"起手名额"**（每人每回合只有 2 动作 + 1 记忆）→ **不会出现"0 体力 + 不占位 = 无限叠盾"** |

> 原因：如果 0 体力卡不限量还能抽牌/打伤害/挂强负面，玩家会无脑堆 0 体力破坏平衡；更致命的是「0 体力再抽牌」+「1 点伤害牌」= 无限循环。故**任何「再抽牌 / 抽牌」牌一律消耗体力**（见第 4A 类 §2.3.3），靠**体力池**当闸门，不可能零成本循环。弱效果 + 不限量 = 免费铺垫但不破坏平衡。
> 🔴 **术语（2026-09-20）**：文件里统一写 **「体力」**，牌的消耗写**具体点数**（**微 0 / 轻 25 / 标准 50 / 重 100 / 极限 150**），**不再写"0 费 / 1 费 / 2 费"**。

### 5.4 记忆强化

| 方式 | 说明 |
|:----|------|
| **金币升级（数值升级）** | 提升记忆的基础数值。依赖城市/城镇设施，不做野外随地升级 |
| **金币升级（状态升级）** | 提升状态层数、强度等。比数值升级更贵 |
| **火种升级** | 稀有资源，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机 |
| **记忆推演** | 用多个记忆作素材 + 火种 + 金钱推演出新记忆，原记忆保留不消失（见 §6.4，机制变更 2026-09-09） |

### 5.5 设计红线：记忆获取途径（珍贵资源约束）

> ⚠️ **记忆是珍贵资源，获取途径受红线约束。**

- **严禁刷怪掉落**：记忆**不随机掉落**，尤其**禁止小怪掉落记忆**。普通敌人（野兽 / 强盗 / 灰烬兽小股）只掉普通物资（零件 / 药包 / 货币 / 普通货物），不掉记忆。
- **合理获取途径**：
  - **击败 Boss**：含遗迹 Boss / 最终 Boss（可选）等，是记忆的主要战斗来源之一（接第 4A 类 §6.2 终极武器说明书同口径）。
  - **搜索遗迹**：搜索特定遗迹产出记忆——尤其 **书库 / 研究所 / 学校类遗迹**（知识存量地）搜索产出记忆，机制合理。
  - **旧文明数据库 / 探索事件**：遗迹深处、灰烬城数据库等。
- **原因**：记忆是旧文明知识领域的完整传承，衰败晚期极度稀少；若小怪随便掉，记忆贬值、成长失控，且背离「去废土里淘知识」的探索基调。
- **推演（§6.4）** 是已有记忆的**派生**手段，不改变「原始记忆从何处来」的红线。

## 6. 记忆升级价格

记忆成长主要依赖城镇/城市设施，不做野外随地升级。

### 6.1 数值升级

提升伤害、护盾、治疗、修车等基础数值。

**公式：第 N 次数值升级价格 = 300 + 20 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 300 金 |
| 第 2 次 | 320 金 |
| 第 3 次 | 340 金 |
| 第 10 次 | 480 金 |
| 第 20 次 | 680 金 |

> 不用乘法增长，避免后期升不动。

### 6.2 状态升级

提升标记层数、流血层数、正面状态层数/强度等。

**公式：第 N 次状态升级价格 = 1000 + 200 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 1000 金 |
| 第 2 次 | 1200 金 |
| 第 3 次 | 1400 金 |
| 第 5 次 | 1800 金 |
| 第 10 次 | 2800 金 |

> 状态升级比数值升级贵，因为状态升级通常强于单纯 +1 数值。

### 6.3 火种升级

火种升级独立于普通等级，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机。

| 作用 | 示例 |
|:----|:----|
| 添加词条 | 射箭【重击】 |
| 添加特殊效果 | 射箭【穿甲】 |
| 改变方向 | 治疗箭、车厢盾架 |
| 解锁特殊处理 | 治疗【净毒】、车体修理【加固】 |

### 6.4 记忆推演规则

**设计定位：单一记忆效果有限，推演后 1+1>2——这是玩家打造强力复合记忆的核心途径。**

**机制变更（2026-09-09）：融合 → 推演**
- 旧口径"记忆融合" = 多个记忆合而为一，**原记忆被消耗消失**。
- 新口径"记忆推演" = 以多个记忆为素材 + 消耗火种 + 消耗金钱，在记忆设施上**推演出一个新记忆**；**原记忆不消失、仍保留在角色身上**（相当于"用这几个记忆去推演"，推演完素材记忆仍在——是派生，不是合并）。
- 世界观解释见第 7A 类 §五：当前记忆设施是损坏且简陋的旧机器，推演是其有限能力的体现。

**推演消耗：**
- 素材记忆：参与推演的多个记忆（**原记忆保留，不消耗**）
- 火种：每个推演消耗若干（⚠️ 数量待定，接第 7A 类 §六）
- 金钱：推演费用（同标签 300 / 跨标签 500，见第 2.1 类；⚠️ 初值待实测）

**推演继承规则：**
```
新记忆数值升级点 = 参与推演记忆中最高的数值升级点
新记忆状态升级点 = 参与推演记忆中最高的状态升级点
新记忆普通总等级 = 新记忆数值升级点 + 新记忆状态升级点
```

推演后，新记忆允许玩家在新记忆可用升级项中**重新分配**继承来的升级点。

**推演示例：射击 + 标记 → 精确射击**

假设：
```
射击：数值升级点 5（伤害累积提升）
标记：状态升级点 1（标记从 1 层变 2 层）
```

推演 → 精确射击：
```
数值升级点：5（继承射击）
状态升级点：1（继承标记）
普通总等级：6
```

效果：造成伤害，并施加 2 层标记。

**记忆领域标签与植入限制（接 §5.1 知识领域）：**
- 每个记忆有**领域标签**（如化学 / 机械 / 草药……），对应其所属知识领域。
- 角色有**领域理解标签**（来自职业 / 已植入领域）：只有具备对应领域理解的角色，才能植入该领域标签的记忆。
- 非对应领域标签的角色**无法植入**特定标签记忆（机制限制；世界观原因见第 7A 类 §五）。
- 推演产生的新记忆同样带领域标签，受同一限制约束。

> 高等级伤害记忆不会因为推演被清零（原记忆保留）；已经升级过的状态记忆也不会浪费。

### 6.5 火种词条融合

火种词条融合时原则上尽量保留，但必须通过新记忆词条池检查。

## 7. 重伤系统

### 7.1 基本规则

| 项目 | 规则 |
|:----|:----|
| 生命归零 | 角色退出当前战斗，进入重伤状态 |
| 重伤后 | 该角色不再抽牌，不再使用专属牌 |
| 休养期间 | **不能上场** |
| 战斗终止 | 所有出战队员均重伤退出 + 货车耐久归零，才触发战斗终止 |

### 7.2 重伤分级

| 重伤次数 | 效果 | 恢复时间 |
|:-------:|:----|:--------:|
| 第一次重伤 | 最大生命 -20%，恢复到当前最大生命的 20%（向上取整） | 休养 3 天 |
| 第二次重伤 | 累计最大生命 -50%，恢复到当前最大生命的 20%（向上取整） | 休养 4 天 |
| 第三次重伤（失能） | 不能上场，必须到城市治疗或替换 | 城市治疗 |

> 正常游玩不做永久死亡、不做永久伤残、不做不可逆惩罚。

### 7.3 恢复方式

| 方式 | 效果 |
|:----|:----|
| 自然休养 | 每天恢复进度 +1，达到天数后自动恢复 |
| 驿站/城镇 | 可以加速重伤自然恢复，但不能清除重伤次数，也不能恢复最大生命惩罚 |
| 城市治疗 | 可以治疗一次重伤、二次重伤、失能；统一花费 1 天 + 金币 |
| 补给耗尽 | 重伤恢复天数 +1（不恢复反而恶化） |

### 7.4 城市治疗价格

| 状态 | 价格 |
|:----|:----:|
| 第一次重伤 | 200 金币 |
| 第二次重伤 | 350 金币 |
| 失能 | 500 金币 |
| 整队失能恢复上限 | 总成本不超过 500 金币 |

## 8. 招募与出行规模

### 8.1 招募

| 项目 | 规则 |
|:----|:----|
| 招募方式 | 城市中可以招募新队员（渠道多样，具体后定） |
| 招募总量 | **不限制**可招募的总人数 |
| 出行上限 | **战斗出战无上限**——商队里所有战斗成员都能出战 |
| 招募类型 | 护卫（战斗）、帮工（车夫/杂役）、特殊人员（厨师/账房/修车匠等） |
| 临时雇员 | **不做** |
| 核心成员 | 初始约6~7人（3护卫 + 2~3车夫 + 1~2杂役）为核心成员，不领日薪 |

> 你可以招募很多人，出战人数不设上限。平衡靠护卫日薪（帮工2倍以上）+食物水消耗+车辆载人限制+帮工必须配够自然约束。

### 8.2 出行规模

商队规模按出行人数划分，通过日薪、食物水消耗、车辆载人和车厢空间形成软限制：

| 规模 | 人数 | 每回合体力（回复 / 上限） | 每回合起手抽牌 | 每天食物/水（全队总） | 说明 |
|:---:|:---:|:----------:|:---------:|:------------------:|------|
| **小型出行** | 3 人 | **150 / 300** | **3 张 / 人**（2 动作 + 1 记忆） | 3 份 | 基础配置 |
| **中型出行** | 5 人 | **250 / 500** | **3 张 / 人** | 5 份 | 扩展配置 |
| **大型出行** | 7+ 人 | **350+ / 700+** | **3 张 / 人** | 7+ 份 | 无硬上限 |

> 每多 1 人：**每回合体力回复 +50、上限 +100**、每天食物/水 **+1 份**（整数份，不拆份；详见第 3A 类 §1.3）。
> 🔴 **"起手 3 张"不是出牌上限**（2026-09-20 明确）：它是**每人回合开始抽的牌数**（2 动作 + 1 记忆）；**回合内出牌数、抽牌数都不受任何限制**，**唯一约束是体力池**。细则见第 4A 类 §2.3。
> **体力基准 = 50/人（有个体差异）**，上表按全员 50 估算；实际全队池 = **各人相加**（见第 4A 类 §2.2）。

### 8.3 成员分类（帮工/护卫/特殊人员）

| 类型 | 是否出战 | 说明 |
|:----|:--------:|:-----|
| **帮工**（车夫/杂役） | ❌ | 无特殊效果，便宜；**每次出发必须带够数量**（每车≥1车夫，杂役按人数配），不够有严重负面惩罚（后定） |
| **护卫**（战斗人员） | ✅ 只有护卫能出战 | 如初始3人，能出战 |
| **特殊人员**（厨师/账房/修车匠等） | ❌ | **无统称，直接叫具体职业**，每个提供一种固定被动效果（后定） |

> 硬性分工：只有护卫能出战，帮工/特殊人员不能参战。
> 人员上限：**升级车厢/车辆 → 增加可携带人员上限**。

### 8.4 成员离队与装备回收

| 情况 | 规则 |
|:----|:------|
| 被挖走 | 其他商队/势力可能开出高价挖走雇佣成员 |
| 逃跑 | 士气过低时触发内部事件，某成员可能逃跑 |
| 核心成员 | 不离队 |
| **装备离队回收** | 成员离队（被挖 / 逃跑 / 解雇）时，其身上所有装备**自动退回商队共享库存**——好装备不跟着人走；雇期内可自由调配给他任意好装备 |
| **改造仅核心** | 身体改造轴（§15）**只作用于核心成员**。设计上让**大多数战斗人员都是核心成员**（初始 + 长期），仅少量可雇佣的临时战斗人员不可改造——避免「砸大量资源改造某角色，后期不用了资源白费」 |
| 🔴 **装具可转移**（2026-09-20） | 身体改造已经改为**"可拆卸的装具"**（§15.1）—— 换阵容时**把装具从老角色拆下、装到新人身上**，**投资不丢**。所以"改动一个人"不再是无法回头的决定 |

> 逻辑：核心成员不离队（改造安全）+ 少量雇佣不可改造（即使走也不亏）+ **装具本身可拆卸转移** → **改造投资不浪费**。

## 11. 商队模块与车辆系统

### 11.1 车辆基础

车队由 **货车** 与 **单车** 组成：

| 车辆 | 作用 | 车厢格 | 耐久 | 说明 |
|:----|:--|:--:|:--:|------|
| **货车** | 载货主力 | **300 格/辆** | **60/辆**（计入耐久） | 商队货舱的全部来源；归零抛锚，需修到 **10 以上**才能走 |
| **单车** | 载人（载人车） | **不载货** | **不计耐久** | 满座载人；**不拉货、不计耐久、不被攻击** |

**初始配置：** **4 辆 = 3 辆货车 + 1 辆单车**（14 人随车）。

| 项目 | 数值 |
|:----|:----:|
| 货舱总容量 | 3 × 300 = **900 格**（单车不拉货） |
| 载重上限 | 格数 × 2 = **1800 kg**（临界 2 kg/格） |
| 耐久上限 | 3 × 60 = **180**（**只计货车**） |

> ⚠️ 旧「小型车 64 格 / 中型车 128 格 / 大型车 192 格」三档车型分级**已废**——那是"初始 2 辆 / 128 格"时代的产物，与现行"**每车 300 格**"不符。**现行扩容方式 = 加挂货车。**

#### 扩容（加挂货车）

| 车队 | 配置 | 货舱 | 载重上限 | 耐久上限 |
|:---:|:----|:---:|:---:|:---:|
| **4 辆（初始）** | 3 货车 + 1 单车 | **900 格** | **1800 kg** | **180** |
| +1 辆 | 加挂 1 辆货车 | 1200 格 | 2400 kg | 240 |
| +2 辆 | 加挂 2 辆货车 | 1500 格 | 3000 kg | 300 |

> ⚠️ 加挂货车的**价格与数量上限待定**（旧参考值 4,000 金/辆）；旧"最多 5 辆"是按车型分级定的，现行口径待重定。
> 玩家可自行安排车队规模。车辆本身不可独立装备，所有车共用一个模块系统。

#### 车辆配件

通过城市工坊可以为车辆加装配件：

| 配件 | 效果 | 说明 |
|:----|:----|------|
| **扩容箱** | 增加车厢格 | 安装在车辆上增加容量 |
| **外挂箱** | 增加负重上限 | 提高商队可携带的总重量 |
| **装甲板** | 提升减伤率 | 降低战斗中商队耐久损耗 |
| **加固车架** | 提高商队耐久上限 | 增加商队耐久最大值 |

### 11.2 重量系统

每件物品有重量值，总重量超过商队负重上限时触发超重惩罚。

- **单位 = kg，保留一位小数、允许小于 1**（如 **0.5 kg**）——**界面照原样显示小数**（`0.5`、`1.5`），**不做取整**。
- 重量是**软限制**（超重仍可走，但有惩罚）；**真正的硬限制是车厢格**（第 3A 类）。所以重量用**细粒度**即可，不必刻意凑整数。

| 物品 | 重量（kg） | 备注 |
|:----|:----:|:--|
| 补给（食物 / 水） | **0.5 / 份** | 参考值 |
| 零件 | **1.5 / 个** | 参考值 |
| 药包 | **0.3 / 个** | 参考值 |
| 普通货物 | **0.1 ~ 3.0 / 件** | 视具体货物而定（密度 / 体积差异） |

**负重上限 = 货舱格数 × 2**（现行初始 = 900 格 × 2 = **1800 kg**；**单车不载货、不计入**）。

| 车队 | 货舱 | 负重上限 |
|:----|:--:|:--:|
| 初始（3 货车 + 1 单车） | 900 格 | **1800 kg** |
| 加挂 1 辆货车 | 1200 格 | 2400 kg |
| 加挂 2 辆货车 | 1500 格 | 3000 kg |

> ⚠️ 旧公式「200（初始）+ 100 ×（车辆数 − 2）+ 配件加成」及旧"阶段负重 200 → 2,500"表**已废**——同属"2 辆初始 / 128 格"时代的口径。**配件加成**（扩容箱 / 外挂箱）在此之上另计。

**超重惩罚**（软限制）：
- 超重比例越高，每天额外消耗补给越多
- 超重时商队耐久损耗略微加快
- 可在城市卸货或购买负重配件解决

## 13. 灰烬扩散系统

### 13.1 污染分级

灰烬污染分为三级，从轻度到重度：

| 等级 | 名称 | 说明 |
|:---:|:----|------|
| 1 | **轻度污染** | 货物首次被灰烬污染 |
| 2 | **中度污染** | 被污染货物再次扩散，二次沾染 |
| 3 | **重度污染** | 第三次污染后达到上限，不可再升级 |

### 13.2 扩散规则

- **污染源**向自身周围**一圈**扩散（相邻的货物格子）
- 被污染的货物也会变成新的污染源，继续向周围扩散
- **被污染次数叠加**：第一次污染→轻度，第二次→中度，第三次→重度

#### 扩散周期

| 天气 | 扩散周期 | 说明 |
|:----|:--------:|------|
| 正常天气 | 每 3 天 | 标准扩散速度 |
| 灰烬风 | 每 2 天 | 加速扩散 |
| 灰烬风暴 | **每天** | 最快扩散 |

### 13.3 清除方式

清除按污染等级计费：轻度污染算 **1 倍**，中度算 **2 倍**，重度算 **3 倍**。

| 地点 | 可清除等级 | 参考价格（基数） | 说明 |
|:----|:---------|:--------------:|------|
| **城市** | 轻/中/重度 | **40 金/倍** | 最便宜，但路程远，适合集中处理 |
| **驿站** | 轻/中/重度 | **60 金/倍** | 应急清除，价格适中 |
| **城镇** | 轻/中/重度 | **70 金/倍** | 最贵，应急使用 |

**示例：**
```
一件重度污染货物（3倍）：
  城市清除：40 × 3 = 120 金
  驿站清除：60 × 3 = 180 金
  城镇清除：70 × 3 = 210 金
```

**示例：**
```
一件重度污染货物（3格）在城市净化：30 × 3 = 90 金
同一件在驿站：50 × 3 = 150 金（但驿站不能净化重度）
同一件在城镇：80 × 3 = 240 金（但城镇不能净化重度）
```

### 13.4 阻断扩散

| 方式 | 效果 |
|:----|:------|
| **灰烬封存箱** | 放入其中的货物不会向外扩散污染，也不会被外部污染沾染 |
| **隔离存放** | 将灰烬货物与其他货物分开存放，降低扩散风险 |
| **天气保护** | 灰烬风/灰烬风暴期间加速扩散，应尽快处理污染源 |

| 内容 | 说明 |
|:----|:-----|
| 死亡系统 | 角色不会永久死亡 |
| 永久伤残 | 不做永久不可逆惩罚 |
| 经验值/熟练度 | 不做普通 RPG 成长 |
| 记忆碎片 | 记忆完整获得，不做碎片 |
| 临时雇员 | 不做短期雇佣 |
| 单车独立装备 | 商队统一结算 |
| 装备耐久 | 不做装备损耗 |
| 随机词条 | 不做装备随机属性 |
| 传统品质等级 | 不做白绿蓝紫品质 |
| 重伤觉醒 | 不做重伤后获得特殊能力 |
| 野外随地升级 | 记忆成长依赖城市/城镇设施 |
| 无限降费 | 避免破坏体力经济 |
| 无限抽牌 | 避免破坏卡牌经济 |
| 主记忆/副记忆 | 融合不设主副关系 |
| 🔴 **出牌张数上限** | **不做"每回合最多出 X 张"这类闸门** —— 本作的闸门是「**起手只有 3 张**（2 动作 + 1 记忆）」与「**体力池**」；**回合内出牌 / 抽牌完全不受限制** |
| 🔴 **生物·医学术语** | 身体改造一律用**机械·工程语汇**（装具 / 滤芯 / 泵 / 支架），**禁用**摘除 / 移植 / 缝合 / 血肉 / 基因 |
| 🔴 **通用减伤率** | 防具**不给无相性的百分比减伤** —— 它是纯优乘数，会抹平软硬甲的相性差异 |
| 职业装备标签 | 不再用"职业标签"锁装备；改为**体格门槛（硬）+ 熟练无门槛** |

## 14. 角色成长·装备驱动

角色不通过经验值或金币直接升级属性。角色的成长通过**装备驱动**实现。

### 14.1 核心理念（**2026-09-20 重写**）

> 🔴 **旧口径作废**：原 §14.1 写"角色基础数值（生命值、**攻击力**等）**固定不变**"——**作废**。角色的**攻击力不是常数**，它来自**武器面板 + 身体加成**，是会成长的东西。

**伤害从哪来（总链）**：

```
伤害 = 武器面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率
        ↓
依次扣：护盾 → 屏障 → 护甲 → 生命
```

| 谁 | 给什么 | 形式 |
|:--|:--|:--|
| **武器** | **面板**（基础伤害） | **固定数字**（离散、有上限） |
| **招式** | 倍数（挥砍 ×1.0 / 重击 ×1.5） | 乘法 |
| **身体（体征盘）** | **战斗加成** | **百分比** |
| **攻击类型 × 防护档** | 克制倍率 | 乘法（第 4A 类 §4.2） |

> **为什么不用"角色基础攻击力 + 两个加成"**（2026-09-20 用户指出）：基础是常数的话，全部成长都得由两个乘数扛 → 后期两个乘数只能一路往上堆 → **相乘 = 平方增长 → 数值爆炸**。**拆成"面板（离散、有上限）+ 加成（百分比）"各承担一半**，两边都不用涨到夸张。
> **加成幅度的上限**：合计 **≈60%**（与体征盘数值一起定，见 `04 §10.1`）。
> **空手兜底**：**拳打 = 3 面板（打击）** —— 防止"卸下武器卡死"。

### 14.2 武器系统

**一件武器给三样东西**：

| 给什么 | 性质 | 例 |
|:--|:--|:--|
| **动作牌** | 定性 · 不随强化变（武器的"身份"） | 剑 → 挥砍 + 轻格挡；重盾 → 重盾防御；小盾 → 盾反；长矛 → 刺击 |
| **面板** | 定量 · **强化就是强化它** | 钢剑 13 |
| **攻击类型** | 定性 · **决定吃倍率表哪一列** | 剑 = 斩击 · 锤 = 打击 · 弓 = 刺击 |

**面板怎么来**：

> **面板 = 材质基准（绝对）× 种类系数（相对）**

- **材质**：**铁 < 钢 < 旧时代**（高级是低级的上位替代）
- **种类**：决定它在这个基准上坐哪一档
- **招式只写倍数**（挥砍 ×1.0 · 重击 ×1.5 · 横扫 ×0.8 打两个）→ **换一次武器，整组招式一起变强**

**十四种类**：

| 握持 | 种类 | 攻击类型 | 特点 |
|:--|:--|:--|:--|
| **单手**<br>（可配盾 · 可双持） | 匕首 | 刺击 | 面板低 · 体力消耗低 · 易挂流血 |
| | 单手剑 | 斩击 | **基准 1.0** · 均衡 |
| | 单手斧 | 斩击 | 面板稍高 · 附带少量流血 |
| | 单手锤 | 打击 | 面板中低 · 破甲 |
| **双手**<br>（占两手 · 格挡弱） | 长矛 | 刺击 | 面板高 · 不挑敌人 |
| | 双手剑 | 斩击 | 面板很高 |
| | 战锤 | 打击 | **面板最高 · 破甲最强** |
| **远程**<br>（双手 · **零格挡**） | 弓 | 刺击 | 无装填 · 便宜 |
| | 弩 | 刺击 | 装填 1 回合 · 面板高于弓 |
| | 火枪 | 打击 | 装填 1 回合 · 面板最高 · **耗火药** |
| **盾** | 小盾 | — | 0~25 体力 · 护盾 5~6 / 12 |
| | 中盾 | — | 50 体力 · 护盾 26 |
| | 重盾 | — | 100 体力 · 护盾 55 / 可全队 |
| | 塔盾 | — | 占两手 · 150 体力 · 护盾 100 |

**握持五型**：

| 配置 | 占手 | 格挡 | 输出 | 性格 |
|:--|:--|:--|--:|:--|
| 单手 + 盾 | 1+1 | **强** | 1.0 | 稳健、护队友 |
| **双持** | 1+1 | 弱 | 1.0 + α | 灵活（两套卡池）· 体力跨度大 |
| **双手武器** | 2 | 弱 | **≈2.5** | 高伤、笨重 |
| **塔盾** | 2 | 极强 | ~0 | 极限防御 |
| **远程** | 2 | 🔴 **无** | **≈1.5** | **纯输出、零防御** |

- **近战都能格挡**（弱于带盾：例 25 体力 → 5~6 护盾）；🔴 **只有远程完全不能格挡、不能近战** → 拉弓占满两手 → **连自救能力都没有**，只能靠队友叠盾（**护盾可给队友**，见第 4A 类 §4.4）。
- **双持**：左右手各一把单手（或两面盾）→ 解锁**连击牌**；**同类双持**给通用连击，**成套武器**（物品标「套」）给专属牌。
- **远程不做弹药计数系统**（成本并入硬账）；**投掷武器（飞刀 / 投斧 / 燃烧瓶）归消耗品**，不占武器栏。

**攻击类型 × 防护档**（完整表与判定规则见 **第 4A 类 §4.2**）：

| 类型 | 对无甲 | 对软甲 | 对硬甲 |
|:--|--:|--:|--:|
| **打击** | ×0.95 | ×1.0 | **×1.3** |
| **斩击** | ×1.1 | **×1.2** | ×0.9 |
| **刺击** | ×1.1 | ×1.0 | ×1.0 |

**其余规则不变**：**不设攻速**、**强化 = 灰烬材料 + 火种 + 金币**、**强化只提数值不改核心特点**、**武器对特定记忆有加成**（如重锤对【重击】+15%——保留，这是"武器 × 记忆"构筑的核心）。

### 14.3 护甲系统

**防具（5 部位：头 / 躯干 / 手 / 腿 / 足）给三样东西**：

| 给什么 | 内容 |
|:--|:--|
| **① 甲值** | **开战一次性赋值**（各部位相加，躯干权重最大）· **本场战斗内持久、不随回合清空** · 只减不增 · **战毕自动复位** |
| **② 防护档** | 材质定 **软甲**（布 / 皮）或 **硬甲**（铁 / 钢）→ **决定敌人打你时吃倍率表哪一列** |
| **③ 体重代价** | 重甲影响**野外体力**（每格消耗）/ 战斗体力（具体值随装备表定） |

**批次规则**：

- **材料是升级轴**：**皮甲 < 铁甲 < 钢甲**（高级是低级的上位替代，花钱买更好天经地义）
- **软 / 硬是取向轴**：**软甲不怕打击、怕斩击；硬甲不怕斩击、怕打击** —— **两者永不互相淘汰**（"哪件甲更好"没有通解，答案取决于对面拿什么武器）
- **甲值差距压到 ≤ ~20%**（软 36 ∶ 硬 45）：**别让厚度把相性吃掉**
- 🔴 **不做"通用减伤率"**（2026-09-20 作废）：它是纯优乘数（谁高谁永远更抗打），会把软硬甲的相性抹平。**防具差异全部由攻击类型倍率表承担。**
- **甲归零 = 防具报废** → 同时失去甲值 + 转「无甲」档；**修补师可用「紧急加固」补甲**（25 点共享体力 + 1 零件 → 队友 +12 甲）
- **强化方式**同武器：**灰烬材料 + 火种 + 金币**

> **厚度目标**：**总甲 ≈ 血池 ÷ 3**（≈ 总耐久 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具得跟着血池一起升级**，否则后期被甩开。

### 14.4 装备分类与价格

装备分为两类，**不存在品质等级（普通/精良/特殊）的区分**，只有装备本身的差异：

| 类型 | 说明 | 参考价格 | 获取方式 |
|:----|:-----|:--------:|:--------|
| **普通装备** | 当代工艺制造的武器和护甲，各有不同特点 | **约 2,000 金** | 城市购买 |
| **旧时代装备** | 旧文明遗留的高科技装备，效果更强 | **约 6,000 金** | 遗迹探索，**出现概率低**。更稀有的可达 **7,000~8,000 金** |

> 旧时代装备是普通装备的**稀有上位替代**（材料与旧文明技术都更强）；普通装备内部按材料分级也存在上位替代（铁<钢）。三者都可用灰烬材料 + 火种 + 金币强化。

## 15. 身体改造轴（第三成长轴）

> 与记忆轴（§5）、装备轴（§14）并列的第三成长轴。**三轴都是主轴，没有主次。**

### 15.1 定位与边界（**2026-09-20 改口径**）

- 成长三轴：**记忆轴（§5）· 装备轴（§14）· 身体改造轴（本节）**。
- 🔴 **改造 = 加装「可拆卸的装具」，不是"换器官"**（2026-09-18 用户定，**基调红线**）：
  - 强化件是**外挂助力装置** —— 像外骨骼那样**接 / 穿**上去，**不是"把肌肉挖出来换掉"**。
  - 因此它**可以完整拆下来、转给另一个人用**（"脱下来给别人穿"）→ **换阵容时改造投资不白费**。
  - 🔴 **禁止恐怖 / 惊悚 / 生物改造感**：一律用 **机械·工程语汇**（装具 / 外骨骼 / 滤芯 / 泵 / 支架 / 护层），**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因）。
- **拆装规则**：拆下 / 装上要收代价（**手术费 / 少量材料损耗**，具体待定）—— 否则改造会变成"免费洗点"，就不存在取舍了。
- **拆装会改变联锁**：从老角色身上拆走一件、装到新人身上，**新人的器官配比就变了**，可能出现"落差 ≥3"的**破口**（见 §15.2）→ 这正是**配装乐趣**：你得给新人配一套平衡的。
- **仅作用于核心成员**（§8.4）：临时雇佣的战斗人员不可改造，防止改造投资随人流失。
- 其余两轴规则不变。

### 15.2 体征盘（改造挂在哪儿）

改造的作用对象是**体征盘**：**8 项 + 血量 = 9 格**，每格 **5 → 15**（与血量 100 → 300 同一根尺子）。完整结构与数值见 `00_Demo开发指南/04 §10.1`。

| 对 | 项 | 装具长什么样 | 管什么 |
|:--|:--|:--|:--|
| **运动** | **动力肌束** | 助力束带 / 上肢助力 | **近战伤害** |
| | **支撑架** | 骨架支撑 | **承载**（落差 ≥3 → 发力自伤） |
| **循环** | **循环助搏泵** | 助搏装置 | **战斗外每日自愈速率** · **体力上限** |
| | **滤尘呼吸器** | 呼吸滤器 | **战斗中每回合的体力回复** |
| **代谢** | **净化滤芯** | 净化滤芯 | 补给消耗 / 恢复（挡"吃进去的脏"） |
| | **解毒滤器** | 解毒滤器 | 体内排毒（扫"已经进来的毒"） |
| **感知** | **反应辅助线路** | 反应线路 | **先手 / 闪避时机** |
| | **防护表皮** | 防护层 | 闪避精度 · 抗感染 / 抗灰蚀 |
| **（独立）** | **血量** | 体魄强化核心 | **单独加点**，**不归心脏** |

**核心机制 = 联锁（不是加点，是配负荷）**：

> **一对落差 ≥ 3 → 弱的那一侧成为"破口"**（主动惩罚）；**强的那侧"单飞"不算罚**，只是"白练"（投了点数没换到主收益）。
> **专精一路 = 强但带一条破口；样样均衡 = 稳但没亮点** → **没有"全能解"**。

> 🔴 **心肺职能（2026-09-20 定）**：**肺 = 战斗中每回合的体力回复** · **心脏 = 体力上限**（+ 战斗外每日自愈）。两者都是"泵"的表现，**不牵强**，也顺手补强了原本偏弱的心脏。

### 15.4 不兼容机制（原「排异」）

- **不兼容率按装具大小定**：微型 **0%** / 小型 **10–20%** / 大型 **40–60%**（⚠️ 初值，实测再锁）。
- **不兼容 ≠ 失败**：不兼容是**这具身体装不上这件**；失败是**技术没做成**（见 15.5）。
- **不兼容后果（轻量、可重试、不永久伤残）**：**装具无效 + 资源白费 + 短暂负面**（休养数天 / 临时 -属性）。绝不影响已完成改造、绝不永久伤残（接「不做永久惩罚」）。

### 15.5 改造结果：六种可能

一次改造落定后，结果分六种，让玩家自己权衡风险：

| 结果 | 说明 |
|:--|:--|
| **成功** | 装具生效，获得效果 |
| **技术失败** | 没做成，资源白费，轻微负面（短时虚弱） |
| **不兼容** | 这具身体接受不了这件装具（见 15.4），轻量可重试 |
| **接口冲突** | 与已装件互斥 / 缺前置 → 无效或需先移除前置（形成 build 多样性，不堆同一项） |
| **感染风险** | 在灰区 / 无高级器械时改造，有灰度感染概率（接第 8A 类感染机制） |
| **副作用** | 成功但附带轻微负面（如支撑架 → 灵活性 -），是 trade-off 非 bug |

### 15.6 接口 / 前置 / 互斥

- 部分装具需前置（如先装体魄强化核心，才能上反应辅助线路）。
- 部分装具互斥（占用同一身体接口）。
- 形成 build 多样性，不堆同一项无脑变强。

### 15.7 资源与显示

- 消耗复用 **灰烬材料 + 火种 + 金币**（与装备强化同源，不另造资源）。
- 改造舱界面显示「本次不兼容率 / 失败率 / 预计恢复 / 兼容性」，玩家自己决定赌不赌基础舱。
- **可拆卸转移** → 换阵容时把装具从老角色拆下、装到新人身上（收拆装费）。

### 15.8 不做内容（身体改造相关）

| 内容 | 说明 |
|:--|:--|
| 永久伤残 / 不可逆惩罚 | 不兼容 / 失败轻量可重试，绝不留永久伤 |
| 改造必成功 | 风险（不兼容 / 失败 / 感染）是机制一部分，不是 bug |
| 堆同一项无脑变强 | 接口 / 前置约束，鼓励 build 多样性 |
| 🔴 **恐怖 / 生物改造感** | **一律机械·工程语汇**；**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因）；强化件**可拆卸、可转给他人** |
