## 5. 记忆系统

### 5.1 基本规则

- 本游戏**没有"技能"这个名词**，统一称为**记忆**
- 记忆是旧文明技术，**完整获得**，要么获得完整记忆，要么不获得
- **不做记忆碎片**、技能碎片、熟练度
- 记忆分为四类：**攻击、防御、辅助、消耗**

### 5.2 出战记忆位

| 阶段 | 可出战记忆位数量 |
|:----|:--------------:|
| 初始 | **8 个** |
| 后期 | 可成长到 **15 个** |

### 5.3 记忆强化

| 方式 | 说明 |
|:----|------|
| **金币升级（数值升级）** | 提升记忆的基础数值。依赖城市/城镇设施，不做野外随地升级 |
| **金币升级（状态升级）** | 提升状态层数、强度等。比数值升级更贵 |
| **火种升级** | 稀有资源，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机 |
| **记忆融合** | 多个记忆融合成新复合记忆 |

## 6. 记忆升级价格

记忆成长主要依赖城镇/城市设施，不做野外随地升级。

### 6.1 数值升级

提升伤害、护盾、治疗、修车等基础数值。

**公式：第 N 次数值升级价格 = 300 + 20 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 300 金 |
| 第 2 次 | 320 金 |
| 第 3 次 | 340 金 |
| 第 10 次 | 480 金 |
| 第 20 次 | 680 金 |

> 不用乘法增长，避免后期升不动。

### 6.2 状态升级

提升标记层数、流血层数、正面状态层数/强度等。

**公式：第 N 次状态升级价格 = 1000 + 200 × (N - 1)**

| 第几次 | 价格 |
|:-----:|:----:|
| 第 1 次 | 1000 金 |
| 第 2 次 | 1200 金 |
| 第 3 次 | 1400 金 |
| 第 5 次 | 1800 金 |
| 第 10 次 | 2800 金 |

> 状态升级比数值升级贵，因为状态升级通常强于单纯 +1 数值。

### 6.3 火种升级

火种升级独立于普通等级，用于添加词条/后缀/特殊效果。每个记忆有自己的火种词条池，不随机。

| 作用 | 示例 |
|:----|:----|
| 添加词条 | 射箭【重击】 |
| 添加特殊效果 | 射箭【穿甲】 |
| 改变方向 | 治疗箭、车厢盾架 |
| 解锁特殊处理 | 治疗【净毒】、车体修理【加固】 |

### 6.4 记忆融合规则

记忆融合**不设主记忆/副记忆**。多个记忆可以融合成新复合记忆。

**融合继承规则：**
```
新记忆数值升级点 = 参与融合记忆中最高的数值升级点
新记忆状态升级点 = 参与融合记忆中最高的状态升级点
新记忆普通总等级 = 新记忆数值升级点 + 新记忆状态升级点
```

融合后，新记忆允许玩家在新记忆可用升级项中**重新分配**继承来的升级点。

**融合示例：射击 + 标记 → 精确射击**

假设：
```
射击：数值升级点 5（伤害累积提升）
标记：状态升级点 1（标记从 1 层变 2 层）
```

融合 → 精确射击：
```
数值升级点：5（继承射击）
状态升级点：1（继承标记）
普通总等级：6
```

效果：造成伤害，并施加 2 层标记。

> 高等级伤害记忆不会因为融合被清零；已经升级过的状态记忆也不会浪费。

### 6.5 火种词条融合

火种词条融合时原则上尽量保留，但必须通过新记忆词条池检查。

## 7. 重伤系统

### 7.1 基本规则

| 项目 | 规则 |
|:----|:----|
| 生命归零 | 角色退出当前战斗，进入重伤状态 |
| 重伤后 | 该角色不再抽牌，不再使用专属牌 |
| 休养期间 | **不能上场** |
| 战斗终止 | 所有出战队员均重伤退出 + 货车耐久归零，才触发战斗终止 |

### 7.2 重伤分级

| 重伤次数 | 效果 | 恢复时间 |
|:-------:|:----|:--------:|
| 第一次重伤 | 最大生命 -20%，恢复到当前最大生命的 20%（向上取整） | 休养 3 天 |
| 第二次重伤 | 累计最大生命 -50%，恢复到当前最大生命的 20%（向上取整） | 休养 4 天 |
| 第三次重伤（失能） | 不能上场，必须到城市治疗或替换 | 城市治疗 |

> 正常游玩不做永久死亡、不做永久伤残、不做不可逆惩罚。

### 7.3 恢复方式

| 方式 | 效果 |
|:----|:----|
| 自然休养 | 每天恢复进度 +1，达到天数后自动恢复 |
| 驿站/城镇 | 可以加速重伤自然恢复，但不能清除重伤次数，也不能恢复最大生命惩罚 |
| 城市治疗 | 可以治疗一次重伤、二次重伤、失能；统一花费 1 天 + 金币 |
| 补给耗尽 | 重伤恢复天数 +1（不恢复反而恶化） |

### 7.4 城市治疗价格

| 状态 | 价格 |
|:----|:----:|
| 第一次重伤 | 200 金币 |
| 第二次重伤 | 350 金币 |
| 失能 | 500 金币 |
| 整队失能恢复上限 | 总成本不超过 500 金币 |

## 9. 能力槽系统

每名角色拥有 **4 个能力槽**：2 个数值被动 + 2 个事件/世界接口。

### 9.1 数值被动

固定生效，不额外叠触发概率：

| 角色 | 词条 | 效果 | 类型 |
|:----|:----|:-----|:----|
| 护路人 | **【护卫】** | 敌对/夜袭/护送/内部恐慌事件中，最差混乱结果权重 ×0.8 | 数值被动 |
| 护路人 | **【护车】** | 货损/抢货/撤退结算中，订单货物/补给/零件的损失权重 ×0.85 | 数值被动 |
| 荒野射手 | **【野外侦察】** | 路线、敌情、痕迹信息等级 +1，初始免费最高到 2 级 | 数值被动 |
| 荒野射手 | **【狩猎采集】** | 自然资源事件中，补给类结果权重 ×1.2 | 数值被动 |
| 修补师 | **【修理知识】** | 修车效率提高（1 零件 +16 耐久，无零件 +5 耐久） | 数值被动 |
| 修补师 | **【现场诊断】** | 结构、车损、普通设备故障信息等级 +1，初始免费最高到 2 级 | 数值被动 |

### 9.2 事件接口

不是常驻主动记忆，只在对应事件中出现额外选项、提示或结果修正：

| 角色 | 接口 | 说明 |
|:----|:----|------|
| 护路人 | **挡在前面** | 遇敌/拦路事件中提供额外保护选项 |
| 护路人 | **维持秩序** | 内部恐慌事件中提供稳定选项 |
| 荒野射手 | **看懂痕迹** | 痕迹/情报事件中提供额外解读选项 |
| 荒野射手 | **野外取食** | 资源事件中获得额外补给选项 |
| 修补师 | **临场修补** | 道路事件/车损事件中提供额外修车选项 |
| 修补师 | **伤病判断** | 伤员恶化事件中提供额外处理选项 |

## 11. 商队模块与车辆系统

### 11.1 车辆基础

车辆分为三种型号，可以在城市工坊购买：

| 车型 | 车厢格 | 负重加成 | 价格 | 说明 |
|:----|:------:|:--------:|:----:|------|
| **小型车** | 8×8 = **64 格** | +200 | **4,000 金** | 基础款，性价比高 |
| **中型车** | 约 **128 格** | +400 | **8,000 金** | 容量翻倍 |
| **大型车** | 约 **192 格** | +600 | **12,000 金** | 容量三倍，最贵 |

**初始配置：** 2 辆小型车，总容量 128 格，负重上限 200。

#### 购买额外车辆

| 车辆数 | 配置 | 总车厢格 | 总负重 | 累计花费 |
|:-----:|:----|:-------:|:------:|:--------:|
| 2 辆（初始） | 2 小型 | 128 格 | 200 | 免费 |
| 3 辆 | 3 小型 / 1中+2小 | 192~256 格 | 400~600 | 4,000~8,000 金 |
| 4 辆 | 按需搭配 | 256~384 格 | 600~1,000 | 8,000~20,000 金 |
| 5 辆（上限） | 按需搭配 | 320~576 格 | 1,000~1,600 | 12,000~32,000 金 |

> 玩家可以自由搭配车型，例如 1 辆大型车 + 2 辆中型车 + 2 辆小型车。车辆本身不可独立装备，所有车共用一个模块系统。

#### 车辆配件

通过城市工坊可以为车辆加装配件：

| 配件 | 效果 | 说明 |
|:----|:----|------|
| **扩容箱** | 增加车厢格 | 安装在车辆上增加容量 |
| **外挂箱** | 增加负重上限 | 提高商队可携带的总重量 |
| **装甲板** | 提升减伤率 | 降低战斗中商队耐久损耗 |
| **加固车架** | 提高商队耐久上限 | 增加商队耐久最大值 |

### 11.2 重量系统

每件物品有重量值，总重量超过商队负重上限时触发超重惩罚。

| 物品 | 重量 |
|:----|:----:|
| 补给 | 1 |
| 零件 | 2 |
| 药包 | 1 |
| 普通货物 | 视具体而定 |

**负重上限 = 200（初始）+ 100 ×（车辆数 - 2）+ 配件加成**

| 阶段 | 可达负重上限 |
|:----|:-----------:|
| 初始（2 车） | 约 200 |
| 前期（3 车 + 基础配件） | 约 500 |
| 中期（4 车 + 升级配件） | 约 1,000 |
| 后期（5 车 + 高级配件） | 约 2,000~2,500 |

**超重惩罚**（软限制）：
- 超重比例越高，每天额外消耗补给越多
- 超重时商队耐久损耗略微加快
- 可在城市卸货或购买负重配件解决

## 13. 灰烬扩散系统

### 13.1 污染分级

灰烬污染分为三级，从轻度到重度：

| 等级 | 名称 | 说明 |
|:---:|:----|------|
| 1 | **轻度污染** | 货物首次被灰烬污染 |
| 2 | **中度污染** | 被污染货物再次扩散，二次沾染 |
| 3 | **重度污染** | 第三次污染后达到上限，不可再升级 |

### 13.2 扩散规则

- **污染源**向自身周围**一圈**扩散（相邻的货物格子）
- 被污染的货物也会变成新的污染源，继续向周围扩散
- **被污染次数叠加**：第一次污染→轻度，第二次→中度，第三次→重度

#### 扩散周期

| 天气 | 扩散周期 | 说明 |
|:----|:--------:|------|
| 正常天气 | 每 3 天 | 标准扩散速度 |
| 灰烬风 | 每 2 天 | 加速扩散 |
| 灰烬风暴 | **每天** | 最快扩散 |

### 13.3 清除方式

清除按污染等级计费：轻度污染算 **1 倍**，中度算 **2 倍**，重度算 **3 倍**。

| 地点 | 可清除等级 | 参考价格（基数） | 说明 |
|:----|:---------|:--------------:|------|
| **城市** | 轻/中/重度 | **40 金/倍** | 最便宜，但路程远，适合集中处理 |
| **驿站** | 轻/中/重度 | **60 金/倍** | 应急清除，价格适中 |
| **城镇** | 轻/中/重度 | **70 金/倍** | 最贵，应急使用 |

**示例：**
```
一件重度污染货物（3倍）：
  城市清除：40 × 3 = 120 金
  驿站清除：60 × 3 = 180 金
  城镇清除：70 × 3 = 210 金
```

**示例：**
```
一件重度污染货物（3格）在城市净化：30 × 3 = 90 金
同一件在驿站：50 × 3 = 150 金（但驿站不能净化重度）
同一件在城镇：80 × 3 = 240 金（但城镇不能净化重度）
```

### 13.4 阻断扩散

| 方式 | 效果 |
|:----|:------|
| **灰烬封存箱** | 放入其中的货物不会向外扩散污染，也不会被外部污染沾染 |
| **隔离存放** | 将灰烬货物与其他货物分开存放，降低扩散风险 |
| **天气保护** | 灰烬风/灰烬风暴期间加速扩散，应尽快处理污染源 |

| 内容 | 说明 |
|:----|:-----|
| 死亡系统 | 角色不会永久死亡 |
| 永久伤残 | 不做永久不可逆惩罚 |
| 经验值/熟练度 | 不做普通 RPG 成长 |
| 记忆碎片 | 记忆完整获得，不做碎片 |
| 临时雇员 | 不做短期雇佣 |
| 单车独立装备 | 商队统一结算 |
| 装备耐久 | 不做装备损耗 |
| 随机词条 | 不做装备随机属性 |
| 传统品质等级 | 不做白绿蓝紫品质 |
| 重伤觉醒 | 不做重伤后获得特殊能力 |
| 野外随地升级 | 记忆成长依赖城市/城镇设施 |
| 无限降费 | 避免破坏行动力经济 |
| 无限抽牌 | 避免破坏卡牌经济 |
| 主记忆/副记忆 | 融合不设主副关系 |

## 14. 角色成长·装备驱动

角色不通过经验值或金币直接升级属性。角色的成长通过**装备驱动**实现。

### 13.1 核心理念

- 角色基础数值（生命值、攻击力等）**固定不变**
- 角色的变强主要依靠**更好的装备**和**更强的记忆**
- 每件装备都有自己的特点，**不存在某把武器是另一把的完全上位替代**

### 13.2 武器系统

| 项目 | 规则 |
|:----|:-----|
| 武器定位 | 每把武器有**独特特点**，初始数值相近 |
| 上位替代 | **不存在**——不会有某把武器完全碾压另一把 |
| 攻速设定 | **不存在**——回合制游戏不设攻速概念 |
| 记忆加成 | 武器对特定类型的记忆有加成。例如重锤对【重击】类记忆伤害+15%，让玩家使用与自己的记忆匹配的武器 |
| 强化方式 | 消耗**灰烬材料 + 火种 + 金币**进行强化 |
| 强化效果 | 提升武器数值，但不改变武器核心特点 |

**示例：**
```
武器 A（弓）：基础伤害 10，对【精确射击】记忆 +15% 伤害
武器 B（重锤）：基础伤害 10，对【重击】记忆 +15% 伤害
→ 两者基础数值相近，但加成方向不同
→ 都可用材料+火种+金币强化
```

### 13.3 护甲系统

同理，护甲也没有上位替代：

| 项目 | 规则 |
|:----|:-----|
| 护甲定位 | 每件护甲有不同侧重（高护甲低抗性、均衡型、轻甲等） |
| 上位替代 | **不存在** |
| 强化方式 | 同武器系统：灰烬材料 + 火种 + 金币 |
| 强化效果 | 提升护甲数值，但不改变核心特点 |

### 13.4 装备分类与价格

装备分为两类，**不存在品质等级（普通/精良/特殊）的区分**，只有装备本身的差异：

| 类型 | 说明 | 参考价格 | 获取方式 |
|:----|:-----|:--------:|:--------|
| **普通装备** | 当代工艺制造的武器和护甲，各有不同特点 | **约 2,000 金** | 城市购买 |
| **旧时代装备** | 旧文明遗留的高科技装备，效果更强 | **约 6,000 金** | 遗迹探索，**出现概率低**。更稀有的可达 **7,000~8,000 金** |

> 旧时代装备不是普通装备的上位替代，只是效果方向不同。两者都可用灰烬材料 + 火种 + 金币强化。
