## 5. 记忆系统

### 5.1 基本规则（记忆 = 知识领域，去战斗化）

- 本游戏**没有"技能"这个名词**，统一称为**记忆**
- 记忆是旧文明技术，**完整获得**，要么获得完整记忆，要么不获得
- **不做记忆碎片**、技能碎片、熟练度
- 记忆 = **知识领域**（化学 / 机械 / 草药 / 旧文明语 / 谈判 / 地形学……），**不再是纯战斗技能**
- **一个领域给三类卡**，一条记忆三种用：
  - **战斗卡**（上层记忆卡）：战斗中主动打出（制毒、拆解……）
  - **探索卡**：非战斗被动 / 事件额外选项（破译旧文明装置、配解毒剂）
  - **跑商卡**：非战斗被动 / 讲价加成 / 识破掺假货
- 非战斗场景记忆 = 被动加成或事件选项，**不消耗体力**（战斗场景才是主动卡，见第 4A 类 §2.3.1）

### 5.2 记忆领域槽位（原「出战记忆位」）

| 阶段 | 可植入领域数量 |
|:----|:--------------:|
| 初始 | **8 个** |
| 后期 | 可成长到 **15 个** |

> ⚠️ **本表数字待重定**（2026-09-24 留待与 §6.2 广度容量一并拍）。**领域槽位 = 一个人能装几门手艺**（数量），**与 §6.2「广度升级」不是一回事**（后者是"某一门手艺里能会几件本事"）。

> 重做后「记忆位」= 能同时植入几个知识领域；每个领域提供战斗 / 探索 / 跑商三类卡。

### 5.3 零体力卡硬约束（全局核心约束，已定）

| 项目 | 规则 |
|:----|:------|
| 携带量 | **0 体力记忆不限量、不占领域槽位**（可任意携带） |
| 效果限制 | **必须很弱**——只能做简单铺垫（给目标挂 1 层标记等轻度负面、给我方少量护盾等轻度正面） |
| 禁止效果 | ❌ 不能直接造成伤害（攻击牌）❌ 不能抽牌 / 再抽牌 / 加手牌 ❌ 不能挂强力负面（灼烧、强迟滞等） |
| 🔴 占位 | **仍然占 1 个"起手名额"**（每人每回合只有 2 动作 + 1 记忆）→ **不会出现"0 体力 + 不占位 = 无限叠盾"** |

> 原因：如果 0 体力卡不限量还能抽牌/打伤害/挂强负面，玩家会无脑堆 0 体力破坏平衡；更致命的是「0 体力再抽牌」+「1 点伤害牌」= 无限循环。故**任何「再抽牌 / 抽牌」牌一律消耗体力**（见第 4A 类 §2.3.3），靠**体力池**当闸门，不可能零成本循环。弱效果 + 不限量 = 免费铺垫但不破坏平衡。
> 🔴 **术语（2026-09-20）**：文件里统一写 **「体力」**，牌的消耗写**具体点数**（**微 0 / 轻 25 / 标准 50 / 重 100 / 极限 150**），**不再写"0 费 / 1 费 / 2 费"**。

### 5.4 记忆成长（**2026-09-24 重写**）

> 🔴 **旧口径已整体作废**（用户 2026-09-24 亲口确认）：原 §5.4「金币数值升级 / 状态升级 / **火种词条池**」＋原 §6「数值升级 300+20×(N−1) / 状态升级 1000+200×(N−1)」**全部作废** —— 那是**本文件交给 AI 之前**写的老稿，记忆系统此后已大改数次，旧升级表不再适用。**现存唯一有效的旧规则 = 「推演」（§6.4 改名保留）。火种词条概念取消。**

#### 5.4.1 三层结构

| 层 | 单位 | 是什么 |
|:--|:--|:--|
| **1. 记忆（领域）** | **一门手艺 / 学科** | 「草药」「机械」「谈判」「地形学」… **不是"卡包"，是"你会的一门本事"** |
| **2. 用途** | 该领域下的**一件具体本事** | 「草药」下有：回血药 / 解毒药 / 驱兽剂… |
| **3. 深度** | 挂在**单个用途**上 | 那个用途的数值（**回血药 10 → 15**） |

#### 5.4.2 成长两轴：广与深

| | **广度升级** | **深度升级** |
|:--|:--|:--|
| **升什么** | 这个领域**多会做一件本事**（解锁新用途） | 这个领域里**某一件事**变强 |
| **粒度** | **领域**（整门手艺） | **用途**（单件，**逐项升**） |
| **草药例** | 只会做回血药 → **学会做解毒药** | **只**升回血药：10 → 15 |
| 🔴 **互不牵连** | —— | **可以只往一个用途上砸，其余用途不受影响**（回血药升到顶，解毒药还是刚会的弱版） |

🔴 **深度是"逐项"的，不是"一升全升"**（用户 2026-09-24 明确纠正）。

#### 5.4.3 用途 ↔ 三类卡

**同一个用途，在战斗里是卡、在事件里是选项**（回扣 §5.1「一个领域三面」）：

| 用途 | 战斗场景 | 探索 / 跑商场景 |
|:--|:--|:--|
| 回血药 | 一张治疗卡 | 野外包扎的选项 |
| 解毒药 | 一张解毒卡 | 喝脏水不闹肚子的选项 |

**深度升级两边一起涨**（本事就是本事，哪儿用都一样强）。

#### 5.4.4 广度从哪里来（三个来源）

| 来源 | 说明 |
|:--|:--|
| **捡** | 遗迹 / Boss / 招募 —— 直接拿到**现成的**领域 |
| **推** | 用已有记忆推演出**遗迹里暂时拿不到的**领域（§6.4） |
| **升** | 广度升级，解锁该领域的**新用途** |

### 5.5 设计红线：记忆获取途径（珍贵资源约束）

> ⚠️ **记忆是珍贵资源，获取途径受红线约束。**

- **严禁刷怪掉落**：记忆**不随机掉落**，尤其**禁止小怪掉落记忆**。普通敌人（野兽 / 强盗 / 灰烬兽小股）只掉普通物资（零件 / 药包 / 货币 / 普通货物），不掉记忆。
- **合理获取途径**：
  - **击败 Boss**：含遗迹 Boss / 最终 Boss（可选）等，是记忆的主要战斗来源之一（接第 4A 类 §6.2 终极武器说明书同口径）。
  - **搜索遗迹**：搜索特定遗迹产出记忆——尤其 **书库 / 研究所 / 学校类遗迹**（知识存量地）搜索产出记忆，机制合理。
  - **旧文明数据库 / 探索事件**：遗迹深处、灰烬城数据库等。
- **原因**：记忆是旧文明知识领域的完整传承，衰败晚期极度稀少；若小怪随便掉，记忆贬值、成长失控，且背离「去废土里淘知识」的探索基调。
- **推演（§6.4）** 是已有记忆的**派生**手段，不改变「原始记忆从何处来」的红线。

## 6. 记忆成长规则

> 🔴 **本章 2026-09-24 整体重写。** 原 §6.1 数值升级（`300 + 20×(N−1)`）· §6.2 状态升级（`1000 + 200×(N−1)`）· §6.3 火种升级（词条池）· 原 §6.5 火种词条融合 —— **全部作废**（老稿，早于记忆系统改版，且**火种词条概念已取消**）。**本章现存唯一沿用自旧稿的是 §6.4「推演」的基本定义**，其余一律按本节新口径。

### 6.1 概览：两条路，一条链

记忆成长只有**两条路**：

| 路 | 名字 | 干什么 | 花什么 |
|:--|:--|:--|:--|
| **变多** | **广度升级** | 领域**多会一件本事**（解锁新用途） | 钱（城镇设施） |
| **变强** | **深度升级** | 领域里**某一件事**变强（10 → 15） | 钱（城镇设施） |
| **派生** | **推演** | 用已有记忆**推演出拿不到的记忆** | 火种 + 钱 |

> **不是三条并行系统，是一条链**：`捡 / 推 / 升` 三个来源 → 都往**同一个领域**里添东西 → 添出来的东西挂在**具体用途**上 → 用途决定那条数值。
> 玩家看到的只有一个东西：**这个领域里我会哪几件事、每件事多强**。

### 6.2 广度升级（解锁新用途）

**提升粒度 = 领域。一次升级 = 该领域 +1 个用途。**

- 例：「草药」原本只会做**回血药** → 广度升级后**学会做解毒药**。
- 新用途**从最弱档起步**（刚会的手艺就是生疏的），深度升级另行追。
- **不增加领域数**——领域是从遗迹 / Boss / 招募**捡**来的，或**推**出来的；广度升级只是把手上这门手艺**打开一点**。
- 领域**容量有限**：每个领域能解锁的用途数**有上限**（⚠️ 具体上限待定，接第 2A 类设施与 §6.4 推演上限），**不能无限广**——否则一个「草药」能通吃所有战斗恢复。

> 🔴 **与「领域槽位」的区别**（防混淆，见 §5.2）：**领域槽位**是"一个人身上能装几门手艺"（数量）；**广度升级**是"某一门手艺里能会几件本事"（深度方向）。两者**不是一回事**。

### 6.3 深度升级（单个用途变强）

**提升粒度 = 用途（单件，逐项升）。**

| 规则 | 说明 |
|:--|:--|
| **逐项独立** | 🔴 深度升级**只升点名的那个用途**——**回血药** 10 → 15 时，同领域的**解毒药不受任何影响**（用户 2026-09-24 明确纠正） |
| **同用途双向涨** | 同一个用途**战斗里是卡 / 事件里是选项**（§5.4.3），深度升级**两边一起涨**——本事就是本事，哪儿用都一样强 |
| **多次叠升** | 同一个用途可以**反复升**（10 → 15 → 20 …），⚠️ 每级加值与等级上限待定（接 `04 §0.1` 锚表 / `23` 公式层） |
| **成本递增** | ⚠️ 同一用途升得越高越贵（具体曲线待定，接 `23`）——防止把钱全砸在一张卡上 |
| **只加数值，不加机制** | 深度升级**纯数值**（伤害 / 层数 / 恢复量 / 成功率…）；**机制变化（改变作用对象、加新效果）归广度与推演**，不归深度 |

> 🔴 **升级存在的理由（用户 2026-09-24 定）**：**必须保留升级**，否则**前中后期数值不在同一个量级**，且玩家会**被迫频繁替换记忆**（"记忆会频繁替换的，那就很不好了"）。升级 = 让已有的好东西**一直跟得上**。

### 6.4 推演

> 定位：**用你能拿到的，换出你拿不到的。** 遗迹里找不到的记忆，可以靠手上已有的**推**出来。

#### 6.4.1 基本定义（沿用旧稿，唯一保留项）

- **推演 = 以多个记忆为素材，推演出一个【新】记忆。**
- 世界观解释见第 7A 类 §五：当前记忆设施是**损坏且简陋的旧机器**，推演是其**有限能力**的体现。
- 旧口径"记忆融合"（**原记忆被消耗消失**）**作废**。

#### 6.4.2 三条硬规则（2026-09-24 用户定）

| # | 规则 | 说明 |
|:--:|:--|:--|
| **1** | 🔴 **素材不消耗，永久保留** | **不是"以旧换新"** —— 旧记忆**不会消失**。推演是**派生**，不是合并；推完素材照旧在角色身上 |
| **2** | 🔴 **链长有限** | 2 个记忆 → 推第 3 个 → 3 个 → 推第 4 个 → …**到某个点就推不动了**（再怎么组合都只出这几条线）→ **不会无限产生新记忆** |
| **3** | 🔴 **必须有线索** | 推演**不能盲试** —— 玩家要能事先知道"**这几个记忆相合，能推出什么**"，否则试错惩罚过重 |

> ⚠️ **链长的具体数字不是铁律**。用户原话是"**我只是做个比喻**"——"4 个"只是举例说明**存在上限**，真实上限由**标签组合表**决定（接 6.4.3）。

#### 6.4.3 线索 = 标签组合表

**线索不是提示文本，是"哪几个标签能配出哪一个标签"的对照表。**

理由：让玩家**预先知道**目标组合，避免"盲试 → 失败 → 惩罚"的挫败感（用户明确要求）。

| 要推的东西 | 需要凑齐的标签 | 例 |
|:--|:--|:--|
| **精确射击** | `射击` + `标记` | 射击（伤害）+ 标记（挂层）→ 打人 + 挂 2 层标记 |
| **群体增益** | `制剂` + `解毒` | 单体回血剂 + 解毒草剂 → 给全队上正面状态 |

> ⚠️ **具体组合表待建**（接第 2A 类设施、第 7A 类世界观）。此处只定**形态**：**标签 → 标签**的映射，玩家可查、可规划。
> **组合表建好后，"链长有限"自动成立**——因为组合表本身就是有限的（每个输出标签只能由固定几种输入凑出，凑不出就是推不动）。

**线索可见性分级**（⚠️ 提案，待实测）：

| 级别 | 玩家看到 |
|:--|:--|
| **基础** | 只有**已拿到**的记忆之间的组合可查 |
| **强化** | 遗迹 / 城市设施可**提前解锁**未持有记忆的组合线索 |

> 这样「推演」和「探索」互相咬合：**多跑一趟遗迹，就多知道一条配方。**

#### 6.4.4 推演消耗

| 项 | 消耗 | 备注 |
|:--|:--|:--|
| **素材记忆** | **不消耗**（6.4.2 规则 1） | 原记忆永久保留 |
| **火种** | 每次消耗若干 | ⚠️ 数量待定，接第 7A 类 §六 |
| **金钱** | 推演费用 | ⚠️ 初值待实测（旧稿 同标签 300 / 跨标签 500 仅作参考，**非约束**） |

> 🔴 **推演不吃升级**：素材记忆上砸的**深度升级一律不丢失**（原记忆还在，升级也还在）。推出来的新记忆是**另一条独立的线**，从它自己的基准值起步（⚠️ 起始基准待定）。
> 原旧稿「推演继承规则」（新记忆继承素材的最高数值升级点 / 状态升级点 / 重新分配升级点）—— **随升级点体系一并作废**，不再有"继承 + 重分配"这回事。

#### 6.4.5 与「广度」的关系

推演**不算**广度升级，但**产出的是新的可用内容**：

| 途径 | 得到什么 | 属于 |
|:--|:--|:--|
| **捡** | 现成的领域（遗迹 / Boss / 招募） | 外部获取 |
| **推** | 遗迹里暂时拿不到的领域 / 用途 | **派生**（本节） |
| **升** | 该领域的新用途（广度升级） | 内部成长 |

> 三条路**并行且都很慢**，玩家要在"**出去找**"和"**在家升**"之间分配时间与钱（用户 2026-09-24 明确要求两线并行）。

### 6.5 领域标签与植入限制

- 每个记忆有**领域标签**（如化学 / 机械 / 草药……），对应其所属知识领域。
- 角色有**领域理解标签**（来自职业 / 已植入领域）：只有具备对应领域理解的角色，才能植入该领域标签的记忆。
- 非对应领域标签的角色**无法植入**特定标签记忆（机制限制；世界观原因见第 7A 类 §五）。
- **推演产生的新记忆同样带领域标签**，受同一限制约束。

## 7. 重伤系统

### 7.1 基本规则

| 项目 | 规则 |
|:----|:----|
| 生命归零 | 角色退出当前战斗，进入**重伤**状态 |
| 重伤后 | 该角色不再抽牌，不再使用专属牌 |
| 恢复期间 | **不能上场**（🔴 到恢复完成为止） |
| 战斗终止 | 🔴 **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）** → 触发强制撤退（见 `第3A类 §5`；2026-10-12 用户裁定，原"全员重伤 + 货车耐久归零"已废） |

> 🔴 **2026-10-12 用户裁定：把"失能"改名为「严重重伤」** —— 原名不好听，且容易被误解为"要死了"。
> 🔴 **术语约定**：**严重重伤 = 全部失去战斗力**（不是濒死）。第一次出现时一律写成「**严重重伤（全部失去战斗力）**」这种**术语 + 括号白话**的形式。

### 7.2 重伤分级（**四级 · 2026-10-12 用户裁定**）

| 重伤次数 | 效果 | 恢复 |
|:-------:|:----|:--------:|
| 第一次**重伤** | 最大生命 **−10%** | **需 3 天恢复** |
| 第二次**重伤（加重）** | 最大生命 **−15%**（**累计 −25%**） | **需 4 天恢复** |
| 第三次**重伤（加重）** | 最大生命 **−25%**（**累计 −50%**） | **需 5 天恢复** |
| 🔴 **第四次** 🔴 **严重重伤（全部失去战斗力）** | 🔴 **完全不能动 · 不能上场** | 🔴 **只能到城市治疗**（野外没有任何手段能救） |

> 🔴 **为什么第四次要单独一级**：前三次**都能靠等待恢复**（只是慢、要付代价），所以**不构成"没救"**；第四次才是**真的动不了** —— 而它**不等于死**，是"**活着，但站不起来**"。
> 🔴 **为什么不是"濒危"**：濒危听起来像"快死了"，但这个状态**不是要死，是失去战力** —— 所以叫「**严重重伤**」。
> ⚠️ **第二第三次显示名相同是有意的** —— 两者**性质一致**（都能动，只是更糟），差别在**数值**，而数值已写在本表里。

> 正常游玩不做永久死亡、不做永久伤残、不做不可逆惩罚。

### 7.3 恢复方式

| 方式 | 效果 |
|:----|:----|
| 🔴 **自动恢复**（2026-10-14 用户裁定） | 🔴 **只要有食物和水，每天自动恢复进度 +1，不需要玩家做任何操作** —— 走不走路都一样 —— 🔴 **只能恢复前三次重伤**（严重重伤不在此列） |
| 🔴 **断粮 / 断水** | 🔴 **恶化一次**（进度倒退，**与 3A §1.6 同一口径**）—— 不是"停止恢复"，是**往回退** |
| 城镇 / 驿站 | 可**加速**恢复进度；但**不能清除重伤次数**，也**不能恢复被削掉的最大生命** |
| 🔴 **大城 / 小城治疗** | 🔴 **唯一能治「严重重伤（全部失去战斗力）」的办法** —— 花 1 天 + 金币（🔴 大城与小城都可以，城镇/驿站/村庄不行，见 `第2A类 §7.5`） |

### 7.4 城市治疗价格

| 状态 | 价格 |
|:----|:----:|
| 第一次重伤 | 200 金币 |
| 第二次重伤 | 350 金币 |
| 严重重伤 | 500 金币 |

> 🔴 **按人数累加，不设整队上限**（2026-10-14 用户裁定）—— 原表「整队严重重伤恢复上限 = 总成本不超过 500」已删：单人严重重伤已是 500 金，整队若也封顶 500，等于多个人只付一个人的钱。
> 🔴 **只有大城 / 小城能治重伤与严重重伤**；价格与地点清单见 `第2A类 §7.5`（**本表不作为价格的家**）。

### 8.1 招募

| 项目 | 规则 |
|:----|:----|
| 招募方式 | 城市中可以招募新队员（渠道多样，具体后定） |
| 招募总量 | **不限制**可招募的总人数 |
| 出行上限 | **战斗出战无上限**——商队里所有战斗成员都能出战 |
| 招募类型 | 护卫（战斗）、**后勤人员**（车夫等）、特殊人员（厨师/账房/修车匠等） |
| 临时雇员 | **不做** |
| 🔴 **核心成员** | 🔴 **初始 14 人全部都是核心成员**（2026-10-06 用户裁定），**不领日薪** |

> 你可以招募很多人，出战人数不设上限。平衡靠护卫日薪（后勤 2 倍以上）+ 食物水消耗 + 车辆载人限制 + **后勤必须配够**自然约束。
> 🔴 **称呼统一**：**只有「后勤人员」一个称呼，没有「杂役」**（全库一律"后勤人员"）。
> 🔴 **核心成员为什么零工资 = 因为"还没被雇佣"**（用户 2026-10-09 给正式解释）：**他们跟着商队走，是因为他们等着被你雇佣**（今天的活干完，下一段路你还可能用他们）——而**商队本来就稀少**（九城之间只剩零星几条路），跟着商队是他们**最赚钱、最稳当的生路**；在**你真正雇佣他们之前**（雇佣 = 建立关系 = 领工资 + 吃商队的粮），**口粮他们自己买、工钱他们不领**。三条疑问由此全部成立（为什么不领工资 / 为什么不消耗 / 为什么跟着你）。同时它也是**「防死档」的结构件**：工资只压在**玩家真正雇佣了的人**身上，而不是开局就背一笔永不缩水的固定开销。详见 `第3A类 §4.5.2`。

### 8.2 出行规模

商队规模按出行人数划分，通过日薪、食物水消耗、车辆载人和车厢空间形成软限制（⚠️ **下表数值为参考值**）：

| 规模 | 人数 | 每回合体力（回复 / 上限） | 每回合起手抽牌 | 每天食物 + 清水（按出战人数） | 说明 |
|:---:|:---:|:----------:|:---------:|:------------------:|------|
| **小型出行** | 3 人 | **150 / 300** | **3 张 / 人**（2 动作 + 1 记忆） | 3 份食物 + 3 份清水 | 基础配置 |
| **中型出行** | 5 人 | **250 / 500** | **3 张 / 人** | 5 份食物 + 5 份清水 | 扩展配置 |
| **大型出行** | 7+ 人 | **350+ / 700+** | **3 张 / 人** | 7+ 份食物 + 7+ 份清水 | 无硬上限 |

> 每多 1 人：**每回合体力回复 +50、上限 +100**、每天食物 **+1 份**、清水 **+1 份**（整数份，不拆份；详见第 3A 类 **§1.5**）。

> 🔴 **"起手 3 张"不是出牌上限**（2026-09-20 明确）：它是**每人回合开始抽的牌数**（2 动作 + 1 记忆）；**回合内出牌数、抽牌数都不受任何限制**，**唯一约束是体力池**。细则见第 4A 类 §2.3。
> **体力基准 = 50/人（有个体差异）**，上表按全员 50 估算；实际全队池 = **各人相加**（见第 4A 类 §2.2）。

### 8.4 出战选择（**没有「离队 / 被挖走」**）

🔴 **2026-10-06 用户裁定：不存在"被挖走""逃跑""减员"。商队人数只增不减。**

| 项目 | 规则 |
|:----|:------|
| **被挖走** | 🔴 **不存在** |
| **逃跑** | 🔴 **不存在** —— 士气低了只是干活变差，不跑 |
| **减员** | 🔴 **不存在** —— 人数只增不减 |
| 🔴 **留在城市** | 🔴 **不存在这个状态** —— **商队走到哪人跟到哪**（没有大本营 / 往返 / 传送），**不存在"把人留在某个城市"** |
| 🔴 **选择出战** | 在**任何城市**都能自由切换谁随队出战斗，**出战无上限** |
| 🔴 **不出战** | 人**还在车队上**，只是这一战没上场：**不领工资**、**不消耗补给**、**不会消失**、**不会老**（理由见下） |
| 🔴 **装备** | **谁出战装备跟谁走**；不出战的人装备在车队库里 |

#### 🔴 为什么不领工资、不消耗补给（2026-10-09 用户给出 · 正式解释）

**一句话：他们跟着你，是因为他们「等着被你雇佣」；在你真正雇佣他们之前，一切费用是他们自己的。**

- **他们为什么跟着商队走**：🔴 **因为他们知道你还会雇佣他们。** 他们不是签了约的雇员，而是**跟着队伍等机会的人** —— 今天的活干完，下一段路你还可能用他们。
- **这是他们的生路**：🔴 **商队本来就稀少**（`第7A类`：九城之间只剩零星几条路，"条数少、人不多、不繁荣"）—— 满世界能让他们赚钱的路子**没几条**，跟着商队是**最赚钱、也最稳当**的一条。
- **所以他们一直跟着你**，不是被绑住，是**在等下一次被雇佣的机会**。
- **为什么不发工资、不消耗补给**：🔴 **因为你还没有雇佣他们。** 雇佣 = 建立关系 = 领工资 + 吃商队的粮；没被雇佣 = **只是跟着走**，所以**口粮他们自己买**、**工钱他们不领** —— 不是克扣，是**还没到那一步**。

> **为什么没有"被挖走"**：玩家在一个角色身上砸了装备、装具、记忆，**还把他排进阵容的核心** —— 结果他被高价挖走，**玩家会非常烦**。这是在惩罚玩家投入，不是在制造决策。
> 🔴 **原两条设计（"装备离队回收" / "加装仅核心"）的前提已消失** —— 它们都是**为了防"人走了装备白费"**才设计的；**人不会走**，所以这两条限制**没有存在的必要**，应当取消。
> 🔴 **装具可转移仍然有效**（2026-09-20 定，§15.1）—— 加装是**可拆卸的装具**，换阵容时拆下来装到新人身上，**投资不丢**。这条与"人不会走"不冲突，是另一回事。

### 11.1 车辆基础

车队由 **货车** 与 **载人车** 组成：

**货车按 `q`（单车格数，锚 A15）分三档规格** —— **买到什么规格，看你到了哪个阶段；旧车不消失，车队天然是混编的**：

| 车型 | 车厢格 `q` | **外挂点**/车 | 耐久 | 说明 |
|:----|:--:|:--:|:--:|------|
| **小型货车** | **300**（前期） | **6** ⚠️ | **60** | 商队货舱的主要来源；归零抛锚，**需修到 20 以上才能走** |
| **中型货车** | **600**（中期） | **10** ⚠️ | **60** | 同上 |
| **大型货车** | **900**（后期） | **14** ⚠️ | **60** | 同上 |
| **小型载人车** | 不载货 | 0 | **不计耐久** | 载人车 · 前期；**不拉货、不计耐久、不被攻击** |
| **大型载人车** | 不载货 | 0 | **不计耐久** | 载人车 · 后期；**不拉货、不计耐久、不被攻击** |

> 🔴 **车辆分两族（2026-10-06 用户裁定）**：**货车族**（小型 / 中型 / 大型，按车厢格数分档）· **载人车族**（**小型 / 大型**，🔴 **不拉货**，只载人）。

> 🔴 **车型 = `q` 的三个档**，**不是"同一队里混装大小车"** —— 前期只能买到小型车、中期中型、后期大型；但**旧车继续在编**，所以车队会自然变成**老车 + 新车**的混编。
> 🔴 **外挂点**（⚠️ 值暂定，原则见 `§11.4`）= **挂外挂箱用的车位**，**随车型走** —— **换车才加挂点**；若让它独立成长，它就变成第二条白送的成长轴。

**初始配置：** **3 辆小型货车**（共 900 格、载 14 人）。

| 项目 | 数值 |
|:----|:----:|
| 货舱总容量 | 3 × 300 = **900 格**（载人车不拉货） |
| 载重上限 | 格数 × 2 = **1800 kg**（临界 2 kg/格） |
| 耐久上限 | 3 × 60 = **180**（**只计货车**） |

> 🔴 **"货舱变大"有三条路，各司其职、量级差一个数量级 —— 别把它们当成一回事**：
> | 路 | 动什么 | 幅度 | 性格 |
> |:--|:--|:--|:--|
> | **① 换车（`q`）** | 车的**规格** | 300 → 600 → 900（**×3**） | **大跳 · 贵 · 一次到位** |
> | **② 加挂货车** | 车队的**规模** | 🔴 **每辆 +`q` 格 / +60 耐久**（**跟着你当期买得到的那档规格**：前 **+300** / 中 **+600** / 后 **+900**） | 多养一辆（多 1 车夫 + 2 后勤） |
> | **③ 装容量箱** | 现有车的**微调** | 每车 **+数十格**（`§11.4`） | **补零头** —— 空间差一点就够，不必换新车 |

|:----|:----|------|

### 11.2 重量系统

每件物品有重量值，总重量超过商队负重上限时触发超重惩罚。

- **单位 = kg，保留一位小数、允许小于 1**（如 **0.5 kg**）——**界面照原样显示小数**（`0.5`、`1.5`），**不做取整**。
- 重量是**软限制**（超重仍可走，但有惩罚）；**真正的硬限制是车厢格**（第 3A 类）。所以重量用**细粒度**即可，不必刻意凑整数。

| 物品 | 重量（kg） | 备注 |
|:----|:----:|:--|
| 补给（食物 / 水） | **0.5 / 份** | 参考值 |
| 零件 | **1.5 / 个** | 参考值 |
| 药包 | **0.3 / 个** | 参考值 |
| 普通货物 | **0.1 ~ 3.0 / 件** | 视具体货物而定（密度 / 体积差异） |

**负重上限 = 货舱格数 × 2**（现行初始 = 900 格 × 2 = **1800 kg**；**载人车不载货、不计入**）。

| 车队 | 货舱 | 负重上限 |
|:----|:--:|:--:|
| 初始（3 辆小型货车） | 900 格 | **1800 kg** |
| 加挂 1 辆货车 | 1200 格 | 2400 kg |
| 加挂 2 辆货车 | 1500 格 | 3000 kg |

> ⚠️ 旧公式「200（初始）+ 100 ×（车辆数 − 2）+ 配件加成」及旧"阶段负重 200 → 2,500"表**已废**——同属"2 辆初始 / 128 格"时代的口径。
> 🔴 **没有"配件加成"这一层**（**2026-09-29 删**）：**负重上限恒 = 货舱格数 × 2**。容量箱（扩容箱 / 外挂箱）加的是**格**，**负重自动跟着涨** —— 再叠一层"配件加成"就是第二根轴，违反"**负重是格的因变量**"这条。

**超重惩罚**（软限制）：
- 超重比例越高，每天额外消耗补给越多
- 超重时商队耐久损耗略微加快
- 可在城市卸货或购买负重配件解决

### 11.3 商队模块栏位

模块既占用模块槽位，也占用车厢空间。玩家需要在"装更多装备"和"留空间带货"之间取舍。

🔴 **2026-10-10 用户裁定：栏位分「共用」与「独立」两类** —— 原设计是"每辆车各自一套槽"，那意味着 **3 辆车 = 24 个槽要管**，纯折磨。改成：

| 栏位类型 | 数量 | 车厢占用 | **取向轴** | 可装内容 | 🔴 **范围** |
|:--------|:---:|:--------:|:--------|:--------|:---:|
| 装甲槽 | ×1 | **不占** | **抗战斗 / 抗路况 / 保货物** | 装甲板、防撞板 | 🔴 **全车队共用** |
| 车载武器槽 | ×1 | **视武器大小** | ⚠️ 无轴（轻/中/重 = 更好的那件，代价见下） | 车载武器（小型占 2~4 格 · 中型 8~12 · 重型 16~20） | **每车一份** |
| 旧时代装备槽 | ×1 | **视装备大小** | ⚠️ 无轴（**是门槛，不是选择**） | 旧文明大型物件（消耗火种激发，效果极强） | **每车一份** |
| 照明/警戒槽 | ×2 | 4 格/个 | **侦察 / 反伏击 / 识别** | 探照灯、警戒装置 | 🔴 **全车队共用** |

| **战术道具槽** | ×3 | 2 格/个 | — | 战术道具（战斗中使用，见 `§12`） | ⚠️ **范围待定** |

#### 划分的理由（一句话）

> **影响「整车耐久 / 防护 / 能见度」的是"结构" → 共用；影响「能装多少、丢多少」的是"货舱" → 独立。**

- 🔴 **共用的**：**买一套，全车队都升级** —— 例：**买一个钢制车轮 → 全车队车轮都变钢制**。
- 🔴 **独立的**：**买一个就是一个** —— 例：外挂箱占的是**每车的外挂点**，本来就一车一份（`§11.4`）。

**为什么照明/警戒要共用**：一车装探照灯、另外两车摸黑 —— 说不通。

#### 🔴 共用件的计价：**按车数计价**（防价格失衡）

> **用户裁定**：「后期可能价格会失衡，比如你买了很多辆车，反而和之前一样便宜。」

**规则**：

| 项目 | 规则 |
|:--|:--|
| **共用件售价** | 🔴 **按车队现有车数 × 单套价** —— 车越多越贵 |
| **买下的效果** | **一套 = 全车队都升级**（不再按车数分别买） |
| **加车后怎么办** | 🔴 **新加入的车默认按当前等级算**（车队标准是"整套"）——**不加价、不倒补差价** |
| **为什么这样** | **玩家仍然能升级车** —— 车多了贵，**但一次买到手就是全车队**；不像"每车各买一份"那样等于被罚 ×车数 |

> ⚠️ **价格数值待定**（归`04` / `23`），**本节只写"按车数计价"这条规则**。
> ⚠️ **耐久上限的算法同步变化**：现在是「每车 60 × 车数」，改部位化后**共用件给的应该是"全车队总耐久 +X"**，不是每车 +X（否则买一个轮子 = 3 辆车各加 X = 翻了 3 倍）。**具体公式留 `23` / `24`。**
> 🔴 **"取向轴" = 这个槽里可选的几条路，且它们互相排斥**。**本节只写"有几条轴"，不写清单** —— 具体哪件、数值多少，**由 `19` 现场配**（与装具盘 `04 §10.2` 同一条做法）。
> 🔴 **判据（照 `04 §9.7` 铁律）**：每件装备**必须有自己的"做不到的事"** —— **同一条轴上的高低不是选择，不同维度上的取舍才是**。
> **有轴（真取舍）**：装甲槽 · 照明/警戒槽 · 环境槽 · 部位升级（**不占槽、不设上限**）。
> **⚠️ 车载武器槽不算轴** —— 轻/中/重是"更好的那件"，它的取舍靠**占格 + 弹药**给（`§11.2` 重量 + 弹药消耗），不靠轴。
> **旧时代装备槽不是选择，是门槛**（终极技三重门槛之一）。
>
> 🔴 **2026-10-14 · 部位系统重做（用户裁定）**：耐久**按四个部位记**（部位表与损坏后果见 `第3A类 §2.2A`）。因此：
> **「车轮」这类配件加的不再是"总体耐久"，而是「**这个部位**的耐久」** —— 换成更好的车轮，**轮子的耐久上限提高**，车的总耐久跟着涨，但**只涨轮子那一份**。
> **四部位四条损耗渠道**：
> - 🔴 **车轮** —— 行驶损耗；损坏 → **车辆无法继续前进**
> - 🔴 **车身** —— 战斗损耗；损坏 → **车辆无法继续前进**
> - 🔴 **车架** —— 地形损耗；损坏 → **走烂路时车轮与车身磨损翻一倍**
> - 🔴 **车篷** —— 天气损耗；损坏 → **雨天或恶劣天气时货物受损**
> 🔴 **原「车体结构槽 ×2 = 五选二」作废** —— 四部位是**每辆车标配**，玩家做的是**升级**（普通件 → 更好的一件），**没有槽位上限、不用放弃谁**。取舍来自**钱**，不来自规则限制。
> ⚠️ **升级几次、升级后效果具体是多少 → 属数值设计**（走 `23` / `24`），本文件只定"每个部位都能独立升级"这条结构。
>
> 同类型/同子类模块互斥。旧时代装备槽消耗火种激发，效果强大但火种稀有。

#### 11.3.1 商队信物（社会模块 · 2026-09-24 新增）

> **与「车辆配件」（§11.1）并列的第二类商队级模块**：车辆配件是**物理模块**（改车），信物是**社会模块**（改世界对你的态度）。
> 🔴 **信物不挂在任何角色名下** —— 它是**商队的对外身份**，**换人不丢 · 全队共享**（车夫 / 后勤人员同样受益）。旧「角色装备栏 · 饰品栏 ×3」**已废**。

**🔴 第一条铁律：信物不提供任何战斗数值，一格都不给。**

它管的是**"人"，不是"命"**：**强盗挡路时有用，野兽 / 灰兽冲上来时完全没用**。
→ 与**装具盘**彻底分开：**装具改你的能力**（身体 · 仅限战斗人员）· **信物改世界的态度**（物品 · 全商队）。**两者永不互相淘汰。**

**四位按「场合」分，不按「件数」分** —— 一个场合一个位（同一场合装两件是**冗余**，不是叠加）：

| 位 | 信物 | 管什么 | **做不到什么** |
|:--|:--|:--|:--|
| **路** | **凭证** | 关卡 / 拦路：降过路费 · 多一个「亮牌子」选项 | 🔴 **对强盗无效**（强盗不认牌子） |
| **野** | **铭牌** | 遗迹 / 旧文明设备：多一个「物品解」选项 | **野外 / 城里都用不上** |
| **队** | **护符** | 队伍状态：内部事件最差结果权重 ×0.85 · **灰度读数** | 🔴 **战斗里一格数值都不给**；🔴 **只读数、不防护** —— 抗灰蚀 / 抗感染走**装具盘**（`§15.2` 防尘罩衣），不归信物 |
| **城** | **城契** | 该城：声望涨得更快 · 解锁专属订单 | **只对那一座城有效** —— 换城即废 |

**唯一的成长位 = 城契**：**1 → 2 → 3**（前 / 中 / 后）；其余三位恒 **1**。

| 阶段 | 凭证 | 铭牌 | 护符 | 城契 | 合计 |
|:--|:--:|:--:|:--:|:--:|:--:|
| 前期 | 1 | 1 | 1 | **1** | **4** |
| 中期 | 1 | 1 | 1 | **2** | **5** |
| 后期 | 1 | 1 | 1 | **3** | **6** |

> **为什么只有城契会长**：一趟只需要一张通行凭证 · 一次只能探一处遗迹 · 队伍只有一个状态 —— 但**你跑的城在变多**（前期 1~2 座 → 后期九座）。**城契 = 你的关系网大小**，且**是长出来的、不是买的**（在某城做够声望，`第10A类 §1.6` → 那座城认你）。
> → 这是与 **`q`（单车格数）· 车数** 并列的**第四条「横向长大」的成长轴**（后期不靠速度，靠"能带的东西"）。

**口径**：

- **不占车厢格**（资质不是货物）—— 与表中"装甲槽 / 环境槽**不占**"同类。
- **两条地基照 `04 §10.2`**：**硬阈值 · 不掷骰** · **永远有保底选项**（不够 = 只能走代价更大的那条）。
  ⚠️ `04 §10.2` 第三条「**只算战斗人员**」是**装具盘专属** —— 信物是**全商队的**，不受此约束。
- 🔴 **本节只写"接口的形状"，不写清单** —— 具体哪件、阈值多少，**在 `19` 事件表现场配**（与装具盘同一条做法）。
- 🟢 **世界会收回它**：城被灰兽攻破（`第8A类`）→ **该城城契作废**；与某城转为敌对 → **城契吊销**。

**解锁类型三足已齐**（`04 §10.2`）：

| 类型 | 载体 | 作用于 |
|:--|:--|:--|
| **知识型** | 记忆 | 你知道什么 |
| **身体型** | 装具盘 | 你身上装了什么（**仅战斗人员**） |
| **物品型** | 🆕 **商队信物** | **你带着什么身份**（**全商队**） |

**与订单系统的接口（它不鸡肋的原因）**：

> **它不决定"你多强"，它决定"这趟你打算怎么走"。**
> 接了什么单、要走什么路 → 才知道该配哪几件：**超长单穿灰烬区** → 护符（灰度读数）+ 铭牌（沿途遗迹是主要收益）；**短途单关卡多** → 凭证。**每件要花钱买，四个位是硬上限 —— 出发前的配装题。**

### 11.4 货舱模块（容量箱 · 功能箱）

**货舱模块不占模块槽**（`§11.3`），**只跟车厢格打交道**。分两族 —— 一个**用格换更多格**，一个**用格换"能装这类货"**。

#### 11.4.1 容量箱（加格）

**"空间差一点就够，不必换一辆新车"** —— 它是 `q` 之上的**微调层**，不是替代层（量级：每车数十格 vs 换车 **+300 格**）。

| 箱 | 装哪 | 净加格 | 代价 |
|:--|:--|:--|:--|
| **扩容箱** | 车**体内** | **低**（**箱体自身有厚度、自己吃格**） | ✅ **安全**，什么货都能装 |
| **外挂箱** | 车**体外**（占**外挂点**） | **高**（不吃内部格） | 🔴 **被劫匪优先抢 · 优先损坏 · 只能放低价值货** |

> **两者正好是"另一种那件"**：一个**安全但低效**、一个**高效但高风险** —— **不是"更好的那件"**。

**🔴 外挂点 = 唯一的闸**：每车的**外挂箱上限**，**随车型走**（小型 **6** / 中型 **10** / 大型 **14** ⚠️ 暂定）。

> ⚠️ **没有这个上限，"装箱"会吃掉"换车"** —— 钱够就无限加格 → `q` 升级当场贬值。
> **值的设计原则**：**满配外挂箱的总加格 ≤ 车本体格数的 40%**（⚠️ 具体值由 `24` 定）。

#### 11.4.2 品质三档（**同一种箱，可靠性不同**）

| 品质 | 价格 | 容量 | 可靠性 |
|:--|:--:|:--:|:--|
| **坚固** | **贵** | **装得少** | ✅ 基本不坏 |
| **标准** | 中 | 中 | 中 |
| **脆弱** | **便宜** | **只能装轻货** | 🔴 **易丢货 · 会自己坏**（见 `§11.4.3`） |

> **"便宜但要担风险 / 贵但省心"** —— 又一条真取舍轴，**不需要任何新概念**。

#### 11.4.3 劣质箱损坏（**挂在 `5A` E2 · R3，不新开事件类型**）

🔴 **脆弱档的箱子会自己坏** —— **这是"便宜"的价格**。

- **判定**：**每走一格判一次**（与事件判定同频，`0A 第5A类 §0`）· 概率**很小**（⚠️ 值由 `24` 定）。
- **事件归属**：**`0A 第5A类 §3.6` E2 道路事件 · `R3 车损/货损风险`**。
- **后果**：箱体破裂 → **部分货物丢失**（**按箱内货量比例掉，不整箱归零**）。

**🔴 补救（必须给 —— 守"惩罚只能要价，不能剥夺"铁律）**：

| 补救 | 花什么 | 效果 |
|:--|:--|:--|
| **停车加固** | **1 天 + 零件** | 该箱**本趟**不再判损坏 |
| **转货** | **0** | 把货挪进**别的箱 / 车厢**，该箱腾空（**空箱不判**） |
| **硬扛** | **0** | 继续走，**继续按原概率判** |

> **永远有保底选项**（转货 / 硬扛都不花资源）—— 与 `04 §10.2` 第三条地基同源。

#### 11.4.4 功能箱（用格换功能）

| 容器 | 用途 |
|:----|------|

| 灰烬封存箱 | 阻断灰烬货向外扩散 |

| 材料箱 | 存放材料 |

#### 11.4.5 🔴 保险箱（**新 · 2026-10-12 用户裁定**）

| 项目 | 规则 |
|:----|:--|
| **作用** | 🔴 **里面的货物在货损中一定不会丢** —— **参与抽签，但抽中不丢** |
| **为什么要它** | 防潮箱 / 药品箱 / 材料箱**各有功能，不是保险** —— 需要专门一类**保护贵重物品** |
| **数量** | 🔴 **固定 1~2 个**（占格）—— **不能多**，否则"撤退不掉东西"变成常态 |
| **用在哪** | 🔴 **撤退货损**（`第3A类 §5.2.3`）—— 抽签时抽到保险箱里的货，**那张不丢** |
| **不保护什么** | ⚠️ **只保货损** —— **不防抢夺**（`第7A类`：劫匪优先抢外挂箱）、**不防损坏**（劣质箱损坏照判） |

> **为什么这个部件有意义**：它把"贵重物品放哪"变成一个**真实决策** —— **占格 + 花钱，但抽中不丢**。配合"货损随机抽签"，玩家会自然地把**碎货放外面、贵货放里面**。
> ⚠️ **具体格数 / 价格**待定（归 `04` / `23`）。

## 13. 灰烬扩散系统

### 13.1 污染分级

灰烬污染分为三级，从轻度到重度：

| 等级 | 名称 | 说明 |
|:---:|:----|------|
| 1 | **轻度污染** | 货物首次被灰烬污染 |
| 2 | **中度污染** | 被污染货物再次扩散，二次沾染 |
| 3 | **重度污染** | 第三次污染后达到上限，不可再升级 |

### 13.2 扩散规则

- **污染源**向自身周围**一圈**扩散（相邻的货物格子）
- 被污染的货物也会变成新的污染源，继续向周围扩散
- **被污染次数叠加**：第一次污染→轻度，第二次→中度，第三次→重度

#### 扩散周期

| 天气 | 扩散周期 | 说明 |
|:----|:--------:|------|
| 正常天气 | 每 3 天 | 标准扩散速度 |
| 灰烬风 | 每 2 天 | 加速扩散 |
| 灰烬风暴 | **每天** | 最快扩散 |

### 13.3 清除方式

清除按污染等级计费：轻度污染算 **1 倍**，中度算 **2 倍**，重度算 **3 倍**。

| 地点 | 可清除等级 | 参考价格（基数） | 说明 |
|:----|:---------|:--------------:|------|
| **城市** | 轻/中/重度 | **40 金/倍** | 最便宜，但路程远，适合集中处理 |
| **驿站** | 轻/中/重度 | **60 金/倍** | 应急清除，价格适中 |
| **城镇** | 轻/中/重度 | **70 金/倍** | 最贵，应急使用 |

**示例：**
```
一件重度污染货物（3倍）：
  城市清除：40 × 3 = 120 金
  驿站清除：60 × 3 = 180 金
  城镇清除：70 × 3 = 210 金
```

> ⚠️ **曾有一个第二示例**写"驿站 / 城镇不能净化重度"且价格为 30 / 50 / 80，**与本表冲突，已删** —— **以本表为准**：三地均可清轻 / 中 / 重度，价差为 **40 / 60 / 70 金/倍**。

### 13.4 阻断扩散

| 方式 | 效果 |
|:----|:------|
| **灰烬封存箱** | 放入其中的货物不会向外扩散污染，也不会被外部污染沾染 |
| **隔离存放** | 将灰烬货物与其他货物分开存放，降低扩散风险 |
| **天气保护** | 灰烬风/灰烬风暴期间加速扩散，应尽快处理污染源 |

## 14. 角色成长·装备驱动

角色不通过经验值或金币直接升级属性。角色的成长通过**装备驱动**实现。

### 14.1 核心理念（**2026-09-20 重写**）

> 🔴 **旧口径作废**：原 §14.1 写"角色基础数值（生命值、**攻击力**等）**固定不变**"——**作废**。角色的**攻击力不是常数**，它来自**武器面板 + 身体加成**，是会成长的东西。

**伤害从哪来（总链）**：

```
伤害 = 武器面板 × 招式倍数 ×（1 + 角色加成%）× 攻击类型倍率
        ↓
依次扣：护盾 → 屏障 → 护甲 → 生命
```

| 谁 | 给什么 | 形式 |
|:--|:--|:--|
| **武器** | **面板**（基础伤害） | **固定数字**（离散、有上限） |
| **招式** | 倍数（挥砍 ×1.0 / 重击 ×1.5） | 乘法 |
| **身体（装具盘）** | **战斗加成** | **百分比** |
| **攻击类型 × 防护档** | 克制倍率 | 乘法（第 4A 类 §4.2） |

> **为什么不用"角色基础攻击力 + 两个加成"**（2026-09-20 用户指出）：基础是常数的话，全部成长都得由两个乘数扛 → 后期两个乘数只能一路往上堆 → **相乘 = 平方增长 → 数值爆炸**。**拆成"面板（离散、有上限）+ 加成（百分比）"各承担一半**，两边都不用涨到夸张。
> **加成幅度的上限**：⚠️ **合计 ≈60% 为 AI 提案，非用户铁律**（用户 2026-09-24 明确：这条是 AI 提的，他只默认，可以改）。数值随装具盘一起定，见 `04 §10.1`。
> **空手兜底**：**拳打 = 3 面板（打击）** —— 防止"卸下武器卡死"。

### 14.2 武器系统

**一件武器给三样东西**：

| 给什么 | 性质 | 例 |
|:--|:--|:--|
| **动作牌** | 定性 · 不随强化变（武器的"身份"） | 剑 → 挥砍 + 轻格挡；重盾 → 重盾防御；小盾 → 盾反；长矛 → 刺击 |
| **面板** | 定量 · **强化就是强化它** | 钢剑 13 |
| **攻击类型** | 定性 · **决定吃倍率表哪一列** | 剑 = 斩击 · 锤 = 打击 · 弓 = 刺击 |

**面板怎么来**：

> **面板 = 材质基准（绝对）× 种类系数（相对）**

- **材质**：**铁 < 钢 < 旧时代**（高级是低级的上位替代）
- **种类**：决定它在这个基准上坐哪一档
- **招式只写倍数**（挥砍 ×1.0 · 重击 ×1.5 · 横扫 ×0.8 打两个）→ **换一次武器，整组招式一起变强**

**十四种类**：

| 握持 | 种类 | 攻击类型 | 特点 |
|:--|:--|:--|:--|
| **单手**<br>（可配盾 · 可双持） | 匕首 | 刺击 | 面板低 · 体力消耗低 · 易挂流血 |
| | 单手剑 | 斩击 | **基准 1.0** · 均衡 |
| | 单手斧 | 斩击 | 面板稍高 · 附带少量流血 |
| | 单手锤 | 打击 | 面板中低 · 破甲 |
| **双手**<br>（占两手 · 格挡弱） | 长矛 | 刺击 | 面板高 · 不挑敌人 |
| | 双手剑 | 斩击 | 面板很高 |
| | 战锤 | 打击 | **面板最高 · 破甲最强** |
| **远程**<br>（双手 · **零格挡**） | 弓 | 刺击 | 无装填 · 便宜 |
| | 弩 | 刺击 | 装填 1 回合 · 面板高于弓 |
| | 火枪 | 打击 | 装填 1 回合 · 面板最高 · **耗火药** |
| **盾** | 小盾 | — | 0~25 体力 · 护盾 5~6 / 12 |
| | 中盾 | — | 50 体力 · 护盾 26 |
| | 重盾 | — | 100 体力 · 护盾 55 / 可全队 |
| | 塔盾 | — | 占两手 · 150 体力 · 护盾 100 |

**握持五型**：

| 配置 | 占手 | 格挡 | 输出 | 性格 |
|:--|:--|:--|--:|:--|
| 单手 + 盾 | 1+1 | **强** | 1.0 | 稳健、护队友 |
| **双持** | 1+1 | 弱 | 1.0 + α | 灵活（两套卡池）· 体力跨度大 |
| **双手武器** | 2 | 弱 | **≈2.5** | 高伤、笨重 |
| **塔盾** | 2 | 极强 | ~0 | 极限防御 |
| **远程** | 2 | 🔴 **无** | **≈1.5** | **纯输出、零防御** |

- **近战都能格挡**（弱于带盾：例 25 体力 → 5~6 护盾）；🔴 **只有远程完全不能格挡、不能近战** → 拉弓占满两手 → **连自救能力都没有**，只能靠队友叠盾（**护盾可给队友**，见第 4A 类 §4.4）。
- **双持**：左右手各一把单手（或两面盾）→ 解锁**连击牌**；**同类双持**给通用连击，**成套武器**（物品标「套」）给专属牌。
- **远程不做弹药计数系统**（成本并入硬账）；**投掷武器（飞刀 / 投斧 / 燃烧瓶）归消耗品**，不占武器栏。

**攻击类型 × 防护档**（完整表与判定规则见 **第 4A 类 §4.2**）：

| 类型 | 对无甲 | 对软甲 | 对硬甲 |
|:--|--:|--:|--:|
| **打击** | ×0.9 | ×1.0 | **×1.3** |
| **斩击** | ×1.1 | **×1.2** | ×0.9 |
| **刺击** | ×1.1 | ×0.9 | ×0.9 |

> 🔴 **2026-10-10 用户裁定**：**打击对无甲 ×0.95 → ×0.9**（"前半场武器"手感更明显）；**刺击 ×1.0 / ×1.0 → ×0.9 / ×0.9**（削弱成"两头都不吃" —— 情报不足时选它是**赌博**而非安全选择）。详见 `第4A类 §4.2`。

**其余规则不变**：**不设攻速**、**强化 = 灰烬材料 + 火种 + 金币**、**强化只提数值不改核心特点**、**武器对特定记忆有加成**（如重锤对【重击】+15%——保留，这是"武器 × 记忆"构筑的核心）。

### 14.3 护甲系统

**防具（5 部位：头 / 躯干 / 手 / 腿 / 足）给三样东西**：

| 给什么 | 内容 |
|:--|:--|
| **① 甲值** | **开战一次性赋值**（各部位相加，躯干权重最大）· **本场战斗内持久、不随回合清空** · 只减不增 · **战毕自动复位** |
| **② 防护档** | 材质定 **软甲**（布 / 皮）或 **硬甲**（铁 / 钢）→ **决定敌人打你时吃倍率表哪一列** |
| **③ 体重代价** | 重甲影响**野外体力**（每格消耗）/ 战斗体力（具体值随装备表定） |

**批次规则**：

- **材料是升级轴**：**皮甲 < 铁甲 < 钢甲**（高级是低级的上位替代，花钱买更好天经地义）
- **软 / 硬是取向轴**：**软甲不怕打击、怕斩击；硬甲不怕斩击、怕打击** —— **两者永不互相淘汰**（"哪件甲更好"没有通解，答案取决于对面拿什么武器）
- **甲值差距压到 ≤ ~20%**（软 36 ∶ 硬 45）：**别让厚度把相性吃掉**
- 🔴 **不做"通用减伤率"**（2026-09-20 作废）：它是纯优乘数（谁高谁永远更抗打），会把软硬甲的相性抹平。**防具差异全部由攻击类型倍率表承担。**
- **甲归零 = 防具报废** → 同时失去甲值 + 转「无甲」档；**修补师可用「紧急加固」补甲**（25 点共享体力 + 1 零件 → 队友 +12 甲）
- **强化方式**同武器：**灰烬材料 + 火种 + 金币**

> **厚度目标**：**总甲 ≈ 血池 ÷ 3**（≈ 总耐久 25%）→ 前期 110 血 ≈ 37 · 中期 200 ≈ 67 · 后期 300 ≈ 100。**防具得跟着血池一起升级**，否则后期被甩开。

### 14.4 装备分类与价格

装备分为两类，**不存在品质等级（普通/精良/特殊）的区分**，只有装备本身的差异：

| 类型 | 说明 | 参考价格 | 获取方式 |
|:----|:-----|:--------:|:--------|
| **普通装备** | 当代工艺制造的武器和护甲，各有不同特点 | **约 2,000 金** | 城市购买 |
| **旧时代装备** | 旧文明遗留的高科技装备，效果更强 | **约 6,000 金** | 遗迹探索，**出现概率低**。更稀有的可达 **7,000~8,000 金** |

> 旧时代装备是普通装备的**稀有上位替代**（材料与旧文明技术都更强）；普通装备内部按材料分级也存在上位替代（铁<钢）。三者都可用灰烬材料 + 火种 + 金币强化。

## 15. 装具轴（第三成长轴）

> 与记忆轴（§5）、装备轴（§14）并列的第三成长轴。**三轴都是主轴，没有主次。**
> 🔴 **本节原名「身体改造轴」（2026-09-24 改称）** —— 改名原因：**"改造"二字自带生物·医学感**，与基调红线冲突。**机制一字未动，只换称谓**。

### 15.1 定位与边界（**2026-09-20 改口径 · 2026-09-24 改称谓**）

- 成长三轴：**记忆轴（§5）· 装备轴（§14）· 装具轴（本节）**。
- 🔴 **加装 = 穿「可拆卸的装具」，不是"换器官"**（2026-09-18 用户定，**基调红线**）：
  - 装具是**外挂助力装置** —— 像外骨骼那样**接 / 穿**上去，**不是"把肌肉挖出来换掉"**。
  - 因此它**可以完整拆下来、转给另一个人用**（"脱下来给别人穿"）→ **换阵容时装具投资不白费**。
  - 🔴 **禁止恐怖 / 惊悚 / 生物改造感**：一律用 **机械·工程语汇**（装具 / 外骨骼 / 支架 / 背心 / 面罩 / 水壶），**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体）。
- **拆装规则**：拆下 / 装上要收代价（**装具台工费 / 少量材料损耗**，具体待定）—— 否则加装会变成"免费洗点"，就不存在取舍了。
- **拆装会改变联锁**：从老角色身上拆走一件、装到新人身上，**新人的配比就变了**，可能出现"落差 ≥3"的**破口**（见 §15.2）→ 这正是**配装乐趣**：你得给新人配一套平衡的。
- 🔴 **2026-10-06：取消「加装仅核心成员」这条限制** —— 原理由是"防止装具投资随人流失"，但**人不会走**（§8.4），前提已消失。**现在任何战斗人员都可以加装**（含后来招募的雇佣成员）。
- 其余两轴规则不变。

### 15.2 装具盘（装具挂在哪儿）

装具的作用对象是**装具盘**：**8 项 + 血量 = 9 格**，每项 **100 → 200 → 300**（前 / 中 / 后，与血量 100 → 200 → 300 同一把大尺子 · **锚 A21**）。完整结构与数值见 `01_Demo计划/04 §10.1`。

| 对 | 项 | 装具长什么样 | 管什么 |
|:--|:--|:--|:--|
| **运动** | **助力臂架** | 上臂助力架 | **近战伤害** |
| | **背负支架** | 背负承重支架 | **承载**（落差 ≥3 → 发力自伤） |
| **循环** | **循环辅助背心** | 循环辅助背心 | **战斗外每日自愈速率** · **体力上限** |
| | **滤尘面罩** | 滤尘面罩 | **战斗中每回合的体力回复** |
| **代谢** | **净水壶** | 净水壶 | 补给消耗 / 恢复（挡"吃进去的脏"） |
| | **解毒滤面罩** | 解毒滤面罩 | 排出已摄入的毒（扫"已经进来的毒"） |
| **感知** | **反应辅助头环** | 反应辅助头环 | **先手 / 闪避时机** |
| | **防尘罩衣** | 防尘罩衣 | 闪避精度 · 抗感染 / 抗灰蚀 |
| **（独立）** | **血量** | 负重背心 | **单独加点**，**不归心脏** |

**核心机制 = 联锁（不是加点，是配负荷）**：

> **一对落差 ≥ 3 → 弱的那一侧成为"破口"**（主动惩罚）；**强的那侧"单飞"不算罚**，只是"白练"（投了点数没换到主收益）。
> **专精一路 = 强但带一条破口；样样均衡 = 稳但没亮点** → **没有"全能解"**。
>
> ⚠️ **落差阈值 ≥3 = AI 提案，非用户铁律**；原按"每格 5→15"写，**已随 15 倍放大改口径，新阈值待拍**（若按同一比例 → 30）。

> 🔴 **心肺职能（2026-09-20 定）**：**肺 = 战斗中每回合的体力回复** · **心脏 = 体力上限**（+ 战斗外每日自愈）。**注意：现在由「滤尘面罩」管肺、「循环辅助背心」管心脏**。

### 15.4 不兼容机制（原「排异」）

- **不兼容率按装具大小定**：微型 **0%** / 小型 **10–20%** / 大型 **40–60%**（⚠️ 初值，实测再锁）。
- **不兼容 ≠ 失败**：不兼容是**这具身体装不上这件**；失败是**技术没做成**（见 15.5）。
- **不兼容后果（轻量、可重试、不永久伤残）**：**装具无效 + 资源白费 + 短暂负面**（休养数天 / 临时 -属性）。绝不影响已完成改造、绝不永久伤残（接「不做永久惩罚」）。

### 15.5 加装结果：六种可能

一次加装落定后，结果分六种，让玩家自己权衡风险：

| 结果 | 说明 |
|:--|:--|
| **成功** | 装具生效，获得效果 |
| **技术失败** | 没做成，资源白费，轻微负面（短时虚弱） |
| **不兼容** | 这具身体接受不了这件装具（见 15.4），轻量可重试 |
| **接口冲突** | 与已装件互斥 / 缺前置 → 无效或需先移除前置（形成 build 多样性，不堆同一项） |
| **感染风险** | 在灰区 / 无高级器械时加装，有灰度感染概率（接第 8A 类感染机制） |
| **副作用** | 成功但附带轻微负面（如背负支架 → 灵活性 -），是 trade-off 非 bug |

### 15.5b 骨架 · 接口 · 负载（**2026-09-24 建 · 用户定**）

> 🔴 **读数（装具盘 9 格）↔ 硬件（骨架）** —— 两者是同一条链的两道工序，**不是两套数字**。
> **链条**：`骨架 → 装具（配件）→ 盘上某格 +N 点 → 换算成 血量 / 伤害 / 体力`。
> **完整规则与数值见 `01_Demo计划/04 §10.1.1`**；本节只留权威定位。

| 词 | 是什么 |
|:--|:--|
| **骨架** | 穿在身上的基础框架（决定能挂几个位、挂哪儿） |
| **接口** | 骨架上的安装位（装具往这儿挂） |
| **负载** | 骨架的承重上限（**超了就装不上**） |

**骨架分两轴**（与武器同构）：

| 轴 | 内容 | 作用 |
|:--|:--|:--|
| **骨架种类** | 运动型 / 循环型 / 代谢型 / 感知型 / **均衡型** | 选**取向** · **相对**（决定接口往哪偏） |
| **骨架材质** | 粗劣 → 常规 → 精良 → **旧时代** | **升级** · **绝对**（决定接口数 / 负载上限） |

- **"超限" = 负载不足**（物理上装不上），**不是"能量 / 供能"** —— 本作不引入能量概念。
- **两个闸门**：**接口占满** = "装不下了"；**负载不够** = "低级骨架装不了高级件"。**不需要额外规则。**
- **专项 ≠ 低级**（铁律 14）：专项骨架本行深、别行缺；均衡骨架每行都浅。**是"另一种"，不是"更好的"。**

| 加装必成功 | 风险（不兼容 / 失败 / 感染）是机制一部分，不是 bug |
| 堆同一项无脑变强 | 接口 / 前置约束，鼓励 build 多样性 |
| 🔴 **恐怖 / 生物改造感** | **一律机械·工程语汇**；**禁用医学·生物语汇**（摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体）；装具**可拆卸、可转给他人** |

## 16. 不做内容

| 内容 | 说明 |
|:----|:-----|
| 死亡系统 | 角色不会永久死亡 |
| 永久伤残 | 不做永久不可逆惩罚 |
| 经验值/熟练度 | 不做普通 RPG 成长 |
| 记忆碎片 | 记忆完整获得，不做碎片 |
| 临时雇员 | 不做短期雇佣 |
| 单辆车独立装备 | 商队统一结算 |
| 装备耐久 | 不做装备损耗 |
| 随机词条 | 不做装备随机属性 |
| 传统品质等级 | 不做白绿蓝紫品质 |
| 重伤觉醒 | 不做重伤后获得特殊能力 |
| 野外随地升级 | 记忆成长依赖城市/城镇设施 |
| 无限降费 | 避免破坏体力经济 |
| 无限抽牌 | 避免破坏卡牌经济 |
| 主记忆/副记忆 | 融合不设主副关系 |
| 🔴 **火种词条池** | **不做词条 / 后缀 / 特殊效果池**（2026-09-24 用户定：词条概念取消）。机制变化走**广度升级**与**推演**，不走"刷词条" |
| 🔴 **推演消耗素材** | **推演不是"以旧换新"** —— **原记忆永久保留**，推演是**派生**不是合并（§6.4.2） |
| 🔴 **推演必须消耗升级** | 推演**不吃**素材上的深度升级（原记忆还在，升级也还在）—— 旧"继承 + 重分配升级点"作废 |
| 🔴 **出牌张数上限** | **不做"每回合最多出 X 张"这类闸门** —— 本作的闸门是「**起手只有 3 张**（2 动作 + 1 记忆）」与「**体力池**」；**回合内出牌 / 抽牌完全不受限制** |
| 🔴 **生物·医学术语** | 加装一律用**机械·工程语汇**（装具 / 背心 / 面罩 / 支架 / 水壶），**禁用**摘除 / 移植 / 缝合 / 血肉 / 基因 / 腺体 |
| 🔴 **通用减伤率** | 防具**不给无相性的百分比减伤** —— 它是纯优乘数，会抹平软硬甲的相性差异 |
| 职业装备标签 | 不再用"职业标签"锁装备；改为**体格门槛（硬）+ 熟练无门槛** |
