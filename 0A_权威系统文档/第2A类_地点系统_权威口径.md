## 1. 地点分类总览

游戏中安全点分以下五类：

| 地点 | 定位 | 核心特征 |
|:---:|------|---------|
| **大城（九城）** | 唯一真正的大安全点 | 唯一有节点反应炉、可处理重伤/严重重伤、功能最完整、物价最低 |
| **小城** | 自发聚集定居点 | 无节点/无旧文明特殊设施（工坊等），但正常设施都有；物价便宜（比城镇低、比大城高）；治安比大城危险；有聚落事件；受灰兽潮影响 |
| **城镇** | 路上的补给容错点 | 补给、生活物资、普通治疗、偏生活 |
| **驿站** | 商队专门休息点 | 零件、修车、路线服务、偏车队；**不接收撤退** |
| **村庄** | 小型聚落 | 功能最少、小订单、少量交易、情报、物价最高 |

> 各地点功能为参考框架，具体功能以实际设定为准。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同，不是上下级。

### 五类地点档案（统一字段）

> **小城是九城时代之后新增的地点类型**（民众自发聚集，不是旧文明城市）。下表把五类地点按**同一套字段**并列，方便对照。

| 字段 | 大城（九城） | 小城 | 城镇 | 驿站 | 村庄 |
|:--|:--|:--|:--|:--|:--|
| 来源 | 旧文明九城时代遗留 | 九城网络失败后，民众**自发聚集**（不是旧文明城市） | 待定 | 旧文明驿站网络遗留 | 待定 |
| 人口 | 待定 | 约 1 万（参考） | 待定 | 待定 | 待定 |
| 数量 | **9 座（九城，已定；名单 + 连接见 `第7A类` 九城概况）** | 🔴 **未定**（2026-10-13 用户定：只定了大城，小城数量之后也不定） | 待定 | 待定 | 待定 |
| 节点反应炉 | ✅ **唯一有** | ❌ 没有 | ❌ | ❌ | ❌ |
| 设施 | **最全** + 旧文明特殊设施（锻造坊 / 工坊 / 记忆设施等） | **大城有的都有**，除**涉及旧文明的设施** | 补给 / 普通治疗 / 生活物资 | 零件 / 修车 / 路线服务 | 功能最少 |
| 物价 | **最低** | 跟大城一档，**比大城稍贵**（参考） | 高于城市 | 高于城市 | **最高** |
| 治安 | 待定 | 比大城危险 | 待定 | 待定 | 待定 |
| 事件 | 待定 | 有聚落事件 | 待定 | 待定 | 待定 |
| 声望 | 有城市声望 | 无城市声望；有**世界声望 + 商会声望** | 待定 | 待定 | 待定 |
| 命名 | 已定（九城） | 暂不命名（后补） | 待定 | 待定 | 待定 |
| **安全点（接收撤退）** | ✅ | ✅ | ❌ | ❌ | ❌ |

> 标 **「待定」**的格子 = 文件里尚无权威值，**此处不编造**，待补（见 §11）。

**灰兽潮说明（五类地点通用）**

**灰兽潮 = 偶发单城围攻**（详见 `第8A类 §六`）：某**单座**城市 / 聚落被几十 ~ 几百只灰兽**聚集围攻**。它是**自然兽群**受迁徙 / 食物 / 受惊驱动的聚集 —— **不是军队，也不是母兽派来的**；**偶发、无法倒计时准备**（旧框架「提前 30 天预警 + 强制加固城墙」已删）。

- 🔴 **任何聚落都可能被波及，但防护弱的更容易中招**：**只有大城有节点反应炉**；小城 / 城镇 / 驿站 / 村庄**均无节点、防护薄弱**，**相对更易遭袭**（**城镇 / 驿站尤其**）。
- 玩家**可自选是否参战**：发生在自己的城 = **指挥官模式**；路过他人的城 = **援军**（可选参战）。

### 撤退规则（已定 · 2026-10-12 三硬规则）

🔴 **只能退到「大城 / 小城」**（细则见 `第3A类 §5`）：

| # | 硬规则 | 说明 |
|:--:|:--|:--|
| ① | **只能退大城 / 小城** | **城镇 / 驿站 / 村庄均不接收撤退** —— 与上表「安全点（接收撤退）」一列一致 |
| ② | **必须已探明** | 没到过 / 没侦察过的地方，**玩家不知道那儿有没有城** |
| ③ | **由玩家指定** | **不是"最近的那个"、不是"出发时的安全点"** —— 否则玩家走到一半故意往后撤，就**白赚一半路程**（地图等于没风险） |

> 🔴 **为什么不是"退到出发时的安全点"**：那会让玩家**故意往坏地形冲** —— 反正出事就退回起点，风险被系统买单。**「指定 + 已探明」把"退到哪儿"变成玩家自己的决策。**

## 2. 城市

城市是游戏中唯一真正的大安全点，也是唯一设有 **节点反应炉** 的地点。

### 2.1 城市能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 大量供应，价格最低 |
| 购买零件 | 大量供应，价格最低 |
| 购买药包 | 大量供应，价格最低 |
| 治疗角色 | 花钱恢复生命，可处理轻伤 |
| 恢复重伤/严重重伤 | 只有城市可以恢复重伤和严重重伤状态 |
| 修理商队耐久 | 花钱恢复商队耐久 |
| 招募新队员 | 🔴 **只增不减** —— 补充后备，**不存在"替换"**（没有被挖走 / 逃跑 / 减员；严重重伤治好后照样归队，见 `第6A类 §8.4`） |
| 接订单 | 各类订单 |
| 卖货 | 处理贸易收益 |
| 打听情报 | 路线风险、天气、特殊事件信息 |
| 消费提升士气 | 酒馆/宴席/休整 |
| 购买旧文明遗物与装备 | 数量有限、刷新慢、有概率随机出现 |
| 工坊与特殊系统 | 工坊复产、古代记忆等后续系统 |
| **购买车辆** | 人员车/货车在城市工坊购买（小型/中型/大型） |
| ~~购买牲畜~~ | 🔴 **不是可交易项**（2026-10-09）—— **牲畜只作背景**（后末日商队用牲口拉车），**不做系统**：无饲料 / 无水源 / 无耐力 / 无买卖 / 不占货舱 / 不进硬账。见 `第3A类 §4.5.4` |

> **激活前 / 激活后功能区分（2026-09-07 重新设计）**：上表所列均为**基础功能，节点反应炉熄火（未激活）时即全部可用**——城市是活着的聚居点，靠人力与中世纪末期技术运转，不依赖旧文明能源。插入余烬核心重启反应炉后，**额外上线**记忆设施 / 工坊复产 / 旧文明遗物专柜 / 节点网络连通 / 高级检疫等"依赖旧能源的特殊设施"（详见第 7A 类「节点激活前后的城市功能差异」）。激活不是解锁城市，是给城市接上旧文明电；玩家可完全不激活、照样跑商生活。

### 2.2 城市不能做什么

- 城市不能无限刷新订单（订单种类和数量受限于城市状态）
- 城市不能直接传送（没有传送系统）

### 2.3 设计口径

> 城市是"大修整"——玩家应在城市完成完整整备后再出发。
> 城市是唯一能处理重伤和严重重伤的地方。
> 城市的价格最便宜，是为了鼓励玩家在城市带足资源，而不是到了路上再补。

## 3. 城镇

城镇是路上的补给容错点，不是低成本完整整备点。

### 3.1 城镇能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存较少 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/严重重伤 |
| 接小订单 | 短途订单为主 |
| 打听消息 | 路线情报（精度和可信度有限） |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 3.2 城镇不能做什么

- 不能恢复重伤/严重重伤
- 不能招募新队员（遇特殊事件除外）
- 不能修理商队耐久（或只能极少量）
- 没有节点反应炉
- 没有工坊等城市特殊系统

### 3.3 设计口径

> 城镇有人长期生活，所以补给比驿站便宜。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同。
> 城镇偏向：补给、药包、普通治疗、生活物资。

## 4. 驿站

驿站是专门给商队的休息点，和城镇是平级关系，功能与城镇基本相同。

驿站的历史背景：旧文明时代的驿站网络，灰潮失联后驿站工作人员留在原地生活，**商路慢慢衰落**（🔴 2026-09-24 改口径：**不是"断了"，是"走得少了"** —— 仍有零星商队在大城之间穿梭，见 `第7A类` §九城时代的兴衰）。玩家重新接入商路后，驿站恢复功能。

### 4.1 驿站能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存比城镇略多 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/严重重伤 |
| 修理商队耐久 | 驿站偏向修车服务 |
| 接小订单 | 短途订单为主 |
| 打听路线信息 | 获得下一段路的风险提示 |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 4.2 驿站不能做什么

- 不能恢复重伤/严重重伤
- **没有**节点反应炉（只有城市有节点反应炉）
- 不能招募新队员
- 没有工坊等城市特殊系统
- 没有传送功能

### 4.3 设计口径

> 驿站是"续命点"——主要解决路上的零件和修车问题。
> 驿站偏向：零件、商队耐久修理、路线服务、旅人消息。
> 驿站不是每个都有节点反应炉，只有城市才有。

## 5. 村庄

村庄是最小型的安全点，功能最少。

### 5.1 村庄能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 数量极少，价格最高 |
| 接极小订单 | 顺路小任务 |
| 打听情报 | 可获取免费传闻级别的信息 |
| 等待天气 | 消耗补给和天数 |

### 5.2 村庄不能做什么

- 不能恢复士气
- 不能治疗（也**不能处理重伤 / 严重重伤**）
- 不能修车
- 不能招募新队员
- **没有**节点反应炉
- 没有工坊等城市特殊系统

### 5.3 设计口径

> 村庄是商路的「最小落脚点」——功能最少、物价最高，只够喘口气、听个消息、接个顺路小活。

| 方式 | 消耗 | 效果 |

> **设计原则（用户原话）：角色平衡只有两种做法 —— 要么"专精一项、其余全差"，要么"水桶、但每项都平庸"；不允许"又专精又全能"。** 修补师的强项在**修车**（§6.3"使用零件·有修补师"仍保留），**恢复生命上没有加成**。

## 8. 等待费用

**没有「等待费用」这回事。**

等待（原地停留 / 等天气）**不是一种消费**，而是**正常过日子**：按天消耗**对应人数的补给**（见 `第3A类 §1.5`）+ **照发工资**，仅此而已 —— **不额外收任何金币**。

> 🔴 **2026-10-05 改**：原表（城市等待 1 天 = 1 补给 + 1 金币 / 驿站 · 城镇 = 1 补给 + 2 金币 / 无补给等待 4~6 金币）**整体作废**。等待已由「按天消耗补给 + 工资」算过账，再收一笔等于重复收费。

## 9. 收入结构

游戏不只有跑商赚钱。战斗、事件、自营贸易都有价值。

| 收入来源 | 定位 | 收入强度 |
|---------|------|:--------:|
| **主订单** | 最稳定收入，路线主收益 | **高** |
| **顺路订单/中途订单** | 路线规划收益核心 | **中高** |
| **战斗收益** | 鼓励玩家愿意打 | 中到中高 |
| **精英/高风险战斗** | 高风险对应高价值 | **高** |
| **事件收益** | 补充收入，随风险变化 | 中 |
| **自营贸易** | 未来重要收入来源 | 中高 |
| **Boss/关键战斗** | 保货、解锁、推进剧情 | 特殊高价值 |

> 战斗收益不能压过所有订单收益，但必须足够有吸引力让玩家愿意承担风险。
