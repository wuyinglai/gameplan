# 《余烬商队》第 2A 类：地点系统 · 权威口径

> 文档状态：权威口径 v2.0（A 级）
> 说明：本文件是第 2 类的当前权威版本。整合地点分类与功能 + 第 2.1 类全局经济系统。
> 文件后缀 A = 该类当前权威版本。生效日期：2026-07-20

---

## 1. 地点分类总览

游戏中安全点分以下四类：

| 地点 | 定位 | 核心特征 |
|:---:|------|---------|
| **城市** | 唯一真正的大安全点 | 唯一有节点反应炉、可处理重伤/失能、功能最完整 |
| **城镇** | 路上的补给容错点 | 补给、生活物资、普通治疗、偏生活 |
| **驿站** | 商队专门休息点 | 零件、修车、路线服务、偏车队 |
| **村庄** | 小型聚落 | 功能最少、小订单、少量交易、情报 |

> 各地点功能为参考框架，具体每个城市/城镇/驿站/村庄的功能以实际设定为准。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同，不是上下级。

---

## 2. 城市

城市是游戏中唯一真正的大安全点，也是唯一设有 **节点反应炉** 的地点。

### 2.1 城市能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 大量供应，价格最低 |
| 购买零件 | 大量供应，价格最低 |
| 购买药包 | 大量供应，价格最低 |
| 治疗角色 | 花钱恢复生命，可处理轻伤 |
| 恢复重伤/失能 | 只有城市可以恢复重伤和失能状态 |
| 修理商队耐久 | 花钱恢复商队耐久 |
| 招募新队员 | 替换失能角色或补充后备 |
| 接订单 | 各类订单 |
| 卖货 | 处理贸易收益 |
| 打听情报 | 路线风险、天气、特殊事件信息 |
| 消费提升士气 | 酒馆/宴席/休整 |
| 购买旧文明遗物与装备 | 数量有限、刷新慢、有概率随机出现 |
| 工坊与特殊系统 | 工坊复产、古代记忆等后续系统 |

### 2.2 城市不能做什么

- 城市不能无限刷新订单（订单种类和数量受限于城市状态）
- 城市不能直接传送（没有传送系统）

### 2.3 设计口径

> 城市是"大修整"——玩家应在城市完成完整整备后再出发。
> 城市是唯一能处理重伤和失能的地方。
> 城市的价格最便宜，是为了鼓励玩家在城市带足资源，而不是到了路上再补。

---

## 3. 城镇

城镇是路上的补给容错点，不是低成本完整整备点。

### 3.1 城镇能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存较少 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/失能 |
| 接小订单 | 短途订单为主 |
| 打听消息 | 路线情报（精度和可信度有限） |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 3.2 城镇不能做什么

- 不能恢复重伤/失能
- 不能招募新队员（遇特殊事件除外）
- 不能修理商队耐久（或只能极少量）
- 没有节点反应炉
- 没有工坊等城市特殊系统

### 3.3 设计口径

> 城镇有人长期生活，所以补给比驿站便宜。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同。
> 城镇偏向：补给、药包、普通治疗、生活物资。

---

## 4. 驿站

驿站是专门给商队的休息点，和城镇是平级关系，功能与城镇基本相同。

驿站的历史背景：旧文明时代的驿站网络，灰潮失联后驿站工作人员留在原地生活，商路断了多年。玩家重新接入商路后，驿站恢复功能。

### 4.1 驿站能做什么

| 功能 | 说明 |
|------|------|
| 购买补给 | 有库存限制，价格高于城市 |
| 购买零件 | 库存比城镇略多 |
| 购买药包 | 有库存限制 |
| 普通治疗 | 可恢复生命，但无法处理重伤/失能 |
| 修理商队耐久 | 驿站偏向修车服务 |
| 接小订单 | 短途订单为主 |
| 打听路线信息 | 获得下一段路的风险提示 |
| 消费提升士气 | 可选 |
| 等待天气 | 消耗补给和天数 |

### 4.2 驿站不能做什么

- 不能恢复重伤/失能
- **没有**节点反应炉（只有城市有节点反应炉）
- 不能招募新队员
- 没有工坊等城市特殊系统
- 没有传送功能

### 4.3 设计口径

> 驿站是"续命点"——主要解决路上的零件和修车问题。
> 驿站偏向：零件、商队耐久修理、路线服务、旅人消息。
> 驿站不是每个都有节点反应炉，只有城市才有。

---

## 5. 村庄

村庄是最小型的安全点，功能最少。

| 功能 | 说明 |
|------|------|
| 购买补给 | 数量极少，价格最高 |
| 接极小订单 | 顺路小任务 |
| 打听情报 | 可获取免费传闻级别的信息 |
| 等待天气 | 消耗补给和天数 |

> 村庄不恢复士气。村庄不能治疗、不能修车、不能招募。

## 7. 士气系统

### 7.1 士气消费（参考价格）

价格翻10倍于旧口径，以下为参考值，实际以具体城市/驿站/城镇为准：

| 项目 | 价格 | 效果 | 生效条件 |
|:----|:---:|:----:|:--------:|
| **酒馆小聚** | 150 金 | 士气 +1 | 士气 6 以下有效 |
| **商队宴席** | 400 金 | 士气 +1 | 士气 10 以下有效 |
| **豪华休整** | 800 金 | 士气 +2 | 不限士气 |

规则：
- 取消"每座城市限一次"的限制，只要有钱可以多次消费
- 但士气有上限（最高10），达到上限后无法再提升
- 以上价格为参考，具体以实际设定为准

### 7.2 自然士气恢复

只有到达 **城市、驿站、城镇** 时才会自然恢复士气：

| 地点 | 恢复 | 条件 |
|:----|:---:|:----:|
| 城市 / 大型城镇 | +2 | 士气 ≤ 8 |
| 普通城镇 | +1 | 士气 ≤ 6 |
| 驿站 | +1 | 士气 ≤ 6 |
| 村庄 | 0 | **不恢复士气** |

> 到达村庄不恢复士气。
> 野外不会自然恢复士气。

## 9. 收入结构

游戏不只有跑商赚钱。战斗、事件、自营贸易都有价值。

| 收入来源 | 定位 | 收入强度 |
|---------|------|:--------:|
| **主订单** | 最稳定收入，路线主收益 | **高** |
| **顺路订单/中途订单** | 路线规划收益核心 | **中高** |
| **战斗收益** | 鼓励玩家愿意打 | 中到中高 |
| **精英/高风险战斗** | 高风险对应高价值 | **高** |
| **事件收益** | 补充收入，随风险变化 | 中 |
| **自营贸易** | 未来重要收入来源 | 中高 |
| **Boss/关键战斗** | 保货、解锁、推进剧情 | 特殊高价值 |

> 战斗收益不能压过所有订单收益，但必须足够有吸引力让玩家愿意承担风险。

## 10. 不做内容

| 不做项 | 原因 |
|--------|------|
| 城市建设价格 | 属于第 8 类城市重建系统 |
| 跑商贸易品细表 | 贸易体系复杂，后续单独做 |
| 货物容量/资源容量 | 和商队车辆货舱系统一起做 |
| 订单数量限制 | 先无限接，靠路线和时间自然限制 |
| 具体特殊事件价格 | 每个事件写入事件系统时再定 |
| 库存刷新规则 | 当前只定库存范围 |
| 技能升级表 | 接 6.4 技能表 |
| 招募传闻/固定招募事件 | 后续角色招募系统 |
