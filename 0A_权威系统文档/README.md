## 🔴 这个目录只放什么

> 🔴 **本目录 = 游戏本身的规则**（世界怎么运转、数值是多少）。

| | 内容 |
|:----|:----|
| ✅ **该在这里** | 机制规则 · 数值 · 世界观 · 设计原则 · 修订记录 |
| 🔴 **不该在这里** | 🔴 **Demo 的临时方案**（"Demo 不做 X""Demo 用 400×400"）—— 那些属于 `01_Demo计划/` |

> 🔴 **为什么清**：Demo 的范围会变，正式版的规则不会。
> **混在一起的后果**：以后看设定的人会被"Demo 不做"误导，以为那是游戏规则。
> 📌 **Demo 的所有限制 → `01_Demo计划/Demo范围与限制.md`**
