## 1. 商队核心资源

### 1.1 资源总览

| 资源 | 说明 | 参考值 |
|:----|------|:------:|
| **补给** | 每天移动消耗 1 份，可在城市/城镇/驿站购买 | 城市 10 金/份 |
| **商队耐久** | 商队车辆的整体状态，上限 100 | 初始 85/100 |
| **金钱** | 高面额经济体系 | 初始 180 金（参考，待 Demo 倒推） |
| **火种** | 稀有战略资源，用于记忆强化/融合/词条 | 非初始持有 |
| **天数** | 全局时间单位，1 步 = 1 天 | 从第 1 天开始 |

### 1.2 重要物品（不消耗，不算资源）

| 物品 | 说明 |
|:----|------|
| **余烬核心** | 激活密钥（不是动力源），用于激活城市节点反应炉。不会消耗，不属于资源类。主线持有，初始不持有。 |

### 1.3 消耗规则

| 项目 | 规则 |
|:----|:----|
| 移动 1 步（1 格） | 消耗 1 天 |
| 每天移动 | 消耗 1 份补给 |
| 休养 1 天 | 重伤恢复进度 +1 |
| 等待（城市/城镇/驿站） | 消耗补给和天数，安全点内等待 |
| 野外扎营 | **仅第一天消耗双倍补给**，消耗天数。不叫等待，野外只有扎营 |
| 订单期限 | 按天计算 |

### 1.4 出发采购方案（参考）

| 方案 | 补给 | 零件 | 花费 | 剩余金钱 |
|:---|:---:|:---:|:---:|:--------:|
| 推荐方案 | 30 | 5 | 100 金 | 80 金 |
| 保守方案 | 35 | 6 | 118 金 | 62 金 |
| 冒险方案 | 25 | 4 | 82 金 | 98 金 |

> 以上为参考价格（旧口径），实际采购成本以第 2A 类经济系统为准。

### 1.5 商队人数与补给消耗

商队基础3人。后期可招募扩展，最多5人。

商队人数影响每天补给消耗和战斗行动点数（行动点数归属第4类战斗系统）。

| 商队人数 | 每天补给消耗 | 说明 |
|:-------:|:----------:|------|
| 3 人 | 1 份/天 | 基础人数 |
| 4 人 | 2 份/天 | 每多一人 +1 份 |
| 5 人 | 3 份/天 | 上限 5 人 |

战斗相关的行动点数和卡牌数规则归属第 4 类战斗系统，此处不展开。

### 1.5 补给耗尽惩罚

补给 = 0 后，每天：

| 惩罚 | 内容 |
|:----|:----|
| 士气 | -1 |
| 全体角色生命 | 每人失去 5 点生命 |
| 重伤恢复 | **恶化**：重伤恢复天数 +1（不恢复反而倒退） |

> 补给归零不直接失败，但三个惩罚叠加会迅速把商队拖垮。
> 没有额外惩罚（没有疲惫状态、没有士气≤2时多扣、没有最大生命百分比扣减）。

## 2. 商队耐久

### 2.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 商队耐久上限 | 100 |
| 归零状态 | 抛锚，无法继续移动，必须修到 20 以上 |

> 商队是商队的命根子，等同于第四名队友。

### 2.2 耐久状态分级

| 耐久范围 | 状态 | 说明 |
|:-------:|:----:|------|
| 81-100 | 完好 | 正常 |
| 61-80 | 轻度损坏 | 略有影响 |
| 41-60 | 损坏 | 效果明显 |
| 21-40 | 严重损坏 | 风险较高 |
| 1-20 | 濒毁 | 随时可能抛锚 |
| 0 | 抛锚 | 不能继续移动，必须修到 20 以上 |

### 2.3 耐久损耗

**固定损耗：**
- 每天固定 -1

**战斗损耗（参考值，具体以战斗系统为准）：**
| 战斗类型 | 大致损耗 |
|:--------|:--------:|
| 普通战斗 | 约 -5 |
| 精英战斗 | 约 -10 |
| Boss 战 | 约 -50 以上 |

> 天气波及、山路、荒路等损耗暂不细化，后续详细设定时再补充。

### 2.4 修理规则

| 方式 | 消耗 | 效果 |
|:----|:---:|:----:|
| 城市修理 | 10 金币 | 恢复 20 商队耐久 |
| 驿站修理 | 25 金币 | 恢复 20 商队耐久 |
| 城镇修理 | 30 金币 | 恢复 20 商队耐久 |
| 使用零件·普通 | 1 零件（50 金） | 恢复 10 商队耐久 |
| 使用零件·有修补师 | 1 零件（50 金） | 恢复 15 商队耐久 |

> 经济数据以第 2A 类/第 2.1 类为准。

### 2.5 修车逃生战（简化版）

触发条件：商队耐久过低 / 特殊事件 / Boss 撞击 / 恶劣天气 / 路线事故。

规则：
- 角色可消耗行动力和零件修车
- 修到指定耐久后可以撤离
- 消耗 1 行动力 + 1 零件，恢复 12 点商队耐久
- 修补师可恢复 18 点

## 3. 车厢容量

### 3.1 当前口径（第 6.2 类修订补丁）

| 项目 | 口径 |
|:----|:----|
| 初始车队 | 2 辆基础货车 |
| 每辆基础货车 | 8×8 车厢格，共 64 格 |
| 初始总车厢空间 | 128 格 |

### 3.2 物品占格

| 物品 | 占格 | 重量 | 堆叠 |
|:----|:---:|:----:|:----:|
| 补给 | 1 格 | 1 | 不堆叠 |
| 零件 | 1 格 | 2 | 不堆叠 |
| 药包 | 1 格 | 1 | 不堆叠 |

### 3.3 车厢容量成长

| 阶段 | 目标容量 |
|:----|:--------:|
| 初始 | 约 128 格 |
| 前期 | 约 200 格 |
| 中期 | 约 400 格 |
| 后期 | 约 600 格 |
| 最大扩展 | 约 700 格 |

### 3.4 车厢限制原则

| 限制 | 含义 |
|:----|------|
| **空间** | 硬限制，格子塞不进去就不能带 |
| **重量** | 软限制，超重可以走但会有惩罚 |
| **补给/药包/零件** | 占格占重量，会挤压货物空间 |
| **订单货物** | 也占格，和补给竞争空间 |
| **战利品/灰烬材料** | 也占格，远行后期进一步挤压空间 |

## 4. 士气系统

### 4.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 士气范围 | 0-10 |
| 推荐初始士气 | 6/10 |
| 士气归零 | 触发强制撤退 |

### 4.2 士气状态

| 士气 | 状态 | 说明 |
|:---:|:----:|------|
| 8-10 | 高昂 | 商队状态很好 |
| 5-7 | 正常 | 商队稳定 |
| 4 | 低士气预警 | 提示需要休整 |
| 2-3 | 危险 | 继续远行风险明显 |
| 1 | 崩溃边缘 | 强烈提示尽快找安全点 |
| 0 | 崩溃 | 强制撤退 |

### 4.3 士气下降

| 事件 | 变化 |
|:----|:----:|
| 一名角色重伤 | -1 |
| 两名角色在同一场战斗中重伤 | -2（受扣减上限限制） |
| 三名角色全部重伤但商队未毁 | -3 |
| 商队耐久降到 25% 以下 | -1（每趟远行只首次触发） |
| 商队耐久归零但未崩溃 | -1 |
| 订单货物损失超过 50% | -1（每单只触发一次） |
| 订单货物损失超过 70% | -1（每单只触发一次） |
| 补给归零后继续行进 | 每天 -1 |
| 灰烬风暴开始 | -1 |
| 主动撤退 | -2 |
| 崩溃撤退 | -4 |
| 订单失败 | -2 |
| 商队成员重伤/失能 | -1 |

> 没有死亡系统，没有死亡扣士气。

### 4.4 扣减上限

- 同一场战斗最多扣 -3 士气
- 同一天最多扣 -3 士气（崩溃撤退除外，可突破此上限）

### 4.5 士气消费（参考价格）

| 项目 | 价格 | 效果 | 生效条件 |
|:----|:---:|:----:|:--------:|
| **酒馆小聚** | 150 金 | 士气 +1 | 士气 6 以下有效 |
| **商队宴席** | 400 金 | 士气 +1 | 士气 10 以下有效 |
| **豪华休整** | 800 金 | 士气 +2 | 不限士气 |

规则：
- 只要有钱可以多次消费，不限制每座城市次数
- 士气有上限（最高 10），达到上限后无法再提升
- 以上价格为参考，具体以实际设定为准

### 4.6 自然士气恢复

成功抵达 **城市、驿站、城镇** 时恢复士气：

| 地点 | 恢复 | 条件 |
|:----|:---:|:----:|
| 城市 / 大型城镇 | +2 | 士气 ≤ 8 |
| 普通城镇 | +1 | 士气 ≤ 6 |
| 驿站 | +1 | 士气 ≤ 6 |
| 村庄 | 0 | **不恢复士气** |

> 到达村庄不恢复士气，野外不会自然恢复士气。
> 打赢精英战斗不加士气。

### 4.7 花费金币额外恢复

在城市、城镇、驿站时，可以通过花钱额外恢复士气：

| 地点 | 可额外恢复 |
|:----|:---------:|
| 城市 | 可额外 +1 到 +2 |
| 大型城镇 | 可额外 +1 到 +2 |
| 普通城镇 | 可额外 +1 |
| 驿站 | 可额外 +1 |
| 村庄 | 可额外 +1（需花钱或触发事件） |
| 野外 | 不可用 |

> 每个地点每次停留最多额外恢复 1 次。具体消费价格见 4.5 士气消费表。

### 4.8 正面士气事件

| 事件 | 士气变化 |
|:----|:-------:|
| 成功守住订单货物 | +1 |
| 首次抵达重要中继点 | +1 |
| 完成小订单 | +1 |
| 救助旅人成功 | +1 |
| 帮助村庄解决危机 | +1 |
| 成功避开灰烬风暴 | +1 |
| 完成商路重建节点 | +1 到 +2 |

> 同一天正面事件最多恢复 +2 士气。

## 5. 失败条件

### 6.1 真正失败条件

只有以下两种情况触发强制撤退（不是游戏结束）：

1. **士气归零** → 士气崩溃，触发强制撤退
2. **全队倒下 + 商队耐久归零** → 无法继续行动，触发强制撤退

> 失败本质是商队被迫撤退止损，不是游戏结束。
> 没有其他失败条件。

### 6.2 全队倒下

全队倒下后不直接游戏结束，触发后果：

| 惩罚项 | 内容 |
|:------|------|
| 货物 | 全部损失 |
| 补给/零件 | 全部损失 |
| 位置 | 退回最近的安全点 |
| 所有角色 | 强制进入休养状态 |
| 士气 | -2 |
| 商队耐久 | 降到 20 |
| 当前订单 | 大概率失败或严重降级 |
| 金钱 | 暂不扣（避免彻底死档） |

> 这会非常痛，但还能继续。
