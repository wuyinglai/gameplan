### 1.2 重要物品（不消耗，不算资源）

| 物品 | 说明 |
|:----|------|
| **余烬核心** | 激活密钥（不是动力源），用于激活城市节点反应炉。不会消耗，不属于资源类。主线持有，初始不持有。 |

### 1.3 消耗规则（按 1/4 份粒度）

**食物和水按 1/4 份为最小单位：**
- 1 份食物 = 4 个 1/4 份
- 1 份水 = 4 个 1/4 份
- 购买补给可按 1/4 份购买

| 项目 | 规则 |
|:----|:----|
| 移动 1 步（1 格） | 消耗 1 天 |
| 每人每天 | 消耗 **1/4 份食物 + 1/4 份水** |
| 休养 1 天 | 重伤恢复进度 +1，消耗正常食物和水 |
| 等待（城市/城镇/驿站） | 消耗正常食物和水，安全点内等待 |
| 野外扎营 | 消耗食物和水，**第一天双倍**。不叫等待，野外只有扎营 |
| 订单期限 | 按天计算 |

### 1.4 出发采购方案（参考）

| 方案 | 食物 | 清水 | 零件 | 花费 | 剩余金钱 |
|:---|:---:|:---:|:---:|:---:|:--------:|
| 推荐方案 | 18 份 | 1 大水桶 | 5 | 待定 | 待定 |
| 保守方案 | 22 份 | 2 中水桶 | 6 | 待定 | 待定 |
| 冒险方案 | 15 份 | 1 中水桶 | 4 | 待定 | 待定 |

> 采购成本以第 2A 类经济系统为准。初始资金是否调整待定。

### 1.5 商队人数与补给消耗

商队基础3人（核心成员），后期可招募扩展，**不设硬上限**。

商队人数影响每天食物/水消耗和战斗行动点数（行动点数归属第4类战斗系统）。

| 商队人数 | 每天食物 | 每天清水 | 说明 |
|:-------:|:--------:|:--------:|------|
| 3 人 | 3/4 份 | 3/4 份 | 基础人数 |
| 5 人 | 1+1/4 份 | 1+1/4 份 | 中型 |
| 7+ 人 | 1+3/4 份 | 1+3/4 份 | 无硬上限 |

> 每多 1 人：每天食物/水 +1/4 份。

### 1.6 食物/水耗尽惩罚（立即生效，不等待）

**食物 = 0 后，每天：**

| 惩罚 | 内容 |
|:----|:----|
| 士气 | -1 |
| 全体角色 | 最大生命值降低 10% |
| 重伤恢复 | 每天恶化一次 |

**清水 = 0 后，每天：**

| 惩罚 | 内容 |
|:----|:----|
| 士气 | -1 |
| 全体角色 | 最大生命值降低 20% |
| 重伤恢复 | 每天恶化一次 |

> 食物和水都归零 → 双重惩罚叠加，商队迅速崩溃。
> 路上基本无法获得可饮用的天然水源。

## 2. 商队耐久

### 2.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 商队耐久上限 | 初始 100，可成长到 300（中期150~200，后期300左右） |
| 归零状态 | 抛锚，无法继续移动，必须修到 20 以上 |
| 底层损耗 | 用小数计算：初始每天-1.0，升级后-0.8（显示取整，底层按小数累加） |

> 商队是商队的命根子，等同于第四名队友。

### 2.2 耐久状态分级

| 耐久范围 | 状态 | 说明 |
|:-------:|:----:|------|
| 81-100 | 完好 | 正常 |
| 61-80 | 轻度损坏 | 略有影响 |
| 41-60 | 损坏 | 效果明显 |
| 21-40 | 严重损坏 | 风险较高 |
| 1-20 | 濒毁 | 随时可能抛锚 |
| 0 | 抛锚 | 不能继续移动，必须修到 20 以上 |

### 2.3 耐久损耗

**固定损耗：**
- 每天固定 -1

**战斗损耗（参考值，具体以战斗系统为准）：**
| 战斗类型 | 大致损耗 |
|:--------|:--------:|
| 普通战斗 | 约 -5 |
| 精英战斗 | 约 -10 |
| Boss 战 | 约 -50 以上 |

> 天气波及、山路、荒路等损耗暂不细化，后续详细设定时再补充。

### 2.4 修理规则

| 方式 | 消耗 | 效果 |
|:----|:---:|:----:|
| 城市修理 | 10 金币 | 恢复 20 商队耐久 |
| 驿站修理 | 25 金币 | 恢复 20 商队耐久 |
| 城镇修理 | 30 金币 | 恢复 20 商队耐久 |
| 使用零件·普通 | 1 零件（50 金） | 恢复 10 商队耐久 |
| 使用零件·有修补师 | 1 零件（50 金） | 恢复 15 商队耐久 |

> 经济数据以第 2A 类/第 2.1 类为准。

### 2.5 修车逃生战（简化版）

触发条件：商队耐久过低 / 特殊事件 / Boss 撞击 / 恶劣天气 / 路线事故。

规则：
- 角色可消耗行动力和零件修车
- 修到指定耐久后可以撤离
- 消耗 1 行动力 + 1 零件，恢复 12 点商队耐久
- 修补师可恢复 18 点

## 3. 车厢容量

### 3.1 当前口径（第 6.2 类修订补丁）

| 项目 | 口径 |
|:----|:----|
| 初始车队 | 3 辆（1小型人员车 + 2小型货车） |
| 初始总车厢空间 | 约 200 格 |
| 中期 | 约 800~1,000 格 |
| 后期 | 约 2,000 格 |

### 3.2 物品占格

| 物品 | 占格 | 说明 |
|:----|:----:|:----|
| 食物 | 1 格/份 | 可按 1/4 份购买 |
| 小水袋 | 1 格 | 装 2 份水（容器固定占格，不管剩多少） |
| 中水桶 | 4 格 | 装 6 份水（容器固定占格） |
| 大水桶 | 9 格 | 装 16 份水（容器固定占格） |
| 零件 | 1 格 | 2 重量 |
| 药包 | 1 格 | 1 重量 |

### 3.3 车厢容量成长

| 阶段 | 目标容量 |
|:----|:--------:|
| 初始 | 约 200 格 |
| 中期 | 约 800~1,000 格 |
| 后期 | 约 2,000 格 |

### 3.4 车厢限制原则

| 限制 | 含义 |
|:----|------|
| **空间** | 硬限制，格子塞不进去就不能带 |
| **重量** | 软限制，超重可以走但会有惩罚 |
| **食物/水/药包/零件/饲料** | 占格占重量，会挤压货物空间 |
| **订单货物** | 也占格，和补给竞争空间 |
| **战利品/灰烬材料** | 也占格，远行后期进一步挤压空间 |

## 4. 士气系统

### 4.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 士气范围 | 0-10 |
| 推荐初始士气 | 6/10 |
| 士气归零 | 触发强制撤退 |

### 4.2 士气状态

| 士气 | 状态 | 说明 |
|:---:|:----:|------|
| 8-10 | 高昂 | 商队状态很好 |
| 5-7 | 正常 | 商队稳定 |
| 4 | 低士气预警 | 提示需要休整 |
| 2-3 | 危险 | 继续远行风险明显 |
| 1 | 崩溃边缘 | 强烈提示尽快找安全点 |
| 0 | 崩溃 | 强制撤退 |

### 4.3 士气下降

| 事件 | 变化 |
|:----|:----:|
| 一名角色重伤 | -1 |
| 两名角色在同一场战斗中重伤 | -2（受扣减上限限制） |
| 三名角色全部重伤但商队未毁 | -3 |
| 商队耐久降到 25% 以下 | -1（每趟远行只首次触发） |
| 商队耐久归零但未崩溃 | -1 |
| 订单货物损失超过 50% | -1（每单只触发一次） |
| 订单货物损失超过 70% | -1（每单只触发一次） |
| 食物归零后继续行进 | 每天士气 -2 |
| 灰烬风暴开始 | -1 |
| 主动撤退 | -2 |
| 崩溃撤退 | -4 |
| 订单失败 | -2 |
| 商队成员重伤/失能 | -1 |

> 没有死亡系统，没有死亡扣士气。

### 4.4 扣减上限

- 同一场战斗最多扣 -3 士气
- 同一天最多扣 -3 士气（崩溃撤退除外，可突破此上限）

### 4.5 士气消费（参考价格）

| 项目 | 价格 | 效果 | 生效条件 |
|:----|:---:|:----:|:--------:|
| **酒馆小聚** | 150 金 | 士气 +1 | 士气 6 以下有效 |
| **商队宴席** | 400 金 | 士气 +1 | 士气 10 以下有效 |
| **豪华休整** | 800 金 | 士气 +2 | 不限士气 |

规则：
- 只要有钱可以多次消费，不限制每座城市次数
- 士气有上限（最高 10），达到上限后无法再提升
- 以上价格为参考，具体以实际设定为准

### 4.6 自然士气恢复

成功抵达 **城市、驿站、城镇** 时恢复士气：

| 地点 | 恢复 | 条件 |
|:----|:---:|:----:|
| 城市 / 大型城镇 | +2 | 士气 ≤ 8 |
| 普通城镇 | +1 | 士气 ≤ 6 |
| 驿站 | +1 | 士气 ≤ 6 |
| 村庄 | 0 | **不恢复士气** |

> 到达村庄不恢复士气，野外不会自然恢复士气。
> 打赢精英战斗不加士气。

### 4.7 花费金币额外恢复

在城市、城镇、驿站时，可以通过花钱额外恢复士气：

| 地点 | 可额外恢复 |
|:----|:---------:|
| 城市 | 可额外 +1 到 +2 |
| 大型城镇 | 可额外 +1 到 +2 |
| 普通城镇 | 可额外 +1 |
| 驿站 | 可额外 +1 |
| 村庄 | 可额外 +1（需花钱或触发事件） |
| 野外 | 不可用 |

> 每个地点每次停留最多额外恢复 1 次。具体消费价格见 4.5 士气消费表。

| 事件 | 士气变化 |
|:----|:-------:|

## 4.5 商队组织与成员

### 4.5.1 成员分类（帮工/护卫/特殊人员）

| 类型 | 是否出战 | 说明 |
|:----|:--------:|:-----|
| **帮工**（车夫/杂役） | ❌ | 基础人员，**无特殊效果**，价格便宜且彼此差不多；**每次出发必须带够数量**（每车≥1车夫，杂役按人数配），不够有严重负面惩罚（具体后定） |
| **护卫**（战斗人员） | ✅ 只有护卫能出战 | 如初始3人（护路人/荒野射手/修补师），能出战 |
| **特殊人员**（厨师/账房/修车匠等） | ❌ | **无统称，直接叫具体职业**；每个职业提供一种固定被动效果（如厨师每隔几天+1士气） |

> 硬性分工：只有护卫能出战，帮工/特殊人员不能参战。职责不交叉。
> 人员上限：**升级车厢/车辆 → 增加可携带人员上限**。

### 4.5.2 核心成员与雇佣

| 项目 | 规则 |

| 新核心角色 | **后期通过剧情/特殊事件，也可能加入新的核心角色**——同样不领日薪 |
| 护卫日薪 | 帮工的 **2 倍以上**（平衡手段：出战无上限）；特殊人员居中 |

## 5. 失败条件


### 6.1 真正失败条件

只有以下两种情况触发强制撤退（不是游戏结束）：

1. **士气归零** → 士气崩溃，触发强制撤退
2. **全队倒下 + 商队耐久归零** → 无法继续行动，触发强制撤退

> 失败本质是商队被迫撤退止损，不是游戏结束。
> 没有其他失败条件。

### 6.2 全队倒下

全队倒下后不直接游戏结束，触发后果：

| 惩罚项 | 内容 |
|:------|------|
| 货物 | 全部损失 |
| 食物/水/零件 | 全部损失 |
| 位置 | 退回最近的安全点 |
| 所有角色 | 强制进入休养状态 |
| 士气 | -2 |
| 商队耐久 | 降到 20 |
| 当前订单 | 大概率失败或严重降级 |
| 金钱 | 暂不扣（避免彻底死档） |

> 这会非常痛，但还能继续。
