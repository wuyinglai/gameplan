# 《余烬商队》第 3A 类：商队资源与失败系统 · 权威口径

> 文档状态：权威口径 v1.0（A 级）
> 说明：本文件是第 3 类的当前权威版本。整合商队核心资源、商队耐久、车厢容量、士气系统、撤退与失败条件。
> 经济数据以第 2A 类/第 2.1 类为准，车厢容量数据以第 6.2 类修订补丁为准。
> 文件后缀 A = 该类当前权威版本。生效日期：2026-07-20

## 1. 商队核心资源

### 1.1 资源总览

| 资源 | 说明 | 初始/参考值 |
|:----|------|:----------:|
| **补给** | 每天移动消耗 1 份，可在城市/城镇/驿站购买 | 推荐出发带 25-30 份 |
| **商队耐久** | 商队车辆的整体状态，上限 100 | 初始 85/100 |
| **金钱** | 高面额经济体系 | 初始 180 金（参考，待 Demo 倒推） |
| **火种** | 稀有战略资源，用于记忆强化/融合/词条 | 非初始持有 |
| **余烬核心** | 激活密钥（不是动力源），用于激活城市节点反应炉 | 主线持有 |
| **天数** | 全局时间单位，1 步 = 1 天 | 从第 1 天开始 |

### 1.2 消耗规则

| 项目 | 规则 |
|:----|:----|
| 移动 1 步（1 格） | 消耗 1 天 |
| 每天移动 | 消耗 1 份补给 |
| 休养 1 天 | 重伤恢复进度 +1 |
| 等待 1 天 | 天气推进 +1 |
| 订单期限 | 按天计算 |
| 天气持续 | 按天计算 |

### 1.3 补给耗尽惩罚

补给 = 0 时，每移动 1 天：
- 士气 -1
- 全队每人失去 2 点生命

士气 ≤ 2 时缺补给移动：
- 士气 -1
- 全队每人失去 3 点生命
- 有概率获得疲惫状态

补给归零后：
- 士气每天 -1
- 全体角色生命 -20%（按最大生命计算）
- 重伤恢复停止
- 撤退压力大幅提高

> 补给归零不直接失败，但会迅速把商队拖垮。

## 2. 商队耐久

### 2.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 商队耐久上限 | 100 |
| 初始商队耐久 | 85/100 |
| 归零状态 | 抛锚，无法继续移动，必须修到 20 以上 |

> 商队是商队的命根子，等同于第四名队友。

### 2.2 耐久损耗

| 情况 | 损耗 |
|:----|:----:|
| 普通道路 | 每 5 天 -1 |
| 荒路 / 山路 | 每 3 天 -1 |
| 灰烬区 / 风暴区 | 每 1-2 天 -1 |
| 普通战斗受波及 | -3 到 -8 |
| 特殊敌人攻击商队 | -8 到 -15 |
| Boss 撞击 / 抢货 | -15 到 -30 |
| 使用强力车载技能 | 消耗 5-20 耐久 |

> 损耗根据路况、天气、战斗和事件变化，不是每走一步都固定掉耐久。

### 2.3 耐久状态

| 耐久 | 状态 | 效果 |
|:---:|:----:|------|
| 71-100 | 完好 | 正常 |
| 41-70 | 受损 | 坏事件概率上升，部分车载技能效果下降 |
| 21-40 | 危险 | 移动额外消耗补给；战斗开始可能少抽牌 |
| 1-20 | 濒毁 | 无法接高价值护送订单；被攻击容易损失货物 |
| 0 | 抛锚 | 不能继续移动，必须修到 20 以上 |

### 2.4 修理规则

| 方式 | 消耗 | 效果 |
|:----|:---:|:----:|
| 城市修理 | 10 金币 | 恢复 20 商队耐久 |
| 驿站修理 | 25 金币 | 恢复 20 商队耐久 |
| 城镇修理 | 30 金币 | 恢复 20 商队耐久 |
| 使用零件·普通 | 1 零件（50 金） | 恢复 10 商队耐久 |
| 使用零件·有修补师 | 1 零件（50 金） | 恢复 15 商队耐久 |

> 经济数据以第 2A 类/第 2.1 类为准。

## 3. 车厢容量

### 3.1 当前正式口径（第 6.2 类修订补丁）

| 项目 | 口径 |
|:----|:----|
| 初始车队 | 2 辆基础货车 |
| 每辆基础货车 | 8×8 车厢格，共 64 格 |
| 初始总车厢空间 | 128 格 |
| 补给占格 | 1 格，重量 1，不堆叠 |
| 零件占格 | 1 格，重量 2，不堆叠 |

### 3.2 车厢容量成长目标

| 阶段 | 目标容量 |
|:----|:--------:|
| 初始基础车队 | 约 128 格 |
| 第一座城市升级后 | 约 200 格 |
| 中期扩展车队 | 约 320 格 |
| 后期大型车队 | 约 450 格 |
| 最终完全扩展 | 约 600 格 |

### 3.3 车厢限制原则

| 限制 | 含义 |
|:----|------|
| **空间** | 硬限制，格子塞不进去就不能带 |
| **重量** | 软限制，超重可以走但会有惩罚 |
| **补给** | 占格、占重量，会挤压货物空间 |
| **订单货物** | 也占格，和补给竞争空间 |
| **战利品/灰烬材料** | 也占格，远行后期进一步挤压空间 |

> 初始车厢约 128 格只支持短程路线（30-60 天），不支持中程以上。

## 4. 士气系统

### 4.1 基础数值

| 项目 | 数值 |
|:----|:----:|
| 士气范围 | 0-10 |
| 推荐初始士气 | 6/10 |
| 士气归零 | 进入崩溃状态，触发强制撤退 |

### 4.2 士气状态

| 士气 | 状态 | 说明 |
|:---:|:----:|------|
| 8-10 | 高昂 | 商队状态很好 |
| 5-7 | 正常 | 商队稳定 |
| 4 | 低士气预警 | 提示需要休整 |
| 2-3 | 危险 | 继续远行风险明显 |
| 1 | 崩溃边缘 | 强烈提示尽快找安全点 |
| 0 | 崩溃 | 强制撤退 |

### 4.3 士气下降

| 事件 | 变化 |
|:----|:---:|
| 一名角色重伤 | -1 |
| 两名角色在同一场战斗中重伤 | -2（受扣减上限限制） |
| 三名角色全部重伤但商队未毁 | -3 |
| 商队耐久降到 25% 以下 | -1（每趟远行只首次触发） |
| 商队耐久归零但未崩溃 | -1 |
| 订单货物损失超过 50% | -1（每单只触发一次） |
| 订单货物损失超过 70% | -1（每单只触发一次） |
| 补给归零后继续行进 | 每天 -1 |
| 灰烬风暴开始 | -1 |
| 主动撤退 | -2 |
| 崩溃撤退 | -4 |
| 订单失败 | -2 |
| 商队成员死亡 | -2（后期死亡系统启用后使用） |
| 打赢精英战斗 | +1 |
| 完成订单 | +1 到 +3 |
| 成功抵达驿站 | +1 |
| 救助 NPC 成功 | +1 |

### 4.4 扣减上限

- 同一场战斗最多扣 -3 士气
- 同一天最多扣 -3 士气（崩溃撤退除外，可突破此上限）

### 4.5 士气消费（参考价格）

| 项目 | 价格 | 效果 | 生效条件 |
|:----|:---:|:----:|:--------:|
| **酒馆小聚** | 150 金 | 士气 +1 | 士气 6 以下有效 |
| **商队宴席** | 400 金 | 士气 +1 | 士气 10 以下有效 |
| **豪华休整** | 800 金 | 士气 +2 | 不限士气 |

规则：
- 只要有钱可以多次消费，不限制每座城市次数
- 士气有上限（最高 10），达到上限后无法再提升
- 以上价格为参考，具体以实际设定为准

### 4.6 自然士气恢复

只有到达 **城市、驿站、城镇** 时才会自然恢复士气：

| 地点 | 恢复 | 条件 |
|:----|:---:|:----:|
| 城市 / 大型城镇 | +2 | 士气 ≤ 8 |
| 普通城镇 | +1 | 士气 ≤ 6 |
| 驿站 | +1 | 士气 ≤ 6 |
| 村庄 | 0 | **不恢复士气** |

> 到达村庄不恢复士气，野外不会自然恢复士气。

### 4.7 士气归零后果

士气归零触发强制撤退。崩溃状态的影响：
- 不能接高风险订单
- 招募价格上升
- 部分队员可能拒绝出战

> 真正失败不是一次失败，而是商队彻底组织不起来。

## 5. 失败条件

### 5.1 全队倒下

全队倒下后不直接游戏结束，而是触发重惩罚：

| 惩罚项 | 内容 |
|:------|------|
| 货物 | 全部损失 |
| 补给/零件 | 全部损失 |
| 位置 | 退回最近的安全点 |
| 所有角色 | 强制进入休养状态 |
| 士气 | -2 |
| 商队耐久 | 降到 20 |
| 当前订单 | 大概率失败或严重降级 |
| 金钱 | 暂不扣（避免彻底死档） |

> 这会非常痛，但还能继续。

### 5.2 真正失败条件

以下情况构成真正失败（商队解散）：
1. 士气归零后再次全队倒下
2. 全队倒下且无法恢复最低行动能力
3. 商队没有补给、没有零件、没有可行动角色、没有金钱，且无法接任何补救任务
4. 关键主线订单彻底失败

> 失败本质是商队解散，而不是某一次战斗输了。
> 正常游玩不做永久死亡，不做永久伤残。

## 6. 撤退系统

### 6.1 撤退战

触发条件：玩家主动撤退 / 遇到强敌 / 订单风险过高 / 天气恶劣

规则：
- 不要求杀光敌人
- 坚持指定回合数即可撤离

| 阶段 | 坚持回合 |
|:----|:--------:|
| 前期 | 4 |
| 中期 | 5-6 |
| 后期 | 7-8 |
| Boss 追击撤退 | 8-10 |

### 6.2 撤退代价

| 类型 | 代价 |
|:----|:----|
| 主动撤退 | 士气 -2 |
| 崩溃撤退 | 士气 -4 |
| 撤退成功 | 损失少量补给、货物受损、商队耐久下降 |

### 6.3 修车逃生战

触发条件：商队耐久过低 / 特殊事件 / Boss 撞击 / 恶劣天气 / 路线事故

规则：
- 角色可消耗行动力和零件修车
- 修到指定耐久后可以撤离
- 消耗 1 行动力 + 1 零件，恢复 12 点耐久
- 修补师可恢复 18 点耐久
