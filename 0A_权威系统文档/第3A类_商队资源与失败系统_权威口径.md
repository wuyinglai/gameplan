| 项目           | 规则                                                                                                |

| 移动 1 步（1 格）  | 消耗 **15 点野外体力**（**体力池上限 100 · 日回 50**；🔴 **不随人数变化——所有人都要一起走**；**正常 3 格/天 · 极限 4 格/天**、攒满冲刺 **6 格**；详见第 1A 类 §2） |

| 每 +1 名出战 | +1 份 | +1 份 | 整数份，不拆份；🔴 **两列永远分开写，禁止合并成「28 份」这类总数** |

> 🔴 **不出战的人不消耗商队补给**（2026-10-06 用户裁定 · 2026-10-09 补解释）：**口粮他们自己买、工钱他们不领** —— 因为**还没被雇佣**（雇佣 = 建立关系 = 领工资 + 吃商队的粮）。商队走到哪人跟到哪（`§4.9.3`），不出战的人**仍在车队上**，只是这一趟没动用他们。完整理由见 `§4.9.2` / `第6A类 §8.4`。

### 1.6 食物/水耗尽惩罚（立即生效，不等待）

🔴 **2026-10-05 用户裁定：血量上限与当前生命值「同步下降」** —— 100/100 断食一天 → **90/90**（上限 −10 **且** 当前 −10，**两件事同时发生**）。与 `第1A类 §5.2` 一致。

> **怎么算**：`−10%` = **减去「该角色最大生命值的 10%」这么多点生命值**。上限 100 → 上限变 **90**、当前血也变 **90**；上限 240 → 上限变 **216**、当前血也变 **216**（各人按自己的上限算，不是固定扣 10 点）。

**食物 = 0 后，每天：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **10%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | 每天恶化一次                                                |

**清水 = 0 后，每天：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **20%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | 每天恶化一次                                                |

> 🔴 **为什么当前血也要扣**：被削掉的那部分上限**当场就没了** —— 100/100 断食一天变 90/90，而不是 100/90。**若只降上限、当前血不动**，会出现 60/100 这种"上限低于当前"的荒谬状态。>   
> ⚠️ **这是"上限被削"，不是"受伤"** —— **治疗只填当前血，不涨上限**；那削掉的 10% **补不回来**（除非另有恢复上限的手段）。>   
> 食物和水都归零 → 双重惩罚叠加（90/90 → 70/70），商队迅速崩溃。>   
> 路上天然水源多为**脏水**，需净化后饮用（详见 §1.7）。

### 1.7 脏水与净化（后期机制）

路上常遇见**脏水**水源（事件系统详见第 5A 类），分两种情况：

| 情况        | 结果                                          |
| :-------- | :------------------------------------------ |
| **未净化饮用** | 直接喝脏水会挂上各种负面状态（中毒 / 腹泻 / 疾病等），不推荐           |
| **净化后饮用** | 后期解锁**净化设备**（水箱改造或车载净水模块）后，脏水可安全饮用，等于沿途白捡水源 |

> **意义**：净化设备大幅减轻**超长途（≥200 天）**&#x7684;补给压力——不必全程自带几百格水，沿途净化脏水即可。>   
> 净化设备属 §3.5「可升级项」之一，升级途径 ⚠️ 待定。

## 2. 商队耐久

### 2.1 基础数值

| 项目     |                   数值                  |
| :----- | :-----------------------------------: |
| 商队耐久上限 | **3 车 × 60 = 180**（每车独立 60；可成长见 §2.6） |
| 单辆归零状态 |     该辆抛锚，无法继续移动，**必须修到 20 以上才能动** · 🔴 **也可以「弃车」把车留在原地**（见 §2.2A）—— **弃了车队伍就能走**     |
| 底层损耗   |      每车每天 -1.5（地形基础，显示取整，底层按小数累加）     |

> 商队是商队的命根子。3 辆货车各自独立计耐久——任何一辆中途抛锚都会拖慢整队。
> 🔴 **但不会把商队卡死**：抛锚可以修，也可以**弃车**（车留在原地，之后能拖回来 —— 见 `§2.2A`）。**只要还有一辆能动，车队就能走。**

### 2.2 耐久状态分级（按单辆百分比）

|   耐久百分比  |  状态  | 说明                       |
| :------: | :--: | ------------------------ |
| 81%-100% |  完好  | 正常                       |
|  61%-80% | 轻度损坏 | 略有影响                     |
|  41%-60% |  损坏  | 效果明显                     |
|  21%-40% | 严重损坏 | 风险较高                     |
|  1%-20%  |  濒毁  | 随时可能抛锚                   |
|    0%    |  抛锚  | 不能继续移动，**必须修到 20 以上才能动** |

> 🔴 **2026-10-06 用户裁定：抛锚修复门槛 10 → 20**（用户原话：「不要必须修到 10 以上才能动，**要修到 20 以上**才能继续行动」）。>   
> **为什么涨到 20**：抛锚的代价必须**真的疼** —— 修 10 点就能走，等于抛锚的代价只有「半天 + 一点零件」；修 20 点才走，**意味着商队得在原地停一整段**（而停着也照按天吃补给和工资）。这跟铁律一致：**让玩家感到"太远修不起"，不是"系统不许"** —— 玩家随时可以修，只是得**多花一天、两天**。

### 2.2A 车损、弃车与回收（🔴 2026-10-10 用户裁定）

> **用户原话**：「你这辆车可能还能捡回来，但是你可能要带着很多零件去给它修到能开……而且你也要在规定时间内去给它修好。不然的话它也会报废。」
> **决策过程**：先议"弃车"→ 发现**弃车即永久失去太狠** → 加一步「**可回收**」→ 定「**限时内不修 → 报废**」→ **模块化车（部位化）**。

#### 一、车有部位，坏哪决定后果

🔴 **耐久不再是"一个整体数字"，而是按部位记**（部位表对齐 `第6A类 §11.3` 的**车体结构槽**）：

| 部位 | 主要坏法 | 🔴 能不能拖回维修 |
|:--|:--|:--:|
| **车轮** | 磨 / 爆 / 陷（最主要的损耗源） | ✅ **能** —— 换件即修好 |
| **车轴** | 断 / 卡死 | ✅ **能** —— 结构性损伤，要拆修，费时间 |
| **车架** | 断裂（结构性） | ❌ **拖不回来** —— 🔴 **只能报废** |
| **减震** | 失效 | ✅ 能（换件） |
| **牵引 / 制动** | 失效 | ✅ 能（换件） |

> 🔴 **规则**：**损耗性损坏能修，结构性损伤只能报废。** 这条同时解释了两种坏法的区别 —— 不是"数值大小"，是**能不能修**。

#### 二、弃车 → 回城修 → 拖回来（玩家视角的完整流程）

```
① 车在乙城附近抛锚
   ↓
② 【弃车】车留在原地，脱离车队（不占编制、不占货舱）
   ↓
③ 你带着车队先撤回甲城（有维修能力的地方）休整
   ↓
④ 修好之后，【回收】—— 再走一趟把弃车拖回来
```

**为什么这条流程是合理的**（三条理由）：

| 理由 | 说明 |
|:--|:--|
| **① 弃车不等于失去** | 车**留在原地**，不是永久报废 —— 玩家有第二次机会 |
| **② "限时" = 你多久没回去** | 🔴 **不写死天数** —— **你的商路如果反复走同一条，你就能救回来**；越走越远不回头的，自然报废。**这样"路线规划"多了一层意义** |
| **③ "刚出发就坏"是玩家自己的问题** | 车刚出门就抛锚 = **你零件没带够** → 这一趟本来就走不通 → 最后大概率强制撤退回甲城 → **休整一下照样能把车拖回来**。**不是倒霉，是准备不足** |

#### 三、弃车的代价

| 代价 | 内容 |
|:--|:--|
| 🔴 **货舱永久减少** | 弃一辆 = **货舱 −300 格**（小型）/ **−600**（中型）/ **−900**（大型）—— **永久，不可逆** |
| 🔴 **耐久上限永久减少** | 每辆车 **−60** |
| 🔴 **车上的货要卸** | 装到别的车上；**装不下的部分只能处理掉**（= 货损） |
| **车夫** | 🔴 **不减人** —— 他跟着走，去**载人车**或**当后勤**（车夫是**岗位**，不是人） |

#### 四、回收的代价

| 代价 | 说明 |
|:--|:--|
| 🔴 **零件** | 回收 = **带零件去修** —— 零件用掉了就真没了 |
| 🔴 **时间** | 要**专门走一趟**去拖回来 —— 这趟的补给和工资照付 |
| 🔴 **车是空的** | 回收的车**没有货** —— 回来后要重新装 |

> **回收是"一次投资"**：你弃车时零件还在，回来时能救回来。**所以"弃"不是终局，是"先保住这趟"。**

### 2.3 耐久损耗

**地形基础损耗（每车独立）：**

- 每车每天 -1.5 耐久（60 天累计 -90/车，已超单辆 60 上限 → 中途必须维修）

**战斗损耗（每车计 · 三辆货车同时扣）：**

| 战斗类型   |   每车损耗  | 全队合计（3 货车） |
| :----- | :-----: | :--------: |
| 普通战斗   |  **-5** |   **-15**  |
| 精英战斗   | **-10** |   **-30**  |
| Boss 战 |  -50 以上 |   -150 以上  |

> **口径（2026-09-14 定）**：战斗损耗按**每辆车**扣，**不是"全队总共扣"**。三辆货车同时受损——"每车 5" = **全队 15**，"每车 10" = **全队 30**。>   
> ⚠️ **Boss 那条也是每车口径**，即一场 Boss ≈ **全队 150 以上**（占上限 180 的 83%）。Boss 是终局战、打完即通关，影响可控；**但若中途中出现 Boss 级撞击（如修车逃生战 §2.5），此值须另定** → 留待战斗层。

**意外缓冲**：远行额外预留约 **+20 耐久/全队**（天气、山路、事故等）。

**一段路（30 天）的耐久账（2026-09-14 核定）：**

| 项                     | 算式               |      全队耐久 |
| :-------------------- | :--------------- | --------: |
| 地形基础                  | 1.5 × 30 天 × 3 车 |   **135** |
| 战斗（5 场 = 4 普通 + 1 精英） | 4×15 + 1×30      |    **90** |
| **合计**                |                  | **≈ 225** |

> **关键结论**：30 天一段路总损耗 **≈225，已超过总上限 180** → **中途必须修车**（刚需，不是可选）。>   
> **单辆车纯自持力 ≈ 24 天**（完全不修车）：每车每天摊销 = 地形 **1.5** + 战斗 **1.0**（90 ÷ 3 车 ÷ 30 天）= **2.5/天** → 60 ÷ 2.5 = **24 天**。>   
> **但玩家随身带零件、能在路上自助修车**（**1 零件 = 10 耐久**，见 §2.4）→ **24~30 天之间的缺口由随身零件补掉**，所以**据点间距 ≈30 天左右**（20~30 天、不固定），**不是被 24 天锁死**。>   
> ⚠️ **2026-09-14 校正**：旧结论"**据点间距上限 ≈24 天**"**已废止** —— 它只算了车的自持力、**漏了随身零件**，会把据点摆得过密。**真正的硬约束是"恢复"不是"耐久"**：药包只能应急，**让队伍回满的是中继点**。

> **60 天典型远行总损耗 ≈ 435 耐久**：地形 270（3车×1.5×60）+ 战斗 165（10 场 = 9 普通 + 1 精英）+ 意外 20。>   
> 平均摊到每天 ≈ **7.3 耐久/天**；折合零件 ≈ **0.73 个/天**（1 零件 = 10 耐久，50 金/个 → ≈36 金/天）。

## 3. 车厢容量（占格系统 v4.2）

> **核心转变**：格子不是「要手动摆放的仓库格」，而是一种**资源计数**。车队有「总容量 N 格」，物品按「占几格」计入，玩家只关心「还剩多少格能装」。**不做整理玩法**（无格子拼图、无挪货），装/卸按数量自动归类。>   
> 旧「1 份/格高密度」「1/4 份粒度」「小水袋1格2份/大水桶9格16份」口径全部作废。

**双约束规则**：

- 物品同时占「体积格」与「重量」。
- 任一满（格满 或 重满）都装不下。
- 轻货（食物 2.5 / 药包 0.3 / 水满 1.5）优先撞格子上限；重货（零件 1.5）优先撞重量上限。

**水/食物特殊规则（用户早期认可，保留）**：

- 食物吃完 → 该格释放（可再装货）。
- 水喝完 → 水箱仍在，占格不释放（可重复灌）；瓶装/容器水可交易（卖/喝两用）。
- 空水箱重量极低（0.1 kg），长途越走越轻。

### 3.3 车厢容量成长

**"货舱变大"有三条路**（完整口径见 `0A 第6A类 §11.1 / §11.4`）—— **互相不顶替，量级差一个数量级**：

| :------------ | :--------- | :----------------------------------------------------------------------------- | :--------------------------- |
| **① 换车（`q`）** | 车的**规格**   | 300 → 600 → 900（**×3**）                                                        | **大跳 · 贵 · 一次到位**（锚 A15）     |
| **② 加挂货车**    | 车队的**规模**  | 🔴 **每辆 +`q` 格 / +60 耐久**（**跟着当期能买到的规格**：前 **+300** / 中 **+600** / 后 **+900**） | 多养一辆（多 1 车夫 + 2 后勤）          |

### 3.4 车厢限制原则

| 限制           | 含义                                        |
| :----------- | ----------------------------------------- |
| **空间（格）**    | 硬限制，格子塞不进去就不能带                            |
| **重量（载重）**   | 硬限制（= 格 × 2），超重同样装不下                      |
| **补给挤压货物**   | 食物/水/零件/药包占格占重，会挤压贸易货空间——但格子是计数不是拼图，不手动整理 |
| **订单货物**     | 也占格，和补给竞争空间                               |
| **战利品/灰烬材料** | 也占格，远行后期进一步挤压空间                           |

#### 升级机制（购买更高品质的同类补给）

**升级的本质 = 在特定城市购买「更高品质的同类补给」，而非独立升级槽。**

- 部分城市有特产 / 更高工艺：例如 **粮野城**（粮产城）出售 **优质食物**——同样 1 格装 10 份，但单价更高（示例：**30 金/份**，对比普通 10 金/份）。
- 同理，高耐久零件（20 耐久/个）在部分城市工坊可按更高价购入（示例：**150 金/个**，对比普通 50 金/个）。
- 含义：「升级」用 **金钱 + 城市选择** 换「更省格子 / 更耐修」，玩家在特产城按需采购即可，无需单独升级界面。

> ⚠️ 上述城市与单价仅为 **机制示例**（正式版由物价/地点系统逐城定稿，AI 不编具体城价）。>   
> **Demo 阶段的基准值** → 见 `01_Demo计划/Demo范围与限制.md`。>   
> **水净化升级途径 ⚠️ 待定**：可能走车辆改造 / 旧文明遗物 / 记忆-机械领域，具体归属与消耗后定。

>   ⚠️ 以上数值**仅作参考值**，具体项目未写死（见 §4.5 消费表同条声明）。

## 4.9 商队组织与成员

### 4.9.1 成员分类（后勤 / 护卫 / 特殊人员）

| 类型                   |    是否出战   | 说明                                                                      |
| :------------------- | :-------: | :---------------------------------------------------------------------- |
| **后勤人员**             |     ❌     | 基础人员，**无特殊效果**，价格便宜且彼此差不多；**每次出发必须带够数量**（每车≥1车夫，后勤按人数配），不够有严重负面惩罚（具体后定） |
| **护卫**（战斗人员）         | ✅ 只有护卫能出战 | 如初始3人（护路人/荒野射手/修补师），能出战                                                 |
| **特殊人员**（厨师/账房/修车匠等） |     ❌     | **无统称，直接叫具体职业**；每个职业提供一种固定被动效果（如厨师每隔几天+1士气）                             |

> 🔴 **称呼统一（2026-10-06 用户裁定）**：**从始至终只有「后勤人员」这一个称呼** —— **没有「杂役」这个名称**。全库凡写"杂役"处一律改为"后勤人员"。>   
> 硬性分工：只有护卫能出战，后勤 / 特殊人员不能参战。职责不交叉。>   
> 人员上限：**升级车厢/车辆 → 增加可携带人员上限**。

### 4.9.2 核心成员与雇佣

🔴 **2026-10-06 用户裁定：初始 14 人「全部都是核心成员」** —— 原表写"初始约 6~~7 人为核心成员（3护卫+2~~3车夫+1~2杂役）"，**其余 7~8 人算什么没说清，是错的**。修正如下：

| 项目       | 规则                                                          |
| :------- | :---------------------------------------------------------- |
| **核心成员** | 🔴 **初始全部 14 人都是核心成员**（3 护卫 + 若干车夫 + 其余后勤 / 特殊人员）· **不领日薪** |
| **雇佣成员** | 之后招募的成员，**领日薪**                                             |
| 新核心角色    | **后期通过剧情/特殊事件，也可能加入新的核心角色**——同样不领日薪                         |
| 护卫日薪     | 后勤人员的 **2 倍以上**（平衡手段：出战无上限）；特殊人员居中                          |

> 🔴 **为什么核心成员不领日薪 —— 是「防死档」的结构件，不是人情设定**（用户 2026-10-06 给出理由）：
>
> **一天的硬账是三笔同时付**：**工资** + **补给（吃喝）** + **货 / 零件 / 药包**。
>
> - 如果**开局 14 人全要领工资**，玩家从第一天起就背上一笔**永不缩水的固定开销**；而**工资是按天付、不做任何折减** —— 于是「买货要钱 / 修车要钱 / 雇人要钱」全部叠加在**同一条已经见底的现金流**上。
> - 结果就是：**玩家迟早破产，且没有任何办法回血** —— 卖货？货已经压在车上了。裁员？🔴 **人只增不减、不可能裁**（§4.9.3）。于是**存档直接崩掉（死档）**。
> - **核心成员不领工资 = 商队有一个"零工资底座"** —— 哪怕玩家打光了钱、走投无路，**还有 14 个人跟着你**，队伍**永远不会因为"发不出工资"而整个垮掉**。工资只压在**后来主动招的人**身上，那是**玩家自己选的扩张**，亏了也是自己该承担的。
>
> **一句话**：**不领日薪 = 给玩家一条"破产了还能爬起来"的后路**，而不是一个温情设定。
>
> ⚠️ **这条同时决定了装备 / 装具可以放心砸**（见 §4.9.3）—— 因为核心成员**不会走**、**也不会因为欠薪而消失**。>   
> 🔴 **反面代价（必须承认）**：不领日薪意味着**工资这个人数抑制器在初期是失效的** —— 早期招人几乎不涨成本，所以"招募"没有天然的价格刹车。这由**补给 + 车辆载人 + 编制铁律**（§1.5）来兜；`04 §0.7.5` 另算"后期工资随人数翻倍"的抑制作用。

### 4.9.3 成员离队

🔴 **2026-10-06 用户裁定：没有「被挖走」这回事。**

| 项目      | 规则                                 |
| :------ | :--------------------------------- |
| **被挖走** | 🔴 **不存在这个设定** —— 没有任何势力会来挖你的成员    |
| **逃跑**  | 🔴 **不存在这个设定** —— 士气低了不跑，只干活变差     |
| **减员**  | 🔴 **不存在"减员"这个概念** —— **商队人数只增不减** |

**玩家能做的只有一件事：在城市里决定谁出战**

| 操作       | 说明                                                           |
| :------- | :----------------------------------------------------------- |
| **选择出战** | 在城市里**自由切换**哪些护卫随队出战斗 —— **出战无上限**（不是"固定三人"，也不是"必须满员"）       |
| **不出战**  | 不出战的人**还在车队上**（他没有离队）：**不领工资**、**不消耗补给**、**不会消失**、**不会老**（理由见 §4.9.2）|
| **轮换**   | 🔴 **在任何城市都能换人** —— 因为人从来没离开过队伍（**商队走到哪人跟到哪**） |
| **装备**   | **谁出战，装备就跟谁走** —— 不出战的人装备在车队库里，不穿就等于在库房，这是玩家的自然选择 |
| **构筑**  | 🔴 **随时能换回来** —— **不需要重招、不重建构筑** |

> **为什么没有"被挖走"**：玩家在一个角色身上砸了装备、装具、记忆，**还把他排进阵容的核心** —— 结果某天他被高价挖走了，**玩家会非常烦**。这个设计是在惩罚玩家投入，不是制造决策。>   
> **锈味替代**：人员选择的压力应该来自**"带谁出、谁留守"**（留守的人不领工资 = 白养），而不是"我会不会突然少个人"。
> 🔴 **两条轴分开算（2026-10-12 校，消歧）**：**工资看"雇佣关系"**（初始 14 核心成员 + 未招募者不领；招募进来的领，与出不出战无关，§4.9.2）· **补给看"出战关系"**（出战的人吃商队的粮，不出战的人口粮自己买，§1.5）。⚠️ 残余待裁：**招募来但不出战的成员**——按现行口径**领工资但不吃商队的粮**。>   
> ⚠️ 原 §8.4「装备离队回收」「加装仅核心」两条设计前提（防装具随人流失）**已无必要** —— 详见 `第6A类` 同步记录。

### 4.9.4 牲畜（🔴 只作背景，不做系统 · 2026-10-09 裁定）

🔴 **本节不是系统，是世界观背景。** 之前那版空壳（有饲料消耗 / 占车厢格 / 种类差异）**全部作废** —— 它**没有任何机制接口**，硬做只会牵动七八个不该动的地方。

**保留的意义**（一句话）：**后末日的世界里，商队是用牲畜拉车的。** 粮野城产马匹与驮畜、黑石城缺驮畜（见 `第7A类` 区域表）—— **这是画面，不是系统。**

| 项目 | 口径 |
|:----|:--|
| **要不要做系统** | 🔴 **不做** —— 没有饲料、没有水源、没有耐力、没有买卖、没有疾病死亡 |
| **进不进硬账** | 🔴 **不进** —— 跟人一样，**商队口粮不按牲畜算** |
| **算不算车数 / 编制** | 🔴 **不算** —— 车辆与编成口径见 `§4.9.5` 与 `§1.5` |
| **种类差异** | 🔴 **不做** —— 无载重 / 耐旱 / 稳定性差异 |
| **购买** | 🔴 **不作为可交易项** —— 城市里有牲畜，是背景 |
| **拉车 / 速度** | 🔴 **不做提速轴** —— 速度只有「加能量」一条轴（动力抬 `S`，见 `23 §2.2`），**牲畜不参与** |

> **为什么不做好**：① 它唯一的功能是"让车走得快"，而这件事 `23 §2.2` 已用「**动力抬 `S`**」解决，**不需要第二套实现**；② 一旦牲畜能加 `S`，就等于**多出一条提速轴** —— 直接违反 **2026-10-05 用户裁定「速度恒定（每格消耗恒定）、无任何提速手段」**；③ 真做起来要接**饲料 / 水源 / 耐力 / 车速 / 地形 / 疾病 / 价格** 七八个接口，**麻烦且收益不抵**。
>⚠️ **术语**：本节统一叫「**牲畜**」（类目，涵盖马 / 驴 / 驼等）；**「驮畜」是其中一类**，不是全部。旧写法"默认统一按驮畜处理"**已作废** —— 那把一个子类当成了全集。
> 🔴 **搭配**：`23 §2.2` 动力轴原写「**驼兽 / 旧文明引擎**」—— **"驼兽"已改称「动力装置」**，避免与本节的牲畜纠缠。

## 5. 失败条件

🔴 **2026-10-06 用户裁定：这里没有"游戏结束"这回事 —— 所有失败都只是「撤退」。** 🔴 **退到哪儿（2026-10-12 用户裁定）**：**玩家指定的、已探明的大城 / 小城** —— **不是"最近的"**（会被白赚路程）、**也不是"出发时的安全点"**（旧口径，已废），完整规则见 §5.2。

### 5.1 三种"失败"

|  #  | 类型          | 触发                   | 是谁决定的    |
| :-: | :---------- | :------------------- | :------- |
|  1  | **士气崩溃**    | 士气归 0                | 系统       |
|  2  | **全队失去战力**    | 🔴 **全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）**，**玩家真的没救了才触发** | 系统|
|  3  | 🔴 **手动撤退** | **玩家主动点撤退**          | **玩家自己** |

> 🔴 **第3 种（手动撤退）也算失败** —— 相当于**玩家主动认输**。但**代价明显小于前两种**（见 §5.3）。

#### 🔴 第 2 种的触发门槛：越难触发越好（2026-10-10 用户裁定）

> **用户原话**：「**强制撤退并不等于失败**……反而相当于**上调了强制撤退的下限**……玩家还有希望的时候不会强制撤退，**要完全没希望了才会**。」

**这是刻意把门槛调高的一批 —— 强制撤退触发得越难，玩家体验越好。**

**原条件（"全队倒下 + 商队耐久归零"）的问题**：它把**"打输了"**当成触发点 —— 但**打输不等于没救**：

| 漏洞 | 问题 |
|:--|:--|
| **车坏了 ≠ 修不好** | 耐久归零 → **抛锚 → 用零件能修好**（§2.4）—— 所以"车坏了"只是"停下来"，不是"没救了" |
| **重伤 ≠ 动不了** | 前三次重伤**都能靠等待恢复**（`第6A类 §7.2`）—— 所以"重伤"只是"这仗打得惨" |

**新条件 = 两条同时成立，"两头都堵死"**：

| | 条件 | 堵住什么 |
|:--|:--|:--|
| **① 人** | 🔴 **全队严重重伤** | 🔴 **全部失去战斗力** | 一个都不能上场（**注意：不是"重伤"** —— 前三次重伤能靠等待恢复） |
| **② 车** | 🔴 **零件耗尽** | 🔴 **再也修不好车** | 抛锚了也修不好 —— **真的走不了** |

> 🔴 **为什么是"零件"不是"药包"**（2026-10-12 用户纠正）：**药包只加血 —— 对「严重重伤」的人无效**（他不是伤，是动不了）。所以带不带药包都一样，**药包不该进触发条件**。
> 🔴 **零件才是真死结**：它是**唯一能解除抛锚的资源**（§2.4）—— 没了它，车一旦抛锚就**永远动不了**。

> ⚠️ **这不是"游戏结束"** —— 触发后仍然退回到安全点（§5.2），代价见 §5.3。**玩家可以接着玩**，只是这一趟完了。
> 🔴 **设计意图**：**玩家还有希望的时候，永远不会触发强制撤退。**

### 5.2 撤退去哪 🔴（2026-10-12 用户裁定 · 三处修正）

🔴 **原写法"最近的安全点（城市/城镇/驿站）"有三个漏洞，本节全部改掉。**

| 原写法的问题 | 🔴 改后 |
|:--|:--|
| 🔴 **"城市/城镇/驿站"都收** | **只有大城 / 小城收** —— 🔴 **城镇与驿站不接收撤退**（与 `第1A类 §6` 一致；它们只作中途补给/修车） |
| 🔴 **"最近"没说是否已探明** | 🔴 **必须是玩家已探明的** —— **没到过/ 没侦察过的地方，玩家不知道那儿有没有城**，不能撤过去 |
| 🔴 **"最近"能被玩家白赚** | 🔴 **不是"最近"，而是"玩家指定的、已探明的安全点"**（代价按实际要退回多远算） |

#### 🔴 漏洞："最近"会被玩家白赚一半路程

**如果按字面"退到最近的安全点"**，会出现这个局面：

> 玩家从灰原走到盐城（全程 60 格），走到第 40 格时手动撤退 → 如果**最近的已探明安全点就在第 30 格** → **玩家白捡了10 格路程**，订单还可能不算失败。

**等于"压着撤退按钮走"就能少走一半路** —— 🔴 **必须堵死**。

**堵法**：🔴 **撤退目的地由玩家指定**（限**已探明的大城 / 小城**），**代价按"实际要退回多远"计算**（见 §5.2.2）。

> **不是"最近"，是"你选的 + 你付代价"** —— 这样"往回退一点再撤"就不是白赚，而是**要真的走回去、真的亏货**。

#### 5.2.1 撤退目的地（三条硬规则）

| 规则 | 内容 |
|:--|:--|
| 🔴 **只能是大城 / 小城** | 城镇 / 驿站 / 村庄**都不接收撤退**（`第1A类 §6`） |
| 🔴 **必须已探明** | 玩家**实际到过**或**侦察到过**的地点 —— **未知的不能退** |
| 🔴 **由玩家指定** | 玩家在撤退界面选"退到哪座城" —— **不是系统自动选最近的** |

#### 5.2.2 撤退代价怎么算（🔴 按距离分档）

> **用户裁定（2026-10-12）**：「**这两条都会影响到货物的损失**……比如说我可能是 100 格撤退，那我可能手动撤退就是乘以四分之一，然后士气崩溃撤退乘以二分之一。」

🔴 **核心原则：退得越远，损失越大。**

**为什么必须按距离**：如果只按"手动 / 被动"固定比例，那**卡在某个距离反复撤退刷最低损耗**就成了最优解。

| 距离档 | 判定 | 手动撤退 | 士气崩溃撤退 |
|:--|:--|--:|--:|
| 🔴 **近** | ≤ 1/3 全程 | **10%** | **30%** |
| 🔴 **中** | 1/3 ~ 2/3 | **20%** | **45%** |
| 🔴 **远** | > 2/3 | **35%** | **60%** |
| 🔴 **强制**（全队严重重伤 + 零件耗尽） | —— | —— | 🔴 **固定 50%** |

- **为什么按距离**：货在车上**越久越危险**（路上还会遇到别的事）—— 所以**退得远 = 货损更大**，这合理。
- **强制撤退固定 50%**：**那时候已经没得选了**，代价应该**明确**，不该让玩家在"没救"时还去算距离。

#### 5.2.3 货损怎么扣（🔴 随机抽签，不是精确扣 %）

> **用户裁定**：「**随机选个几个格子抽**……让它凑到多少格……**可能我一次损失少一点，有一次损失多一点**。」

| 步骤 | 规则 |
|:--|:--|
| **① 排除储水格** | 🔴 **水不会被抽走** —— 它有专门的格子（水箱），**不参与货损** |
| **② 保险箱参与抽签** | 🔴 保险箱里的货**参与抽**，但**抽中不丢** |
| **③ 随机抽货凑格数** | 从剩下的货里**随机拿**，一直拿到**达标格数**就停（**不是精确扣 25%**） |
| **④ 每次不一样** | 🔴 **抽到大件就少抽几件，抽到碎的就多抽几件** |

> **为什么随机而不是精确扣**：① 玩家可以**优化**（碎货放外面、贵重放保险箱）；② 有**悬念**；③ **统一按格数算**，不用算货物价值。

#### 🔴 保险箱（新部件 · 2026-10-12 用户裁定）

| 项目 | 规则 |
|:--|:--|
| **作用** | 🔴 **里面的货物在货损中一定不会丢** —— **参与抽签，但抽中不丢** |
| **为什么要有它** | 扩容箱 / 防潮箱 / 药品箱**各有功能，不是保险** —— 需要专门一类**保护贵重物品** |
| **数量** | 🔴 **固定 1~2 个**（占格）—— **不能多**，否则"撤退不掉东西"变成常态 |
| 归属 | `第6A类 §11.4`（货舱模块） |

#### 🔴 撤退路上不再补扣补给（2026-10-12 用户裁定）

**原问题**：如果撤退路上照常按天扣补给，会出现**死档** ——
> 补给已耗尽 → 遇到意外 → 撤退 → **路上还要扣补给** → 全队饿死 → 到城直接死档。

**解决**：🔴 **撤退的代价是货损，不补扣补给。**

**为什么这样自洽**：**货损的钱 ≫ 撤退那几天的补给** → **玩家永远不会选"饿着走回去"** → 所以不需要再叠一层补给惩罚。

> **玩家的账**：撤退 = **一次性货损（重）** + **路上照常消耗**。两条都是真实代价，但**不会出现"饿死"**。

### 5.3 撤退代价（三者不同）

| 代价项| 士气崩溃 / 全队严重重伤+零件耗尽 |         🔴 **手动撤退**（玩家认输）         |
| :---------- | :-----------------------------: | :-------------------------------: |
| **性质**      |               被迫止损              |         **主动认输** —— 损失小一点         |
| 货物          | 🔴 **按距离档随机抽**（§5.2.2 / §5.2.3）     | 🔴 **按距离档随机抽**（玩家指定退去哪，决定档位） |
| 食物 / 水 / 零件 |              损失一部分              |                 少量                |
| 士气          | **不额外扣**（触发时已为 0）· 到达后**恢复到 1** |   🔴 **主动撤退 −2**（§4.3）· 到达后恢复到 1  |
| 商队耐久        |            降到 **30**            |               视损失比例               |
| 所有角色        |               强制休养              |                 无                 |
| 钱           |                不扣               |                 不扣                |
| 位置          |   🔴 **玩家指定的已探明大城/小城**    |              同左             |
| 当前订单        |            大概率失败或严重降级           |        **可当场放弃**（不罚士气之外的东西）       |

> 🔴 **为什么手动撤退的代价更小**：它是**玩家的主动选择** —— 玩家一看"这趟亏了"，**果断掉头止损**，这是**合理的经营决策**，不该跟"被打崩"同等处罚。系统惩罚的是**被动失败**（士气崩 / 全队倒），玩家主动认输只需要付"退掉的货"这份**真实成本**。>   
> ⚠️ 这也符合铁律 8：**惩罚只能要价，不能剥夺** —— 手动撤退的代价是**货损 + 士气**，不是"你这一趟白干"。

### 5.4 全队严重重伤 + 零件耗尽（**门槛最高的一种**）

「**全队严重重伤（全部失去战斗力）+ 零件耗尽（再也修不好车）**」是**三种失败里门槛最高的一种** —— 🔴 **它是"真的没救了"才触发**，不是"打输了"就触发。它意味着**一个能打的人都没有，而且车再也修不好**。它的**专属代价**（在 §5.3 基础上追加）：

| 惩罚项         | 内容                                      |
| :---------- | --------------------------------------- |
| **货物**      | 🔴 **按固定 50% 抽**（不按距离 —— 强制撤退时已没得选，代价要**明确**） |
| 食物 / 水 / 零件 | **全部损失**（零件本来就已经耗尽）                |
| 所有角色        | **强制进入休养状态**（全部严重重伤 → 只能到城市治） |
| 当前订单        | **大概率失败或严重降级**                          |

> 其余项（位置 / 士气 / 耐久 / 钱）同 §5.3：**退回到玩家指定的已探明大城 / 小城（§5.2.1）** · **士气不额外扣、到达后恢复到 1** · **耐久降到 30** · **钱不扣**（避免彻底死档）。>   
> 这会非常痛，**但还能继续** —— 玩家不会被踢出游戏。
> 🔴 **触发条件见 §5.1 的专门说明** —— 关键是**「玩家还有希望时不触发」这条设计意图**：前三次重伤**都能靠等待恢复**，所以只有**第四次（严重重伤）+ 零件也耗尽**才算真的没救。
