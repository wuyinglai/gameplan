# 动态经济系统设计方案（独立大类）

> 状态：v0.2（待定项已补全：供需公式 / 波动上下限 / 基准恢复均已设计，全部数值标 ⚠️ 初值待实测）
> 说明：**全局系统**——不属于商会、也不属于城市。玩家自己运货、NPC运货、一切商业活动都会影响供需和价格。
> 关联：订单与贸易系统、城市系统、商会系统、主线

---

## 一、核心机制

**运输改变供需，供需改变价格。**

- 玩家（和NPC商队）运货到某城市 → 该城市此货物变多 → 价格下降
- 城市货物被买走/消耗 → 变少 → 价格上涨
- 世界物价不是固定的，是被"做生意"这件事动态改变的

---

## 二、例子

| 情况 | 结果 |
|:-----|:-----|
| 运大量食物和水到火油城（沙漠城市） | 火油城食物水**降价**、**不再短缺** |
| 长期没人给黑石城送粮 | 黑石城粮价上涨、短缺加重 |
| 大量采购海盐城的海盐 | 海盐城盐价上涨（供不应求） |

---

## 三、玩家能利用它做什么

| 玩法 | 说明 |
|:-----|:------|
| **低买高卖** | 看准供需缺口：缺货的城市运去→卖高价 |
| **解决短缺** | 城市缺什么运什么→价格回落→城市感激（声望） |
| **制造机会** | 大量买入某地货物→拉高当地价→再高价卖出（投机） |
| **长期供应** | 挂长期订单稳定供应→稳定价格→稳定收入 |

---

## 四、对城市的影响

- 城市"短缺"状态可以**被玩家治好**（运货解决）
- 城市繁荣度/价值受供需影响（配合城市经营）
- **跑商不是单纯赚钱——你在改变每一座城市的生活**

---

## 五、防刷限制（避免被滥用）

| 限制 | 说明 |
|:-----|:------|
| 价格波动幅度 | 乘数上下限：普通货 [0.5, 2.0]、战略资源 [0.7, 1.5]，超出一律 clamp，不会崩盘/暴涨（见 §6.4） |
| 恢复速度 | 每日向基准回归 5%（bias ×= 0.95），一次性囤货/扫货的影响会随时间消退，不会一劳永逸（见 §6.5） |
| 情报可见 | 玩家能看到各城供需/价格状态（情报系统配合） |

## 六、供需公式与参数（已设计）

### 6.1 核心变量

每座城市对每个货物维护一个**供需净偏移 `bias`**（浮点数，初始 0）：

- `bias > 0`：该城该货**供过于求**（运入多、买走少）
- `bias < 0`：该城该货**短缺**（买走多、运入少）

### 6.2 偏移如何变化

| 事件 | bias 变化 |
|:-----|:---------|
| 玩家或 NPC 商队运入 Q 单位 | `bias += Q / SCALE` |
| 玩家买走 / 城市自然消耗 Q 单位 | `bias -= Q / SCALE` |

- `SCALE` = 该城该货的**规模系数**（基准日均交易量）。⚠️ 初值：普通货 **50**，战略资源/紧俏货 **20**（规模小→同样运量造成更大波动，更灵敏）。

### 6.3 价格乘数

成交价乘数由 `bias` 经弹性函数得出：

```text
multiplier = 1 / (1 + E × bias)
```

- `E` = 价格弹性。⚠️ 初值：普通货 **0.5**、战略资源 **0.3**（战略资源对供需更钝感，防止几趟货就拉崩）。
- 物理含义：供过于求（bias>0）→ 乘数<1（降价）；短缺（bias<0）→ 乘数>1（涨价）。
- 用 `1/(1+E·bias)` 而非线性，保证**价格永不为负**，且越偏离边际效应越弱。

### 6.4 波动上下限（防崩盘）

| 货物类型 | 乘数下限 | 乘数上限 |
|:-----|:---:|:---:|
| 普通货 | 0.5（半价） | 2.0（双倍） |
| 战略资源 | 0.7 | 1.5 |

超出一律 clamp；价格不会归零，也不会暴涨到离谱。

### 6.5 基准恢复（防僵尸价）

每天（游戏内）所有 `bias` 向 0 缓慢回归：

```text
bias *= (1 - REC)
```

- `REC` = 每日回归率，⚠️ 初值 **5%**（≈20 天衰减到一半）。
- 含义：城市自有消耗/补充、其他商队活动会把供需拉回基准。玩家一次性囤货/扫货造成的价格漂移会随时间消退，**不会永久改变某城价格**。

### 6.6 与现有经济文档的叠加关系

本系统是**动态供需层**，与以下两层乘法叠加，互不冲突：

```text
最终成交价 = 城市基准价      (第2.1类 物价锚点层，不动)
           × 地域系数        (各城一套价，doc14，不动)
           × 每日三角波动    (1+δ，doc14，不动)
           × 供需乘数        (本系统 §6.3，缓慢漂移层)
```

- 第2.1类 = 基准价锚点层
- doc14 = 地域价差 + 每日随机波动层
- 本文件 = 运货累计改变供需的**缓慢漂移层**（长期、可被玩家经营改变）

### 6.7 参数总表（⚠️ 初值，待实测调优）

| 参数 | 普通货 | 战略资源 |
|:-----|:---:|:---:|
| SCALE 规模系数 | 50 | 20 |
| E 价格弹性 | 0.5 | 0.3 |
| 乘数下限 | 0.5 | 0.7 |
| 乘数上限 | 2.0 | 1.5 |
| REC 每日回归率 | 5% | 5% |

### 6.8 验证（与第二章例子对齐）

| 原例子 | 验算 |
|:-----|:-----|
| 运 500 食物到火油城 | bias += 500/50 = +10 → 乘数 = 1/(1+0.5×10) = 0.167 → clamp 0.5（半价，且短缺解除）✅ |
| 长期不送粮给黑石城 | 每日消耗使 bias 持续下降 → 短缺加重 → 涨价 ✅ |
| 大量采购海盐城盐 | 买走使 bias 下降 → 乘数上升 → 涨价（供不应求）✅ |
