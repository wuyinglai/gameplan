# 主线故事大纲（小说式）

> 状态：故事大纲 v0.5
> 说明：整个主线是一整条故事，支线是故事中的插曲。本文按小说梗概的方式写完整故事的起承转合。

---

## 一、世界观基调

**母兽正在沉睡**——灰烬母兽在烬渊山的地底沉睡，短期内威胁不大：它不会醒着统治世界，也不会主动袭击谁。但**玩家激活节点有可能把它惊醒**，惊醒之后才是真正的灾难。

玩家前期没有"必须救世界"的压力——你激活城市是做生意，把母兽惊醒的风险是后面才知道的事。

---

## 二、玩家为什么心甘情愿激活节点（驱动力）

1. **激活 = 城市复活 = 商路打通 = 更多生意可做**（钱）
2. **城主给报酬**（钱/货/图纸/声望）
3. 部分城主给**特殊好处**（配方、情报、人脉）
4. **商队声望**——在九城的信誉，影响一切交易

> 玩家不是活菩萨，不是救世主。激活节点首先是一笔买卖。

---

## 三、九城掌权者态度（友善2 / 中立4 / 敌对3）

**所有城主都知道激活有好处，都愿意让玩家激活。** 区别只在"给真报酬"还是"另有所图"。

| 城市 | 态度 | 理由 |
|:-----|:----:|:------|
| **灰原城** | ⚪ 中立 | 城主软弱，商会管事，公事公办（新手安全区） |
| **枯林城** | 🔴 敌对 | 猎首表面欢迎，实际想独占核心——**诱骗进城设局抢夺**（前期第一课） |
| **鱼水城** | ⚪ 中立 | 水司想抢但没动手，只是谈判刁钻、防着玩家（前期缓冲） |
| **粮野城** | 🟢 友善 | 农长最实在，谈价干脆，真给报酬 |
| **海盐城** | 🔴 敌对 | 某个盐场主想夺权，设局抢核心（中期考验，玩家已有经验可识破） |
| **火油城** | ⚪ 中立 | 油主精明，只谈生意，给钱大方但防着玩家 |
| **药泽城** | ⚪ 中立 | 长老会守着文献，合作但不轻易松口 |
| **黑石城** | 🟢 友善 | 工头长正直，欢迎激活，给报酬+图纸 |
| **灰烬城** | 🔴 敌对 | 教团暗中把持，想利用/阻止核心（终局） |

**节奏：** 中立 → 敌对(枯林·第一课) → 中立缓冲 → 友善 → 敌对(海盐·中期) → 中立 → 中立 → 友善 → 敌对(灰烬·终局)

> 敌对的城分散开：前期一次教训、中期一次考验、后期一次对决，中间全是缓冲。玩家不会连续被坑，也不会忘了提防。

### 玩家面对敌对城的应对（不止这几种，更多后定）

| 方式 | 说明 |
|:-----|:------|
| 识破并反制 | 不进城/先付钱/带人提防，或反过来骗他们 |
| 策反民众 | 散布城主恶行，联合百姓推翻他（剧情线） |
| 同流合污 | 跟城主合伙一起发财，不管百姓死活 |

## 四、序幕：灰原城——一把钥匙

故事从灰原城开始。这是九城最边缘的城市，破败，但还活着——有市集、有酒馆、有人。

商队三人在灰原城跑商。某天酒馆里，一个快老死的人把他们叫住。老人从怀里摸出一件旧东西——**余烬核心**。他不知道这是干什么的，只说是祖上传下来的，可能是他爷爷的爷爷的爷爷哪辈子出门捡的、换的、还是偷的，时间太久，他也说不清了。反正传到他手上，他也没后代，快老死了，就想随便找个人把东西送出去，免得烂在箱底。

商队一开始没当回事。直到有人发现：核心能插进灰原城中心那个废弃的铁塔——节点反应炉。插进去，拉闸，**灰原城亮了**。水井出水，路灯亮起，工坊的锤声重新响起来。

灰原城的人第一次在夜里看见全城亮灯。城主站在城头说不出话，商会连夜给商队送钱。

**传说**：老商人告诉玩家，灰原城只是九城之一——像这样停摆的城市还有八座。它们的"铁心脏"都熄着。要是都能点着，整个九城就活了，那得是多大的买卖。

老商人送玩家一句话："**世界是灰的，但路是人走出来的。** 八座城还黑着呢，你要是愿意跑，这买卖够你做一辈子。"

商队出发了。为了生意——顺路，也让几座城市亮起来。

## 五、第一幕：商路初开——枯林城（第一次吃大亏）

第一站是枯林城。猎户之城，几个猎户家族把持一切，排外。

枯林城猎首**表面热情**：欢迎商队，说愿意谈激活节点的事，请商队进城详谈，许诺重酬。

**然后玩家吃了一个大亏**——进城后被设局：猎首翻脸，想抢夺余烬核心。玩家被迫应战/逃跑/交涉，损失惨重（货物被扣、队员受伤、声望受损），但**死不了**——核心没被抢走，还能继续玩。

**这一课玩家永远记住：不是每个笑脸背后都是好意。** 从此学会提防。

（具体翻脸方式、脱身途径：后定）

## 六、第二幕：中圈商路（鱼水/海盐/粮野）

商路网络开始成形。每座城的节点激活，都可能遇到不同情况：谈成、被骗、或跳过。

**线索全图分布**——灰潮真相的线索不用等到后面才有，每座城都有一小块拼图：
- 鱼水城旧码头：刻着旧文明文字的残缺石柱
- 海盐城老盐工：记得小时候见过"会走路的灰"
- 粮野城农长：无意提过"北边有座山，山里有动静"
- 火油城炼油厂：老技工说烬油"不干净"，里头有"活的东西"的痕迹

### 鱼水城：水源即权力（中立）
水司掌握净水厂，城主是傀儡。水司**想抢核心但没动手**——他谈判刁钻、处处防着玩家、条件苛刻，但始终守住了"生意"的底线。玩家吃过枯林城的亏，在这里会格外提防，但最终发现：水司只是难缠，不是骗子。

### 海盐城：投票与盐场（敌对·中期）
公会内斗。某个盐场主想借激活节点夺权——他许诺重酬把玩家骗进城，设局想抢核心。玩家这时已有枯林城的经验，有机会识破。节点炉埋在旧盐场底下被盐壳封死，激活需要组织人手挖开（无论谁掌权都要做这件事）。

### 粮野城：最实在的地方
农长直接问玩家："你要什么？"玩家报个价，他点头。整个游戏里最干脆的一次交易。

## 七、第三幕：烬油与命脉（火油/药泽/黑石）

火油城油主那句"**你到底是来赚钱的，还是来当救世主的？**"——全篇主题句。

药泽城文献触到真相边缘、黑石城撞见教团正面势力。此时玩家回头看，会发现教团的网早就存在——只是现在才浮出水面。

**每座城都有教团的影子**——前期隐藏极深：
- 枯林城酒馆角落里那个总念叨"净化"的老酒鬼
- 鱼水城码头上帮人搬货的沉默力工
- 粮野城集市上低价卖"护身符"的货郎

玩家前期不会注意到他们是一伙的。只有走到黑石城之后回看，才惊觉教团的网早就撒遍了九城。

## 九、终幕：烬渊山（母兽沉睡之地）

**烬渊山**——灰烬城以北最大的山脉，山体蕴藏大量稀有矿物，但环境极其恶劣。灰烬母兽沉睡在山体的地底深处（一座超巨型矿山遗迹内部）。

**玩家怎么知道烬渊山：**
- 传闻：老商队、灰烬城拾荒者、教团只言片语
- 地图/线索：灰烬城数据库里有旧文明矿脉图，标注了烬渊山的位置
- 教团：他们知道烬渊山的一切，甚至守护着它

**进入方式：**
- 烬渊山必须经过灰烬区域（地理限制）
- 山体内部 = 超巨型矿山遗迹（1,000格以上）
- 遗迹里：旧文明机关、机械守卫、灰烬兽——战斗强度最高的区域

**玩家去烬渊山意味着什么（此时玩家已知）：**
- 激活节点让网络恢复，而网络恢复的尽头是唤醒母兽
- 教团认为"网络恢复 = 给母兽续命"，阻止玩家
- 但不去烬渊山，灰潮永远不会停止——九城还是会慢慢被灰吞掉

**选择：** 去，或不去（结局部分写）。故事到此，所有悬念都指向山底的母兽。

## 十、结局（四个方向）

### 结局A：「灰烬止息」（好结局）

**达成条件：** 最终战胜利。

**过程：** 玩家在烬渊山超巨型矿山遗迹深处找到旧文明的巨型装置（巨型武器/封印装置）。母兽苏醒后，玩家利用巨型装置对抗它——先铺状态削弱（标记/穿甲/迟滞），再用旧文明武器强发射（烧火种）重创，最终终结或封印母兽。

**结局画面：** 灰潮停止扩散，九城重连，世界重新亮起来。商队成了传奇——但玩家很清楚：自己只是把路走通的那个人。灰烬教团失去信仰崩溃；各城恢复运转，商路繁忙。

### 结局B：「灰烬吞噬」（坏结局）

**达成条件：** 最终战失败。

**结局画面：** 母兽彻底苏醒，暴怒失控。灰潮再次大规模爆发，吞没九城——这一次没有旧文明能压制它。整个世界被灰烬吞噬。商队的名字和最后的身影一起，消失在灰色的海里。

### 结局C：「时间结局」（经商结局）

**达成条件：** 玩家长期不做主线（约5000~10000天），触发时间结局。

**按玩家积累的财富给不同结局：**
- **富可敌国**：多年经商，商队成为九城最大的商行。世界维持灰，但你的钱包是亮的。你听说过烬渊山有个"传说"，但你没去过——那与你无关。
- **穷困潦倒**：多年漂泊，商队散了，车卖了，你一个人在驿站里喝着最便宜的劣酒。你怀里还揣着那把没人要的旧钥匙——但你已经不再想它了。
- （中间状态：普通商人了此一生，待细化）

### 结局D：「灰烬共生」（共存结局）

**达成条件：** 玩家在旅途中满足特定条件（灰烬城数据库读到"最终安全协议"真相、持有旧文明沟通装置、或旅途中某些选择被母兽"看见"），并在最终战选择不启动巨型装置攻击母兽，而是尝试与它建立联系。

**过程：** 母兽醒来，暴怒——但它没有立刻攻击，它在"观察"这个和旧文明不一样的人。玩家放下武器/启动沟通装置/说出关键的话。母兽第一次遇到"不把它当工具也不把它当神"的人。

**结局画面：** 灰潮没有完全停止，但**不再扩散**——母兽学会控制自己的力量，只守护灰烬区域。九城重连，商路恢复。烬渊山不再是绝地，而是世界的"边界"。母兽沉睡在烬渊山，偶尔醒来，看着商队从山下走过。玩家的商队成了唯一能"进出烬渊山"的商队——因为母兽认得他们。

**代价：** 灰潮仍在（没消失），灰烬区域依然是禁区；教团视玩家为"背叛者"；部分城市不信任这个结局（母兽还活着）。
