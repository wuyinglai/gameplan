## 各城特殊设施详情

### N6 火油城 —— 炼油厂
| 项目 | 内容 |
|:----|:------|
| 功能 | 将原油提炼成烬油 |
| 产出 | 烬油（节点反应炉核心能源，只能在此生产） |
| 解锁 | 节点激活 |
| 玩家用途 | 购买烬油、接烬油运输订单、用烬油换取火油城特产 |

### N2 枯林城 —— 锯木坊
| 项目 | 内容 |
|:----|:------|
| 功能 | 将枯木加工成各种板材和结构件 |
| 产出 | 大量木材、部分木质零件 |
| 解锁 | 节点激活 |
| 玩家用途 | 购买大量木材、低价木质零件 |

### N3 鱼水城 —— 净水厂
| 项目 | 内容 |
|:----|:------|
| 功能 | 利用旧文明设备净化水源 |
| 产出 | 纯净水（价比外面低） |
| 解锁 | 节点激活 |
| 玩家用途 | 补充补给（水比别处便宜）、接运水订单 |

### N4 粮野城 —— 食品作坊
| 项目 | 内容 |
|:----|:------|
| 功能 | 将粮食加工成各种可长期保存的食品和补给 |
| 产出 | 低价补给、干粮、军用口粮 |
| 解锁 | 节点激活 |
| 玩家用途 | 补充补给最便宜的地方、买驮畜 |

### N5 海盐城 —— 晒盐场
| 项目 | 内容 |
|:----|:------|
| 功能 | 旧文明晒盐设施，产量大品质高 |
| 产出 | 海盐（九城最好） |
| 解锁 | 节点激活 |
| 玩家用途 | 买盐（高价品，运到缺盐城市卖差价）、接盐运输订单 |

### N7 药泽城 —— 制药坊
| 项目 | 内容 |
|:----|:------|
| 功能 | 旧文明的制药设备，药包比别处便宜 |
| 产出 | 药包、解毒剂、净化药 |
| 解锁 | 节点激活 |
| 玩家用途 | 最划算的买药地方、接药品订单 |

### N8 黑石城 —— 锻钢坊
| 项目 | 内容 |
|:----|:------|
| 功能 | 旧文明冶金设备，九城最强 |
| 产出 | 高品质武器、护甲、金属零件 |
| 解锁 | 节点激活+材料修复 |
| 玩家用途 | 买最好的装备、装备强化、用图纸制作金属装备 |

### N9 灰烬城 —— 旧文明设施群
| 设施 | 功能 | 说明 |

## 城市联通关系

**九城时代后商路稀疏，但旧文明时代网络更密。玩家激活节点、打通商路后，城市间的实际通路如下：**

```
         枯林 ── 海盐
        /  |      |  \
     灰原   |      |   粮野
        \  |      |  /   |
         鱼水 ── 火油 ── 药泽
                  |      |  \
                  |      |   黑石
                粮野 ── 黑石 ── 灰烬
                              /  \
                          药泽    火油
```

| 城市 | 可直达 |
|:----|:-------|
| 灰原城 | 枯林城、鱼水城 |
| 枯林城 | 灰原城、鱼水城、海盐城 |
| 鱼水城 | 灰原城、枯林城、火油城、粮野城 |
| 粮野城 | 鱼水城、火油城、药泽城、黑石城 |
| 海盐城 | 枯林城、火油城、粮野城 |
| 火油城 | 鱼水城、海盐城、粮野城、药泽城 |
| 药泽城 | 粮野城、火油城、黑石城、灰烬城 |
| 黑石城 | 粮野城、药泽城、灰烬城 |
| 灰烬城 | **黑石城、药泽城、火油城** |

> **灰烬城作为旧文明旧都遗址，不止一条路可通**——黑石、药泽、火油三条旧道仍在（虽然都荒废了）。旧都曾是网络枢纽，灰潮后大部分路断了，但这三条还勉强能走。
