# 社会结构

> 九城时代的社会阶层划分。每个城市大同小异，细节略有不同。

---

## 一、总览

九城时代末期，每座城市的社会大体分为六个阶层：

| 阶层 | 地位 | 包含人群 |
|:----|:----:|:---------|
| **统治者** | 最高 | 城主/油主/大药师等及其家族 |
| **大商人/工头** | 高 | 商会负责人、大商队主、公会核心成员 |
| **技术工匠** | 较高 | 会修旧设备的人、铁匠、药剂师、炼油师傅 |
| **普通市民** | 中 | 小商贩、猎人、农民、渔民、手艺人 |
| **底层** | 低 | 无地农民、搬运工、临时工 |
| **边缘人** | 极低 | 流浪汉、拾荒者、被灰烬污染的人 |

---

## 二、各阶层详情

**统治者**
每个城市只有极少数人处于这个阶层。他们掌握着城市最重要的资源——土地、水源、能源、武力。住在城市最好的区域，有仆人，有卫队。但也并非高枕无忧——如果城市长期衰败，统治者的地位也会动摇。

**大商人/工头**
财富雄厚，能左右城市的经济决策。城主缺钱了也得找他们借。这一阶层和玩家关系最密切——玩家本身就是商队，到各个城市都要和商会打交道。

**技术工匠**
人数稀少但非常受尊重。掌握着旧设备的维修和操作知识——铁匠铺的师傅知道怎么打一把好刀，炼油厂的老技工知道怎么提炼烬油。无论到了哪个城市，技术工匠都不会饿死。他们通常不太关心政治，更在乎自己的手艺。

**普通市民**
城市里的大多数人。每天为了生计奔波，勉强糊口。不太关心城主是谁，更在乎明天的粮价和今天的治安。他们是市场的主要交易对象，也是各种消息的源头。

**底层**
无地农民、搬运工、临时工。干最苦最累的活，赚最少的钱。住在城市外围的破旧棚屋里。如果有人生病或受伤，往往没钱去医馆，只能硬扛。灰潮对他们影响最大——土地退化后他们第一批失去生计。

**边缘人**
流浪汉、拾荒者、被灰烬污染的人。不被视为城市的一员。灰烬污染者身上有明显的灰蚀痕迹，其他人会刻意避开。这些人通常出现在城市外围的废墟和灰烬污染区附近。偶尔知道一些别人不知道的秘密。

---

## 三、阶层流动性

阶层有一定的流动性，但不高：

| 向上途径 | 难度 | 说明 |
|:---------|:----:|------|
| 做生意发财 | 中 | 有本钱+运气，小贩可以变成大商人 |
| 学徒出师 | 低 | 跟师傅学手艺，学成了就是工匠 |
| 保卫城市立功 | 中 | 兽潮中表现突出，可能被领主赏识 |
| 发现旧文明遗物 | 高 | 找到有价值的旧设备或记忆，一夜暴富 |

> 玩家作为外来商队，不受这个阶层体系的限制。

---

## 四、阶层与玩家的关系

| 阶层 | 与玩家的关系 |
|:----|:------------|
| 统治者 | 发订单、给奖励、声望够高时可以接见 |
| 商会 | 声望系统、专属订单 |
| 技术工匠 | 修设备、做图纸 |
| 普通市民 | 日常交易、闲聊消息 |
| 底层 | 可能提供不值钱但有用的情报 |
| 边缘人 | 偶尔触发特殊事件 |
