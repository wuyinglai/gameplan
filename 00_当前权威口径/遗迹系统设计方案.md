# 遗迹系统设计方案 v3

> 状态：初稿 v0.3
> 说明：旧文明遗迹分布在整个大世界地图上，位置全部固定。

---

## 一、遗迹位置（已定）

- 遗迹分布在整个大世界地图上（不是局部小格子）
- **所有遗迹位置固定**，不会随机变化
- 玩家可记住位置、规划路线、反复探索

---

## 二、遗迹分布规律（已定）

**越靠近灰烬城，遗迹越多、越大、越危险。**

世界观依据：灰烬城建在旧文明旧都遗址上，是旧文明的核心区域。越靠近旧都，旧文明设施越密集。

| 区域 | 遗迹密度 | 遗迹等级 |
|:-----|:--------:|:---------|
| 灰原城周边（起点） | 稀疏 | 小型为主 |
| 中部区域 | 中等 | 中/小型 |
| 黑石城附近 | 较密 | 中/大型 |
| 灰烬城周边（旧都遗址） | **最密** | 大型/巨型为主 |

---

## 三、空间维度

| 维度 | 说明 | 入口方式 |
|:----|:------|:---------|
| **地面遗迹** | 直接暴露在地表 | 到达即进 |
| **地下遗迹** | 埋在地下（防空洞、地下城、掩体） | 需要特殊渠道/钥匙/任务解锁 |
| **高险遗迹** | 建在悬崖/高山顶，因能源丧失已坠落，但地形险要 | 需要升降装置等特殊渠道才能上去 |

> 高险遗迹世界观：旧文明浮空/高空设施因能源丧失大量坠落，但坠落位置地形险要，需要升降梯等旧装置才能到达。

---

## 四、遗迹内部规模（已定）

遗迹内部是格子区域地图，大小按类型分档：

| 规模 | 格数范围 | 对应类型 |
|:-----|:--------:|:---------|
| 小型 | 约 50 格 | 地下设施、小研究所 |
| 中型 | 100~300 格 | 研究所、矿山、大书库 |
| 大型 | 300~800 格 | 城市遗迹、工厂 |
| 超巨型 | **1,000 格以上** | 灰烬母兽所在遗迹 |

> 超巨型遗迹可达上千格甚至更多，探索时间长、风险高、产出顶级。

---

## 五、遗迹类型（细分）

| 类型 | 规模倾向 | 产出倾向 |
|:-----|:--------:|:---------|
| **城市遗迹** | 大 | 均衡（住宅/商区/市政） |
| **研究所遗迹** | 中 | 记忆最多 |
| **工厂遗迹** | 中~大 | 零件/装备最多 |
| **大书库遗迹** | 中 | 记忆/知识类产出（含世界观线索） |
| **矿山遗迹** | 中~大 | 矿石/材料最多 |
| **地下设施** | 小~中 | 火种概率高 |
| **高险遗迹** | 待定 | 最稀有 |

> 可继续扩充（军械库、码头、粮仓、发电站等），不限于此表。

---

## 五、发现方式

| 方式 | 说明 |
|:-----|:------|
| 地图直接显示 | 已知遗迹 |
| 探索发现 | 移动时发现固定遗迹 |
| 情报购买 | 酒馆/驿站买位置情报 |
| 任务指引 | 订单/悬赏指向 |

---

## 六、探索机制（同常规地图）

**遗迹探索和常规大地图探索一样：**
- 消耗：与常规移动相同（时间+补给）
- 形式：在遗迹范围内移动探索
- 事件概率调整：
  - 常规随机事件概率**大幅降低**
  - 战斗随机事件概率**大幅提升**

**战斗配置（已定）：**
- **主体**：旧文明机关、旧文明机器人（遗迹守卫）
- **辅助**：灰烬兽、普通野兽（被吸引进遗迹的）
- **没有强盗**——强盗不会进遗迹

**战斗强度：**
- 比遗迹外正常跑商战斗**强约 25%**
- 数量更多、更密集

**撤离：** 可中途撤离，已消耗的时间和补给不返还。

---

## 七、产出

| 类型 | 说明 |
|:-----|:------|
| 记忆 | 研究所/大书库最多 |
| 旧文明零件 | 工厂遗迹最多 |
| 矿石/材料 | 矿山遗迹最多 |
| 火种 | 地下设施概率高 |
| 图纸 | 中型以上 |
| 装备 | 旧文明武器/护甲 |
| 灰烬材料 | 兽潮相关 |
| 世界观线索 | 大书库遗迹 |

---

## 九、奖励结算（已定）

**核心区域/特殊建筑触发式：**
- 遗迹内部有核心区域、特殊建筑
- 走到特定格子时触发特殊事件（如：在大书库遗迹中走到某一格，发现大书库）
- 触发后获得记忆、知识等奖励

**物资刷新规则：**

| 项目 | 规则 |
|:-----|:------|
| 特殊格子奖励 | **一次性**，拿过就没有 |
| 宝箱 | **不刷新** |
| 敌人 | 是随机事件，不存在刷新问题——每次进遗迹都可能遇到 |
| 守关 Boss | **部分有、部分没有**（机器人/陷阱等，详细后定） |
| 首次探索 | 首次探索能获得大部分好东西 |
| 二次探索 | **意义不大**（特殊物资不会刷新，只剩敌人） |

## 十、探索风险（已定）

**与正常探索风险相同，只是敌人更多、战斗更密集。** 没有额外风险机制。

## 十一、与主线绑定（已定）

**灰烬母兽所在的超巨型遗迹，是一座山底下的超巨型矿山遗迹。**

- 之前世界观设定灰烬母兽在某座山底下
- 那座山 = 旧文明**超巨型矿山遗迹**（1,000 格以上）
- 主线最终决战发生在该遗迹内部

## 十二、待定

| 待定项 | 说明 |
|:-------|:------|
| 探索消耗具体数值 | 时间/补给 |
| 旧文明机关/机器人配置 | 强度/数量 |
| 各类型遗迹数量 | 分布细节 |
| 高险遗迹入口装置 | 因情况而定，暂不写 |
