# 城市系统：小城（Demo用）

> 文档状态：v0.1
> 说明：小城是九城网络失败后民众自发聚集形成的定居点（约1万人、无节点、无旧文明特殊设施）。
> 本文件定义**Demo使用的2座小城**（灰原城周边），作为大城与野外之间的贸易点。

---

## 一、小城通用设定（参考第2A类）

| 项目 | 设定 |
|:-----|:------|
| 来源 | 九城失败后民众自发聚集形成 |
| 人口 | 约 1 万（参考） |
| 节点 | 无节点反应炉 |
| 设施 | 正常设施都有（商店/集市/酒馆/驿站），**无旧文明特殊设施**（无交易所/医馆/工坊等需节点激活的设施） |
| 物价 | 跟大城一档，但比大城**稍贵一点**（参考） |
| 治安 | 比大城危险一点 |
| 订单 | 有本地订单（送货/收购） |

---

## 二、Demo小城A（灰原东南）

| 项目 | 设定 |
|:-----|:------|
| 位置 | 灰原城东南方向，约2~3格 |
| 人口 | 约 1 万 |
| 特点 | 农耕型小城——产粮，附近有小片耕地 |
| 设施 | 商店、集市、酒馆、驿站 |
| 特产 | 粮食（比灰原城略便宜一点） |
| 稀缺 | 缺盐、缺零件 |
| 订单 | 收购粮食、送盐过来 |
| 物价 | 基准+10%（参考） |

---

## 三、Demo小城B（灰原西北）

| 项目 | 设定 |
|:-----|:------|
| 位置 | 灰原城西北方向，约3格 |
| 人口 | 约 1 万 |
| 特点 | 猎户型小城——靠打猎和拾荒为生 |
| 设施 | 商店、酒馆、驿站 |
| 特产 | 兽皮、肉（比灰原城便宜） |
| 稀缺 | 缺粮、缺水 |
| 订单 | 收购兽皮、送粮食过来 |
| 物价 | 基准+10%（参考） |

---

## 四、Demo小城功能（简化版，Demo够用）

| 功能 | 说明 |
|:-----|:------|
| 交易 | 买卖特产/补给（价格见数值表） |
| 接订单 | 本地订单（送货/收购） |
| 休息 | 花50金，士气+1 |
| 补给 | 买食物/水（比大城贵一点） |

> Demo不做：医馆（治疗）、工坊（修车只能回灰原城或用零件）、记忆设施。
> 小城无节点——**只有灰原城能激活节点**（Demo核心目标清晰）。
