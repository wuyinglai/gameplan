# 多主线系统设计方案

> 状态：v0.1
> 说明：游戏采用**多条主线**结构——玩家自由选择主线，一个存档体验一条（或几条），可通过开新存档体验其他主线。
> 更新：2026-08-18（多主线框架取代单主线；商会/城市经营恢复启用）

---

## 一、核心结构

### 1.1 世界基础活动（不是主线）

| 活动 | 说明 |
|:-----|:-----|
| **点亮九城** | 像开放世界"开图"——玩家自由做的基础目标（激活节点、打通商路） |
| 定位 | 不是主线本身；但某些主线可能**要求**先激活某些城（前置条件） |

### 1.2 多条主线（总框架9条）

- **总框架：9条主线**
- 现在先定 **3 条**（其余6条之后再做）
- 每条主线独立：有自己的目标、故事、结局
- **不做"多线完成度"机制**（难设定）——玩家一个存档选择推进主线，想体验其他主线就开新存档

### 1.3 存档设计

- 一个存档 = 一条主线的主视角体验
- 玩家可开多个存档体验不同主线（多周目式）
- 不强制一个存档玩完所有主线

## 二、已定3条主线

### 主线①：商道线（商人之道）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 打通全部商路，建立九城最强商行（商业帝国） |
| 配套玩法 | **商会系统**（创建商会/雇佣商队/发布订单）+ **城市经营**（买城/收税/建设）+ **动态经济**（供需影响价格） |
| 对应玩家 | 纯商人——最契合商队身份 |
| 结局方向 | 富可敌国 / 商行崩塌 / 商业帝国（具体结局后定） |

### 主线②：秘闻线（灰潮之秘）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 查清灰潮真相、母兽来历、旧文明秘密 |
| 配套玩法 | **遗迹探索**（旧文明废墟）+ **情报系统**（线索收集）+ 各地文献 |
| 对应玩家 | 求知的探索者 |
| 结局方向 | 真相公开 / 真相深埋 / 真相被利用（具体结局后定） |

### 主线③：救世线（终结灰潮）

| 项目 | 内容 |
|:-----|:-----|
| 玩家目标 | 激活九城、直面烬渊山的母兽，终结灰潮 |
| 配套玩法 | **卡牌战斗**（高难Boss战）+ **旧文明武器**（终极爆发）+ 激活节点 |
| 对应玩家 | 想当英雄的人 |
| 结局方向 | 吸收现有4结局：灰烬止息 / 灰烬吞噬 / 灰烬共生 / （时间结局） |

> 现有主线故事（激活九城→真相→烬渊山→母兽）归入**救世线**。

## 三、玩法多样化（配合多主线）

主线多了，玩法也要多样，每条主线有各自的玩法重点：

| 主线 | 核心玩法 | 次要玩法 |
|:-----|:---------|:---------|
| 商道线 | 贸易/经营/商会 | 跑商/护送 |
| 秘闻线 | 探索/遗迹/情报 | 战斗/解谜 |
| 救世线 | 战斗/激活节点 | 跑商（补给准备） |

> 玩家选不同主线 → 玩法侧重不同 → 一个游戏多种体验。

---

## 四、主线冲突（部分互斥）

- **不是所有主线都冲突**——有些可并行
- **部分主线互斥**：核心资源/NPC互斥时二选一
  - 例：A线要杀某NPC，B线要保护该NPC → 做了A，B锁死
- 冲突关系：**具体哪几条冲突，之后定**
