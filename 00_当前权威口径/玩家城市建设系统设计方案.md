# 玩家城市建设系统设计方案

> 状态：v0.2（2026-08-23）
> 说明：**玩家拥有自己城市后的完整系统**——购买、当城主、建设、经营、防守战。
> 区别于世界设定（九城总表/统治结构等见各独立文件），本文件聚焦"玩家自己的城"。
> 关联：商会系统（资金/订单）、灰兽潮系统（防守战触发）、动态经济

---

## 一、定位

**城市建设 = 主要玩法之一（约占整个游戏玩法的25%）**，不是辅助玩法。

### 1.1 玩法阶段进化（避免重复无聊）

| 阶段 | 玩法 | 说明 |
|:-----|:-----|:-----|
| **前期** | 自己跑商攒钱 | 生存+积累，熟悉跑商循环 |
| **中期** | 攒够钱 → 成立商会 → 购买城市 | 大部分玩家中后期都会转型经营 |
| **后期** | 跑商 + 经营 + 解决城市问题（混合） | 多种玩法交织 |

### 1.2 玩家要自己动手（不是挂机经营）

**城市经营不是躺着收钱——玩家要亲自处理城市周边的问题：**

| 问题 | 玩家要做的 |
|:-----|:-----------|
| 城市周边有土匪 | 用**自己的商队**出城清剿 |
| 某条商路被截断 | 亲自去疏通（战斗/护送） |
| 城市附近有威胁（兽潮/野兽群） | 带队清理 |
| 城市缺货/物价崩 | 亲自运货解决（跑商联动） |

> **核心：城市经营 = 经营 + 行动。** 玩家拥有城市后不是挂机——城市带来的问题（土匪/截路/威胁）都需要玩家用自己的商队去解决，跑商和战斗依然重要。

### 1.3 玩法占比（参考）

| 玩法 | 占比 |
|:-----|:----:|
| 跑商/贸易 | ~40% |
| **城市经营（含解决问题）** | **~25%** |
| 战斗/冒险 | ~20% |
| 其他（剧情/事件等） | ~15% |

### 1.4 核心关系

- 商会的钱 → 买城
- 城市的税收 → 养商会
- 玩家的商队 → 解决城市问题（清剿/疏通）
- 玩家身份：商会会长 + 城主 + 商队长（三者一体）

## 二、购买城市

| 项目 | 规则 |
|:-----|:------|
| 可购买 | **村庄 → 驿站/小镇（同级）→ 小城 → 九大城**（价格递增） |
| 时机 | 村庄前期就能买（最便宜）；九大城后期极贵（终极目标） |
| 驿站与城镇 | **平级**（第2A类：城镇和驿站平级）——价格同档，比村庄贵 |
| **驿站** | 也能买——功能像城市，但特色是**收过路费**（见下方"驿站购买"） |
| 价格 | 按城市规模/价值定（后定） |
| 与主线 | 九大城购买是后期玩法；主线激活节点是"救人"，购买是"拥有"，不冲突 |
| 购买后 | 城市归玩家所有——收税、建设、任命、防守 |

## 三、驿站购买（特殊地点）

### 3.1 驿站世界观（为什么断联后还有驿站）

商路断了之后，驿站**没人光顾了**，但驿站**还有人**：

- 驿站里的人世代生活在驿站周边——种田、狩猎，自给自足
- **九城时代留存的货物**还在驿站仓库里 → 这就是为什么驿站**零件便宜**（旧文明的存量）
- **补给贵**——因为补给都是自己种/打猎来的，量少价高
- 这样驿站的设定就合理了：旧货便宜、新补给贵、人守着驿站过日子

### 3.2 驿站购买与功能

| 项目 | 规则 |
|:-----|:------|
| 可购买 | ✅ 驿站也能买（前期便宜） |
| 功能 | 和城市差不多：可建设/经营 |
| 特色 | **收过路费**——经过的商队要交钱（商路流量×费率） |
| 其他 | 补给收费/修车收费（过路费+服务费） |
| 价值 | 驿站守着商路——商路通了，过路费就是稳定收入 |

## 四、城主功能

| 功能 | 说明 |
|:-----|:------|
| **收税** | 获得城市一定百分比的税收（税率可调，后定） |
| **看产业** | 查看城市产业（特产/商铺/工坊）——决定城市价值和税收 |
| **建设** | 简化自由建造（见第四章） |
| **颁布法令** | 宏观调控城市发展方向（见4.9） |
| **任命** | 任命管理者代管（玩家不在也能运转） |
| **防守** | 城市被袭击时进入防守战（见第七章） |

## 五、自建城镇（野外开荒）

### 5.1 机制

玩家在**野外发现资源点/矿点**（无主地），可以**自己开发建设城镇**——从零开始建。

| 项目 | 规则 |
|:-----|:------|
| 发现 | 野外探索发现资源点（铁矿/矿脉/林场等） |
| 获取 | 这块地**无主** → 玩家**买下/占地**开发 |
| 代价 | **很贵**——开荒+招工+建房都要很多钱 |
| 形成时间 | **很长**——工人待久了才有人来定居做生意 |

### 5.2 开发流程

1. **买地/占地**：买下资源点地块（贵）
2. **招工人**：花钱招工人来（工资高，因为地方偏）
3. **建住房**：给工人建房子（他们才留下来）
4. **开工**：工人开始挖矿/采资源 → 产出资源
5. **发展**：工人待久了 → 有人来做生意 → 有人定居 → 逐渐变成**小型城镇**
6. **成型**：小型城镇可继续扩建（4.2扩张规则）

### 5.3 特点

| 维度 | 直接买城 | 自建城镇 |
|:-----|:---------|:---------|
| 成本 | 固定价格 | **很贵**（开荒+招工+建房） |
| 时间 | 买了就归你 | **很长**（慢慢形成） |
| 位置 | 固定 | **自主选择**（资源点附近） |
| 潜力 | 看城市本身 | **看资源点**（矿好就值） |
| 收获 | 立即收益 | 前期投入大，后期矿产出回报 |

> **自建城镇 = 高投入慢回报，但位置自主。** 适合想深耕资源点的玩家——买下好矿点自己开发，长远看比买现成城更赚。

## 六、城市建设

### 6.1 建设方式（已定：自由建造+地形）

**玩家自由建设城市**——位置、布局、形状由玩家决定：

| 要素 | 设计 |
|:-----|:-----|
| **不规则地形** | 城市地形不方正——两山之间/河边/山脚下（预定义地形，障碍格标"山/河"） |
| **大网格** | 小型10×10 → 大型100×100（文字界面显示局部可滚动） |
| **多格建筑** | 建筑占1~4格，**矩形为主**（1格/2格横竖/2×2）——L型等复杂形状延后 |
| **相邻加成** | 位置有意义：水井旁农田增产、矿场靠矿脉增产、商铺靠路口增收、民居远离污染 |
| **城墙** | 玩家可建城墙（占格子），防守战更轻松 |

**操作（文字界面）：** 选择格子 → 选择建筑类型 → 选择形状（1格/2格横/2格竖/2×2）→ 放置。

### 6.2 城市扩张（村庄也能变大城）

| 阶段 | 网格 | 说明 |
|:-----|:----:|:-----|
| 村庄 | 10×10 | 初始规模 |
| 城镇 | 更大 | 扩张 |
| 城市 | 更大 | 发展 |
| 大城市 | 100×100 | 最终 |

> 城市可以**扩建**——通过建设/人口/发展逐步扩大网格。**买的村庄也能扩建成大城市。**
> 网格大小范围：小型10×10 → 大型100×100（地形不规则，障碍格除外）。

### 6.3 建筑类型

| 建筑 | 效果 |
|:-----|:-----|
| **民居** | 增加人口上限 |
| **农田/粮仓** | 产粮（受土地肥力影响） |
| **水井** | 供水 |
| **商铺** | 增加税收/贸易 |
| **工坊** | 生产/加工 |
| **城墙/城防** | **防守战时更轻松**（守军+防御） |
| **娱乐设施** | 满足民众娱乐需求 |
| **矿场/采掘点** | 开发城市外资源点 |

### 6.4 地形与土地肥力

| 项目 | 说明 |
|:-----|:------|
| 土地肥力 | 城市地块有**肥力属性**——肥力高的地方种田收益高 |
| 地形加成 | 种田区域的城市 → 农田收益高；山区 → 矿场收益高 |
| 选址影响 | 买城时地形影响城市发展潜力（后定） |

### 6.5 资源点与开荒

| 项目 | 说明 |
|:-----|:------|
| 资源点 | 城市外的格子有资源（铁矿/林地/矿脉等） |
| 开发 | 建设**矿场/采掘设施**开发资源点 → 民众迁入、税收增加 |
| **开荒** | 城市外的格子可**开荒**扩展——消耗**资源+人手+时间** |
| 效果 | 开荒出的格子可建设 → 城市扩大 |

### 6.6 人口与劳动力

**人口 = 劳动力。城市有多少人，就有多少可用人力。**

| 项目 | 规则 |
|:-----|:-----|
| 人口 | 城市有总人口数 → 对应**可用劳动力** |
| 建筑耗时 | 建建筑需要人力+时间：**1人力 = 3天建成；3人力 = 1天建成** |
| 农田照料 | 农田每天需要**1个人力**照料（种田） |
| 开荒 | 可**无限向外开荒**，但代价极高：**城外开垦约需10人力/天 + 大量钱** |
| 人力有限 | 玩家会发现自己**人力不够**——大量农田但没人种，就**不会盲目向外开垦** |
| 经济来源 | 钱主要来源于**税收** |
| 居民关系 | 玩家**招募/雇佣居民**干活——但玩家是城主，**不是完全为居民服务**（居民是劳动力） |

> **核心矛盾：人力是有限的。** 玩家要在"种田/建设/开荒"之间分配人力——人力不够时，扩张自然停止（玩家自己权衡）。这是模拟经营的核心张力。

**人口流入：** 城市**幸福度高** → 吸引**周边/其他城市的居民迁入**（人口自然增长）。

### 6.7 民众需求系统（保持简单）

**居民需求自然产生，但不会提过分要求——核心就是"吃得饱饭"。**

| 需求 | 说明 |
|:-----|:------|
| **吃饭** | 保证居民吃得饱饭 → 基本满足（最核心） |
| 喝水 | 供水正常 |
| 交税 | 交不上税居民会不满 |
| 就业 | 有工作更好（非硬性） |

> **原则：需求系统简单。** 居民只要吃得饱饭就基本满意，不会提过分要求（不做复杂的娱乐/心情系统）。

### 6.8 社会稳定

- 民众满意度 = 吃饱饭（核心）+ 供水 + 税负
- 满意度低 → **社会不稳定** → 叛乱风险 / 人口流失
- 玩家平衡：多收税 → 钱多但民怨；少收税 → 民安但没钱

### 6.9 经济管控

- 玩家要管理城市经济，**避免经济崩溃**（亏空/供应断裂/税收崩）
- 城市经济 = 税收 − 维护费 − 民众消耗
- 破产/崩溃 → 城市荒废（可救，但要投入）

### 6.10 法令系统

| 法令 | 效果示例 |
|:-----|:---------|
| **种田减税** | 种田上缴税更低 → 民众更偏向种田 |
| **贸易扶持** | 降低商铺税 → 商业繁荣 |
| **募兵令** | 增加守军（消耗资源） |
| **休养生息** | 降低税收 → 民众满意度上升 |

> 法令 = 玩家宏观调控手段——引导城市发展方向（种田/商业/军事/休养）。

---

### 6.11 城市评级系统（自动升级）

**城市评级 = 称号制**（只是对城市贫瘠/富庶的称号），**不是角色升级**：

| 评级（示例） | 条件 |
|:-------------|:-----|
| 贫瘠 | 初始 |
| 普通 | 基础发展 |
| 富庶 | 发展良好 |
| 繁荣 | 高度发展 |

- **自动升级**：城市到达某个标准就**自动变成**对应评级——**不需要玩家花费材料/时间手动升级**
- 例：村庄扩建很大之后 → 自动变成城镇
- 评级影响：吸引力（人口流入）、税收基础等

## 七、城市发展与收益

| 项目 | 规则 |
|:-----|:------|
| 城市价值 | 产业+人口+繁荣度（决定税收） |
| 发展途径 | 解决短缺（运货）、建设、开通商路 |
| 动态经济 | 城市缺什么→玩家供应→城市繁荣→税收涨 |
| 原则 | **买城不是躺着收钱，要经营** |

## 八、风险与危机

| 风险 | 说明 |
|:-----|:------|
| **灰兽潮** | 兽潮来袭城市受损（税收降/建筑坏）→ **防守战** |

## 九、城市防守战（核心特色）

**防守战 = 玩家自己城市特有的战斗**（在别人城市不触发）。

### 9.1 触发
- 灰兽潮逼近玩家城市
- 强盗/势力大规模攻城

### 9.2 指挥官模式（区别于普通战斗）

| 维度 | 普通战斗 | 防守战 |
|:-----|:---------|:-------|
| 玩家角色 | 亲自上阵（3角色） | **指挥官**（不上场） |
| 牌组 | 角色技能牌 | **指挥牌** |
| 消耗 | 行动力 | 资源（士气/补给/零件/钱） |
| 目标 | 消灭敌人 | 守住城市 |

### 9.3 指挥牌机制

| 指挥牌类型 | 效果示例 | 消耗 |
|:-----------|:---------|:-----|
| **集结** | 守军集中防御某段城墙（全体防御+） | 士气 |
| **出击** | 守军主动出击（一波攻击） | 士气 |
| **补给** | 消耗补给给守军回血/恢复 | 食物/水/零件 |
| **陷阱** | 城墙布陷阱（对敌军造成伤害） | 零件 |
| **火攻** | 用火油/燃油烧攻城器械 | 烬油/钱 |
| **求救** | 呼叫援军/请求支援 | 声望 |
| **撤退** | 放弃一段城墙，退守内城 | 士气 |

> 指挥牌完整列表/数值：后定。城墙/城防建筑可让防守战更轻松（见4.3）。

### 9.4 守军

| 项目 | 说明 |
|:-----|:------|
| 来源 | 城市守军（数量/强度由城市发展+城墙/募兵令决定） |
| 状态 | 有生命/士气，打光则城市沦陷 |
| 补充 | 战后/平时花钱招募恢复 |

### 9.5 胜负与后果

| 结果 | 后果 |
|:-----|:-----|
| **胜利** | 袭击退去，城市保全；可能有战利品/声望 |
| **失败（沦陷）** | 城市被占领/摧毁（见9.6） |

### 9.6 沦陷与夺回

**沦陷后果（按敌人类型不同）：**

| 攻城者 | 建筑 | 居民 |
|:-------|:-----|:-----|
| **人类（其他城市/强盗）** | **建筑毁得多**（被劫掠/摧毁） | 居民**只少一些**（被抓走/逃散一部分） |
| **灰烬兽（兽潮）** | 建筑**毁得少**（兽不拆建筑） | 居民**可能全部没了**（被杀死/被污染） |

**夺回规则：**
- 城市沦陷后**可以夺回**
- 夺回后：**被摧毁的建筑要重建**（花钱/花人力）
- **居民少了要重新吸引**（幸福度/发展恢复后人口流入）
- 灰烬兽沦陷的城市：居民全没 → 几乎要从零开始（建筑还在，但没人）

> 不同敌人的沦陷后果不同：人类劫掠毁房留人，灰烬兽灭人留房。玩家夺回后的重建重点也不同。

## 十、城市外交与战争

**不只是兽潮攻城——城市之间也有外交与战争。**

### 10.1 城市间关系

| 关系 | 说明 |
|:-----|:-----|
| 和平 | 正常贸易往来 |
| 紧张 | 摩擦（抢订单/抢地盘） |
| 敌对 | 可能开战 |
| 战争 | 互相攻城 |

### 10.2 别的城市攻城

- 不只是兽潮——**其他城市/势力也可能来攻城**（玩家城市被进攻）
- 触发：与某城敌对/交恶时

### 10.3 玩家攻击别人的城市

- 玩家**也可以主动攻城**——攻打其他城市
- 攻城成功 → 占领/获取利益（后定）
- 代价：与对方交恶、世界声望影响

### 10.4 外交手段

| 手段 | 说明 |
|:-----|:-----|
| 谈判 | 解决冲突/定条约 |
| 通商协议 | 贸易优惠 |
| 结盟 | 共同防御 |
| 宣战 | 主动开战 |

> 外交系统详细规则：后定。

## 十一、在别城买地（地产）

**买不下一整座城市？可以先在别人城市买几块地。**

| 项目 | 规则 |
|:-----|:------|
| 机制 | 在**其他城市买地**（地块所有权）——买不起整城时的替代 |
| 用途 | 在这些地上**种田 / 建工厂 / 买矿**（开发资源点） |
| 例子 | 买下别人城市的**矿**开采 |
| 意义 | 不用拥有整城，也能在他城经营产业 |

> 地产 = 轻量版城市拥有——整城买不起时，先买地经营。
