# 商会经营系统设计方案 v2

> 状态：初稿 v0.2
> 说明：商队跑商（核心）+ 商会经营（约40%）双轨制，两者相辅相成。玩家可创建商会、雇佣商队、发布订单、购买城市、影响动态经济。定框架，不定详细数值。

---

## 一、定位

**商队是"手"，商会是"家"，两者相辅相成。**

- 亲自跑商 = 核心（主线、难单、遗迹、战斗）
- 商会经营 = 约 **40%**（雇佣商队、发布订单、买城、动态经济）
- 两者互相成就：商会帮你消化琐碎订单，你跑商赚的钱投入商会扩张

---

## 二、商会是什么

玩家自己创建的商业组织（不用加入别人的商会）。

| 项目 | 规则 |
|:-----|:------|
| 解锁 | **不一定要后期解锁——前期就能解锁** |
| 前期状态 | 解锁了但**没商队愿意加入**/雇佣极贵——商会空壳 |
| 后期状态 | 声望高了之后，雇佣变便宜，可以指挥商队完成订单 |

---

## 三、雇佣商队（核心机制）

| 项目 | 规则 |
|:-----|:------|
| 机制 | 玩家花代价**雇佣别的商队**替你运货/完成订单 |
| 收益 | 完成订单后，玩家获得**部分订单收获**（分给NPC一部分） |
| 好处 | 琐碎/重复的小订单不用自己跑——玩家不再觉得"小单也要跑很久很折磨" |
| 成长 | **后期能雇更厉害的商队，完成更难的订单** |
| 支付方式 | 不一定要金币——可以用**等价材料/物品**支付（对应价值的货物、材料） |
| 限制 | 太难的/太长的订单NPC商队依然完成不了，必须玩家亲自（保留核心玩法） |

---

## 四、发布订单（玩家当雇主）

| 项目 | 规则 |
|:-----|:------|
| 机制 | 玩家发布订单，让NPC商队来做 |
| 订单类型 | 收购材料、把货物运到对应城市等 |
| 支付 | 悬赏金（金币）或等价材料/物品 |
| 用途 | 城市建设、补给调度、赚取差价的中间商玩法 |

---

## 五、城市购买与经营

| 项目 | 规则 |
|:-----|:------|
| 能买什么 | 小城/小镇先买（便宜）；**九大城后期也能买**（极贵） |
| 买了之后 | 当城主：**规划区域**、查看有哪些**产业** |
| 收益 | 获得城市**一定百分比的税收** + 城市各种价值 |
| 建设 | 发布建设订单（用商会系统），让NPC做 |
| 时机 | 前期能买小镇，后期买大城（价格梯度） |

---

## 六、动态经济系统

| 项目 | 规则 |
|:-----|:------|
| 核心 | **运输改变供需，供需改变价格**（动态经济） |
| 例子 | 运大量食物和水到沙漠城市（如火油城）→ 那里食物水**降价**、不再短缺 |
| 效果 | 玩家跑商本身就在影响世界物价——做生意能"治好"城市的短缺 |
| 意义 | 让跑商有真实感：你不只是在赚钱，你在改变城市 |
| 注意 | 动态经济也要避免被刷（具体后定） |

---

## 七、跑商 vs 经营比例

| 玩法 | 占比 | 内容 |
|:-----|:----:|:-----|
| **亲自跑商** | ~60% | 主线、难单长单、遗迹、战斗 |
| **商会经营** | ~40% | 雇佣商队、发布订单、买城当城主、动态经济 |

---

## 八、待定

| 待定项 | 说明 |
|:-------|:------|
| 商会解锁条件 | 前期解锁的具体门槛 |
| 雇佣价格 | 金币/材料的换算 |
| NPC商队上限 | 能同时雇几支 |
| 订单收益分成 | 玩家拿多少、NPC拿多少 |
| 城市税收比例 | 城主拿百分之几 |
| 动态经济公式 | 供需影响价格的规则 |
| 城市购买价格 | 小镇/小城/九大城价格梯度 |
