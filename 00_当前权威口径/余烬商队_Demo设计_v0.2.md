# 《余烬商队》Demo 设计 · 权威口径 v0.2

> 文档状态：v0.2（Draft → 待你审核定版）
> v0.2 修订：① 地图放大到 100×100（大地图开放感，仍格子移动）；② 村庄 ×20（定位为 ubiquitous 最小聚落，必须测，修正此前"仅2村"的前后矛盾）；③ **系统做/不做最终裁定**（测核心广度、不测细枝末节，这是本版最重要结论）。
> 关联：第1A类地图、第2A类地点、第3A类商队资源、第4A类战斗、第5A类天气与事件。

---

## 一、Demo 目标与定位

| 项目 | 设定 |
|:-----|:------|
| **核心目的** | 测**核心系统的可行性**——广度优先、深度适中。不是"功能越少越好"（不能砍到测不出东西），也**不是全测**（细枝末节写了也跑不透，浪费工时）。把关键系统跑通、记下手感，留给正式版。 |
| **范围** | 灰原城周边大区域（1 大城 + 2 小城 + 中途网 + 大量村庄），不跨大区。 |
| **通关目标** | 携带余烬核心抵达灰原城并**激活节点**（Demo 终点）。 |
| **失败条件** | 全员失能且无法撤退 / 商队耐久 0 且无零件无撤退点 / 金钱与补给同时耗尽（阈值见数值表）。 |

> 设计口径：Demo 允许"粗糙但能跑"。但**系统范围本版已拍死**——第二节列表之外的不测，列表之内的必测。

---

## 二、系统做 / 不做 · 最终裁定（最重要）

> 判定原则：是否属于"大地图商队RPG + 卡牌战斗 + 订单护送 + 资源管理 + 天气风险事件"这个核心循环的骨架。是→测；否（成长深层/大事件/叙事/正式版专属）→不测。

### ✅ 必测核心系统（广度覆盖，11 项）

| # | 系统 | 测什么 |
|:--:|:-----|:------|
| 1 | **大地图移动 + 格子节点** | 上下左右走、空地/战斗/事件/营地/补给点/危险区六类格；绕路决策 |
| 2 | **商队资源管理与失败** | 补给/零件/药包/耐久/士气/金钱；每日消耗与耗尽惩罚 |
| 3 | **五类地点交互** | 大城/小城/城镇/驿站/**村庄** 全部功能（村庄×20 必测） |
| 4 | **交易与地区价差** | 各地点买卖价不同 → 跑商/自营贸易可行性 |
| 5 | **订单系统** | 送货+收购、最多3个、超时失败 |
| 6 | **卡牌战斗** | 3 角色 / 共享行动力 / 抽牌 / 多状态（标记·流血·穿甲·减速·灼烧·反击·护盾·超载） |
| 7 | **敌人 3 种** | 强盗 / 野兽 / 灰烬兽（Demo 轻量配置） |
| 8 | **随机事件** | 探索驱动，正面/负面/选择分支 |
| 9 | **节点激活** | 通关目标，仅灰原城可激活 |
| 10 | **天气系统（基础）** | 晴/雨/雾 3 种，影响移动消耗与事件触发（核心五大支柱之一，**不是细枝末节**） |
| 11 | **侦察信息等级** | 前方格子按 0–5 级显示可见度，影响探索手感（地图大了必须测） |
| + | **撤退系统**（归在资源管理下） | 耐久抛锚/全灭 → 撤到最近小城或大城；**驿站不接收撤退** |

### ❌ 不测（细枝末节 / 留正式版，本版明确不做）

| 不测项 | 原因 |
|:------|:-----|
| 记忆系统 | 成长太深，属第6类完整系统，Demo 跑不透 |
| 装备模块 | 你已裁定"算了" |
| 遗迹探索 | 大系统，留正式版 |
| 灰兽潮大事件 | 大事件级，留正式版 |
| 主线 / 支线剧情 | 叙事留正式版 |
| 存档 / 读档 | Demo 不存档 |
| 玩家城市建设 | 属第9类城市系统，留正式版 |
| 招募 / 角色替换 | 保持 3 人固定阵容，不测替换 |
| 情报购买经济 | 非核心循环（第2A类子项），本版不测 |
| 工会 / 商会 / 声望深层 | 经济社交深层，留正式版 |
| 多队员(>3) / 阵容缩放战斗 | 保持 3 人，不测 5 人缩放 |
| 地图随机生成 | 固定地图 |

> 以上"不测"≠不重要，是 Demo 阶段**写不起 / 非核心骨架**。先测关键的，跑通再扩。

## 三、地图规格（修订：100×100）

| 项目 | 上版（已否） | **本版** |
|:-----|:------------|:--------|
| 网格 | 14×12 = 168 格 | **100×100 = 10,000 格** |
| 定位 | 区域地图 | **大地图开放感**（自由上下左右走，有探索广度） |
| 移动 | 1 格=1天+1补给 | 同左，固定，无速度属性 |
| 格子类型 | 六类（无 Boss） | 同左（Demo 无 Boss 格） |
| 障碍格 | 10–15% | 约 10–15% 不可走（山河/塌方） |
| 地图生成 | 固定 | 固定（不随机） |

> 仍是大地图**格子移动**（非早期废弃的 3D 开放世界），只是格子够大、有开放探索感。
> Demo **不要求遍历全图**——靠 35 个地点 + 事件格测系统即可，不用走满 10,000 格。

## 四、地点清单（共 35 个）

| 类型 | 数量 | 说明 |
|:----:|:----:|:-----|
| 大城 | 1 | 灰原城（出发，唯一有节点） |
| 小城 | 2 | 农耕A（东南）、狩猎B（西北） |
| 城镇 | 6 | 镇1–镇6，补给/普通治疗/小订单/情报 |
| 驿站 | 6 | 驿1–驿6，零件/修车/路线情报；**不接收撤退** |
| **村庄** | **20** | 村1–村20，散布全图，最小聚落，**必测** |
| **合计** | **35** | 大城+小城 + 城镇/驿站(12) + 村庄(20) |

> 城镇+驿站 = 12 个（满足"≥10"）。村庄 20 个，定位为 ubiquitous 最小聚落——路上随处可遇，所以数量必须多，修正此前仅 2 村的矛盾。
> 地点命名均为代号，正式命名后补。

| 类型 | 核心功能 | 接收撤退 | 物价档（补给/零件/药包） |
|:----|:--------|:--------:|:-----------------------:|

> 各地点价差 → 跑商/自营贸易可行性测试的核心变量。

## 六、界面与操作（草案）

| 界面 | 内容 |
|:-----|:------|
| 主地图 | 100×100 网格（视口滚动）+ 商队位置 + 信息等级 |
| 状态栏 | 常驻（金钱/资源/耐久/士气/天数） |
| 地点界面 | 按类型显示可用项（交易/订单/休息/修车/治疗/激活） |
| 战斗界面 | 手牌队列 + 角色HP + 敌情 + 行动力 |
| 事件界面 | 文本 + 选项 |
| 订单界面 | 进行中/可接订单 |
| 结算界面 | 通关/失败统计 |

操作：W/A/S/D 移动；数字键选菜单；Enter 确认；Esc 返回。（键位数值表再定）

## 七、与权威设计的一致性核对

| 权威规则 | Demo 落实 |
|:--------|:----------|
| 余烬核心 = 激活钥匙（非能源），只激活城市节点 | ✅ 仅灰原城可激活 |
| 节点反应炉仅存在于城市 | ✅ 小城/城镇/驿站/村庄均无节点 |
| 无传送；驿站不接收撤退 | ✅ 撤退只撤大城/小城；无传送 |
| 地点五类：大城/小城/城镇/驿站/村庄 | ✅ 35 地点全覆盖五类（村庄×20） |
| 中继点仅城镇+驿站 | ✅ 12 个中途点 |
| 移动 1 格=1 天，无速度属性 | ✅ 固定 |
