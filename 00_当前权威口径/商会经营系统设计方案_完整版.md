## 第一部分：商会基础

## 一、商会是什么

商会是玩家**自己创建**的商业组织——不需要加入任何别的商会。玩家既是商队的老板，也是商会的会长，两者是同一套班底、两个身份。

**核心关系：商队是"手"，商会是"家"。**
- 商队负责跑（玩家亲自跑商、探索、战斗）
- 商会负责"养"（人手、业务、城市、持续收入）
- 两者相辅相成：商会帮你消化琐碎订单和后勤，你跑商赚的钱反过来投入商会扩张

**玩家身份可以兼任：**
- 玩家可以是**商会会长**
- 玩家也可以是**城主**（买下城市后）
- 两个身份不冲突，且能互相配合：
  - 例：你拥有A城和B城（或商会业务覆盖两城）
  - A城缺粮食、B城有余粮 → 你用商队/雇佣商队把粮食从B运到A
  - 结果：A城粮价降了（不再短缺）、B城卖出去了（产业活起来）、你自己两头赚钱
  - **商路连通城市 = 城市发展 = 你赚钱**——跑商和经营完全是一件事

---

## 二、创建流程

**创建方式（建议）：**
- 到任意**大城**的**商会大厅**（城市设施之一），申请登记
- 条件：满足基础声望 + 交一笔登记金（具体数值后定）
- 流程：登记 → 命名商会 → 创建成功

**创建后状态（重要）：**
- **前期就能创建**，门槛不高
- 但刚创建时是**空壳商会**：没有雇员、没有业务、没有分会
- 商会从"空壳"到"成规模"，靠玩家一步步经营

---

## 三、商会结构

### 3.1 会长与职位

| 项目 | 规则 |
|:-----|:------|
| 会长 | **玩家**（唯一） |
| 职位/部门 | 可以有——分"接单商队"、"探索商队"等方向 |
| 任命方式 | **指派有才能的人担任职务**（详见3.2） |

### 3.2 人才与才能

- 商会可以**指派NPC**担任职务（如分会负责人、业务主管、商队领队）
- 这些NPC**各有才能**，才能会给商会带来加成：

| 才能示例 | 效果 |
|:---------|:-----|
| 谈判才能 | 商会交易/雇佣价格优惠一点 |
| 调度才能 | 商队完成订单效率更高 |
| 探索才能 | 探索类业务收获更好 |
| 经营才能 | 分会/城市业务收入提升 |

> **明确不做：** 不做"忠诚度""心情""派系"这类常见游戏设定——商会的人就是干活拿钱的关系，简单直接。

---

## 四、商会规模等级（评分制）

**原则：等级只是"状态显示"，不限制玩家玩法。**

- 商会发展得好，评分涨；经营不善，评分跌
- 等级让玩家**清楚知道自己商会的规模**（相当于一个"成就刻度"）

| 等级（示例） | 状态 |
|:-------------|:-----|
| 小小商会 | 刚成立，一两支小商队 |
| 当地商会 | 在1~2个城市有业务 |
| 区域商会 | 业务覆盖多个城市，有分会 |
| 九城商行 | 业务遍布九城，传说级别 |

**评分加减（示例）：**
- 完成大订单 / 买下城市 / 建分会 → **加分**
- 濒临破产 / 商会亏空 / 业务失败 → **减分**

> 分数和等级不锁死玩法：就算等级低，玩家照样能自由做任何事；等级只是反馈。

---

## 五、分会（不强制总部）

| 项目 | 规则 |
|:-----|:------|
| 总部 | **不一定要有总部** |
| 分会 | 可以在各个城市（大城/小城）建立**分会** |
| 分会作用 | ①发布订单 ②发布指令 ③收税点/业务点 |
| 建立条件 | 花钱 + 该城声望达标（后定） |

**分会 = 商会在各城市的"据点"：**
- 玩家不在某城，也能通过分会发布订单、下达指令
- 分会是商会"远程经营"的窗口

---

## 六、商会开销

| 项目 | 规则 |
|:-----|:------|
| 结算方式 | **日结**——跟商队成员一样按天结算 |
| 开销内容 | 雇员工资、分会维护、商队雇佣费 |
| 意义 | 商会养着越多人越贵——玩家要平衡规模与收入 |

---

## 七、前期解锁状态（空壳到起步）

**前期不需要很多钱也能用商会：**

| 阶段 | 商会的用途 |
|:-----|:-----------|
| 刚创建 | 空壳，没业务 |
| 起步期 | 花小钱招 **1~2支小型商队**，让它们跑：超短途订单 / 很简单的小单 / 收集野兽材料 |
| 好处 | 这些琐碎小事不用玩家亲自跑——玩家专注主线和大单 |
| 局限 | **有用但远不如后期**——小商队只能干小活，难的长的干不了 |

> 前期的商会是"省心助手"，后期的商会才是"商业帝国"。

---

## 八、可购买范围（村庄起步）

- 玩家的城市购买**从村庄买起**（最便宜）
- 一路升级：村庄 → 小镇 → 小城 → 九大城（极贵，后期目标）
- 买了之后当城主：收税、建设、规划（详见子系统4：城市经营）

---

## 九、商会声望

| 项目 | 规则 |
|:-----|:------|
| 独立声望 | 商会有自己的**商会声望**（独立于玩家个人声望） |
| 高声望 | 更多人主动找你做生意、愿意把生意交给你的商会 |
| 低声望 | **没人找你做生意、没人愿意把生意给你**——商会难以为继 |

> 商会声望靠完成大订单、长期稳定经营、解决危机积累；被抢单、业务失败、破产会掉声望。

## 十、竞争对手（多个商会）

| 项目 | 规则 |
|:-----|:------|
| 不止一个 | 世界里**有很多商会**（玩家创建的只是其中之一） |
| 本地商会 | 每个城有**自己的本地商会**——九城虽断联，但各自与周边小城有生意联系 |
| 本地优势 | 本地商会一直在这做生意、**大家更信任他们**——玩家作为外地来的，天然处于劣势，他们要跟你竞争 |
| 竞争方式 | 抢订单、压价、抢地盘、抢客户 |
| 抗衡资本 | 本地商会规模/根基深，有跟玩家抗衡的实力（后期玩家做大后反过来碾压） |

## 十一、商会与各方关系

| 对象 | 关系 |
|:-----|:-----|
| 九城统治者 | 好感高→免税/优先权；低→被刁难 |
| 其他商会 | 竞争关系（抢单/抢地盘） |
| 灰烬教团 | 商会做大后会被教团盯上 |
| 灰兽潮 | 商会业务会被兽潮打断（危机） |

## 十二、商会危机（必须玩家参与，防挂机）

**商会不能全自动挂机赚钱——必须有危机，且必须玩家亲自解决，否则有参与感问题。**

| 危机 | 发生 | 玩家要做 |
|:-----|:-----|:---------|
| **商队被洗劫** | 手下的商队被强盗劫了 | 玩家要亲自**开通商路、清剿劫匪**，否则商队业务瘫痪 |
| **灰兽潮来袭** | 兽潮逼近 | 玩家要**命令所有商队躲进最近城市避险**，否则商队全灭 |
| **破产危机** | 商会亏空严重 | 玩家要**裁员、解散部分商队、缩小规模**度过危机 |
| **（其他危机后定）** | — | — |

> 设计原则：商会是"需要经营的活物"——赚钱时给回报，出事了要玩家出手。不能挂机。

## 第二部分：雇佣与派遣

## 一、核心定位

**玩家是"王牌"，NPC是"打杂的"。**

- 玩家亲自跑：主线、难单、长单、遗迹、战斗（核心玩法）
- 雇佣/派遣解决：琐碎、重复、简单的小订单——玩家不用再为"一个小订单跑几天"而折磨
- **难的单、长的单NPC完成不了，必须玩家亲自上**（保住核心玩法）

---

## 二、雇佣商队（让别人替你跑）

### 2.1 基本机制

| 项目 | 规则 |
|:-----|:------|
| 机制 | 玩家花代价**雇佣别的商队**替你运货/完成订单 |
| 支付 | **金币或等价材料/物品**（对应价值的货物、材料都可以） |
| 收益 | 完成后玩家获得**部分订单收获**（分给NPC商队一部分） |

### 2.2 商队等级与能力

| 商队等级 | 能干什么 | 雇佣价 |
|:---------|:---------|:-------|
| 小型商队 | 超短途订单、很简单的小单、收集野兽材料 | 便宜 |
| 中型商队 | 短途订单、普通订单 | 中等 |
| 大型商队 | 较长订单、较难订单 | 贵 |
| 精英商队 | 难单（但极难的还是要玩家） | 很贵 |

> 前期只能雇到小型商队（干杂活）；**后期声望高了能雇到更强商队**，做更难的订单。

### 2.3 收益分成

| 项目 | 规则 |
|:-----|:------|
| 玩家拿 | 大部分订单奖励 |
| NPC拿 | 一部分（雇佣费已付一部分，完成后再分一部分） |
| 比例 | 具体后定（原则：玩家拿大头，NPC拿跑腿钱） |

---

## 三、派遣NPC接单（自己的商会干活）

| 项目 | 规则 |
|:-----|:------|
| 机制 | 商会派手下NPC（或自家小商队）去完成订单 |
| 能接的 | **只有简单/短途订单** |
| 接不了 | 难单、长单——必须玩家亲自 |
| 数量限制 | **无上限**——一个NPC同时只能接一个订单，但**可以无限招NPC**（只需要花更多钱） |
| 收益 | **低于玩家亲自完成的收益**（NPC效率不如玩家） |

---

## 四、派遣指令（让商队去做什么）

**目标（已定）：让NPC能干绝大多数事**——不只是接单，还有收购、护送、探索、清剿、调查、跑腿杂务等——玩家不用每件小事都亲自跑，世界更真实。

> 具体指令列表与执行规则：**等真正做游戏时再写**。现在只定方向。

---

## 五、派遣结果与风险

| 结果 | 说明 |
|:-----|:-----|
| 成功 | 按约定交付，玩家拿收益 |
| 迟到 | 订单逾期，收益减少（玩家承担部分损失） |
| 货物受损 | 按损失比例扣收益 |
| **被劫** | 商队被强盗洗劫——**触发危机，玩家要亲自清剿**（见子系统1"危机"） |
| 兽潮损失 | 兽潮期间商队未避险——全灭风险（玩家要下令避险） |

> 派遣不是"稳赚不赔"——NPC商队会失败、会被劫，出大事还是要玩家出手。

---

## 六、与跑商玩法的关系（不喧宾夺主）

| 原则 | 说明 |
|:-----|:------|
| 琐碎单 | 交给NPC（省心） |
| 大单/难单 | 玩家亲自（核心玩法） |
| 收益 | NPC干活收益 < 玩家亲自收益——鼓励玩家亲自跑重要业务 |
| 危机 | NPC失败会连锁引发需要玩家解决的问题——玩家始终有参与感 |

## 第三部分：发布订单

## 一、核心定位

**玩家能接什么订单，就能发布什么订单。**

- 玩家平时是接订单的商队，商会成型后也可以当"雇主"
- 发布订单 → 其他商队/NPC接单 → 完成 → 玩家支付报酬

---

## 二、能发布的订单（与订单系统一致，4类）

| 订单类型 | 内容 |
|:---------|:-----|
| **送货订单** | 把货物运到指定收货地 |
| **护送订单** | 护送某人/某物到指定城市 |
| **收购订单** | 高价收购指定物品 |
| **悬赏订单** | 悬赏击杀指定敌人/Boss |

> 与玩家能接的订单完全一致——玩家能接什么，就能发布什么。

---

## 三、接单规则

| 项目 | 规则 |
|:-----|:------|
| 接单者 | 世界上的其他商队/NPC都可以接 |
| **优先自己人** | **优先给自己商会的人接**——自己人接单**更便宜一点**；自己人接不了/没人接才轮到外人 |
| 竞争 | 其他商队也可能接走你发布的订单（世界是活的） |

---

## 四、长期订单（固定周期供应）

| 项目 | 规则 |
|:-----|:------|
| 机制 | 发布**周期性订单**：每月/每天/固定时间送某物到某地 |
| 例子 | "每月送30份粮到火油城"、"每旬送盐到灰原城" |
| 好处 | 某个城市长期需要什么 → 玩家挂长期订单 → **省心**（不用每次重发） |
| 风险 | 签了就要履约，断供会损商会声望 |

> 长期订单 = 稳定的被动业务：城市长期缺的东西，玩家稳定供应，稳定赚钱。

---

## 五、与商会声望的关系

| 行为 | 声望影响 |
|:-----|:---------|
| 靠谱雇主（按时给钱、不赖账） | 商会声望涨 |
| 赖账/坑商队 | 声望崩，没人再接你的单 |
| 高价收购解决城市短缺 | 声望涨（城市感激） |
