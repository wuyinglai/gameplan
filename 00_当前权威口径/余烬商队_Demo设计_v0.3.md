# 《余烬商队》Demo 设计 · 权威口径 v0.3

> 文档状态：v0.3（Draft → 待你审核定版）
> v0.3 修订（相对 v0.2）：用户要求**保留装备/遗迹/记忆/招募**四项（v0.2 误判为不测）。装备做简化版（4–10 套），遗迹做 1–2 处简化探索，记忆测获取/装备/生效流程，招募限 1–2 人（队伍上限 5）。

## 一、Demo 目标与定位

| 项目 | 设定 |
|:-----|:------|
| **核心目的** | 测**核心系统的可行性**——广度优先、深度适中。不是"功能越少越好"，也**不是全测**。把关键系统跑通、记下手感，留给正式版。 |
| **范围** | 灰原城周边大区域（1 大城 + 2 小城 + 中途网 + 大量村庄 + 简化遗迹），不跨大区。 |
| **通关目标** | 携带余烬核心抵达灰原城并**激活节点**（Demo 终点）。 |
| **失败条件** | 全员失能且无法撤退 / 商队耐久 0 且无零件无撤退点 / 金钱与补给同时耗尽（阈值见数值表）。 |

> 设计口径：Demo 允许"粗糙但能跑"。系统范围本版已拍死——第二节列表之外的不测，列表之内的必测（带简化范围的按简化做）。

## 二、系统做 / 不做 · 最终裁定（v0.3）

> 判定原则：是否属于核心循环骨架，或用户明确要测。是→测（带简化范围）；否→不测。

| # | 系统 | 测什么 | 简化范围 |
|:--:|:-----|:------|:--------|

| 3 | **五类地点交互** | 大城/小城/城镇/驿站/**村庄×20** 全部功能 | — |
| 4 | **交易与地区价差** | 各地点买卖价不同 → 跑商/自营贸易可行性 | — |
| 5 | **订单系统** | 送货+收购、最多3个、超时失败 | — |
| 6 | **卡牌战斗** | 3–5 角色 / 共享行动力 / 抽牌 / 多状态 | 招募后队伍 3–5 人，AP/手牌按人数缩放（第4A类：3人=AP3/7张，5人=AP5/11张） |

| 14 | **遗迹探索（简化）** | 进入/探索/领取奖励（遗物·装备·记忆手册） | **1–2 处遗迹**，单 reward 流程，非地牢 |
| 15 | **记忆系统** | 获取/装备/生效流程（攻击/防御/辅助/消耗四类） | 若干预设记忆，验证流程即可，非完整成长树 |

### ❌ 不测（留正式版，本版明确不做）

| 不测项 | 原因 |
|:------|:-----|
| 灰兽潮大事件 | 大事件级，留正式版 |
| 主线 / 支线剧情 | 叙事留正式版 |
| 存档 / 读档 | Demo 不存档 |
| 玩家城市建设 | 属第9类城市系统，留正式版 |
| 情报购买经济 | 非核心循环（第2A类子项），本版不测 |
| 工会 / 商会 / 声望深层 | 经济社交深层，留正式版 |
| 地图随机生成 | 固定地图 |

> 以上"不测"≠不重要，是 Demo 阶段非核心骨架 / 写不起。先测关键的，跑通再扩。

## 三、地图规格（150×150）

| 项目 | 设定 |
|:-----|:------|
| 网格 | **150×150 = 22,500 格** |
| 定位 | 大地图开放感（自由上下左右走） |
| 移动 | 1 格=1天+1补给，固定，无速度属性 |
| 格子类型 | 空地/战斗/事件/营地/补给点/危险区/**遗迹**（七类；Demo 无 Boss 格） |
| 障碍格 | 约 10–15% 不可走（山河/塌方） |
| 地图生成 | 固定（不随机） |

> 仍是大地图**格子移动**（非早期废弃的 3D 开放世界），只是格子够大、有开放探索感。
> Demo **不要求遍历全图**——靠 35 个地点 + 遗迹 + 事件格测系统即可。

## 四、地点清单（共 35 个 + 1–2 遗迹）

| 类型 | 数量 | 说明 |
|:----:|:----:|:-----|
| 大城 | 1 | 灰原城（出发，唯一有节点，可招募） |
| 小城 | 2 | 农耕A（东南）、狩猎B（西北） |
| 城镇 | 6 | 镇1–镇6，补给/普通治疗/小订单/情报 |
| 驿站 | 6 | 驿1–驿6，零件/修车/路线情报；不接收撤退 |
| **村庄** | **20** | 村1–村20，散布全图，最小聚落，必测 |
| 遗迹 | 1–2 | 特殊格，简化探索（奖励遗物/装备/记忆手册） |
| **合计** | **35 + 遗迹** | 大城+小城 + 城镇/驿站(12) + 村庄(20) |

> 城镇+驿站 = 12（满足≥10）。村庄 20 个（ubiquitous 最小聚落）。遗迹 1–2 处。
> 地点命名均为代号，正式命名后补。

## 六、界面与操作（草案）

| 界面 | 内容 |
|:-----|:------|
| 主地图 | 150×150 网格（视口滚动）+ 商队位置 + 信息等级 |
| 状态栏 | 常驻（金钱/资源/耐久/士气/天数） |

## 七、与权威设计的一致性核对

| 权威规则 | Demo 落实 |
|:--------|:----------|
| 余烬核心 = 激活钥匙（非能源），只激活城市节点 | ✅ 仅灰原城可激活 |
| 节点反应炉仅存在于城市 | ✅ 小城/城镇/驿站/村庄/遗迹均无节点 |
| 无传送；驿站不接收撤退 | ✅ 撤退只撤大城/小城；无传送 |
| 地点五类：大城/小城/城镇/驿站/村庄 | ✅ 35 地点全覆盖五类（村庄×20） |
| 中继点仅城镇+驿站 | ✅ 12 个中途点 |
| 移动 1 格=1 天，无速度属性 | ✅ 固定 |
| 战斗 AP/手牌按人数缩放 | ✅ 3–5 人沿用第4A类 |
