# 《余烬商队》Demo 设计 · 权威口径 v0.1

> 文档状态：v0.1（Draft → 待你审核定版）
> 定位：Demo 是**可行性试验场**，不是"功能越少越好"。本文件只定**范围与功能清单**，具体数值见下一份《Demo 数值细化表 v0.1》。
> 关联：第1A类地图、第2A类地点、第3A类商队资源、第4A类战斗、第5A类天气与事件。

---

## 一、Demo 目标与定位

| 项目 | 设定 |
|:-----|:------|
| **核心目的** | 把尽可能多的系统**塞进来做可行性验证**——哪些跑通、哪些跑不通、哪些手感差，记录下来留给正式版。不是"砍功能换省事"。 |
| **范围** | 灰原城周边区域（1 大城 + 2 小城 + 中途补给网），不跨大区。 |
| **通关目标** | 携带余烬核心抵达灰原城并**激活节点**（Demo 终点）。 |
| **失败条件** | 全员失能且无法撤退 / 商队耐久 0 且无零件无撤退点 / 金钱与补给同时耗尽（具体阈值见数值表）。 |
| **不做** | 遗迹、灰兽潮、记忆系统、装备模块、主线剧情、支线、存档、城市建造、随机地图生成（这些留给正式版，Demo 只验证"够小的切片"）。 |

> 设计口径：Demo 允许"粗糙但能跑"。实验性系统如果实装后手感差或拖节奏，**直接砍**，不纠结。

## 二、地图规格（修订：放大）

| 项目 | 旧方案（已否） | **本方案** |
|:-----|:--------------|:----------|
| 网格 | 7×7 = 49 格 | **14×12 = 168 格** |
| 可移动空间 | 扣城/障碍后约 30 格（太少） | 17 地点 + 事件/障碍格后仍有 **约 130–150 格**可自由移动 |
| 出发位 | 左下角 | 左下角（灰原城） |
| 移动 | 上下左右 1 格 = 1 天 + 1 份补给 | 同左，固定不变，无速度属性 |
| 网格类型 | 空地/战斗/事件/营地/补给点/危险区/Boss | 同左（Demo **无 Boss 格**，Boss 留正式版） |
| 障碍格 | 少量 | 约 10–15% 为不可走格（山河/塌方），用于测试绕路决策 |
| 地图生成 | 固定地图 | 固定地图（不随机生成） |

> 路线节点密度参考第1A类：约每 2–3 格一个中间休息点。14×12 足以铺开 12 个中途补给点且互不挤占。

## 四、功能清单（分层：核心 + 实验性）

### A. 核心必做（验证基础循环）

| # | 功能 | 说明 |
|:--:|:-----|:------|
| 1 | 开局 | 3 角色（护路人/荒野射手/修补师）+ 余烬核心 + 基础资源（金钱/补给/零件/药包/耐久） |
| 2 | 地图移动 | 14×12 网格，上下左右 1 格=1天+1补给 |
| 3 | 状态栏 | 金钱/食物/水/零件/药包/耐久/士气/天数 实时显示 |
| 4 | 补给消耗 | 每人每天 1/4 份食物+水；耗尽惩罚（士气-1/人-5HP/重伤恶化） |
| 5 | 大城界面 | 交易/接订单/休息/修车/治疗/招募/情报/激活节点 |
| 6 | 交易 | 买卖补给/零件/药包/特产，各地点价差 |
| 7 | 订单 | 送货+收购，最多 3 个，超时失败扣声望 |
| 8 | 卡牌战斗 | 3 角色 / 共享行动力 3 / 抽 7 张；攻击/防御/治疗/修车 |
| 9 | 敌人 3 种 | 强盗 / 野兽 / 灰烬兽（Demo 轻量配置） |
| 10 | 随机事件 | 正面/负面/选择分支（发现补给/遇伏击/商人求助等） |
| 11 | 激活节点 | Demo 通关目标，灰原城唯一可激活 |
| 12 | 结算 | 天数/金钱/战斗次数/订单完成数/失败原因 |

### B. 实验性（塞进去试可行性，跑不通就砍）

| # | 功能 | 验证什么 | 砍的条件 |
|:--:|:-----|:--------|:--------|
| 13 | **天气系统（基础）** | 晴/雨/雾 3 种，影响移动消耗与事件触发概率 | 手感拖沓或数值难平衡 |
| 14 | **侦察/信息等级** | 前方格子按 0–5 级显示可见度（第1A类侦察机制） | 信息太晦涩或太透明 |
| 15 | **撤退系统** | 耐久抛锚/全灭 → 撤到最近小城或大城（驿站不接收撤退） | 规则歧义多、体验差 |
| 16 | **情报购买** | 城镇/驿站付费打听路线/天气情报（第2A类情报经济） | 性价比无感、玩家不买 |
| 17 | **基础招募** | 大城可替换/补 1 名队员（测试角色替换流程） | 与 3 人固定阵容冲突 |

> 以上 5 项为实验性，本文件**不强制全做**。若开发中发现某项是坑，直接砍并记入《Demo 复盘》。

## 五、界面与操作（草案）

| 界面 | 内容 |
|:-----|:------|
| 主地图 | 14×12 网格 + 商队位置 + 信息等级显示 |

## 六、与权威设计的一致性核对

| 权威规则 | Demo 落实 |
|:--------|:----------|
| 余烬核心 = 激活钥匙（非能源），只激活驿站/城市节点 | ✅ 仅灰原城可激活节点 |
| 节点反应炉仅存在于城市 | ✅ 小城/城镇/驿站/村庄均无节点 |
| 无传送；驿站不接收撤退 | ✅ 撤退只撤大城/小城；无传送 |
| 地点五类：大城/小城/城镇/驿站/村庄 | ✅ 17 地点全覆盖五类 |
| 中继点仅城镇+驿站，密度 2–3 格 | ✅ 12 个中途点铺在 168 格上 |
| 移动 1 格=1 天，无速度属性 | ✅ 固定 |
