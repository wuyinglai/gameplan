# 玩家体验分段设计 v3

> 状态：初稿 v0.3
> 说明：把游戏全程分成几段，每段玩家的具体表现、实力、体验基调。人数与商队成员系统对齐。数值为大致参考，不写死。

---

## 商队实力参照（来自商队成员系统）

| 阶段 | 总人数 | 战斗成员 | 车队 | 耐久上限 | 车厢 |
|:-----|:------:|:--------:|:-----|:--------:|:----:|
| 初始 | **5人**（3战斗+1驾驶+1后勤，全部核心成员） | 3 | 3辆（1人员车+2货车） | 100 | 200格 |
| 中期 | 10人左右 | 4~5 | 加车/换大车 | 150~200 | 800~1,000格 |
| 后期 | 15~20人 | 5+ | 大型车队 | 300 | 2,000格 |

## 分段总览

| 段 | 名称 | 主线位置 | 玩家实力 | 体验基调 |
|:--:|:-----|:---------|:---------|:---------|
| 1 | 起步 | 灰原城 | 5人核心小队+3辆车 | 摸索、新鲜、略笨拙 |
| 2 | 上路 | 灰原→枯林 | 5人，开始雇佣 | 紧张、第一次吃亏 |
| 3 | 立足 | 枯林→鱼水/粮野 | 6~8人，车队成型 | 熟悉、有底气 |
| 4 | 扩张 | 中圈各城 | 8~10人，实力跃升 | 自由、选择多 |
| 5 | 深入 | 火油/药泽/黑石 | 10~12人，接近巅峰 | 沉重、真相逼近 |
| 6 | 决战前夜 | 灰烬城 | 15人左右，满编 | 压抑、孤注一掷 |
| 7 | 终局 | 烬渊山 | 15~20人或联合商队 | 终局（结局后定） |

## 第一段：起步（灰原城）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 序幕 |
| 玩家实力 | **5人核心小队**（3战斗+1驾驶+1后勤）、3辆车（1人员车+2货车）、耐久100、车厢200格 |
| 大致数值 | 金钱约300~800金；角色基础属性（护路人68血/射手40血/修补师46血）无强化；记忆位8个无升级无融合；初始破烂装备；火种0；敌人最弱（灰原周边小股野兽/零散强盗） |
| 能做什么 | 接小订单、学跑商、学战斗、熟悉UI、熟悉队伍 |
| 玩家感受 | 新鲜但笨拙——规则多，钱包瘪，地图陌生 |
| 关键事件 | 获得余烬核心、激活灰原城节点 |
| 节奏 | 舒缓，教学为主 |

---

## 第二段：上路（灰原→枯林）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 第一幕 |
| 玩家实力 | 5人，开始接触雇佣渠道（尚未招人） |
| 大致数值 | 金钱约1,000~3,000金（跑了几单）；基础属性+少量强化（个别记忆升级1次）；记忆位8个；商店普通装备；火种0~1；敌人低（野兽、小股强盗） |
| 能做什么 | 跑第一段商路、打第一场硬仗、接第一个大单 |
| 玩家感受 | 紧张——路上处处是危险，钱包刚鼓起来就被消耗 |
| 关键事件 | **枯林城被骗吃亏**（第一课）、教团初现（未察觉） |
| 节奏 | 第一个小高峰，紧张但能承受 |

---

## 第三段：立足（枯林→鱼水/粮野）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 第二幕前半 |
| 玩家实力 | **6~8人**（开始雇佣，可加1辆货车）、战斗熟练 |
| 大致数值 | 金钱约3,000~8,000金（商路通了开始赚钱）；属性+10~20%；记忆位9~10、核心记忆升级2~3次；商店中等装备；火种1~3；敌人中（枯林野兽群、鱼水周边水盗） |
| 能做什么 | 多城跑商、接中级订单、开始做选择（帮谁不帮谁） |
| 玩家感受 | 熟悉、有底气——不再是刚上路的菜鸟 |
| 关键事件 | 鱼水城难缠的水司（考验耐心）、粮野城最实在的交易 |
| 节奏 | 舒缓，恢复期 |

---

## 第四段：扩张（中圈各城）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 第二幕后半~第三幕前 |
| 玩家实力 | **8~10人**、车辆升级（耐久150~200）、记忆/装备成型、商队声望起来 |
| 大致数值 | 金钱约8,000~25,000金（订单开始大）；属性+30%左右、组合套路成型；记忆位10~12、**融合开始出现**、火种词条起步；较好品质装备；火种3~8；敌人中高（精英、灰烬兽增多） |
| 能做什么 | 自由选择路线、接高难订单、开始参与城市事务 |
| 玩家感受 | 自由、选择多——世界向你打开 |
| 关键事件 | 海盐城被设局（中期考验）、线索越拼越多 |
| 节奏 | 开放，玩家自己定节奏 |

---

## 第五段：深入（火油/药泽/黑石）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 第三幕 |
| 玩家实力 | **10~12人**、装备好、核心共鸣高、车厢800~1,000格 |
| 大致数值 | 金钱约25,000~60,000金（大订单+特产贸易）；属性+40~50%接近巅峰；记忆位12~14、融合成型+火种词条、**开始接触奥义记忆（说明书）**；高品质装备、可能有旧文明装备；火种8~15；敌人高（烬油危机周边、教团势力、遗迹守卫） |
| 能做什么 | 打通命脉商路、对抗教团正面势力、直面真相 |
| 玩家感受 | 沉重——"你到底是来赚钱还是当救世主"的问题甩不掉 |
| 关键事件 | 烬油危机、药泽文献、黑石城撞见教团 |
| 节奏 | 收紧，危机感上升 |

---

## 第六段：决战前夜（灰烬城）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 第四幕 |
| 玩家实力 | **15人左右**、接近满配（耐久~300、车厢~2,000格） |
| 大致数值 | 金钱约60,000~150,000金（富商级别）；满级属性；记忆位15、顶级记忆+奥义说明书集齐（可选）；满配装备、**旧文明武器（若去找了）**；火种15~30（攒着放大招 or 强化记忆，玩家取舍）；敌人极高（灰烬污染区、教团精锐） |
| 能做什么 | 揭示全部真相、面对教团、决定去不去烬渊山 |
| 玩家感受 | 压抑、孤注一掷——"你觉得你在救人还是招灾" |
| 关键事件 | 灰烬城数据库、教团领袖质问 |
| 节奏 | 压抑，为终局蓄力 |

---

## 第七段：终局（烬渊山）

| 项目 | 内容 |
|:-----|:------|
| 主线位置 | 终幕 |
| 玩家实力 | **15~20人**满配，或组联合商队（2~5支） |
| 大致数值 | 金钱不限（结局后定）；巅峰战力；记忆满配、奥义说明书+旧文明武器齐备（强发射）；火种决定终局表现（烧火种强发射=终极爆发）；敌人终局（超巨型矿山遗迹、灰烬母兽） |
| 能做什么 | 进入超巨型矿山遗迹、决战灰烬母兽 |
| 玩家感受 | 终局（结局后定） |
| 关键事件 | 烬渊山（结局阶段写） |
| 节奏 | 终局 |
