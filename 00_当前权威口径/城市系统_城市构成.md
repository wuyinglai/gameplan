# 城市构成与统治结构

> 文档状态：草稿 v0.1
> 说明：九座城市的统治形式、权力结构、城市格局。

---

## 一、九城时代后的统治格局

九城时代结束后，城市之间彻底失联。每座城市各自为政，形成了不同的统治方式。没有统一的政权，城市之间没有从属关系。

---

## 二、各城统治结构

| 城市 | 统治形式 | 谁说了算 | 说明 |
|:----|:--------|:---------|:------|
| **灰原城** | **名义领主** | 灰原家族——世袭领主，威信不高但没人反对 | 领主府在城中心。城中事多由商会和几个大商人商量着办，领主只管收税和维持秩序 |
| **枯林城** | **猎头议会** | 几个大猎户家族的族长联合议事 | 城市结构松散，没有强权。城主由各猎户家族轮流当——实际上就是挂个名 |
| **鱼水城** | **水厂主** | 水源的所有者，掌握全市命脉 | 鱼水城最有权势的不是领主，是掌握净水厂的人。水源就是权力。领主反而是个傀儡 |
| **海盐城** | **独立城邦** | 由渔民公会和盐场主联合治理 | 没有传统领主。大事由公会投票决定——投票按盐场大小算权重 |
| **粮野城** | **农场主联合** | 几大农场主说了算 | 粮食是硬通货，种粮的人最有话语权。名义上有领主但没什么实权 |
| **火油城** | **炼油厂主** | 掌握炼油技术和油矿的人 | 烬油是九城命脉，火油城也因此最有底气。领主就是炼油厂主本人——世袭的 |
| **药泽城** | **长老会** | 几位年长的药师和学者组成的议会 | 药泽城闭塞但文化保存最好，长老会里有人还认识旧文字。城市没有军队也不需要 |
| **黑石城** | **铁匠公会** | 锻钢坊的工头和老师傅们联合治理 | 黑石城是九城的工业中心，公会掌握着最好的手艺。领主是公会推选的 |
| **灰烬城** | **无政府** | 没有正式的统治结构 | 城市半废弃，只住了一两千人。人人自顾不暇，没人管也没人想被管。有事靠街坊邻居互相帮衬 |

## 三、城市格局（通用）

每个城市的基本格局类似：

| 区域 | 功能 |
|:----|:------|
| **广场/商业区** | 市场、交易所、商会、悬赏板集中在此 |
| **领主府/议政厅** | 城市权力中心，领主或议会所在地 |
| **居民区** | 普通市民居住的地方 |
| **工业区** | 工坊、铁匠铺、特殊设施所在 |
| **外围/城墙** | 城门、防御设施、驿站 |

> 各城的具体布局和特殊建筑的位置在后续地图细化时设计。
