# ① 地图探索与风险（探索期发生的一切）

### ①-1 大地图移动（行动点制）
- **干什么**：在 150×150 格子上四向走；**每天 3 行动点**，每点可走 1 格 或 做格子内活动（采集野果/侦察邻格/休整/修车）。补给按天扣，与当天走几格无关。无速度属性。地图固定，不要求走满全图，靠 35 地点 + 事件格测系统即可。
- **每日行动点可用动作**：

  | 动作 | 行动点 | 说明 |
  |:----:|:------:|:-----|
  | 走 1 格（四向） | 1 | 进入触发该格类型行为 |
  | 采集野果/拾荒 | 1–2 | 当前格获得食物/零件/物资 |
  | 侦察邻格 | 1 | 揭示相邻格信息等级（提前看敌情/资源） |
  | 休整回士气 | 1 | 扎营，士气 +1（不移动） |
  | 修车 | 1 | 用零件修复耐久 |
  | 等待 1 天 | 耗尽剩余 AP | 不移动，天气+1天、地点结算 |

- **关键参数**：网格 150×150=22,500 格（较原 100×100 扩大约 2.25 倍，因 AP 需分用于采集/侦察等非赶路动作）；每天基础 3 行动点（升级车辆/畜力/特殊人员 +1，封顶 4–5）；约 10–15% 障碍格（不可走）；出发位左下角；**全版本固定地图（见第1A类 §3）**。
- **已有权威参考**：第1A类 §1（AP 规则）/ §3 / §5。
- **⚠️需数值**：障碍格占比精确值；视口滚动规则；升级加点的具体来源（车辆/畜力/人员各 +几）。

### ①-2 七类格子（地图节点类型）
- **干什么**：每格是以下七类之一，进入后触发对应行为：

| 格类型 | 干什么 |
|:------|:-----|
| 空地 | 只消耗资源，无事件 |
| 战斗 | 进入普通战斗 |
| 事件 | 触发随机事件（正面/负面/选择分支） |
| 营地 | 休息、修车、鼓舞士气（不额外消耗补给） |
| 补给点 | 补充少量补给和零件 |
| 危险区 | 可能战斗也可能得奖励（高风险高回报） |
| 遗迹 | 特殊格，简化探索（见⑤-4） |

- **已有权威参考**：第1A类 §4。Demo 无 Boss 格。
- **⚠️需数值**：各类型格在地图上的分布比例（如战斗格占比、事件格占比）。

### ①-3 侦察信息等级（0–5）
- **干什么**：玩家移动时，前方格子按信息等级决定能看到多少。不同角色专精影响不同信息类型（荒野射手【野外侦察】、修补师【现场诊断】各 +1 级，护路人不提供）。
- **等级定义（0–5 各代表什么）**：

| 等级 | 名称 | 玩家知道什么 |
|:---:|:----|-------------|
| 0 | 无信息 | 什么都不知道，只知道有异常（"前方出现异常"） |
| 1 | 模糊信息 | 可能有危险，但不知类型（"情况不太对"） |
| 2 | 类型信息 | 大概类型（"可能有人活动过，敌对风险"） |
| 3 | 关键信息 | 具体类别（"大概率强盗活动痕迹"） |
| 4 | 详细信息 | 大致数量、方向、位置范围（"约5-8人，北侧断路"） |
| 5 | 精确信息 | 具体人数、具体格、触发条件（"强盗6人，前方第3格右侧"） |

- **信息类型（6类）**：路线信息 / 敌情信息 / 资源信息 / 结构信息 / 车损信息 / 异常·旧文明信息。
- **计算方式**：最终等级 = 事件基础(0–2) + 区域(0–1) + 角色词条(0–1) + 装备(0–1) + 记忆/情报(0–2)，封顶 5。
- **初始上限**：无装备/记忆/情报时最高 2 级；加路线情报/工具可到 3；中后期专用装备/记忆可到 4–5。
- **已有权威参考**：第1A类 §8。Demo 实装按此。
- **⚠️需数值**：初始三人无装备时最高 2 级（已定）；各信息来源的加成数值（已定，待复核）。

### ①-4 天气系统·基础（晴 / 雨 / 雾 3 种）
- **干什么**：按天气段持续，影响移动消耗、事件触发、战斗伏击率。Demo 只取 3 种基础天气（正式版扩 12 种）。
- **各天气干什么（Demo 简化口径）**：

| 天气 | 干什么 | 主要效果 |
|:----|:-----|:--------|
| 晴朗 | 稳定赶路 | 伏击率 -10%；最适合推进 |
| 雨（小雨/暴雨合并） | 火焰削弱、可收集雨水 | 火焰伤害↓；可减补给消耗；暴雨重伤恶化+5%/天 |
| 雾（浓雾/重雾合并） | 伏击与迷路风险提高 | 伏击率 +20%~+40%；雾中线索更多但易迷路 |

- **天气段**：普通天气持续 5–7 天；特殊天气 3–6 天。
- **已有权威参考**：第5A类 §2（Demo 取其中的晴/雨/雾轴）。
- **⚠️需数值**：3 种天气的精确概率、消耗倍率、伏击率修正、持续时间分布。

### ①-5 随机事件
- **干什么**：探索驱动，格子/天气触发，分正面 / 负面 / 选择分支。Demo 用第5A类 E1–E13 框架，取"正面/负面/选择分支"三类体验。
- **事件池（来自权威，Demo 验证可行性）**：E1遇敌 / E2道路 / E3资源 / E4商队旅人 / E7小遗迹 / E9痕迹情报 / E10路线判断 / E11落脚点 / E12关卡拦路 / E13地标视野。
- **冷却**：降权冷却（E1遇敌4步保留0.15、E2道路3步0.30 等），避免连刷。
- **已有权威参考**：第5A类 §3。Demo 不测内部事件系统（商队内部争执），只测外部事件。
- **⚠️需数值**：各事件在 Demo 地图的触发概率/权重；具体事件内容库。

### ①-6 撤退系统
- **干什么**：失败时止损，不删档。分战斗撤退与地图撤退。
- **战斗撤退**：每回合可选，第3回合起判定，基础成功率 50%；成功撤出、士气 -1、不获战斗奖励、不丢货。
- **地图撤退（3种）**：

| 类型 | 触发 | 货物损失 | 士气 |
|:----|:-----|:--------:|:----:|
| 主动撤退 | 玩家主动 | 25% | -2 |
| 士气崩溃撤退 | 士气归0自动 | 50% | 到安全点恢复1 |
| 强制撤退 | 全队倒下+耐久归0 | 75% | 到安全点恢复1 |

- 撤离目标：最近**安全点 = 仅大城 / 小城**；**城镇与驿站不接收撤退**（只作中途补给，不作撤退终点），村庄不接收。
- **已有权威参考**：第4A类 §9（安全点范围按本 Demo 收窄为「大城 + 小城」）。

# ② 商队资源与生存（活下去的账本）

### ②-1 资源状态栏（常驻显示）
- **干什么**：常驻显示 8 项资源：金钱 / 食物 / 水 / 零件 / 药包 / 商队耐久 / 士气 / 天数。
- **各资源干什么**：

| 资源 | 干什么 |
|:----|:-----|
| 金钱 | 交易、修车、治疗、招募、订单本金 |
| 食物 | 每日消耗（与水分开计），耗尽扣血 |
| 水 | 每日消耗，与食物并列 |
| 零件 | 修车、技能、事件消耗 |
| 药包 | 战斗/事件治疗消耗 |
| 商队耐久 | 货车血量，0=抛锚 |
| 士气 | 队伍状态，0=崩溃撤退 |
| 天数 | 全局时间，订单/天气按天算 |

### ②-2 每日消耗
- **干什么**：每过 1 天（无论当天走几格、做几次活动），每人消耗 1/4 份食物 + 1/4 份水（合计每人 1/2 份/天）。
- **已有权威参考**：第1A类 §5、第3A类。
- **⚠️需数值**：精确粒度（1/4 份已定，待复核）；扎营首日双倍消耗。

### ②-3 补给耗尽惩罚
- **干什么**：食物/水=0 后每天：士气 -1 / 全队每人 -5 HP / 重伤恢复天数 +1（恶化）。
- **已有权威参考**：第1A类 §5.1。

### ②-4 商队耐久与损耗
- **干什么**：货车血量，分六档（完好81–100/轻度61–80/损坏41–60/严重21–40/濒毁1–20/抛锚0）。战斗损耗：普通 -5 / 精英 -10 / Boss -50。
- **已有权威参考**：第3A类、第4A类 §8。
- **⚠️需数值**：耐久上限（权威100，Demo待定）；修理单价。

### ②-5 失败判定
- **干什么**：三种失败——①全员失能且无法撤退 ②耐久0且无零件无撤退点 ③金钱与补给同时耗尽。
- **⚠️需数值**：各项阈值（部分已定，待 Demo 复核）。

# ③ 地点与贸易（停靠点与经济）

### ③-1 五类地点交互
- **干什么**：停靠后按类型提供不同功能。Demo 共 35 地点：1大城+2小城+6城镇+6驿站+**20村庄**。
- **各类型干什么 + 物价档（补给/零件/药包）+ 接收撤退**：

| 类型 | 数量 | 核心功能 | 接收撤退 | 物价档 |
|:----:|:----:|:--------|:--------:|:------:|
| 大城（灰原） | 1 | 交易/订单/治疗/修车/激活节点/**招募** | ✅ | 10/50/50 |
| 小城 | 2 | 正常设施、特产便宜 | ✅ | 11/55/55 |
| 城镇 | 6 | 补给/普通治疗/小订单/情报 | ❌（撤只到城） | 15/75/70 |
| 驿站 | 6 | 零件/修车/路线情报 | ❌ | 16/70/75 |
| 村庄 | 20 | 极少高价补给/极小订单/免费传闻；不治疗不修车不恢士气 | ❌ | 20/90/90 |

- **中继点**：仅城镇+驿站（12个，满足≥10）。
- **已有权威参考**：第2A类、v0.3 §四。
- **⚠️需数值**：各地点具体库存量、订单库、特产清单、村庄订单规模。

### ③-2 交易与地区价差
- **干什么**：在地点买卖 补给/零件/药包/特产/装备，各地点买卖价不同 → 跑商/自营贸易可行性。
- **价差逻辑**：大城基准价最低，越往外围（驿站/村庄）越贵；卖出价低于买入价（买卖差）。
- **已有权威参考**：第2A类、第1A类 §9（城市基准：补给10/零件50/药包50）。
- **⚠️需数值**：各地点买卖倍率、特产种类与价差幅度。

### ③-3 订单系统
- **干什么**：接送货+收购订单，最多同时 3 个，超期限失败。
- **规则**：订单期限 = 路程天数 × (1.3~1.5)；货损≥70% 订单失败；奖励 ≈ 预计消耗×1.5。
- **已有权威参考**：第2A类、第1A类 §6.6。
- **⚠️需数值**：订单库（起点/终点/货物/数量/期限/奖励）；超时惩罚。

# ④ 战斗（打起来的一套）

### ④-1 卡牌战斗框架
- **干什么**：回合制战术卡牌，全队共享行动力，队列式 UI（非棋盘）。核心不只杀敌，还要保护商队/货物/避免重伤。
- **已有权威参考**：第4A类 §1。

### ④-2 行动力与抽牌（按人数缩放）
- **干什么**：出战人数决定每回合 AP 与抽牌数（Demo 3–5 人）。

| 出战人数 | 每回合AP | 每回合抽牌 |
|:------:|:-------:|:---------:|
| 3 人 | 3 点 | 7 张（2×3+商队1） |
| 4 人 | 4 点 | 9 张 |
| 5 人 | 5 点 | 11 张（2×5+商队1） |

- 技能费用：0费铺垫 / 1费主力 / 2费强力。消耗品（药包/零件）使用也耗 1 AP。
- **已有权威参考**：第4A类 §2。

### ④-3 伤害类型（内伤/外伤）
- **干什么**：外伤可被防御阻挡（普通/穿甲/灼烧）；**内伤不可阻挡**（流血、已施加持续伤害）。防御只对外伤生效。

### ④-4 防御三层
- **干什么**：

| 层 | 特性 | 持续 |
|:---|:-----|:----:|
| 护盾 | 临时，挡外伤，过回合清空 | 当前回合 |
| 护甲 | 长期，只挡普通攻击 | 直到被打掉 |
| 屏障 | 高级，挡外伤+多数负面施加 | 直到被打掉 |

- 结算顺序（外伤）：护盾→屏障→护甲→生命；穿甲无视护甲。

### ④-5 状态系统（各状态干什么）
- **干什么**：战斗中施加的状态效果。

| 状态 | 类型 | 干什么 | 上限 |
|:----|:----|:-----|:----:|
| 标记 | 增益铺垫 | 命中消耗1层，本次伤害+25%，每击最多耗1层 | 不限 |
| 反击 | 反打 | 受攻击后反伤50%，耗1层 | 不限层 |
| 流血 | 持续(内伤) | 每层3伤，行动后触发，层数-1，无视防御 | 不限 |
| 灼烧 | 持续(外伤) | 每层4伤，回合结束触发，可被盾/屏障挡 | 不限 |
| 迟滞 | 控制 | 提高目标行动失败概率，上限50% | 不限，概率封顶50% |
| 蓄力 | 预警 | 敌我准备状态，多用于敌人强技能 | — |
| 狂化 | 强化 | 敌人每层提伤，精英/Boss用 | — |
| 灰蚀 | 特殊威胁 | 最多3层，每回合4灰烬伤，满3层爆发清零，需灰烬治疗 | 3层 |

- **注**：穿甲是攻击类型非状态；"超载"已删除（见第4A类 §5.4）。v0.3 写的"减速"即此处"迟滞"。
- **已有权威参考**：第4A类 §5。

### ④-6 敌人 3 种
- **干什么**：Demo 轻量配置三种敌人，逃跑机制各异。

| 敌人 | 干什么 | 逃跑特点 |
|:----|:-----|:--------|
| 强盗 | 普通敌人基准（路匪/抢货强盗） | 抢到货+100意愿立刻逃 |
| 野兽 | 低强度多数量（野狗/狼群） | 天生易逃（+20初始，+5/回合） |
| 灰烬兽 | 高危险（灰爪兽/灰蚀兽） | **不会逃跑** |

- **已有权威参考**：第4A类 §9.2、第5A类 §3.5。
- **⚠️需数值**：各敌人血量/攻击（普通≤100/精英≤200，Demo 取普通+少量精英）。

| 灰烬治疗 | 1 | 净化 | 清灰蚀；成功抽1牌 |
| 过载 | 2 | 强化 | 任意牌效果翻倍(+100%)；自身受5内伤 |

- **已有权威参考**：第6A类 §2–4。

### ④-8 重伤系统
- **干什么**：生命归零→退出战斗进重伤；休养不能上场。
- **分级**：1次重伤（最大生命-20%，休养3天）/ 2次（-50%，4天）/ 3次失能（须城市治疗）。
- **城市治疗价**：1次200 / 2次350 / 失能500 金。
- **已有权威参考**：第6A类 §7。

### ④-9 战斗消耗品
- **干什么**：战斗中药包/零件使用耗 1 AP（迫使"打/防/治/修"取舍）。

# ⑤ 角色成长（变强的一套，均简化）

### ⑤-1 装备模块（简化 4–10 套）
- **干什么**：验证装备槽 / 属性加成 / 获取。不做完整装备树、不做装备耐久/随机词条/品质等级。
- **装备栏位（来自权威）**：左手×1 / 右手×1 / 头部×1 / 躯干×1 / 手部×1 / 腿部×1 / 足部×1 / 工具栏×3 / 饰品×3。
- **装备分类**：普通装备（约2000金，城市买）/ 旧时代装备（约6000金，遗迹出，概率低）。
- **成长理念**：角色基础数值固定，变强靠更好装备+更强记忆；武器/护甲无上位替代，各有特点。
- **已有权威参考**：第6A类 §10、§14。
- **⚠️需数值**：Demo 具体 4–10 套装备清单（名称/栏位/属性加成/获取地点）。

### ⑤-2 记忆系统（四类）
- **干什么**：验证获取/装备/生效流程。记忆=旧文明技能，完整获得（无碎片）。
- **四类**：攻击 / 防御 / 辅助 / 消耗。
- **出战记忆位**：初始 8 个（Demo 取初始值）。
- **0费记忆**：不限量、不占出战位，只能弱铺垫（如挂1层标记），不能抽牌/打伤/挂强负面。
- **强化**：数值升级（300+20(N-1)金）/ 状态升级（1000+200(N-1)金）/ 火种升级 / 记忆融合（1+1>2）。
- **已有权威参考**：第6A类 §5–6。
- **⚠️需数值**：Demo 预设记忆清单（四类各若干，含初始3人已有的+可获取的新记忆）。

### ⑤-3 招募（轻量）
- **干什么**：大城可招 1–2 人，队伍上限 5；测补员/替换流程。
- **成员分类**：护卫（出战）/ 帮工（车夫杂役，不出战）/ 特殊人员（厨师/账房/修车匠/演讲专家等，不出战，固定被动 + **可选主动buff卡**，见⑤-6）。
- **Demo 简化**：只招 1–2 名护卫，不展开招募网络。
- **已有权威参考**：第6A类 §8。
- **⚠️需数值**：可招候选 1–2 人配置（职业/血量/预设记忆）。

### ⑤-4 遗迹探索（简化 1–2 处）
- **干什么**：进入→探索→领奖，单 reward 流程，非地牢。产出遗物/装备/记忆手册（成长资源）。
- **已有权威参考**：v0.3 #14、第6A类旧时代装备。
- **⚠️需数值**：1–2 处遗迹位置、探索流程、具体奖励内容。

### ⑤-5 终极技 / 旧文明武器系统（后期强力一击·多回合蓄能）
- **干什么**：集齐三重门槛（遗迹武器 + 操作说明书/记忆手册 + 火种电池）后，可释放"后期强力一击"。
- **新机制**：废弃"一回合消耗火种直接打高伤"模型；改为 **≥5 回合蓄能**——玩家逐回合在自身叠增益、敌方叠减益，主动释放时打出爆发，伤害随铺垫组合放大。奖励多回合规划与 combo，而非无脑触发。
- **已有权威参考**：第6A类 §16（新机制）。
- **⚠️需数值**：蓄能层数→倍率曲线、基础值、各增益/减益对终伤的加成系数（数值待重调）。

### ⑤-6 特殊人员主动技能卡（buff only）
- **干什么**：特殊人员不参战，但每名可带 **1 张主动卡**进战斗牌库；卡**只上buff**（攻击/护盾/防御/蓄能等），**不直接打伤、不直接治疗**。
- **示例**：演讲专家 → 【鼓舞士气】卡：全队 +攻击/+护盾 buff（部分卡可小幅影响地图士气）。
- **设计意图**：让非战斗成员也能提供可规划支援、丰富 combo，维持"仅护卫能出战"硬分工。
- **已有权威参考**：第6A类 §8.3.1。
- **⚠️需数值**：Demo 特殊人员候选及其主动卡效果（含演讲专家）。
