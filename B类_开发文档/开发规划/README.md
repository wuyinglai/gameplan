## 🔴 三个 AI 怎么协作

| 谁 | 干什么 | 🔴 不能做什么 |
|:--|:--|:--|
| 🔴 **项目主**（你） | 决定设计规则 · 验收大阶段 · 判断体验 | —— |
| 🔴 **ChatGPT** | 协助规划阶段边界 · 审查规则冲突 · 检查测试覆盖 | 🔴 **不能写文件**（在浏览器里）→ 输出由我转落 · 🔴 **不建第二套进度表** |
| 🔴 **WorkBuddy**（我） | 写 A/B 类文档 · 写开发指令 · **更新总控台** · 核对执行证据 | 🔴 不把没批准的内容写成权威规则 |
| 🔴 **Hermes** | 🔴 **写代码**（`游戏本体\src\pNN\`） | 🔴 **不许改 `游戏大纲\` 下任何文档**（只能写 `B类_开发文档\AI交流\回复_HERMES_*.md`） |

### 你怎么用

```
我写指令 → B类_开发文档\AI交流\HERMES_xxx.md → 你说「让 Hermes 看这个」
Hermes 做完 → 写 回复_HERMES_xxx.md → 你说「小烬看这个」
                              ↓
                  我核对代码 + 跑测试 → 更新总控台
                              ↓
                        你只看总控台 + 10 行摘要
```

## 🔴 关键约定

| # | 约定 |
|:-:|:--|
| 1 | 🔴 **A 类是规则终审** —— 🔴 B 类只是施工图，冲突时以 `A类文件\正文\` 为准 |
| 2 | 🔴 **新旧代码不混用** —— 🔴 新代码在 `src\pNN\`，🔴 旧代码在 `90_历史与废案\16_...\` |
| 3 | 🔴 **每个阶段物理隔离** —— `src\pNN\`，🔴 **不许互相 import** |
| 4 | 🔴 **地图是内容不是逻辑** —— 换图只换 `地图.json`，代码一行不改 |
| 5 | 🔴 **已完成且有效的代码，不因重新规划被重写** |
| 6 | 🔴 **自动测试通过 ≠ 阶段通过** —— 🔴 「代码写完」「测试通过」「人工验收通过」是三件事 |
| 7 | 🔴 **没有权威来源的数值，不许实现者自己补** —— 🔴 停下报告，不许编 |
| 8 | 🔴 **改完必须读盘核实 + 跑 `vitest` + 跑 `tsc`** —— 🔴 三条都过才算完 |
| 9 | 🔴 **每个大阶段完成 → 更新总控台** —— 版本/完成内容/测试/问题/下一步 |
| 10 | 🔴 **记录里的数字只能来自命令输出** —— 🔴 跑 `node 其他\工具\开发记录.mjs` 生成，🔴 不许手打 |
| 11 | 🔴 **换地图后必须跑 `node 其他\工具\地图同步.mjs`** —— 🔴 不跑 = 测试跑的是旧图 |
| 12 | 🔴 **改现有代码前先备份** —— 🔴 快照到 `90_历史与废案\`，🔴 标明日期和"这次要改什么" |
