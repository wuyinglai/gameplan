## 🔴 规矩

| # | 规矩 |
|:-:|:--|
| 1 | 🔴 **一条指令做完 → 写一个记录文件**（🔴 不许都堆在一个长文档里） |
| 2 | 🔴 **文件名格式** = `中阶段_主题_日期.md`（🔴 见上面清单） |
| 3 | 🔴 **记录里必须有**「版本 / 完成内容 / 测试结果 / 遇到的问题 / 下一步」五项 |
| 4 | 🔴 **「完成内容」写实际做了什么** —— 🔴 不写"应该做什么" |
| 5 | 🔴 **遇到的问题必须写** —— 🔴 包括自己挖的坑，🔴 写"没问题"等于没查 |
| 6 | 🔴 **验收状态只有两个**：⏳ 待项目主验收 / ✅ 已验收 |
| 7 | 🔴 **自动区的数字只能由 `node 其他\工具\开发记录.mjs` 生成** —— 🔴 不许手打 |
| 8 | 🔴 **代码与文档分两个 commit**（`feat(pNN):` / `docs(B类):`）—— 🔴 回滚要能分清是谁的锅 |
| 9 | 🔴 **新旧代码永不混用** —— 🔴 新代码在 `src\pNN\`，🔴 旧代码在 `90_历史与废案\16_...\` |
