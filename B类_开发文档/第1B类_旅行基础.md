## 2. 时间系统与行进能量

游戏所有系统统一到 **"天数"** 上计算；但**移动不再按"走一格 = 一天"**，而是采用 **行进体力（体力池）** 模型。🔴 **2026-09-30 改口径**：野外体力由"**每日预算（用不完作废）**"改为 **"存量池"** —— **池上限 100 点 · 每天回复 50 点**（没花完的留到明天）。**原「与战斗体力同源 · 50 点/人」整套作废** —— 野外是**车队固定池**，🔴 **它不随人数变化，理由只有一个：所有人都要一起走**（人多也走不了更快）。🔴 **2026-10-13 用户裁定**：**体力上限不动（100）**，只把「每格 20」调成「**每格 15**」—— 配合「**正常 3 格/天 · 极限 4 格/天**」：正常 3 格 = 45 点（当天回复就够）、极限 4 格 = 60 点（需攒 10 点）、**攒满 100 点 = 冲刺 6 格（90 点）= 12 小时，时间正好用完**。

| 项目                  | 规则                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 每个自然日               | 野外体力池 **+50 点**（回复），**上限 100 点** —— 🔴 **不随人数 / 个体变化**（**所有人都要一起走**，人多也走不了更快）                                     |
| 移动 1 格              | 消耗 **15 点**（🔴 **恒定**；**路况 / 载重 / 车况损坏可抬高每格消耗**，见 §5）                                                             |
| 恶劣天气 / 坏路况          | **每格消耗上升**（暴雨 / 暴雪 / 灰烬风 **+5**、灰烬风暴 **+10**，见第 5A 类）→ 最差 1 天只够 **2 格**（日回 50 ÷ 每格 25）                            |
| 休养 1 天              | 重伤恢复进度 +1（不移动，体力不用于赶路）                                                                                            |
| 等待 1 天（城市/城镇/驿站/村庄） | 天气推进 +1，消耗补给                                                                                                      |
| 订单期限                | 按天计算                                                                                                              |
| 天气持续                | 按天计算                                                                                                              |
| 补给消耗                | 按**天**消耗（与走几格无关，见 §5）                                                                                             |
| 🔴 **速度口径**         | 正常 **3 格/天** · 极限 **4 格/天** · 冲刺 **6 格**（池攒满）· 🔴 **"3 格/天"是全库折算基准**（路程天数 × 3 = 格数）—— **完整口径见 §2.1 / §2.2**，本表不重复 |

> 🔴 **野外体力 ≠ 战斗体力（同刻度，但不同源）**：两套共用 **「50 点 = 1 人份」** 这一套刻度（**玩家只学一套刻度**），但**算法完全不同、互不通用**（野外按"天"结算、战斗按"回合"结算）：
>
> - **战斗体力 = Σ 各出战人体力** —— **人数是乘数**，多一个人就多 50 点（那是"多一个能打的人"），见第 4A 类 §2。
> - **野外体力 = 车队共用一个固定池** —— **上限 100 · 日回 50 · 与人数无关**（🔴 **所有人都要一起走**，人多也走不了更快）。
>
> **原唯一接口「疲劳接战」已废案**（2026-10-13 用户定：暂不实施，规则文本保留备查，见 §2.1）—— 两套体力**默认互不影响**。
>
> 核心体验：每一步消耗的是体力而非天数——一天能走几格取决于你舍得/能花多少体力；**坏天气、超载和车况损坏让你走得更近**。每一天都在消耗补给，每一次等待都在赌订单，每一次坏天气都可能是灾难，也可能是机会。

**🔴 速度恒定：没有「提速轴」（2026-10-05 用户裁定 · 车轮机制整体作废）**

**每格消耗恒 15 点 · 每天恒 50 点**（🔴 2026-10-13 调平：20 → 15） —— **不存在任何"让车队走更快"的手段**。原「车轮档次 → 改每格消耗」（标准 20 / 改良 16 / 精制 12）**整体作废**。

> 📜 **本段历史论证已移入附件** → 见 `第1A类_附录_历史与修订.md`（2.0 车轮档为什么删（2026-10-05））  
> **仍然存在的方向：只有「变慢」，没有「变快」**

| 方向     | 手段                                                | 后果                |
| :----- | :------------------------------------------------ | :---------------- |
| **变慢** | 恶劣天气（`第5A类`）· 坏路况 · 超载 · **车况损坏**（抛锚 / 车轮磨损 / 陷车） | 每格消耗上升 → 同样天数走得更近 |
| **不变** | 玩家自己决定今天花不花体力（走几格）                                | 节奏完全在玩家手里         |

**落地**：订单期限按**路程天数 × `k_期`** 给（`§7.6`）；**路程天数 = 格数 ÷ 3 格/天**（`§7.1` 折算基准），**与装备无关**。

### 2.1 野外体力池（这 100 点怎么花）

**池是"存量"**：当天没花完的**留到明天**，**上限 100 点**（≈ 攒两天）。四种花法：

| 用途       | 消耗               | 说明                                                                              |
| :------- | :--------------- | :------------------------------------------------------------------------------ |
| **移动**   | **15 点 / 格**（恒定） | 日回 50 点全用于赶路 = **3 格**（🔴 正常速度）；极限 **4 格**（需攒 10 点）；攒满 100 点 = **冲刺 6 格**（90 点） |
| **主动侦察** | **10 点**         | 把自身周围一片区域的信息等级抬升 **2 级**（🔴 **只抬等级、不给坐标**，见 §9.6）                               |
| **采集**   | **20 点**         | 就地拾取资源（**资源点属「事件」类**，见 §4 第二层；食物 / 水 / 零件 / 草药等）                                |
| **休整**   | **20 点**         | 原地停留：养伤、整备，不移动（🔴 **修车不在此处** —— **修车 = 自己耗零件**，见 §5）                            |

> **日常花法**：日回 50 点 —— **全速赶路 = 3 格（45 点）**，剩 5 点零头；**想沿途做事 = 2 格（30 点）+ 侦察 1 次（10 点）= 40 点**，或 **2 格 + 采集（20 点）= 50 点刚好花完**。  
> **极限赶路 = 4 格（60 点）**，需从池里补 10 点（攒一天、或当天少花一格）—— 这是"快"的代价，也是订单分化的来源：**普通单**期限宽裕、早到无用 → 留点侦察采集；**急单**不走就赶不上 → 全速赶路（代价即"今天什么都别想干"）。

**🔴 攒池（2026-09-30 新增 —— 这就是"保留机制"）**

| 玩法       | 做法                          | 结果                          |                             |
| :------- | :-------------------------- | :-------------------------- | --------------------------- |
| **攒着不花** | 今天少走两格、或干脆不走                | 明天带着 **90~100 点**出门         |                             |
| **原地休整** | 在据点停 1 天（**照常消耗 1 天补给与工资**） | 池回满 **100 点**，次日冲刺          |                             |
| **冲刺**   | 攒满的 100 点全用于移动              | **一天走 6 格**（= 12 小时，时间正好用完） | **一天走 5 格**（= 10 小时，时间硬顶重合） |

> **代价 = 天**：攒池期间**照常按天消耗补给与工资**（`§5`）—— **"攒"不是免费的，它是拿「天」换「格」**。这正是赶急单的核心权衡：**要么费钱（停下来攒池），要么费时间（硬赶 4 格、沿途什么都做不了）**。  
> **不侦察的机会成本也在这里**：省下一次侦察（10 点）攒着，明天能多走半格 —— **但今天就得瞎着走**。

## 2.2 🔴 时间与作息（2026-10-12 用户裁定）

> **用户原话**：「一天可以分成七个时段……野外是绝对不会耗完的，在城市里可能就会耗完了……给它一天弄成 12 个小时，从早上七点到晚上七点，干一个事情消耗 1~3 小时。」  
> **追加**：「走路改成**两小时一格**，总共六小时。」

### 🔴 一天 = **12 小时**（07:00 → 19:00）

| 项目           | 规则                                                       |
| :----------- | :------------------------------------------------------- |
| 🔴 **可支配时间** | **早上 07:00 → 晚上 19:00 = 12 小时**                          |
| 🔴 **入夜后**   | **睡觉，不消耗任何时间**（所以**永远不会"少一段"**）                          |
| **时间单位**     | 🔴 **连续小时数**，**不是格子** —— 玩家看到的是"天亮了/天黑了"，**不是"我还剩 1 格"** |

### 🔴 每件事的耗时

| 动作           |    耗时    |
| :----------- | :------: |
| 🔴 **走 1 格** | **2 小时** |
| 侦察           |   1 小时   |
| 采集           |   2 小时   |
| 搜索 / 探索      |   3 小时   |
| 修车           |   3 小时   |
| 采购 / 接单 / 交单 |  2~3 小时  |
| 谈判 / 讲价      |   2 小时   |
| 治疗 / 招募      |  2~3 小时  |

> ⚠️ **数值待平衡** —— 上表是**初版参考值**，等Demo 实测再定（用户："到时候再平衡"）。

### 🔴 两个限制的分工（关键）

> 🔴 **时间管"能做几件事"，体力管"能走几格"** —— **不是第二个体力。**

|           | 限制             | 能支持                                                        |
| :-------- | :------------- | :--------------------------------------------------------- |
| **时间**    | 12 小时 ÷ 2 小时/格 | **6 格**（🔴 **单日就只有 12 小时，没有别的上限**）                         |
| 🔴 **体力** | 50 点 ÷ 15 点/格  | 🔴 **3 格**（正常）· 极限 **4 格**（需攒 10 点）· 攒满 100 点 = 冲刺 **6 格** |

🔴 **体力先耗尽** —— 所以玩家正常走 **3 格 = 6 小时**（45 点），还剩 **6 小时**。  
**"每天 6 格"只有攒满池才做得到**（冲刺 6 格 = 90 点 = 12 小时，时间正好用完）· 🔴 **正常速度 = 3 格/天 · 极限 4 格/天**（与 §2 一致）· 🔴 **单日没有任何额外硬顶 —— 12 小时就是全部**。

### 🔴 野外 vs 城市：**时间限制只在城市里显形**

| 地点             | 一天能做的事                                                    | 12 小时够吗   | 玩家感觉      |
| :------------- | :-------------------------------------------------------- | :-------- | :-------- |
| 🔴 **野外**      | 走路 3（6 小时）+ 侦察 1 + 采集 2 = **9 小时**；冲刺 4 格 + 侦察 = **9 小时** | ✅ **宽裕**  | "我今天干了不少" |
| 🔴 **城市 / 驿站** | 采购 3 + 接单 2 + 交单 3 + 谈判 2 + 治疗 3 = **13**                 | 🔴 **打满** | "这儿事情真多"  |

**实际效果**：🔴 **在驿站本来待1 天 → 变成 2~3 天** —— 而因为**补给照扣**，玩家是**自己权衡**要不要多待。

### 🔴 兜底规则（必须有 · 铁律 8）

> 🔴 **"什么都不做"永远合法** —— 时间用完时，玩家可以选择「**今天就这样过**」→ 时间过去，**什么也没干，补给照扣**。

🔴 **绝不出现"时间不够就什么都干不了"** —— 那是**剥夺**（违反铁律 8：惩罚只能要价，不能剥夺）。  
**它只是"多待一天"，不是"被卡住"。**

### 🔴 入夜 = 睡觉

**入睡不是一个可消耗的时段** —— 商队**到点就睡**，第二天早上起来。  
玩家想睡就点「**休息**」→ **剩下的时间直接跳到第二天早上**（**不会让玩家觉得"白丢了一段"**）。

## 1. 时间结算系统（5.5）

### 1.1 基础规则

- **移动消耗以野外体力计**：**野外体力 = 车队固定池**（**上限 100 · 日回 50**，🔴 **不随人数变化 —— 所有人都要一起走**，2026-09-30 改）；每走 1 格消耗 **15 点**（基准车）；🔴 **正常 3 格/天 · 极限 4 格/天**（🔴 与 `第1A类 §2.2` 十二小时制一致：走 1 格 = 2 小时 → 6 小时走 3 格，当天还剩 6 小时），**攒满冲刺 = 6 格**（= 12 小时，时间正好用完）（**恶劣天气 / 坏路况抬高"每格消耗"**，详见第 1A 类 §2 / §5）。**与战斗体力共用「50 点 = 1 人份」的刻度，但不同源、互不通用**（战斗 = Σ 各人体力，人数是乘数）。
- 🔴 **时间粒度 = 小时**（2026-10-12 用户裁定 · 十二小时制，见 `第1A类 §2.2`）—— **不存在"半小时"这种粒度**，但**存在 1~3 小时的动作与"当天还剩几小时"的余量**；旧口径「1 格 = 1 天 / 不存在 0.5 天、半天」**作废**。
- 事件要么不额外占时间，要么按小时占（采集 2 · 搜索 3 · 侦察 1）；**占满当天剩余时段即入睡结算**，写"+1 天"的按"多待一天"处理
- "正常移动"同时消耗**体力**（每格 15 点）与**时间**（每格 2 小时）—— 🔴 **不是固定 1 天/格**；事件里写"+1 天"是在本次路程已用天数上额外增加 1 天
- 恶劣天气按 `第1A类 §5` 的**每格消耗加成**叠加（🔴 恶劣天气 **+5** · 灰烬风暴 **+10** —— 具体值见 `第1A类 §5`，本文件不重复）

### 1.2 行为时间消耗

| 行为 | 时间消耗 | 说明 |
|:----|:--------:|------|
| 正常移动 1 格 | **2 小时** | 基础移动（口径见 `第1A类 §2.2`） |
| 快速查看 / 简单交谈 / 快速处理 | 不额外消耗 | 事件本身不延长时间 |
| 停留采集 / 深入搜索 / 仔细侦察 | **按小时计**（采集 2 · 搜索 3 · 侦察 1） | 占满当天剩余时段即入睡 |
| 绕路（棋盘上主动选择） | 后续路线变长 | 玩家在地图上规划路线时选更长但更安全的路径 |
| 走近路（棋盘上主动选择） | 后续路线变短 | 玩家选更短但风险更高的路径 |
| 强行通过 | 当前格结算风险 | 如车损、货损、遇敌 |
| 🔴 **野外扎营** | **用掉当天全部可支配时间 + 当天全部野外体力** | 🔴 **不额外消耗食物和水**（2026-10-14 用户定，旧口径"第一天双倍"已废）· **不受外部事件影响**（只有内部事件，且扎越久触发率越高）—— 详见 `第3A类 §1.3` |
| 🔴 **等待** | 1 天/次 | 🔴 **野外也能等**（2026-10-14 用户定，不只安全点内）· 照常消耗食物和水 · **风险更高**：外部事件照常触发 |

> 绕路和走近路有两种形式：一种是在棋盘地图上玩家主动规划的路线选择；另一种是通过 E10 路线判断事件触发的临时路线选择。

### 3.1 地点分布规律（聚居圈结构）

🔴 **2026-10-05 用户裁定**：地点**不是均匀撒点**，而是按**真实聚居规律**长出来的 —— **城市是大型居住圈的中心**。

**核心图像：一座城 = 一个大型居住圈**

| 层级              | 位置             | 逻辑                                |
| :-------------- | :------------- | :-------------------------------- |
| **城市（大城 / 小城）** | 居住圈**中心**      | 人口最多、辐射最强，周边必然有人烟                 |
| **城镇**          | **城市周围**       | 依附大城的次级聚落，吃城市的溢出                  |
| **村庄**          | **城镇周围**（成堆）   | 最小聚落，必然挨着更高级的据点                   |
| **驿站**          | **城市与城市之间的沿途** | 服务**往来**而非**定居**，所以长在**路上**，不围着城转 |

**三条推论**

1. **驿站走"线"，城镇 / 村庄走"面"** —— 驿站是城市之间的**长距服务点**，可以相隔很远；城镇和村庄必须挤在城市的辐射范围内。
2. **纯野外只可能有驿站** —— 一片远离所有城市的荒地，**没有定居点**（无城镇、无村庄），但**可能有一个驿站**（老文明留下的服务点，正是为"两城之间那段没人烟的路"准备的）。
3. **聚居圈内必然有多级** —— 有城的地方，附近一定有镇；有镇的地方，附近一定有村。**不会孤零零一座城镇杵在荒野里。**

> ⚠️ **待落库**：**分布的具体密度 / 间距** —— 等行进节奏定死后一并填（🔴 **行进节奏已定死 = 正常 3 格/天 · 极限 4 格/天**，2026-10-13；**密度 / 间距本身仍待正式版地图重做时填**）。  
> 🔴 **地图尺寸是下游量** —— 先定"一天走几格"，再定"地图多大"。

**移动规则**：移动按**野外体力池**结算（**池怎么攒、每格多少点，见 §2.1**）。每移动一格的消耗：

### 5.2 补给耗尽惩罚

补给 = 0 后，每天：

- 士气 −1
- 全体角色**最大生命值降低 + 当前生命值同步扣掉同样的量**（食物归零 −10%，水归零 −20%；二者皆零则叠加）
- 重伤恢复天数 +1（不恢复反而恶化）

> 🔴 **2026-10-05 用户裁定：上限与当前血同步下降**。100/100 断食一天 → **90/90**（上限 −10 **且** 当前 −10，**两件事同时发生**）；断水一天 → **80/80**；二者皆零 → **70/70**。  
> **这不是"扣血"而是"身体上限被削掉了一块"**—— 当前血跟着降，是因为被削掉的那部分**当场就没了**，之后靠治疗也补不回那 10 点上限（治疗只填当前血，不涨上限）。

## 6. 安全点（地图休整与撤退）

**安全点 = 地图上可让商队安全休整、补给、修车、恢复士气、处理重伤的地点**，是长途商路的"锚"。

| 规则                 | 内容                                                      |

## 7. 路线分类

每段路（城市到驿站、驿站到驿站、城市到城市）之间的距离：

### 7.1 路线长度分类

|  路线类型  |      总距离（天）     |     折算格距（约）    | 定位           |
| :----: | :-------------: | :------------: | ------------ |
| **短途** |  30 天以上，60 天以下  |    90–180 格    | 新手路线 / 短途跑商  |
| **中途** |  60 天以上，120 天以下 |    180–360 格   | 有规划压力的主力路线   |
| **长途** | 120 天以上，200 天以下 |    360–600 格   | 真正远征         |
| **超长** | 200 天左右（**封顶**） | ≈600 格（**封顶**） | 后期大订单 / 边境商路 |

> 格距按 **3 格/天**（🔴 **全库折算基准**）折算；🔴 **速度恒定：没有任何提速手段**，所以**路程天数一律按 3 格/天折算**，否则"天数锚"会随节奏浮动而失去意义。
>
> 🔴 **"10 小时"说的是超长订单的全程游玩时长，不是单日行动**（2026-10-13 用户澄清）—— 按「1 格 ≈ 40 秒~1 分钟」的玩家体感，**超长档 ≈600 格 ≈ 10 小时** → **超长档封顶在 600 格 / 200 天**；再远的路不是"加档"，而是靠玩家自己分段跑。

### 7.2 补给携带（不推荐，由玩家自定）

**本文件不提供推荐携带量，也不假设"推荐玩法"。** 玩家按实际商队规模与路程自行估算：

- 消耗基准见第 3A 类 §1.5：🔴 **按出战人数算** —— **N 人出战 → 每天 N 份食物 + N 份清水**（每人每天 1 食物 + 1 水）；**不出战的人不消耗**（口粮自己买、工钱不领 =「还没被雇佣」）。
- 所需总量 ≈ 路程天数 × **出战人数** + 绕路/坏天气余量 + 沿途据点可补货程度 —— **本节不写具体份数，由 `23` / `24` 按当期出战人数生成**。
- 想怎么买就怎么买（见第 3A 类 §1.4 出发采购）。

### 7.3 中继点（休整点）与间距

**中继点只有城镇和驿站**，是路线中途的安全休息点，用于补给、修车、休整；村庄不算中继点。

- **两个相邻中继点之间**：**约 30 天左右**（**20–30 天区间、不固定**；按均速 3 格/天 ≈ 90 格）。⚠️ **不是固定 30 天**——是量级，不是一个硬值。
  - ⚠️ **为什么能到 30 天（2026-09-14 校正）**：单辆货车**纯自持**（完全不修）只有 **≈24 天**（地形 1.5 + 战斗摊销 1.0 = **2.5 耐久/天**，见第 3A 类 §2.3）——**但玩家随身带零件、能在路上自助修车**（**1 零件 = 10 耐久**，见第 3A 类 §2.4）→ **24~30 天之间的缺口由随身零件补掉**，所以中继点**不必卡在 24 天**。**这正是"零件消耗率 ≈0.73 个/天"存在的意义**（`04 §0.1` 锚 A14）。

> 📜 **本段历史论证已移入附件** → 见 `第1A类_附录_历史与修订.md`（2.3 据点间距「必须 ≤24 天」为什么废止（2026-09-14））

- 每段路（城市↔驿站、驿站↔驿站、城市↔城市）整体约 **30 天**量级（**中间必含至少 1 个中继点**）。
- 途中的"营地 / 落脚点"类格子（见 §4 节点类型）是更小型的临时休息与事件点，**不替代**中继点的补给/修车功能。

| ---- | -------------------------------------------------- |
| 标准路线 | 约 100 天                                            |

### 7.5 超长商路

超长路线（200 天以上）中间可以有一座城市作为大休整点，但到达该城市**不代表订单结束**，玩家只是中途整备后继续完成订单。

**🔴 沿途玩法 = 超长档的核心内容（2026-09-24 定）**

**"订单只规划路线"** —— 订单给**起点 + 终点 + 保底报酬**，**怎么走是玩家自己的事**。超长的**期限余量（325 天 / 975 格）就是给沿途活动的预算**，不是"缓冲"：

| 沿途可做的事    | 已有机制                                                                               | 出处                   |
| :-------- | :--------------------------------------------------------------------------------- | :------------------- |
| 探索遗迹      | E7 小型遗迹事件                                                                          | `第5A类 §3.10`         |
| 周围村庄卖货    | 顺路单无上限 + 自带货低买高卖                                                                   | `04 §8` · `第10A类 §三` |
| 中途大休整     | 城市作大休整点（本条）                                                                        | 本节                   |
| 分段推进（不无聊） | 中继点每 30 天一个 = 8 个小目标                                                               | `§7.3`               |
| 时间预算      | 期限 − 路程 = **325 天**（≈57% 期限）；全程体力：路程耗 **11,250 点** ÷ 期限回 **28,750 点** ≈ **61% 余量** | 锚 A11 · `§2.1`       |

**🔴 自带刹车（不用另写规则）**：**走 2 格（30 点）+ 采集（20 点）= 50 点刚好花完；再叠加侦察（10 点）就得再省半格** → **想沿途做事，速度自动从 3 格/天掉到 2 格/天（再叠加侦察 / 搜索 → 1~1.5 格/天）**。这是玩家自己选的，不是系统禁止（符合"不用硬限制"铁律）。

**🔴 代价自成天平**：**早交 = 省消耗但少收获；绕路 = 多消耗但多收获** —— 沿途每多待一天，就多烧一天硬账（后期 ≈1,493 金/天）；赚不赚得回来，玩家自己押。

### 7.6 订单期限

```
订单期限 = 路程天数 × k_期        （k_期 分档：短途 2.0 / 中途 2.1 / 长途 2.2 / 超长 2.3）
```

例：100 天路程 → 订单期限 **210 天**。250 天路程 → 订单期限 **575 天**。

| 档  | 路程天数 | k_期 |  期限 | **余量（= 沿途活动预算）** |
| :- | ---: | --: | --: | ---------------: |
| 短途 |   60 | 2.0 | 120 |             60 天 |
| 中途 |  100 | 2.1 | 210 |            110 天 |
| 长途 |  150 | 2.2 | 330 |            180 天 |
| 超长 |  250 | 2.3 | 575 |        **325 天** |

> 🔴 **期限不是"限时死线"，是"里程预算"（2026-09-24 定）**：**"订单只规划路线"** —— 订单给**起点 + 终点 + 保底报酬**，**怎么走是玩家自己的事**。  
> **余量 = 给沿途活动的天数**（探索遗迹 / 卖货 / 顺路单 / 分段推进），**不是"缓冲"**。  
> **代价自成天平**：**早交 = 省消耗但少收获；绕路 = 多消耗但多收获**。

**一句话**：**会变的东西才需要藏，不变的东西一律直接可见。**

| 东西                             |   有没有迷雾  | 为什么                                                  |
| ------------------------------ | :------: | ---------------------------------------------------- |
| **随机事件**（战斗 / 危险区 / 资源点 / 传闻…） |  ✅ **有** | **"今天这里有没有事"是不确定的** → 看不见，要靠侦察抬高信息等级去确认              |
| **地形**（山 / 水 / 桥 / 林 / 废墟）     | ❌ **没有** | 它**一直就在那里** —— 玩家直接看到                                |
| **灰度读数**（`第8A类` 灰度三层）          | ❌ **没有** | 同上 —— 地图的固定属性，不是随机内容                                 |
| **城市 / 城镇 / 驿站 / 村庄的位置**       | ❌ **没有** | 同上 —— 地点是固定的，玩家直接看到                                  |
| **遗迹的位置**                      | ❌ **没有** | 🔴 **遗迹位置永远不变**（`§9.7` ⑥）—— 位置一直可见，**变的是它今天"给不给"东西** |


- **基准可见范围 = 自身格 + 十字四邻**（上下左右各 1 格）。
- **信息等级 = 决定"随机事件看得清不清"**（是强盗还是商队、有几个），0 级几乎只知脚下。
- 范围 / 半径的**具体对照表属数值细化，待填**（见 §12）。

### 9.1 信息等级定义（迷雾里"能看到多清"）

🔴 **2026-10-05 用户裁定：0~~5 档 → 0~~10 档，但信息量上限不变。**

**为什么加密**：商队规模变大了（不再是最初 3 人小队），一个区域里可能同时有好几拨人、好几处资源 —— **5 档太粗，"知道有敌人"和"知道是强盗"之间没有过渡**。10 档是为了**更精细**，**不是让玩家看到更多**。

**怎么加密**：**等比映射**，原来的每一档落在偶数档，中间奇数档是**过渡精度**（比下一档多知道一点、但不到下一档）。

|  等级 | 名称   | 玩家知道什么                 | 示例                     |
| :-: | :--- | ---------------------- | ---------------------- |
|  0  | 无信息  | 什么都不知道，只知道有异常          | "前方出现异常。"              |
|  1  | 异常   | 知道有东西，但连"是不是威胁"都定不了    | "前面那片不太对劲……"           |
|  2  | 模糊信息 | 知道可能有危险，但不知道类型         | "前方情况不太对，可能有危险。"       |
|  3  | 性质   | 知道是"人"还是"兽"，但不知道是哪类    | "有活物，看不清是人还是兽。"        |
|  4  | 类型信息 | 知道大概类型                 | "前方像是有人活动过，可能是敌对风险。"   |
|  5  | 势力   | 知道属于哪一类敌人              | "是野兽，不是人。"             |
|  6  | 关键信息 | 知道具体类别                 | "前方大概率是强盗活动痕迹。"        |
|  7  | 数量级  | 知道大概规模                 | "人不少，不止三五个。"           |
|  8  | 详细信息 | 知道大致数量、方向、位置范围         | "约 5-8 人，位置在北侧断路附近。"   |
|  9  | 定位   | 知道大致方位，但格子仍模糊          | "就在前面那片，靠近断路。"         |
|  10 | 精确信息 | 知道具体人数、**具体格子**、具体触发条件 | "强盗 6 人，埋伏在前方第 3 格右侧。" |

> **对照关系**：旧 0~5 档 ≡ 新 **0 / 2 / 4 / 6 / 8 / 10** 档；新 **9 档 = 只差一步到精确定位**（比旧 4 档强，比旧 5 档弱）。所有提到"5 级上限""4 级"的地方，一律按 ×2 换算。  
> **上限依旧是 10** —— 走到 10 级也不能透视全图（范围仍受 §9.0 半径约束）。

> **低等级的"不确定"来自信息不足，不是"敌人生成靠随机"**：敌人与资源点在地图上是**预先摆好的、占具体格子的**，只是你看不清。所以"侦察 → 绕开"才成立——你绕开的是**真实存在的那一队人 / 那一片危险**。
>
> 等级越高知道的越多，可细到：**在第几格、几人、是否被悬赏、击败能得多少战利**。

### 9.2 信息类型

信息分为6大类，不同角色只影响自己专业的信息类型：

| 信息类型         | 说明               | 初始角色来源                     |   提升幅度   |
| :----------- | ---------------- | -------------------------- | :------: |
| **路线信息**     | 前路、岔路、雾天、危险地形    | 荒野射手【野外侦察】                 | **+2 级** |
| **敌情信息**     | 强盗、野兽、灰烬兽、伏击、夜袭  | 荒野射手【野外侦察】                 | **+2 级** |
| **资源信息**     | 补给、水源、草药、材料、猎物   | 荒野射手【狩猎采集】（偏结果权重，不直接加信息等级） |     —    |
| **结构信息**     | 桥梁、道路、坡道、废墟结构（现场结构，不含车体） | 修补师【现场诊断】                  | **+2 级** |
| **车损信息**     | 车轮、车身、车架、车篷（🔴 四部位，见 `第3A类 §2.2A`）、抛锚隐患 | 修补师【现场诊断】                  | **+2 级** |
| **异常/旧文明信息** | 灰烬、火种、旧文明设备      | 初始修补师暂不专精                  |     —    |

> 🔴 **2026-10-05**：原 +1 级全部改为 **+2 级**（因为等级刻度从 5 档加密到 10 档，**同样强度的信源必须给等比的提升**，否则等于把侦察能力砍半）。  
> 护路人不提供信息等级。护路人负责稳定结算，不负责侦察。

### 9.3 信息计算方式

```
最终信息等级 = 事件基础信息 + 区域信息 + 角色词条信息 + 装备信息 + 路线情报/记忆信息
最高不超过 10 级
```

| 信息来源      |  范围 | 说明                        |
| --------- | :-: | ------------------------- |
| 事件基础信息    | 0-4 | 事件本身给出的可见程度（原 0-2 ×2）     |
| 区域信息      | 0-2 | 该区域是否有明显特征（原 0-1 ×2）      |
| 角色词条信息    | 0-2 | 随行角色是否有对应信息词条（原 0-1 ×2）   |
| 装备/工具信息   | 0-2 | 望远镜、探测器、地图等（原 0-1 ×2）     |
| 记忆/路线情报信息 | 0-4 | 旧文明记忆、驿站情报、商队传闻（原 0-2 ×2） |

### 9.4 初始信息上限

在没有装备、记忆、路线情报的初始阶段，最高可看到 **4 级（类型信息）**。

| 阶段                | 信息上限（10 档制） | 旧 5 档制 |
| :---------------- | :---------: | :----: |
| 初始队伍，无装备/无记忆/无情报  |  最高 **4 级** |   2 级  |
| 加上路线情报、驿站预警、基础工具  |  可到 **6 级** |   3 级  |
| 中后期专用装备、专精角色、特殊记忆 |  可到 **8 级** |   4 级  |
| 高级记忆、高级设备、剧情关键情报  | 可到 **10 级** |   5 级  |

> 🔴 **刻度变了，档位描述不变** —— 走的还是同一条从"啥也不知道"到"精确定位"的阶梯，只是每级切得更细。  
> ⚠️ **人数口径未定**：`第3A类` 现写「开局 14 人」，用户口头提过"三四十人"。**商队越大 → 需要的信息粒度越细**，这是本次加密的动因；上表按**等比**设计，与具体人数无绑定，待人数口径定死后再复核一次。

### 9.5 角色信息能力（关联第 **6A** 类）

角色词条信息的具体设定属于第 **6A** 类，此处仅列接口：

| 角色   | 词条     | 影响的信息类型                 |
| :--- | :----- | ----------------------- |
| 荒野射手 | 【野外侦察】 | 路线信息、敌情信息、痕迹信息等级 **+2** |
| 修补师  | 【现场诊断】 | 结构信息、车损信息等级 **+2**      |
| 护路人  | —      | 不提供信息等级，负责稳定结算          |

### 9.6 主动侦察（花体力买信息）

§9.3 那套是**被动叠加**（带了谁、带了什么，就看得多清）。在此之上，玩家可以**主动花资源买一次侦察**：

🔴 **2026-10-05 用户裁定：侦察只抬「信息等级」，不给「精确位置」。**

| 项目         | 规则                                                                 |
| :--------- | :----------------------------------------------------------------- |
| **消耗**     | **10 点野外体力**（从体力池里出，见 §2.1）                                        |
| **作用范围**   | 自身周围 **5×5 = 25 格**                                                |
| **效果**     | 该范围内**信息等级 +2**（仍受 **10 级**上限约束，见 §9.1）                            |
| **🔴 硬边界** | **只涨等级，不揭示坐标** —— **永远不会告诉你"敌人在第几格"**                              |
| **能揭示**    | 那一带**有什么**（有几拨人 / 是人还是兽 / 属于哪类 / 大概多少人 / 有物资 / 有据点）—— **但不知道在哪个格** |
| **门槛**     | **基础侦察人人可用**；**记忆 / 角色词条 / 装备** 提供强化版（范围更大、提升更多、甚至不耗体力）            |

**为什么不能给精确位置**：否则**所有敌人只用侦察就能精准避开** —— 战斗（卡牌战术）这一整块就没用了，野外也退化成"点一下看清地图"。侦察的职责是**让你知道"前面有麻烦"，让你自己决定绕还是打**，不是替你把路选好。

**"看到具体格子"只有一个途径：走到十字格**

| 途径           | 说明                                                    |
| :----------- | :---------------------------------------------------- |
| **走到十字邻格**   | 站在目标格**上下左右任一格**，即可看清该格内容（基准可见范围 = 自身格 + 十字四邻，见 §9.0） |
| **等级到 10 级** | 也**只是**看清十字邻格 —— **等级再高也不给全局坐标**（上限不变）                |

**典型用法**：远处只知"这一带有个驿站"（2 级）→ 花 10 点侦察 → **升到 4 级，得知"是个驿站，不止一个，还有个村子"** → 但**仍不知道具体格** → 只能靠读地形 / 问情报 / 一路走过去。

- ⚠️ **侦察只揭示"预先摆在那儿的实体"，不预知随机结果**：它会告诉你"这一带有 6 个强盗"，不会告诉你"走哪一格会掷出遭遇"。
- ⚠️ **不是免费万能**：花体力就少走一格 / 少采一次（§2.1），而**绕开一格 ≈ 1/3 天 ≈ 100 金**、与打一场普通仗的开销同量级——两边都得付钱，玩家才会真权衡，而不是"见敌必绕"。
- **关联**：荒野射手【野外侦察】（第 6A 类）在本动作之上再 +2 级；E13 地标 / 视野事件（第 5A 类 §3.15）是**免费的一次性侦察**，与本动作并列。

## 2. 天气系统（5.1）

### 2.1 天气段规则

天气不再按"每走一格重新随机一个天气"处理，而是按**天气段**生成。

**生成流程：**
1. 当前天气段剩余天数每天 -1
2. 若剩余天数 > 0，继续使用当前天气
3. 若剩余天数为 0，按天气基础概率抽取下一段天气
4. 根据抽到的天气类别，生成持续天数
5. 写入当前天气和剩余天数
6. 每天按当前天气结算补给、货物、战斗、外部事件权重、内部事件压力等

**天气段持续时间：**
| 天气类别 | 包含天气 | 持续时间 |
|:--------|---------|:--------:|
| 普通天气 | 晴朗、阴天 | 5-7 天 |
| 特殊天气 | 小雨、暴雨、高温、酷热、寒潮、严寒、浓雾、重雾 | 3-6 天 |
| 灰烬风 | 灰烬风 | 4-5 天 |
| 灰烬风暴 | 灰烬风暴 | 2-3 天 |

### 2.2 基础天气概率

## 3.5 🔴 数据结构（写代码前先把这个定死）

> 🔴 **这是最重要的一块** —— AI 各写各的，八成是因为这块没定。
> 🔴 **下面用 Python 语法举例**（只是举例，**换成任何语言都是同样的字段**）。

### 3.5.1 地图格子

```python
# 一格 = 地图上的一个格子
格子 = {
    "坐标": (x, y),           # 整数，(0,0) 在左下 / 左上（🔴 方向本轮不定死，只要求一致）
    "类型": "野地",           # 见 3.5.2 枚举
    "路况档": "普通",         # 好 / 普通 / 差 / 恶劣
    "地点名": None,           # 只有"地点类"格子才有名字（如"灰原城"）
    "已探明": False,          # 玩家没去过、也没侦察到 → False
}
```

### 3.5.2 格子类型枚举（🔴 抄自 `1A §4`，不要自创）

| 类型 | 说明 | 能否停留 |
|:--|:--|:--:|
| 大城 / 小城 / 城镇 / 驿站 / 村庄 | 地点类（有名字） | ✅ |
| 野地 / 林地 / 草原 / 沙地 / 沼泽 | 地形类 | ❌ |
| 山 / 水 / 桥 | 通行类 | 桥可停？⚠️ 待定 |
| 废墟 | 特殊类 | ⚠️ 待定 |

> 🔴 **本轮先不做"能不能停"的区分** —— 只要走进地点类格子就算"抵达"，进城买东西是单元 02。

### 3.5.3 游戏状态（玩家跑一整趟，期间会变的那些）

```python
游戏状态 = {
    # —— 位置 ——
    "当前坐标": (0, 0),
    "地图": [ ... 所有格子 ... ],

    # —— 时间 ——
    "第几天": 1,
    "当前小时": 7,              # 7 = 07:00 · 19 = 19:00

    # —— 体力 ——
    "野外体力": 100,            # 🔴 上限 100 · 每格 −15 · 每天 +50
    "体力上限": 100,

    # —— 天气 ——
    "当前天气": "晴朗",
    "天气剩余天数": 3,
    "恶劣天气": False,          # 恶劣 → 每格消耗 +5（风暴 +10）

    # —— 侦察 ——
    "信息等级": 1,              # 见 1A §9.1
    "已探明地点": ["灰原城"],

    # —— 本轮不存在的（留给单元 02 之后）——
    # "金币" / "食物" / "清水" / "零件" / "士气" / "车队耐久" / "角色生命"
}
```

> 🔴 **把不存在的状态写在注释里** —— 这样下一个 AI 知道边界在哪，不会顺手把金币也做了。

## 3.6 🔴 模块划分（文件清单）

> 🔴 **建议 7 个文件，不要更多** —— 一个单元拆太细，等于把简单的事写复杂。

| # | 文件（名字可换） | 只负责一件事 | 🔴 不许碰 |
|:-:|:--|:--|:--|
| 1 | `地图.py` | 地图数据存哪、怎么查一格、怎么铺测试地图 | 不管时间、体力 |
| 2 | `时间.py` | 第几天 + 当前小时怎么推进、怎么跨日 | **🔴 不管跨日时发什么**（只报"我跨日了"） |
| 3 | `体力.py` | 体力池：够不够、扣、回 | 不管扣完谁来触发 |
| 4 | `天气.py` | 掷天气段、算当前每格消耗加成 | 不管消耗怎么用 |
| 5 | `侦察.py` | 信息等级、已探明标记、侦察消耗 | 不管走格 |
| 6 | `结算.py` | 跨日那一刻发生什么（天气推进、体力回满） | 不管单个动作 |
| 7 | `主循环.py` | 🔴 **唯一串起 1~6 的地方** —— 玩家按键 → 走一格 → 谁先谁后 | 不写具体规则，只转发 |

> 🔴 **为什么要拆成"跨日"和"单步"两个文件**（`结算.py` / `主循环.py`）：
> 🔴 **本单元最大的风险就是"跨日那一刻漏算或重算"** —— 单独一个文件专门管跨日，出问题一查就知道。

## 3.7 🔴 实施顺序（照这个顺序写，别跳）

| 步 | 写什么 | 产出 | 🔴 怎么确认这步做完了 |
|:-:|:--|:--|:--|
| **1** | `地图.py` | 一张能加载的测试地图 | 🔴 **能把地图打印出来**（或画出来），看得见 30×30 和两个地点 |
| **2** | `时间.py` | 推进函数 | 🔴 连续调 20 次，每次 +2 小时，**到 19 就跨日** |
| **3** | `体力.py` | 够/扣/回 | 🔴 调一次"走一格"，体力 −15；体力 5 点时调"走一格" → **拒绝** |
| **4** | `天气.py` | 掷天气 + 加成 | 🔴 强制掷出暴雨时，打印出的加成是 5 |
| **5** | `侦察.py` | 标记已探明 | 🔴 侦察一次后，那一格 `已探明 = True` |
| **6** | `结算.py` + 🔴 `主循环.py` | **串起来** | 🔴 **连走 3 格，然后跨日**，体力从 100 → 55 → 第二天变 100 |
| **7** | 两条路对比 | 跑一次近路、一次远路 | 🔴 **两边的天数和总消耗不一样** |

> 🔴 **第 6 步之前不要碰主循环** —— 前五步每一步都能单独测，主循环一写就套住了，反而难查。

## 3.8 🔴 主循环长什么样（一次"走一格"的完整链路）

```
玩家输入"走"
   ↓
① 主循环：读玩家指令
   ↓
② 体力.够不够(15 + 天气加成)？  ── 不够 ──→ 提示"今天走不动了"，回到 ①（不消耗任何东西）
   │ 够
   ↓
③ 体力.扣(15 + 天气加成)
   ↓
④ 时间.推进(2 小时)
   ↓
⑤ 地图.换格子(新坐标 → 查新格子的类型与路况)
   ↓
⑥ 时间.到 19 点了吗？  ── 没有 ──→ 回到 ①
   │ 有
   ↓
⑦ 结算.跨日()：天气推进 +1 天、体力 +50（不超上限）、掷新天气
   ↓
⑧ 侦察.检查新格子 → 如果是新的地点，标记为已探明
   ↓
回到 ①
```

> 🔴 **每一步都必须能被单独打断检查** —— 比如第 ⑦ 步跑完后打印一下状态，能立刻看出"体力加了吗、天气推进了吗"。

## 3.9 🔴 出错了怎么查（不用引擎也能查）

| 症状 | 大概率错在哪 |
|:--|:--|
| 🔴 **一天结束扣了两次体力** | `主循环` 和 `结算` 都调了恢复 —— **只留一处** |
| 🔴 **体力变成负数** | `体力.够不够` 的判断没生效，或者扣之前没查 |
| 🔴 **走到 19 点还能继续走** | `主循环` 第 ⑥ 步的判断写错（`>` 还是 `>=`） |
| 🔴 **跨日没发生 / 永远跨不了日** | `时间.推进` 到 19 之后没触发 `结算` |
| 🔴 **两条路算出来一样** | 路况加成没接进 `体力.够不够` 那个计算里 |
| 🔴 **天气一直不变** | `天气` 的"剩余天数 −1"没写在 `结算.跨日` 里 |

> 🔴 **建议每写完一步，就用最笨的办法验证**：往代码里插一行 `打印(当前状态)`，跑一次，看一眼对不对，**再删掉**。

## 4. 测试步骤与预期结果

> 🔴 **这一节是本单元的核心** —— 测试的人照着做就行。

### 步骤 1：从起点出发，正常走

| 做什么 | 预期发生什么 |
|:--|:--|
| 从起点走到下一格 | 体力 **−15**、当前小时 **+2** |
| 连续走 3 格 | 体力 **−45**、当前小时 **到 13:00** |
| 再走第 4 格 | 体力 **−60**（累计）· 🔴 **第 4 格要到 15:00，仍在 19:00 之前** |
| 走完这一天 | 🔴 **19:00 收工** · 触发跨日结算 · **第 2 天** · 体力 **+50（不超过上限 100）** |

**要盯的**：🔴 **跨日那一刻有没有重复扣、漏扣、或扣两次**。

### 步骤 2：测试冲刺

| 做什么 | 预期发生什么 |
|:--|:--|
| 连着几天不花体力 | 体力攒到 **100（上限）** |
| 满体力出发 | 走 **6 格**（90 点）· 🔴 **正好用完 12 小时** |

### 步骤 3：测试恶劣天气

| 做什么 | 预期发生什么 |
|:--|:--|
| 天气掷成暴雨（+5） | 每格消耗变成 **20** |
| 恶劣天气下走一天 | 50 点回复只能走 **2 格**（100 ÷ 20 = 5，但一天回复只有 50 → 2 格） |
| 灰烬风暴（+10） | 每格 **25 点** → 一天只够 **2 格** |

### 步骤 4：测试两条路的差别

| 做什么 | 预期发生什么 |
|:--|:--|
| 走近的那条（路况差） | 天数少 · 但**每格消耗更高** |
| 走远的那条（路况好） | 天数多 · 但**每格消耗更低** |
| 🔴 **关键判据** | **两条路的天数与消耗要真的不同** —— 如果算下来一样，说明"路线选择"没成立 |

### 步骤 5：测试侦察与信息

| 做什么 | 预期发生什么 |
|:--|:--|
| 花体力侦察 | 信息等级提升（见 `1A §9.6`）· 🔴 **不给坐标** |
| 走到一个没去过的地方 | 该地点从"迷雾"变成"已知" |
| 🔴 **关键判据** | **侦察不能替代走路** —— 不该出现"侦察完就不用去了" |

### 步骤 6：抵达终点

| 做什么 | 预期发生什么 |
|:--|:--|
| 走进终点格 | 当天正常结算 · 提示"已抵达" · **本轮到此为止**（进城买东西是单元 02） |

## 5. 边界情况

| # | 情况 | 预期 |
|:-:|:--|:--|
| 1 | 🔴 **体力不够走到下一格** | 不能走（**不许欠体力硬走**），提示"今天走不动了" |
| 2 | 🔴 **在 19:00 前走不完最后一格** | **允许走完这格**（2 小时一格是整块的），之后强制收工 |
| 3 | 🔴 **19:00 正好卡在一格中间** | 不许卡半格 —— **格是整块单位** |

| 5 | 天气段到期 | 自动掷新天气 · 🔴 **不能让天气"卡住"不让走** |
| 6 | 连日扎营 | 🔴 体力归零但**时间在走** · 扎营期间**不受外部事件**（本轮无事件，但预留） |

| 8 | 🔴 **反复横跳同一条路** | 允许（没有限制），但要确认**没有资源泄漏** |
