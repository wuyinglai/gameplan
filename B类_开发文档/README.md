## 🔴 三条判定原则

| # | 原则 |
|:-:|:--|
| 1 | 🔴 **一个阶段做完就该能独立跑起来** —— 能"走一趟"、能"买一次东西" |
| 2 | 🔴 **规则能跑 ≠ 已平衡** —— 未定稿的数值一律标「暂定 / 待验证」 |
| 3 | 🔴 **本阶段只抓严重问题** —— 会阻断流程、造成规则冲突、破坏核心体验、让玩家无法恢复的 |
