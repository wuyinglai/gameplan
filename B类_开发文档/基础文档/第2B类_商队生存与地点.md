## 2. 🔴 本轮的三条口径（必须先看）

### 2.1 🔴 补给按**出战人数**扣，不是按总人数

> 🔴 这是 A 类铁律，**最容易搞错的一条**。

| 情况 | 消耗 |
|:--|:--|
| **N 人出战** | 🔴 **N 份食物 + N 份清水 / 天** |
| **1 人出战，13 人在车上** | 🔴 **只扣 1 份食物 + 1 份清水** |
| 出战者受伤不能上场 | 🔴 **当天就不再算他那份** |

> 🔴 **为什么不按总人数**：不出战的人**口粮自己买、工钱不领**（"还没被雇佣"）。

### 2.2 🔴 四部位车损 = 四条损耗渠道

| 部位 | 损耗来源 | 🔴 损坏后 |
|:--|:--|:--|
| **车轮** | 行驶 | 🔴 **车辆无法继续前进** |
| **车身** | 战斗 | 🔴 **车辆无法继续前进** |
| **车架** | 地形 | ⚠️ **走烂路时，车轮与车身磨损翻一倍** |
| **车篷** | 天气 | ⚠️ **下雨或恶劣天气时，货物受损** |

**四档状态**：完好 / 磨损 / 破损（🔴 **纯显示无效果**）/ **损坏**（🔴 后果生效，必须修）

### 2.3 🔴 断粮是**恶化**，不是"停止恢复"

| | |
|:--|:--|
| 🔴 **有食物和水** | 每天正常推进 |
| 🔴 **断粮 / 断水** | 🔴 **恶化一次**（进度倒退）—— 不是"不变"，是**往回退** |

### 1.3 消耗规则（按「份」整数计量）

**食物和水以「份」为最小单位（整数，不拆份）：**

- 1 份食物 = 1 人 1 天口粮
- 1 份水 = 1 人 1 天饮水
- 购买补给按格（1 格 = 整数份），不拆散份

| 项目           | 规则                                                                                                              |
| :----------- | :-------------------------------------------------------------------------------------------------------------- |
| 移动 1 步（1 格）  | 消耗 **15 点野外体力**（**体力池上限 100 · 日回 50**；🔴 **不随人数变化——所有人都要一起走**；**正常 3 格/天 · 极限 4 格/天**、攒满冲刺 **6 格**；详见第 1A 类 §2） |
| 每人每天         | 消耗 **1 份食物 + 1 份水**                                                                                             |
| 🔴 **重伤恢复**    | 🔴 **重伤不是只有"休养"才恢复 —— 只要有食物和水，重伤每天自动恢复进度 +1**（走不走路都一样）。**食物或水归零 → 不但不恢复，反而恶化 1 档**（见 §1.6） |
| 🔴 **等待**        | 🔴 **野外也能等**（不只是城市 / 城镇 / 驿站）—— 原地不动过一天，**照常消耗食物和水**。等待**风险更高**：外部事件照常触发，且不会因为"你在等人"就减少 |
| 🔴 **野外扎营**    | 🔴 **和等待不是一回事**：① **不额外消耗食物和水**（和平时一样）② **消耗当天全部体力 + 全部可支配时间**（按日回 50 点体力 = 当天体力全掉，12 小时全用掉）③ **不受外部事件影响** —— 扎营期间只会有内部事件 ④ **扎营越久，内部事件触发率越高**（久扎必出事，但出的不是外部那类） |

### 1.4 出发采购（无推荐方案）

商队出发前自行采购补给，**不预设推荐 / 保守 / 冒险等方案**——玩家按路线长短、资金、据点分布自行决定买多少，**想怎么买就怎么买**。

- 清水以**水箱**为单位采购（1 格 = 1 水箱 = 3 份），喝完水箱占格不释放、可沿途再灌（见 §3.2），**没有"水桶"设定**。
- 食物 / 零件 / 药包按 §1.3 消耗、§3.2 占格与重量自行搭配。
- 采购成本以第 2A 类经济系统为准；初始资金见 §1.1。



### 1.5 商队人数与补给消耗

商队初始 **14 人**（核心成员，含 3 护卫 + 车夫 + 后勤 + 其余，详见第 **6A** 类），后期可招募扩展，**不设硬上限**。

商队人数影响战斗行动点数（行动点数归属第 **4A** 类战斗系统）；🔴 **每天食物/水消耗只按「出战人数」算**（见下表）。

|   **出战人数**  | 每天食物 | 每天清水 | 说明                                                                     |
| :---------: | :--: | :--: | ---------------------------------------------------------------------- |
| 3 人（初始出战基准） |  3 份 |  3 份 | 🔴 **每人每天 = 1 份食物 + 1 份清水**（2026-10-13 用户亲口定：14 人 = 14 份食物 + 14 份清水/天） |
|   每 +1 名出战  | +1 份 | +1 份 | 整数份，不拆份；🔴 **两列永远分开写，禁止合并成「28 份」这类总数**                                 |


> 🔴 **表述铁律**：两种资源**永远分开写**（「N 份食物 + N 份清水」），**禁止合并成「28 份」这类总数**。
> 🔴 **受影响的数值链待重调**：`§3.6` 示例账 · `04 §0.3` 日均硬账 300 / 934 / 1,493 · `第1A类 §10.2` 消耗模型 →统一由 `23` / `24` 处理（**盖章法：不在本文件逐行改数**）。
> 占格换算见 §3.2 / §3.6。
>
> 🔴 **不出战的人不消耗商队补给**（2026-10-06 用户裁定 · 2026-10-09 补解释）：**口粮他们自己买、工钱他们不领** —— 因为**还没被雇佣**（雇佣 = 建立关系 = 领工资 + 吃商队的粮）。商队走到哪人跟到哪（`§4.9.3`），不出战的人**仍在车队上**，只是这一趟没动用他们。完整理由见 `§4.9.2` / `第6A类 §8.4`。

### 1.6 食物/水耗尽惩罚（立即生效，不等待）

🔴 **2026-10-05 用户裁定：血量上限与当前生命值「同步下降」** —— 100/100 断食一天 → **90/90**（上限 −10 **且** 当前 −10，**两件事同时发生**）。与 `第1A类 §5.2` 一致。

> **怎么算**：`−10%` = **减去「该角色最大生命值的 10%」这么多点生命值**。上限 100 → 上限变 **90**、当前血也变 **90**；上限 240 → 上限变 **216**、当前血也变 **216**（各人按自己的上限算，不是固定扣 10 点）。

**食物 = 0 后，每天恶化一次：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **10%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | **恶化一次**（见下方说明） |

**清水 = 0 后，每天恶化一次：**

| 惩罚   | 内容                                                    |
| :--- | :---------------------------------------------------- |
| 士气   | -1                                                    |
| 全体角色 | **最大生命值** 减少「该角色上限的 **20%**」 **且** **当前生命值**同步减少同样的点数 |
| 重伤恢复 | **恶化一次**（见下方说明） |

**🔴 重伤恶化 = 什么**（2026-10-14 用户要求写明）：

- 重伤角色本来**每天恢复进度 +1**；**一旦食物或水归零，这一天不但不恢复，反而倒退 1 档** —— 从"离治好更近"变成"离治好更远"。
- **恶化是往回退，不是叠加扣血** —— 血量那部分已经在上面两张表里扣了，这里动的是**重伤恢复进度**。
- 🔴 **恶化可以靠后续补粮补水退回来**（见下方「恢复机制」）—— **不是永久的**。

> 🔴 **为什么当前血也要扣**：被削掉的那部分上限**当场就没了** —— 100/100 断食一天变 90/90，而不是 100/90。**若只降上限、当前血不动**，会出现 60/100 这种"上限低于当前"的荒谬状态。
>
> 食物和水都归零 → 双重惩罚叠加（90/90 → 70/70），商队迅速崩溃。

### 1.6.1 🔴 补给耗尽的**恢复机制**（不是永久的）

🔴 **2026-10-14 用户裁定**：断粮断水削掉的上限**能补回来** —— 只要重新有食物和水，**每天自动往回修**，**但当前血量不会因此恢复**。

| 恢复来源 | 每天恢复「该角色上限的」 | 当前生命值 |
|:--|--:|:--:|
| **重新有食物** | **10%** | 🔴 **不恢复** |
| **重新有水** | **20%** | 🔴 **不恢复** |

- **上限会回来，血不会自己回来**：断食两天把上限从 100 削到 80，补粮两天后上限回到 100 —— 但**当前血仍然是 80**（或更低），要靠**药包 / 治疗 / 自然休息**把血填回来。
- **只挨一两天完全补得回来**；长期断粮削掉的幅度很大，靠自然回补会慢很多（每天 10% / 20%）。
- 🔴 **上限恢复到多少封顶**：**不超过该角色原本的上限**（不会因为多吃几天把上限撑得比初始还高）。

> 路上天然水源多为**脏水**，需净化后饮用（详见 §1.7）。

### 1.7 脏水与净化（后期机制）

路上常遇见**脏水**水源（事件系统详见第 5A 类），分两种情况：

| **情况** | **结果** |
| :--- | :--- |
| **未净化直接喝** | 🔴 **挂负面状态**：**污染度累积**（叠加型，可多层）→ 体力恢复变慢、士气自然恢复受阻；喝够一定量会**直接生病**（持续掉当前血，不治疗不会好） |
| **净化后饮用** | 后期解锁**净化设备**（水箱改造或车载净水模块）后，脏水可安全饮用，等于沿途白捡水源 |

> 🔴 **脏水不是"一次就死"，是"越喝越糟"**（2026-10-14 用户定方向）：脏水的代价走**累积**路线 —— 喝着喝着，队伍的整体状态被拖下去。
> **具体数值**（污染度几层、每层扣多少、几层生病）⚠️ **待定**，走 `23` / `24` 调平。
> **意义**：净化设备大幅减轻**超长途（≥200 天）**的补给压力——不必全程自带几百格水，沿途净化脏水即可。
>
> 净化设备属 §3.5「可升级项」之一，升级途径 ⚠️ 待定。

## 1. 地点分类总览

游戏中安全点分以下五类：

| 地点 | 定位 | 核心特征 |
|:---:|------|---------|
| **大城（九城）** | 唯一真正的大安全点 | 唯一有节点反应炉、可处理重伤/严重重伤、功能最完整、物价最低 |
| **小城** | 自发聚集定居点 | 无节点、无**记忆设施与装具台**；🔴 **但有基础工坊**（普通铁匠活），其余正常设施与大城相同；物价同大城一档（比城镇低）；治安比大城危险；有聚落事件；受灰兽潮影响 |
| **城镇** | 路上的补给容错点 | 补给、生活物资、普通治疗、偏生活 |
| **驿站** | 商队专门休息点 | 零件、修车、路线服务、偏车队；**不接收撤退** |
| **村庄** | 小型聚落 | 功能最少、小订单、少量交易、情报、物价最高 |

> 各地点功能为参考框架，具体功能以实际设定为准。
> 城镇和驿站是平级关系，功能基本相同，只是偏向不同，不是上下级。

### 同一档内的偏向（2026-10-14 用户定）

| 地点 | 🔴 什么便宜 | 什么贵一点 |
|:--|:--|:--|
| **城镇** | **生活物资** —— 补给 / 食物 / 清水 · **药包** | 零件 · 修车 |
| **驿站** | **车队机械件** —— **零件 / 修车** | 生活物资 · **药包** |

🔴 **印证现有价格表**（`§7.1` / `§7.3`）：食物 城镇 **15** < 驿站 **16** · 零件 **驿站 70 < 城镇 75** · 药包 **城镇 70 < 驿站 75** · 修车 **驿站 25 < 城镇 30** · 治疗 **城镇 25 < 驿站 30** —— 方向全部对得上。

**为什么城镇的药包反而比驿站便宜**（2026-10-14 用户给的原理）：

- **药包存放时间长** —— 它不像鲜货那样容易坏，城镇能囤得住。
- **城镇是商队补给的集散地** —— 大多数商队上路都要药包，需求量集中、存货量大。
- **驿站是"路过歇脚"的地方** —— 存货少、卖完就得等下一队，所以药包反而贵。
- 一句话：**城镇靠"住着人、日子长、货能囤"，驿站靠"车队常来、修车顺手"。**

🔴 **别把档内偏向当成"谁更贵"**：二档里两地的价格是**互相有高有低**的，不是固定谁贵 —— 城镇药包 / 治疗便宜但零件修车贵，驿站零件修车便宜但药包贵。

**灰兽潮说明（五类地点通用）**

**灰兽潮 = 偶发单城围攻**（详见 `第8A类 §六`）：某**单座**城市 / 聚落被几十 ~ 几百只灰兽**聚集围攻**。它是**自然兽群**受迁徙 / 食物 / 受惊驱动的聚集 —— **不是军队，也不是母兽派来的**；**偶发、无法倒计时准备**（旧框架「提前 30 天预警 + 强制加固城墙」已删）。

- 🔴 **任何聚落都可能被波及，但防护弱的更容易中招**：**只有大城有节点反应炉**；小城 / 城镇 / 驿站 / 村庄**均无节点、防护薄弱**，**相对更易遭袭**（**城镇 / 驿站尤其**）。
- 玩家**可自选是否参战**：发生在自己的城 = **指挥官模式**；路过他人的城 = **援军**（可选参战）。

### 撤退规则（已定 · 2026-10-12 三硬规则）

🔴 **只能退到「大城 / 小城」**（细则见 `第3A类 §5`）：

| # | 硬规则 | 说明 |
|:--:|:--|:--|
| ① | **只能退大城 / 小城** | **城镇 / 驿站 / 村庄均不接收撤退** —— 与上表「安全点（接收撤退）」一列一致 |
| ② | **必须已探明** | 没到过 / 没侦察过的地方，**玩家不知道那儿有没有城** |
| ③ | **由玩家指定** | **不是"最近的那个"、不是"出发时的安全点"** —— 否则玩家走到一半故意往后撤，就**白赚一半路程**（地图等于没风险） |

> 🔴 **为什么不是"退到出发时的安全点"**：那会让玩家**故意往坏地形冲** —— 反正出事就退回起点，风险被系统买单。**「指定 + 已探明」把"退到哪儿"变成玩家自己的决策。**

### 2.2A 车损、弃车与回收（🔴 2026-10-10 用户裁定）

> **用户原话**：「你这辆车可能还能捡回来，但是你可能要带着很多零件去给它修到能开……而且你也要在规定时间内去给它修好。不然的话它也会报废。」  
> **决策过程**：先议"弃车"→ 发现**弃车即永久失去太狠** → 加一步「**可回收**」→ 定「**限时内不修 → 报废**」→ **模块化车（部位化）**。

#### 一、车有四个部位，坏哪个决定什么后果

🔴 **2026-10-14 用户重做** —— 原「车轮 / 车轴 / 车架 / 减震 / 牵引 / 制动」**五部位表作废**，改为 **四部位**。理由：**部位要对应一条真实的损耗渠道**，玩家一眼能预判"什么时候会坏"。

🔴 **每辆车标配四个部位**，部位本身是「那条损耗的缓冲垫」—— 坏了不夺走你的车（还在走），只是**那条损耗失去压制**。

| 部位 | 损耗来源 | 主要坏法 | 🔴 掉到「损坏」后的后果 |
| :--- | :--- | :--- | :--- |
| **车轮** | 行驶 | 磨 / 爆 / 陷 | 🔴 **车辆无法继续前进** |
| **车身** | 战斗 | 打架时受冲击 | 🔴 **车辆无法继续前进** |
| **车架** | 地形 | 烂路 / 碎石 / 托底 | ⚠️ **走烂路时，车轮与车身的磨损翻一倍** |
| **车篷** | 天气 | 大风 / 暴雨 / 灰烬风 | ⚠️ **下雨或恶劣天气时，货物受损** |

**四条渠道互不重叠** —— 跑长途磨车轮 · 打架磨车身 · 走烂路磨车架 · 雨天磨车篷。玩家能按这趟的行程，提前决定要养哪个部位。

| 档 | 名称 | 效果 |

#### 二、弃车 → 回城修 → 拖回来（玩家视角的完整流程）

```
① 车在乙城附近抛锚
   ↓
② 【弃车】车留在原地，脱离车队（不占编制、不占货舱）
   ↓
③ 你带着车队先撤回甲城（有维修能力的地方）休整
   ↓
④ 修好之后，【回收】—— 再走一趟把弃车拖回来
```

**为什么这条流程是合理的**（三条理由）：

| 理由                    | 说明                                                                                |
| :-------------------- | :-------------------------------------------------------------------------------- |
| **① 弃车不等于失去**         | 车**留在原地**，不是永久报废 —— 玩家有第二次机会                                                      |
| **② "限时" = 你多久没回去**   | 🔴 **不写死天数** —— **你的商路如果反复走同一条，你就能救回来**；越走越远不回头的，自然报废。**这样"路线规划"多了一层意义**          |
| **③ "刚出发就坏"是玩家自己的问题** | 车刚出门就抛锚 = **你零件没带够** → 这一趟本来就走不通 → 最后大概率强制撤退回甲城 → **休整一下照样能把车拖回来**。**不是倒霉，是准备不足** |

#### 三、弃车的代价

| 代价              | 内容                                                               |
| :-------------- | :--------------------------------------------------------------- |
| 🔴 **货舱永久减少**   | 弃一辆 = **货舱 −300 格**（小型）/ **−600**（中型）/ **−900**（大型）—— **永久，不可逆** |
| 🔴 **耐久上限永久减少** | 每辆车 **−60**                                                      |
| 🔴 **车上的货要卸**   | 装到别的车上；**装不下的部分只能处理掉**（= 货损）                                     |
| **车夫**          | 🔴 **不减人** —— 他跟着走，去**载人车**或**当后勤**（车夫是**岗位**，不是人）               |

#### 四、回收的代价

| 代价          | 说明                           |
| :---------- | :--------------------------- |
| 🔴 **零件**   | 回收 = **带零件去修** —— 零件用掉了就真没了  |
| 🔴 **时间**   | 要**专门走一趟**去拖回来 —— 这趟的补给和工资照付 |
| 🔴 **车是空的** | 回收的车**没有货** —— 回来后要重新装       |

> **回收是"一次投资"**：你弃车时零件还在，回来时能救回来。**所以"弃"不是终局，是"先保住这趟"。**

### 2.3 耐久损耗

**地形基础损耗（每车独立）：**

- 每车每天 -1.5 耐久（60 天累计 -90/车，已超单辆 60 上限 → 中途必须维修）

**战斗损耗（每车计 · 三辆货车同时扣）：**

| 战斗类型   |   每车损耗  | 全队合计（3 货车） |
| :----- | :-----: | :--------: |
| 普通战斗   |  **-5** |   **-15**  |
| 精英战斗   | **-10** |   **-30**  |
| Boss 战 |  -50 以上 |   -150 以上  |

> **口径（2026-09-14 定）**：战斗损耗按**每辆车**扣，**不是"全队总共扣"**。三辆货车同时受损——"每车 5" = **全队 15**，"每车 10" = **全队 30**。
>
> ⚠️ **Boss 那条也是每车口径**，即一场 Boss ≈ **全队 150 以上**（占上限 180 的 83%）。Boss 是终局战、打完即通关，影响可控；**但若中途中出现 Boss 级撞击（如修车逃生战 §2.5），此值须另定** → 留待战斗层。

**意外缓冲**：远行额外预留约 **+20 耐久/全队**（天气、山路、事故等）。

**一段路（30 天）的耐久账（2026-09-14 核定）：**

| 项                     | 算式               |      全队耐久 |
| :-------------------- | :--------------- | --------: |
| 地形基础                  | 1.5 × 30 天 × 3 车 |   **135** |
| 战斗（5 场 = 4 普通 + 1 精英） | 4×15 + 1×30      |    **90** |
| **合计**                |                  | **≈ 225** |

> **关键结论**：30 天一段路总损耗 **≈225，已超过总上限 180** → **中途必须修车**（刚需，不是可选）。
>
> **单辆车纯自持力 ≈ 24 天**（完全不修车）：每车每天摊销 = 地形 **1.5** + 战斗 **1.0**（90 ÷ 3 车 ÷ 30 天）= **2.5/天** → 60 ÷ 2.5 = **24 天**。
>
> **但玩家随身带零件、能在路上自助修车**（**1 零件 = 10 耐久**，见 §2.4）→ **24~30 天之间的缺口由随身零件补掉**，所以**据点间距 ≈30 天左右**（20~30 天、不固定），**不是被 24 天锁死**。
>
> 🔴 **真正的硬约束是「恢复」，不是「耐久」**：药包只能应急，**让队伍回满的是中继点**（治伤 / 修车 / 补给）—— 所以每段路必须有中继点。


> **60 天典型远行总损耗 ≈ 435 耐久**：地形 270（3车×1.5×60）+ 战斗 165（10 场 = 9 普通 + 1 精英）+ 意外 20。
>   
> 平均摊到每天 ≈ **7.3 耐久/天**；折合零件 ≈ **0.73 个/天**（1 零件 = 10 耐久，50 金/个 → ≈36 金/天）。

| 方式            |   消耗  |               效果               |
| :------------ | :---: | :----------------------------: |
| 城市修理          | 10 金币 |           恢复 20 商队耐久           |
| 驿站修理          | 25 金币 |           恢复 20 商队耐久           |

### 3.5.3 🔴 每天扣几份补给（单元 02 最核心的一条公式）

> 🔴 **在 `src/b02/` 下另开目录** —— 单元 01 的代码保持原样，不许改。

| # | 文件 | 只管什么 | 🔴 不许碰 |
|:-:|:--|:--|:--|
| 1 | `b02/补给.ts` | 🔴 **每天扣几份、够不够、断没断** | 不管买东西 |
| 2 | `b02/车损.ts` | 四部位耐久 · 每格扣多少 · 档位判定 · 损坏后果 | 不管修理 |
| 3 | `b02/士气.ts` | 加减 · 上限 · 消费 | 不管受伤（那是战斗） |
| 4 | `b02/经济.ts` | 买卖价 · 🔴 **物价三档** | 不管订单 |
| 5 | `b02/地点服务.ts` | 🔴 **能干什么**：买 / 修 / 治伤 / 恢复士气 | 不管界面 |
| 6 | `b02/日结算02.ts` | 🔴 **跨日那一刻**：扣补给 · 扣士气 · 车损走一格 | 🔴 **不许改单元 01 的 `跨日()`** |
| 7 | `b02/主循环02.ts` | 🔴 **在单元 01 主循环上加一层** | 🔴 **不许重写单元 01 的九步** |

### 🔴 🔴 本单元最容易出的 bug：跨日被做两次

| 谁 | 做什么 |
|:--|:--|
| 单元 01 `结算.跨日()` | 时间 +1 · 体力 +50 · 天气段推进（🔴 **已写好，不许动**） |
| 🔴 **`b02/日结算02.ts`** | 扣补给 · 扣士气 · 车损走一格 · 重伤恶化 |

> 🔴 **两条链是并行的，不许互相调用** —— 单元 01 的 `跨日()` 不知道补给的存在。
> 🔴 `主循环02` **同时调两个**，但🔴 **各调一次，不许把两个合成一个**（否则又会变成"只回一次体力、却扣了两次补给"）。

## 3.8 🔴 出错了怎么查（不用引擎也能查）

| 症状 | 大概率错在哪 |
|:--|:--|
| 🔴 **一天扣两次补给** | 🔴 `主循环02` 和 `日结算02` 都扣了 —— **只留一处** |
| 🔴 **补给扣了但体力没回** | 两个 `跨日` 互相覆盖了 🔴 看调用链有没有断 |
| 🔴 **5 个人只扣 1 份** | 🔴 用了 `总人数` 而不是 `出战人数` |
| 🔴 **坏车还能走** | `车损.能不能走()` 没被主循环调用 —— **第③步之前可以，第③步之后必须检查** |
| 🔴 **大城比村庄还贵** | 🔴 `物价三档` 没接上 |
| 🔴 **伤员还在扣他那份补给** | 🔴 `出战人数` 没在受伤后减掉 |
