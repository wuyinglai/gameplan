### 3.4 json 的实际结构（🔴 实测过，不许猜）

```json
{
  "map": { "width": 400, "height": 400 },
  "start": [10, 199],
  "end": [390, 389],
  "note": "...",
  "locations": [ { "t": "big", "x": 10, "y": 199 }, ... ]   // 41,131 条
}
```

🔴 **`start` / `end` 是数组不是对象** —— `[10, 199]` 不是 `{x:10, y:199}`。
🔴 **加载时要转**：`起点 = { x: raw.start[0], y: raw.start[1] }`。

🔴 **`locations` 里每条只有 4 个字段**：`t` · `x` · `y` · `r`（`r` 可能没有）

🔴 **实测的类型分布与路况分布**（🔴 用来写断言，不是让你硬编码）：

| `t` | 含义 | 格数 | `r` |
|:--|:--|--:|:--|
| `big` | 大城 | 1 | 无 |
| `small` | 小城 | 3 | 无 |
| `town` | 城镇 | 18 | 无 |
| `village` | 村庄 | 41 | 无 |
| `inn1` | 驿站 | 34 | 无 |
| `special` | 🔴 映射成营地（见施工图 §6.4） | 10 | 无 |
| `road` | 商路 → 空地 | **4,840** | 🔴 **r=0 2,886 / r=2 1,954** |
| `blk_fr` | 可通行地形（桥/碎石） | 1,464 | 🔴 **r=2 1,255 / 无 209** |
| `block` | 🔴 **不可通行**（山/裂谷） | **32,823** | 无 |
| `blk_wt` | 🔴 **不可通行**（水/河） | **1,897** | 无 |

> 🔴 **`road` 里有 1,954 格标了 `r=2`（差路况）** —— 🔴 这是**数据疑点**（见施工图 §6.5），
> 🔴 **你不要"修正"它**，🔴 照实读，写进回执的「已知问题」。

## 6. 🔴 一条不许踩的坑（🔴 旧代码踩过）

**跨日只能有一个入口。**

```
主循环调 结算.跨日()  ✅
主循环自己也回体力   ❌  → 一天回两份（+100 而不是 +50）
```

🔴 **怎么防**：🔴 `第几天` 和 `当前小时` 🔴 **只有 `结算.跨日()` 能改**，
🔴 其余任何文件碰这两个字段都是 bug。🔴 判据 §23 就是抓这个。
