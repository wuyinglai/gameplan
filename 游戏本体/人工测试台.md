# 人工测试台（浏览器 UI）· 使用说明

> 用途:让你**手动点几下**就能确认 P1 旅行逻辑和 P2 资源字段没问题。
> 🔴 这个页面**不含任何游戏规则** —— 它只调用 `src/p1`、`src/p2` 里已经写好并测过的函数,
> 所以页面显示的数字就是模块真实算出来的数字。规则要出错,锅在被调的模块,不在页面。

## 怎么起

```
cd C:\Users\Administrator\Desktop\游戏大纲\游戏本体
npm run ui
```

然后浏览器打开 **http://localhost:5173**(端口被占就改 `npx vite --port 5180`)。
不想开服务器也可以 `npm run ui:build`,产物在 `dist/`,双击 `dist/index.html` 前的提示看底下「已知小坑」。

## 操作

| 做什么 | 怎么按 |
|:--|:--|
| 走一格 | **方向键** 或 **WASD**(北 = y+1,地图原点在左下角) |
| 结束当天 | **空格** 或「结束当天」按钮 |
| 重开一局 | **+R** 或「重开」按钮 |
| 打边界判据 | 「测试:斜着走 / 隔两格走 / 往图外走 / 体力清成 0」四个按钮,专门测判据 2 / 3 / 4 / 18 |
| P2~P7 操作 | 虚线那排(侦察/采集/搜索/补给/修车/治疗/交易)—— 现在**全部该被拒「本阶段未实现」** |
| 看附近/看全图 | 「视野 ±」改放大倍数;右边小地图永远是整张 400×400 |

## 每点一次该看到什么(照这个核对)

| 动作 | 期望 |
|:--|:--|
| 走一格 | 时刻 **+2 小时**、体力 **−15**、坐标变 1 格 |
| 走到 19:00 | **自动跨日** → 第 N+1 天 07:00、体力 **+50 封顶 100** |
| 斜着走 / 隔两格 | ❌ 拒绝:**不是相邻格** |
| 往图外走 | ❌ 拒绝:**出地图了** |
| 撞山 / 撞水 | ❌ 拒绝:**过不去** |
| 体力清零后再走 | ❌ 拒绝:**体力不够** |
| 「结束当天」连点两次 | 第一次 ✅ 跨日,第二次 ❌ **今天已结算过了**(幂等) |
| 天气/路况 | 每格消耗恒 **15**,状态栏会写明「加成未裁定 → 恒 0」 |
| P2 资源那行 | 八个字段恒 **0**(第 1 步只有字段,不扣不加) |

日志每行前面有**序号**,报问题时直接说「第 07 行:结束当天被拒但体力还是 70」这种,我能立刻定位。

## 颜色

`大城`黄 `小城`橙黄 `城镇`绿 `村庄`深绿 `驿站`蓝 `special→营地`紫
`深灰`=山/裂谷(不可通行) `深蓝`=水/河(不可通行) `棕灰`=碎石地或桥(可通行) `亮棕`=商路(r=0)

## 三条照实说明(不算 bug,但你测试时会被绊到)

1. **天气与路况的消耗恒 15** —— `§6.1 / §6.2` 的加成数值还没裁定,两张表全 0。
   所以暴雨和晴朗走一格**都是 15**,这是当前口径,不是测坏了。
2. **起点(10,199)是大城,但脚下「已到访 = false」** —— 「走进地点格」才置 true,
   **开局就站在原地**不会触发。要不要「开局即已到访」归项目主裁定(P2 第 3 步地点服务用得上)。
3. **P2 资源永远全 0** —— 扣补给 / 断粮惩罚是第 2 步的事,现在还不动。
