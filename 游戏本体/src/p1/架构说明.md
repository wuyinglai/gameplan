## 二、一次「走一格」经过哪几个文件

```
   [移动.test.ts]   ← 测试：调它，检查每个结果对不对
        ↓
   [移动.ts]        ← 九步：范围 → 相邻 → 可通行 → 体力 → 时间 → 提交 → 到点？→ 跨日 → 标记
        ↓ 问            ↓ 问                    ↓ 问          ↓ 问
   [地图.ts]      [消耗.ts] → [天气.ts]     [时间.ts]      [体力.ts]
   查格 / 判相邻    15 + 天气 + 路况          只加数         够吗 / 扣
        ↓ 到点就调一次（🔴 只调一次）
   [结算.ts] 跨日() → 天数 +1 · 时钟 07:00 · 体力 +50封顶 · 天气段 −1
```

**读法**：🔴 箭头 = 谁调用谁。`消耗.ts` 与 `结算.ts` 是两条**唯一出口**，别处出现第二份就是 bug。

## 三、状态里每个字段谁能写（施工图 §2.2 + §3）

| 字段 | 初值 | 谁能写 | 为什么只有它能写 |
|:--|:--|:--|:--|
| `当前坐标` | 地图起点 | `移动.ts` | 只有走一格会挪位置 |
| `第几天` / `当前小时` | 1 / 7 | 🔴 **只有 `结算.跨日()`** | 旧代码踩过：主循环也回体力 → 一天回两份 |
| `野外体力` | 100 | `体力.扣()` / `体力.回()` | 回体力只发生在跨日那一刻 |
| `体力上限` | 100 | 🔴 没人写（常量） | 恒为 100，不许加档 |
| `当前天气` / `天气剩余天数` | 晴朗 / 5 | `天气.推进天气段()` | 由跨日触发 |
| `今天已结算` | false | 置 true = `结算.跨日()`；清 false = `时间.推进()` | 见下面那段 |

### 为什么「清标记」放在 `时间.推进()`（🔴 唯一一处我自己拍的设计，已写进回执）

幂等标记必须清回 false，否则**跨日之后那一天永远点不了「结束当天」** —— 而判据 26/27 恰恰要求它任何时候都能用。
放这里的三个理由：① 「推进了时间」= 这一天还在继续 = 没有可结束的今天；② 不碰 `第几天` / `当前小时`（禁止事项 57 仍成立）；
③ 不违反 §4 步骤 ⑥「只有三个改动」。顺序也安全：`推进()`（清）→ `跨日()`（置）。

### 🔴 那 2 条 skip 是什么（不是偷懒）

| 判据 | 内容 | 为什么 skip |

| 41 | 指定晴朗 vs 指定暴雨，扣的点必须不同 | 天气每格加成待裁定（施工图 §6.1：1A 与 5A 互相矛盾） |

裁定之后只改 `天气.ts` 与 `消耗.ts` 各一张表、去掉 `.skip` —— 这两条就是验收线。
