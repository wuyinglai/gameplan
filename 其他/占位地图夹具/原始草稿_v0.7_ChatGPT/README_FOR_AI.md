# 余烬商队 · 400×400测试地图 v0.7（特殊建筑探索距离微调版）

**仅供测试开发，不并入正式版地图、地点清单或正式世界观。** 地点名采用“类别+编号”，无正式命名。空白格不生成记录。

## 推荐读取顺序
1. `05_reference/legend_and_map_reading.md`：先看图形、路线和地形说明。
2. `05_reference/preview.jpg`：总览；`map_only.jpg`看地图；`legend_only.jpg`看图例。
3. `05_reference/map_layout_compact.json`：全局结构摘要。
4. 按任务读取分类文件夹：地点、地形、道路路线或订单。
5. `05_reference/validation_report.md`：检查结果；聚落密度看 `cluster_density_check.csv`，中继间距看 `relay_segment_intervals.csv`。

## 文件分工
- `01_locations/`：城市、城镇、村庄、驿站、特殊建筑。
- `02_terrain/`：河流、山地、裂谷、桥梁、山口及碎石地的形状与格子。
- `03_roads_and_routes/`：逐格路线坐标、主路/险道类别、路线摘要和驿站链接。
- `04_orders/`：测试订单及可选路线，不锁死玩家走法。
- `05_reference/`：图例、预览、布局摘要、聚落/中继/路线检查。

## 规则口径
- 400×400，左上角为(0,0)，x向右、y向下。游戏内只允许上下左右移动一格。
- 河流不可直接穿越，只能走桥梁；山地/裂谷不可通行；山口是合法缺口。
- 虚线为较短/较险路线；实线为略绕、路况较好的主商路；颜色表示城市对。
- 主商路中继区段参考约90格/30天；不是全地图的最大距离。
- 聚落按城市聚居圈成簇：城镇围绕城市，村庄更多靠近本圈城镇，不均匀撒点。


## v0.7 特殊建筑距离规则
- 特殊建筑尽量位于商路附近的可探索区域，但不直接贴在商路上。
- 目标是距最近可通行商路约27–38格；少数地点可略远。按3格/天，单程约9–13天。
- 坐标距离采用实际可通行格的步数，不采用直线距离。具体位置见 `01_locations/special_structures.csv`；变更前后对照见 `05_reference/special_structure_detour_check.csv`。
