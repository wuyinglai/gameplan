## 🔴 三条硬规矩

**① 编程 AI（Hermes）不许改 `游戏大纲\` 里的任何文件**
- 🔴 `0A_权威系统文档\` `A类文件附件\` `B类_开发文档\` —— **一律不许动**
- 🔴 代码写在 `游戏本体\src\b01\`，**不写进本仓库**
- 发现文档有问题 → 🔴 **写进 `AI交流\`，说清楚，不要自己改**

**② 有疑问就停下问，不要自己挑一个方案**
> 上一轮就是这么出事的：某份指令写"数值照抄 5A §2.3"，
> 可那儿根本没这个数 → AI 自己猜了一个 → **违反"不许自创"**。
> 🔴 **停下问一句，比猜一个值省事得多。**

**③ 三份文档冲突时，以顺序为准**
```
施工图（规则搬入 + 数据结构 + 主循环）
  ↓ 实施顺序以它为准
开发流程（🔴 唯一的执行顺序 · 5 刀垂直切片）
  ↓ 怎么验以它为准
测试用例（17 条 · 测的时候填结果）
```
